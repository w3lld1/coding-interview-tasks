# Задачи для технических собеседований

[English version](README.en.md)

Задачи по программированию для собеседований и тренировки, разложенные по темам: строки, массивы, динамическое
программирование, графы, асинхронность, SQL и другие. Сейчас их 2234. Здесь только условия: тесты, подсказки и эталонные решения
живут на сайте.

Каждую задачу можно решить в браузере, ничего не устанавливая: кнопка «Решить онлайн» открывает её на
[CodeShare](https://code-share.ru/?utm_source=github&utm_medium=tasks-repo) с редактором, запуском кода и автопроверкой. Там же задачу можно взять на
собеседование: создать сессию и отправить кандидату одну ссылку.

## Лицензии

Условия взяты из открытых наборов задач и пересказаны на русском и английском или написаны для CodeShare. В конце
каждой задачи указаны её источник и лицензия. Подробности: [LICENSE.md](LICENSE.md).

Репозиторий собирается из банка задач CodeShare. Нашли ошибку в условии? Откройте issue.
