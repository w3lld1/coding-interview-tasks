# Coding interview tasks

[Русская версия](README.md)

1321 programming tasks for interviews and practice, grouped by topic: strings, arrays, dynamic programming,
graphs, async code, SQL and more. This repository holds the statements only: tests, hints and reference solutions
live on the site.

Solve any task in the browser with nothing to install: the «Solve online» button opens it on
[CodeShare](https://code-share.online/?utm_source=github&utm_medium=tasks-repo) with an editor, code execution and automatic checks. You can also use
a task in an interview there: create a session and send the candidate one link.
