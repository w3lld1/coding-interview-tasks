# A member’s first booking next to each of their bookings

**Difficulty:** easy · **Language:** SQL (SQLite) · **Topics:** [SQL: window functions](../sql-window/), [SQL: joins](../sql-join/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-905?utm_source=github&utm_medium=tasks-repo)**

For each booking of July 2012 (before 1 August) made by a club member (not the guest, `memid = 0`) output the columns `bookid`, `memid`, `surname` and `first_booking`, the start time (`starttime`) of that member's earliest booking. The club has namesakes, and each of them has their own first booking. The row order does not matter.

The tables and data are already in the starter code and are created afresh on every run (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — club facilities; `membercost` and `guestcost` are the price of one slot for a member and for a guest.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — members; `recommendedby` is the `memid` of who invited them, or `NULL`; `memid = 0` is a guest.
- `bookings(bookid, facid, memid, starttime, slots)` — bookings; one slot is 30 minutes; `starttime` is text such as `2012-09-14 09:00:00`.
