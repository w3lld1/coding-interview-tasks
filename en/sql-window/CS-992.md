# The latest booking is longer than all before

**Difficulty:** hard · **Language:** SQL (SQLite) · **Topics:** [SQL: window functions](../sql-window/), [SQL: filtering](../sql-filter/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-992?utm_source=github&utm_medium=tasks-repo)**

Find the `memid` values with two or more bookings in `bookings` (the guest with `memid = 0` counts too) whose latest booking by `starttime` is longer in `slots` than each of their earlier ones. Output the columns `memid`, `bookid` (the latest booking) and `slots`. No `memid` has two bookings with one `starttime`. The row order does not matter.

The tables and data are already in the starter code and are created afresh on every run (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — club facilities; `membercost` and `guestcost` are the price of one slot for a member and for a guest.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — members; `recommendedby` is the `memid` of who invited them, or `NULL`; `memid = 0` is a guest.
- `bookings(bookid, facid, memid, starttime, slots)` — bookings; one slot is 30 minutes; `starttime` is text such as `2012-09-14 09:00:00`.
