# A facility's hot booking streaks

**Difficulty:** hard · **Language:** SQL (SQLite) · **Topics:** [SQL: window functions](../sql-window/), [SQL: aggregation](../sql-aggregate/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-973?utm_source=github&utm_medium=tasks-repo)**

Call a streak a chain of bookings of one facility in which each next booking starts no later than 24 hours after the start of the previous one; a booking that starts later opens a new streak. All bookings count, the guest's included. For streaks of two or more bookings output the columns `facid`, `first_start` (the start of the streak's first booking), `last_start` (the start of its last one) and `bookings` (the number of bookings). The row order does not matter.

The tables and data are already in the starter code and are created afresh on every run (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — club facilities; `membercost` and `guestcost` are the price of one slot for a member and for a guest.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — members; `recommendedby` is the `memid` of who invited them, or `NULL`; `memid = 0` is a guest.
- `bookings(bookid, facid, memid, starttime, slots)` — bookings; one slot is 30 minutes; `starttime` is text such as `2012-09-14 09:00:00`.
