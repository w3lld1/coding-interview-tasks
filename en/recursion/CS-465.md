# Dice outcomes with a sum

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-465?utm_source=github&utm_medium=tasks-repo)**

`dice` ordinary six-sided dice are rolled one after another (the order matters: `[1, 4]` and `[4, 1]` are different outcomes). Return all outcomes in which the points add up to `total`. Each outcome is a list of the dice values in order; outcomes are in lexicographic order (lists compared element by element from the left). If no outcome fits, return an empty list. Assume `1 ≤ dice ≤ 5` and `total ≥ 0`.

Example: `2`, `5` → `[[1, 4], [2, 3], [3, 2], [4, 1]]`.
