# Killer Sudoku cage combinations

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-62?utm_source=github&utm_medium=tasks-repo)**

A Killer Sudoku cage has several cells; the digits in them are from 1 to 9, never repeat, and add up to a given sum. You get the sum `total`, the cage size `size` and a list of forbidden digits `exclude` (they are already in the row or column). Return all sets of `size` different digits that are not in `exclude` and add up to `total`. Digits inside a set go in ascending order, and the sets are in lexicographic order (compare by the first digit, then the second, and so on). If no set fits, return an empty list.

Example: `10`, `2`, `[1, 4]` → `[[2, 8], [3, 7]]`.
