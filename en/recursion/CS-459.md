# Cantor ruler

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-459?utm_source=github&utm_medium=tasks-repo)**

A ruler is drawn in stages. Level 0 is a single mark `"-"`. Level `n` is built from level `n - 1`: write the level `n - 1` string, then as many dots `.` as its length, then the level `n - 1` string again. Return the string of level `n`. Assume `n` is at most 7.

Example: `2` → `"-.-...-.-"` (level 1 is `"-.-"`).
