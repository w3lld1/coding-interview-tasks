# Googol string

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-32?utm_source=github&utm_medium=tasks-repo)**

Define strings of zeros and ones: `S1 = "0"`, and `S(N) = S(N-1) + "0" + flip(reverse(S(N-1)))`, where reverse writes the string backwards and flip turns every `0` into `1` and vice versa. This gives `S2 = "001"`, `S3 = "0010011"`, `S4 = "001001100011011"` and so on. Each string is a prefix of the next, so the sequence has a limit: an infinite string. Return its `k`-th character (counting from 1) as the number `0` or `1`.

Limits: `1 ≤ k ≤ 9·10^15`.

Example: `3` → `1` (the third character of `S2 = "001"` is `1`); `10` → `0`.
