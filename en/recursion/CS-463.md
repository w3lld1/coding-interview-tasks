# Sums of picking from a list

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-463?utm_source=github&utm_medium=tasks-repo)**

A wallet holds banknotes whose values are the list `numbers` (repeats are possible; negative numbers and zero are allowed too, treat them as plain numbers). You may take any set of notes, including none. Return all distinct sums you can get, in ascending order. The empty set gives `0`, so it is always present. The list has at most 12 items, each of absolute value at most 100.

Example: `[1, 2, 3]` → `[0, 1, 2, 3, 4, 5, 6]`.
