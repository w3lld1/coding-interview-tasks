# Splitting a row into piles

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-468?utm_source=github&utm_medium=tasks-repo)**

You must lay `n` tiles in a row as several consecutive piles, each pile holding at least one tile; the order of piles matters (`[1, 2]` and `[2, 1]` are different layouts). Return all layouts: each is a list of pile sizes from left to right, summing to `n`. Layouts are in lexicographic order (lists compared element by element from the left). For `n = 0` there is one layout, the empty list. Assume `n` is at most 8.

Example: `3` → `[[1, 1, 1], [1, 2], [2, 1], [3]]`.
