# Flatten Array

**Difficulty:** medium · **Language:** Java · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-10?utm_source=github&utm_medium=tasks-repo)**

Convert a list containing numbers and nested lists of arbitrary depth into a single flat list of numbers. Preserve the left-to-right traversal order and skip null values at any nesting level. Empty nested lists add no elements to the result.
