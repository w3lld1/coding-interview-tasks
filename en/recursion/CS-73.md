# Ways to place non-attacking queens

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-73?utm_source=github&utm_medium=tasks-repo)**

Given an integer `n` from 1 to 10, count the ways to place `n` queens on an `n × n` board so that no two attack each other: no queen shares a row, a column or a diagonal (in either direction) with another. Placements that turn into each other by rotating or reflecting the board count as different. If the queens cannot be placed, return `0`.

Example: `6` → `4`.
