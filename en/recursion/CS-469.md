# Nested min, max and sum calls

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-469?utm_source=github&utm_medium=tasks-repo)**

The string `expr` is an expression with no spaces. It is either an integer (possibly with a minus sign) or a call `name(arg1,arg2,…)`, where the name is `min`, `max` or `sum` and each argument (one or more) is itself an expression of this kind. A call returns the smallest argument value, the largest, or their sum respectively. Return the value of the whole expression. The expression is valid, nesting is at most 10, and all values fit in a 32-bit integer.

Example: `"max(3,min(5,2),sum(1,1))"` → `3` (the arguments are 3, 2 and 2).
