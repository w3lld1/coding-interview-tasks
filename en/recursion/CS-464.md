# Missing bits

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-464?utm_source=github&utm_medium=tasks-repo)**

A sensor sent a bit mask where some bits were lost and marked with `?`. The string `pattern` has only the characters `0`, `1` and `?`. Return all strings obtained by replacing every `?` with `0` or `1`, in ascending order (as strings). If there is no `?`, the answer is a list with the string itself; for an empty string it is a list with the empty string. There are at most 6 question marks.

Example: `"1?0?"` → `["1000", "1001", "1100", "1101"]`.
