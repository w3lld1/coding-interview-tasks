# Lamps with no neighbours

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-452?utm_source=github&utm_medium=tasks-repo)**

A garland has `n` lamps, each on (`1`) or off (`0`). Two lit lamps next to each other are not allowed. Return every valid state of the garland as a string of `0`s and `1`s of length `n`, in ascending order (as strings, left to right; `0` before `1`). For `n = 0` there is one state, the empty string. Assume `n` is at most 10.

Example: `3` → `["000", "001", "010", "100", "101"]`.
