# Balanced bracket strings

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-66?utm_source=github&utm_medium=tasks-repo)**

Given a number `n` from 0 to 8, return all balanced strings made of `n` pairs of round brackets: every `(` is closed by its own `)`, and no prefix has more closing brackets than opening ones. Order the strings ascending as ordinary strings, where `(` is smaller than `)`. For `n = 0` the only string is the empty one, so the answer is `[""]`.

Example: `3` → `["((()))", "(()())", "(())()", "()(())", "()()()"]`.
