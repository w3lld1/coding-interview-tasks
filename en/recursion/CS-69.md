# Unique subsets

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-69?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, possibly with repeats, of at most 10 elements, return all distinct subsets (including the empty one and the whole list), where two subsets are the same if their sorted forms are equal. Write each subset in non-decreasing order. Order the subsets lexicographically: compare element by element, and if one is a prefix of the other, the shorter comes first (so the empty subset is first).

Example: `[2, 1, 2]` → `[[], [1], [1, 2], [1, 2, 2], [2], [2, 2]]`.
