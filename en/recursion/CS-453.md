# Gray code

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-453?utm_source=github&utm_medium=tasks-repo)**

A rotary switch with `n` bit positions is encoded as a string of `n` bits. You need an order of all `2^n` codes in which neighbouring codes differ in exactly one bit (the reflected Gray code). Build it like this: for `n = 0` the list is `[""]`; for `n > 0` take the list for `n - 1`, put `0` in front of each code, then the same list in reverse order with `1` in front. Return the list of strings. Assume `n` is at most 8.

Example: `2` → `["00", "01", "11", "10"]`.
