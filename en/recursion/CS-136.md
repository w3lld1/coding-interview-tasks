# Word on a letter grid

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-136?utm_source=github&utm_medium=tasks-repo)**

Given a grid of letters (a list of equal-length non-empty strings, up to 6×6) and a non-empty word, return `true` if the word can be read by moving between cells that share a side (up, down, left, right; no diagonals) without using any cell twice. The first letter may be in any cell. Case matters.

Example: `["ab", "cd"]`, `"abdc"` → `true`; `"abab"` → `false`.
