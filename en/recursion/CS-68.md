# Combinations with a target sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-68?utm_source=github&utm_medium=tasks-repo)**

Given a list of distinct positive integers `candidates` (at most 20) and an integer `target` from 1 to 40, return all distinct sets of numbers from `candidates` whose sum is `target`; each number may be used any number of times. Sets that differ only in the order of numbers are the same, so write each set in non-decreasing order. Order the sets themselves lexicographically. If no set fits, return an empty list.

Example: `[2, 3, 6, 7]`, `7` → `[[2, 2, 3], [7]]`.
