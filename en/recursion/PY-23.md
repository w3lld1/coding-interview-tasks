# Alphametics

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Math](../math/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-23?utm_source=github&utm_medium=tasks-repo)**

Solve an addition puzzle of the form WORD + WORD == RESULT in which letters stand for decimal digits. The same letter always means the same digit, different letters get different digits, and a multi-digit number cannot start with zero. Return a map from letter to digit that makes the equation true, or an empty map if there is no solution.
