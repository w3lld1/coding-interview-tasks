# Depth-weighted sum

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-457?utm_source=github&utm_medium=tasks-repo)**

The string `text` describes a nested list of integers: elements are separated by commas with no spaces, nested lists are wrapped in square brackets, and the whole string is one list (for example `[1,[4,[6]]]`). Numbers may have several digits and may be negative. Each number is multiplied by the depth of its list: the outer list has depth 1, a list inside it depth 2, and so on. Return the sum of all these products. If there are no numbers (for example `[]`), the answer is `0`. The depth is at most 20.

Example: `"[1,[4,[6]]]"` → `27` (1·1 + 4·2 + 6·3).
