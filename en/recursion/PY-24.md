# Dominoes

**Difficulty:** hard · **Language:** Python · **Topics:** [Recursion and backtracking](../recursion/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-24?utm_source=github&utm_medium=tasks-repo)**

Arrange the given pairs of numbers into a closed domino chain, using each input domino exactly once. The touching halves of adjacent dominoes must match, as must the outer values of the first and last dominoes; dominoes may be flipped. Identical pairs count as separate dominoes. Return any valid sequence, an empty sequence for empty input, or None if no chain can be built.
