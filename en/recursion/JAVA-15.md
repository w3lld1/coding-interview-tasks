# Dominoes

**Difficulty:** hard · **Language:** Java · **Topics:** [Recursion and backtracking](../recursion/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-15?utm_source=github&utm_medium=tasks-repo)**

Arrange all the given dominoes into a closed chain so that the touching halves of adjacent dominoes match and the two free ends match as well. A domino may be flipped, but each occurrence must be used exactly once, including identical copies. Return any valid sequence or report that the chain cannot be built.
