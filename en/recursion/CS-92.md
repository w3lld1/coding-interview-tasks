# Operators between digits to hit a target

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-92?utm_source=github&utm_medium=tasks-repo)**

You are given a string of digits (0 to 10 characters) and an integer `target`. Between neighbouring digits you may put nothing (the digits merge into one number) or one of the signs `+`, `-`, `*`; the digits keep their order, and no sign goes before the first digit. A number of several digits may not start with `0` (a lone `0` is fine). The expression is evaluated by the usual rules: multiplication before addition and subtraction; intermediate values may exceed 32 bits. Return every expression whose value equals `target`, without spaces, sorted in ascending string order (character by character by code: `*` < `+` < `-` < digits). If there is none, or the string is empty, return `[]`.

Example: `"232"`, `8` → `["2*3+2", "2+3*2"]`.
