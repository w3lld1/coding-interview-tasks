# Flatten Array

**Difficulty:** medium · **Language:** Python · **Topics:** [Recursion and backtracking](../recursion/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-03?utm_source=github&utm_medium=tasks-repo)**

Convert a list with nested lists of arbitrary depth into a single flat list. Preserve the order of elements in a left-to-right traversal and skip every None value at any level. Empty nested lists must add nothing to the result.
