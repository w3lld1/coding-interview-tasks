# Switch panel settings

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-466?utm_source=github&utm_medium=tasks-repo)**

A panel has `n` switches in a row. Exactly `k` of them must be on. Return all such settings as strings of `n` characters (`1` for on, `0` for off), left to right, in ascending order (as strings). If no setting fits, return an empty list. For `n = 0`, `k = 0` the answer is a list holding the empty string. Assume `n` is at most 10.

Example: `3`, `1` → `["001", "010", "100"]`.
