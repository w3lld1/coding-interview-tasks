# Letter case variants

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-458?utm_source=github&utm_medium=tasks-repo)**

In a password each Latin letter may be written in lower or upper case, while digits stay as they are. Return all distinct variants of the string `text` obtained by choosing a case for every letter (the original case of the letters does not matter). Order: left to right, with the lower-case choice before the upper-case one at each letter, so the first letter changes slowest. The string has only Latin letters and digits, at most 8 letters. A string without letters has one variant, itself.

Example: `"a1b"` → `["a1b", "a1B", "A1b", "A1B"]`.
