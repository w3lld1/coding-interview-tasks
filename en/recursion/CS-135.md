# Split digits into an IP address

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-135?utm_source=github&utm_medium=tasks-repo)**

Given a string of digits, insert three dots so that it becomes a valid IPv4 address: four parts, each a decimal number from 0 to 255 with no leading zeros (the part `0` is fine, `01` and `00` are not). Digits cannot be reordered, removed or added. Return all such addresses sorted ascending as strings; if there are none (including for an empty string), return an empty list. The string has at most 20 characters.

Example: `"25525511135"` → `["255.255.11.135", "255.255.111.35"]`.
