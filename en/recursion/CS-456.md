# Words from phone keys

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Recursion and backtracking](../recursion/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-456?utm_source=github&utm_medium=tasks-repo)**

On a keypad phone the letters are laid out like this: `2` — `abc`, `3` — `def`, `4` — `ghi`, `5` — `jkl`, `6` — `mno`, `7` — `pqrs`, `8` — `tuv`, `9` — `wxyz`. You get a string of digits `2`–`9`. Return every string of letters that these presses can type (one letter per digit). Order: the last letter changes fastest, then the one before it, and so on; letters on one key go as in the table. For an empty string return an empty list. Assume at most 5 digits.

Example: `"23"` → `["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]`.
