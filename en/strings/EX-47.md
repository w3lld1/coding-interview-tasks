# Letter diamond

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-47?utm_source=github&utm_medium=tasks-repo)**

Given an uppercase Latin letter `letter` from `A` to `Z`, build a diamond of letters: the first row has one `A`, then the letters go up the alphabet to `letter` in the widest row, and then back down to `A` in the last row. Return a list of rows.

All rows have the same length `2·k + 1`, where `k` is the index of the given letter (`A` is 0), padded with spaces on both sides. Every row except the first and the last has two identical letters, the `A` rows have one. The diamond is symmetric horizontally and vertically. For `A` the result is `["A"]`.

Example: `"C"` → `["  A  ", " B B ", "C   C", " B B ", "  A  "]`.
