# Rotation as a substring

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-154?utm_source=github&utm_medium=tasks-repo)**

You get two strings: `text` and `word`. Return `true` if `text` contains as a substring either `word` itself or any of its rotations (moving some leading characters to the end), otherwise `false`. An empty `word` occurs in every text, so the answer for it is `true`.

Example: `"efef"`, `"fee"` → `true` (the rotation `"efe"` is at the start of `"efef"`).
