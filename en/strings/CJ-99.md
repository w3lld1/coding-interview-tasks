# Overlap of two star patterns

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-99?utm_source=github&utm_medium=tasks-repo)**

A pattern consists of Latin letters (upper and lower case differ) and stars `*`. A string of letters matches the pattern if every star can be replaced by a string of **zero to four** arbitrary letters so that the pattern equals the string. For example, `Gone**` matches `GoneGirl` and `GoneTomorrow`, but neither `Gonetomorrow` (one letter too many) nor `TheGoneGirl`.

Given two patterns of length at least `1`, return `true` if some string (possibly empty) matches both, otherwise `false`.

Limits: each pattern is up to `200` characters long, with any number of stars.

Example: `"Shakes*e"`, `"*peare"` → `false` (the star at the start of the second pattern cannot cover the six letters `Shakes`).
