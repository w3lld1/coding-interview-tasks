# Prime digits in a hex string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-78?utm_source=github&utm_medium=tasks-repo)**

You get a string with a hexadecimal number: digits `0`–`9` and uppercase letters `A`–`F`. Count how many of its digits have a prime value. Those digits are `2`, `3`, `5`, `7`, `B` (11) and `D` (13). For an empty string return `0`.

Example: `"AB"` → `1`; `"1077E"` → `2`; `"2020"` → `2`.
