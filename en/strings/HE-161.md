# Flip case or reverse

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-161?utm_source=github&utm_medium=tasks-repo)**

You get a string of ASCII characters. If it contains at least one Latin letter, swap the case of every letter (lowercase to uppercase and vice versa) and leave the other characters as they are. If it has no letters, return the string written in reverse order. An empty string stays empty.

Example: `"#a@C"` → `"#A@c"`; `"1234"` → `"4321"`.
