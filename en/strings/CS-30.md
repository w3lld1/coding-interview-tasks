# Word break

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-30?utm_source=github&utm_medium=tasks-repo)**

You get a string `s` of lowercase Latin letters (up to 300 characters) and a list of dictionary words. Each word can be used any number of times. Return `true` if `s` can be cut into consecutive parts so that every part is a dictionary word, otherwise `false`. The empty string can always be split (into zero parts), even with an empty dictionary.

Example: `"leetcode"`, `["leet", "code"]` → `true`.
