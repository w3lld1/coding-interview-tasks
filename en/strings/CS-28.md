# Edit distance

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-28?utm_source=github&utm_medium=tasks-repo)**

You get two strings of lowercase Latin letters, each at most 500 characters (a string may be empty). In one operation you can insert a character anywhere, delete any character, or replace any character with another. Return the smallest number of operations that turn the first string into the second.

Example: `"horse"`, `"ros"` → `3` (horse → rorse → rose → ros).
