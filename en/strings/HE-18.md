# Overlapping occurrences

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-18?utm_source=github&utm_medium=tasks-repo)**

Given a string and a non-empty substring, return how many times the substring occurs in the string. Occurrences may overlap: in `"aaaa"` the substring `"aa"` occurs three times. If the substring is longer than the string, the answer is `0`.

Example: `"aaaa"`, `"aa"` → `3`.
