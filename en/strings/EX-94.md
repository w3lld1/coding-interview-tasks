# Guess the word by letters

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Errors and exceptions](../errors/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-94?utm_source=github&utm_medium=tasks-repo)**

A player guesses a secret word (non-empty, lowercase letters) by naming one letter at a time. You get the list of named letters in order. Rules:
- A named letter is a failure if it is not in the word **or** it was already named before (even a correct letter named again).
- Remaining failures: `9 - the number of failures`, but not below 0.
- The game is won when all letters of the word have been named; it is lost when 10 failures are made. Otherwise it goes on.
- The word is masked: revealed letters stay, the others become `_`.

Return the string `"<state> <mask> <remaining failures>"`, where the state is `Ongoing`, `Win` or `Lose`.

If a letter is named when the game is already won or lost, report an error: throw an exception, or return an error in Go.

Example: `"loot"`, `["t", "t", "o"]` → `"Ongoing _oot 8"`.
