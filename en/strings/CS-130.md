# Anagram start positions

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-130?utm_source=github&utm_medium=tasks-repo)**

Given strings `s` and `p` of lowercase Latin letters, return all indexes `i` (in increasing order) at which a substring of `s` of length `len(p)` starts that is an anagram of `p`, that is, made of the same letters with the same counts in any order. If there are none or `p` is longer than `s`, return an empty list. `p` is not empty and `s` has up to 5000 characters.

Example: `"cbaebabacd"`, `"abc"` → `[0, 6]` (the substrings `cba` and `bac`).
