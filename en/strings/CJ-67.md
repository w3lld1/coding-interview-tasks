# Worst-case trie sharding

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-67?utm_source=github&utm_medium=tasks-repo)**

You are given a list `words` of M distinct non-empty strings of uppercase Latin letters and a number of servers `servers` (1 ≤ servers ≤ M). The strings are split among the servers: each string goes to exactly one server, every server gets at least one string, and the servers are distinguishable. Each server builds a trie of its strings: one node for every distinct prefix of its strings, including the empty prefix (the root).

Return a list of two numbers: the largest possible total number of nodes over all servers, and the number of splits that reach it, modulo 1 000 000 007. Limits: M ≤ 400, string length ≤ 12, servers ≤ 100.

Example: `["AAA", "AAB", "AB", "B"]`, `2` → `[10, 8]`.
