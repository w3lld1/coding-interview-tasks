# Isogram check

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-61?utm_source=github&utm_medium=tasks-repo)**

An isogram is a word or phrase in which no letter repeats; spaces and hyphens may repeat any number of times. Letter case does not matter: `A` and `a` are the same letter. Return `true` if the string is an isogram, otherwise `false`. An empty string is an isogram.

Example: `"six-year-old"` → `true`, `"isograms"` → `false`.
