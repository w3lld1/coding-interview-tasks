# Pattern match with dots and stars

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-77?utm_source=github&utm_medium=tasks-repo)**

Given a string `text` and a pattern `pattern`, return `true` if the pattern describes the **whole** string, otherwise `false`.

The pattern consists of lowercase Latin letters and two special characters:
- `.` matches any single character;
- `*` applies to the character before it and means "that character (or `.`) zero or more times in a row".

The pattern is valid: `*` is never first and never directly follows another `*`. The string consists of lowercase Latin letters. An empty pattern describes only the empty string, while a pattern like `a*b*` describes the empty string too. Both lengths are up to 500 characters.

Example: `"aab"`, `"c*a*b"` → `true` (`c*` takes zero letters, `a*` takes two).
