# Nested brackets as a subsequence

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-132?utm_source=github&utm_medium=tasks-repo)**

Given a string made only of `[` and `]`, return `true` if you can delete some characters (without reordering the rest) and get the string `[[]]`, that is, a nested pair of brackets. Otherwise return `false`. The brackets in the string itself may be unbalanced; this does not matter. An empty string gives `false`.

Example: `"[[]][["` → `true` (subsequence `[[]]`), `"[][]"` → `false`.
