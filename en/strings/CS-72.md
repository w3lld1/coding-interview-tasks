# Shortest window with all letters

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-72?utm_source=github&utm_medium=tasks-repo)**

Given strings `s` and `t`, find the shortest contiguous substring of `s` in which every character of `t` occurs at least as many times as in `t` itself (order does not matter, extra characters are allowed). If several substrings have the minimum length, return the one that starts furthest left. If there is no such substring, or `t` is empty, return `""`. Case matters: `a` and `A` are different characters.

The strings consist of Latin letters, each up to 10,000 long.

Example: `"zaxbyaczb"`, `"abc"` → `"byac"` (`"aczb"` has the same length but starts further right).
