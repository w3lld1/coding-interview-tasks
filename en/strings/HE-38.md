# Undo a cyclic shift

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-38?utm_source=github&utm_medium=tasks-repo)**

A string was encrypted like this: it was split into groups of three characters from left to right (the last group may be shorter), and in each full group the first character was moved to the end: `abc` became `bca`. A short last group was left unchanged. Given the encrypted string `s`, return the original one. An empty string gives an empty string.

Example: `"bcaef"` → `"abcef"` (the group `bca` became `abc`, the group `ef` stayed).
