# Delete characters, check palindrome

**Difficulty:** easy · **Language:** Python · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-112?utm_source=github&utm_medium=tasks-repo)**

Given two strings `s` and `c`, remove from `s` every character that occurs in `c`, then check whether the resulting string is a palindrome (reads the same forwards and backwards). Return a list of two elements: the resulting string and a boolean `true` or `false`. The empty string counts as a palindrome.

Example: `"abcde"`, `"ae"` → `["bcd", false]`.
