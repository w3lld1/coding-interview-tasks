# Cyclic digit pair substitutions

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-109?utm_source=github&utm_medium=tasks-repo)**

You are given a string `digits` of the digits `0`–`9`. One pass consists of ten operations done strictly in order: replace every occurrence of `01` with `2`, then every occurrence of `12` with `3`, then `23` with `4`, … , `89` with `0`, and finally `90` with `1`. Each operation works on the string left by the previous one. Passes repeat until a whole pass changes nothing. Return the resulting string.

Occurrences of one pair never overlap, and replacing a pair never creates a new occurrence of the same pair, so each operation is well defined. The order of operations matters: `012` becomes `22`, not `03`.

Limits: `1 ≤ length of digits ≤ 20000`; repeating the replacements over the whole string may be too slow.

Example: `"0145"` → `"26"` (`01` → `2` gives `245`, then `45` → `6`).
