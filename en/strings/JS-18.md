# Custom Signs

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-18?utm_source=github&utm_medium=tasks-repo)**

The buildSign(occasion, name) function must create the string 'Happy {occasion} {name}!', and buildBirthdaySign(age) must create 'Happy Birthday! What a {category} fellow you are.', where the category is mature for ages 50 and up and young otherwise. The graduationFor(name, year) function returns 'Congratulations {name}!' and 'Class of {year}' on two lines. The costOf(sign, currency) function computes the cost as 20 plus 2 for each character, including spaces, and returns 'Your sign costs {amount with two decimal places} {currency}.'.
