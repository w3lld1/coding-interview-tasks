# Longest palindromic substring

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-40?utm_source=github&utm_medium=tasks-repo)**

Given a string (up to 1000 characters), return its longest palindromic substring — a contiguous piece that reads the same forwards and backwards. If several have the same length, return the leftmost (smallest start index). An empty string gives an empty string.

Example: `"babad"` → `"bab"` (`"aba"` has the same length but starts further right).
