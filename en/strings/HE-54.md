# Same set of characters

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-54?utm_source=github&utm_medium=tasks-repo)**

Given two strings, return `true` if they consist of the same set of distinct characters, meaning every character of the first string appears in the second and vice versa. Order and repeat counts do not matter, and case is significant. Two empty strings give `true`; an empty and a non-empty string give `false`.

Example: `"abcd"`, `"dddddddabc"` → `true`.
