# All valid strings after the fewest bracket removals

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Recursion and backtracking](../recursion/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-204?utm_source=github&utm_medium=tasks-repo)**

You are given a string `s` of up to 25 characters made of round brackets `(`, `)` and lowercase Latin letters. A string is valid when every `)` has an unclosed `(` before it and all brackets are closed at the end; letters do not matter, and the empty string is valid. Remove the smallest possible number of brackets from `s` (letters cannot be removed) so that it becomes valid, and return every distinct string you can get this way, without repeats, sorted in ascending order (by character code: `(` < `)` < letters). If `s` is already valid, the answer is a list with just `s`; if every bracket has to go, the answer is the one string of the remaining letters (possibly empty).

Example: `"()())()"` → `["(())()", "()()()"]`.
