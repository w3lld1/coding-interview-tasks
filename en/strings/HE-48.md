# Palindrome string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-48?utm_source=github&utm_medium=tasks-repo)**

Given a string, return `true` if it reads the same from left to right and from right to left, otherwise `false`. Letter case matters: `"Aba"` is not a palindrome. An empty string and a one-character string are palindromes.

Example: `"xywyx"` → `true`.
