# String to 32-bit integer

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-132?utm_source=github&utm_medium=tasks-repo)**

Convert a string to an integer by these rules:

1. Skip leading spaces (the space character only).
2. If the next character is `+` or `-`, it is the sign (with no sign the number is positive).
3. Read consecutive digits `0`-`9` and stop at the first other character or at the end of the string.
4. If there were no digits, the result is `0`.
5. Clamp the result to the signed 32-bit range: below `-2147483648` gives `-2147483648`, above `2147483647` gives `2147483647`.

Digits must follow the sign immediately: `"+-12"` and `" - 5"` contain no digits. The string has up to 200 characters and may hold many digits, so watch for overflow.

Example: `"   -042 apples"` → `-42`.
