# Smallest subsequence without repeats

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-121?utm_source=github&utm_medium=tasks-repo)**

You are given a string `s` of lowercase Latin letters (up to 1000 characters). Remove some letters so that every letter that appears in `s` stays exactly once and the order of the remaining letters is unchanged. Return the lexicographically smallest of all possible results. For an empty string the answer is `""`.

Example: `"cbacdcbc"` → `"acdb"`; `"bcabc"` → `"abc"`.
