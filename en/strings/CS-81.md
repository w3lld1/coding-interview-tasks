# Longest well-formed bracket fragment

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-81?utm_source=github&utm_medium=tasks-repo)**

You are given a string `s` of up to 10,000 characters made only of brackets of three kinds: `()`, `[]` and `{}`. A string is well-formed when every opening bracket is closed by a bracket of the same kind, pairs do not cross (`([)]` is not well-formed), and the empty string is well-formed too. Find the longest well-formed fragment of `s` (a contiguous substring) and return its length. If there is no non-empty one (or `s` is empty), return `0`.

Example: `"(]{}[()]"` → `6` (the fragment `{}[()]`).
