# Split parenthesis groups

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-1?utm_source=github&utm_medium=tasks-repo)**

Given a string made of `(`, `)` and spaces, where the brackets form several balanced groups written one after another and not nested in each other, return the list of these groups in order, each without spaces. Ignore all spaces. For an empty string or a string of spaces only, return an empty list.

Example: `"( ) (( )) (( )( ))"` → `["()", "(())", "(()())"]`.
