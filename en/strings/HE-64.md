# Vowels in a word

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-64?utm_source=github&utm_medium=tasks-repo)**

Given a word of Latin letters, return the number of vowels in it. The vowels are `a`, `e`, `i`, `o`, `u` in either case; the letter `y` (also in either case) counts as a vowel only when it is the last letter of the word. For an empty string the answer is `0`.

Example: `"ACEDY"` → `3` (A, E and the final Y).
