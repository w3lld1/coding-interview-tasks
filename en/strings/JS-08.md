# Employee Badges

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-08?utm_source=github&utm_medium=tasks-repo)**

Write printBadge(id, name, department) that returns a string like '[17] Anna - MARKETING', where the department name is converted to upper case. If id is null, do not print the ID along with its brackets and the extra space. If department is null, use OWNER instead of the department; this rule also applies when the ID is missing.
