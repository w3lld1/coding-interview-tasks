# Double or bitwise NOT

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-85?utm_source=github&utm_medium=tasks-repo)**

You are given two non-negative numbers in binary: `start` and `end` (no leading zeros; zero is written `"0"`; length up to 100). One operation either:

- **doubles** the number — appends `0` on the right (zero stays zero);
- takes the **bitwise NOT** — flips every digit of the representation without leading zeros and drops the leading zeros this produces. For example, `0 → 1`, `1 → 0`, `11 → 0`, `1110 → 1`, `1010 → 101`, `101 → 10`.

Return the smallest number of operations that turns `start` into `end`, or `-1` if it is impossible. If `start` equals `end`, the answer is `0`.

Example: `"10001"`, `"111"` → `4` (NOT: `1110`, double: `11100`, double: `111000`, NOT: `111`).
