# Largest concatenated number

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-159?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-negative integers, write their decimal forms one after another in any order to get one number. Return the largest possible number as a string (it may not fit in an integer). If all numbers are zero, return `"0"`. For an empty list return an empty string.

Example: `[3, 30, 34, 5, 9]` → `"9534330"`.
