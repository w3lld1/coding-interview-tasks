# Uppercase vowels at even positions

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-98?utm_source=github&utm_medium=tasks-repo)**

Given a string, count how many uppercase vowels (`A`, `E`, `I`, `O`, `U`) stand at even indices. Indices start at zero, so the first character has index `0`. Lowercase vowels do not count. For an empty string the answer is `0`.

Example: `"aBCdEf"` → `1` (`E` at index 4).
