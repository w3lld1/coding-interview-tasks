# Last word is a single letter

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-134?utm_source=github&utm_medium=tasks-repo)**

Words in a string are separated by spaces. Return `true` if the last word of the string consists of exactly one Latin letter (`a`–`z` or `A`–`Z`), and `false` otherwise. If the string ends with a space, the last word is empty and the answer is `false`. An empty string gives `false`. Digits and other symbols are not letters.

Example: `"apple pi e"` → `true`, `"apple pie"` → `false`.
