# Even-length words in order

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-149?utm_source=github&utm_medium=tasks-repo)**

Given a list of strings (duplicates are possible), remove the strings of odd length and return the rest sorted by ascending length. Strings of the same length are ordered alphabetically by character code (uppercase letters come before lowercase ones). Duplicates are kept. If nothing is left, return an empty list.

Example: `["ab", "a", "aaa", "cd"]` → `["ab", "cd"]`.
