# Wildcard match with ? and *

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-78?utm_source=github&utm_medium=tasks-repo)**

Given a string `text` and a mask `pattern`, return `true` if the mask describes the **whole** string, otherwise `false`.

The mask consists of lowercase Latin letters and two special characters:
- `?` matches exactly one character of any kind;
- `*` matches any sequence of characters, including the empty one.

A letter in the mask matches only the same letter. The string consists of lowercase Latin letters. An empty mask describes only the empty string, a mask of only `*` describes every string, the empty one included. Both lengths are up to 500 characters.

Example: `"adceb"`, `"*a*b"` → `true`.
