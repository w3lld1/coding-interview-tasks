# Words with n consonants

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-117?utm_source=github&utm_medium=tasks-repo)**

Given a string of Latin letters and spaces and an integer `n`, return the list of words (runs of letters between spaces) that contain exactly `n` consonants, in the order they appear in the string. Vowels are `a`, `e`, `i`, `o`, `u` in either case; every other letter is a consonant. An empty string gives an empty list.

Example: `"Mary had a little lamb"`, `4` → `["little"]`.
