# Square code cipher

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-45?utm_source=github&utm_medium=tasks-repo)**

Encrypt a text with the square code method. First normalise the text: keep only Latin letters and digits and lowercase the letters. Say `n` characters remain. Write them row by row into a rectangle of `r` rows and `c` columns, where `c` is the smallest number such that `r·c ≥ n`, `c ≥ r` and `c − r ≤ 1` (the last row may be incomplete). Then read the rectangle column by column from left to right: each column is a chunk of length `r`. A chunk that lacks characters is padded with spaces on the right to length `r`. Return all `c` chunks joined by one space. If nothing remains after normalisation, return an empty string.

Example: `"Chill out."` → `"clu hlt io "` (8 characters, 3 columns, 3 rows; the last chunk is padded with a space).
