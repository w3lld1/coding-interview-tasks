# Strongest class extension

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-153?utm_source=github&utm_medium=tasks-repo)**

You get a class name and a non-empty list of extension names. The strength of an extension is the number of uppercase Latin letters in its name minus the number of lowercase ones; digits and other characters do not count. Find the strongest extension and return the string `ClassName.Extension`. If several extensions are equally strong, take the one that comes first in the list.

Example: `"my_class"`, `["AA", "Be", "CC"]` → `"my_class.AA"` (strengths 2, 0 and 2, the first one wins).
