# Count nucleotides in DNA

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-72?utm_source=github&utm_medium=tasks-repo)**

A DNA strand is a string of the characters `A`, `C`, `G` and `T` (uppercase). Return a map with the keys `"A"`, `"C"`, `"G"`, `"T"` whose values say how many times each character occurs in the strand. All four keys are always present, even when a count is 0; an empty string gives four zeros. If the string has any other character (a lowercase letter too), report an error: throw an exception, or return an error in Go.

Example: `"GATTACA"` → `{"A": 3, "C": 1, "G": 1, "T": 2}`.
