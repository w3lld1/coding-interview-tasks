# Vigenere cipher

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-98?utm_source=github&utm_medium=tasks-repo)**

Implement the Vigenere cipher for lowercase Latin letters. You get a mode (`"encode"` or `"decode"`), a key of lowercase letters and a text of lowercase letters.

Each key letter is a shift: `a` is 0, `b` is 1, ..., `z` is 25. The text letter at position `i` is shifted around the alphabet (`a` follows `z`) by the shift of the key letter number `i mod key length`: forward for `"encode"`, backward for `"decode"`. If the text is longer than the key, the key repeats from its start. An empty text gives an empty string.

Example: `"encode"`, `"abcd"`, `"hello"` → `"hfnoo"`.
