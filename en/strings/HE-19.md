# Sort digit words

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-19?utm_source=github&utm_medium=tasks-repo)**

Given a string of English digit names separated by single spaces (`zero`, `one`, `two`, `three`, `four`, `five`, `six`, `seven`, `eight`, `nine`), return a string with the same words sorted by digit value from smallest to largest, also separated by single spaces. Duplicates are kept. For an empty string return an empty string.

Example: `"three one five"` → `"one three five"`.
