# Robot simulator

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-90?utm_source=github&utm_medium=tasks-repo)**

A robot stands on an infinite grid at cell `(x, y)` facing `direction`: `"north"`, `"east"`, `"south"` or `"west"`. The `x` coordinate grows to the east, `y` to the north. The string `instructions` consists of the characters `R` (turn 90° right), `L` (turn 90° left) and `A` (advance one cell in the current direction). Run the commands in order and return the final state as the string `"x y direction"`. An empty command string leaves the robot where it is.

Example: `7`, `3`, `"north"`, `"RAALAL"` → `"9 4 west"`.
