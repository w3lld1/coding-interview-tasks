# Binary form wrapped in db

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-79?utm_source=github&utm_medium=tasks-repo)**

You get a non-negative integer. Write it in binary without leading zeros and return a string with `db` added at the start and at the end. The number `0` is written as `0`.

Example: `15` → `"db1111db"`; `32` → `"db100000db"`; `0` → `"db0db"`.
