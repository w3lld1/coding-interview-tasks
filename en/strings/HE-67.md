# Mangoes in a basket

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-67?utm_source=github&utm_medium=tasks-repo)**

A basket holds apples, oranges and mangoes. The string `counts` always has the form `"<A> apples and <O> oranges"`, where `<A>` and `<O>` are non-negative integers. The second argument `total` is the number of all fruits in the basket. Return the number of mangoes: `total` minus the apples and oranges. The result is guaranteed not to be negative.

Example: `"5 apples and 6 oranges"`, `19` → `8`.
