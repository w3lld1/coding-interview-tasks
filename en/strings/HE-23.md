# String length

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-23?utm_source=github&utm_medium=tasks-repo)**

Given a string, return the number of characters in it. The empty string has length `0`, and spaces count as characters. The tests use ASCII characters only.

Example: `"abc"` → `3`.
