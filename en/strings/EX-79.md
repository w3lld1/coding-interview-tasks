# Translate RNA into a protein

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-79?utm_source=github&utm_medium=tasks-repo)**

An RNA strand is split into codons of three characters. Each codon maps to an amino acid:

- `AUG` → `Methionine`
- `UUU`, `UUC` → `Phenylalanine`
- `UUA`, `UUG` → `Leucine`
- `UCU`, `UCC`, `UCA`, `UCG` → `Serine`
- `UAU`, `UAC` → `Tyrosine`
- `UGU`, `UGC` → `Cysteine`
- `UGG` → `Tryptophan`
- `UAA`, `UAG`, `UGA` are stop codons.

Return the list of amino acids, reading codons from left to right. Reading ends at a stop codon: it and everything after it are ignored (even an incomplete tail). If an unknown codon or an incomplete codon of 1 or 2 characters comes before the stop, report an error: throw an exception, or return an error in Go. An empty strand gives an empty list.

Example: `"AUGUUUUGGUAA"` → `["Methionine", "Phenylalanine", "Tryptophan"]`.
