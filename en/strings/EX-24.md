# Rail fence cipher

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-24?utm_source=github&utm_medium=tasks-repo)**

The rail fence cipher writes a message in a zigzag over `rails` rows: diagonally down to the last row, then up to the first, and so on. The ciphertext is then read row by row: the whole first row left to right, then the second, and so on.

Given a string `message`, a number of rows `rails` (`rails ≥ 1`) and a flag `decode`: if `decode` is `false`, encode `message` and return the result; if `true`, treat `message` as ciphertext and return the original message. All characters, spaces included, take part as they are. With `rails = 1` and for an empty string the result equals the input.

Example: `"WEAREDISCOVERED"`, `3`, `false` → `"WECRERDSOEEAIVD"`.
