# Shortest palindrome with prefix

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-10?utm_source=github&utm_medium=tasks-repo)**

Given a string, return the shortest palindrome that starts with it. To build it, find the longest suffix of the string that is a palindrome and append to the end the reverse of the part that comes before that suffix. For an empty string the answer is an empty string.

Example: `"cat"` → `"catac"`.
