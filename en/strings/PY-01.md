# Anagram

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-01?utm_source=github&utm_medium=tasks-repo)**

Given a word and a list of candidates, find the words that have the same letters with the same number of occurrences. Compare case-insensitively, but exclude a match with the original word itself, even if its case differs. Return the matching candidates in their original spelling.
