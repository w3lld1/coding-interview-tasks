# Run-Length Encoding

**Difficulty:** easy · **Language:** Java · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-03?utm_source=github&utm_medium=tasks-repo)**

Implement string compression and the reverse decompression: replace each run of identical adjacent characters with its length and the character, omitting the length for a single character. The input contains only Latin letters of both cases and whitespace, so digits in the compressed form always denote the length of the following run. Support multi-digit lengths and the empty string.
