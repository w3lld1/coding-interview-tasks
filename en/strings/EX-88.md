# Reverse a string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-88?utm_source=github&utm_medium=tasks-repo)**

Return the string with the characters of the input in reverse order. Case, spaces and punctuation stay as they are; an empty string gives an empty string. The string is reversed character by character (by Unicode code points); the tests have no combining marks and no characters outside the basic plane.

Example: `"stressed"` → `"desserts"`, `"I'm hungry!"` → `"!yrgnuh m'I"`.
