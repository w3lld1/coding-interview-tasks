# Decode a shift by five letters

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-50?utm_source=github&utm_medium=tasks-repo)**

A string of lowercase Latin letters `a`–`z` was encrypted like this: every letter was replaced by the letter 5 positions further in the alphabet, wrapping from `z` back to `a`. Given the encrypted string, return the original one. An empty string gives an empty string.

Example: `"mjqqt"` → `"hello"`.
