# All slices of a given length

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Errors and exceptions](../errors/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-97?utm_source=github&utm_medium=tasks-repo)**

Given a string of digits and a slice length `n`, return a list of all substrings of `n` adjacent characters in the order they appear (slices may overlap and repeat).

Report an error: throw an exception, or return an error in Go, if the string is empty, if `n` is not positive, or if `n` is greater than the string length.

Example: `"49142"`, `3` → `["491", "914", "142"]`.
