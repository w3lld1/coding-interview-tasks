# Space-separated numbers

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-15?utm_source=github&utm_medium=tasks-repo)**

Given a non-negative integer `n`, return a string with all integers from `0` to `n` inclusive in ascending order, separated by single spaces. There is no space at the start or the end.

Example: `5` → `"0 1 2 3 4 5"`.
