# Count palindromic substrings

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-41?utm_source=github&utm_medium=tasks-repo)**

Given a string of lowercase Latin letters, up to 1000 characters, return how many of its substrings (contiguous pieces) read the same forwards and backwards. Substrings at different positions count separately even when their text is equal. For an empty string the answer is `0`.

Example: `"aaa"` → `6` (`a` three times, `aa` twice and `aaa`).
