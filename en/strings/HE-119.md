# Concatenate parenthesis strings

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-119?utm_source=github&utm_medium=tasks-repo)**

Given two strings made only of the characters `(` and `)`, check whether they can be concatenated in some order (first then second, or second then first) so that the result is a balanced parenthesis sequence: every closing bracket closes a previously opened one, and at the end all brackets are closed. Return `true` if possible, otherwise `false`. The empty string is balanced.

Example: `"()("`, `")"` → `true` (it gives `"()()"`).
