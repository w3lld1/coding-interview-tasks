# Circular digit shift

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-65?utm_source=github&utm_medium=tasks-repo)**

Given a non-negative integer `x` and a non-negative integer `shift`, rotate the digits of `x` to the right by `shift` positions and return the result as a string (leading zeros are kept). If `shift` is greater than the number of digits, return the digits reversed. A shift of zero or of exactly the number of digits returns the number unchanged.

Example: `12`, `1` → `"21"`; `100`, `2` → `"001"`.
