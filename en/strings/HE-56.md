# Balanced angle brackets

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-56?utm_source=github&utm_medium=tasks-repo)**

Given a string of `<` and `>` characters, return `true` if every opening bracket `<` has a matching closing bracket `>` to its right and vice versa, otherwise `false`. An empty string is valid.

Example: `"<<><>>"` → `true`, while `"><<>"` → `false`.
