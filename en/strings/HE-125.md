# Split text into words or count letters

**Difficulty:** easy · **Language:** Python · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-125?utm_source=github&utm_medium=tasks-repo)**

Given a string, the result depends on its content:

1. If the string contains at least one space, return the list of words separated by spaces (empty words between consecutive spaces are dropped).
2. Otherwise, if it contains a comma, return the list of words separated by commas (empty words are dropped too).
3. Otherwise return the number of lowercase Latin letters with an odd alphabet index, numbering `a` = 0, `b` = 1, …, `z` = 25 (that is `b`, `d`, `f`, …, `z`). Other characters are not counted; an empty string gives `0`.

Example: `"Hello world,!"` → `["Hello", "world,!"]`; `"abcdef"` → `3`.
