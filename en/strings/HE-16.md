# Distinct characters, ignoring case

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-16?utm_source=github&utm_medium=tasks-repo)**

Given a string of ASCII characters, return how many distinct characters it has, treating the uppercase and lowercase forms of a letter as the same character. Spaces and punctuation count as characters too. For an empty string the answer is `0`.

Example: `"Jerry"` → `4` (`j`, `e`, `r`, `y`).
