# List with fewer total characters

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-74?utm_source=github&utm_medium=tasks-repo)**

You get two lists of strings. For each list, count the total number of characters across all its strings, and return the list with the smaller total. If the totals are equal, return the first list.

Example: `["hi", "admin"]`, `["hI", "Hi"]` → `["hI", "Hi"]`; `["hi", "admin"]`, `["hI", "hi", "hii"]` → `["hi", "admin"]` (7 and 7 characters, a tie).
