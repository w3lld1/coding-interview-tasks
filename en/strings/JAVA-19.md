**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-19?utm_source=github&utm_medium=tasks-repo)**

Truncate the input string to its first five Unicode code points, leaving a shorter string unchanged. In Java you cannot simply take the first five char values: a character outside the Basic Multilingual Plane occupies a surrogate pair, which must not be split. This task counts code points, not visual graphemes.
