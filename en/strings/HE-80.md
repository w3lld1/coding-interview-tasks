# Happy string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-80?utm_source=github&utm_medium=tasks-repo)**

A string is happy if its length is at least 3 and, in every three consecutive characters, all characters are distinct. Return `true` if the string is happy, otherwise `false`. A string that is too short (including the empty string) is not happy.

Example: `"abcd"` → `true`; `"aabb"` → `false`; `"aba"` → `false`.
