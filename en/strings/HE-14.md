# All prefixes

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-14?utm_source=github&utm_medium=tasks-repo)**

Given a string, return the list of all its non-empty prefixes from the shortest to the longest. For an empty string return an empty list.

Example: `"abc"` → `["a", "ab", "abc"]`.
