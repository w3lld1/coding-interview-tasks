# Charging chaos

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-16?utm_source=github&utm_medium=tasks-repo)**

A house has `n` outlets; the flow of each outlet is a binary string of length `L`. The strings in `outlets` are all different. A farmer has `n` devices, and each needs a flow from `devices` (also different strings of length `L`). The panel has `L` switches: switch `i` flips bit `i` of the flow of every outlet at once (`0` to `1` and back). Each switch may be pressed at most once. After the presses, the set of outlet flows must equal the set of device flows (a device may be plugged into any outlet). Return the minimum number of switches pressed, or `-1` if it is impossible.

Example: `["01", "11", "10"]`, `["11", "00", "10"]` → `1` (press the second switch).
