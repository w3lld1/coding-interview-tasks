# Remove vowels

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-51?utm_source=github&utm_medium=tasks-repo)**

Given a string, return a copy with every English vowel `a`, `e`, `i`, `o`, `u` removed, in both lower and upper case. All other characters, including newlines, spaces and punctuation, stay in place. The letter `y` is not a vowel. An empty string gives an empty string.

Example: `"Hello, World!"` → `"Hll, Wrld!"`.
