# Odd digits in a template

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-113?utm_source=github&utm_medium=tasks-repo)**

Given a list of strings that each consist only of digits, count the odd digits `k` in each string and build the phrase `the number of odd elements kn the strkng k of the knput.` in which every `k` is replaced by that count (so the words `kn`, `strkng` and `knput` carry the number instead of the letter `i`). Return the phrases in the same order. An empty list gives an empty list; a string with no odd digits has `k` equal to 0.

Example: `["3", "11111111"]` → `["the number of odd elements 1n the str1ng 1 of the 1nput.", "the number of odd elements 8n the str8ng 8 of the 8nput."]`.
