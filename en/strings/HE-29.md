# Filter strings by prefix

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-29?utm_source=github&utm_medium=tasks-repo)**

Given a list of strings and a prefix string, return only the strings that start with that prefix, in the original order (duplicates are kept). Case matters. The empty prefix matches every string, and a string shorter than the prefix does not match.

Example: `["abc", "bcd", "cde", "array"]`, `"a"` → `["abc", "array"]`.
