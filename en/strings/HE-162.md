# MD5 hash of a string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-162?utm_source=github&utm_medium=tasks-repo)**

You get a string of ASCII characters. Return its MD5 hash as a string of 32 lowercase hexadecimal digits. For an empty string return `null`. Use the language's standard library; you do not need to implement MD5 yourself.

Example: `"abc"` → `"900150983cd24fb0d6963f7d28e17f72"`.
