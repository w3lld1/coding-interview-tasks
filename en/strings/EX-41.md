# Ten Green Bottles song

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-41?utm_source=github&utm_medium=tasks-repo)**

Write out the lyrics of the children's song "Ten Green Bottles". You get the number of bottles in the first verse `start_bottles` (1 to 10) and the number of verses `take_down` (1 to `start_bottles`). Return a list of lines. The verse for `k` bottles has four lines:

```
K green bottles hanging on the wall,
K green bottles hanging on the wall,
And if one green bottle should accidentally fall,
There'll be K-1 green bottles hanging on the wall.
```

Numbers are written as English words: capitalised in the first two lines (`Ten`, `One`), lowercase in the last (`nine`, `no`). The word `bottle` is singular only after the word `one` (`One green bottle`, `one green bottle`) and is `bottles` otherwise, including `no green bottles`. Consecutive verses are separated by one empty line `""`; there is none after the last verse.

Example: `2`, `1` → `["Two green bottles hanging on the wall,", "Two green bottles hanging on the wall,", "And if one green bottle should accidentally fall,", "There'll be one green bottle hanging on the wall."]`.
