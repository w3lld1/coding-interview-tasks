# Four-letter shift cipher

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-89?utm_source=github&utm_medium=tasks-repo)**

Given a string, return a string where each lowercase Latin letter `a`-`z` is replaced by the letter 4 positions later in the alphabet; after `z` the count wraps to `a` (so `w` → `a`, `z` → `d`). All other characters (uppercase letters, digits, spaces, punctuation) stay unchanged. An empty string gives an empty string.

Example: `"hi"` → `"lm"`, `"xyz"` → `"bcd"`.
