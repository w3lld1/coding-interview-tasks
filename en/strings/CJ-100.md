# Typing a string with copy and paste

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Dynamic programming](../dp/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-100?utm_source=github&utm_medium=tasks-repo)**

You need to type the string `target` of lowercase Latin letters. You start with an empty string and an empty clipboard; one operation is one of:

- append any single letter to the string;
- copy any substring (consecutive characters) of the current string to the clipboard, replacing its old content;
- append the whole clipboard to the string (the clipboard does not change).

At the end you must have exactly `target`, with no extra letters. Return the smallest number of operations.

Limits: `1 ≤ len(target) ≤ 150`.

Example: `"abcabab"` → `6` (type `a`, `b`, `c`, copy `ab`, paste it twice).
