# Filter by substring

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-7?utm_source=github&utm_medium=tasks-repo)**

Given a list of strings and a substring, return the strings that contain the substring, keeping their original order and duplicates. Matching is case-sensitive. An empty substring is contained in every string.

Example: `["abc", "bacd", "cde", "array"]`, `"a"` → `["abc", "bacd", "array"]`.
