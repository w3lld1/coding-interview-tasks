# Longest string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-12?utm_source=github&utm_medium=tasks-repo)**

Given a list of strings, return the longest one. If several have the same maximal length, return the one that comes first in the list. For an empty list return `null`.

Example: `["a", "bb", "ccc"]` → `"ccc"`.
