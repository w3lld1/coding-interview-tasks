# DNA strand distance

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-57?utm_source=github&utm_medium=tasks-repo)**

You get two DNA strands, strings of the letters `C`, `A`, `G`, `T`. Return the number of positions at which the strands have different letters (the Hamming distance). If the strands have different lengths, report an error: throw an exception, or return an error in Go. Two empty strands give `0`.

Example: `"GAGCCTACTAACGGGAT"`, `"CATCGTAATGACGGCCT"` → `7`.
