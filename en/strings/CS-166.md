# Unique letter frequencies

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-166?utm_source=github&utm_medium=tasks-repo)**

Given a string of lowercase Latin letters, one action deletes one character. Return the fewest deletions after which no two different letters that remain in the string occur the same number of times. A letter deleted completely does not count (frequency 0 may repeat). For an empty string the answer is `0`.

Example: `"aaabbbcc"` → `2` (frequencies 3, 3, 2 → 3, 2, 1: delete one `b` and one `c`).
