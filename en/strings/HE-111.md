# Most frequent letters

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-111?utm_source=github&utm_medium=tasks-repo)**

Given a string of lowercase letters separated by spaces, return a map that contains only the most frequent letters, each mapped to its number of occurrences. If several letters tie for the highest count, return all of them. For an empty string the result is empty.

Example: `"a b c a b"` → `{"a": 2, "b": 2}`.
