# Sort letters inside each word

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-86?utm_source=github&utm_medium=tasks-repo)**

Given an ASCII string whose words are separated by single spaces (there may be several spaces in a row, and at the start or the end), return a string where the characters of each word are sorted by ASCII code in ascending order, while the words and all spaces stay in place. Uppercase letters come before lowercase ones, and punctuation sorts by code like any other character. An empty string gives an empty string.

Example: `"Hello World!!!"` → `"Hello !!!Wdlor"`.
