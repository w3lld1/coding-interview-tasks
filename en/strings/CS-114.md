# String with no equal neighbours

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-114?utm_source=github&utm_medium=tasks-repo)**

You are given a string `s` of lowercase Latin letters (up to 500 characters). Rearrange its letters so that no two adjacent letters are equal. If several arrangements exist, return the lexicographically smallest one. If no such arrangement exists, return the empty string `""`. For an empty string the answer is also `""`.

Example: `"aabb"` → `"abab"`; `"aaab"` → `""`.
