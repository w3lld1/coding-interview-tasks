# Word with most distinct letters

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-158?utm_source=github&utm_medium=tasks-repo)**

You get a non-empty list of words. Return the word that has the most distinct characters (repeats of a character count once). If several words tie, return the lexicographically smallest one: the one that comes first when strings are compared character by character by code.

Example: `["name", "enam", "game"]` → `"enam"` (all three have 4 distinct letters, and `"enam"` is first alphabetically).
