# Longest substring without repeats

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-38?utm_source=github&utm_medium=tasks-repo)**

Given a string (up to 10,000 characters, any characters), return the length of its longest substring — a contiguous piece — that has no two equal characters. Case matters, and a space is an ordinary character. An empty string gives `0`.

Example: `"abcabcbb"` → `3` (`"abc"`).
