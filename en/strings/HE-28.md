# Join strings

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-28?utm_source=github&utm_medium=tasks-repo)**

Given a list of strings, join them into one string in the same order, with no separator. For an empty list return the empty string; empty strings inside the list add nothing.

Example: `["a", "b", "c"]` → `"abc"`.
