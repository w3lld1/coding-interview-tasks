# The repeater

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-17?utm_source=github&utm_medium=tasks-repo)**

You are given a list of non-empty strings of lowercase letters. One move either takes any letter in any string and repeats it (inserts another copy right after it), or, in any string, deletes one of two adjacent equal letters. Return the minimum number of moves after which all strings become identical, or `-1` if it is impossible. With a single string the answer is `0`.

Example: `["mmaw", "maw"]` → `1` (delete one `m`).
