# File name check

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-141?utm_source=github&utm_medium=tasks-repo)**

Given a file name, return the string `"Yes"` if the name is valid and `"No"` otherwise. A name is valid when all of these hold:
- it has at most three digits `0`-`9`;
- it has exactly one dot;
- the part before the dot is not empty and starts with a Latin letter (`a`-`z` or `A`-`Z`);
- the part after the dot is `txt`, `exe` or `dll` (case matters).

An empty string is not valid.

Example: `"example.txt"` → `"Yes"`; `"1example.dll"` → `"No"`.
