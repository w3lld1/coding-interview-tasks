# Prime-length words

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-143?utm_source=github&utm_medium=tasks-repo)**

Given a sentence, a non-empty string of words separated by single spaces and containing only letters, return a string with the words whose length is a prime number, in the original order and separated by single spaces. If no word qualifies, return an empty string. Remember that 1 is not prime.

Example: `"lets go for swimming"` → `"go for"`.
