# String XOR

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-11?utm_source=github&utm_medium=tasks-repo)**

Given two strings of equal length made only of the characters `0` and `1`, apply a bitwise exclusive OR to them: at each position the result is `0` if the characters are equal and `1` if they differ. Return the result as a string of the same length. Two empty strings give an empty string.

Example: `"010"`, `"110"` → `"100"`.
