# Lock with dead ends

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-109?utm_source=github&utm_medium=tasks-repo)**

A lock has four wheels with digits `0..9`; each wheel is a ring: `0` follows `9` and `9` precedes `0`. One move turns one wheel by one digit up or down. The lock shows `"0000"`. You get a list of dead ends, which are combinations that jam the lock when shown (no more turns after that), and a target combination. Return the fewest moves to reach the target, or `-1` if it cannot be reached. If `"0000"` is a dead end the answer is `-1`, even when the target is `"0000"`; if the target is a dead end the answer is `-1` too. There are at most 500 dead ends.

Example: dead ends `["0201", "0101", "0102", "1212", "2002"]`, target `"0202"` → `6`.
