# Poetry Club Door Policy

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-01?utm_source=github&utm_medium=tasks-repo)**

Implement four functions that derive passwords from lines of a poem: frontDoorResponse returns the first character of a line, and backDoorResponse returns the last character after trimming whitespace at both ends. The frontDoorPassword function takes an already assembled word and capitalizes the first letter, making the rest lowercase. The backDoorPassword function performs the same transformation and appends ', please'.
