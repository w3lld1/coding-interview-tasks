# Permutation inside a string

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-43?utm_source=github&utm_medium=tasks-repo)**

Given two strings of lowercase Latin letters, `pattern` and `text` (each up to 1000 characters), return `true` if some substring of `text` (a contiguous piece) is a permutation of `pattern`, that is, has the same letters with the same counts. Otherwise return `false`. An empty `pattern` is found in any string: the answer is `true`.

Example: `"ab"`, `"eidbaooo"` → `true` (the substring `ba`).
