# Nesting depth of groups

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-6?utm_source=github&utm_medium=tasks-repo)**

Given a string with several groups of balanced parentheses `(` and `)` separated by spaces, find the maximum nesting depth of each group and return these numbers in the order of the groups. Skip extra and repeated spaces; for an empty string return an empty list.

Example: `"(()()) ((())) () ((())()())"` → `[2, 3, 1, 3]`.
