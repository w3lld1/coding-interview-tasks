# Run-Length Encoding

**Difficulty:** medium · **Language:** Python · **Topics:** [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-06?utm_source=github&utm_medium=tasks-repo)**

Implement compression and decompression of a string by encoding runs of consecutive identical characters. A run is written as its length followed by the character, but the count is omitted for a single character. The input string contains Latin letters of both cases and whitespace, but no digits; when decoding, handle multi-digit lengths. An empty string must convert to an empty string in both directions.
