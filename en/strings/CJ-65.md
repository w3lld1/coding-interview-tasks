# Coupling train cars without split letters

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Strings](../strings/), [Math](../math/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-65?utm_source=github&utm_medium=tasks-repo)**

You are given a list `cars` of `n` strings of lowercase Latin letters: each string is a coupled group of cars that cannot be reversed. Couple all groups into one train by choosing their order. The train is valid when all occurrences of each letter are next to each other. Return the number of orders of the groups that give a valid train, modulo `1 000 000 007`. Groups are told apart by their position in the list: two equal strings swapped give two different orders.

Limits: `1 ≤ n ≤ 100`, each string has length 1 to 100; trying all orders is too slow.

Example: `["aa", "aa", "bc", "c"]` → `4`.
