# A series of pings to one server

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-588?utm_source=github&utm_medium=tasks-repo)**

To estimate the stability of a link, the same server is pinged several times in a row. A ping is an async function with no arguments (`await job()`) that returns a number or fails (throws); every new call is a new ping, and its result may differ from the previous one.

Call `job` exactly `count` times, strictly one at a time. Wait `pause` milliseconds between the pings (no pause after the last ping). A failed ping does not stop the series. Return a list of two numbers: how many pings succeeded and how many milliseconds passed from the call to the return. Time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. `0 ≤ count ≤ 50`.

Example: every ping takes 10 ms and succeeds, `count = 3`, `pause = 100` → `[3, 230]`.
