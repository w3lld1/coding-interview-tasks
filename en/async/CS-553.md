# How many attempts it took

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-553?utm_source=github&utm_medium=tasks-repo)**

You are given a job `job` and a number `max_attempts` (at least 1). A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Call the job until the first success, but at most `max_attempts` times; each call is a new attempt, with no pause between attempts. Return the number of the successful attempt (counting from 1), or `-1` if every attempt failed.

Example: the job fails twice, then succeeds, `max_attempts = 3` → `3`.
