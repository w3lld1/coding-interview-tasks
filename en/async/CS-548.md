# Outcome labels for jobs

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-548?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run all the jobs (one at a time or all at once: the answer does not depend on it) and return a list of strings in the order of `jobs`: `"ok:<value>"` for a job that succeeded and `"err:<message>"` for a job that failed, where the message is the error's text (`e.message` in JS/TS, `str(e)` in Python). A value example: `"ok:-2"`. One job's failure must not affect the others. For an empty list return `[]`.

Example: jobs that return `7` and fail with the text `boom` → `["ok:7", "err:boom"]`.
