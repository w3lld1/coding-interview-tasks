# Job tree with all, any and seq combinators

**Difficulty:** hard · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-672?utm_source=github&utm_medium=tasks-repo)**

A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

A tree of tasks has nodes `0…n−1`: node 0 is the root, `parent[v]` (smaller than `v`) is the parent of node `v` (`-1` for the root), and the children of a node go in increasing index order. `kinds[v]` is `"job"` (a leaf: the k-th job node in index order runs `jobs[k]` once) or a group with at least one child:
- `"all"` starts all children at once; it succeeds when all have succeeded, with the sum of their values, and fails as soon as one fails, with that child's message;
- `"any"` starts all children at once; it succeeds as soon as one succeeds, with its value, and fails when all have failed, with the message of the last failure;
- `"seq"` starts its children one by one, each at the moment the previous one succeeded; it succeeds with the sum of their values, and fails as soon as a child fails, with its message (later children never start).

When an `"all"` or `"any"` group settles, its children still running are cancelled with their whole subtrees: nothing in them starts or settles any more (in JS/TS a cancelled job keeps running, ignore its result).

Run the root at moment 0. Return a list: first `"ok:<value>@<moment>"` or `"err:<message>@<moment>"` for the root (the moment in ms when it settled), then a label per job in order: `"ok:<value>"` or `"err:<message>"` if it ended, `"cancelled"` if it started and was cancelled, `"skipped"` if it never started. Every job takes at least 1 ms; in the tests no two started jobs end (or would end) at the same moment. Up to 30 nodes. The current time in ms: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: `parent = [-1, 0, 0, 0]`, `kinds = ["all", "job", "job", "job"]`, jobs (10 ms → `1`), (30 ms → `2`), (20 ms → error `"disk"`) → `["err:disk@20", "ok:1", "cancelled", "err:disk"]`.
