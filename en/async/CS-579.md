# How many requests were slow

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-579?utm_source=github&utm_medium=tasks-repo)**

A request log must be checked for slow requests. A request is an async function with no arguments (`await job()`) that returns a number (you may ignore it) or fails (throws). Start all the requests at once.

Return how many requests lasted strictly longer than `threshold` milliseconds. The duration of a request is the time from its start to its end, for a failed request up to the moment of the failure; failed requests count too. Up to 50 requests.

Example: requests last 5, 50 and 500 ms, `threshold = 10` → `2`.
