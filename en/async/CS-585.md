# Upload progress after each file

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-585?utm_source=github&utm_medium=tasks-repo)**

A cloud client uploads files one at a time and shows how many bytes have been sent in total. An upload is an async function with no arguments (`await upload()`) that returns the number of bytes sent (a non-negative integer) or fails (throws); a failed upload sent no bytes.

Run the uploads strictly one at a time, in list order, without stopping on failures. Return a list of the same length: element i is the total number of bytes sent after upload i. For an empty list return `[0]`. Up to 50 uploads.

Add, as the last element of the answer, the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: uploads take 10, 5 and 5 ms; the first returns `5`, the second fails, the third returns `3` → `[5, 5, 8, 20]`.
