# First k answers

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-580?utm_source=github&utm_medium=tasks-repo)**

A request is sent to several replicas, and the first `k` answers are enough. A request to a replica is an async function with no arguments (`await job()`) that returns a number and never fails. Send all the requests at once.

Return the values of the first `k` replicas that answered, in the order of answering; if answers come at the same moment, the replica earlier in the list goes first. Do not wait for the rest. If `k` is greater than the number of replicas, return the values of all; if `k = 0` or the list is empty, return `[0]`. Up to 50 replicas.

Add, as the last element of the answer, the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: replicas answer after 30, 10 and 20 ms with values `1`, `2`, `3`, `k = 2` → `[2, 3, 20]`.
