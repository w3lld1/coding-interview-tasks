# Sum of jobs run one by one

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-539?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the jobs one at a time, in list order: start the next one when the previous one has ended. Return the sum of the values of the jobs that succeeded. Skip a job that fails (it adds `0`) and go on to the next one. For an empty list return `[0, 0]`. Up to 50 jobs, integer values.

The answer is a list of two numbers: this result and the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: jobs take 10, 5 and 10 ms; the first returns `10`, the second fails, the third returns `6` → `[16, 25]`.
