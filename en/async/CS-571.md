# Error messages of installation steps

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Strings](../strings/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-571?utm_source=github&utm_medium=tasks-repo)**

An installer runs several steps. A step is an async function with no arguments (`await step()`) that returns a number or fails (throws an exception with a text message). The steps are independent: you may run them one at a time or all at once, the answer does not depend on it.

Return the error messages of the steps that failed, in the order of the step list (not in the order of failure time). The message of an exception is `str(e)` in Python and `e.message` in JS/TS. If nothing failed, return `[]`. Up to 50 steps.

Example: steps `1`, an error `"no disk"`, `2` → `["no disk"]`.
