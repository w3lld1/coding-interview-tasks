# Average price with a timeout

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-565?utm_source=github&utm_medium=tasks-repo)**

An app asks several shops for the price of an item. A request is an async function with no arguments (`await shop()`) that returns a non-negative integer price or fails (throws). Ask all the shops at once. Wait for each shop for at most `limit` milliseconds from the call of the function: a shop that has not answered by then counts as not answering. In the tests no shop answers exactly at `limit`.

The average price is the average over the shops that answered in time without an error, rounded down to an integer; if there are none, it is `0`. Return a list of two numbers: the average price and the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. The function finishes as soon as every shop has answered or `limit` has passed. For an empty list return `[0, 0]`. Up to 50 shops.

Example: shops answer after 10, 50 and 20 ms with `7`, `100` and an error, `limit = 30` → `[7, 30]` (the second shop was too late, the third failed).
