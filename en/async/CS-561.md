# Primary job and a backup

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-561?utm_source=github&utm_medium=tasks-repo)**

You are given two jobs, `primary` and `backup`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the primary one first. If it succeeds, return its value and do not start the backup. If the primary fails, run the backup and return its value. If that fails too, the value is `-1`. Return a list of two numbers: the value and the time in milliseconds from the call of the function to the answer. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: the primary fails after 10 ms, the backup returns `2` after 20 ms → `[2, 30]`.
