# Job pool with a timeout for each job

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-216?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`, a timeout `timeout` in milliseconds and a limit `limit`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the jobs with at most `limit` of them at once: start the first `limit` jobs, and each time a place frees up, start the next one in list order right away. Every job gets `timeout` ms from its own start: if it has not ended strictly before that, it has timed out; abandon it (do not wait for it) and give its place to the next job at that same moment. A job that ends exactly `timeout` ms after its start has timed out too.

Return a list as long as `jobs`: for each job its value if it ended in time, and `-1` if it timed out or failed. Job values are non-negative. Up to 50 jobs, `1 ≤ timeout ≤ 10^6`, `limit ≥ 1` (it may exceed the number of jobs). The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: jobs that take 10, 80 and 30 ms and return `1`, `2`, `3`, `timeout = 50`, `limit = 2` → `[1, -1, 3]` (the third starts at 10 ms, the second times out at 50 ms).
