# Poll the status until it is ready

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-573?utm_source=github&utm_medium=tasks-repo)**

You wait for a server to finish processing a file and poll its status. A poll is an async function with no arguments (`await check()`): it returns `1` when ready, any other number when not ready yet, or fails (throws), which you also treat as not ready. The list `checks` holds the polls in the order to run them.

Run the polls strictly one at a time, in list order. If a poll did not show readiness, wait `pause` milliseconds and run the next one (make no pause after the last poll). Stop at the first poll that returns `1`.

Return a list of two numbers: how many polls were run (`-1` if none returned `1`) and how many milliseconds passed from the call to the return. Time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 polls.

Example: polls of 5 ms return `0`, `0`, `1`, `pause = 100` → `[3, 215]`.
