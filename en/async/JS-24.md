# Promises

**Difficulty:** hard · **Language:** JavaScript · **Topics:** [Async and concurrency](../async/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-24?utm_source=github&utm_medium=tasks-repo)**

Implement `promisify` for a function whose last argument is `callback(error, data)`, returning a new function whose result is a Promise. Without using the built-in combinators of the same name, implement `all` that preserves order and rejects on the first error, `allSettled` that waits for all results and keeps the input order, `race` that settles on the first completion, and `any` that resolves on the first success. This is a learning contract, not exact ECMAScript polyfills: `allSettled` returns an array of values or error objects without status wrappers; when everything fails, `any` rejects with an array of errors in the input order, not an AggregateError. For `all`, `allSettled` and `race`, an empty array resolves to `[]`, and a missing argument resolves to `undefined`. `any([])` returns a Promise rejected with `[]`; `any()` returns a Promise resolved with the value `undefined`.
