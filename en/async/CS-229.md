# Pipeline with bounded buffers

**Difficulty:** hard · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-229?utm_source=github&utm_medium=tasks-repo)**

Items `0, 1, …, n − 1` pass through `m` stages in order: stage 0, then 1, …, then `m − 1`. Stage `s` has `limits[s]` slots, so at most `limits[s]` items are processed there at once; item `i` spends exactly `stage_times[i][s]` ms in stage `s`. At moment 0 all items are ready for stage 0 and enter it in increasing index order.

Between stages `s` and `s + 1` there is a queue. An item that finished stage `s` joins its end. The first `buffers[s]` items of the queue lie in the buffer; all the others are blocked: each keeps occupying its slot in stage `s`, and that slot cannot take a new item. A stage takes items strictly in queue order: as soon as it has a free slot and the queue in front of it is not empty, it takes the head at once. When the head leaves, the next blocked item moves into the buffer at that same moment and frees its slot; such a chain of moves may run back through several stages instantly. After the last stage the item leaves the pipeline at once.

If several items finish a stage at the same moment, they join the queue in increasing index order, and all of this happens before any slot is filled at that moment.

Return, for each item in index order, the moment it left the last stage, in ms from the start. The function is async: it is convenient to handle the events in time order and wait for each with a timer; the current time in milliseconds is `Date.now()` in JS/TS and `round(asyncio.get_running_loop().time() * 1000)` in Python. In the tests, waits run on a virtual clock and take no real time. Limits: up to 30 items, `1 ≤ m ≤ 5`, each `stage_times[i]` has exactly `m` numbers from 1 to 100000, `limits` has `m` numbers from 1 to 10, `buffers` has `m − 1` numbers from 0 to 10. With no items return `[]`.

Example: `stage_times = [[1, 5], [1, 5], [1, 5]]`, `limits = [1, 1]`, `buffers = [0]` → `[6, 11, 16]` (item 1 finishes stage 0 at moment 2 and keeps the only slot of stage 0 until moment 6, so item 2 starts stage 0 only at moment 6).
