# Jobs with a pause between them

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-558?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs` and a pause `pause` in milliseconds. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the jobs one at a time, in list order, keeping a pause of `pause` ms between neighbouring jobs (no pause after the last job). Return the time in milliseconds from the call of the function to the moment it finished. Every job in the tests succeeds. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. For an empty list return `0`.

Example: jobs that take 10 and 20 ms, `pause = 5` → `35`.
