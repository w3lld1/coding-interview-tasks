# Single-flight cache with a fetch limit

**Difficulty:** hard · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-228?utm_source=github&utm_medium=tasks-repo)**

Requests come to a cache: request `i` for key `keys[i]` arrives at moment `at[i]` (in ms from the start; the list `at` is not necessarily sorted). Fetching a key's value takes `fetch` ms, and at most `limit` fetches run at the same time. A fetch that found no free slot waits in a queue and starts as soon as a slot frees up; queued fetches start in the order they were created. A value whose fetch finished at moment `d` is valid for answers at moments `t` with `d ≤ t < d + ttl`.

An arriving request is handled like this: (1) if the key has a valid value, the request is answered at once; (2) otherwise, if a fetch of this key is already running or queued, the request waits for it and is answered when it finishes; (3) otherwise the request creates a new fetch of this key and is answered when it finishes. Requests that arrive at the same moment are handled by increasing index; a slot freed at some moment goes to the first queued fetch at that same moment.

Return the answer moments in request order, with the number of fetches created as the last element. The function is async: it is convenient to start one coroutine per request and wait with timers; the current time in milliseconds is `Date.now()` in JS/TS and `round(asyncio.get_running_loop().time() * 1000)` in Python. In the tests, waits run on a virtual clock and take no real time. The lists have the same length, up to 50 requests; `fetch`, `ttl` and `limit` are from 1 to 1000000, moments from 0 to 1000000. For empty lists return `[0]`.

Example: `["a", "a", "b", "a"]`, `[0, 5, 6, 30]`, `fetch = 10`, `ttl = 25`, `limit = 1` → `[10, 10, 20, 30, 2]` (request 1 waits for the running fetch of `a`, the fetch of `b` waits for a slot until 10, request 3 finds a valid value of `a`).
