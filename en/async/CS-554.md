# Values with a fallback number

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-554?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs` and a number `fallback`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Start all the jobs at once and return a list in the order of `jobs`: the job's value if it succeeded and `fallback` if it failed. One job's failure must not affect the others. For an empty list return `[0]`. Up to 50 jobs.

Add, as the last element of the answer, the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: jobs take 10, 30 and 20 ms; the first returns `1`, the second fails, the third returns `3`, `fallback = 0` → `[1, 0, 3, 30]`.
