# Price spread across shops

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-564?utm_source=github&utm_medium=tasks-repo)**

You want to compare the price of an item in several shops. A price request is an async function with no arguments (`await shop()`) that returns a non-negative integer price or fails (throws, for example the shop does not answer). Ask all shops at once.

Return the difference between the largest and the smallest received price. Ignore the shops that failed. If fewer than two requests succeeded, the result is `0`. Up to 50 shops.

The answer is a list of two numbers: this result and the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: shops answer after 10, 5 and 20 ms with `50`, an error and `90` → `[40, 20]`.
