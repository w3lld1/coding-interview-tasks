# Jobs in pairs

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-560?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Split the list into pairs of consecutive jobs: the first and the second, the third and the fourth, and so on (the last pair may hold one job). Start the jobs of a pair at the same time, and run the pairs one after another: the next pair starts when both jobs of the previous one have ended. Return the time in milliseconds from the call of the function to the end of the last pair. Every job in the tests succeeds. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. For an empty list return `0`.

Example: jobs that take 10, 20 and 30 ms → `50` (the pair 10 and 20 gives 20, then one job of 30).
