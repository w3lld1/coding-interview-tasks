# Values up to the first failure

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-547?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the jobs one at a time, in list order. As soon as a job fails, stop: start no further jobs. Return the list of the values of the jobs that succeeded before that failure, in list order. If nothing fails, these are the values of all the jobs; for an empty list return `[0]`. Up to 50 jobs.

Add, as the last element of the answer, the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: each job takes 5 ms; the first returns `1`, the second fails, the third returns `3` → `[1, 10]` (the third is never started).
