# Should the loading spinner show

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-575?utm_source=github&utm_medium=tasks-repo)**

An interface shows a loading spinner only if a request lasts longer than `threshold` milliseconds: fast answers must not flash it. A request is an async function with no arguments (`await job()`) that returns a number or fails (throws).

Run the request once. Return a list of two numbers: `1` if the request lasted strictly longer than `threshold` ms, otherwise `0`; and the value of the request, or `-1` if the request failed. A request that ends exactly at `threshold` does not show the spinner. Measure the duration from the call of your function.

Example: the request takes 500 ms and returns `7`, `threshold = 100` → `[1, 7]`.
