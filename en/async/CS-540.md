# All results in job order

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-540?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Start all the jobs at once, without waiting for one another, and return the list of their values in the order of `jobs`, not in the order they finish. Every job in the tests succeeds. For an empty list return `[0]`. Up to 50 jobs.

Add, as the last element of the answer, the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: jobs that take 30, 10 and 20 ms and return `1`, `2`, `3` → `[1, 2, 3, 30]`.
