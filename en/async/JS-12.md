# Translation Service

**Difficulty:** hard · **Language:** JavaScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-12?utm_source=github&utm_medium=tasks-repo)**

You are given a local learning `api`: `fetch(text)` returns a Promise of an object `{translation, quality}` or rejects with an error, and `request(text, callback)` adds a translation to the storage; a callback call without an error means success. Implement the class `TranslationService` with the constructor `new TranslationService(api)`. The method `free(text)` returns a Promise of the translation string without checking quality and passes API errors through; `batch(texts)` returns a Promise of all strings in the original order, rejects on the first error, and for an empty list rejects with `BatchIsEmpty`. The method `request(text)` wraps the callback API in a Promise: at most three attempts in total, `resolve(undefined)` on the first success; if all attempts fail, `reject` with the last error (not a successful return of an Error object). The method `premium(text, minimumQuality)` returns a Promise of a string: it first runs fetch; only on `NotAvailable` does it create the translation via request and repeat fetch; quality below `minimumQuality` means `reject` with `QualityThresholdNotMet`, and other errors are passed to the caller. Quality equal to the threshold is acceptable.
