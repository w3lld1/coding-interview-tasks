# Which photos failed to upload

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-566?utm_source=github&utm_medium=tasks-repo)**

A user picked several photos. Uploading one photo is an async function with no arguments (`await upload()`) that returns the file size or fails (throws). Upload all the photos at once.

Return the numbers (zero-based indexes) of the uploads that failed, in ascending order. If nothing failed, the answer holds only the time. Up to 50 uploads.

Add, as the last element of the answer, the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: three uploads take 10, 20 and 5 ms, the second one fails → `[1, 20]`.
