# Sum of the first n successful answers

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-586?utm_source=github&utm_medium=tasks-repo)**

A service collects data from a list of sources and stops as soon as it has `n` successful answers. A source is an async function with no arguments (`await job()`) that returns an integer or fails (throws).

Query the sources strictly one at a time, in list order. Skip a failure and go on to the next source. As soon as `n` successful answers are received, stop: do not call the remaining sources. Return a list of two numbers: the sum of the received values and the number of milliseconds from the call to the return. If fewer than `n` successful answers were found, sum all that there are. Time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 sources, `n ≥ 0`.

Example: sources return an error (5 ms), `2` (10 ms), an error (7 ms), `4` (1 ms), `5` (3 ms), `n = 2` → `[6, 23]`.
