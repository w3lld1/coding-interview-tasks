# Rolling update of service instances

**Difficulty:** hard · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-723?utm_source=github&utm_medium=tasks-repo)**

A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

A service of `n = len(jobs)` old instances is replaced by `n` new ones. Starting new instance `i` is a call of `jobs[i]` (a try); a success makes the instance ready, a failure makes it disappear; if it had fewer than `attempts` tries, it waits to be started again, otherwise the update fails. Stopping an old instance takes `stop` ms; during that time it no longer serves but still takes a place.

Available are the old running (not stopping) instances and the ready new ones; the total is all old ones except those fully stopped, plus the new ones starting or ready. At moment `0` and after every event (the end of a try, the end of a stop), repeat while something changes: stop an old instance if afterwards at least `n − max_unavailable` stay available; start the waiting new instance with the smallest number if the total is less than `n + max_surge`.

The update is complete when all new instances are ready and all old ones are stopped: return `[completion moment, s0, s1, …]`, where `si` is the moment instance `i`'s last (successful) try started. If a try of an instance that used up `attempts` failed at moment `t`, return `[-1, t]` at once. For `n = 0` the answer is `[0]`. The current time in ms: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 20 instances, `stop ≥ 1`, `attempts ≥ 1`, `max_surge, max_unavailable ≥ 0` with a sum of at least 1.

Example: three jobs of 10 ms each, `stop = 5`, `max_surge = 1`, `max_unavailable = 0`, `attempts = 1` → `[45, 0, 15, 30]`.
