# Delayed start of a job

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-562?utm_source=github&utm_medium=tasks-repo)**

You are given a pause `delay` in milliseconds and a job `job`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

First wait `delay` ms, then run the job. Return a list of two numbers: the job's value (or `-1` if it failed) and the time in milliseconds from the call of the function to the answer. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: `delay = 30`, the job takes 10 ms and returns `5` → `[5, 40]`.
