# All or nothing when saving settings

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-569?utm_source=github&utm_medium=tasks-repo)**

A settings form is saved with several requests. A request is an async function with no arguments (`await save()`) that returns an integer (how many records were saved) or fails (throws). Start all the requests at once.

If every request succeeded, the result is the sum of their results. If at least one failed, the form counts as not saved: the result is `-1`, and the function returns right after the first failure without waiting for the other requests. For an empty list return `[0, 0]`. Up to 50 requests.

The answer is a list of two numbers: this result and the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: requests take 10, 20 and 5 ms and return `3`, `4`, `5` → `[12, 20]`; requests take 10, 5 and 5 ms and the second one fails → `[-1, 5]`.
