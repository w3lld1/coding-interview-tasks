# Dependency-aware job pool

**Difficulty:** hard · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-224?utm_source=github&utm_medium=tasks-repo)**

A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

You are given a list of jobs `jobs`, a list of dependencies `deps` of the same length and an integer `limit ≥ 1`. Job `i` may start once every job whose index is in `deps[i]` has finished successfully (at once if `deps[i]` is empty). At most `limit` jobs run at the same time. A free slot always takes the ready job with the lowest index. A job with at least one dependency that failed (or that itself never starts) never starts.

If several jobs finish at the same moment, first take all of them into account (their successes may make new jobs ready), and only then fill the free slots. Every job takes at least 1 ms. `deps` has no cycles, no repeats and no job depending on itself; indexes are from 0 to `n − 1`, up to 30 jobs.

Return the indexes of all jobs that started, successful and failed alike, in the order they finished; at the same moment, in increasing index order. For an empty list the answer is `[]`.

Example: jobs (30 ms → `1`), (10 ms → `2`), (10 ms → error), (5 ms → `4`), (1 ms → `5`); `deps = [[], [], [1], [0, 1], [2]]`, `limit = 2` → `[1, 2, 0, 3]` (job 4 depends on the failed job 2 and never starts).
