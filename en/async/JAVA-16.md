# Parallel Letter Frequency

**Difficulty:** hard · **Language:** Java · **Topics:** [Async and concurrency](../async/), [Hash maps and sets](../hashing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-16?utm_source=github&utm_medium=tasks-repo)**

For an array of texts, compute the total frequency of each letter, distributing the work across parallel computations. Do not distinguish upper and lower case, and do not count digits, punctuation or whitespace; Unicode letters must also be counted. Merging the partial results must be thread-safe and give the same result as a sequential count.
