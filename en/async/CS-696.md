# Button with a cooldown

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-696?utm_source=github&utm_medium=tasks-repo)**

A «Send the code again» button starts the action `action`. A job is an async function with no arguments: call it (`await action()`) to run it; it may fail (throw). Every call is a new action of the same length; a failure also ends the action.

The user presses the button at the moments `clicks` (milliseconds from the call of the function, non-decreasing). A press is accepted if no action is running now and at least `cooldown` ms have passed since the end of the previous action (exactly `cooldown` is already enough); the first press is always accepted. An accepted press starts the action at once; a rejected one does nothing. Presses at the same moment are handled one by one, so at most one of them is accepted. Return the indexes of the accepted presses in increasing order. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python; in the tests the clock is virtual and waits take no real time. Up to 50 presses, `cooldown ≥ 1`.

Example: presses at 0, 5 and 20 ms, the action takes 10 ms, `cooldown = 5` → `[0, 2]` (at 5 ms the action is still running; at 20 ms 10 ms have passed since its end).
