# Quorum read

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-595?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs` (replicas, each with its own answer), a number `need ≥ 1` and a deadline `timeout` in milliseconds. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). Start all the jobs at once at the moment of the call. A replica's answer is the job's value; a failure means no vote.

Only answers that arrive no later than `timeout` ms count. Answers are handled by arrival moment, and for equal moments by increasing replica index. The winner is the value that first collects `need` equal answers. Return a list `[value, moment]`, where moment is the time in milliseconds from the call of the function at which the needed number was reached. If no value collects `need` answers, return `[-1, -1]`. Values are non-negative. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 jobs.

Example: jobs return `5` (10 ms), `7` (20 ms), `5` (30 ms), `7` (15 ms), `need = 2`, `timeout = 100` → `[7, 20]` (the seven collected two votes at 20 ms, the five only at 30 ms).
