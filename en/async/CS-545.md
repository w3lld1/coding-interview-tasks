# One job with a time limit

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-545?utm_source=github&utm_medium=tasks-repo)**

You are given a job `job` and a limit `limit` in milliseconds. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the job. If it succeeds sooner than `limit` ms, return its value. If it has not ended after `limit` ms, wait no longer and return `-1`. If it fails before the limit, return `-2`. In the tests no job ends exactly `limit` ms after the start.

Example: the job takes 100 ms and returns `5`, `limit = 50` → `-1`.
