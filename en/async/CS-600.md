# Rollout in waves

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-600?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`, the size of the first wave `first ≥ 1` and a factor `factor ≥ 2`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). The jobs are started in waves in index order: the first wave has `first` jobs, the second `first · factor`, the third `first · factor²` and so on (the last wave may be incomplete).

All jobs of one wave start together. The next wave starts at the moment all jobs of the previous one have ended, but only if the previous wave had no failure. After a wave with a failure no more jobs are started.

Return a list of two numbers: how many jobs succeeded and how many milliseconds passed from the call of the function to the end of the last started job. For an empty list return `[0, 0]`. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 jobs.

Example: jobs that take 10, 20, 5, 8 and 8 ms, `first = 1`, `factor = 2`, all succeed → `[5, 38]` (waves of 1, 2 and 2 jobs take 10, 20 and 8 ms).
