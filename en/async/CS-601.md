# Leaky-bucket queue

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-601?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`, moments `arrivals` (ms after the call of your function, non-decreasing), a queue capacity `capacity ≥ 1` and an interval `interval ≥ 1`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). Request `i` arrives at moment `arrivals[i]` and asks to run job `i`.

The server starts at most one job per `interval` ms. A request starts at once on arrival if the queue is empty and at least `interval` ms have passed since the last start (or there was no start yet). Otherwise it joins the queue if fewer than `capacity` requests are waiting, and if the queue is full it is dropped: its job is never called. Queued requests start one by one, in order of arrival, as soon as `interval` ms have passed since the last start. If a start from the queue and an arrival fall on the same moment, the queued request starts first. Started jobs run together, with no limit on their number.

Return the values of the started jobs that succeeded, in the order they finished; equal moments by increasing index. For an empty list return `[]`. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 jobs.

Example: four jobs of 5 ms return `1`, `2`, `3`, `4`, all arrive at 0 ms, `capacity = 2`, `interval = 10` → `[1, 2, 3]` (the requests start at 0, 10 and 20 ms, the fourth did not fit in the queue).
