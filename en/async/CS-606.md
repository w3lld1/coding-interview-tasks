# Pool with a changing number of places

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-606?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`, an increasing list of moments `times` (ms after the call of your function, `times[0] = 0`) and a list `caps` of the same length, `caps[k] ≥ 1`. From moment `times[k]` (until `times[k + 1]`) at most `caps[k]` jobs are allowed to run at once. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Jobs start strictly in index order, each at the first moment when the number of running jobs is below the current limit, including the very moment when the limit changed or a place was freed. When the limit goes down, running jobs are not interrupted: new jobs simply do not start until fewer jobs than the limit are running.

Return the values of the jobs that succeeded, in the order they finished; equal moments by increasing index. For an empty list return `[]`. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 jobs.

Example: four jobs of 10 ms return `1`, `2`, `3`, `4`, `times = [0, 10]`, `caps = [1, 3]` → `[1, 2, 3, 4]` (the first runs from 0 to 10 ms, the other three start at 10 ms and end at 20 ms).
