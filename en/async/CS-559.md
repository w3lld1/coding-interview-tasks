# Message of the earliest failure

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-559?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Start all the jobs at once and return the error text (`e.message` in JS/TS, `str(e)` in Python) of the job that failed first. If two failures happen at the same moment, return the one earlier in the list. If nothing fails (an empty list included), return the empty string `""`. Up to 50 jobs.

Example: jobs of 30 and 10 ms fail with `slow` and `fast` → `"fast"`.
