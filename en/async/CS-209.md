# Finish order in a job pool

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-209?utm_source=github&utm_medium=tasks-repo)**

Given a list of jobs `jobs` and a number `limit` (at least 1). A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). Run the jobs so that at most `limit` of them work at once, and start them strictly in index order: first the first `limit` jobs, and as soon as any running job finishes (with a value or with an error), start the next index at that same moment.

Return the values of the jobs that succeeded, in the order they finished; jobs that finished at the same moment go in increasing index order. A failed job adds nothing to the answer, but its slot is freed. For an empty list return `[]`. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. The list holds up to 50 jobs.

Example: jobs that take 30, 10 and 10 ms and return `1`, `2` and `3`, `limit = 2` → `[2, 3, 1]` (the job at index 2 starts at 10 ms, when a slot frees, and finishes at 20 ms).
