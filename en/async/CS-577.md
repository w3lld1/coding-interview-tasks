# Log in, then load the profile

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-577?utm_source=github&utm_medium=tasks-repo)**

An app first logs into an account and then loads the profile. Both operations are async functions with no arguments (`await login()`, `await profile()`) that return an integer or fail (throw). `login` returns the user number: a positive number means a successful login, any other number is a refusal.

Run `login` first. If it failed or returned a number not greater than zero, do not load the profile (do not call `profile`). Otherwise run `profile` after `login`. Return a list of two numbers: the value of `profile` (or `-1` if the login failed, the profile was not loaded or `profile` failed) and the number of milliseconds from the call to the return. Time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: `login` takes 30 ms and returns `42`, `profile` takes 50 ms and returns `7` → `[7, 80]`.
