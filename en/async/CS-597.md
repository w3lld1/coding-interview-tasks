# Collect answers until it goes quiet

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-597?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs` and a number `quiet ≥ 0` (milliseconds). A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). Start all the jobs at once.

Collect the values of the successful jobs in the order they finish (equal moments by increasing index), starting from the first successful one. Collecting stops when more than `quiet` ms pass after an accepted answer with no new successful answer: the next successful answer is accepted only if it arrives no later than `quiet` ms after the previous accepted one. Failures are not answers and do not extend the collecting. If no job succeeds, return `[]`. For an empty list return `[]` too. Up to 50 jobs.

Example: jobs return `1` (10 ms), `2` (20 ms) and `3` (60 ms), `quiet = 15` → `[1, 2]` (from 20 to 60 ms it stays quiet for 40 ms > 15).
