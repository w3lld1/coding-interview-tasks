# A second chance for failed jobs

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-583?utm_source=github&utm_medium=tasks-repo)**

A report builder runs jobs and retries the failed ones once. A job is an async function with no arguments (`await job()`) that returns an integer or fails (throws); calling the same function again may give another result.

First start all the jobs at once and wait for all of them. Then start again, also at once, only the jobs that failed, and wait for them. There are no more retries. Return a list of two numbers: the sum of the values of all successful calls (from both passes) and the number of milliseconds from the call to the end of the second pass (if nothing failed, the second pass is empty and takes no time). Time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 jobs.

Example: jobs `1` in 10 ms, `5` in 30 ms (the first call fails, the second succeeds) and `2` in 20 ms → `[8, 60]`.
