# First success within a time limit

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-211?utm_source=github&utm_medium=tasks-repo)**

Given a list of jobs `jobs` and a limit `timeout` in milliseconds. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). Start all jobs at once, at the moment the function is called, and return the value of the one that succeeds first; failures are not an answer. If several jobs succeed at the same moment, return the value of the one with the smaller index.

Return `-1` if no job succeeds before `timeout` ms have passed: all failed, the rest were too slow, or the list is empty. Answer right away: do not wait for the other jobs after the first success or after the limit. The jobs' values are non-negative; in the tests no job finishes exactly `timeout` ms after the start. The list holds up to 50 jobs.

Example: jobs that return `1` after 20 ms, fail after 5 ms and return `3` after 10 ms; `timeout = 100` → `3`.
