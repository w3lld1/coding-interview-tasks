# Finish moments, one by one

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-555?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the jobs one at a time, in list order. Return a list in the order of `jobs`: for each job, the time in milliseconds from the call of the function to the moment it ended. Every job in the tests succeeds. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. For an empty list return `[]`.

Example: jobs that take 10, 20 and 30 ms → `[10, 30, 60]`.
