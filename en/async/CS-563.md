# Widgets that loaded in time

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-563?utm_source=github&utm_medium=tasks-repo)**

A page shows several widgets. A widget is an async function with no arguments (`await widget()`) that returns a number or fails (throws). Start loading all the widgets at once, without waiting for one another.

Return the values of the widgets that loaded without an error strictly earlier than `budget` milliseconds after the call, in the order they finished. If two widgets finish at the same moment, the one earlier in the list goes first. Skip widgets that failed and widgets that were late. Up to 50 widgets.

Example: widgets take 30, 10 and 20 ms and return `1`, `2`, `3`, `budget = 25` → `[2, 3]`.
