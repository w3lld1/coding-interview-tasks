# Retry rounds with a growing pause

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-593?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`, a number of rounds `rounds ≥ 1` and a pause `pause ≥ 0` in milliseconds. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

In round `0` start all the jobs at once and wait until each has ended. If some jobs failed and the round is not the last, wait `pause · 2^r` ms, where `r` is the number of the round that just ended (from zero), and in round `r + 1` start only the failed jobs, all at once (each is called again: a new attempt). There are at most `rounds` rounds. If no job failed in a round, stop at once; there is no pause after the last round.

Return a list of two numbers: the sum of the values of all successful attempts and the time in milliseconds from the call of the function to the end of the last round. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. For an empty list return `[0, 0]`. Up to 50 jobs.

Example: jobs that take 10 ms (value `1`), 20 ms (value `2`, the first attempt fails) and 5 ms (always fails), `rounds = 3`, `pause = 10` → `[3, 75]` (round 0 ends at 20 ms, pause 10, round 1 takes 20 ms, pause 20, round 2 takes 5 ms).
