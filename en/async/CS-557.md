# Smallest of the results

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-557?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Start all the jobs at once, wait for each and return the smallest value among the jobs that succeeded. Failed jobs are ignored. If no job succeeded (an empty list included), the result is `-1`. Values may be negative. Up to 50 jobs.

The answer is a list of two numbers: this result and the time in milliseconds from the call of the function to the moment it finished. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: jobs take 10, 20 and 30 ms; the first returns `3`, the second fails, the third returns `8` → `[3, 30]`.
