# Job pool that stops at the first failure

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-226?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs` and a limit `limit ≥ 1`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw). Jobs return non-negative integers.

Run the jobs with at most `limit` of them at once: start the first jobs, and each time a job ends successfully, the next one in list order takes its place right away. After the first failure no new jobs start, but the ones already running are carried to the end, and the function waits for all of them. The exact rule for simultaneous events: a place freed by a success at moment `t` takes the next job only if no job failed strictly before `t` (a failure at the same moment `t` does not prevent the start); the place of a failed job takes no new jobs.

If nothing failed, return `["ok:<sum of the values>", "time:<time>"]`. Otherwise return `["error:<message of the first failure>", "done:<how many jobs ended successfully>", "time:<time>"]`; the first failure is the earliest one in time, and on equal times the one of the job with the lower index. The time is in milliseconds from the call to the end of the last job started. For an empty list return `["ok:0", "time:0"]`. The failure message is `error.message` in JS/TS and `str(error)` in Python. Up to 50 jobs. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python.

Example: jobs that take 50, 10, 5 and 5 ms, the second failing with `"bad"`, `limit = 2` → `["error:bad", "done:1", "time:50"]`.
