# Servers that answered the ping in time

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-567?utm_source=github&utm_medium=tasks-repo)**

A monitor pings several servers. A ping is an async function with no arguments (`await server()`) that returns any number or fails (throws). Start all the pings at once.

Return how many servers answered without an error no later than `limit` milliseconds after the call (an answer exactly at `limit` still counts). Up to 50 servers.

Example: the pings answer after 5, 8 and 12 ms, `limit = 10` → `2`.
