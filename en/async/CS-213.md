# Debounce with a maximum wait

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-213?utm_source=github&utm_medium=tasks-repo)**

A function is called at the moments `events` (milliseconds from the call of your function, non-decreasing; equal moments may occur). Its debounce wrapper does not run the function at once but postpones it: after each call at moment `t` the run is scheduled for `min(t + wait, first + max_wait)`, where `first` is the moment of the first call of the current burst, and the earlier schedule is cancelled. A burst starts with the first call after the previous run (or with the very first call) and ends with a run. A call that arrives exactly at the scheduled moment is handled before the run and joins the burst.

Your function is async: model the wrapper with timers (`setTimeout` in JS/TS, `loop.call_later` or `asyncio.sleep` in Python; the current time in milliseconds is `Date.now()` in JS/TS and `round(asyncio.get_running_loop().time() * 1000)` in Python) or compute the answer otherwise, and return the list of moments at which the function ran, in increasing order. For an empty `events` the answer is `[]`. Limits: `1 ≤ wait ≤ max_wait`, up to 100 calls, moments up to 10⁶.

Example: `[0, 5, 12, 30]`, `wait = 10`, `max_wait = 15` → `[15, 40]` (the first burst starts at 0 and cannot wait longer than 15 ms).
