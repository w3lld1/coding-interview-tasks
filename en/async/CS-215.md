# Sequential jobs until a deadline

**Difficulty:** medium · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-215?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs` and a deadline `deadline` in milliseconds after the call. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Run the jobs one at a time, in list order: the next one starts as soon as the previous one has ended. A job is in time if it ends strictly before the moment `deadline`; one that ends exactly at `deadline` is already late. When the deadline comes, stop: abandon the job still running (do not wait for it) and start no more. A job that fails before the deadline is skipped, and you go on to the next one.

Return a list: the values of the jobs that finished in time, in list order, and as the last element the time in milliseconds from the call to the moment the function returned (that is `deadline` if the deadline cut the work short, otherwise the moment the last job ended). For an empty list return `[0]`. The current time in milliseconds: `Date.now()` in JS/TS, `round(asyncio.get_running_loop().time() * 1000)` in Python. Up to 50 jobs, `0 ≤ deadline ≤ 10^6`.

Example: jobs that take 30, 40 and 50 ms and return `1`, `2`, `3`, `deadline = 100` → `[1, 2, 100]` (the third job started at 70 ms and had not ended by 100 ms).
