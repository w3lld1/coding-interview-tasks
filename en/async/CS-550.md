# Last successful job to finish

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-550?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Start all the jobs at once and return the value of the successful job that ends last; failed jobs do not count, even if they end later. Every job in the tests ends at a different moment. If no job succeeded (an empty list included), return `-1`. Up to 50 jobs.

Example: jobs that take 30, 10 and 20 ms and return `1`, `2`, `3` → `1`; if the first job fails instead, the answer is `3`.
