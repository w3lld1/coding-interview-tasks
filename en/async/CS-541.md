# Job that finishes first

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-541?utm_source=github&utm_medium=tasks-repo)**

You are given a list of jobs `jobs`. A job is an async function with no arguments: call it (`await job()`) to run it; it may fail (throw).

Start all the jobs at once and return the value of the one that ends first. If two jobs end at the same moment, return the value of the one earlier in the list. Every job in the tests succeeds. For an empty list return `-1`. Up to 50 jobs.

Example: jobs that take 30, 10 and 20 ms and return `1`, `2`, `3` → `2`.
