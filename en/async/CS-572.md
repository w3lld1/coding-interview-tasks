# Downloads until the data cap

**Difficulty:** easy · **Languages:** Python, JavaScript, TypeScript · **Topics:** [Async and concurrency](../async/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-572?utm_source=github&utm_medium=tasks-repo)**

A mobile plan has a data cap `cap` (in megabytes). A download is an async function with no arguments (`await download()`) that returns the file size in megabytes (a non-negative integer) or fails (throws); a failed download used no data.

Run the downloads strictly one at a time, in list order. Before each download check: if `cap` megabytes or more have already been downloaded, stop. Return how many downloads were started (failed ones included). Up to 50 downloads, `cap ≥ 0`.

Example: files `40`, `50`, `30`, `cap = 80` → `2` (after two files 90 ≥ 80 are downloaded, so the third is not started).
