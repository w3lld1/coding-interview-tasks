# Selecting columns from CSV with quotes

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Errors and exceptions](../errors/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-651?utm_source=github&utm_medium=tasks-repo)**

You get a CSV text `text`, a delimiter `delimiter` (one character, not a quote and not a line break) and a list of names `columns`. The first row is the header with the column names. Return the data rows (without the header) in order; each holds the values of the columns from `columns` in the order of that list (a name may repeat).

Parsing rules:
- rows are separated by `\n`; one `\n` at the very end of the text ends the last row and does not start a new one; an empty line in the middle is a row with one empty field;
- fields of a row are separated by `delimiter`;
- an unquoted field is any characters except the delimiter, `\n` and `"`; spaces are part of the value;
- a quoted field starts with `"` as the first character of the field and ends at a single `"`; it may contain the delimiter and `\n`, and a pair `""` stands for one quote; right after the closing quote must come the delimiter, `\n` or the end of the text.

Report an error: throw an exception, or return an error in Go, if the text is empty, a quote appears inside an unquoted field, another character follows a closing quote, a quote is never closed, a row has a different number of fields than the header, a header name is empty or repeated, or `columns` has a name that is not in the header.

Example: `"id,item\n1,\"Tea, green\"\n"`, `","`, `["item"]` → `[["Tea, green"]]`.
