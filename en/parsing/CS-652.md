# INI configuration with references between values

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Errors and exceptions](../errors/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-652?utm_source=github&utm_medium=tasks-repo)**

A settings file is given as a list of lines `lines`. Return the values of the keys in `queries` (each query is `section.key`) after substituting references, in the order of the queries.

Each line is first stripped of spaces at both ends, then:
- an empty line and a line starting with `;` or `#` are skipped;
- `[name]` starts a section; the name is non-empty, made of Latin letters, digits and `_`, with no spaces inside the brackets; a section may appear several times and its keys are merged;
- `key = value` is a key of the current section: the key is the text before the first `=` without surrounding spaces (a name by the same rules), the value is the text after it without surrounding spaces (it may be empty and may contain `=`);
- any other line is an error; a key before the first section and a key repeated within one section are errors too.

In a value, `${key}` is a reference to a key of the same section and `${section.key}` to a key of another section; a reference is replaced by the final value of that key (its own references are expanded in its section). `$$` stands for one `$` character; any other `$` (not followed by `{` or `$`, without a closing `}`, or with an invalid name inside) is an error.

The whole file is checked: every value must expand, even if no query asks for it. Report an error: throw an exception, or return an error in Go, on any format error, a reference to a missing key, a reference cycle, and a query for a missing key.

Example: `["[app]", "name = Shop", "title = ${name}!"]`, `["app.title"]` → `["Shop!"]`.
