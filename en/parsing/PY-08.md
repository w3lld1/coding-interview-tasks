# Luhn

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Math](../math/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-08?utm_source=github&utm_medium=tasks-repo)**

Validate a string identifier with the Luhn algorithm and return true or false. Remove spaces; if fewer than two digits remain or any other characters are present, the answer is false. Moving from right to left, double every second digit starting with the second from the right, and subtract 9 from any result greater than 9. The identifier is valid if the sum of the transformed and remaining digits is divisible by 10.
