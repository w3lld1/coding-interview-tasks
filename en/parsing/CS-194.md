# Decimal number with digit separators

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-194?utm_source=github&utm_medium=tasks-repo)**

Check whether a string is a valid decimal number. A valid number is made of three consecutive parts, with no spaces:

1. an optional sign `+` or `-`;
2. a mantissa of one of the forms "digits", "digits`.`", "digits`.`digits" or "`.`digits";
3. an optional exponent: the letter `e` or `E`, then an optional sign `+` or `-`, then digits (no dot).

Here "digits" is a non-empty run of the characters `0`–`9` in which single underscores `_` may be placed for readability, but only between two digits (`1_000` is fine; `1__0`, `_1`, `1_` are not). Leading zeros are allowed. Any other character makes the number invalid. Return `true` or `false`; an empty string gives `false`.

The string has at most 50 characters.

Example: `"1_000.25e-3"` → `true`; `"1__000"` → `false`.
