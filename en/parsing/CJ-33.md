# Summarize IPv4 subnets

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-33?utm_source=github&utm_medium=tasks-repo)**

An IPv4 subnet is written `A.B.C.D/P`: an address of four numbers from 0 to 255 and a prefix length `P` from 0 to 32. The subnet contains every address (a 32-bit number) whose first `P` bits equal those of the given address. A subnet is normalized if all address bits after the prefix are zero: `10.8.1.2/24` is the same subnet as `10.8.1.0/24`, and the normalization of `255.255.255.255/13` is `255.248.0.0/13`.

You get a list of subnets (repeats and overlaps are possible). Return the shortest list of normalized subnets that covers exactly the same addresses as the input. This list is unique; order it by increasing address (numerically, that is by the first number, then the second, and so on).

Limits: up to 10000 subnets. A subnet of length 0 is written `0.0.0.0/0`.

Example: `["10.1.2.3/8", "10.2.3.4/17"]` → `["10.0.0.0/8"]` (the second subnet lies entirely inside the first).
