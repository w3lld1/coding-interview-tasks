# Lisp-like evaluator with let

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Recursion and backtracking](../recursion/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-196?utm_source=github&utm_medium=tasks-repo)**

You are given a string holding an expression of a tiny Lisp-like language. Evaluate it and return the integer result. An expression is one of five kinds:

- an integer: an optional minus sign and digits, such as `-12`;
- a variable: a lowercase Latin letter followed by lowercase letters and digits (`x`, `ab2`); its value is the one assigned by the innermost enclosing `let`;
- `(add e1 e2)`: the sum of the values of `e1` and `e2`;
- `(mult e1 e2)`: their product;
- `(let v1 e1 v2 e2 … vn en expr)` with `n ≥ 1`: the assignments run in order from left to right, `vi` gets the value of `ei`, and each `ei` already sees the assignments made before it in the same `let`; then the last expression `expr` is evaluated, and its value is the value of the `let`. Assigning the same variable again in one `let` replaces its value.

Variables of a `let` are visible only inside it: an inner `let` hides an outer variable of the same name, and after the closing parenthesis the outer one applies again. The words `let`, `add` and `mult` are never variable names. Neighbouring items are separated by exactly one space, with no spaces next to parentheses. The expression is guaranteed to be valid, every variable is assigned before it is used, the string has at most 2000 characters, and every intermediate value fits in a signed 32-bit integer.

Example: `"(let x 2 (mult x (let x 3 y 4 (add x y))))"` → `14`.
