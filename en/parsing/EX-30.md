# Parse an SGF game record

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-30?utm_source=github&utm_medium=tasks-repo)**

Parse a simplified SGF game record. Grammar (there is no whitespace between elements): a tree is `(`, one or more nodes in a row, zero or more nested trees, `)`; a node is `;` followed by zero or more properties; a property is a key of uppercase Latin letters (`A` to `Z`, at least one) and one or more values in `[...]`. Nodes in a row form a chain in which every next node is a child of the previous one, and the nested trees are children of the last node of the chain. Keys in one node never repeat. Inside a value `\` escapes the next character: `\]` and `\\` give `]` and `\`, and `\` before a newline removes the newline; any other character after `\` is inserted as it is (`\n` is just `n`). Any whitespace character other than a newline (tab, `\r`, `\f`, `\v`), including one after `\`, becomes a space, and a newline without `\` stays. The whole string must be exactly one tree, otherwise report an error: throw an exception, or return an error in Go.

Return the nodes in depth-first order (a node, then its children left to right), one string per node of the form `<depth>:<properties>`. The root has depth `0`. Properties are in ascending key order, each written as the key followed by its values in `[...]` with no separators, and `\` and `]` in values are escaped with a backslash again. A node without properties gives `<depth>:`.

Example: `"(;A[B](;C[d\]])(;E[f]))"` → `["0:A[B]", "1:C[d\]]", "1:E[f]"]` (the characters are shown as they are, without string-literal escaping).
