# Note durations

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-17?utm_source=github&utm_medium=tasks-repo)**

A string describes musical notes in a text format, with notes separated by a single space. The symbols are: `o` whole note (4 beats), `o|` half note (2 beats), `.|` quarter note (1 beat). Return the list of note durations in beats, in the same order. For an empty string return an empty list.

Example: `"o o| .| o"` → `[4, 2, 1, 4]`.
