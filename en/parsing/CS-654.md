# Mini template engine with conditions and filters

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Errors and exceptions](../errors/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-654?utm_source=github&utm_medium=tasks-repo)**

Render the template `template` with the variables `variables` (a map from name to string). Text outside tags is copied as is. A tag starts with `{{` and ends at the nearest `}}`; its content is stripped of spaces at both ends. A name is a non-empty string of Latin letters, digits and `_`. The template and the values consist of printable ASCII characters.

Kinds of tags:
- `{{name}}` or `{{name|filter|filter...}}` outputs the variable's value; spaces around the parts between `|` are ignored; filters apply from left to right: `upper` (upper case), `lower` (lower case), `trim` (strip spaces at both ends), `reverse` (reverse), `length` (the length of the string as a decimal number);
- `{{#if name}}` ... `{{/if}}` outputs its content if the variable exists and its value is not empty; `{{#unless name}}` ... `{{/unless}}` is the opposite; `#` is directly followed by the word `if` or `unless`, and one or more spaces separate that word from the name;
- `{{else}}` inside a block (at most once) starts the part that is output when the main part is not.

Blocks nest. A missing variable in a condition counts as empty.

Report an error: throw an exception, or return an error in Go, if a tag is not closed, a tag is empty or of another kind, a filter is unknown, `{{else}}` is outside a block or repeated, a closing tag does not match the open block, or a block is not closed. These errors are looked for in the whole template, even in parts that are not output. Outputting a missing variable is also an error, but only if that tag is actually output.

Example: `"Hi {{name|upper}}{{#if vip}}, VIP{{/if}}!"`, `{"name": "ann"}` → `"Hi ANN!"`.
