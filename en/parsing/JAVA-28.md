# Logs, Logs, Logs!

**Difficulty:** easy · **Language:** Java · **Topics:** [Parsing and validation](../parsing/), [Classes and OOP](../oop/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-28?utm_source=github&utm_medium=tasks-repo)**

Parse a log line of the form [LVL]: MESSAGE and represent the level as an enum: TRC, DBG, INF, WRN, ERR and FTL correspond to TRACE, DEBUG, INFO, WARNING, ERROR and FATAL. Convert an unknown code to UNKNOWN. Build a short form "code:message" without brackets, using the numeric codes UNKNOWN=0, TRACE=1, DEBUG=2, INFO=4, WARNING=5, ERROR=6 and FATAL=42.
