# Matching versions against a semver range

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Errors and exceptions](../errors/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-658?utm_source=github&utm_medium=tasks-repo)**

You get a list of versions `versions` and a range `spec` in a simplified semver notation. Return the versions that satisfy the range, in ascending order.

A version is `MAJOR.MINOR.PATCH`, three non-negative integers without leading zeros; versions compare as triples of numbers; all versions in the list are distinct. A partial version is 1–3 parts separated by dots, each part a number without leading zeros or a wildcard `x`, `X`, `*`; only wildcards may follow a wildcard (`1.x.x` is fine, `1.x.3` is not). Let `p` be the numbers of a partial version before the first wildcard, `k` their count (0–3), `pad(p)` be `p` padded with zeros to three numbers, and `next(p, i)` be `p` with number `i` (from zero) increased by 1 and zeros after it.

A comparator is an operator directly followed by a partial version (`p`, `k` as above). For `k = 0`: `>` and `<` match nothing, the others match everything. Otherwise (`k = 3` for a full version):
- no operator or `=`: equal to `p` when `k = 3`, otherwise `>= pad(p)` and `< next(p, k − 1)`;
- `>`: greater than `p` when `k = 3`, otherwise `>= next(p, k − 1)`; `>=`: `>= pad(p)`; `<`: `< pad(p)`;
- `<=`: at most `p` when `k = 3`, otherwise `< next(p, k − 1)`;
- `~`: `>= pad(p)` and `< next(p, min(k − 1, 1))`;
- `^`: `>= pad(p)` and `< next(p, i)`, where `i` is the index of the first non-zero number in `p`, or `k − 1` if there is none.

A range is parts separated by `||` (spaces around it are allowed); a version satisfies it if it satisfies at least one part. A part is comparators separated by one or more spaces (all must hold), or exactly `A - B` of two partial versions without operators: the lower bound is `>= pad(A)` (none if `A` has `k = 0`), the upper is `<= B` for a full `B`, `< next(B, k − 1)` for a partial one, and none for `k = 0`.

Report an error: throw an exception, or return an error in Go, if a version in the list or the range notation is malformed (an empty part, an unknown operator, a space after an operator, extra version parts, leading zeros, a number after a wildcard).

Example: `["1.2.3", "1.3.0", "2.0.0"]`, `"^1.2.3"` → `["1.2.3", "1.3.0"]`.
