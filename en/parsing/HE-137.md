# Larger of two mixed-type values

**Difficulty:** easy · **Language:** Python · **Topics:** [Parsing and validation](../parsing/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-137?utm_source=github&utm_medium=tasks-repo)**

Each of the two arguments is a real number written either as a number (integer or fraction) or as a string. In a string the fractional part is separated by a dot or a comma: `"2.5"` or `"2,5"`. Compare the values as numbers and return the argument that is larger, exactly as it was passed (a number stays a number, a string stays a string with its original comma or dot). If the values are equal, return `null`.

Example: `1`, `"2,3"` → `"2,3"`; `"1"`, `1` → `null`.
