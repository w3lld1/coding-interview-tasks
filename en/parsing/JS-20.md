# Regular Chatbot

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-20?utm_source=github&utm_medium=tasks-repo)**

Write functions that recognize Chatbot at the start of a command case-insensitively and remove all emoji sequences followed by digits without fixing the surrounding spaces; for the removal, create the expression with the RegExp constructor. A phone number must strictly match the format '(+##) ###-###-###', where # is a digit: return 'Thanks! You can now download me to your phone.' on success or 'Oops, it seems like I can't reach out to {input}' otherwise. Extract from a text an array of simple addresses made of word parts separated by dots. Using a regex replacement, convert a name like 'Smith, John' into the greeting 'Nice to meet you, John Smith'.
