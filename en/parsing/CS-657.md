# Filter language for records

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-657?utm_source=github&utm_medium=tasks-repo)**

You get records `records` (maps from field to string) and a filter query `query`. Return the indexes of the records (from `0`, ascending) for which the query is true.

Query tokens (spaces between them are ignored):
- a field: a Latin letter or `_`, then Latin letters, digits and `_`; the words `and`, `or`, `not` are keywords and are never fields;
- a number: an optional `-` right before the digits, and digits (`42`, `-5`);
- a string in single quotes; inside, `\'` stands for a quote and `\\` for a backslash; any other character after `\` is not allowed;
- the comparison operators `=`, `!=`, `<`, `<=`, `>`, `>=`, and the parentheses `(` and `)`.

Grammar: a comparison is `field operator number` or `field operator string` (the field is always on the left); `not`, then `and`, then `or`, in order of decreasing binding strength; parentheses group.

If a record has no such field, the comparison is false (for `!=` too). With a string, the value is compared as a string (character by character, by code). With a number, the record's value must be an integer (an optional `-` and digits), and the numbers are compared. Every comparison is evaluated for every record, without short-circuiting `and`/`or`. All numbers in the query and the records are at most `10^9` in absolute value.

Report an error: throw an exception, or return an error in Go, if the query is empty or breaks the rules above (an unterminated string, a bad escape, an unknown character, a missing operand, an extra or unclosed parenthesis, extra tokens), and also if a value compared with a number exists in a record but is not an integer.

Example: `[{"city": "Rome", "total": "80"}, {"city": "Oslo", "total": "9"}]`, `"total > 10 or city = 'Oslo' and not total = 9"` → `[0]`.
