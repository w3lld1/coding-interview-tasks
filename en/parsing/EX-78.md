# Clean a phone number

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Strings](../strings/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-78?utm_source=github&utm_medium=tasks-repo)**

A North American Numbering Plan number has 10 digits `NXX NXX-XXXX`: an area code (3 digits) and a local number (7 digits, the first three are the exchange code). `N` is a digit from 2 to 9, `X` is any digit. The country code `1` or `+1` may come before the number.

Convert the input text to the 10 digits without the country code. The text may contain digits and the characters space, `+`, `(`, `)`, `-`, `.`; these are dropped. Any letter or any other character is an error. These are errors too: fewer than 10 digits; more than 11 digits; exactly 11 digits when the first is not `1`; the first digit of the area code (after removing the country code) is 0 or 1; the first digit of the exchange code is 0 or 1. To report an error, throw an exception, or return an error in Go.

Example: `"+1 (613)-995-0253"` → `"6139950253"`.
