# ISBN-10 verifier

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-60?utm_source=github&utm_medium=tasks-repo)**

An ISBN-10 has 9 digits and a check character: a digit or an upper-case `X` (meaning 10). Hyphens may appear anywhere and are ignored. The number is valid if the sum `d₁·10 + d₂·9 + … + d₁₀·1` is divisible by 11. Return `true` for a valid number and `false` for any other string: exactly 10 characters must remain after removing hyphens, `X` is allowed only in the last place, and every other character is invalid (a lower-case `x` too).

Example: `"3-598-21508-8"` → `true`, `"3-598-2X507-9"` → `false`.
