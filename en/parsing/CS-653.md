# Parsing a URL query string with nested keys

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Errors and exceptions](../errors/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-653?utm_source=github&utm_medium=tasks-repo)**

You get a URL query string `query` (the part of an address after `?`; one leading `?`, if present, is dropped). Parse it and return a list of `path=value` strings in the order of the pairs.

Rules:
- pairs are separated by `&`; empty pieces (`&&`, a trailing `&`) are skipped;
- in a pair the name is the text before the first `=` and the value is the text after it; a pair without `=` has an empty value;
- the name and the value are decoded: `+` becomes a space, `%HH` (two hexadecimal digits of any case) becomes the character with that code; the code must be below `128`; any other `%` is an error;
- the decoded name looks like `base[step1][step2]...`: the base is non-empty, a step is `[text]` (an object key) or `[]` (a new array element); only such steps may follow the base; the characters `[`, `]` and `.` are not allowed inside the base or a step;
- the path is the base and the steps joined with dots; each `[]` appends a new element to the array at that place and is replaced by its number: `0`, `1`, ... (counted separately for each array).

Every place in the structure has one kind: a value, an object or an array. Report an error: throw an exception, or return an error in Go, if a decoding or name rule is broken, one place is used both as an object and as an array, or both as a value and as a container, or the value at one path is given twice.

Example: `"tags[]=new&tags[]=sale&q=red+shoes"` → `["tags.0=new", "tags.1=sale", "q=red shoes"]`.
