# Add-and-subtract calculator with parentheses

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Parsing and validation](../parsing/), [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-82?utm_source=github&utm_medium=tasks-repo)**

You are given a string `expression` of up to 1000 characters holding a valid arithmetic expression. It contains non-negative integers (up to 10⁹, unsigned), binary `+` and `-`, unary minus, parentheses and spaces between any tokens. A unary minus may appear wherever an operand is expected: at the start, after `(`, after a binary operator or after another unary minus (`2 - -3`, `--4`). There is no unary plus. Evaluate the expression and return the result. Every intermediate value fits in a 64-bit integer. Built-in expression evaluators (`eval` and the like) are not allowed.

Example: `"10 - (4 - -2)"` → `4`.
