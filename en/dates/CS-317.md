# Busiest week

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-317?utm_source=github&utm_medium=tasks-repo)**

You get a list of event dates `"YYYY-MM-DD"` (in any order; one date may repeat, meaning several events that day) and a window length `window_days` ≥ 1. A window is `window_days` consecutive calendar days, including the first and the last. Return the largest number of events inside any window. For an empty list return `0`. The calendar is Gregorian, at most 10000 events.

Example: `["2024-03-01", "2024-03-02", "2024-03-08"]`, `7` → `2` (the window 1 to 7 March holds two dates; 8 March is not in it).
