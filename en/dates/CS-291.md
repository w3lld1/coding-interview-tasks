# Overlap of two time ranges

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-291?utm_source=github&utm_medium=tasks-repo)**

You get two ranges of the same day written as `HH:MM-HH:MM` (start, hyphen, end; exactly 11 characters). Return how many minutes the two ranges overlap. Ranges that only touch at a border, and disjoint ranges, give `0`.

A time is a string `HH:MM` of exactly 5 characters: hours `00` to `23`, minutes `00` to `59`. The start must be strictly before the end: a range does not cross midnight and is not empty. If either range is written wrongly, report an error: throw an exception, or return an error in Go.

Example: `"09:00-11:00"`, `"10:00-12:00"` → `60`.
