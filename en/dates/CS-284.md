# 12-hour clock

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Strings](../strings/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-284?utm_source=github&utm_medium=tasks-repo)**

You get a number of minutes since midnight (from 0 to 1439). Return the time in the 12-hour format `H:MM AM` or `H:MM PM`: the hour without a leading zero from 1 to 12, the minutes with two digits, then a space and `AM` (before noon) or `PM` (from noon). Midnight is `12:00 AM`, noon is `12:00 PM`.

If the number is outside 0 to 1439, report an error: throw an exception, or return an error in Go.

Example: `785` → `"1:05 PM"`.
