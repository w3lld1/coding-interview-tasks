# Periods when too many people are away

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-647?utm_source=github&utm_medium=tasks-repo)**

You get employees' vacations `vacations` — strings `"YYYY-MM-DD YYYY-MM-DD"`, a vacation from the first date to the second inclusive (the first is not after the second); each string is one person away. Find every day when at least `k` people (`k ≥ 1`) are away at the same time and return those days as maximal runs of consecutive days — strings `"FROM TO"` in the same format, in increasing order. If there are no such days, return `[]`.

Vacations can be long (years), so walking every single day is not required and not always wise. The calendar is Gregorian, all dates are valid, and there are up to 10000 strings.

Example: `["2024-07-01 2024-07-14", "2024-07-10 2024-07-20", "2024-07-12 2024-07-12"]`, `2` → `["2024-07-10 2024-07-14"]`.
