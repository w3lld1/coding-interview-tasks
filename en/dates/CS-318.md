# Sum of duration strings

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-318?utm_source=github&utm_medium=tasks-repo)**

You get a list of durations written like `"1h30m15s"`: optional parts "hours `h`", "minutes `m`", "seconds `s`", in exactly this order, each at most once, each a number of 1 to 6 decimal digits plus the letter. Minutes and seconds need not be below 60 (`"90m"` is fine). Return the sum of all durations in seconds (it may not fit into 32 bits). For an empty list return `0`.

Report an error: throw an exception, or return an error in Go — if a string is empty or does not follow this notation (another order of parts, a repeated part, an unknown letter, a number without a letter, spaces, a minus sign, a number longer than 6 digits).

Example: `["1h30m15s", "45s"]` → `5460`.
