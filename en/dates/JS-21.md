# Appointment Time

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Dates and time](../dates/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-21?utm_source=github&utm_medium=tasks-repo)**

Implement creating an appointment n calendar days after the passed now, or after the current time if now is absent, keeping the local time of day. Add converting a Date to an ISO string and getting from a timestamp string an object {year, month, date, hour, minute}, where the month is zero-based. Updating an appointment takes an object with new values for these fields, respects zero values and Date normalization, and returns the same kind of details object. Two more functions must return the rounded difference "second appointment minus first" in seconds and check whether an appointment is strictly later than the passed current time.
