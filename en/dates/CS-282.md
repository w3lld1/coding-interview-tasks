# Minutes between two times

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-282?utm_source=github&utm_medium=tasks-repo)**

You get the start time and the end time of a shift. Return how many minutes passed from the start to the end. If the end is earlier than the start, the shift crossed midnight and the end belongs to the next day; if the times are equal, the answer is 0 (a shift is never a full day or longer).

A time is a string `HH:MM` of exactly 5 characters: hours `00` to `23`, minutes `00` to `59`. If either time is written wrongly, report an error: throw an exception, or return an error in Go.

Example: `"23:30"`, `"00:15"` → `45`.
