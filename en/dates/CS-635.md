# Timesheet against the badge log

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-635?utm_source=github&utm_medium=tasks-repo)**

Payroll checks how much time an employee declared in the timesheet against what the door badge recorded. The badge log `badge` holds strings `"YYYY-MM-DD HH:MM IN"` (entry) and `"YYYY-MM-DD HH:MM OUT"` (exit) in any order. Sorted by time, the events must alternate: in, out, in, out…, start with an entry and end with an exit, and no two events fall on the same minute. Each entry–exit pair gives worked minutes; if a pair crosses midnight, the minutes before midnight belong to one date and those after it to the next.

The timesheet `declared` holds strings `"YYYY-MM-DD HH:MM"`: a date and the declared length in hours and minutes (`00:00` to `24:00`), each date at most once. For every date with worked minutes or a timesheet line, the difference is declared minus worked (a missing value counts as zero). Return, by increasing date, strings `"YYYY-MM-DD ±N"` for the dates where the absolute difference exceeds `tolerance`; the sign is always written (`+15`, `-30`).

Report an error (throw an exception, or return an error in Go) if `tolerance < 0`, a string is malformed, an event type is not `IN`/`OUT`, a date does not exist, a time is outside `00:00`–`23:59`, the alternation is broken, two events share a minute, a timesheet length exceeds `24:00` or has minutes above 59, or a timesheet date repeats.

Example: `["2024-03-05 22:00 IN", "2024-03-06 06:00 OUT"]`, `["2024-03-05 02:00", "2024-03-06 06:15"]`, `10` → `["2024-03-06 +15"]`.
