# Sort dates chronologically

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Parsing and validation](../parsing/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-299?utm_source=github&utm_medium=tasks-repo)**

You get a list of dates in the format `DD.MM.YYYY` (all valid, a four-digit year, Gregorian calendar). Return a new list of the same strings ordered from the earliest date to the latest; equal dates stay together. You do not need to change the input list. Plain string comparison does not work here: `"10.02.2023"` is lexicographically greater than `"09.03.2024"` although its date is earlier.

Example: `["15.03.2024", "01.01.2025", "31.12.2023"]` → `["31.12.2023", "15.03.2024", "01.01.2025"]`.
