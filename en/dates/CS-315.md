# First common meeting slot

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-315?utm_source=github&utm_medium=tasks-repo)**

Several people want to schedule a meeting. For each one you get a list of busy spans `"HH:MM-HH:MM"` (in any order, they may overlap and stick out of the workday). The workday runs from `day_start` to `day_end` (`"HH:MM"`). Find the earliest time from which everyone is free for `duration` minutes in a row (`duration` ≥ 1) inside the workday and return it as `"HH:MM"`. If there is no such slot, return an empty string. A slot may start exactly when someone's busy time ends and end exactly when it begins.

Example: `[["09:00-10:00", "12:00-13:00"], ["09:30-11:00"]]`, `"09:00"`, `"17:00"`, `60` → `"11:00"`.
