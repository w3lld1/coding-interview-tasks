# Sessions from event times

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-321?utm_source=github&utm_medium=tasks-repo)**

You get the event log of one day: strings `"HH:MM:SS"` in any order (repeats are possible). Events are split into sessions: if more than `max_gap_minutes` minutes passed between two events that are neighbours in time, a new session starts (exactly `max_gap_minutes` stays in the same session). The length of a session is the time from its first to its last event in seconds; a session of one event has length 0. Return the session lengths in seconds in chronological order of the sessions. For an empty log return an empty list. All events are within one day, midnight is never crossed.

Example: `["09:00:00", "09:10:00", "09:50:00", "09:55:30"]`, `30` → `[600, 330]`.
