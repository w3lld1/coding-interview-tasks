# Booking Up For Beauty

**Difficulty:** medium · **Language:** Java · **Topics:** [Dates and time](../dates/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-29?utm_source=github&utm_medium=tasks-repo)**

Create a scheduler that parses a string with a month, day, year and time into a LocalDateTime, for example in the format M/d/yyyy HH:mm:ss. Implement checks that an appointment has already passed relative to the current time and that it falls in the interval from 12:00 inclusive to 18:00 exclusive. Build a description in English using the template "You have an appointment on <weekday>, <month> <day>, <year>, at <hour>:<minutes> <AM/PM>.". Separately, return the date of the salon's opening anniversary: September 15 of the current year.
