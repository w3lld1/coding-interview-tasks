# "In N days" label

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-615?utm_source=github&utm_medium=tasks-repo)**

You get today's date `today` and an event date `event` in the format `"YYYY-MM-DD"` (existing dates, Gregorian calendar). Let `n` be the number of calendar days from `today` to `event` (negative if the event is in the past). Return the label:
- `n = 0` → `"today"`;
- `n = 1` → `"tomorrow"`;
- `n = -1` → `"yesterday"`;
- `n >= 2` → `"in n days"`;
- `n <= -2` → `"k days ago"`, where `k = -n`.

Example: `"2024-03-10"`, `"2024-03-15"` → `"in 5 days"`.
