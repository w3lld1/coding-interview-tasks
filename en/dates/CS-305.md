# Dates of a repeating event

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-305?utm_source=github&utm_medium=tasks-repo)**

An event first happened on day `start` and then repeats every `every_days` days (`every_days` ≥ 1), forever. Return all event dates that fall between `from_date` and `to_date` inclusive, in ascending order, as `"YYYY-MM-DD"` strings. All dates use the `"YYYY-MM-DD"` format and the Gregorian calendar. `from_date` is not later than `to_date`; the range has at most 4000 days. If the range has no events, return an empty list. Dates before `start` are not part of the answer.

Example: `"2024-01-01"`, `7`, `"2024-01-10"`, `"2024-01-31"` → `["2024-01-15", "2024-01-22", "2024-01-29"]`.
