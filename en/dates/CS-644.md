# Exclusive time of nested kitchen tasks

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dates and time](../dates/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-644?utm_source=github&utm_medium=tasks-repo)**

A cook keeps a log `log` for one day — strings `"HH:MM:SS start NAME"` and `"HH:MM:SS end NAME"` in chronological order (time never decreases). Tasks nest: if a new task starts while another one runs, the outer one pauses, and when the inner one ends, the outer one resumes. Each `end` closes the most recently started task that is still open and carries its name; the log is valid and every task is closed by the end. A task name may run several times, including nested inside itself.

A task's exclusive time is how many seconds it was the innermost running task (`end` at moment `t` means it ran until `t`, exclusive). Return a map name → total exclusive time in seconds over all its runs; it contains every name seen, even with time `0`. An empty log gives an empty map.

Example: `["18:00:00 start soup", "18:05:00 start onions", "18:12:30 end onions", "18:20:00 end soup"]` → `{"soup": 750, "onions": 450}`.
