# Jigsaw puzzle details

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-18?utm_source=github&utm_medium=tasks-repo)**

Some details of a jigsaw puzzle are known, others are not. A puzzle is a rectangle of `rows` rows with `columns` pieces each, at most 2000 pieces in total. A piece on the edge is a border piece (`border`), the others are inside pieces (`inside`); a puzzle with one or two rows (or columns) has no inside pieces. The format (`shape`) is `"portrait"` when there are fewer columns than rows, `"square"` when they are equal and `"landscape"` when there are more. `aspect_ratio` is the number of columns divided by the number of rows.

You get seven values: `pieces` (total), `border`, `inside`, `rows`, `columns`, `aspect_ratio` and `shape`. An unknown integer is `-1`, an unknown `aspect_ratio` is `-1`, an unknown `shape` is an empty string. You look for a puzzle in which every known value equals the real one; compare the aspect ratio with a tolerance of `1e-9`.

If exactly one puzzle agrees with all known values, return the list `[pieces, border, inside, rows, columns]`. If there is none (the data contradict) or more than one (not enough data), report an error: throw an exception, or return an error in Go.

Example: `-1, -1, -1, 32, -1, -1, "square"` → `[1024, 124, 900, 32, 32]`.
