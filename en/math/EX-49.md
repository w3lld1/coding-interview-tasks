# D&D character stats

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-49?utm_source=github&utm_medium=tasks-repo)**

A tabletop game character gets its abilities from rolls of four six-sided dice. The function gets an operation `operation` and a list of integers `values`.

- `"ability"`: `values` holds the four dice. The ability score is the sum of the three largest dice (the smallest is dropped; on a tie any one of the smallest is dropped). Return that score.
- `"modifier"`: `values` holds one element, an ability score. The modifier is `(score − 10) / 2` rounded down (towards minus infinity): for 3 it is `-4`, for 9 it is `-1`.
- `"hitpoints"`: `values` holds one element, the constitution score. Return `10 +` its modifier.

Example: `"ability"`, `[5, 3, 1, 6]` → `14`; `"hitpoints"`, `[3]` → `6`.
