# Prime Factors

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-28?utm_source=github&utm_medium=tasks-repo)**

Factor a positive integer into primes and return them as a list in ascending order. Repeat each factor as many times as it occurs in the factorization, so that the product of the list gives the original number. For 1, return an empty list.
