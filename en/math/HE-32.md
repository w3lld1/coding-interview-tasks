# Root of a polynomial

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-32?utm_source=github&utm_medium=tasks-repo)**

Given the coefficients of a polynomial `c[0] + c[1]·x + c[2]·x² + … + c[n]·xⁿ`. The number of coefficients is even (the degree is odd), the leading coefficient is not zero, and the polynomial has exactly one real root. Return that root; the answer is accepted within 1e-6.

Example: `[1, 2]` → `-0.5` (the polynomial `1 + 2x`).
