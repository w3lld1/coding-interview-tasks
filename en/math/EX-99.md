# Age on other planets

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Hash maps and sets](../hashing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-99?utm_source=github&utm_medium=tasks-repo)**

Given a planet name and an age in seconds, return the age on that planet in its own years, rounded to two decimal places.

One Earth year is 31,557,600 seconds (365.25 days). Orbital periods in Earth years: `"Mercury"` 0.2408467, `"Venus"` 0.61519726, `"Earth"` 1.0, `"Mars"` 1.8808158, `"Jupiter"` 11.862615, `"Saturn"` 29.447498, `"Uranus"` 84.016846, `"Neptune"` 164.79132. Names are written exactly like this, capitalised.

If the planet is not in the list, report an error: throw an exception, or return an error in Go.

Example: `"Earth"`, `1000000000` → `31.69`.
