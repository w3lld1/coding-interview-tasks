# Variable-length quantity (VLQ)

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-107?utm_source=github&utm_medium=tasks-repo)**

Implement VLQ (variable-length quantity) encoding and decoding. You get a `mode` (`"encode"` or `"decode"`) and a list of numbers. Numbers are non-negative and fit into 32 unsigned bits (up to 4294967295).

For `"encode"` each number becomes a sequence of bytes (values 0-255): the number is split into groups of 7 bits, from the highest group to the lowest; every byte except the last has its high bit (value 128) set, the last one has it clear. The number 0 is the single byte `0`. The result is the bytes of all numbers concatenated in order. For `"decode"` the list of bytes is parsed back into a list of numbers.

When decoding, report an error: throw an exception, or return an error in Go, if the list ends with a byte whose high bit is set (the sequence is incomplete).

Example: `"encode"`, `[128, 0]` → `[129, 0, 0]`; `"decode"`, `[192, 0]` → `[8192]`.
