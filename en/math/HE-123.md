# Odd terms of a Collatz sequence

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-123?utm_source=github&utm_medium=tasks-repo)**

A Collatz sequence is built like this: start with a positive integer `n`; if the current number is even, the next one is half of it, if it is odd, the next one is three times it plus 1. The sequence ends when it reaches 1 (which is part of it). For `n = 1` the sequence is just the number 1.

Return all odd numbers of this sequence in increasing order. Each value appears once.

Example: `5` → `[1, 5]` (the sequence is 5, 16, 8, 4, 2, 1).
