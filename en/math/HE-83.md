# Numbers starting or ending with 1

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-83?utm_source=github&utm_medium=tasks-repo)**

Given an integer `n` from 1 to 15, return how many `n`-digit positive integers start with the digit `1` or end with the digit `1` (or both). Numbers have no leading zeros. The result fits in 53 bits, so it is exact in every language.

Example: `2` → `18` (the ten numbers `10`–`19` plus eight more that end in 1: `21`, `31`, …, `91`; `11` is counted once).
