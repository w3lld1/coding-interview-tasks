# Raindrop sounds

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-82?utm_source=github&utm_medium=tasks-repo)**

Convert a number into raindrop sounds. If the number is divisible by 3, add `Pling` to the result; by 5, add `Plang`; by 7, add `Plong`. The sounds go in this order and are joined without separators. If the number is divisible by none of 3, 5 and 7, return the number itself as a string.

Example: `28` → `"Plong"`, `30` → `"PlingPlang"`, `34` → `"34"`.
