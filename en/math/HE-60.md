# Sum from 1 to n

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-60?utm_source=github&utm_medium=tasks-repo)**

Given an integer `n >= 0`, return the sum of all integers from 1 to `n` inclusive. For `n = 0` the sum is 0. The result fits in a 32-bit integer.

Example: `5` → `15` (1 + 2 + 3 + 4 + 5).
