# Sum of multiples of a set

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-104?utm_source=github&utm_medium=tasks-repo)**

Given a list of base values `factors` and a number `limit`, find all positive numbers strictly less than `limit` that are a multiple of at least one positive value of the list, and return their sum. Each number counts once, even if it is a multiple of several values.

The value `0` adds nothing (its only multiple is 0, which does not change the sum). An empty list gives `0`.

Example: `[3, 5]`, `20` → `78` (3 + 5 + 6 + 9 + 10 + 12 + 15 + 18).
