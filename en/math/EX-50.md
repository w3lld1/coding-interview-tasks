# Eggs in the incubator

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-50?utm_source=github&utm_medium=tasks-repo)**

A number describes the occupied slots of an incubator: every 1 bit in its binary form is one egg. Given a non-negative integer, return the number of 1 bits in its binary representation. Do not use the standard bit-count functions; count them yourself. For `0` the answer is `0`.

Example: `89` → `4` (binary `1011001`).
