# The k-th of 1..n in dictionary order

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Trees and graphs](../trees-graphs/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-200?utm_source=github&utm_medium=tasks-repo)**

You are given integers `n` and `k` with `1 ≤ k ≤ n ≤ 2,147,483,647`. Write the numbers from 1 to `n` and order them as strings in dictionary (lexicographic) order: digits are compared from left to right, and a number that is a prefix of another comes before it (`1`, `10`, `100`, `11`, `2`, …). Return the number at position `k` of this order (positions start at 1). Writing out and sorting all the numbers will not work: `n` can exceed a billion.

Example: `15`, `4` → `12` (the order starts `1`, `10`, `11`, `12`, `13`).
