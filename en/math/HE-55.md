# Fibonacci number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-55?utm_source=github&utm_medium=tasks-repo)**

Return the `n`-th Fibonacci number, where `n >= 0`. The sequence starts with F(0) = 0, F(1) = 1, and every next number is the sum of the previous two. In the tests `n` is at most 40.

Example: `10` → `55`.
