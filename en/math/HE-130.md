# Odd Tribonacci sequence

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-130?utm_source=github&utm_medium=tasks-repo)**

A sequence `t` is defined as follows: `t(0) = 1`, `t(1) = 3`; for even `i ≥ 2`, `t(i) = 1 + i / 2` (an integer); for odd `i ≥ 3`, `t(i) = t(i - 1) + t(i - 2) + t(i + 1)`. All values are integers. For odd `i` the term `t(i + 1)` uses the formula for an even index, so the definition has no cycle.

Given an integer `n ≥ 0`, return the list of the first `n + 1` terms, that is `t(0)`, …, `t(n)`.

Example: `3` → `[1, 3, 2, 8]` (t(2) = 2, t(3) = 2 + 3 + t(4) = 2 + 3 + 3 = 8).
