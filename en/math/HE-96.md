# Primes below n

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-96?utm_source=github&utm_medium=tasks-repo)**

Given a non-negative integer `n`, return the list of all prime numbers strictly less than `n`, in ascending order. For `n` equal to `0`, `1` or `2` the list is empty.

Example: `11` → `[2, 3, 5, 7]` (`11` itself is not included). Example: `20` → `[2, 3, 5, 7, 11, 13, 17, 19]`.
