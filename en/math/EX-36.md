# Allergies from a score

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-36?utm_source=github&utm_medium=tasks-repo)**

An allergy test result is stored as one number. Each allergen has its own power of two: `eggs` (1), `peanuts` (2), `shellfish` (4), `strawberries` (8), `tomatoes` (16), `chocolate` (32), `pollen` (64), `cats` (128). The score is the sum of the values of all the person's allergens: a score of 34 means peanuts and chocolate. The values 256, 512 and above are not allergens of the list and must be ignored.

You get a score `score` and a string `item`. If `item` is empty, return the list of all the person's allergens in the order given above. Otherwise return a list with the single element `item` if the person is allergic to it, and an empty list if not.

Example: `257`, `""` → `["eggs"]`; `5`, `"peanuts"` → `[]`.
