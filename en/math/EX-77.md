# Perfect, abundant or deficient number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-77?utm_source=github&utm_medium=tasks-repo)**

The aliquot sum of a number is the sum of all its positive divisors except the number itself (for 15 it is `1 + 3 + 5 = 9`). If the number equals this sum, return `"perfect"`; if the number is less than the sum, return `"abundant"`; if it is greater, return `"deficient"`. For 1 the sum is 0, so 1 is deficient. If the number is less than 1, report an error: throw an exception, or return an error in Go. Numbers go up to tens of millions, so trying every value up to the number itself is too slow.

Example: `28` → `"perfect"` (1 + 2 + 4 + 7 + 14 = 28).
