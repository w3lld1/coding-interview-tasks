# Polynomial derivative

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-62?utm_source=github&utm_medium=tasks-repo)**

The list `xs` holds the coefficients of a polynomial: `xs[0] + xs[1]·x + xs[2]·x² + …`. Return the coefficients of its derivative in the same form. A constant (a list of one number) and an empty list both give an empty list.

Example: `[3, 1, 2, 4, 5]` → `[1, 4, 12, 20]`.
