# Parity bits in transmission

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-12?utm_source=github&utm_medium=tasks-repo)**

A message is a list of bytes (numbers 0 to 255). The transmitter sends exactly 8 bits at a time: 7 data bits and, as the rightmost (lowest) bit, a parity bit chosen so that the transmitted byte has an even number of 1 bits.

The function takes `mode` and `message`. For `mode = "encode"`, join all bits of the message in order (each byte is 8 bits, highest first), cut the stream into groups of 7 bits (pad the last short group on the right with zeros), append a parity bit to each group on the right and return the resulting bytes. An empty message gives an empty list.

For `mode = "decode"`, check that every byte has an even number of 1 bits, otherwise report an error: throw an exception, or return an error in Go. Then drop the lowest bit of each byte, join the remaining 7-bit groups in order, cut the stream into 8-bit bytes and return them; an incomplete tail at the end (the zero padding) is dropped.

Example: `"encode"`, `[2]` → `[3, 0]` (bit groups `0000001` and `0` + zeros, parities 1 and 0); `"decode"`, `[3, 0]` → `[2]`.
