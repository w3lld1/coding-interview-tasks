# Power of two modulo p

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-49?utm_source=github&utm_medium=tasks-repo)**

Given a non-negative integer `n` and a positive integer `p`, return the remainder of dividing `2` to the power `n` by `p`. The value `2^n` can be huge, so do not compute it in full. For `n = 0` the result is `1 % p`, that is `0` when `p = 1`.

Example: `3`, `5` → `3` (8 leaves remainder 3 when divided by 5).
