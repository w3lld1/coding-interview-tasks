# Collatz steps to one

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-43?utm_source=github&utm_medium=tasks-repo)**

You get an integer `number`. Count how many steps it takes to reach 1 by the rules of the Collatz conjecture: if the number is even, divide it by 2; if it is odd, multiply it by 3 and add 1. Repeat until you get 1. For `1` the answer is `0`. Intermediate values can exceed 32 bits, so the argument is a 64-bit integer.

If `number` is less than 1 (zero or negative), report an error: throw an exception, or return an error in Go.

Example: `12` → `9` (12, 6, 3, 10, 5, 16, 8, 4, 2, 1).
