# Broken calculator

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-93?utm_source=github&utm_medium=tasks-repo)**

A calculator has only some digit keys working, plus the «×» and «=» keys. The list `working` of 10 items tells which digits work: `working[d] = 1` means key `d` works, `0` means it is broken. To get the number `x` (`1 ≤ x ≤ 10⁶`) you type an expression `a₁ × a₂ × … × aₘ =` (`m ≥ 1`) where each `aᵢ` uses only working digits and the product equals `x`. Every digit, every «×» and the final «=» is one click. Return the fewest clicks, or `-1` if `x` cannot be obtained.

Example: keys `1`, `2`, `5` work, `x = 60` → `5` (`12×5=`).
