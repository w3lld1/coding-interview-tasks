# Prime string length

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-82?utm_source=github&utm_medium=tasks-repo)**

Given a string, return `true` if its length is a prime number, otherwise `false`. A prime is a natural number greater than 1 that is divisible only by 1 and itself. Lengths `0` and `1` are not prime, so an empty string and a one-character string give `false`.

Example: `"Hello"` → `true` (length 5), `"orange"` → `false` (length 6).
