# Grains on a chessboard

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-56?utm_source=github&utm_medium=tasks-repo)**

A chessboard has 64 squares. Square 1 holds one grain, square 2 holds two, square 3 holds four, and so on, doubling on each following square. Given a square number, return the number of grains on it as a string of decimal digits (the last square does not fit into a signed 64-bit integer). If the number is below 1 or above 64, report an error: throw an exception, or return an error in Go.

Example: `4` → `"8"`.
