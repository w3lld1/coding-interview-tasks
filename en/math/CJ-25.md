# Rational number tree

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-25?utm_source=github&utm_medium=tasks-repo)**

An infinite complete binary tree is built as follows: the root is `1/1`, and a node `p/q` has the left child `p/(p+q)` and the right child `(p+q)/q`. A level-order traversal from left to right gives the sequence `1/1, 1/2, 2/1, 1/3, 3/2, 2/3, 3/1, …`; every positive rational number appears in it exactly once. Positions start at 1.

The function receives `kind`, `a` and `b`:
- for `kind = 1`, return `[p, q]`, the numerator and denominator of the element at position `a` (`1 ≤ a < 2^53`); `b` is 0;
- for `kind = 2`, return `[n]`, the position of the fraction `a/b`, where `a` and `b` are coprime and the position is below `2^53`.

Example: `1`, `5`, `0` → `[3, 2]`; `2`, `3`, `2` → `[5]`.
