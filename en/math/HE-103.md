# Rounded average in binary

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-103?utm_source=github&utm_medium=tasks-repo)**

You get two positive integers `n` and `m`. Compute the arithmetic mean of all integers from `n` to `m` inclusive, round it to the nearest integer, and return it in binary with the string prefix `0b` (for example `0b101`). If the mean is exactly halfway between two integers (fractional part `.5`), round to the nearest even integer. If `n` is greater than `m`, return the string `"-1"`.

Example: `1`, `5` → `"0b11"` (the mean is 3). Example: `996`, `997` → `"0b1111100100"` (the mean 996.5 rounds to 996).
