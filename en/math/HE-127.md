# Prime length of interval overlap

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-127?utm_source=github&utm_medium=tasks-repo)**

Given two closed intervals, each a list of two integers `[start, end]` with start not greater than end. Their intersection is the common part; its length is end minus start (the interval `[2, 3]` has length 1). If the intervals do not intersect, the answer is `"NO"`. If the length of the intersection is a prime number, return `"YES"`, otherwise `"NO"`. An intersection of a single point has length 0 and is not prime.

Example: `[-3, -1]`, `[-5, 5]` → `"YES"` (the intersection `[-3, -1]` has length 2).
