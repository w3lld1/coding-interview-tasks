# Queens attacking each other

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Errors and exceptions](../errors/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-81?utm_source=github&utm_medium=tasks-repo)**

Two queens stand on different squares of an 8×8 chessboard; rows and columns are numbered from 0, so they run from 0 to 7. A queen attacks any piece on her row, column or diagonal. Return `true` if the queens attack each other, otherwise `false`.

If the row or the column of either queen is outside 0 to 7, report an error: throw an exception, or return an error in Go.

Example: `2`, `4`, `2`, `6` → `true` (same row); `2`, `4`, `6`, `6` → `false`.
