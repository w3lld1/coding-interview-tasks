# Pick by primality

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-150?utm_source=github&utm_medium=tasks-repo)**

Given three integers `n`, `x` and `y`, where `n ≥ 1`, return `x` if `n` is a prime number and `y` otherwise. The number 1 is not prime.

Example: `7`, `34`, `12` → `34`; `15`, `8`, `5` → `5`.
