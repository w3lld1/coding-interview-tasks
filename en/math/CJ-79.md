# New elements: weights from an order

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-79?utm_source=github&utm_medium=tasks-repo)**

The atomic weights of two new elements are unknown integers `wc ≥ 1` and `wj ≥ 1`. You are given a list of molecules (2 to 10), each a pair `[c, j]`: `c` atoms of the first element and `j` of the second (`1 ≤ c, j ≤ 10^6`, all pairs distinct). A molecule weighs `c·wc + j·wj`. The molecules are known to be listed in strictly increasing order of weight.

Find weights consistent with this order: return `[wc, wj]` with the smallest `wc`, and among those the smallest `wj`. If no such weights exist, return an empty list.

Example: `[[1, 1], [1, 2], [2, 1]]` → `[2, 1]`.
