# Binary digit sum

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-84?utm_source=github&utm_medium=tasks-repo)**

Given an integer `n` from 0 to 10000, compute the sum of its decimal digits and return that sum written in binary as a string with no leading zeros. For a sum of 0 return `"0"`.

Example: `150` → `"110"` (the digit sum is 1 + 5 + 0 = 6, and 6 in binary is `110`).
