# Pile of stones

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-100?utm_source=github&utm_medium=tasks-repo)**

Given a positive integer `n`, build a pile of `n` levels. The first level holds `n` stones and every next level holds two more than the previous one (so the parity of the count never changes). Return the number of stones on each level as a list, starting from the first level.

Example: `3` → `[3, 5, 7]`. Example: `4` → `[4, 6, 8, 10]`.
