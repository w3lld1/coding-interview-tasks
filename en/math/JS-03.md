# Lucky Numbers

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Math](../math/), [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-03?utm_source=github&utm_medium=tasks-repo)**

Implement twoSum, which converts two non-empty arrays of decimal digits into numbers and returns their sum, and luckyNumber, which checks whether a positive integer is a palindrome. Add errorMessage for an input field value: for null, undefined or an empty string, return 'Required field'. If a non-empty input does not produce a non-zero number under JavaScript's numeric conversion rules, return 'Must be a number besides 0'; otherwise, return an empty string.
