# Rational number arithmetic

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-83?utm_source=github&utm_medium=tasks-repo)**

A rational number is a list of two integers `[numerator, denominator]`; the denominator is never zero (it may be negative). Perform the operation `operation` and return the result in the same form, **always reduced to lowest terms with a positive denominator** (zero is written `[0, 1]`).

Operations:
- `"add"`, `"sub"`, `"mul"`, `"div"` — the sum, difference, product and quotient of `first` and `second` (for division the numerator of `second` is not zero);
- `"abs"` — the absolute value of `first` (`second` is empty);
- `"reduce"` — only reduce `first` (`second` is empty);
- `"pow"` — `first` raised to an integer power `n`, where `second = [n]`. For a negative `n` the result is `(denominator^|n|) / (numerator^|n|)` (the numerator of `first` is not zero then), and any number to the power 0 is `[1, 1]`.

Example: `"add"`, `[1, 2]`, `[2, 3]` → `[7, 6]`; `"reduce"`, `[3, -4]`, `[]` → `[-3, 4]`.
