# All Your Base

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-14?utm_source=github&utm_medium=tasks-repo)**

Given an input base, a list of digits from most to least significant, and an output base, return the representation of the same non-negative number in the output base. Both bases must be at least 2, and each input digit must be in the range from 0 to the input base minus one; on a violation, report an error: throw an exception, or return an error in Go. Do not keep leading zeros, and convert empty input and any representation of zero to [0]. Perform the conversion yourself, without built-in base converters.
