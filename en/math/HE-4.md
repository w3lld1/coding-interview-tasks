# Mean absolute deviation

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-4?utm_source=github&utm_medium=tasks-repo)**

Given a non-empty list of numbers, compute their arithmetic mean, then the average of the absolute differences between each number and that mean. Return this value. For a single number or all-equal numbers the result is `0`.

Example: `[1.0, 2.0, 3.0, 4.0]` → `1.0` (mean `2.5`, deviations `1.5, 0.5, 0.5, 1.5`).
