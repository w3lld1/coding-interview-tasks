# Square root without a library

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-101?utm_source=github&utm_medium=tasks-repo)**

Given a positive integer that is a perfect square, return its square root as an integer. Avoid the built-in square-root and fractional-power functions: find the root yourself (by scanning, binary search or Newton's method).

The number is guaranteed to be a perfect square, and the answer fits into a 32-bit integer.

Example: `81` → `9`.
