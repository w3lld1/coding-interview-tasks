# Pythagorean triplets with a given sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-23?utm_source=github&utm_medium=tasks-repo)**

A Pythagorean triplet is three natural numbers `a < b < c` with `a² + b² = c²`. Given a number `n`, return all triplets `[a, b, c]` with `a + b + c = n`. Order the triplets by ascending `a`; if there are none, return an empty list.

For `n` around 30000, trying every pair `a`, `b` is too slow, so aim for something faster than O(n²).

Example: `12` → `[[3, 4, 5]]`.
