# Round a numeric string away from zero

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-99?utm_source=github&utm_medium=tasks-repo)**

Given a string with the decimal notation of a number: an optional `-` sign and an optional fractional part, such as `"15.3"` or `"-7"`. The integer part is always written: a form like `".5"` does not occur. Return the integer closest to that number. If the number is exactly halfway between two integers, return the one farther from zero.

Examples: `"15.3"` → `15`, `"14.5"` → `15`, `"-14.5"` → `-15`.
