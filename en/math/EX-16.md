# Palindrome products

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Searching and sorting](../search-sort/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-16?utm_source=github&utm_medium=tasks-repo)**

A palindrome is a number that reads the same forwards and backwards (`121`, but not `112`). You get non-negative integers `min_factor` and `max_factor` and a flag `largest`. Consider all products `a * b` where `min_factor <= a <= b <= max_factor` and the product is a palindrome.

If `largest` is `true`, take the greatest such product, otherwise the smallest. Return all pairs of factors `[a, b]` (with `a <= b`) that give exactly this product, in any order. If there is no palindrome product, return an empty list.

If `min_factor` is greater than `max_factor`, report an error: throw an exception, or return an error in Go.

Checking every pair on large ranges (up to four-digit numbers) is too slow, so search with pruning.

Example: `1`, `9`, `true` → `[[1, 9], [3, 3]]` (the largest palindrome is 9).
