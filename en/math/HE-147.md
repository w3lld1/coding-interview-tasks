# Triples divisible by three

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-147?utm_source=github&utm_medium=tasks-repo)**

Given a positive integer `n`, consider the array `a` of length `n` where `a[i] = i·i − i + 1` for `i` from 1 to `n` (indexing from 1). Return the number of triples `(a[i], a[j], a[k])` with indexes `i < j < k` whose sum is divisible by 3. If there are fewer than three elements, the answer is `0`.

Example: `5` → `1` (the array is `[1, 3, 7, 13, 21]`; only the triple `1, 7, 13` works).
