# Factorial or sum by position

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-106?utm_source=github&utm_medium=tasks-repo)**

You get an integer `n` from 0 to 12. Return a list of `n` elements: for position `i` (counting from 1) the element is the factorial of `i` (`1 · 2 · … · i`) when `i` is even, and the sum of the numbers from 1 to `i` when `i` is odd. For `n = 0`, return an empty list.

Example: `5` → `[1, 2, 6, 24, 15]`.
