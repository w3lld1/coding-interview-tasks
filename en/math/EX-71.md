# The nth prime number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-71?utm_source=github&utm_medium=tasks-repo)**

You get a position `number`. Return the prime at that position, counting from 1: the first prime is 2, the second is 3, the sixth is 13. If `number` is less than 1, report an error: throw an exception, or return an error in Go. The position is at most 10001. Do not use library functions for primes.

Example: `6` → `13`.
