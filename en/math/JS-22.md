# Captain's Log

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-22?utm_source=github&utm_medium=tasks-repo)**

Create a generator of ship registry numbers in the format NCC-number, where the integer is in the range from 1000 to 9999 inclusive. The second generator must return a random fractional stardate from 41000 inclusive to 42000 exclusive. The third randomly picks one of the planet classes: D, H, J, K, L, M, N, R, T, Y.
