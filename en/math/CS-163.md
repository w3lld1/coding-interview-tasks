# Fraction as a decimal string

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Strings](../strings/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-163?utm_source=github&utm_medium=tasks-repo)**

Given integers `numerator` and `denominator` (the denominator is not 0), return the value of `numerator / denominator` in decimal notation as a string. If the decimal is infinite, put the repeating part in parentheses, starting at the first digit from which the period repeats. A whole result has no point. A minus sign appears only when the result is negative; zero is written as `"0"`. Intermediate values can leave the 32-bit range.

Example: `1`, `6` → `"0.1(6)"`; `2`, `1` → `"2"`; `-50`, `8` → `"-6.25"`.
