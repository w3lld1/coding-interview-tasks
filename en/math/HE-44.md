# Convert a number to another base

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Math](../math/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-44?utm_source=github&utm_medium=tasks-repo)**

Given a positive integer `x` and a `base` from 2 to 9, return a string with the representation of `x` in that base, without leading zeros. All digits are below 10, so no letters are needed.

Example: `8`, `3` → `"22"`.
