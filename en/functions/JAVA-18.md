# List Ops

**Difficulty:** medium · **Language:** Java · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-18?utm_source=github&utm_medium=tasks-repo)**

Implement the list operations append, concat, filter, size, map, foldLeft, foldRight and reverse yourself. Concatenation must preserve the order of elements, filter must keep the elements that satisfy the predicate, and map must apply the given function to each element. The left and right folds take an initial accumulator and differ in traversal direction; do not substitute ready-made library equivalents of these operations.
