# Tiny query engine over a table

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-669?utm_source=github&utm_medium=tasks-repo)**

You get a table: column names `columns` and rows `rows` (lists of integers of the same length). A query `query` is a list of steps that transform the table (and its set of columns) in turn; return the rows of the final table. Steps (words separated by spaces):
- `where C OP V`: keep rows where the value of column `C` compared with the integer `V` by `OP` (`<`, `<=`, `>`, `>=`, `==`, `!=`) is true;
- `select C1 C2 …`: keep only these columns, in this order;
- `derive N F A B`: append a column `N` with the value `F(A, B)`, where `F` is `add`, `sub` (A − B), `mul`, `max` or `min`, and `A` and `B` are column names or integers;
- `group K1,K2,… AGG:C …`: group rows by the values of the key columns (comma-separated) and produce one row per group: the key values, then the aggregate values in the given order. Aggregates: `sum`, `count` (rows in the group), `min`, `max`, `avg` (the sum divided by the count, rounded down). The new columns are the keys, then `AGG_C` (e.g. `sum_qty`). Groups come in the order of their first row;
- `order C1 DIR1 C2 DIR2 …`: a stable sort by the columns, `DIR` is `asc` or `desc`; rows equal on all keys keep their order;
- `limit N`: keep the first `N` rows;
- `distinct`: drop repeated rows, keeping the first occurrence.

The query is valid: all names exist and column names are distinct. Up to 100 rows, up to 10 steps, all values fit in a 32-bit integer.

Example: `["a", "b"]`, `[[1, 5], [2, 7], [1, 4]]`, `["group a sum:b", "order sum_b asc"]` → `[[2, 7], [1, 9]]`.
