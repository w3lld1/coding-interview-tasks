# Bind the first argument

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-350?utm_source=github&utm_medium=tasks-repo)**

You get the name of a two-argument function `name`, a number `fixed` and a list of numbers `rest`. Bind `fixed` as the first argument of the function and apply the resulting one-argument function to each number `x` in `rest`: the result for `x` is `f(fixed, x)`. Return the list of results in the order of `rest`.

Functions `f(a, b)`:
- `"sub"`: `a - b`.
- `"div"`: the integer part of `a / b`.
- `"pow"`: `a` to the power `b` (`0` to the power `0` is `1`).
- `"mod"`: the remainder of `a` divided by `b`.

Guarantees: `fixed >= 0`; for `"div"` and `"mod"` all `x >= 1`; for `"pow"` `fixed <= 9` and `0 <= x <= 8`; for `"sub"` any `x`.

Example: `"div"`, `100`, `[1, 3, 7]` → `[100, 33, 14]`.
