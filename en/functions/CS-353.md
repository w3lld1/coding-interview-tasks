# Calculator with an accumulator

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-353?utm_source=github&utm_medium=tasks-repo)**

Implement a calculator with one number, the accumulator, which starts at `0`. You get a list of commands `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Run the commands in order and return the list of accumulator values after each command.

Commands (`acc` is the accumulator):
- `"set"` with argument `n`: `acc = n`.
- `"add"` with argument `n`: `acc = acc + n`.
- `"sub"` with argument `n`: `acc = acc - n`.
- `"mul"` with argument `n`: `acc = acc * n`.
- `"max"` with argument `n`: `acc` becomes the larger of `acc` and `n`.
- `"min"` with argument `n`: `acc` becomes the smaller of `acc` and `n`.
- `"neg"` with no arguments: change the sign of `acc`.
- `"square"` with no arguments: square `acc`.

Values fit in a 32-bit integer.

Example: `["add", "mul", "neg", "max"]`, `[[5], [3], [], [10]]` → `[5, 15, -15, 10]`.
