# Select and transform by name

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-354?utm_source=github&utm_medium=tasks-repo)**

You get a condition name `predicate`, a transform name `transform` and a list of integers `numbers`. Keep only the numbers that satisfy the condition, apply the transform to each of them and return the results in the original order.

Conditions (for a number `n`): `"even"` (even, 0 is even), `"odd"` (odd, negative numbers included), `"positive"` (`n > 0`), `"negative"` (`n < 0`), `"multiple_of_5"` (divisible by 5, 0 is).

Transforms: `"double"` (`n * 2`), `"square"` (`n * n`), `"negate"` (`-n`), `"inc"` (`n + 1`), `"abs"` (absolute value).

Example: `"even"`, `"square"`, `[1, 2, 3, 4]` → `[4, 16]`.
