# Memoising binomial coefficients

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Dynamic programming](../dp/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-359?utm_source=github&utm_medium=tasks-repo)**

The binomial coefficient is computed by Pascal's recursion: `c(n, k) = 1` if `k = 0` or `k = n`, otherwise `c(n, k) = c(n - 1, k - 1) + c(n - 1, k)`.

The function is memoised on the pair `(n, k)` with one shared cache, empty at the start and shared by all calls. An "evaluation" is a run of the function body on a cache miss (the base cases `k = 0` and `k = n` included); a cache hit is not an evaluation.

You get a list of queries `calls`, each a pair `[n, k]` with `0 ≤ k ≤ n ≤ 30`. Process them in order and for each return the pair `[c(n, k), number of evaluations in this query]`.

Example: `[[4, 2], [4, 2], [5, 2]]` → `[[6, 8], [6, 0], [10, 3]]`. `c(4, 2)` evaluates eight pairs; the repeated query evaluates nothing; for `c(5, 2)` the new pairs are `(5, 2)`, `(4, 1)` and `(3, 0)`.
