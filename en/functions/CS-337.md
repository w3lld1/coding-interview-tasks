# Pipeline of steps on a number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-337?utm_source=github&utm_medium=tasks-repo)**

You get a list of step names `steps` and an integer `x`. Apply the steps to the number in order, each one to the result of the previous, and return the final value. An empty list of steps leaves the number unchanged.

Steps:
- `"double"`: multiply by 2.
- `"triple"`: multiply by 3.
- `"inc"`: add 1.
- `"dec"`: subtract 1.
- `"square"`: square the number.
- `"negate"`: change the sign.

Other step names do not appear in the tests, and the result fits in a 32-bit integer.

Example: `["double", "inc", "square"]`, `3` → `49` (3 → 6 → 7 → 49).
