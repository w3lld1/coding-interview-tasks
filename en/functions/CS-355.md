# Steps until one

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-355?utm_source=github&utm_medium=tasks-repo)**

You get a step name `name` and an integer `x` from 1 to 100000. Apply the step to `x`, then to the result, and so on, until the value equals `1`. Return the number of times the step was applied. If `x` is already `1`, the answer is `0`.

Steps (on the current value `v`):
- `"half"`: `v / 2` with the fraction dropped.
- `"isqrt"`: the integer part of the square root of `v`.
- `"collatz"`: if `v` is even, `v / 2`, otherwise `3 * v + 1`.
- `"third_ceil"`: `v / 3` rounded up to an integer.

For every test input the value reaches `1`, and the intermediate values fit in a 32-bit integer.

Example: `"isqrt"`, `81` → `3` (81 → 9 → 3 → 1).
