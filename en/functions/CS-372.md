# Fold every window with a named operation

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-372?utm_source=github&utm_medium=tasks-repo)**

Folding a list left to right takes the first element and then combines it with the following ones using the chosen operation: for `[a, b, c]` this is `op(op(a, b), c)`. The operations are named:
- `sum`, `product`, `max`, `min`;
- `gcd` — greatest common divisor (`gcd(0, 0) = 0`), `lcm` — least common multiple (`lcm` with a zero is `0`);
- `xor` — bitwise exclusive OR;
- `diff` — difference, i.e. `a - b - c - …`.

You get a list of operation names `names`, a list `values` (numbers from 0 to 99) and a window size `k` (from 1 to 4). A window is `k` consecutive elements of `values`; there are `len(values) - k + 1` windows (none if `values` is shorter than `k`). For each name in `names` return the list of fold results over all windows from left to right; the answer is the list of these lists in the order of `names`. An empty `names` gives an empty list.

Example: `["sum", "max"]`, `[3, 1, 4, 1, 5]`, `3` → `[[8, 6, 10], [4, 4, 5]]`.
