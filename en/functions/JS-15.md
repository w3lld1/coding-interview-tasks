# Lasagna Master

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-15?utm_source=github&utm_medium=tasks-repo)**

The cookingStatus function returns 'Lasagna is done.' for zero minutes, 'Not done, please wait.' for any other given non-negative number, and 'You forgot to set the timer.' when the argument is missing; preparationTime computes the time from the number of layers, using 2 minutes per layer by default. The quantities function takes an array of layer names and returns a noodles/sauce object, counting 50 grams per noodles layer and 0.2 liters per sauce layer. The addSecretIngredient function adds the last element of a friend's list to your list, does not change the friend's list, and returns undefined. The scaleRecipe function scales the quantities from a two-portion recipe to the required number of portions, returning a new object without changing the original.
