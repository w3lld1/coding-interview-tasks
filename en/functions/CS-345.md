# How many numbers pass all conditions

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-345?utm_source=github&utm_medium=tasks-repo)**

You get a list of condition names `predicates` and a list of integers `numbers`. Return how many numbers satisfy all of the named conditions at once. If the list of conditions is empty, every number qualifies.

Conditions (for a number `n`):
- `"even"`: `n` is even (0 is even too).
- `"positive"`: `n > 0`.
- `"multiple_of_3"`: `n` is divisible by 3 (0 is).
- `"two_digit"`: the absolute value of `n` is from 10 to 99 inclusive.
- `"palindrome"`: the decimal digits of the absolute value of `n` read the same forwards and backwards (every single-digit number qualifies).

Example: `["even", "positive"]`, `[1, 2, 4, -6, 10]` → `3`.
