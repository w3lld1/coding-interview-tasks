# Firewall: the first matching rule

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-364?utm_source=github&utm_medium=tasks-repo)**

A firewall checks packets against a list of rules `rules`. A rule is written as `action protocol ports` (three words separated by spaces):
- the action is `allow` or `deny`;
- the protocol is `tcp`, `udp` or `any` (matches every protocol);
- the ports are `*` (any port) or a comma-separated list without spaces where each item is a number `80` or a range `1000-2000` (both ends included).

A packet is written as `protocol port`, for example `tcp 443`. For each packet in `packets` find the first rule, in order, that matches it (protocol and port) and return its action. If no rule matches, the answer is `deny`.

Return a list of answers, one per packet. Ports are numbers from 0 to 65535.

Example: `["allow tcp 80,443", "deny any *"]`, `["tcp 80", "tcp 22", "udp 443"]` → `["allow", "deny", "deny"]`.
