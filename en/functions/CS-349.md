# A function with a call limit

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-349?utm_source=github&utm_medium=tasks-repo)**

There is a function `f(x) = x * x + 1`. A wrapper lets only the first `limit` calls reach `f`; each such call returns the value of `f`. All later calls do not run `f` and return the result of the last call that did reach `f`. The number `limit` is at least 1.

Call the wrapper for each number of `inputs` in turn and return the list of results.

Example: `2`, `[1, 2, 3, 4]` → `[2, 5, 5, 5]`: `f(1) = 2`, `f(2) = 5`, and the third and fourth calls return the earlier `5`.
