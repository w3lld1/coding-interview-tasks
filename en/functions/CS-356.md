# Tag numbers with the conditions they meet

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-356?utm_source=github&utm_medium=tasks-repo)**

You get a list of condition names `predicates` (the names are distinct) and a list of integers `numbers`. For each number return a string: the names of all conditions the number satisfies, in the order they appear in `predicates`, separated by commas without spaces. If the number meets none of the conditions, the string is empty. The result has one string per number, in the original order.

Conditions (for a number `n`): `"even"` (even, 0 is even), `"odd"` (odd, negative numbers included), `"positive"` (`n > 0`), `"negative"` (`n < 0`), `"multiple_of_5"` (divisible by 5, 0 is), `"big"` (the absolute value of `n` is at least 100).

Example: `["even", "positive"]`, `[4, -2, 3, 0]` → `["even,positive", "even", "positive", "even"]`.
