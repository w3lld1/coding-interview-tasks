# Value and derivative with dual numbers

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-671?utm_source=github&utm_medium=tasks-repo)**

You get function definitions `definitions` of the form `NAME(x) = EXPRESSION` (the parameter is always `x`), an expression `expression` in `x`, and points `points`. For each point `x₀` return `[f(x₀), f′(x₀)]`: the value of the expression and its derivative with respect to `x`.

An expression has non-negative integer literals, the variable `x`, parentheses, binary `+`, `-`, `*` (multiplication binds tighter than addition and subtraction, operators of one level apply left to right), unary minus, a power `A^N` with an integer `N ≥ 0` (tighter than unary minus: `-x^2` means `-(x^2)`; `x^0 = 1`), and calls `NAME(expression)`. Built-in functions: `sq(t) = t²` and `cube(t) = t³`; a function in `definitions` may call the built-ins and the functions defined above it. Spaces are optional.

All values and derivatives are below 10¹⁵ in absolute value and are computed exactly in integers.

Example: `[]`, `"3*x^2 - 2*x + 7"`, `[2]` → `[[15, 10]]`.
