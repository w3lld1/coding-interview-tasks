# Composing partially applied functions

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-362?utm_source=github&utm_medium=tasks-repo)**

The two-argument functions `add`, `sub`, `mul`, `div`, `mod`, `min`, `max` are partially applied: one argument is fixed to a number, the other is still free. A step is written as the string `name@side:k`. With `left` the number `k` is the left operand (`sub@left:10` means `x → 10 - x`), with `right` it is the right one (`sub@right:10` means `x → x - 10`).

The list of steps `steps` defines the composition `f1 ∘ f2 ∘ … ∘ fn`: the last step is applied first, then the one before it, up to the first. An empty list is the identity function.

You get `steps` and a list of numbers `xs`. Return the result of the composition for every number.

Arithmetic rules: `div` is integer division rounding toward zero (`-7 / 2 = -3`); `mod` is the remainder with the sign of the dividend (`-7 mod 2 = -1`), i.e. `a - b · div(a, b)`; when the divisor is `0`, both `div` and `mod` give `0`. Values fit in 32 bits.

Example: `["sub@left:10", "mul@right:3"]`, `[4]` → `[-2]`: first `4 · 3 = 12`, then `10 - 12 = -2`.
