# Spreadsheet with lazy formulas

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Errors and exceptions](../errors/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-374?utm_source=github&utm_medium=tasks-repo)**

A spreadsheet is given by a list of definitions `cells`. A definition is a string `NAME = EXPRESSION` (the separator is exactly ` = `). A cell name starts with a Latin letter (for example `A1`, `Total`), each name is defined at most once. An expression is either a single operand or three words `operand operator operand`, where the operator is `+`, `-` or `*`. An operand is an integer (maybe negative, e.g. `-3`) or a cell name.

A cell's value is computed lazily and once: its operands are computed first (both, always, even when multiplying by `0`) and the result is remembered. Cells that are neither queried nor needed by a queried cell are not evaluated, so they may contain errors.

For a list of names `queries` return the values of those cells. If the evaluation meets a reference to an undefined cell, or a cell depends on itself (directly or through others), report an error: throw an exception, or return an error in Go. The error applies to the whole call; no partial result is returned.

Example: `["A1 = 5", "B1 = A1 + 3", "C1 = B1 * A1"]`, `["C1", "B1"]` → `[40, 8]`.
