# Wrappers that limit calls of a function

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-368?utm_source=github&utm_medium=tasks-repo)**

There is a base function `f(x)`: on every real call it increments its own counter (initially `0`) and returns `x * 10 + counter`. Wrappers are put around it; each wrapper has its own counter of the calls it received (initially `0`) and a "last result" (initially `null`).

A wrapper counts the call (the counter grows before the decision) and then acts by its type:
- `once` — only the first call is passed inward, the others return the last result;
- `before:n` — calls number `1…n-1` are passed inward, from the `n`-th on the last result is returned (for `n = 1` nothing goes inward and the answer is always `null`);
- `after:n` — calls number `1…n-1` return `null` and do not go inward, from the `n`-th on every call is passed inward and its result is returned as is;
- `every:n` — every `n`-th call (`n`, `2n`, …) is passed inward, the others return the last result (`null` at first).

In all cases except `after`, the result that came back from a forwarded call is remembered as the last result (`null` included).

The list `wrappers` names the wrappers from the inner one to the outer one: the first is put around `f`, the second around the result of the first, and so on. Call the outermost function with each number of `args` in turn and return the list of results (a number or `null`). An empty `wrappers` means calls of `f` itself.

Example: `["once"]`, `[1, 2, 3]` → `[11, 11, 11]`: `f` was called once.
