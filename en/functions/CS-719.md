# Scheme interpreter with closures and tail calls

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-719?utm_source=github&utm_medium=tasks-repo)**

You are given a string `source`, a program in a tiny Scheme dialect: several forms in a row. Run them in order and return the value of the last form: an integer in decimal, or `"function"` if it is a function.

Tokens are `(`, `)` and words between spaces and parentheses; a word of an optional `-` and digits is an integer, the others are names. Forms:
- a number; a name is the value of the nearest binding (innermost scopes first, the global one last);
- `(define name e)` and `(define (name p1 … pk) body…)` (a function), only at the top level, create or replace a global name;
- `(lambda (p1 … pk) body…)` is a function that remembers the environment it was created in (lexical scope);
- `(let ((n1 e1) …) body…)`: all `ei` are evaluated in the outer environment, then a new scope holds the `ni`;
- `(if c a b)`: only `0` is false; `(begin e…)`;
- `(set! name e)` changes the nearest existing binding of `name`; every closure that shares this binding sees the change; the form's value is the new value;
- a call `(f a1 … ak)`: `f` is evaluated, then the arguments from left to right; calling a function makes a new scope with its parameters. A body (`body…`) is one or more expressions, its value is the last one's.

The built-in two-argument functions `+`, `-`, `*`, `<`, `=` (comparisons give `1` or `0`) are ordinary values: they can be passed to a function or hidden by your own name. The words `define lambda let if begin set!` are never names.

Tail calls must not grow the stack: in the tests, loops through tail recursion run up to `10^4` steps, and ordinary (non-tail) recursion depth is at most `100`. The program is valid, up to 3000 characters, and all values fit in a 32-bit integer.

Example: `"(define (make-counter) (let ((n 0)) (lambda () (set! n (+ n 1)) n))) (define c (make-counter)) (c) (c)"` → `"2"`.
