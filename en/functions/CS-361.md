# Middleware chain around a handler

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-361?utm_source=github&utm_medium=tasks-repo)**

A request is an integer. It passes through a chain of middleware like an onion: each layer does something on the way in, hands the request to the next layer and then does something to the response on the way out. In the very centre sits a handler that returns the number it gets unchanged.

Layers are written as strings `name:k` (`k` is an integer, maybe negative); the first string is the outermost layer:
- `add:k` — pass `x + k` inward; return the response as is;
- `mul:k` — pass `x * k` inward; return the response as is;
- `wrap:k` — pass `x`, add `k` to the response;
- `scale:k` — pass `x`, multiply the response by `k`;
- `cap:k` — pass `x`, limit the response from above by `k` (the smaller of the response and `k`);
- `limit:k` — if the current `x` is greater than `k`, return `-1` at once without calling the inner layers; otherwise pass `x` inward and return the response as is. The outer layers still process this `-1` on the way out.

You get a list of layers `middlewares` and a list of requests `requests`. Return the response to each request; requests do not affect each other. An empty chain returns the request as is. Values fit in 32 bits.

Example: `["add:1", "limit:10", "wrap:5"]`, `[3, 20]` → `[9, -1]`: for `3` the first layer gives `4`, `limit` lets it pass, the centre returns `4`, `wrap` adds 5; for `20` the first layer gives `21` and `limit` stops the chain.
