# Event handlers with priorities and a stop

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-369?utm_source=github&utm_medium=tasks-repo)**

An event bus keeps, for each event, handlers with priorities. Handlers have names and change a number (the payload): `inc` adds 1, `double` multiplies by 2, `square` squares it, `negate` flips the sign, `stop` leaves the number alone but interrupts the chain.

You get a list of commands `commands`; return one number per command. Words in a command are separated by a single space:
- `on event handler priority` — register a handler (the priority is an integer, maybe negative); the result is the number of handlers of that event after the registration. The same handler may be registered several times;
- `off event handler` — remove all registrations of this handler for this event; the result is the number of handlers left for the event;
- `emit event number` — run the event's handlers by descending priority (equal priorities in registration order): each gets the result of the previous one, the first gets `number`. If `stop` runs, the remaining handlers do not run. The result is the final number (for an event with no handlers, the original one).

Example: `["on save inc 1", "on save double 5", "emit save 3"]` → `[1, 2, 7]`: first `double` (priority 5): 6, then `inc`: 7.
