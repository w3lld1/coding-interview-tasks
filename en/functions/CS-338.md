# Fold a list by operation name

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-338?utm_source=github&utm_medium=tasks-repo)**

You get an operation name `op`, a list of integers `numbers` and a starting value `start`. Put `start` into an accumulator, then for each number in order replace the accumulator with the result of the operation applied to the accumulator and that number. Return the accumulator. For an empty list the answer is `start`.

Operations (on the accumulator `a` and the number `b`):
- `"sum"`: `a + b`.
- `"product"`: `a * b`.
- `"max"`: the larger of the two.
- `"min"`: the smaller of the two.
- `"gcd"`: the greatest common divisor; all numbers and `start` are non-negative then, and `gcd(0, 0)` is `0`.

The result fits in a 32-bit integer.

Example: `"product"`, `[2, 3, 4]`, `1` → `24`.
