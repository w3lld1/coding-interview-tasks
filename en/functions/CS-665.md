# Dial program: the position after trillions of ticks

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Math](../math/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-665?utm_source=github&utm_medium=tasks-repo)**

A code dial has `m` positions `0 … m-1`; it starts at position `start`. On every tick the steps of the program `program` are applied to the position in turn; each step is a string `name` or `name:K`:
- `add:K` → `(x + K) mod m`; `mul:K` → `(x · K) mod m`; `xor:K` → `(x XOR K) mod m` (bitwise exclusive or);
- `square` → `x² mod m`; `rev` → `m − 1 − x`; `half` → `x / 2` rounded down;
- `digitsum` → the sum of the decimal digits of `x`, modulo `m`.
An empty program leaves the position unchanged.

For each `k` in `queries` return the dial position after `k` ticks (after `0` ticks it is `start`). Limits: `1 ≤ m ≤ 20000`, `0 ≤ start < m`, `0 ≤ K ≤ 10000`, up to 10 steps, up to 20 queries, `0 ≤ k ≤ 10¹⁵`.

Example: `12`, `1`, `["mul:5", "add:1"]`, `[0, 1, 2, 3]` → `[1, 6, 7, 0]`.
