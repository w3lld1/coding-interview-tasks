# Group numbers by a rule

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-344?utm_source=github&utm_medium=tasks-repo)**

You get a rule name `rule` and a list of integers `numbers`. The rule gives every number a string key. Return a map in which every key that occurred holds the list of numbers with that key, in their original order. Keys that did not occur are absent; for an empty list the answer is an empty map.

Rules:
- `"parity"`: key `"even"` for an even number and `"odd"` for an odd one (negative numbers included).
- `"sign"`: `"negative"`, `"zero"` or `"positive"`.
- `"last_digit"`: the last digit of the absolute value as a string, for example `"3"`.
- `"digits"`: the number of digits of the absolute value as a string; `0` has one digit.

Example: `"parity"`, `[1, 2, 3, 4, 5]` → `{"odd": [1, 3, 5], "even": [2, 4]}`.
