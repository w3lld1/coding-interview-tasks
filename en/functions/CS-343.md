# Sort words by a chosen key

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-343?utm_source=github&utm_medium=tasks-repo)**

You get a key name `key` and a list of words `words` made of lowercase Latin letters (no word is empty). Return a new list of the same words sorted by the key value in ascending order. Words with an equal key value keep their original order (the sort is stable).

Keys:
- `"length"`: the length of the word.
- `"vowels"`: the number of vowels `a`, `e`, `i`, `o`, `u` in the word.
- `"last_letter"`: the alphabet position of the last letter (`a` = 1, …, `z` = 26).
- `"alphabet_sum"`: the sum of the alphabet positions of all letters of the word.

Example: `"vowels"`, `["sky", "tree", "banana", "go"]` → `["sky", "go", "tree", "banana"]` (0, 1, 2 and 3 vowels).
