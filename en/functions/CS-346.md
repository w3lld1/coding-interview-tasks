# Running results by a rule

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-346?utm_source=github&utm_medium=tasks-repo)**

You get a rule name `op` and a list of integers `numbers`. Return a list of the same length: the first element is `numbers[0]`, and each next one is made from the previous element of the result `r` and the current number `n` by the rule. For an empty list the answer is an empty list.

Rules:
- `"sum"`: `r + n`.
- `"max"`: the larger of `r` and `n`.
- `"min"`: the smaller of `r` and `n`.
- `"diff"`: `r - n`.

Example: `"diff"`, `[10, 3, 2]` → `[10, 7, 5]`.
