# Memoised evaluator of a tiny language

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-663?utm_source=github&utm_medium=tasks-repo)**

A program `program` is a list of function definitions `NAME(P1, P2, …) = EXPRESSION` (one or more parameters). An expression is:
- `if A OP B then X else Y`, where `OP` is `<`, `<=`, `>`, `>=`, `==` or `!=`; only the chosen branch is evaluated; `else` belongs to the nearest `if`, and a branch extends to the end of the expression;
- otherwise arithmetic: `+` and `-` (lower), `*`, `/`, `%` (higher), operators of one level applied left to right; unary minus; parentheses; non-negative integer literals; parameter names; calls `NAME(expr, expr, …)`.
`/` is division rounded down and `%` the remainder; in the tests their operands are non-negative and the divisor is positive. Spaces between items are optional.

Calls to program functions are memoised: the result for the same name with the same arguments is computed once for the whole `evaluate` call and later taken from memory, including in later queries. Each query in `queries` is an expression without parameters. Return for each query `[value, evaluations]`, where "evaluations" is how many times the body of some function was evaluated during that query (memory misses).

Programs are valid, recursion terminates, the call depth is at most 100 and all intermediate values are below 10¹⁵ in absolute value.

Example: `["fib(n) = if n < 2 then n else fib(n - 1) + fib(n - 2)"]`, `["fib(10)", "fib(12)"]` → `[[55, 11], [144, 2]]`.
