# Dispatching events to handlers

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-352?utm_source=github&utm_medium=tasks-repo)**

Implement an event dispatcher. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). At first there are no handlers. Return a list of results, one per operation.

The handlers are called `"double"` (multiplies the number by 2), `"inc"` (adds 1), `"square"` (squares the number) and `"negate"` (changes the sign). The same handler can be subscribed several times; each subscription works on its own.

Operations:
- `"on_<name>"` with no arguments, for example `"on_double"`: add a subscription of the handler `<name>`; result: the number of subscriptions.
- `"off_<name>"` with no arguments: remove one subscription of the handler `<name>` (any of equal ones); if there is none, change nothing; result: the number of subscriptions afterwards.
- `"emit"` with argument `x`: call every subscription with the number `x`; result: the sum of all their values, `0` with no subscriptions.

Example: `["on_double", "on_inc", "emit", "off_double", "emit"]`, `[[], [], [5], [], [5]]` → `[1, 2, 16, 1, 6]`.
