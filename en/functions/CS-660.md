# Incremental cells with early cutoff

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Trees and graphs](../trees-graphs/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-660?utm_source=github&utm_medium=tasks-repo)**

Implement a lazy incremental spreadsheet. You get a list of commands `operations`, each made of words separated by one space:
- `input NAME V`: create an input cell with value `V`; result `[]`;
- `formula NAME F A1 A2 …`: create a formula cell: the function `F` of the values of cells `A1, A2, …` (created earlier). Functions: `add` (sum), `sub` (first minus second), `mul` (product), `max`, `min` take two arguments; `neg` (negation) and `abs` (absolute value) take one. A formula is not computed when created; result `[]`;
- `set NAME V`: give an input cell the value `V`; result `[]`;
- `get NAME`: result `[value, evaluations]`: the cell's value and how many times formula functions were called during this command.

To get a fresh value of a formula `x`: if `x` was never computed, get fresh values of its arguments in order and compute `x`. Otherwise, if since `x` was last fresh no input cell that `x` depends on (directly or through others) received through `set` a value different from its previous one, `x` is fresh: do nothing. Otherwise get fresh values of the arguments in order and compute `x` again only if at least one argument differs from the value `x` was last computed with (early cutoff). After that `x` is fresh. An input cell's value is always fresh and needs no evaluation.

Return the list of results of all commands. Commands are valid, up to 100 commands, all values fit in a 32-bit integer.

Example: `["input a 2", "formula b abs a", "formula c neg b", "get c", "set a -2", "get c"]` → `[[], [], [], [-2, 2], [], [-2, 1]]`.
