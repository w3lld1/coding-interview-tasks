# Fruit Picker

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Functions and closures](../functions/), [Async and concurrency](../async/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-11?utm_source=github&utm_medium=tasks-repo)**

An external API provides order(query, onSuccess, onError), where query contains variety and quantity; the notify function is used to notify the customer. Implement success and error handlers that call notify with the objects {message: 'SUCCESS'} and {message: 'ERROR'} respectively. The orderFromGrocer wrapper must pass the query and both handlers to order without changing the arguments, and postOrder(variety, quantity) must build the query itself and attach the prepared handlers.
