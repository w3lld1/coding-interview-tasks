# First input that reaches the target

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-348?utm_source=github&utm_medium=tasks-repo)**

You get the name of an increasing function `name` and an integer `target` (from 0 to 1000000). Find the smallest integer `n >= 0` for which the function's value at `n` is not less than `target`.

Functions:
- `"square"`: `n * n`.
- `"cube"`: `n * n * n`.
- `"triangle"`: `n * (n + 1) / 2` (the result is an integer).
- `"double_inc"`: `2 * n + 1`.
- `"power_of_two"`: `2` to the power `n`.

Example: `"square"`, `50` → `8` (`7 * 7 = 49 < 50`, `8 * 8 = 64`).
