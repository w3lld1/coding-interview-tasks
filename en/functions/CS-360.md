# Event bus with named handlers

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-360?utm_source=github&utm_medium=tasks-repo)**

An event bus keeps a shared counter (starting at `0`) and, for each event, a list of registered handlers in registration order. Handlers have names and change the counter: `inc` adds 1, `dec` subtracts 1, `double` multiplies by 2, `negate` flips the sign, `reset` sets it to 0.

You get a list of commands `commands`; return one number per command. Words in a command are separated by a single space:
- `on event handler` — append the handler to the event's list;
- `once event handler` — the same, but the handler runs only at the next `emit` of that event and is removed right after running;
- `off event handler` — remove the earliest registration of this handler for this event (plain or `once`); do nothing if there is none;
- `emit event` — run all handlers of the event in order (a handler registered twice runs twice); an event with no handlers leaves the counter alone.

The result of `on`, `once` and `off` is the number of handlers of that event after the command; for `emit` it is the counter after all handlers have run.

Example: `["on tick inc", "on tick double", "emit tick", "off tick inc", "emit tick"]` → `[1, 2, 2, 1, 4]`.
