# Text pipeline with conditional steps

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-366?utm_source=github&utm_medium=tasks-repo)**

You get a pipeline of string steps: a list `steps` applied one after another to every string in `texts` (all strings are ASCII). Return the list of results in the same order. An empty pipeline returns the strings unchanged.

Simple steps:
- `trim` — strip spaces at both ends; `squeeze` — replace every run of spaces with one space;
- `upper`, `lower` — convert letters to upper / lower case; `reverse` — reverse the string;
- `drop_vowels` — delete the vowels `aeiouAEIOU`;
- `truncate:n` — keep the first `n` characters (or the whole string if it is shorter);
- `pad:n` — append dots `.` on the right up to length `n` (if the string is shorter);
- `repeat:n` — repeat the string `n` times (`n ≥ 0`).

Conditional steps wrap any other step, a conditional one included: `when_longer:n:STEP` applies `STEP` only if the current length is greater than `n`; `when_shorter:n:STEP` — if it is less than `n`; `when_has:c:STEP` — if the string contains the character `c` (a single character, not a colon, may be a space). Otherwise the string passes unchanged. The condition is checked on the string that arrives at this step.

Example: `["when_longer:5:reverse"]`, `["abcdef", "abcde"]` → `["fedcba", "abcde"]`.
