# Pipeline of named steps over a list

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-357?utm_source=github&utm_medium=tasks-repo)**

You get a pipeline: a list of strings `steps` — names of steps applied one after another to a list of integers `values`; the result of each step is the input of the next. Return the final list. An empty pipeline returns the list unchanged.

A step is written `name` or `name:k`, where `k` is an integer (maybe negative):
- `add:k`, `mul:k` — add `k` to / multiply by `k` every element;
- `square`, `neg` — square / negate every element;
- `keep_even`, `keep_odd` — keep even / odd elements (order is kept);
- `keep_gt:k`, `keep_lt:k` — keep elements strictly greater / strictly less than `k`;
- `dedupe` — drop repeats, keeping the first occurrence of each value;
- `sort` — ascending; `reverse` — reverse the list;
- `take:k` — keep the first `k` elements (or all if there are fewer); `drop:k` — drop the first `k` (or all).

In the tests `k` of `take` and `drop` is not negative and every name is known. Values fit in 32 bits.

Example: `["add:1", "keep_even", "square"]`, `[1, 2, 3, 4]` → `[4, 16]` (after `add:1`: `[2, 3, 4, 5]`, after `keep_even`: `[2, 4]`).
