# Self-referential infinite streams

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Recursion and backtracking](../recursion/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-720?utm_source=github&utm_medium=tasks-repo)**

An infinite stream is a sequence of integers numbered `0, 1, 2, …`. You are given a list of definitions `definitions` of the form `"name = expression"` and a list of queries `queries` of the form `"name k"`. Return a list: for each query, element number `k` of the stream `name`.

Expressions (tokens are words, integers, `(`, `)` and `:`):
- `N : S` is the stream that starts with the number `N`, followed by the stream `S` (right-associative: `0 : 1 : S`);
- `from A D` is `A, A + D, A + 2D, …`;
- `add S T`, `mul S T` are the element-wise sum and product; `scale K S` multiplies every element by `K`;
- `tail S` is `S` without its first element; `sums S` is the partial sums `S[0], S[0] + S[1], …`;
- `merge S T` merges: compare the current elements `x` of `S` and `y` of `T`; output the smaller one and move to the next one in its stream, and when `x = y` output `x` once and move both streams; repeat.
Each of the arguments `S` and `T` is a name or a parenthesised expression; `A`, `D`, `K`, `N` are integers (possibly negative).

Definitions may refer to any names, including themselves and names defined further down: `fibs = 0 : 1 : add fibs (tail fibs)`. Every queried element is guaranteed to be defined (the computation does not loop), up to 20 definitions, `k ≤ 2000`, and every element needed for the answers has absolute value at most `10^15`.

Example: `["fibs = 0 : 1 : add fibs (tail fibs)"]`, `["fibs 10"]` → `[55]`.
