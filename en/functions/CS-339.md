# Combine two lists element by element

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-339?utm_source=github&utm_medium=tasks-repo)**

You get an operation name `op` and two lists of integers `a` and `b`. Return a list whose element at index `i` is the result of the operation on `a[i]` and `b[i]`. If the lists differ in length, the extra tail of the longer one is ignored: the result is as long as the shorter list.

Operations (on `x = a[i]` and `y = b[i]`):
- `"add"`: `x + y`.
- `"sub"`: `x - y`.
- `"mul"`: `x * y`.
- `"max"`: the larger of the two.
- `"min"`: the smaller of the two.
- `"diff"`: the absolute difference, `|x - y|`.

Example: `"sub"`, `[5, 5]`, `[1, 7]` → `[4, -2]`.
