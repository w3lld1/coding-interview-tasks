# Shortest chain of number transforms

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-371?utm_source=github&utm_medium=tasks-repo)**

There are five named transforms of an integer: `dec` (subtract 1), `double` (multiply by 2), `half` (divide by 2, only for an even number), `inc` (add 1) and `square` (square it). Only values from 0 to 100 are allowed: if the result leaves this range or the transform does not apply (`half` to an odd number), the step cannot be made.

You get the numbers `start` and `target` (both from 0 to 100). Find a pipeline — a list of transform names that turns `start` into `target` — with the fewest steps. If several exist, return the one whose list of names is earlier in lexicographic order (names compared as strings, left to right). If `start` equals `target`, return an empty list.

The target is always reachable, because `inc` and `dec` cover the whole range.

Example: `3`, `10` → `["square", "inc"]` (3 → 9 → 10).
