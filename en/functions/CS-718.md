# Multimethods and C3 linearization

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Classes and OOP](../oop/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-718?utm_source=github&utm_medium=tasks-repo)**

Implement classes with multiple inheritance and generic functions that pick a method by the classes of all arguments. You get a list of commands `operations` (words separated by one space); return a list of results, one per command.

- `class NAME P1 P2 …` creates a class with direct parents `P1, P2, …` in this order (created earlier, no repeats; there may be no parents). Its method resolution order (MRO) is the C3 linearization: `L(NAME) = NAME + merge(L(P1), …, L(Pk), [P1, …, Pk])`, where `merge` takes the first of the lists' heads (left to right) that occurs in the tail of no list, appends it to the result, removes it from the heads and repeats. If no head fits, the class is not created and the result is `"error"`; otherwise the result is the MRO joined by spaces.
- `method G LABEL FLAG T1 … Tk` adds to the generic function `G` a method for argument classes `T1 … Tk` labelled `LABEL`; `FLAG` is `next` (the method calls the next method) or `stop`. A method with the same `G` and the same classes replaces the old one. Result `""`.
- `call G A1 … Ak` calls `G` with arguments of classes `A1 … Ak`. A method is applicable if it has `k` classes and each `Ti` is in the MRO of `Ai`. Order the applicable methods from the most specific: compare argument positions from left to right, and at the first position where the classes differ, the more specific method is the one whose class comes earlier in the MRO of `Ai`. The first method runs; if the method that ran has `next`, the next one in order runs, and so on. The result is the labels of the methods that ran, joined by `>`; if the last method that ran called the next one and there is none, append `>no-next`. If no method is applicable (or there is no function `G`), the result is `"no-method"`.

Commands mention only created classes, up to 100 commands.

Example: `["class A", "class B A", "class C A", "class D B C", "method greet b next B", "method greet a stop A", "call greet D"]` → `["A", "B A", "C A", "D B C A", "", "", "b>a"]`.
