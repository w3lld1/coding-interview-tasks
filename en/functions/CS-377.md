# Expanding operation aliases

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Recursion and backtracking](../recursion/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-377?utm_source=github&utm_medium=tasks-repo)**

There are five basic operations on an integer: `inc` (+1), `dec` (−1), `double` (×2), `negate` (flip the sign) and `square`. Aliases are built from them: a definition `ALIAS=name name …` (the `=` sign has no spaces, on the right is a non-empty list of names separated by spaces) defines an operation that applies the listed operations in turn — basic ones or other aliases. An alias name never equals a basic operation name and is defined at most once.

You get a list of definitions `definitions`, a list of names `names` and a number `x`. Return the list of results of applying each operation of `names` to `x` (each is applied to the original `x` separately). An empty `names` gives an empty list.

If expansion meets an unknown name, or an alias that contains itself directly or through others, report an error: throw an exception, or return an error in Go. Definitions that the requested names do not need are not checked. Using one alias in several places is not a cycle. The error applies to the whole call. Results fit in 32 bits.

Example: `["triple_inc=inc inc inc", "twice=triple_inc triple_inc"]`, `["twice", "inc"]`, `1` → `[7, 2]`.
