# Pipeline of text steps

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-351?utm_source=github&utm_medium=tasks-repo)**

You get a list of step names `steps` and a string `text` of ASCII characters. Apply the steps to the string in order, each to the result of the previous, and return the final string. An empty list of steps leaves the string unchanged.

Steps:
- `"upper"`: every letter to upper case.
- `"lower"`: every letter to lower case.
- `"reverse"`: the characters in reverse order.
- `"trim"`: remove spaces (the space character only) at the start and the end of the string.
- `"squeeze"`: replace every group of several consecutive spaces with a single space.
- `"drop_vowels"`: delete the vowels `a`, `e`, `i`, `o`, `u` in either case.
- `"twice"`: write the string two times in a row.

Example: `["squeeze", "trim"]`, `"  a   b    c "` → `"a b c"`.
