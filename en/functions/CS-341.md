# Counter factory

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-341?utm_source=github&utm_medium=tasks-repo)**

Implement a set of independent counters. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). At first there are no counters. Return a list of results, one per operation. Counter ids in the tests always exist.

Operations:
- `"create"` with arguments `start` and `step`: create a counter whose current value is `start` and whose step is `step`; ids are handed out in order of creation from 0; result: the id of the new counter.
- `"tick"` with argument `id`: result: the counter's current value, after which its step is added to it.
- `"peek"` with argument `id`: result: the counter's current value, unchanged.
- `"reset"` with argument `id`: give the counter its starting value `start` back; result: that value.

Example: `["create", "tick", "tick", "peek", "reset", "tick"]`, `[[10, 5], [0], [0], [0], [0], [0]]` → `[0, 10, 15, 20, 10, 10]`.
