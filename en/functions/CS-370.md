# Handler chain with an error and a catch

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-370?utm_source=github&utm_medium=tasks-repo)**

A request goes through a chain of handlers, as in a web framework. The state is a log (a list of strings, empty at first) and a "current error" (none at first). A step is written `name:text`; the text is everything after the first colon, with no colons or spaces in the tests. Steps run in order:
- `ok:text` — if there is no error, append `text` to the log; otherwise skip;
- `fail:text` — if there is no error, create an error with that text (nothing is logged); otherwise skip;
- `catch:text` — if there is an error, append `text(message)` to the log, where `message` is the error's text, and clear the error; otherwise skip;
- `rethrow:text` — if there is an error, replace its text with the new one; otherwise skip;
- `always:text` — always append `text` to the log, leaving the error alone.

If an error is left after the last step, append the line `unhandled:message` to the log. Return the log.

Example: `["ok:auth", "fail:boom", "ok:handler", "catch:recovered", "ok:done"]` → `["auth", "recovered(boom)", "done"]`.
