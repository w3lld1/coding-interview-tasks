# Curry and compose interpreter

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-664?utm_source=github&utm_medium=tasks-repo)**

Evaluate the expression `expression` of a tiny functional language. An expression is a number (an integer, maybe negative: `-7`) or the name of a built-in function, optionally followed by several applications in parentheses: `f(a, b)(c)…`; the arguments are expressions again. A value is either an integer or a function. Every built-in has an arity (number of arguments):
- `add`, `sub` (first minus second), `mul`, `max`: arity 2, the arguments are numbers;
- `neg` (negation), `inc` (+1): arity 1, the argument is a number;
- `id`: arity 1, returns its argument as is (a number or a function);
- `compose(f, g)`: arity 2, `f` and `g` are functions; the result is a function of arity 1: `x ↦ f(g(x))`;
- `twice(f)`: arity 1, `f` is a function; the result is a function of arity 1: `x ↦ f(f(x))`;
- `flip(f)`: arity 1, `f` is a function; the result is a function of arity 2: `(a, b) ↦ f(b, a)`.

Application is curried: with fewer arguments than the function still lacks, the result is a partially applied function that remembers them; with exactly that many the function is called; with more, it is called on the needed number of first arguments and its result is applied to the rest. Arguments and applications are evaluated left to right.

If the result is a number return its decimal form; if it is a function return the string `<fn/k>`, where `k` is how many arguments it still lacks. If a number is applied to arguments, a function gets where a number is needed, or a number where a function is needed, report an error: throw an exception, or return an error in Go. The expression is syntactically valid, parentheses are never empty and all numbers fit in a 32-bit integer.

Example: `"compose(inc, mul(2))(5)"` → `"11"`.
