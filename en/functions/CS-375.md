# Partial application with numbered arguments

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-375?utm_source=github&utm_medium=tasks-repo)**

There are these functions: `sub(a, b) = a - b`, `pow(a, b) = a` to the power `b`, `mad(a, b, c) = a · b + c`, `clamp(x, lo, hi)` — `x` pressed into the segment from `lo` to `hi` (i.e. `min(max(x, lo), hi)`), and `between(lo, x, hi)` — `1` if `lo ≤ x ≤ hi`, otherwise `0`.

The string `spec` defines a partially applied function: `name(arg,arg,…)` without spaces, where each argument is either an integer (maybe negative) or a placeholder `_k` (`k ≥ 1`). The placeholder `_k` means "take the `k`-th of the numbers that arrive with the call"; a placeholder may appear several times, and placeholders may come in any order.

You get a list of calls `calls`: each call is a list of numbers that contains every needed placeholder (extra numbers are ignored). Return the function's result for each call. In the tests the exponent of `pow` is not negative and results fit in 32 bits.

Example: `"mad(_1,_1,_2)"`, `[[3, 1], [-4, 0]]` → `[10, 16]`: `3·3+1` and `(-4)·(-4)+0`.
