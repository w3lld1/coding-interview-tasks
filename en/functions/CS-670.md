# Commands with inverses and selective undo

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Functions and closures](../functions/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-670?utm_source=github&utm_medium=tasks-repo)**

The state is a pair of integers `(a, b)`, initially `(0, 0)`. Every command has a forward function and an inverse:
- `add_a K`: `a + K` / `a − K`; `add_b K`: `b + K` / `b − K`;
- `move K`: `(a − K, b + K)` / `(a + K, b − K)`;
- `swap`: `(b, a)` / `(b, a)`; `neg_a`: `(−a, b)` / `(−a, b)`;
- `rot`: `(b, −a)` / `(−b, a)`.
A macro is a sequence of commands and previously defined macros; its forward function runs the parts in order, its inverse runs the parts' inverses in reverse order.

Process the list `operations` (`K` is an integer):
- `define NAME PART1 ; PART2 ; …`: define a macro (parts separated by ` ; `);
- `do COMMAND`: run a command or macro (its forward function); this is a history entry with a number: the first `do` is `1`, the next `2` and so on. The redo stack is cleared;
- `undo`: take the last active history entry, apply its inverse to the current state and push the entry on the redo stack; with no active entries do nothing;
- `redo`: pop an entry from the redo stack, apply its forward function and make it the last active entry again; with an empty stack do nothing;
- `revert N`: selective undo: if entry `N` is active, apply its inverse to the current state (even if other entries came after it) and remove it from the active ones; the redo stack is cleared. If there is no entry `N` or it is no longer active, do nothing.

After every operation record the state as the string `"a,b"` and return the list of these strings. Up to 100 operations, all values fit in a 32-bit integer.

Example: `["do add_a 5", "do rot", "undo", "redo"]` → `["5,0", "0,-5", "5,0", "0,-5"]`.
