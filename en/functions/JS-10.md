# Coordinate Transformation

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-10?utm_source=github&utm_medium=tasks-repo)**

Create translate2d(dx, dy) and scale2d(sx, sy) that return functions of coordinates (x, y) with the result as a pair [x, y]; the first adds the offsets, the second multiplies the coordinates by positive factors. Implement composeTransform(f, g), which applies f first and then g. Add memoizeTransform: the wrapper stores only the last pair of input coordinates and the last result, so a repeated call with the same pair must not compute the transformation again.
