# Constant diagonals

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-497?utm_source=github&utm_medium=tasks-repo)**

Given a non-empty rectangular matrix of integers `matrix`. It is a Toeplitz matrix if on every diagonal running from top-left to bottom-right all numbers are equal. Return `true` if the matrix is like that, otherwise `false`. A matrix of one row or one column always qualifies.

Example: `[[1, 2, 3], [4, 1, 2], [5, 4, 1]]` → `true`; `[[1, 2], [2, 2]]` → `false` (the diagonal `1, 2` has different numbers).
