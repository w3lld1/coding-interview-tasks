# Sums of the rings of a table

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-508?utm_source=github&utm_medium=tasks-repo)**

Given a rectangular table of integers `grid` (possibly empty). Ring number 0 consists of all cells on the border of the table (the first and last rows, the first and last columns). Ring number 1 is the border of what remains after removing ring 0, and so on until the cells run out. Return the list of ring sums, starting from the outer one. For an empty table return an empty list.

Example: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[40, 5]`.
