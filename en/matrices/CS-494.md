# Halve an image

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-494?utm_source=github&utm_medium=tasks-repo)**

A grayscale image is a rectangular list of lists of non-negative integers `image`; both the number of rows and the number of columns are even (the image can be empty). Shrink it by half along each side: the image is split into 2×2 blocks, and each block becomes one pixel, the arithmetic mean of its four values rounded down. Return the new image; for an empty image return an empty list.

Example: `[[1, 3, 0, 0], [5, 7, 0, 1]]` → `[[4, 0]]`.
