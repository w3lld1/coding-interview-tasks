# Zigzag diagonal traversal

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-138?utm_source=github&utm_medium=tasks-repo)**

Given a rectangular matrix of integers (all rows of equal length, up to 100×100), read it along its diagonals, where `row + column` is constant, starting at the top-left corner: diagonal 0 is one element; read diagonal 1 from top to bottom (the row grows), diagonal 2 from bottom to top (the row shrinks), and so on alternately until the bottom-right corner. Return all elements in reading order. For an empty matrix (no rows or no columns) return an empty list.

Example: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[1, 2, 4, 7, 5, 3, 6, 8, 9]`.
