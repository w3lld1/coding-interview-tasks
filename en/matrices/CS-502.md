# Rectangle sums in a table

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-502?utm_source=github&utm_medium=tasks-repo)**

Given a table of integers `grid` and a list of queries `queries`. A query `[r1, c1, r2, c2]` asks for the sum of all numbers in the rectangle with rows from `r1` to `r2` and columns from `c1` to `c2` (bounds inclusive, zero-based, `r1 ≤ r2`, `c1 ≤ c2`, the rectangle lies inside the table). Return the answers in the order of the queries. There may be many queries, so it pays to prepare the table once and answer each query in a few operations instead of adding up every cell of the rectangle again.

Example: `[[1, 2, 3], [4, 5, 6]]`, `[[0, 1, 1, 2], [1, 0, 1, 0]]` → `[16, 4]`.
