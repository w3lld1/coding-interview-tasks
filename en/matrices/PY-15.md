# Spiral Matrix

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-15?utm_source=github&utm_medium=tasks-repo)**

Given a non-negative size n, create a square matrix containing the numbers from 1 to n². Fill it clockwise from the top-left corner: first right, then down, left and up, gradually moving toward the center. For size zero, return an empty list.
