# Safe rooks

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-506?utm_source=github&utm_medium=tasks-repo)**

A chessboard is a non-empty list of equal-length strings `board`: `R` is a rook, `.` is an empty cell. There are no other pieces. Two rooks threaten each other if they stand in the same row or the same column. A rook is safe if there is no other rook in its row and no other rook in its column. Return the number of safe rooks.

Example: `["R..", "R..", "..R"]` → `1`.
