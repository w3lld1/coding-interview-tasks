# Saddle Points

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-10?utm_source=github&utm_medium=tasks-repo)**

Find all elements of a numeric matrix that are both the maximum in their row and the minimum in their column. Return their coordinates as [row, column] pairs numbered from one, in any order; equal extreme values may produce several answers. For an empty matrix, return an empty list, and if the rows have different lengths, report an error: throw an exception, or return an error in Go.
