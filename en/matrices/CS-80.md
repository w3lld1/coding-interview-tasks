# Largest rectangle of ones

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Stacks, queues, linked lists](../stacks-lists/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-80?utm_source=github&utm_medium=tasks-repo)**

Given a rectangular table of `'0'` and `'1'` characters as a list of strings `grid`, one string per row, all of the same length (at least 1), find the rectangle with sides along the rows and columns whose cells are all `'1'` and has the largest area, and return that area (the number of cells). If there are no ones or the list is empty, return `0`. The table has up to 200 × 200 cells.

Example: `["10100", "10111", "11111", "10010"]` → `6` (rows 1–2, columns 2–4).
