# Snake order

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-507?utm_source=github&utm_medium=tasks-repo)**

Given a rectangular table of integers `grid` (possibly empty). Traverse it in a "snake" order: read row 0 from left to right, row 1 from right to left, row 2 from left to right again, and so on. Return all numbers in the order of the traversal as one list. For an empty table return an empty list.

Example: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[1, 2, 3, 6, 5, 4, 7, 8, 9]`.
