# Column heights in a well

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-503?utm_source=github&utm_medium=tasks-repo)**

A well is a non-empty list of equal-length strings `board`: `#` is a block, `.` is an empty cell; row 0 is the top, the last row is the bottom. The height of a column is the distance from the bottom to the topmost block of that column, counting the block: if the topmost block sits on the bottom, the height is `1`; if the column has no blocks, the height is `0`. Blocks may hang in the air, and empty cells under them do not reduce the height. Return the heights of all columns from left to right.

Example: `["..#", "#..", "#.."]` → `[2, 0, 3]`.
