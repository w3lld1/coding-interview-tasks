# Hottest square of the map

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-492?utm_source=github&utm_medium=tasks-repo)**

A heat map is a rectangular list of lists of integers `heat`, and `k` is the window size: `1 ≤ k ≤` the smaller dimension of the map. Among all square windows `k × k` find the one with the largest sum of values. Return `[row, column]` of its top-left corner (zero-based). If several windows tie, return the one met first in row-major order: the smaller row, and for equal rows the smaller column.

Example: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]`, `2` → `[1, 1]` (sum `5 + 6 + 8 + 9 = 28`).
