# Falling blocks

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-504?utm_source=github&utm_medium=tasks-repo)**

A well is a non-empty list of equal-length strings `board`: `#` is a block, `.` is an empty cell; row 0 is the top, the last row is the bottom. Every block falls down along its column until it hits the bottom or another (already fallen) block; blocks in different columns do not affect each other, and the order of blocks within a column is kept. Return the well after everything has fallen.

Example: `["#.", "..", "#."]` → `["..", "#.", "#."]`.
