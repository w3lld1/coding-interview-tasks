# Tic-tac-toe game state

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-102?utm_source=github&utm_medium=tasks-repo)**

Given a 3×3 board as a list of three strings of three characters each: `"X"`, `"O"` or a space (an empty cell). X moves first and the players alternate. Return the state of the game: `"win"` (somebody has three in a row along a row, column or diagonal), `"draw"` (the board is full and nobody won) or `"ongoing"`.

Report an error: throw an exception, or return an error in Go, if the board is impossible: there are more O than X, or more than one X more than O; both players have won; or the game went on after a win (when X won, X must have exactly one mark more than O; when O won, the counts must be equal). A win by one player along two lines at once is possible and is not an error.

Example: `["XXX", "OO ", "   "]` → `"win"`.
