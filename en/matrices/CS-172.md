# Smallest longest increasing path

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Dynamic programming](../dp/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-172?utm_source=github&utm_medium=tasks-repo)**

You are given a rectangular table of integers. A path starts in any cell and each step moves to a cell sharing a side (up, down, left or right, staying inside the table), and each next number is strictly greater than the previous one. Find a path of the greatest length and return the list of numbers it passes through, in order. If several such paths exist, return the one whose list of numbers is lexicographically smallest (compared at the first differing number). For an empty table (no rows, or rows of length zero) return `[]`.

The table has up to 10,000 cells, with numbers from -10⁹ to 10⁹. Trying all paths will not fit the time limit on the large tests.

Example: `[[3, 4, 5], [3, 2, 6], [2, 2, 1]]` → `[2, 4, 5, 6]` (the path `3, 4, 5, 6` also has length 4, but it is greater).
