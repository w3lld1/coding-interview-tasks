# Longest run of free seats

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-485?utm_source=github&utm_medium=tasks-repo)**

A cinema hall is a list of equal-length strings `seats`: `.` is a free seat, `X` is a taken one. Return the largest number of free seats that sit next to each other in one row (one string). Seats from different rows never join. If there are no free seats or the plan is empty, return `0`.

Example: `["..X..", "....X", ".XX.."]` → `4` (the first four seats of the second row).
