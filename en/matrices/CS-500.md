# Painting rectangles

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-500?utm_source=github&utm_medium=tasks-repo)**

There is a blank canvas of `rows` rows and `cols` columns, every cell is the character `.`. The list `rects` holds rectangles `[r1, c1, r2, c2, d]`: paint all cells with rows from `r1` to `r2` and columns from `c1` to `c2` (bounds inclusive, zero-based) with the digit `d` (from `1` to `9`). The rectangles are painted in list order, a later one covers an earlier one. Every rectangle lies completely on the canvas, `r1 ≤ r2`, `c1 ≤ c2`. Return the canvas as a list of strings.

Example: `3`, `4`, `[[0, 0, 1, 1, 1], [1, 1, 2, 3, 2]]` → `["11..", "1222", ".222"]`.
