# Connect Four winner

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-490?utm_source=github&utm_medium=tasks-repo)**

A Connect Four board is a non-empty list of equal-length strings `board`: `R` is a red disc, `Y` is a yellow disc, `.` is an empty cell (row 0 is the top). A player has won if they own four discs in a row horizontally, vertically or on either diagonal. Return `"R"` or `"Y"` for the winner, and the empty string `""` if nobody has won. The two players never have a four at the same time. The board can be of any size.

Example: `["....", "R...", ".R..", "..R.", "...R"]` → `"R"` (a diagonal).
