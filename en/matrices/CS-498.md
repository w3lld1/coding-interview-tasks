# Latin square

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-498?utm_source=github&utm_medium=tasks-repo)**

Given a square `square` of `n` rows and `n` columns of integers (`n ≥ 1`). It is a Latin square if every row and every column contains each number from `1` to `n` exactly once (and no other numbers). Return `true` if the square is Latin, otherwise `false`.

Example: `[[1, 2, 3], [2, 3, 1], [3, 1, 2]]` → `true`; `[[1, 2], [1, 2]]` → `false` (the first column has two ones).
