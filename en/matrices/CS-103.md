# Distance to the nearest exit

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-103?utm_source=github&utm_medium=tasks-repo)**

You get a rectangular map of rooms: `-1` is a wall, `0` is an exit, `1000000` is an empty room. One step moves to a side-adjacent cell that is not a wall. Return a new map where every empty room holds the fewest steps to the nearest exit. A room from which no exit can be reached keeps `1000000`. Walls and exits do not change. An empty map gives an empty list. The map is at most 200×200.

Example: `[[1000000, -1, 0], [1000000, -1, 1000000], [1000000, -1, 1000000]]` → `[[1000000, -1, 0], [1000000, -1, 1], [1000000, -1, 2]]`.
