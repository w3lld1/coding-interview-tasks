# Collecting coins along a route

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-496?utm_source=github&utm_medium=tasks-repo)**

A game board is a rectangular list of lists of integers `board`: a cell holds that many coins (a number can be negative, which is a penalty). The player stands in the top-left cell `(0, 0)` and takes its content right away. The string `moves` consists of the characters `U`, `D`, `L`, `R` (up, down, left, right). Each command moves the player to the adjacent cell and takes its content; a command that leads off the board is skipped. A cell's content is taken only once: when the player comes back, the cell is empty. Return the sum of everything taken.

Example: `[[1, 2], [3, 4]]`, `"RLRD"` → `7` (the cells `1`, `2` and `4`).
