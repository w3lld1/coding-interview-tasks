# Symmetry of an image

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-487?utm_source=github&utm_medium=tasks-repo)**

An image is a non-empty list of equal-length strings `image`; each character is a pixel. The image is horizontally symmetric if it equals its left-to-right mirror (every row reads the same in both directions). It is vertically symmetric if it equals its top-to-bottom mirror (the first row equals the last, the second equals the one before last, and so on). Return `"both"` if both hold, `"horizontal"` or `"vertical"` if only that one holds, and `"none"` otherwise.

Example: `["ab", "ab"]` → `"vertical"`.
