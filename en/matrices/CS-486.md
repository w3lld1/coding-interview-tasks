# Seats for a group

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-486?utm_source=github&utm_medium=tasks-repo)**

A cinema hall is a list of equal-length strings `seats`: `.` is a free seat, `X` is a taken one. A group of `k` people (`k ≥ 1`) needs `k` free seats next to each other in one row. Find the earliest suitable block: the smallest row index, and within the row the smallest index of the first seat. Return `[row, seat]` (zero-based) of the first seat of the block. If there is no suitable block, return `[-1, -1]`.

Example: `["..X..", "....."]`, `3` → `[1, 0]` (the first row has only runs of two).
