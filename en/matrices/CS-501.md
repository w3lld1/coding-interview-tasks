# Kind of a square matrix

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-501?utm_source=github&utm_medium=tasks-repo)**

Given a square matrix of integers `matrix` of size `n × n` (`n ≥ 1`). Return a string naming its kind, checking the kinds in this order: `"identity"` — ones on the main diagonal and zeros everywhere else; `"diagonal"` — all numbers outside the main diagonal are zero; `"upper"` — all numbers below the main diagonal are zero; `"lower"` — all numbers above the main diagonal are zero; `"other"` — none of the kinds fits. Return the first name that fits.

Example: `[[1, 2], [0, 3]]` → `"upper"`; `[[2, 0], [0, 3]]` → `"diagonal"`.
