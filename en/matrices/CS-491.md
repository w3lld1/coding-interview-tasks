# Table with totals

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-491?utm_source=github&utm_medium=tasks-repo)**

A table is a rectangular list of lists of integers `table`. Return a new table where the sum of each row is appended to the end of that row, and one more row is added at the bottom with the sums of the columns (including the new column, so the bottom-right corner holds the grand total). Do not change the original table. For an empty list return an empty list.

Example: `[[1, 2], [3, 4]]` → `[[1, 2, 3], [3, 4, 7], [4, 6, 10]]`.
