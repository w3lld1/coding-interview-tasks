# Lexicographically smallest grid path

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-129?utm_source=github&utm_medium=tasks-repo)**

Given a square grid `N × N` (N ≥ 2) in which each number from 1 to N·N appears exactly once, and a step count `k`. A path of length `k` visits exactly `k` cells (cells may repeat); you can start in any cell, each next step goes to a cell sharing a side with the current one, and you cannot leave the grid. Paths are compared as lists of cell values lexicographically. Return the list of values along the smallest path of length `k`.

Example: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]`, `3` → `[1, 2, 1]`.
