# Robot on a map with walls

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-495?utm_source=github&utm_medium=tasks-repo)**

A map is a non-empty list of equal-length strings `grid`: `S` is the robot's starting cell (there is exactly one), `.` is a free cell, `#` is a wall. The string `commands` consists of the characters `U`, `D`, `L`, `R` (up, down, left, right; row 0 of the map is the top). On each command the robot moves one cell, but if that cell is a wall or outside the map, the robot stays where it is and goes on to the next command. Return `[row, column]` (zero-based) of the cell where the robot ends up after all commands.

Example: `["S#.", "..."]`, `"RDR"` → `[1, 1]` (the first command hits a wall).
