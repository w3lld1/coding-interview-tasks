# Word Search

**Difficulty:** medium · **Language:** Python · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-22?utm_source=github&utm_medium=tasks-repo)**

In a rectangular grid of letters, find a given word along a straight line in any of the eight horizontal, vertical or diagonal directions. Return the pair of coordinates of the first and last letters in the order the word is read, using x for the column and y for the row, both numbered from zero. Turns inside the word and wrapping across the grid boundary are not allowed; if the word is absent, return None.
