# Blur an image

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-489?utm_source=github&utm_medium=tasks-repo)**

A grayscale image is a non-empty rectangular list of lists of non-negative integers `image` (pixel brightness). Blurring replaces every pixel with the arithmetic mean of itself and its existing neighbours on the left, right, above and below (diagonals are not used), rounded down to an integer. All new values are computed from the original image, not from already blurred pixels. Return the new image of the same size.

Example: `[[1, 2], [3, 4]]` → `[[2, 2], [2, 3]]` (for the top-left pixel `(1 + 2 + 3) / 3 = 2`).
