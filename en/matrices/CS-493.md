# Frame around a drawing

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Matrices and grids](../matrices/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-493?utm_source=github&utm_medium=tasks-repo)**

An image is a list of equal-length strings `image`: `#` is a painted pixel, `.` is an empty one. Find the smallest axis-aligned rectangle that contains all painted pixels. Return `[top, left, bottom, right]`: the indexes of its extreme rows and columns (zero-based, inclusive). If there are no painted pixels, return an empty list.

Example: `["....", ".##.", "..#.", "...."]` → `[1, 1, 2, 2]`.
