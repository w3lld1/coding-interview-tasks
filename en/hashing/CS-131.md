# Palindrome from two-letter words

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-131?utm_source=github&utm_medium=tasks-repo)**

Given a list of words, each made of exactly two lowercase Latin letters, you may pick some of them (each list entry at most once, equal words in the list count as separate copies) and write them one after another in any order. Return the greatest length of such a string that reads the same forwards and backwards. If nothing can be formed, return `0`. There are up to 1000 words.

Example: `["lc", "cl", "gg"]` → `6` (the string `lcggcl`).
