# Scrabble scores format change

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-51?utm_source=github&utm_medium=tasks-repo)**

In the old format letters are stored in groups by points: the key is the number of points (as a string) and the value is a list of letters worth that many points (usually upper-case, but any case may occur). Convert it to the new format: a map whose key is a lower-case letter and whose value is its points (a number). Each letter appears in only one group of the old format. An empty input gives an empty map.

Example: `{"1": ["A", "E"], "2": ["D"]}` → `{"a": 1, "e": 1, "d": 2}`.
