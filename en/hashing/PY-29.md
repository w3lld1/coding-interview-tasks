# Tournament

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Searching and sorting](../search-sort/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-29?utm_source=github&utm_medium=tasks-repo)**

From records of the form team1;team2;result, compute for each team the number of matches played, wins, draws, losses and points, where win, loss and draw describe the outcome for the first team. Award 3 points for a win, 1 for a draw and 0 for a loss; sort by points in descending order, and by team name on ties. Return a text table with columns Team, MP, W, D, L, P: the name field is 30 characters wide and left-aligned, the numeric fields are 2 characters wide and right-aligned, and the field separator is a space, a vertical bar and a space. For an empty list of matches, return only the header.
