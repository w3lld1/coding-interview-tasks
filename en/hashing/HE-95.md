# Keys in a single case

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-95?utm_source=github&utm_medium=tasks-repo)**

Given a map with string keys, return `true` if all keys are lowercase or all keys are uppercase. A key is lowercase if it has at least one Latin letter and no uppercase letters; it is uppercase if it has at least one letter and no lowercase letters. A key with no letters (for example `"8"`) fits neither. For an empty map return `false`.

Example: `{"a": "apple", "b": "banana"}` → `true`. Example: `{"a": "apple", "A": "banana"}` → `false`.
