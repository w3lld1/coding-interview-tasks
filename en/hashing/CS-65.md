# Merge accounts by email

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-65?utm_source=github&utm_medium=tasks-repo)**

You get a list of accounts: each account is a list of strings where the first string is the owner's name and the rest (at least one) are the owner's email addresses. Addresses consist of lowercase Latin letters, digits and the characters `@` and `.`. If two accounts share an address they belong to the same person, and the link is transitive: accounts joined by a chain of shared addresses merge. Merged accounts always have the same name, and people with the same name but no shared address are different people.

Return the merged accounts in the same format: the name, then all distinct addresses of the group in ascending order (by character codes). Order the accounts themselves by ascending first address. For an empty list return an empty list. There are at most 1000 accounts.

Example: `[["A", "a@x", "b@x"], ["B", "c@x"], ["A", "b@x", "d@x"]]` → `[["A", "a@x", "b@x", "d@x"], ["B", "c@x"]]`.
