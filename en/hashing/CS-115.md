# Cards in consecutive groups

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-115?utm_source=github&utm_medium=tasks-repo)**

You are given a list of integers `cards` (up to 2000 items, values may repeat and be negative) and a number `k >= 1`. Can all the numbers be split into groups so that every group has exactly `k` numbers forming `k` consecutive values (`x, x + 1, …, x + k - 1`)? Each number is used in exactly one group. For an empty list the answer is `true`.

Example: `[1, 2, 3, 3, 4, 4, 5, 6]`, `4` → `true` (`1 2 3 4` and `3 4 5 6`).
