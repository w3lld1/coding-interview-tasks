# Ozan's Playlist

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Hash maps and sets](../hashing/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-14?utm_source=github&utm_medium=tasks-repo)**

A playlist contains strings of the form 'song - artist'; implement removing duplicate tracks, checking whether a track is present, adding without duplicates, and deleting a track. Operations that produce a playlist must return an array, preserving the order of first occurrences of the remaining elements, and the check must return a boolean. Add getting the unique artists, and use a Set to handle a large number of entries.
