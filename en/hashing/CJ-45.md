# Perfect Subarrays

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-45?utm_source=github&utm_medium=tasks-repo)**

Given an array of integers (each at most 100 in absolute value). A subarray is a non-empty contiguous part of the array; it is perfect if the sum of its elements is a perfect square of a non-negative integer (0, 1, 4, 9, 16, …). Subarrays with different bounds are different even when their values are equal.

Return the number of perfect subarrays. The array may have up to 10^5 elements, so you cannot check every subarray.

Example: `[4, 0, 0, 16]` → `9`.
