# International Calling Connoisseur

**Difficulty:** medium · **Language:** Java · **Topics:** [Hash maps and sets](../hashing/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-30?utm_source=github&utm_medium=tasks-repo)**

Implement a Map<Integer, String> directory that maps a dialing code to a country, with getting the whole map, lookup by code, and setting an entry that replaces an existing value. A separate add method must change nothing if that code or that country is already present. Support reverse lookup of a code by country, returning null when absent, and updating the code of an existing country while removing the old entry; for an unknown country, the update does nothing.
