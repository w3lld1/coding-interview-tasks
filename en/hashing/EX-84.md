# Resistor band color code

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-84?utm_source=github&utm_medium=tasks-repo)**

Bands on a resistor encode digits. The colors in order: `black` is 0, `brown` is 1, `red` is 2, `orange` is 3, `yellow` is 4, `green` is 5, `blue` is 6, `violet` is 7, `grey` is 8, `white` is 9. Given a lowercase color name, return its digit.

Example: `"brown"` → `1`, `"white"` → `9`.
