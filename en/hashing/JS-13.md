# High Score Board

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-13?utm_source=github&utm_medium=tasks-repo)**

Create a high score board as an object mapping "player name → score" with the initial entry 'The Best Ever': 1000000. Implement adding a player, removing an existing or missing player, and increasing a given player's score by the passed number. A separate function must add 100 bonus points to every player; all mutating functions return the original object after the change.
