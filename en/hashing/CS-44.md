# Most frequent words

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Hash maps and sets](../hashing/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-44?utm_source=github&utm_medium=tasks-repo)**

Given a list of words made of lowercase Latin letters and a number `k ≥ 0`, return the `k` most frequent words (each distinct word once). Order of the result: words with more occurrences first; words with the same count in alphabetical order. If there are fewer than `k` distinct words, return all distinct words in the same order. For an empty list or `k = 0` the answer is an empty list.

Example: `["i", "love", "code", "i", "love", "tests"]`, `2` → `["i", "love"]`.
