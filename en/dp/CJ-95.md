# Albocede DNA subsequences

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-95?utm_source=github&utm_medium=tasks-repo)**

A block is a string `a…a b…b c…c d…d`: first `i ≥ 1` letters `a`, then `j ≥ 1` letters `b`, then exactly `i` letters `c` and exactly `j` letters `d` (for example `abcd` and `aabbbccddd`). A valid string is one or more blocks written one after another (for example `aaabcccdaabbbccdddabcd`).

Given a string `dna` of letters `a`, `b`, `c`, `d` (length 1 to 500), count its subsequences that are valid strings. Subsequences taken at different positions count separately even when they are equal as strings. Return the count modulo `1 000 000 007`.

Example: `"aaaabcd"` → `4` (one of the four letters `a`, then `b`, `c`, `d`).
