# Longest chain of nested envelopes

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Searching and sorting](../search-sort/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-90?utm_source=github&utm_medium=tasks-repo)**

You are given a list `envelopes` (up to 10^5 of them), each a pair `[width, height]` of integers from 1 to 10^9. Envelope A fits into envelope B when A's width is strictly less than B's and A's height is strictly less than B's; envelopes cannot be rotated. Return the largest number of envelopes that can be nested in a chain (each inside the next). Identical envelopes do not fit into each other. An empty list gives `0`, a single envelope gives `1`.

Example: `[[5, 4], [6, 4], [6, 7], [2, 3]]` → `3` (`[2, 3]` → `[5, 4]` → `[6, 7]`).
