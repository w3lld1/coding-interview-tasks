# Smooth the pixels

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-51?utm_source=github&utm_medium=tasks-repo)**

You are given a row of pixels: a list of numbers from 0 to 255 (up to 40 pixels). The row is smooth if every two neighbouring pixels differ by at most `max_gap`; an empty row and a row of one pixel are smooth. You may use three operations any number of times, in any order:

- delete any pixel for `delete_cost` (its neighbours become neighbours);
- insert a pixel of any value from 0 to 255 anywhere (at the start, at the end or between two pixels) for `insert_cost`;
- change a pixel's value to any value from 0 to 255; the cost is the absolute difference of the old and new values.

All costs and `max_gap` are integers from 0 to 255. Return the minimum total cost of operations that make the row smooth.

Example: `delete_cost = 100`, `insert_cost = 1`, `max_gap = 5`, `[1, 50, 7]` → `17` (insert 9 pixels between 1 and 50 and 8 pixels between 50 and 7).
