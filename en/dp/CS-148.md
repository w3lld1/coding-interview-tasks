# Longest arithmetic subsequence

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-148?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers from 0 to 500 (up to 1000 elements). A subsequence is made by deleting some elements without reordering the rest. It is arithmetic if the difference between every two neighbouring elements is the same (a subsequence of one or two elements is arithmetic too; the difference may be zero or negative). Return the length of the longest arithmetic subsequence. For an empty list return `0`.

Example: `[9, 4, 7, 2, 10]` → `3` (the subsequence `4, 7, 10` with difference 3).
