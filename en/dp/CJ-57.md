# Box factory

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-57?utm_source=github&utm_medium=tasks-repo)**

A factory has two assembly lines: one makes boxes, the other makes toys, and every box and toy has a type. You take the first box and the first toy, and at each step you do one of three things: throw away the current box and take the next one, throw away the current toy and take the next one, or, if their types match, put the toy in the box and ship it (then take the next box and the next toy). You cannot change the order on either line.

The lines make long runs of one type. `boxes` is a list of pairs `[count, type]`: first come `boxes[0][0]` boxes of type `boxes[0][1]`, then the next run, and so on; `toys` describes the toys the same way. Return the largest number of toys you can ship in boxes. Each line has 1 to 100 runs, a run has from 1 to 2·10¹² items and types are 1 to 100, so expanding the runs into single items is not an option.

Example: `[[10, 1], [20, 2], [25, 3]]`, `[[10, 2], [30, 3], [20, 1]]` → `35`.
