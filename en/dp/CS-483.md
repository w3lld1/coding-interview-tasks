# How many calls naive Fibonacci makes

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-483?utm_source=github&utm_medium=tasks-repo)**

The function `fib(k)` is defined as follows: `fib(0)` returns `0`, `fib(1)` returns `1`, and for `k >= 2` it calls `fib(k - 1)` and `fib(k - 2)` and returns their sum. Nothing is remembered. Return the total number of calls of `fib` (including the very first one) made when `fib(n)` runs. `n` is from 0 to 40. Do not run the recursion itself: for `n = 40` there are hundreds of millions of calls.

Example: `4` → `9` (`fib(4)`, `fib(3)`, `fib(2)`, `fib(1)`, `fib(0)`, `fib(1)`, `fib(2)`, `fib(1)`, `fib(0)`).
