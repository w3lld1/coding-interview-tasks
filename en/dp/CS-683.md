# Exactly k made free throws

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-683?utm_source=github&utm_medium=tasks-repo)**

A basketball player takes a series of free throws. Throw `i` goes in with probability `chances[i]` (a number from 0 to 1), and the throws are independent. Return the probability that exactly `k` throws go in. If `k` is larger than the number of throws, the answer is `0`; for an empty series, exactly 0 hits happen with probability `1`. There are 0 to 100 throws and `k` is 0 to 200. The answer is compared within 1e-6.

Example: `[0.2, 0.7]`, `1` → `0.62` (0.2 · 0.3 + 0.8 · 0.7).
