# Increasing speed-limit subsequences

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-46?utm_source=github&utm_medium=tasks-repo)**

A driver passed `n` speed-limit signs. The sequence `s` of their values comes from a generator: you get a list `a` of `m` numbers and numbers `x`, `y`, `z`. For `i = 0, 1, …, n − 1` in turn, `s[i]` is the current `a[i mod m]`, and then `a[i mod m]` is replaced with `(x · a[i mod m] + y · (i + 1)) mod z`.

Count the non-empty strictly increasing subsequences of `s`: sets of positions `i1 < i2 < … < it` (`t ≥ 1`) with `s[i1] < s[i2] < … < s[it]`. Sets with the same values at different positions count separately. Return the count modulo `1 000 000 007`.

Limits: `1 ≤ m ≤ 100`, `m ≤ n ≤ 10 000`, `0 ≤ x, y ≤ 10^9`, `1 ≤ z ≤ 10^9`, `0 ≤ a[i] < z`. The product `x · a[i]` reaches `10^18`: use 64-bit arithmetic (in JavaScript, split the multiplication).

Example: `5, 5, 0, 0, 5, [1, 2, 1, 2, 3]` → `15` (here `s = [1, 2, 1, 2, 3]`).
