# P-th bit string under constraints

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-102?utm_source=github&utm_medium=tasks-repo)**

Consider bit strings of length `n` (made of `0` and `1`), positions numbered from 1. You are given a list of constraints: each is a triple `[a, b, c]` meaning that positions `a` through `b` inclusive hold exactly `c` ones. A string is valid if it satisfies every constraint. There are guaranteed to be at least `p` valid strings.

Return the valid string that is `p`-th (counting from 1) in lexicographic order of all valid strings (`0` before `1`).

Limits: `1 ≤ n ≤ 60`, up to 60 constraints, `1 ≤ a ≤ b ≤ n`, `b - a ≤ 9`, `0 ≤ c ≤ n`, `1 ≤ p ≤ 10^15`. With no constraints every string is valid.

Example: `n = 3`, `[[2, 2, 1]]`, `p = 2` → `"011"` (the valid strings are `010`, `011`, `110`, `111`).
