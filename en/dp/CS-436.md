# Longest zigzag subsequence

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-436?utm_source=github&utm_medium=tasks-repo)**

Given a list of numbers `values`. A subsequence is made by deleting any elements without reordering the rest. Call it a zigzag if the differences between its neighbouring elements strictly alternate in sign: plus, minus, plus... or minus, plus, minus... A subsequence of one element is a zigzag, one of two elements is a zigzag if they differ. Return the length of the longest zigzag. For an empty list the answer is 0. Limits: up to 1000 elements.

Every element has two states: the zigzag ends with a rise or with a fall.

Example: `[1, 7, 4, 9, 2, 5]` → `6` (differences +6, -3, +5, -7, +3).
