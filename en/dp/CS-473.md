# Longest run without a sales drop

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-473?utm_source=github&utm_medium=tasks-repo)**

Given a list `sales` with a shop's sales per day, find the length of the longest stretch of consecutive days in which sales never decreased: each day is at least as high as the day before. A single day counts as a stretch. For an empty list return `0`. The list has at most 1000 numbers.

Example: `[5, 3, 4, 4, 7, 2]` → `4` (the stretch `3, 4, 4, 7`).
