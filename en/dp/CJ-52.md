# Pure rank

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-52?utm_source=github&utm_medium=tasks-repo)**

Let S be a set of integers, each at least 2. The rank of a number x in S is its position in S in increasing order, counting from 1. A number x in S is pure with respect to S if the chain "x, rank of x, rank of the rank of x, …" stays inside S until it reaches 1 (1 is never in S). For example, with S = {2, 3, 5} the number 5 is pure: the rank of 5 is 3, the rank of 3 is 2, the rank of 2 is 1.

Given an integer `n` (2 ≤ n ≤ 150), count the subsets S of {2, 3, …, n} that contain n and in which n is pure. Return the count modulo 100003.

Example: `5` → `5` ({5}, {2, 5}, {2, 3, 5}, {3, 4, 5} and {2, 3, 4, 5}).
