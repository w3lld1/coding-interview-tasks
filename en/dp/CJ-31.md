# K-th balanced parentheses

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-31?utm_source=github&utm_medium=tasks-repo)**

A valid parentheses sequence of `n` pairs is a string of `n` characters `(` and `n` characters `)` that can be erased completely by repeatedly removing adjacent pairs `()`. Sort all such strings lexicographically, with `(` smaller than `)`. Return the `k`-th one (counting from 1). If there are fewer than `k` sequences, return the empty string.

Limits: `1 ≤ n ≤ 100`, `1 ≤ k ≤ 9·10^15`. The number of sequences may not fit in 64 bits.

Example: `3`, `4` → `"()(())"`; the five strings for `n = 3` are `((()))`, `(()())`, `(())()`, `()(())`, `()()()`.
