# How many sets give the sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-442?utm_source=github&utm_medium=tasks-repo)**

Given a list of positive integers `values` and a number `target`. Return the number of ways to pick a set of elements whose sum is exactly `target`. Each element is either taken or not and cannot be used twice; sets are told apart by the chosen positions, so equal numbers at different positions give different sets. The empty set has sum 0. Limits: up to 20 elements, values from 1 to 100, `target` from 0 to 1000.

Each element splits the count into two cases: it is in the set (`target - v` remains to be reached) or it is not (`target` remains from the others).

Example: `[1, 1, 1]`, `2` → `3` (any two positions of the three).
