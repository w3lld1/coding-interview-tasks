# Plus and minus to reach a target

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-37?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-negative integers (at most 20 elements, sum at most 1000) and an integer `target`, put a `+` or `-` sign before each number and add everything up. Return the number of sign assignments whose result equals `target`. Assignments differ if the sign differs for at least one list position (zeros get a sign too, so each zero doubles the answer). For an empty list the sum is `0` and there is one empty assignment.

Example: `[1, 1, 1, 1, 1]`, `3` → `5`.
