# Best streak ending on each day

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-478?utm_source=github&utm_medium=tasks-repo)**

Given a list `profits` with a kiosk's profit per day (integers, possibly negative), find for every day `i` the largest total profit of a stretch of consecutive days that ends exactly on day `i` (the stretch contains at least that day and may start on any earlier day). Return the list of these totals, the same length as the input. For an empty list return an empty list. There are at most 1000 days.

Example: `[3, -5, 2, 4, -1]` → `[3, -2, 2, 6, 5]`.
