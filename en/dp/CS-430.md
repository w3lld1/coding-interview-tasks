# Lamp row with no long runs

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-430?utm_source=github&utm_medium=tasks-repo)**

A string of lights has `n` lamps in a row, each on or off. To keep it from dazzling, no `k` or more lamps in a row may be on. Return the number of different rows of `n` lamps that contain no `k` consecutive lamps on. For `n` = 0 there is one row (the empty one). Limits: `n` from 0 to 30, `k` from 1 to 10.

Watch how many lamps are on at the very end of the row: from 0 to `k - 1`. Adding a lamp either resets this run or extends it by one.

Example: `3`, `2` → `5` (000, 001, 010, 100, 101).
