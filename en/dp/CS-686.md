# How many texts a run of key presses can mean

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-686?utm_source=github&utm_medium=tasks-repo)**

On an old keypad phone, letters are typed by repeated presses: keys `2`, `3`, `4`, `5`, `6` and `8` have three letters each, `7` and `9` have four. One press of a key gives its first letter, two in a row the second, and so on; one letter is always typed with presses of a single key. Pauses between letters are not recorded, so a string of presses `presses` (digits `2` to `9`) may mean different texts: for example, `"22"` is two first letters of the key or one second letter. Return the number of different texts the string `presses` may mean. An empty string means one empty text. The string has 0 to 40 characters; the answer may not fit in 32 bits.

Example: `"22233"` → `8` (`222` splits into letters in four ways: 1+1+1, 1+2, 2+1, 3; `33` in two).
