# Count minimum-sum paths in a triangle

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-147?utm_source=github&utm_medium=tasks-repo)**

Given a triangle of numbers: row `i` (from zero) has exactly `i + 1` numbers, and numbers may be negative. A path starts at the only number of the first row and steps one row down each time: from position `j` to position `j` or `j + 1` of the next row. The sum of a path is the sum of all numbers it visits. Return how many different paths (from the top to the last row) have the smallest possible sum. Paths differ by their chosen positions. For an empty triangle return `0`. There are at most 20 rows.

Example: `[[1], [2, 2], [3, 1, 3]]` → `2` (the minimum sum 4: the path 1 → 2 → 1 can go through either of the two 2s; and `[[1], [2, 2], [3, 3, 3]]` → `4`).
