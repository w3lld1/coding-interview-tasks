# Run with a positive product

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-441?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers `values`. Return the length of the longest contiguous segment whose product is strictly greater than zero. A segment holding a single positive number qualifies. If there is no such segment (for example, the list is empty or consists of zeros), the answer is 0. You do not need to multiply the numbers: only the sign matters. Limits: up to 1000 elements, values up to 1000 in absolute value.

A zero breaks a segment. For each position keep the length of the longest segment that ends here with a positive product, and the same with a negative product.

Example: `[1, -2, -3, 4]` → `4` (two negatives make a positive).
