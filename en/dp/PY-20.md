# Knapsack

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-20?utm_source=github&utm_medium=tasks-repo)**

Given a knapsack's weight capacity and a list of items, where each item is a map with the keys "weight" and "value", both positive. Each item may be taken at most once, and the total weight must not exceed the capacity. Return the maximum total value of a valid selection; if no item fits, the answer is zero.
