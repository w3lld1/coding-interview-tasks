# Mushroom colony

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-440?utm_source=github&utm_medium=tasks-repo)**

At the start of month 0 a lab receives one newborn pair of mushrooms. A pair matures `maturity` months after its birth; from the month it matures, every mature pair produces one new pair at the end of each month (it appears in that same month). Pairs never die. Return the number of pairs at the end of month `months`, counting that month's newborns. Limits: `months` from 0 to 40, `maturity` from 1 to 40.

The number of pairs in month `t` is last month's pairs plus the new pairs made by every pair born no later than month `t - maturity`.

Example: `6`, `2` → `13` (1, 1, 2, 3, 5, 8, 13).
