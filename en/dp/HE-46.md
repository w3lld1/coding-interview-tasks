# Fib4 sequence

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-46?utm_source=github&utm_medium=tasks-repo)**

The Fib4 sequence is defined as follows: `fib4(0) = 0`, `fib4(1) = 0`, `fib4(2) = 2`, `fib4(3) = 0`, and for `n ≥ 4` the value is the sum of the four previous ones: `fib4(n) = fib4(n-1) + fib4(n-2) + fib4(n-3) + fib4(n-4)`. Compute `fib4(n)` for `n ≥ 0` without recursion and without recomputing the same values.

Example: `6` → `8`.
