# Decode a digit string

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-31?utm_source=github&utm_medium=tasks-repo)**

Letters map to numbers: `A` = 1, `B` = 2, …, `Z` = 26. Given a non-empty string of digits (at most 40 characters), split it into consecutive parts so that every part is the number of a letter, written without a leading zero (`06` is not allowed, and neither is `0`). Return the number of ways to do this, or `0` if there is none.

Example: `"226"` → `3` (`2|2|6`, `22|6`, `2|26`).
