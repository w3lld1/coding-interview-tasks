# Most profitable non-overlapping jobs

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-189?utm_source=github&utm_medium=tasks-repo)**

You are given three lists of equal length: job `i` starts at time `start[i]`, ends at time `end[i]` (`start[i] < end[i]`) and pays `profit[i]`. Only one job can run at a time; the next one may start exactly when the previous one ends. Choose a set of jobs, no two of which overlap in time, with the largest total profit, and return that total. If there are no jobs, return `0`. There are up to 20 000 jobs, times are from 0 to 10⁹ and profits from 1 to 10 000.

Example: `[1, 2, 3, 3]`, `[3, 4, 5, 6]`, `[50, 10, 40, 70]` → `120` (jobs 0 and 3).
