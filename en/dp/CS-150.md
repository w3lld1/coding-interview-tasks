# How many binary strings fit the budget

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-150?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-empty strings made of the characters `0` and `1`, and two non-negative integers `m` and `n` — a supply of zeros and a supply of ones. Choosing a string spends as many zeros and ones as it contains; neither supply may go below zero. Each string of the list can be chosen at most once (equal strings in the list are different elements). Return the greatest number of strings you can choose. Limits: up to 600 strings, `m` and `n` up to 100. If no string fits, return `0`.

Example: `["10", "0001", "111001", "1", "0"]`, `m = 5`, `n = 3` → `4` (take `"10"`, `"0001"`, `"1"`, `"0"`: zeros 1 + 3 + 0 + 1 = 5, ones 1 + 1 + 1 + 0 = 3).
