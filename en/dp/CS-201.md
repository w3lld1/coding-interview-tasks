# Eggs and the critical floor

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-201?utm_source=github&utm_medium=tasks-repo)**

A building has floors numbered `1` to `floors`. There is a critical floor `c` between `0` and `floors`: an egg dropped from above floor `c` breaks, and one dropped from floor `c` or below does not. You have `eggs` identical eggs. An unbroken egg can be dropped again, a broken one cannot. Return the smallest number of drops that is guaranteed to find `c` whatever its value turns out to be.

Limits: `1 ≤ eggs ≤ 100`, `0 ≤ floors ≤ 1,000,000,000`. With no floors (`floors = 0`) the answer is `0`. With one egg you must go up floor by floor, so the answer is `floors`.

Example: `2`, `10` → `4`.
