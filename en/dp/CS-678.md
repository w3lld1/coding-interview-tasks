# A lamp row: off lamps first, then lit ones

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-678?utm_source=github&utm_medium=tasks-repo)**

A row of lamps is a string `lamps` of `'0'` (off) and `'1'` (on). One toggle changes the state of any one lamp. Every off lamp must come before every lit lamp: the string must look like "only `0`, then only `1`" (either part may be empty). Return the fewest toggles needed. The string has 0 to 10,000 characters; for an empty string the answer is `0`.

Example: `"00110"` → `1` (turn the last lamp on: `"00111"`).
