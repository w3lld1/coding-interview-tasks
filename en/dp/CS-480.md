# Climbs along a trail profile

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-480?utm_source=github&utm_medium=tasks-repo)**

Given a list `heights` with the heights of consecutive points on a hiking trail. A climb is a continuous stretch of the trail (consecutive points) in which every height is strictly greater than the one before. A stretch of one point is also a climb. Stretches with a different start or end are different climbs. Return the number of climbs. For an empty list return `0`. There are at most 1000 points.

Example: `[1, 2, 3, 1, 2]` → `9` (five single points, three of two points: `1,2`, `2,3`, `1,2`, and one `1,2,3`).
