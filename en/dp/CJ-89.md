# Unlock the combination lock

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-89?utm_source=github&utm_medium=tasks-repo)**

A combination lock has `n` dials in a row; each dial shows a number from `0` to `size − 1`, the starting values are in the list `dials`. The lock opens when every dial shows `0`.

One operation picks a range of consecutive dials `[l, r]` and turns all of them together one step up (`+1`) or down (`−1`), wrapping around: `size − 1` is followed by `0`, and `0` is preceded by `size − 1`. Each operation's range must fully contain the previous operation's range (`l` no further right and `r` no further left than before); the first range is free.

Return the minimum number of operations that opens the lock. There are 1 to 200 dials and `2 ≤ size ≤ 10^9`, so the number of turns made so far cannot be part of a search state.

Example: `[1, 1, 9, 9, 1, 1]`, `10` → `3` (raise dials 3–4 twice, then lower the whole row).
