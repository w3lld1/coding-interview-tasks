# Can the token reach the last cell

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-482?utm_source=github&utm_medium=tasks-repo)**

A strip of cells is numbered from 0 and a list `jumps` gives a number `jumps[i]` (an integer, at least 0) written in cell `i`. A token stands on cell 0. From cell `i` it may move forward by any number of cells from 1 to `jumps[i]` (with `0` it cannot move), but not past the end of the strip. Return `true` if the token can land on the last cell, otherwise `false`. The list has 1 to 1000 numbers; with one cell the answer is `true`.

Example: `[2, 3, 0, 0, 1]` → `true` (0 → 1 → 4), while `[2, 0, 1, 0, 4]` → `false`.
