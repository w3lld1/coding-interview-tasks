# Graceful chainsaw jugglers

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-76?utm_source=github&utm_medium=tasks-repo)**

You have `red` red and `blue` blue chainsaws (`0 ≤ red, blue ≤ 100`, `red + blue > 0`) and any number of jugglers. All chainsaws must be handed out: each performing juggler gets a pair of numbers (how many red and how many blue chainsaws), at least one chainsaw each, and no two jugglers get the same pair. In other words, pick a set of distinct pairs `(r, b)` of non-negative integers other than `(0, 0)` whose first numbers sum to exactly `red` and second numbers to exactly `blue`.

Return the largest possible number of jugglers (the size of such a set).

Example: `4`, `5` → `5` (pairs `(1,0)`, `(2,0)`, `(0,1)`, `(0,3)`, `(1,1)`).
