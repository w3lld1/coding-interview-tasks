# A printer that prints runs

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-203?utm_source=github&utm_medium=tasks-repo)**

A printer works on a tape as long as the target string. In one turn it picks any contiguous range of positions and one letter and paints the whole range with that letter, overwriting what was there. The tape starts blank. Given a string `s` of lowercase Latin letters, up to 100 long, return the smallest number of turns after which the tape reads exactly `s`. For the empty string the answer is `0`.

Example: `"abcba"` → `3` (first `aaaaa`, then `abbba`, then `abcba`).
