# Two berry pickers on a field

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-188?utm_source=github&utm_medium=tasks-repo)**

A field is a rectangular table `grid` (at least 1 × 1): `1` is a cell with a berry, `0` an empty cell, `-1` a thorn bush that cannot be entered. Two pickers start in the top-left cell and walk to the bottom-right one, each moving only right or down and only through cells without a bush. Each picks the berries in the cells of its path, but a berry in a cell both of them visit counts once. Return the largest number of berries they can pick together. If there is no path from corner to corner (including a bush in the first or last cell), return `0`. The table is up to 50 × 50.

Example: `[[0, 1, -1], [1, 0, -1], [1, 1, 1]]` → `5` (one goes right, down, down, right, the other down, down, right, right).
