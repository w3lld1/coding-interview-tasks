# Largest sum divisible by three

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-450?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-negative integers `values`. Choose any set of its elements (possibly empty, possibly all) so that the chosen sum is divisible by 3 and as large as possible, and return that sum. The empty set has sum 0, so an answer always exists. Limits: up to 1000 elements, values from 0 to 10 000.

What matters is not the set but the remainder of its sum modulo 3: keep, for each remainder, the largest reachable sum.

Example: `[3, 6, 5, 1, 8]` → `18` (3 + 6 + 1 + 8).
