# Grid routes around obstacles

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-32?utm_source=github&utm_medium=tasks-repo)**

Given a rectangular grid (from 1×1 to 12×12): `0` is a free cell, `1` is an obstacle. A token starts in the top-left cell and must reach the bottom-right one, moving one step right or down per move and never entering an obstacle. Return the number of distinct routes. If the top-left or bottom-right cell is an obstacle, there are no routes and the answer is `0`.

Example: `[[0, 0, 0], [0, 1, 0], [0, 0, 0]]` → `2`.
