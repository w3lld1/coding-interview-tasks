# Shortest closed route through all cities

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Trees and graphs](../trees-graphs/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-86?utm_source=github&utm_medium=tasks-repo)**

You are given a square matrix `dist` of size n × n (1 ≤ n ≤ 12): `dist[i][j]` is the cost of travelling from city `i` to city `j` (an integer from 0 to 10^6, `dist[i][i] = 0`; the matrix need not be symmetric). A courier starts in city 0, visits every other city exactly once and comes back to city 0. Return the smallest possible total cost of such a route. With a single city the route is empty and the answer is `0`.

Example: `[[0, 1, 15, 6], [2, 0, 7, 3], [9, 6, 0, 12], [10, 4, 8, 0]]` → `21` (0 → 1 → 3 → 2 → 0 costs 1 + 3 + 8 + 9 = 21).
