# Bitwise AND lottery

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-63?utm_source=github&utm_medium=tasks-repo)**

A lottery picks the winning number like this: the first machine produces an integer `x` with `0 ≤ x < a`, the second an integer `y` with `0 ≤ y < b`, and the number is their bitwise AND `x & y`. You bought every ticket from `0` to `k - 1`. Return how many ordered pairs `(x, y)` make you win, that is `x & y < k`. The pairs `(0, 1)` and `(1, 0)` are different.

Limits: `1 ≤ a, b, k ≤ 9·10^7`. Checking every pair is too slow: the answer can reach `8·10^15` and does not fit in 32 bits.

Example: `3`, `4`, `2` → `10` (every pair except `(2, 2)` and `(2, 3)`).
