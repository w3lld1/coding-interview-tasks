# Permuting blocks before RLE

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-47?utm_source=github&utm_medium=tasks-repo)**

You get a number `k` and a string `text` of lowercase Latin letters whose length is a multiple of `k`. The string splits into blocks of `k` consecutive letters. Choose a permutation `p` of the positions `1..k` and apply it to every block (the same one to all): the `j`-th letter of the new block is the `p[j]`-th letter of the old one. For example, the permutation `[3, 1, 4, 2]` turns `"abcdefgh"` into `"cadbgehf"`.

The compressed size of a string is the number of maximal groups of consecutive equal letters: for `"aabcaaaa"` it is 4. Return the smallest compressed size any permutation achieves.

Limits: `1 ≤ k ≤ 10`, the string length is between `k` and 2000.

Example: `4`, `"abcabcabcabc"` → `7`.
