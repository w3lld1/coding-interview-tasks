# Dice totals

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-431?utm_source=github&utm_medium=tasks-repo)**

You roll `dice` ordinary six-sided dice with faces 1 to 6. The dice are told apart by position, so the outcome `(1, 2)` differs from `(2, 1)`. Return the number of outcomes whose total is exactly `target`. For `dice` = 0 the total is 0: with `target` = 0 there is one outcome, for any other `target` none. If `target` is negative or too large, the answer is 0. Limits: `dice` from 0 to 8, `target` at most 60.

Look at the last die: if it shows `f`, the other `dice - 1` dice must give `target - f`.

Example: `2`, `7` → `6` (1+6, 2+5, 3+4, 4+3, 5+2, 6+1).
