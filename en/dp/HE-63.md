# FibFib sequence

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-63?utm_source=github&utm_medium=tasks-repo)**

The FibFib sequence is like the Fibonacci numbers, but each term is the sum of the three previous ones: `f(0) = 0`, `f(1) = 0`, `f(2) = 1`, and `f(n) = f(n-1) + f(n-2) + f(n-3)` for `n ≥ 3`. Compute `f(n)` for a given `n ≥ 0` efficiently: it must run fast for `n` around 30.

Example: `5` → `4` (the sequence is 0, 0, 1, 1, 2, 4).
