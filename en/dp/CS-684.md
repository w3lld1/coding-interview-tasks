# Longest chain of tiles in order

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-684?utm_source=github&utm_medium=tasks-repo)**

Tiles lie in a row, each with two numbers, a left and a right one: `tiles[i] = [left, right]`. Pick some tiles keeping their order in the row (they need not be next to each other) so that for every picked tile except the first, its left number equals the right number of the previously picked tile. Tiles cannot be turned around. Return the largest number of tiles in such a chain; a single tile is a chain too, and for an empty row the answer is `0`. There are 0 to 10,000 tiles with numbers from 0 to 10^6.

Example: `[[1, 2], [5, 6], [2, 3], [7, 7], [3, 1]]` → `3` (tiles `[1, 2]`, `[2, 3]`, `[3, 1]`).
