# A garland without long runs

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-484?utm_source=github&utm_medium=tasks-repo)**

A garland holds `n` flags, each red (`R`) or blue (`B`). No `k` flags in a row may have the same colour. Return the number of different garlands (the order of flags matters). `n` is from 1 to 30, `k` from 2 to 30.

Example: `3`, `3` → `6` (all eight strings of length 3 except `RRR` and `BBB`); `4`, `4` → `14`; with `k = 2` the colours alternate, so there are only two garlands.
