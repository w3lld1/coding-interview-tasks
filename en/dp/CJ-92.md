# Discarding card triples

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-92?utm_source=github&utm_medium=tasks-repo)**

Cards with numbers lie in a row from left to right, and a number `k ≥ 0` is given. One move removes three cards that are currently adjacent if their numbers `a, b, c` (left to right) satisfy `b − a = c − b = k`; the remaining cards then close the gap. Moves may be made in any order, any number of times. Return the smallest number of cards that can remain. The row holds 1 to 100 cards.

Example: `[3, 1, 2, 3, 4]`, `k = 1` → `2` (remove `1, 2, 3`, leaving `3` and `4`).
