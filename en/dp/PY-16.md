# Change

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-16?utm_source=github&utm_medium=tasks-repo)**

Given a set of positive denominations and a target amount, find the combination with the smallest total number of coins. An unlimited number of coins of each denomination is available, and the result must be returned as a list of denominations in ascending order. For a zero amount, return an empty list; for a negative or unreachable amount, report an error: throw an exception, or return an error in Go. The denominations are arbitrary, so picking the largest coin that fits does not guarantee a correct answer.
