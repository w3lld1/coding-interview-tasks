# Down to one: halve or step

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-681?utm_source=github&utm_medium=tasks-repo)**

A display shows a whole number `n`. Each move changes it by the rule: an even number is halved, and an odd number (greater than 1) may be either increased by 1 or decreased by 1, as you choose. Return the fewest moves after which the display shows `1`. For `n = 1` the answer is `0`. `n` is from 1 to 2,147,483,647 (`2^31 - 1`), so the intermediate `n + 1` may not fit in a 32-bit number.

Example: `15` → `5` (15 → 16 → 8 → 4 → 2 → 1).
