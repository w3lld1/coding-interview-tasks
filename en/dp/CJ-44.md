# Touchbar Typing

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-44?utm_source=github&utm_medium=tasks-repo)**

A keyboard is a single row of M keys; key `j` (from zero) carries the character `keyboard[j]`, characters are integers, and the same character can appear on several keys. You must type the word `word` (N characters), one character after another in order; every character of the word occurs on the keyboard.

You may put your finger on any key at the start. Moving the finger from key `i` to key `j` takes `|j − i|` seconds, and there are no key presses: while the finger rests on key `x`, you can type its character `keyboard[x]` any number of times instantly. Return the smallest time in which the word can be typed (N, M ≤ 2500).

Example: `[1, 2, 3, 2, 1]`, `[3, 1, 2, 3]` → `4`.
