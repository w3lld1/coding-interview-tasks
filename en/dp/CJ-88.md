# Ball collecting robot

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Hash maps and sets](../hashing/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-88?utm_source=github&utm_medium=tasks-repo)**

Stations stand on an infinite line, numbered …, −2, −1, 0, 1, 2, …; station 0 holds a warehouse. You are given a list `balls`: each element `[x, s]` is a ball at station `x` (`x ≠ 0`, all `x` distinct) of shape `s` (`0` or `1`). A robot starts at station 0 with two compartments: one holds one ball of shape 0, the other one ball of shape 1.

Moving to a neighbouring station costs 1 unit of power. Picking up a ball at the current station into the free compartment of its shape is free. Compressing a ball at the current station, which switches its shape, costs `compress_cost` (a ball already in a compartment cannot be changed). At station 0 the robot can unload all carried balls into the warehouse for free.

Return the minimum power needed to bring every ball to the warehouse. There are up to a few thousand balls, positions are up to `10^9` in absolute value, `0 ≤ compress_cost ≤ 10^9`. An empty list gives `0`.

Example: `[[3, 0], [6, 0], [8, 0], [10, 1], [15, 1]]`, `10` → `56`.
