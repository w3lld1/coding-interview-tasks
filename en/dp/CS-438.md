# Countdown to one

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-438?utm_source=github&utm_medium=tasks-repo)**

Given a positive integer `n`. One move does one of three things: subtract 1; divide by 2 if the number is even; divide by 3 if it is divisible by 3. Return the smallest number of moves that turns `n` into 1. For `n` = 1 the answer is 0. Limits: `n` from 1 to 10 000.

A greedy choice ("always divide when possible") fails here; you need a table of answers for all smaller numbers. The same can be written as a memoised recursion: the answer for `m` is one more than the best answer among the numbers one move leads to.

Example: `10` → `3` (10 → 9 → 3 → 1).
