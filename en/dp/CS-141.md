# Interleaving of two strings

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-141?utm_source=github&utm_medium=tasks-repo)**

Given three strings `s1`, `s2`, `s3` (each up to 100 characters), return `true` if `s3` is an interleaving of `s1` and `s2`: characters of both strings are taken one at a time, each string is read left to right with no skips or reordering, and every character of both is used exactly once. Otherwise return `false`. Empty strings are allowed: three empty strings give `true`.

Example: `"ab"`, `"cd"`, `"acbd"` → `true`; `"ab"`, `"cd"`, `"abdc"` → `false`.
