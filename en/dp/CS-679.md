# Ski runs between the trees

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-679?utm_source=github&utm_medium=tasks-repo)**

A slope is a list of strings `slope` of equal length: each string is a row from top to bottom, each character a cell, `'.'` is free and `'#'` is a tree. The skier stands in the top row in cell `start` (cells in a row are numbered from 0). Each step goes one row down: into the same column or the one just left or right of it. Leaving the slope and riding into trees is not allowed. Return the number of different routes that reach the bottom row (any of its cells). If the start cell has a tree, the answer is `0`; with one row and a free start there is one route. There are 1 to 30 rows of width 1 to 10.

Example: `["...", "..."]`, `0` → `2`.
