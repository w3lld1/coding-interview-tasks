# Passwords from fingerprints

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-30?utm_source=github&utm_medium=tasks-repo)**

A password is made of `length` keystrokes. The fingerprints show that exactly `keys` particular keys were used and each of them was pressed at least once; no other keys appear. Every keystroke gives one character. How many different passwords are possible? Return the answer modulo 1000000007. If `keys` is greater than `length`, the answer is `0`.

Limits: `1 ≤ keys, length ≤ 100`.

Example: `3`, `4` → `36` (keys 3, 7 and 5 and a four-character password: one key is pressed twice, the others once).
