# Fewest cuts into palindromes

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-89?utm_source=github&utm_medium=tasks-repo)**

Given a string `s` of lowercase Latin letters (length 0 to 1000), cut it into non-empty pieces so that every piece is a palindrome (reads the same left to right and right to left). Return the smallest number of cuts. A string that is itself a palindrome gives `0`, and so do the empty string and a one-character string.

Example: `"abacc"` → `1` (`"aba" | "cc"`).
