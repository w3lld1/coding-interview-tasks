# Cards with alternating signs

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-677?utm_source=github&utm_medium=tasks-repo)**

In a TV game, cards with numbers `cards` lie in a row. The player picks any of them, keeping their order (picking none is allowed). The score is counted like this: the first picked card is added, the second is subtracted, the third is added again and so on, the signs alternate. Return the largest possible score; if nothing is picked, the score is `0`. There are 0 to 1000 cards with numbers from -1000 to 1000.

Example: `[4, 2, 5, 3]` → `7` (pick 4, 2, 5: 4 - 2 + 5).
