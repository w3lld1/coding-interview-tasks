# Copy and paste

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-429?utm_source=github&utm_medium=tasks-repo)**

A text editor shows a single letter `A`. Two commands exist: "select all and copy" (the clipboard gets everything on screen) and "paste" (append the clipboard to the end). Each command is one keystroke. Copying several times in a row is allowed but it only overwrites the clipboard. Return the smallest number of keystrokes after which the screen holds exactly `n` letters `A`. For `n` = 1 the answer is 0. Limits: `n` from 1 to 1000.

The last series of pastes starts by copying a text of `j` letters, where `j` divides `n`: the screen then grows from `j` to `n`.

Example: `6` → `5` (copy, paste, paste gives three letters in 3 keystrokes; copy, paste gives six, 5 in total).
