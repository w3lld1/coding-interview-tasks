# Three-colour tile row

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-447?utm_source=github&utm_medium=tasks-repo)**

A path of `n` tiles in a row is to be laid with tiles of three colours: red, green and blue. Two red tiles may not be next to each other; there are no other restrictions. Return the number of different rows. For `n` = 0 there is one row (the empty one). Limits: `n` from 0 to 18.

Look at the last tile: if it is red, the one before must not be red; otherwise it is one of the two non-red colours, and anything may stand before it.

Example: `2` → `8` (nine colour pairs, minus red-red).
