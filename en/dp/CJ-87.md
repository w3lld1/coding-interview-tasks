# Weights on a stack machine

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Dynamic programming](../dp/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-87?utm_source=github&utm_medium=tasks-repo)**

A workout is a sequence of exercises done strictly in order. There are `w` kinds of weights; exercise `i` is given by a list `exercises[i]` of length `w`: `exercises[i][j]` is how many weights of kind `j` must be on the machine (every exercise needs at least one weight).

The weights on the machine form a stack. One operation either puts any weight on top of the stack or removes the top weight. Before each exercise the stack must hold exactly the required weights (in any order). The stack starts empty and must be empty again after the last exercise.

Return the minimum number of operations to do all the exercises. There are up to 60 exercises and up to 20 kinds of weights.

Example: `[[1, 2, 1], [2, 1, 2]]` → `12`.
