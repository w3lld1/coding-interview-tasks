# Search in a rotated list

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-49?utm_source=github&utm_medium=tasks-repo)**

A list of distinct integers sorted in ascending order was cyclically rotated by an unknown number of positions (for example, `[0, 1, 2, 4, 5, 6, 7]` may have become `[4, 5, 6, 7, 0, 1, 2]`; a rotation by 0 is possible). Given such a list (up to 100000 elements) and a number `target`, return the index of `target` or `-1` if it is absent. For an empty list the answer is `-1`. An O(log n) solution is expected.

Example: `[4, 5, 6, 7, 0, 1, 2]`, `0` → `4`.
