# Version number "major.minor.patch"

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-335?utm_source=github&utm_medium=tasks-repo)**

A program version is written as `major.minor.patch`: exactly three numbers separated by dots. Each number is the decimal form of a non-negative integer without sign and spaces, without leading zeros (the number 0 is the single digit `0`) and at most six digits long.

Return a list of three integers `[major, minor, patch]`. If the text does not match the format (not three parts, an empty part, a leading zero, a stray character such as `v`, a number that is too long), report an error: throw an exception, or return an error in Go.

Example: `"1.2.3"` → `[1, 2, 3]`; `"10.0.30"` → `[10, 0, 30]`; `"1.02.3"` → error; `"1.2"` → error.
