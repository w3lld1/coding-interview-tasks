# Config line "key = value"

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-326?utm_source=github&utm_medium=tasks-repo)**

A settings loader reads a file line by line. A line must look like `key = value`. Split it at the FIRST `=`: everything before it is the key, everything after is the value (the value may be empty and may contain more `=`). Strip spaces (the space character only) from both ends of the key and of the value.

A key is valid if it is not empty, starts with a Latin letter or `_`, and all its other characters are Latin letters, digits or `_`. If the line has no `=` or the key is invalid, report an error: throw an exception, or return an error in Go.

Return a list of two strings: the key and the value.

Example: `"  port =  8080 "` → `["port", "8080"]`; `"path=/a=b"` → `["path", "/a=b"]`; `"1abc=2"` → error.
