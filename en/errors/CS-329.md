# Hex colour "#RRGGBB" to numbers

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-329?utm_source=github&utm_medium=tasks-repo)**

A designer sends a colour as `#RRGGBB`: the `#` character and exactly six hexadecimal digits (`0`-`9`, `a`-`f`, `A`-`F`, any case). The first two digits are the red channel, the next two the green one, the last two the blue one.

Return a list of three integers `[red, green, blue]`, each from 0 to 255. If the text does not match the format (no `#`, not six digits, any other characters, spaces included), report an error: throw an exception, or return an error in Go.

Example: `"#FF8000"` → `[255, 128, 0]`; `"#1a2B3c"` → `[26, 43, 60]`; `"FF8000"` → error.
