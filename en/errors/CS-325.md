# Safe element-wise division

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-325?utm_source=github&utm_medium=tasks-repo)**

You get two lists of numbers of the same length: dividends and divisors. Return a list where each position holds the ordinary (not integer) quotient of the dividend and the divisor at that position.

If the lists have different lengths or any divisor is zero (at any position, even the last), report an error: throw an exception, or return an error in Go. Two empty lists give an empty list.

Example: `[10, 9, 7]`, `[2, 3, 2]` → `[5, 3, 3.5]`; `[4, 5]`, `[2, 0]` → error.
