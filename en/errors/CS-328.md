# Exam average with validation

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-328?utm_source=github&utm_medium=tasks-repo)**

A teacher collected the exam scores. Each score is an integer from 0 to 100 inclusive. Return the average score: the sum divided by the count (ordinary division, not integer division).

If the list is empty (there is no average) or at least one score is outside 0 to 100, report an error: throw an exception, or return an error in Go.

Example: `[80, 90, 100]` → `90`; `[70, 71]` → `70.5`; `[]` → error; `[50, 101]` → error.
