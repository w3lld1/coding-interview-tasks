# List items by indexes

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-332?utm_source=github&utm_medium=tasks-repo)**

You get a list of strings `items` and a list of indexes `indexes`. Return a list of strings: for each index in order, the element of `items` at that index. Indexes count from zero; a negative index counts from the end: `-1` is the last element, `-2` the one before it, and so on. Indexes may repeat.

Valid indexes run from `-n` to `n - 1`, where `n` is the length of `items`. If any index is outside that range, report an error: throw an exception, or return an error in Go. An empty `indexes` gives an empty result, even if `items` is empty too.

Example: `["a", "b", "c", "d"]`, `[-1, 0]` → `["d", "a"]`; `["a", "b", "c"]`, `[1, 3]` → error.
