# Spreadsheet column number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Strings](../strings/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-336?utm_source=github&utm_medium=tasks-repo)**

In spreadsheets columns are named with letters: `A` is the first, `B` the second, …, `Z` the 26th, then `AA` is 27th, `AB` 28th, …, `AZ` 52nd, `BA` 53rd and so on (like a base-26 number system without a zero).

Given a column name, return its number, counting from 1. A name is valid if it consists of 1 to 4 uppercase Latin letters `A`-`Z`. If the name is empty, longer than four letters, or contains anything but uppercase letters (lowercase letters, digits, spaces, other characters), report an error: throw an exception, or return an error in Go.

Example: `"A"` → `1`; `"AB"` → `28`; `"ZZ"` → `702`; `"a"` → error.
