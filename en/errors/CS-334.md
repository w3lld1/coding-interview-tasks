# Coordinates "lat,lon"

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-334?utm_source=github&utm_medium=tasks-repo)**

A navigator gets a point as the string `"lat,lon"`: exactly two numbers separated by one comma, with no spaces. Each number is an optional minus sign, one or more digits of the whole part and an optional fraction: a dot and one or more digits. A plus sign, spaces, an exponent and forms such as `.5` or `1.` are invalid.

The latitude must be between -90 and 90 and the longitude between -180 and 180, bounds included. Return a list `[lat, lon]`. If the string does not match the format or a number is out of range, report an error: throw an exception, or return an error in Go.

Example: `"55.75,37.62"` → `[55.75, 37.62]`; `"90,180"` → `[90, 180]`; `"90.5,10"` → error; `"10, 20"` → error.
