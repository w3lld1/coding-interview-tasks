# Stock left after orders

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-333?utm_source=github&utm_medium=tasks-repo)**

A shop warehouse holds `stock` items of one product. Orders are processed strictly in order; an order is the number of items to ship. A processed order lowers the stock.

Return a list: the stock left after each order.

If the starting stock is negative, any order is below 1, or any order is bigger than the current stock (not enough items), report an error: throw an exception, or return an error in Go. An order for exactly the whole stock is valid. With no orders the result is empty (for a valid stock, zero included).

Example: `10`, `[3, 2, 5]` → `[7, 5, 0]`; `10`, `[6, 5]` → error.
