# Price string to cents

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-324?utm_source=github&utm_medium=tasks-repo)**

A till program gets a price as a string and must turn it into a whole number of cents. A valid price is: an optional `$` at the start, then 1 to 7 digits of the whole part, then an optional fraction: a dot followed by 1 or 2 digits. A single digit after the dot means tens of cents (`12.5` is 12 dollars 50 cents). Nothing else is allowed: no spaces, no minus sign, no comma, no dot without digits after it, no fraction without a whole part.

Return the price in cents. If the text does not match this format, report an error: throw an exception, or return an error in Go.

Example: `"$12.50"` → `1250`; `"7"` → `700`; `"12.505"` → error.
