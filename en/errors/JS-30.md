# Error Handling

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-30?utm_source=github&utm_medium=tasks-repo)**

Implement processString(input): for a non-string argument, throw TypeError, and for an empty string, return null. A non-empty string shorter than 10 or longer than 100 code units must cause a RangeError; after the length check, a mix of Latin letters and decimal digits in one string must cause a SyntaxError. If validation passes, return the string in upper case, and give every exception a non-empty message.
