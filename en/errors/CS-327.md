# Length unit conversion

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-327?utm_source=github&utm_medium=tasks-repo)**

Convert a length from one unit to another. Seven units are known (names are lowercase): `mm` is 0.001 m, `cm` is 0.01 m, `m` is 1 m, `km` is 1000 m, `in` is 0.0254 m, `ft` is 0.3048 m, `mi` is 1609.344 m.

You get a number `value`, the unit `from_unit` it is written in and the unit `to_unit` to convert it to. Return the length in the new unit. If either unit is unknown (case matters, and an empty string is unknown) or `value` is below zero, report an error: throw an exception, or return an error in Go. Zero is allowed.

Example: `5`, `"km"`, `"m"` → `5000`; `12`, `"in"`, `"cm"` → `30.48`; `1`, `"yd"`, `"m"` → error.
