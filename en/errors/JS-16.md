# Factory Sensors

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Errors and exceptions](../errors/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-16?utm_source=github&utm_medium=tasks-repo)**

Implement a humidity check: a value above 70 must cause an exception, and other values must return undefined. The temperature check must throw ArgumentError for null and OverheatingError with a stored temperature field for temperatures above 500. The monitor calls actions.check and calls alertDeadSensor on ArgumentError, alertOverheating on overheating at no more than 600, and shutdown above 600. Unknown exceptions must be rethrown, and a successful check requires no further action.
