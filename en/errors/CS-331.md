# Integer list from a string

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Errors and exceptions](../errors/), [Parsing and validation](../parsing/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-331?utm_source=github&utm_medium=tasks-repo)**

A user types numbers separated by commas, for example `"1, 2, -3"`. Convert the string into a list of integers in the same order.

Rules. The string is split by commas into items. Spaces (the space character only) around an item are dropped. An item is an optional minus sign and 1 to 9 digits; a plus sign, spaces inside the number, a fraction and any other characters are invalid. Leading zeros are allowed. An empty item (for example in `"1,,2"` or after a trailing comma) is an error. A string that is empty or consists only of spaces gives an empty list.

On any violation report an error: throw an exception, or return an error in Go.

Example: `"1, 2, -3"` → `[1, 2, -3]`; `""` → `[]`; `"1,,2"` → error; `"1.5, 2"` → error.
