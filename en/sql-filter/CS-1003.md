# Each facility's busiest hour

**Difficulty:** hard · **Language:** SQL (SQLite) · **Topics:** [SQL: filtering](../sql-filter/), [SQL: aggregation](../sql-aggregate/), [SQL: joins](../sql-join/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-1003?utm_source=github&utm_medium=tasks-repo)**

Call a booking's hour the hour of its start, `strftime('%H', starttime)`. For each facility find the hour with the most booked slots (all bookings, including the guest's); when there is a tie, output all such hours. Output the columns `facility` (the facility's name), `hour`, `slots` (that hour's slots) and `percent`, the percentage of all the facility's slots that falls on that hour, rounded to one decimal. The row order does not matter.

The tables and data are already in the starter code and are created afresh on every run (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — club facilities; `membercost` and `guestcost` are the price of one slot for a member and for a guest.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — members; `recommendedby` is the `memid` of who invited them, or `NULL`; `memid = 0` is a guest.
- `bookings(bookid, facid, memid, starttime, slots)` — bookings; one slot is 30 minutes; `starttime` is text such as `2012-09-14 09:00:00`.
