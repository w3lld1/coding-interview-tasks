# Everything a task needs

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-414?utm_source=github&utm_medium=tasks-repo)**

A project has `n` tasks numbered `0…n-1`. The list `deps` holds pairs `[a, b]`: «task `a` requires task `b` to be done earlier». The dependencies have no cycles, and pairs may repeat.

Return how many different tasks must be done before task `task`: those it depends on directly, those they depend on, and so on. `task` itself does not count.

Example: `5`, `[[0, 1], [1, 2], [0, 3]]`, `0` → `3` (tasks 1, 2, 3).
