# Is the org chart valid

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-396?utm_source=github&utm_medium=tasks-repo)**

The list `parent` describes a company org chart: `parent[i]` is the index of the boss of employee `i`, and `-1` means "no boss". The chart is valid if exactly one employee has no boss, every boss index is in the range `0…n-1`, nobody is their own boss, and from every employee you can climb up to the root (no cycles). Return `true` for a valid chart, otherwise `false`. An empty list is invalid: it has no root.

Example: `[-1, 0, 1]` → `true`; `[-1, 2, 1]` → `false` (employees 1 and 2 report to each other).
