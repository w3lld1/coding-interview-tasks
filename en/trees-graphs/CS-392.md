# Number of generations

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-392?utm_source=github&utm_medium=tasks-repo)**

A family tree. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. The root is the ancestor, their children are the second generation, and so on. Return the number of generations: how many levels the tree has, counting the root's level. An empty tree gives `0`, a tree with only a root gives `1`.

Example: `[-1, 0, 0, 1, 1, 2]` → `3` (generations: {0}, {1, 2}, {3, 4, 5}).
