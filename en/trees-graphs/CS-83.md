# Letter order of an alien alphabet

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Strings](../strings/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-83?utm_source=github&utm_medium=tasks-repo)**

An unknown language uses the lowercase Latin letters, but its alphabet orders them differently. You are given a list `words` (1 to 100 words of 1 to 20 letters each) sorted by that language's dictionary order: words are compared at the first position where they differ, and a word that is the beginning of another comes before it. Equal words may stand next to each other. Find an order of all the distinct letters that appear in the words under which the list really is sorted, and return it as a string. If several orders fit, return the lexicographically smallest one in the usual alphabet. If none fits (a contradiction, or a longer word placed before its own beginning), return the empty string `""`.

Example: `["bca", "bcd", "cab", "cd", "da"]` → `"abcd"` (we know a<d and b<c<d; the smallest order is `abcd`).
