# Diamond inheritance

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-12?utm_source=github&utm_medium=tasks-repo)**

You are given a class diagram. Classes are numbered from `0`; `parents[i]` lists the distinct classes that class `i` inherits from directly. A class never inherits from itself, and there are no cycles. An inheritance path from `X` to `Y` is a chain `X, C1, …, Cn, Y` in which every class is a direct parent of the previous one (a direct parent is a path of two classes). The diagram contains a diamond if some pair of classes `X` and `Y` has at least two different inheritance paths between them. Return `true` if the diagram contains a diamond, otherwise `false`.

Example: `[[1, 2], [3], [3], []]` → `true` (two paths lead from class 0 to class 3: through 1 and through 2).
