# Record nodes of a binary tree

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-689?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node `0` is the root; an empty tree is three empty lists. Call a node a record if its value is strictly greater than the values of all its ancestors (the nodes on the path from the root to it, not counting itself). The root is always a record. Return the number of record nodes; for an empty tree `0`. There are up to 500 nodes with values from -10^6 to 10^6.

Example: `values = [5, 1, 7, 6, 8]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `4` (the nodes with values 5, 7, 6, 8; node 1 has the larger ancestor 5).
