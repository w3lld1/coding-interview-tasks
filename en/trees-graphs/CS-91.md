# Distance sums in a tree

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-91?utm_source=github&utm_medium=tasks-repo)**

You are given an undirected tree with `n` vertices numbered `0` to `n - 1` (`1 ≤ n ≤ 10000`) and the list of its `n - 1` edges, each a pair `[u, v]`. The distance between two vertices is the number of edges on the path between them. For every vertex `i`, compute the sum of its distances to all other vertices and return a list of `n` numbers whose position `i` holds the answer for vertex `i`. A tree of one vertex (no edges) gives `[0]`.

Running a traversal from every vertex takes O(n²) and is too slow for large trees.

Example: `n = 5`, edges `[[0, 1], [0, 2], [2, 3], [2, 4]]` → `[6, 9, 5, 8, 8]`.
