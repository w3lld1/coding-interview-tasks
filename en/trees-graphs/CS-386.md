# Mirrored pre-order

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-386?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node `0` is the root; an empty tree is three empty lists. Imagine that every node has its left and right child swapped (the mirror image of the tree). Return the values of the mirrored tree in pre-order: the node first, then its left subtree, then its right subtree, both already mirrored. Do not rebuild the tree. For an empty tree return an empty list.

Example: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `[4, 6, 2, 3, 1]`.
