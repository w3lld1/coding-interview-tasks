# Count the friend groups

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-404?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. A group is a set of vertices where any two are linked by a chain of edges. A vertex without edges is a group of one person.

Return the number of groups. There may be no vertices at all (`n = 0`), then the answer is `0`. Repeated edges are allowed, loops `[a, a]` do not occur.

Example: `5`, `[[0, 1], [1, 2], [3, 4]]` → `2`.
