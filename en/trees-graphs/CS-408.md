# Hops to a person

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-408?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are acquaintances. One «hop» is a move from a person to someone they know.

Return the smallest number of hops needed to pass a message from `start` to `end`. If `start` equals `end`, the answer is `0`. If there is no chain of acquaintances, return `-1`.

Example: `5`, `[[0, 1], [1, 2], [2, 3], [0, 4], [4, 3]]`, `0`, `3` → `2` (via 4).
