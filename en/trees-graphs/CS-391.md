# Cousins in a family tree

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-391?utm_source=github&utm_medium=tasks-repo)**

A family tree. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. Two people are cousins (in the broad sense) if they are in the same generation (their nodes have equal depth) but have different parents. Given `parent` and two different indexes `a` and `b`, return `true` if they are cousins, otherwise `false`. Siblings (the same parent) are not cousins.

Example: `[-1, 0, 0, 1, 2]`, `3`, `4` → `true` (both at depth 2, parents 1 and 2).
