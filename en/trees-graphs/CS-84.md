# Bridges of an undirected graph

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-84?utm_source=github&utm_medium=tasks-repo)**

You are given an undirected graph: the number of vertices `n` (1 to 1000, vertices `0..n-1`) and a list of edges `edges` (up to 2000 pairs `[u, v]`, with no self-loops and no repeated edges). The graph may be disconnected. A bridge is an edge whose removal increases the number of connected components. Return all bridges, each as a pair `[u, v]` with `u < v`, the list sorted by `u` and then by `v`. If there are no bridges, return the empty list `[]`.

Example: `n = 5`, `[[0, 1], [1, 2], [2, 0], [1, 3], [3, 4]]` → `[[1, 3], [3, 4]]`.
