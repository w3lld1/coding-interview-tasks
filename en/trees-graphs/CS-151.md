# Maximum width of a tree level

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-151?utm_source=github&utm_medium=tasks-repo)**

The tree is given by three lists: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right children, or `-1` when there is none. The root is node `0`; an empty tree has three empty lists.

The width of a level is the number of positions from its leftmost to its rightmost existing node, counting the empty places in between as if the tree were complete (the children of a node at position `p` sit at positions `2p` and `2p + 1` of the next level). Return the greatest width among all levels. For an empty tree return `0`. The answer fits in a 32-bit integer.

Example: the tree `1(3(5, 3), 2(−, 9))` — root 1; node 3 has children 5 and 3; node 2 has only a right child 9 — gives `4` (the third level uses positions 0, 1 and 3).
