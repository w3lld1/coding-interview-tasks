# The extra link

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-9?utm_source=github&utm_medium=tasks-repo)**

A tree of `n` vertices (numbered `0` to `n - 1`) was turned into a connected graph by adding one more edge. The edges `[u, v]` are given as a list of `n` pairs in some order (so the number of edges equals the number of vertices). Return an edge whose removal makes the graph a tree again. If several edges qualify, return the one that appears last in the list. Return the edge exactly as written in the input. There are at most 1000 vertices.

Example: `[[0, 1], [1, 2], [0, 2]]` → `[0, 2]`.
