# Employees with no reports

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-378?utm_source=github&utm_medium=tasks-repo)**

A company org chart. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. Return how many employees have no direct reports (the leaves of the tree). An empty tree gives `0`, a tree with only a root gives `1`.

Example: `[-1, 0, 0, 1, 1, 2]` → `3` (employees 3, 4 and 5).
