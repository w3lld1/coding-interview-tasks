# Post-order walk

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-385?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node `0` is the root; an empty tree is three empty lists. Return the node values in post-order: the whole left subtree first, then the whole right subtree, and the node itself last. This is how folder sizes are summed: the contents first, then the folder. For an empty tree return an empty list.

Example: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `[1, 3, 2, 6, 4]`.
