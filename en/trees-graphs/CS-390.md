# Chain up to the CEO

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-390?utm_source=github&utm_medium=tasks-repo)**

A company org chart. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. Return the list of indexes from employee `node` up the chain of bosses to the root, inclusive: the employee first, then their direct boss, and so on, with the root last. For the root the result is a list of one element.

Example: `[-1, 0, 0, 1, 1, 2]`, `4` → `[4, 1, 0]`.
