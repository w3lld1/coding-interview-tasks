# Everyone knows everyone

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-415?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are acquaintances. Repeated edges (including `[a, b]` and `[b, a]`) mean the same pair; loops `[a, a]` do not occur. Here `1 ≤ n ≤ 100`.

Return `true` if every two different people know each other directly, otherwise `false`. A single person gives `true`.

Example: `3`, `[[0, 1], [1, 2], [0, 2]]` → `true`; `[[0, 1], [1, 2]]` with `n = 3` → `false`.
