# The leaf closest to the root

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-690?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by two lists of equal length: `left[i]` and `right[i]` are the indexes of the left and right child of node `i`, or `-1` if there is none. Node `0` is the root; an empty tree is two empty lists. A leaf is a node with no children. Return the number of nodes on the shortest path from the root to a leaf (the root and the leaf count). A node with one child is not a leaf, so a path through it goes on. For an empty tree the answer is `0`, for a single root `1`. There are up to 10,000 nodes.

Example: `left = [1, 2, -1, -1]`, `right = [3, -1, -1, -1]` → `2` (the root and its right child 3).
