# Reporting depth of an employee

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-379?utm_source=github&utm_medium=tasks-repo)**

A company org chart. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. The depth of a node is the number of steps from it up to the root; the root has depth `0`. Given `parent` and an employee index `node`, return its depth.

Example: `[-1, 0, 0, 1, 1, 2]`, `4` → `2` (4 → 1 → 0).
