# Roots of minimum-height trees

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-106?utm_source=github&utm_medium=tasks-repo)**

You get a tree of `n` vertices numbered `0` to `n - 1` and a list of edges `[a, b]`. If a vertex is chosen as the root, the height of the tree is the largest number of edges from the root to any vertex. Return all vertices that give the minimum height when chosen as the root, in increasing order. For `n = 1` the answer is `[0]`. There are at most 1000 vertices.

Example: `4`, `[[1, 0], [1, 2], [1, 3]]` → `[1]` (with root 1 the height is 1, with any other root it is 2).
