# Signal travel time

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-10?utm_source=github&utm_medium=tasks-repo)**

A network has `n` nodes numbered `0` to `n - 1`. Each record `[u, v, w]` in `times` is a directed link: a signal goes from `u` to `v` in `w` time units (`w` ≥ 0; one pair of nodes may have several links). A signal is sent from node `k` at time 0 and spreads along all links at once. Return the time when the signal has reached every node, that is, the largest of the shortest times to the nodes. If some node is never reached, return `-1`. There are at most 100 nodes and 6000 links.

Example: `4`, `[[1, 0, 1], [1, 2, 1], [2, 3, 1]]`, `1` → `2`.
