# Best short path in a binary tree

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-173?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the number in node `i`, and `left[i]` and `right[i]` are the indexes of its left and right child (`-1` if there is none); node `0` is the root, and the tree has at least one node. A path is a sequence of distinct nodes where neighbours are joined by a parent-child edge; it may start and end at any nodes and need not pass through the root. You are also given an integer `k ≥ 1`. Find the greatest sum of the numbers on a path with 1 to `k` nodes.

The tree has up to 500 nodes, numbers from -1000 to 1000, and `k` up to 500 (it may exceed the number of nodes).

Example: `values = [1, 2, 3]`, `left = [1, -1, -1]`, `right = [2, -1, -1]`, `k = 2` → `4` (the path `0 → 2`); with `k = 3` the answer is `6`.
