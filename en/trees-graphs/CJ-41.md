# Distance to the Cycle

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-41?utm_source=github&utm_medium=tasks-repo)**

Planets are numbered 1 to N (3 ≤ N ≤ 1000) and joined by N two-way tubes; each tube is a pair `[x, y]` (x ≠ y), and no pair appears twice. You can travel from any planet to any other, and the whole network has exactly one cycle.

For every planet find the smallest number of tubes on a path to the nearest planet that lies on the cycle (0 for planets on the cycle). Return a list of N numbers: item i belongs to planet i.

Example: `5`, `[[1, 2], [2, 3], [3, 4], [2, 4], [5, 3]]` → `[1, 0, 0, 0, 1]` (planets 2, 3, 4 form the cycle).
