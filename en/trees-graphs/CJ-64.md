# Smallest route by ZIP codes

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Searching and sorting](../search-sort/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-64?utm_source=github&utm_medium=tasks-repo)**

There are `n` cities numbered `0` to `n − 1`; `zips[i]` is the five-digit ZIP code of city `i` (no leading zeros, all distinct). The list `flights` holds pairs `[u, v]`: a two-way flight connects cities `u` and `v`. You pick a starting city and travel under these rules:
- a ticket is an outbound flight `X → Y` and a return flight `Y → X`; the return is used after the outbound (you may fly further in between);
- you may arrive in each city by an outbound flight at most once, and never in the starting city;
- every ticket you buy is used in full.

In effect you walk the cities like a stack: fly forward to a new city or return to the previous open one. You must visit every city. Writing down each city's ZIP code on its first visit (the start included) gives a string of `5n` digits. Return the smallest such string. All cities are guaranteed to be connected by flights; `1 ≤ n ≤ 50`.

Example: `["10001", "20000", "10000"]`, `[[0, 1], [1, 2]]` → `"100002000010001"`.
