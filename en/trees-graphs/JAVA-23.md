# Tree Building

**Difficulty:** medium · **Language:** Java · **Topics:** [Trees and graphs](../trees-graphs/), [Errors and exceptions](../errors/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-23?utm_source=github&utm_medium=tasks-repo)**

Given an unordered list of records, each with a node ID and its parent's ID, rebuild the tree by improving the slow implementation from the starter code. For n records, the IDs must form the range from 0 to n−1 without repeats, the root has the pair (0, 0), and every other node's parent ID is less than its own. Reject invalid records and return each node's children ordered by ID; empty input gives an empty tree.
