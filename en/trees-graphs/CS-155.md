# Nodes at distance k from a target

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-155?utm_source=github&utm_medium=tasks-repo)**

The tree is given by three lists: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right children, or `-1` when there is none. The root is node `0`; an empty tree has three empty lists. All values in the tree are distinct. A value `target`, certainly present in the tree, and an integer `k >= 0` are given.

The distance between nodes is the number of edges on the path between them; an edge may be walked downwards and upwards. Return the values of all nodes at distance exactly `k` from the node with value `target`, in ascending order. If there are none, return an empty list. For `k = 0` the answer is `target` itself.

Example: the tree `3(5(6, 2(7, 4)), 1(0, 8))`, `target = 5`, `k = 2` → `[1, 4, 7]`.
