# Route over every ticket

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-171?utm_source=github&utm_medium=tasks-repo)**

You are given a list of plane tickets, each a pair `[from, to]` of airport codes (three uppercase Latin letters, the two airports differ), and an airport code `start`. A traveller leaves `start` and wants to use every ticket exactly once: ticket `[A, B]` can be used only while in `A`, and it takes the traveller to `B`. Identical tickets may repeat, and each copy must be used.

Return the route: the list of airports in the order visited, starting with `start` (one longer than the number of tickets). If several routes work, return the lexicographically smallest one: routes compare at the first airport where they differ, and codes compare as strings. If the tickets cannot all be used, return `[]`. With no tickets the answer is `[start]`.

There are up to 5000 tickets.

Example: `[["MOW", "LED"], ["LED", "KZN"], ["MOW", "KZN"], ["KZN", "MOW"]]`, `"MOW"` → `["MOW", "KZN", "MOW", "LED", "KZN"]`.
