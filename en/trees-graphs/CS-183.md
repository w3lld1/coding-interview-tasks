# Islands after each landfill

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-183?utm_source=github&utm_medium=tasks-repo)**

Given a map of `rows` rows and `cols` columns (1 ≤ `rows`, `cols` ≤ 1000), all water at first. The list `positions` (up to 10,000 items) lists landfills in order: item `[r, c]` turns the cell in row `r` and column `c` into land (every cell is inside the map; filling a land cell again changes nothing). An island is a maximal group of land cells joined through shared sides (diagonal cells are not neighbours).

Return a list as long as `positions`: at index `i`, the number of islands right after landfill `i`. An empty `positions` gives `[]`. Recounting the whole map after each landfill is too slow.

Example: `rows = 3`, `cols = 4`, `positions = [[0, 0], [0, 2], [1, 1], [0, 1], [2, 3], [1, 3], [1, 2]]` → `[1, 2, 3, 1, 2, 2, 1]`.
