# Binary tree level order

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-57?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of the same length: `values[i]` is the value of node `i`, and `left[i]` and `right[i]` are the indexes of its left and right children, or `-1` when there is none. The root is node `0`. Return the values level by level from the top: one list per level, left to right inside a level. An empty tree (empty lists) gives an empty list. The tree has up to 1000 nodes, and node indexes need not follow level order.

Example: `values = [3, 9, 20, 15, 7]`, `left = [1, -1, 3, -1, -1]`, `right = [2, -1, 4, -1, -1]` → `[[3], [9, 20], [15, 7]]`.
