# How many friends each person has

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-402?utm_source=github&utm_medium=tasks-repo)**

A social network has `n` people numbered `0…n-1`; the list `edges` holds pairs `[a, b]` meaning «a and b are friends». Friendship is mutual, so every pair raises the count of both people. A pair that appears twice counts twice; pairs like `[a, a]` do not occur.

Return a list of `n` numbers: position `i` holds how many times person `i` appears in the pairs. With no people, return an empty list.

Example: `4`, `[[0, 1], [1, 2], [1, 3]]` → `[1, 3, 1, 1]`.
