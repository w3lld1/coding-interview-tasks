# Sum nodes

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-398?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node `0` is the root; an empty tree is three empty lists. Call a node a sum node if it has at least one child and its value equals the sum of the values of its direct children (a missing child adds `0`). Leaves are never sum nodes, even when their value is `0`. Return the number of sum nodes. For an empty tree the answer is `0`.

Example: `values = [9, 4, 5, 2, 2]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `2` (9 = 4 + 5 and 4 = 2 + 2).
