# Is one employee a boss of another

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-400?utm_source=github&utm_medium=tasks-repo)**

A company org chart. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. Employee `a` is a boss of employee `b` if `a` lies on the chain going up from `b` to the root: the direct boss, the boss's boss, and so on. Nobody is their own boss. Return `true` if `a` is a boss of `b` (direct or indirect), otherwise `false`.

Example: `[-1, 0, 0, 1, 1, 2]`, `0`, `4` → `true`; `2`, `4` → `false`.
