# Direct reports

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-380?utm_source=github&utm_medium=tasks-repo)**

A company org chart. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. Return a list of length `n` where element `i` is the number of direct reports of employee `i` (the nodes whose parent is `i`). For an empty tree return an empty list.

Example: `[-1, 0, 0, 1, 1, 2]` → `[2, 2, 1, 0, 0, 0]`.
