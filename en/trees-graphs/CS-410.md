# Where can you fly

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-410?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are two-way flights between cities.

Return the numbers of all cities reachable from city `start` with any number of connections, in increasing order. `start` itself is part of the answer.

Example: `6`, `[[0, 1], [1, 2], [3, 4]]`, `0` → `[0, 1, 2]`.
