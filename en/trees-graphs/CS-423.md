# A clean edge list

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-423?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. The list is «clean» if it has no loops (an edge `[a, a]` joins a vertex to itself) and no repeats: the same pair of vertices does not appear twice, and `[a, b]` and `[b, a]` are the same pair.

Return `true` if the list is clean, otherwise `false`. An empty list is clean.

Example: `3`, `[[0, 1], [1, 2]]` → `true`; `[[0, 1], [1, 0]]` with `n = 3` → `false`.
