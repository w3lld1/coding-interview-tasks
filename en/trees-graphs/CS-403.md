# The most popular member

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-403?utm_source=github&utm_medium=tasks-repo)**

A community has `n` members (`1 ≤ n ≤ 1000`) numbered `0…n-1`. The list `edges` holds pairs `[a, b]` meaning the two know each other; a repeated pair counts twice, pairs like `[a, a]` do not occur.

Return the number of the member who knows the most people (the most appearances in the pairs). If several tie, return the smallest number. If there are no pairs at all, the answer is `0`.

Example: `4`, `[[0, 1], [1, 2], [1, 3]]` → `1`.
