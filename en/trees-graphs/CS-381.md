# Size of a manager's team

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-381?utm_source=github&utm_medium=tasks-repo)**

A company org chart. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. A manager's team is the manager, their direct reports, those people's reports, and so on down the tree. Given `parent` and an index `manager`, return the size of that team, counting the manager.

Example: `[-1, 0, 0, 1, 1, 2]`, `1` → `3` (employees 1, 3 and 4).
