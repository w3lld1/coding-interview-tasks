# Restoring a matrix from checksums

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Matrices and grids](../matrices/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-108?utm_source=github&utm_medium=tasks-repo)**

There was an `n × n` matrix of zeros and ones. For each row `i` its checksum `row_xor[i]` (the XOR of the row's elements) was written down, and for each column `j` its checksum `col_xor[j]`. Then some elements were lost: in matrix `a` a lost element is `-1`, the others hold their original `0` or `1`.

A lost element `a[i][j]` can be recovered by hand in `b[i][j]` hours (`b[i][j] = 0` for known elements). An element can also be computed for free when it is the only unknown left in its row or column: the checksum gives its value. Return the smallest total number of hours after which the whole matrix is known for certain.

The lost elements can always be filled so that all checksums hold. Limits: `1 ≤ n ≤ 30`, `1 ≤ b[i][j] ≤ 1000` for lost elements.

Example: `[[-1, -1], [-1, -1]]`, `[[1, 10], [100, 1000]]`, `[1, 0]`, `[0, 1]` → `1` (recover `a[0][0]`; the other three follow from the checksums).
