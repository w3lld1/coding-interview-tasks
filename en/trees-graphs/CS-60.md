# Validate a binary search tree

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-60?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by lists `values`, `left`, `right` of the same length: `values[i]` is the value of node `i`, and `left[i]`, `right[i]` are the indexes of its children or `-1`. The root is node `0`. Return `true` if the tree is a strict search tree: for every node, all values in its left subtree are strictly less than its value, and all values in its right subtree are strictly greater. Equal values are not allowed. An empty tree (empty lists) counts as a search tree. Values are 32-bit integers, with up to 1000 nodes.

Example: `values = [5, 1, 4, 3, 6]`, `left = [1, -1, 3, -1, -1]`, `right = [2, -1, 4, -1, -1]` → `false` (node 4 has 3 on its left, but 3 sits in the right subtree of the root 5).
