# Network without redundant links

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-406?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. A network is a tree if all vertices are connected to each other and there is no cycle (no link is redundant). A repeated edge forms a cycle. Here `1 ≤ n ≤ 1000` and loops `[a, a]` do not occur.

Return `true` if the graph is a tree, otherwise `false`. A single vertex without edges is a tree.

Example: `4`, `[[0, 1], [1, 2], [1, 3]]` → `true`; `[[0, 1], [1, 2], [2, 0]]` with `n = 4` → `false`.
