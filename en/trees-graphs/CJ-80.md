# Transmuting metals into lead

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-80?utm_source=github&utm_medium=tasks-repo)**

There are `m` metals (`2 ≤ m ≤ 500`); lead is metal 1. Each metal `i` has exactly one formula `recipes[i-1] = [a, b]` (`1 ≤ a < b ≤ m`): it destroys one gram of metal `i` and creates one gram each of metals `a` and `b` (one of them may be `i` itself). Formulas work on whole grams only and can be applied any number of times while the needed metal is available. The treasury holds `grams[i-1]` grams of metal `i` (`0 ≤ grams[i-1] ≤ 10^9`).

Return the string `"UNBOUNDED"` if an unlimited amount of lead can be made. Otherwise return the largest reachable number of grams of lead modulo `1000000007` as a decimal string.

Example: `[[1, 2], [1, 2]]`, `[1, 0]` → `"UNBOUNDED"`.
