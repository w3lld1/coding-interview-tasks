# Binary Search Tree

**Difficulty:** medium · **Language:** Python · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-19?utm_source=github&utm_medium=tasks-repo)**

Build a binary search tree by inserting numbers in the order they arrive. Send values less than or equal to a node's value to the left subtree, and greater values to the right. Provide access to each node's value and children, and a traversal that returns all values in non-decreasing order, keeping duplicates.
