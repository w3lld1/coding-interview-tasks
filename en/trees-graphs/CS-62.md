# Downward paths with a given sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Hash maps and sets](../hashing/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-62?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given as three lists of equal length: `values[i]` is the value of node `i`, and `left[i]` and `right[i]` are the indexes of its left and right child (`-1` when there is none). The root is node `0`; an empty tree is given by empty lists. Values can be negative or zero.

A downward path starts at any node and follows parent → child links, ending at that node or a deeper one; a path of a single node is allowed. Return how many downward paths have the values on them add up to `target`. Paths with different sets of nodes count separately even if their values are the same. For an empty tree return `0`. The tree has at most 1000 nodes.

Example: `values = [1, 2, 3]`, `left = [1, -1, -1]`, `right = [2, -1, -1]`, `target = 3` → `2` (the path `1 → 2` and the single node `3`).
