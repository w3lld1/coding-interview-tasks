# Path with the highest probability

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-111?utm_source=github&utm_medium=tasks-repo)**

You get an undirected graph of `n` vertices `0..n-1`. The edge `edges[i] = [a, b]` is crossed successfully with probability `succ_prob[i]` (a number from 0 to 1), and crossings are independent. The success probability of a path is the product of the probabilities of its edges. Find the path from `start_node` to `end_node` with the highest probability and return that probability. If there is no path, return `0.0`. If `start_node` equals `end_node`, the probability is `1.0`. There are at most 1000 edges. Numbers are compared within 1e-6.

Example: `3`, `[[0, 1], [1, 2], [0, 2]]`, `[0.5, 0.5, 0.2]`, `0`, `2` → `0.25` (the path `0 → 1 → 2` beats the direct edge).
