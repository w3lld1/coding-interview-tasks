# Nodes with a single child

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-383?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node `0` is the root; an empty tree is three empty lists. Return how many nodes have exactly one child (a left or a right one, but not both). Leaves and nodes with two children do not count. For an empty tree the answer is `0`.

Example: `values = [5, 3, 8, 1]`, `left = [1, 3, -1, -1]`, `right = [2, -1, -1, -1]` → `1` (node 1 has only a left child).
