# Satellite

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-24?utm_source=github&utm_medium=tasks-repo)**

Rebuild a binary tree with unique values from its preorder and inorder traversals. In preorder, the root comes first, followed by the left and right subtrees; in inorder, the left subtree comes first, then the root, then the right subtree. Return the postorder traversal of the rebuilt tree: the left subtree, the right one, then the root. If the data is inconsistent (different sets of values, different lengths, duplicates), report an error: throw an exception, or return an error in Go.
