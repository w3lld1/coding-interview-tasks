# House robber on a tree

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Dynamic programming](../dp/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-156?utm_source=github&utm_medium=tasks-repo)**

A tree is given by three lists: `values[i]` is the money in node `i` (at least 0), and `left[i]`, `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node 0 is the root; an empty tree is given by empty lists. You pick a set of nodes so that no parent and its child are both picked. Return the largest possible total of the picked values. For an empty tree the answer is `0`.

Example: `values = [3, 2, 3, 3, 1]`, `left = [1, -1, -1, -1, -1]`, `right = [2, 3, 4, -1, -1]` → `7` (the root and its two grandchildren: 3 + 3 + 1).
