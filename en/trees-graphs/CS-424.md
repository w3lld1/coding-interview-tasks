# Stops in a line

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-424?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are segments between stops. The stops form a line if they can be written in a row so that the segments join exactly the neighbours in the row and nothing else. Here `1 ≤ n ≤ 1000` and loops `[a, a]` do not occur.

Return `true` if the stops form a line, otherwise `false`. A single stop without segments is a line.

Example: `4`, `[[2, 0], [0, 3], [3, 1]]` → `true` (row 2, 0, 3, 1); `[[0, 1], [0, 2], [0, 3]]` with `n = 4` → `false`.
