# Evaluate division queries

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-105?utm_source=github&utm_medium=tasks-repo)**

You get equations of the form `a / b = k`: `equations[i] = [a, b]` and `values[i] = k` (a positive number), where `a` and `b` are variable names. The equations never contradict each other. For each query `[x, y]` find the value of `x / y`. If it cannot be derived from the equations, or either name appears in no equation, the answer is `-1.0`. For a known variable `x / x = 1.0`; for an unknown one (in no equation) it is `-1.0` too. Return the answers in the order of the queries. There are at most 100 equations and queries. Numbers are compared within 1e-6.

Example: equations `[["a", "b"], ["b", "c"]]`, values `[2.0, 3.0]`, queries `[["a", "c"], ["b", "a"], ["a", "e"]]` → `[6.0, 0.5, -1.0]`.
