# Right side view

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-61?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given as three lists of equal length: `values[i]` is the value of node `i`, and `left[i]` and `right[i]` are the indexes of its left and right child (`-1` when there is none). The root is node `0`; an empty tree is given by empty lists.

Imagine standing to the right of the tree and looking at it. Return the values of the nodes you can see: one value per level, starting at the root, namely the value of the rightmost node of that level. For an empty tree return an empty list. The tree has at most 1000 nodes.

Example: `values = [1, 2, 3, 4]`, `left = [1, 3, -1, -1]`, `right = [2, -1, -1, -1]` → `[1, 3, 4]`.
