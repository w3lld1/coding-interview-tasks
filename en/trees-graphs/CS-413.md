# Airports with no departures

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-413?utm_source=github&utm_medium=tasks-repo)**

An air network has `n` airports numbered `0…n-1`. The list `flights` holds one-way flights `[from, to]` — from airport `from` to airport `to`. Flights may repeat; there is no flight from an airport to itself.

Return, in increasing order, the numbers of airports from which no flight departs. An airport with no flights at all is included too. If there are none, return an empty list.

Example: `4`, `[[0, 1], [1, 2], [0, 3]]` → `[2, 3]`.
