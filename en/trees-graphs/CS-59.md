# Diameter of a tree

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-59?utm_source=github&utm_medium=tasks-repo)**

A tree is given by the number of nodes `n` and a list of edges `[u, v]`; nodes are numbered `0` to `n - 1`, edges are undirected, and the tree is connected with no cycles. The diameter is the length of the longest simple path between two nodes, measured in edges. Return the diameter. If there is one node, the answer is `0`. There are 1 to 1000 nodes.

Example: `n = 6`, `[[0, 1], [1, 2], [1, 3], [3, 4], [4, 5]]` → `4` (the path 2-1-3-4-5).
