# Tree Building

**Difficulty:** medium · **Language:** Python · **Topics:** [Trees and graphs](../trees-graphs/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-13?utm_source=github&utm_medium=tasks-repo)**

Refactor the slow tree builder from the starter code, which takes unordered records with record_id and parent_id fields, keeping its purpose and checks. The IDs must form the range from 0 to n−1 with no duplicates or gaps; the root has both IDs equal to 0, and every other node's parent ID is less than its own. Return the root of the tree with children ordered by ID, or None for empty input. Reject invalid links and IDs with ValueError.
