# Go board territory

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Matrices and grids](../matrices/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-10?utm_source=github&utm_medium=tasks-repo)**

A Go board is a list of equal-length strings: `B` is a black stone, `W` a white stone, a space an empty intersection. Coordinates `(x, y)`: `x` is the column, `y` the row, and `(0, 0)` is the top-left corner. Only horizontal and vertical neighbours count.

Find the region of empty intersections that contains `(x, y)`: all empty cells reachable from it through empty neighbours. The region belongs to a player if every stone bordering it has the same colour; if no stone borders it, or both colours do, it has no owner. Return a list of strings: the first element is the owner `"BLACK"`, `"WHITE"` or `"NONE"`, then the cells of the region as `"x,y"`, sorted by `x` and, for equal `x`, by `y` (compare them as numbers). If `(x, y)` holds a stone, return just `["NONE"]`.

Report an error: throw an exception, or return an error in Go, when the coordinate is outside the board.

Example: board `["  B  ", " B B ", "B W B", " W W ", "  W  "]`, `0`, `1` → `["BLACK", "0,0", "0,1", "1,0"]`.
