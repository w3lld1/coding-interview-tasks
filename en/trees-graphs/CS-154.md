# Lowest common ancestor of two values

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-154?utm_source=github&utm_medium=tasks-repo)**

The tree is given by three lists: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right children, or `-1` when there is none. The root is node `0`; an empty tree has three empty lists. All values in the tree are distinct. Two values `p` and `q` are given, both certainly present in the tree (they may be equal).

The lowest common ancestor is the deepest node whose subtree contains both the node with value `p` and the node with value `q`; a node counts as an ancestor of itself. Return the value of that node.

Example: the tree `3(5(6, 2(7, 4)), 1(0, 8))`, `p = 5`, `q = 4` → `5`; for `p = 6`, `q = 8` → `3`.
