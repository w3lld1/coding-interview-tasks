# Lighthouses in villages

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-106?utm_source=github&utm_medium=tasks-repo)**

There are `n` villages numbered `0` to `n - 1`, connected by `n - 1` roads so that any village can reach any other by exactly one path (the roads form a tree). Village `i` has beauty `beauty[i]`, which may be negative. Each road `roads[j] = [x, y]` connects villages `x` and `y`.

You may build lighthouses in any set of villages, possibly none. A village is lit if it has a lighthouse or a village directly connected to it by a road has one. Return the largest possible total beauty of the lit villages. If lighting anything only lowers the total, the answer is `0` (build nothing).

Limits: `1 ≤ n ≤ 1000`, `|beauty[i]| ≤ 10^9`; the answer may not fit in 32 bits.

Example: `[-2, 20, 20, 20]`, `[[0, 1], [0, 2], [0, 3]]` → `58` (lighthouses in villages 1, 2 and 3 light all four villages).
