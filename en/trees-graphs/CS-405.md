# Is there a road between the towns

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-405?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are two-way roads between towns.

Return `true` if town `end` can be reached from town `start` by driving along roads (through any number of towns in between), otherwise `false`. If `start` equals `end`, the answer is `true`.

Example: `5`, `[[0, 1], [1, 2], [3, 4]]`, `0`, `2` → `true`; for `0` and `4` the answer would be `false`.
