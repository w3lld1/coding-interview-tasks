# Reroot a tree

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-21?utm_source=github&utm_medium=tasks-repo)**

A tree is given by its root `root` and a list of edges `edges`: each edge is a pair `[parent, child]`. All node names are different. A tree has no inherent direction: you can look at it from any node by pulling that node up to the root and dragging its relationships along.

You get a node `new_root`. Return the edges of the same tree directed away from `new_root`: pairs `[parent, child]` where the parent is the neighbour closer to `new_root`. The order of the pairs does not matter. If `new_root` does not occur in the tree, report an error: throw an exception, or return an error in Go. A tree of one node (no edges) gives an empty list.

Example: `"parent"`, `[["parent", "x"], ["parent", "sibling"]]`, `"x"` → `[["x", "parent"], ["parent", "sibling"]]`.
