# To the nearest charger

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-422?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are roads between stops of an electric bus. The list `has_charger` holds `n` numbers: `1` means the stop has a charging station, `0` means it has none.

Return the smallest number of road segments (edges) to drive from stop `start` to a stop with a charger. If `start` itself has a charger, the answer is `0`. If no charger can be reached, return `-1`.

Example: `5`, `[[0, 1], [1, 2], [2, 3], [3, 4]]`, `[0, 0, 1, 0, 1]`, `0` → `2`.
