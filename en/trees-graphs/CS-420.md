# How many routes to the end

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-420?utm_source=github&utm_medium=tasks-repo)**

A city has `n` stations numbered `0…n-1`; the list `roads` holds one-way lines `[from, to]`, and always `from < to`, so there are no cycles. A line does not repeat in the list. Here `1 ≤ n ≤ 20`.

Return how many different routes lead from station `0` to station `n-1` (a route is a sequence of stations where neighbouring ones are joined by a line). If `n = 1`, there is one route (a single station). If you cannot get there, the answer is `0`.

Example: `4`, `[[0, 1], [0, 2], [1, 3], [2, 3]]` → `2`.
