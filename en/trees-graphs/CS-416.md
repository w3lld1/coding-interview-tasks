# A loop of roads

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-416?utm_source=github&utm_medium=tasks-repo)**

A graph is given by the number of vertices `n` (vertices `0…n-1`) and a list of edges `edges`: an edge `[u, v]` joins `u` and `v` in both directions. Edges are two-way roads. A loop is a closed route along roads that uses no road twice. Two equal roads between the same pair of towns (`[a, b]` and `[b, a]` too) already form a loop. Loops `[a, a]` do not occur.

Return `true` if the network has at least one loop, otherwise `false`.

Example: `3`, `[[0, 1], [1, 2], [2, 0]]` → `true`; `4`, `[[0, 1], [1, 2], [2, 3]]` → `false`.
