# Walk Over Visited Cells

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-42?utm_source=github&utm_medium=tasks-repo)**

A robot stands on a grid of `rows` rows (numbered 1 from the top) and `cols` columns (numbered 1 from the left) in the cell `start` = `[row, column]`. It gets a string of commands made of `N` (north, row −1), `S` (south, row +1), `E` (east, column +1) and `W` (west, column −1).

On each command the robot steps in that direction. If the cell was visited before (the start cell counts), it keeps moving the same way until it reaches a cell it has never been in. The robot never leaves the grid. Return `[row, column]` of the cell where it ends after all commands (1 ≤ rows, cols ≤ 50000, up to 50000 commands).

Example: `3`, `6`, `[2, 3]`, `"EEWNS"` → `[3, 2]`.
