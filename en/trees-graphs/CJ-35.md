# Order of assignments

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-35?utm_source=github&utm_medium=tasks-repo)**

You get an unordered list of assignment statements of the form `x=f(a,b)`: a variable name, the sign `=` and a function call with zero or more variable arguments separated by commas, with no spaces (`g()` is a call with no arguments). All names are lowercase Latin letters, no variable has the same name as a function, and each variable is assigned at most once. A variable may repeat among the arguments.

Statements run one at a time in an order you choose. A statement is valid if every variable argument has been assigned by an earlier statement (a call without arguments is always valid). Return `true` if some order makes all statements valid, `false` otherwise. A variable used as an argument but never assigned makes the answer `false`; so does a statement that depends on itself.

Limits: up to 1000 statements, up to 10 arguments per call, names up to 20 letters.

Example: `["a=f(b,c)", "b=g()", "c=h()"]` → `true` (order `b`, `c`, `a`); `["a=f(b)", "b=f(a)"]` → `false`.
