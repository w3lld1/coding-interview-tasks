# All routes to the end

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-421?utm_source=github&utm_medium=tasks-repo)**

A city has `n` stations numbered `0…n-1`; the list `roads` holds one-way lines `[from, to]`, and always `from < to`, so there are no cycles. A line does not repeat in the list. Here `1 ≤ n ≤ 20`. There are at most 100 routes.

Return all routes from station `0` to station `n-1`, each as a list of stations from `0` to `n-1`. Order the routes lexicographically (compare lists at the first differing station). If `n = 1`, there is one route: `[0]`. If you cannot get there, return an empty list.

Example: `4`, `[[0, 1], [0, 2], [1, 3], [2, 3]]` → `[[0, 1, 3], [0, 2, 3]]`.
