# Binary Search Tree

**Difficulty:** medium · **Language:** Java · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-06?utm_source=github&utm_medium=tasks-repo)**

Build a binary search tree by inserting integers one by one in the order they arrive. Send values less than or equal to a node's value to the left subtree, and greater values to the right. Provide access to the data and child nodes, and a way to get all values of the tree in sorted order.
