# Depth of a value in a search tree

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-395?utm_source=github&utm_medium=tasks-repo)**

A binary tree is given by three lists of equal length: `values[i]` is the value of node `i`, `left[i]` and `right[i]` are the indexes of its left and right child, or `-1` if there is none. Node `0` is the root; an empty tree is three empty lists. This is a search tree: the values are distinct, in the left subtree of any node all values are smaller than its value, in the right subtree all are larger. Return the depth of the node whose value is `key` (the root has depth `0`), or `-1` if the tree has no such value. For an empty tree the answer is `-1`.

Example: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]`, `key = 3` → `2`; `key = 5` → `-1`.
