# Folder sizes

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-389?utm_source=github&utm_medium=tasks-repo)**

A file system. A tree is given by a list `parent`: `parent[i]` is the index of the parent of node `i`, and the root has `-1`. Nodes are numbered from `0`, there is exactly one root. The nodes are folders, `parent[i]` is the folder that contains folder `i`. Folder `i` holds files of total size `sizes[i]` (not counting sub-folders). Return a list where element `i` is the full size of folder `i`: its own files plus the full sizes of all folders inside it. For an empty tree return an empty list.

Example: `[-1, 0, 0, 1]`, `[5, 10, 20, 30]` → `[65, 40, 20, 30]`.
