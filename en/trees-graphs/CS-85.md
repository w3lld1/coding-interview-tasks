# Shortest walk through every vertex of a small graph

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/), [Dynamic programming](../dp/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-85?utm_source=github&utm_medium=tasks-repo)**

You are given an undirected unweighted graph: the number of vertices `n` (1 to 12, vertices `0..n-1`) and a list of edges `edges` (pairs `[u, v]`, with no self-loops and no repeats). A walk starts at any vertex, moves along an edge to a neighbouring vertex at each step and ends at any vertex; vertices and edges may be reused. Return the fewest steps of a walk that visits every vertex at least once. A graph of one vertex gives `0`. If the graph is disconnected and no such walk exists, return `-1`.

Example: `n = 5`, `[[0, 1], [0, 2], [0, 3], [3, 4]]` → `5` (for example `1 → 0 → 2 → 0 → 3 → 4`).
