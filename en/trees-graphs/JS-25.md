# React

**Difficulty:** hard · **Language:** JavaScript · **Topics:** [Trees and graphs](../trees-graphs/), [Classes and OOP](../oop/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-25?utm_source=github&utm_medium=tasks-repo)**

Implement a system of input cells with a value that can be changed, and compute cells that depend on other cells. A change to an input cell must propagate through the dependencies to a new stable state. For compute cells, provide adding and removing change callbacks; notify them only when the final value differs from the previous one, and at most once per update, even if there were several intermediate recalculations.
