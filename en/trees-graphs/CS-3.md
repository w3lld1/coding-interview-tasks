# Course prerequisites

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-3?utm_source=github&utm_medium=tasks-repo)**

There are `num_courses` courses numbered `0` to `num_courses - 1`. Each pair `[a, b]` in `prerequisites` means course `b` must be taken before course `a`. Return `true` if all courses can be taken in some order, and `false` if the requirements contradict each other (there is a cycle, including a course that requires itself). Pairs may repeat. There are at most 2000 courses and 5000 pairs.

Example: `2`, `[[1, 0], [0, 1]]` → `false`.
