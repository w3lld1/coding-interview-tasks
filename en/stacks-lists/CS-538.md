# A list with nested lists

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Recursion and backtracking](../recursion/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-538?utm_source=github&utm_medium=tasks-repo)**

A structure is given by three arrays: node `i` holds the number `values[i]`, a link `next[i]` to the next node of its own list and a link `child[i]` to the first node of a nested list (`-1` if there is none; `-1` in `next` for the last node). `head` is the index of the first node of the main list, `-1` for an empty one. A nested list is built the same way and may itself have nested lists. Every node belongs to exactly one list, there are no shared nodes and no cycles; the nodes lie in the arrays in any order.

Flatten the structure into one list by this rule: right after a node comes its whole nested list (flattened by the same rule), and only then whatever followed the node by `next`. Return the numbers of the flattened list in order.

Example: `values = [10, 20, 30, 40, 50]`, `next = [1, 2, -1, 4, -1]`, `child = [-1, 3, -1, -1, -1]`, `head = 0` → `[10, 20, 40, 50, 30]` (node `20` has the nested list `40 → 50`).
