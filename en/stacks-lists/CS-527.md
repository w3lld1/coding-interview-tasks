# Reverse the links of a list

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-527?utm_source=github&utm_medium=tasks-repo)**

A linked list is given by an array of links: `next[i]` is the index of the node after node `i`, or `-1` for the last node. `head` is the index of the first node, `-1` for an empty list (then the array is empty). Every array index is a node of the list, and the nodes lie in any order.

Reverse the list: each node's new link leads to the node that used to stand before it, and the former first node gets the new link `-1`. Return the new array of links (nodes keep their indexes).

Example: `next = [2, -1, 1]`, `head = 0` (the list `0 → 2 → 1`) → `[-1, 2, 0]` (the list `1 → 2 → 0`).
