# Playlist with a current track

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-274?utm_source=github&utm_medium=tasks-repo)**

Implement a circular playlist with a pointer to the current track. Tracks are integer numbers (numbers may repeat), the playlist is empty at first. When the first track appears, it becomes the current one. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"add"` with argument `song`: append a track to the end; result: the playlist length.
- `"insert_next"` with argument `song`: insert a track right after the current one (into an empty playlist just insert it); the current track does not change; result: the playlist length.
- `"next"`: go to the next track, the first one follows the last; result: the number of the new current track, `-1` for an empty playlist.
- `"prev"`: go to the previous track, the last one precedes the first; the result is as for `"next"`.
- `"remove_current"`: remove the current track; the track after it becomes current, and if the last one was removed, the first; result: the number of the removed track, `-1` for an empty playlist.
- `"current"`: result: the number of the current track, `-1` for an empty playlist.

Example: `["add", "add", "add", "next", "insert_next", "next", "remove_current", "current"]`, `[[11], [22], [33], [], [44], [], [], []]` → `[1, 2, 3, 22, 4, 44, 44, 33]`.
