# Days until a warmer day

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-12?utm_source=github&utm_medium=tasks-repo)**

You get a list of daily temperatures. For each day, return how many days you must wait for a warmer day, that is, the nearest later day with a strictly higher temperature. If there is none, return `0` for that day. The result has the same length as the input; for an empty list return an empty list. The input may have a few thousand items, and the solution should beat O(n²).

Example: `[73, 74, 75, 71, 69, 72, 76, 73]` → `[1, 1, 4, 2, 1, 1, 0, 0]`.
