# Depth of mixed nested brackets

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-526?utm_source=github&utm_medium=tasks-repo)**

The string `text` contains brackets of three kinds: `()`, `[]`, `{}`; all other characters (letters, digits, spaces) are ignored. If the brackets are placed correctly (each closing bracket closes the last still open bracket of the same kind, and none stays open at the end), return the greatest nesting depth, the largest number of brackets open at the same time. For a string without brackets that is `0`. If the placement is wrong, return `-1`.

Example: `"a(b[c]{d})"` → `2`; `"([)]"` → `-1`.
