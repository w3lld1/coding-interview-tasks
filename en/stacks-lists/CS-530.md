# The value in the middle of a list

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-530?utm_source=github&utm_medium=tasks-repo)**

A linked list is given by arrays: node `i` holds the number `values[i]` and a link `next[i]` to the next node (`-1` for the last node). `head` is the index of the first node (`-1` for an empty list, then the arrays are empty). Nodes lie in the arrays in any order, follow the links. The numbers in the list are non-negative.

Return the number from the middle node of the list. If the number of nodes is even, there are two middle ones, and the second of them is needed. For an empty list return `-1`.

Example: `values = [10, 20, 30, 40]`, `next = [1, 2, 3, -1]`, `head = 0` → `30`.
