# The one-three-two triple

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-119?utm_source=github&utm_medium=tasks-repo)**

You are given a list of integers `nums` (up to 5000 items, absolute values up to 10⁹). Return `true` if it has three positions `i < j < k` with `nums[i] < nums[k] < nums[j]` (values shaped "small, large, middle", strict inequalities). Otherwise return `false`. For a list shorter than three items the answer is `false`.

Example: `[3, 1, 4, 2]` → `true` (`1, 4, 2`); `[1, 2, 3, 4]` → `false`.
