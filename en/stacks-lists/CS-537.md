# Simplify a file path

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-537?utm_source=github&utm_medium=tasks-repo)**

Given an absolute path in a file system: a string of names separated by `/`, starting with `/`. A name consists of Latin letters, digits and dots. Rules:
- several `/` in a row count as one separator;
- the name `.` means the current folder and changes nothing;
- the name `..` means going to the parent folder; at the root `/` it changes nothing;
- any other name, even three dots `...` or something like `.hidden`, is an ordinary folder.

Return the simplified path: it starts with a single `/`, names are separated by a single `/`, and there is no trailing `/` (except the path to the root, which is `"/"`).

Example: `"/a/./b/../../c/"` → `"/c"`.
