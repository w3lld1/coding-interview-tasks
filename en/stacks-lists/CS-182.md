# Stack of the most frequent

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Hash maps and sets](../hashing/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-182?utm_source=github&utm_medium=tasks-repo)**

Implement a special stack and run a list of operations on it. The stack starts empty. Operation `operations[i]` takes its arguments from `values[i]`:
- `push` — `values[i]` holds one number `v` (0 to 10^9); `v` goes onto the stack. The result is how many times `v` is now in the stack (counting this one);
- `pop` — `values[i]` is empty. It removes one occurrence of the most frequent value, the one present in the stack the most times. If several values tie, it picks the one whose last remaining occurrence was pushed latest, and removes that last occurrence. The result is the removed value;
- `peek` — `values[i]` is empty; the result is the value `pop` would remove, and the stack does not change.

`pop` and `peek` on an empty stack give `-1`. Return the list of results, one per operation. There are at most 20,000 operations, and each must run in O(1).

Example: operations `push 5, push 7, push 5, push 7, push 4, push 5, pop, peek, pop, pop, pop`, that is `operations = ["push", …]`, `values = [[5], [7], [5], [7], [4], [5], [], [], [], [], []]` → `[1, 1, 2, 2, 1, 3, 5, 7, 7, 5, 4]`.
