# List without outrun nodes

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-536?utm_source=github&utm_medium=tasks-repo)**

A linked list is given by arrays: node `i` holds the number `values[i]` and a link `next[i]` to the next node (`-1` for the last node). `head` is the index of the first node (`-1` for an empty list, then the arrays are empty). Nodes lie in the arrays in any order, follow the links.

Remove from the list every node that has a node with a strictly larger number somewhere after it (further along the list). The other nodes keep their order. Return the numbers of the remaining nodes in order. The last node always stays. Numbers may be negative.

Example: `values = [5, 2, 13, 3, 8]`, `next = [1, 2, 3, 4, -1]`, `head = 0` → `[13, 8]` (after 5, 2 and 3 there is a larger number, while 13 and 8 have no larger number to the right).
