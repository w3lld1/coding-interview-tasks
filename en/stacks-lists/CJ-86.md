# Hidden pancakes

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Trees and graphs](../trees-graphs/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-86?utm_source=github&utm_medium=tasks-repo)**

We cook `n` pancakes with radii 1, 2, …, `n` (each radius exactly once) in some order. Each new pancake is laid on top of the stack with centres aligned. A pancake is visible from the top until a pancake with a larger radius is laid on it; once covered by a larger one, it is never visible again.

You are given a list `visible` of length `n`: `visible[i]` is how many pancakes are visible right after the first `i + 1` pancakes are on the stack. Return how many of the `n!` cooking orders produce exactly this list, modulo the prime `1000000007`. If no order fits (for example, the visible count grows by more than one in a step), return `0`.

It is guaranteed that `1 ≤ visible[i] ≤ i + 1`; `n` goes up to a few thousand, so enumerating orders is too slow.

Example: `[1, 2, 2, 1]` → `1` (only the order 3, 1, 2, 4 fits).
