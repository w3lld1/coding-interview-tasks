# Next greater element in a circle

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-13?utm_source=github&utm_medium=tasks-repo)**

You get a list of numbers that is treated as a circle: after the last element comes the first one again. For each element, return the nearest number strictly greater than it when moving forward around the circle from its position (at most one full lap). If there is none, return `-1`. The result has the same length as the input and is empty for an empty list. An element is not compared with itself on the second lap: the search for it ends there.

Example: `[1, 2, 1]` → `[2, -1, 2]`.
