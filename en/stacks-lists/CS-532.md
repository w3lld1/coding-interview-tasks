# Remove the node n-th from the end

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-532?utm_source=github&utm_medium=tasks-repo)**

A linked list is given by arrays: node `i` holds the number `values[i]` and a link `next[i]` to the next node (`-1` for the last node). `head` is the index of the first node (`-1` for an empty list, then the arrays are empty). Nodes lie in the arrays in any order, follow the links.

Remove from the list the node that stands `n`-th from the end (the last node is first from the end) and return the numbers of the remaining nodes in list order. If `n` is larger than the list length, the list does not change. Assume `n ≥ 1`.

Example: `values = [1, 2, 3, 4, 5]`, `next = [1, 2, 3, 4, -1]`, `head = 0`, `n = 2` → `[1, 2, 3, 5]`.
