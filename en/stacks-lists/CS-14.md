# Reverse Polish notation

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-14?utm_source=github&utm_medium=tasks-repo)**

You get a list of tokens of an expression in reverse Polish (postfix) notation: each token is either an integer (possibly negative, such as `"-3"`) or one of the operators `"+"`, `"-"`, `"*"`, `"/"`. Evaluate it. An operator takes the last two computed values, and the value computed earlier is the left operand. Division is integer division that rounds toward zero (`-7 / 2` is `-3`). The expression is valid, there is no division by zero, and every intermediate value fits in a 32-bit integer.

Example: `["4", "13", "5", "/", "+"]` → `6` (13 / 5 = 2, then 4 + 2).
