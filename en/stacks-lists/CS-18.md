# Remove k digits for the smallest number

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-18?utm_source=github&utm_medium=tasks-repo)**

You get a string `number` of digits representing a non-negative integer and an integer `k` (from `0` to the length of the string). Remove exactly `k` digits so that the resulting number is as small as possible; the remaining digits keep their order. Return the result as a string without leading zeros; if no digits are left or all remaining digits are zeros, return `"0"`. The string has up to a few thousand digits, so a linear algorithm is expected.

Example: `"1432219"`, `3` → `"1219"`.
