# Adding numbers stored as digit lists

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-273?utm_source=github&utm_medium=tasks-repo)**

A non-negative number is written as a linked list of digits, **least significant digit first**. The list is given by arrays: node `i` holds the digit `values[i]` (`0..9`) and a link `next[i]` to the next node (`-1` for the last). `head` is the index of the first node; `-1` means an empty list, that is the number `0`. The order of nodes in the arrays is arbitrary, follow the links.

You get two such numbers (`values_a`, `next_a`, `head_a` and `values_b`, `next_b`, `head_b`). Return their sum in the same form: a list of digits from the least to the most significant, with no extra zeros at the end. For the sum `0` return `[0]`.

Example: `[2, 4, 3]` (that is 342) and `[5, 6, 4]` (that is 465) in traversal order → `[7, 0, 8]` (that is 807).
