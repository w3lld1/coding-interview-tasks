# Merge two sorted linked lists

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-528?utm_source=github&utm_medium=tasks-repo)**

Two linked lists lie in the same arrays: node `i` holds the number `values[i]` and a link `next[i]` to the next node of its own list (`-1` for the last). `head_a` and `head_b` are the indexes of the first nodes of the first and the second list, `-1` for an empty list. Each list is sorted in non-decreasing order, the nodes of the two lists are mixed in the arrays in any way, and there are no shared nodes. The arrays may also hold nodes that belong to neither list.

Return the numbers of both lists as one list in non-decreasing order (a merge).

Example: `values = [1, 2, 4, 3]`, `next = [2, 3, -1, -1]`, `head_a = 0`, `head_b = 1` (the lists `1 → 4` and `2 → 3`) → `[1, 2, 3, 4]`.
