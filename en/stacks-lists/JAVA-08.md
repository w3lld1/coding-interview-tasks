# Circular Buffer

**Difficulty:** medium · **Language:** Java · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Errors and exceptions](../errors/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-08?utm_source=github&utm_medium=tasks-repo)**

Create a fixed-capacity buffer from which elements are read in the order they arrived. A regular write to a full buffer and a read from an empty one must fail with an error, while an overwrite into a full buffer replaces the oldest element. If there is free space, an overwrite acts like a regular write; also implement clearing the whole buffer.
