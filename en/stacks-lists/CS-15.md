# Expand bracketed repeats

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-15?utm_source=github&utm_medium=tasks-repo)**

A string is encoded with the rule `k[text]`: the fragment inside the square brackets is repeated `k` times. Brackets may be nested, `k` may have several digits (and may be `0`), and plain text may also stand outside brackets. Digits appear only as the multiplier `k` before a `[`; the original text contains no digits. The encoding is valid and brackets always contain at least one character. Return the decoded string; for an empty string return an empty string. The result is at most a few thousand characters long.

Example: `"3[a2[c]]"` → `"accaccacc"`.
