# Wagons through a dead-end siding

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-533?utm_source=github&utm_medium=tasks-repo)**

Wagons numbered `1, 2, ..., n` arrive at a station one by one in exactly that order. Each arriving wagon enters a dead-end siding where wagons stand one behind another, and only the last wagon that entered can leave the siding. A wagon can be released from the siding onto the exit track at any moment, and the next wagon does not have to arrive yet. Wagons on the exit track line up in the order of release.

`order` is the wanted order of wagons on the exit track; it is a permutation of the numbers 1 to n (an empty list for `n = 0`). Return `true` if this order can be reached, otherwise `false`.

Example: `[3, 2, 1]` → `true`; `[3, 1, 2]` → `false` (to release 3 and then 1, wagon 2 would have to stand under 3 and block the way).
