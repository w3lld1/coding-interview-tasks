# Text after typing with backspaces

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-525?utm_source=github&utm_medium=tasks-repo)**

A user presses keys one by one. The string `keys` is the sequence of presses: an ordinary character (a letter, a digit or a space) is typed at the end of the text, while the character `<` is the backspace key: it erases the last typed character, or does nothing if the text is empty. Return the final text.

Example: `"abc<<d"` → `"ad"`.
