# Price streak counter

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-117?utm_source=github&utm_medium=tasks-repo)**

Implement a "price counter" that starts empty. You get a list of operations `operations` and a list of arguments `values`: the arguments of `operations[i]` are in `values[i]`. Return a list of results, one per operation. The operations:
- `"next"` with argument `[price]` — the price of the next day arrives. Result: the day's "span", i.e. the number of consecutive days ending today whose price was at most today's (today included; only days after the last `reset` count).
- `"reset"` with empty arguments — forget all days. Result `0`.
- `"max_span"` with empty arguments — the largest span among all days after the last `reset`, `0` if there are none.

Up to 2000 operations, prices are integers.

Example: operations `["next", "next", "next", "next"]`, arguments `[[100], [80], [60], [70]]` → `[1, 1, 1, 2]`.
