# Linked List

**Difficulty:** medium · **Language:** Python · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-18?utm_source=github&utm_medium=tasks-repo)**

Implement a doubly linked list with node and list classes that supports adding and removing at both ends and getting the length via len. Add deletion of the first node with a given value, correctly updating both neighbouring links and the list boundaries. Removing from an end of an empty list raises IndexError, and deleting a value that is not present raises ValueError.
