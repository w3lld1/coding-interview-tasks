# Erasing runs of equal stickers

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-276?utm_source=github&utm_medium=tasks-repo)**

A row of stickers lies on a tape, each marked with a lowercase Latin letter (the string `row`). While the tape contains a run of `k` or more equal letters in a row, take the leftmost such run (a maximal one, not a part of a longer run) and erase it whole; the remaining parts of the tape stick together, and letters that end up side by side form one run (for example `aa` and `aa` make `aaaa`). Repeat until nothing can be erased and return the remaining string. Assume `k ≥ 1`.

Example: `"aabbbbaa"`, `k = 3` → `""` (`bbbb` is erased, `aaaa` remains, and it is erased too).
