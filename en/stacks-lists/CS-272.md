# Reverse the odd groups of a list

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-272?utm_source=github&utm_medium=tasks-repo)**

A linked list is given by arrays: node `i` holds the number `values[i]` and a link to the next node `next[i]` (`-1` for the last node). `head` is the index of the first node (`-1` for an empty list, then the arrays are empty). Nodes may lie in the arrays in any order, follow the links.

Split the list into groups of `k` consecutive nodes counted from the head: group 1, group 2 and so on; the last group may be shorter. **Reverse** the odd-numbered groups (the first, the third, …) when they have exactly `k` nodes; leave the other groups, a short last one included, as they are. Return the numbers of the list after that, in traversal order. Assume `k ≥ 1`.

Example: `values = [10, 20, 30, 40, 50, 60, 70]`, `next = [1, 2, 3, 4, 5, 6, -1]`, `head = 0`, `k = 2` → `[20, 10, 30, 40, 60, 50, 70]`.
