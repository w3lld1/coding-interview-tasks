# Interleave a list from both ends

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-535?utm_source=github&utm_medium=tasks-repo)**

A linked list is given by arrays: node `i` holds the number `values[i]` and a link `next[i]` to the next node (`-1` for the last node). `head` is the index of the first node (`-1` for an empty list, then the arrays are empty). Nodes lie in the arrays in any order, follow the links.

Let the list hold nodes `L0, L1, ..., L(n-1)` in order. Rearrange it as `L0, L(n-1), L1, L(n-2), L2, ...`: alternate a node from the front with a node from the back until all nodes are used (for an odd `n` the middle node goes last). Return the numbers in the new order.

Example: `values = [1, 2, 3, 4, 5]`, `next = [1, 2, 3, 4, -1]`, `head = 0` → `[1, 5, 2, 4, 3]`.
