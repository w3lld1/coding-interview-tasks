# Where the cycle begins

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-63?utm_source=github&utm_medium=tasks-repo)**

A singly linked list is stored as a list of indexes: `next_index[i]` is the index of the node after node `i`, or `-1` when `i` is the last node. The parameter `head` is the index of the first node (`-1` for an empty list). Some nodes may be unreachable from `head`; ignore them.

If walking from `head` eventually returns to a node already visited, return the index of the first such node, the one where the cycle begins. If the chain reaches `-1`, return `-1`. There are at most 10 000 nodes; a solution with O(1) extra memory is the better one.

Example: `next_index = [1, 2, 3, 1]`, `head = 0` → `1` (the chain is `0 → 1 → 2 → 3 → 1`).
