# Circular Buffer

**Difficulty:** medium · **Language:** Python · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-11?utm_source=github&utm_medium=tasks-repo)**

Implement a fixed-capacity buffer with operations to write, read the oldest element, overwrite, and clear. Reading removes the returned element; reading from an empty buffer and a regular write to a full one must raise BufferEmptyException and BufferFullException respectively. An overwrite replaces the oldest element only when the buffer is full; otherwise it works like a regular write. After clearing, the full capacity is available again.
