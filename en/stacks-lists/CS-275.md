# Shared node of two chains

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-275?utm_source=github&utm_medium=tasks-repo)**

Nodes are numbered `0..n-1`, the link `next[i]` leads from node `i` to the following node (`-1` means the end of a chain). There are no cycles. Two chains start at nodes `head_a` and `head_b` (`-1` means an empty chain). The chains may merge: from some node on they share a tail.

Return the index of the first node of chain A (counting from `head_a`) that also lies on chain B. If there is no shared node, return `-1`. If `head_a` and `head_b` are equal, the answer is that node itself.

Example: `next = [1, 2, 3, 4, -1, 2]`, `head_a = 0`, `head_b = 5` → `2` (chains `0→1→2→3→4` and `5→2→3→4` merge at node 2).
