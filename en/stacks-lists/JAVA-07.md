# Linked List

**Difficulty:** medium · **Language:** Java · **Topics:** [Stacks, queues, linked lists](../stacks-lists/), [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-07?utm_source=github&utm_medium=tasks-repo)**

Implement your own doubly linked list in which a node stores a value and references to its neighbours. Support adding and removing elements at both ends: push/pop for the tail and unshift/shift for the head. Sequences of operations must work correctly after the list has been emptied and when it holds a single element.
