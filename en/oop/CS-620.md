# Editor with selection, clipboard and undo

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Strings](../strings/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-620?utm_source=github&utm_medium=tasks-repo)**

Implement a single-line text editor. At first the text is empty, the cursor is at position `0`, there is no selection and the clipboard is empty. You get a list of commands `commands`; each command is a list of strings: the name and its arguments (numbers are written as decimal strings). After each command append the editor state to the answer: the text with the character `|` inserted at the cursor position, or, when there is a selection, the text with the selected part wrapped in `[` and `]` (then no `|` is written).

Commands:
- `["type", s]`: insert the non-empty string `s` (letters, digits, spaces) at the cursor; if there is a selection, `s` replaces it. The cursor ends after the inserted text and the selection is cleared.
- `["select", a, b]`: select the characters from position `min(a, b)` up to (not including) `max(a, b)`; both numbers are first clamped to `[0, text length]`. If they are equal, there is no selection and the cursor moves to that position.
- `["left", k]`, `["right", k]` (`k` ≥ 0): with a selection the cursor moves to its start (`left`) or end (`right`) and the selection is cleared, whatever `k` is; without one the cursor moves by `k`, staying within the text.
- `["backspace"]`: delete the selection, or without one the character before the cursor (nothing happens at the start of the text).
- `["copy"]`: put the selected text into the clipboard (nothing happens without a selection). `["cut"]`: the same, and delete the selection. `["paste"]`: like `type` with the clipboard content; nothing happens when the clipboard is empty.
- `["undo"]`: undo the last text-changing step and restore the text, cursor and selection as they were before that step. `["redo"]`: bring back the last undone step (the state right after it). If there is nothing to undo or redo, nothing happens.

A text-changing step is each `type`, `backspace`, `cut` or `paste` command that changed the text; such a command clears the steps available to `redo`. The exception: a `type` right after another `type` in the list does not start a new step but extends the previous one, so one `undo` reverts both. Up to 300 commands.

Example: `[["type", "hi"], ["type", "!"], ["undo"]]` → `["hi|", "hi!|", "|"]`.
