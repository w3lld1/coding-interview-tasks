# Prepaid metro card

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-255?utm_source=github&utm_medium=tasks-repo)**

Implement a prepaid metro card. The balance starts at `0`. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"top_up"` with one argument `amount`: add `amount` to the balance; result: the new balance. If `amount` ≤ 0, report an error: throw an exception, or return an error in Go.
- `"ride"` with one argument `fare`: charge a ride; result: the new balance. If `fare` is greater than the balance, report an error: throw an exception, or return an error in Go. A ride that costs exactly the whole balance is allowed.
- `"balance"` with no arguments: result: the current balance.

The error applies to the whole call: the first bad operation aborts it and no partial result is returned.

Example: `["top_up", "ride", "balance"]`, `[[50], [18], []]` → `[50, 32, 32]`.
