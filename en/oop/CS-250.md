# Interrupted work stack

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-250?utm_source=github&utm_medium=tasks-repo)**

A developer keeps getting interrupted: a new task pauses the current one, and the old one resumes when the new one is done. At first there are no tasks. Implement the operations:
- `start` (id, minutes): take a new task with a positive id and positive time; it becomes current and the previous one waits. The result is the number of tasks in progress;
- `work` (minutes): spend the given minutes on the current task only (unused minutes do not pass to another task). If the task needed no more than that, it is finished and the result is its id; otherwise the minutes are subtracted and the result is `0`. If there are no tasks, the result is `-1`;
- `current`: the result is the id of the current task, or `-1` if there are none;
- `remaining`: the result is the minutes left on the current task, or `-1` if there are none.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["start", "start", "work", "work", "current", "work", "remaining"]`, `[[1, 10], [2, 4], [3], [3], [], [5], []]` → `[1, 2, 0, 2, 1, 0, 5]`.
