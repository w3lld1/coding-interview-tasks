# Windowing System

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Classes and OOP](../oop/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-19?utm_source=github&utm_medium=tasks-repo)**

Create Size(width=80, height=60) with a resize method and Position(x=0, y=0) with a move method; implement these two types using constructor functions and prototypes. The ProgramWindow class stores an 800×600 screen and a default size and position. Its resize clamps the dimensions to a minimum of 1 and to the space left before the screen edge, and move clamps the coordinates to zero and to bounds that keep the window entirely on the screen. The changeWindow function must set the size to 400×300 and the position to (100, 150), returning the passed instance.
