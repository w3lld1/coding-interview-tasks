# Recently closed tabs

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-513?utm_source=github&utm_medium=tasks-repo)**

A browser keeps its open tabs in the order they were opened (a tab id is an integer) and a stack of recently closed tabs. Everything starts empty. Operations:
- `open` (id): if tab id is not among the open tabs, open it at the end of the list and, if it was among the closed ones, remove it from there; if it is already open, change nothing. The result is the number of open tabs;
- `close` (id): if tab id is open, close it (it goes onto the top of the closed stack) and the result is `1`; otherwise nothing happens and the result is `0`;
- `reopen`: bring back the most recently closed tab: it leaves the closed stack and opens at the end of the list; the result is its id, or `-1` if nothing is closed;
- `count`: the result is the number of open tabs;
- `last`: the result is the id of the last open tab, or `-1` if none is open.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["open", "open", "open", "close", "close", "reopen", "last", "reopen", "last", "reopen", "count"]`, `[[1], [2], [3], [2], [3], [], [], [], [], [], []]` → `[1, 2, 3, 1, 1, 3, 3, 2, 2, -1, 3]`.
