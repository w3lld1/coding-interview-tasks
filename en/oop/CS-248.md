# Music play queue

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-248?utm_source=github&utm_medium=tasks-repo)**

A player keeps a queue of songs (positive numbers), a history of played songs and the current song (`0` if nothing is playing). At first everything is empty. Implement the operations:
- `add` (song): put it at the end of the queue; the result is the queue length;
- `play_next` (song): put it at the front of the queue so it plays next; the result is the queue length;
- `skip`: if the queue is not empty, the current song (if any) goes to the history and the first song of the queue becomes current; with an empty queue nothing changes. The result is the current song;
- `previous`: if the history is not empty, the current song (if any) returns to the front of the queue and the last song of the history becomes current; with an empty history nothing changes. The result is the current song;
- `now`: the result is the current song.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["add", "add", "add", "skip", "skip", "previous", "play_next", "skip", "now"]`, `[[1], [2], [3], [], [], [], [9], [], []]` → `[1, 2, 3, 1, 2, 1, 3, 9, 9]`.
