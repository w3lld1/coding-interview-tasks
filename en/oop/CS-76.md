# Running median

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Searching and sorting](../search-sort/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-76?utm_source=github&utm_medium=tasks-repo)**

Numbers arrive one at a time, and at any moment you must quickly report the median of all numbers received so far. The function receives a list of operations `operations` and a list of arguments `values`: `values[i]` holds the arguments of `operations[i]`. Return a list of results, one per operation. The collection starts empty.

Operations:
- `add` — arguments `[x]`: add the integer `x` to the collection; the result is `null`;
- `median` — no arguments (`[]`): the result is the median of all numbers added so far, or `null` if the collection is empty.

The median is the middle element of the sorted collection when it has an odd count, and the average of the two middle elements when the count is even (a fractional result, for example `1.5`). Repeated numbers each count separately. There are up to 5000 operations and every number is at most 10⁶ in absolute value; answer `median` faster than by sorting the whole collection.

Example: `["add", "add", "median", "add", "median"]`, `[[1], [2], [], [3], []]` → `[null, null, 1.5, null, 2.0]`.
