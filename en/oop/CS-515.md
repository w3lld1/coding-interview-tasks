# Plate stacks of three

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-515?utm_source=github&utm_medium=tasks-repo)**

A canteen piles plates into stacks of at most 3. The stacks stand in a row, numbered from 0 left to right; at first there are none. A plate is an integer. Operations:
- `push` (x): put plate x on the last stack, or start a new stack on the right if there are no stacks or the last one already has 3 plates; the result is the number of stacks;
- `pop`: take the top plate of the last stack; the result is its number, or `-1` if there are no stacks;
- `pop_at` (i): take the top plate of the stack numbered i; the result is its number, or `-1` if there is no such stack. The other stacks are not rearranged;
- `stacks`: the result is the number of stacks;
- `total`: the result is the number of all plates.

A stack that becomes empty disappears, and the numbers of the stacks to its right drop by 1.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["push", "push", "push", "push", "push", "stacks", "total", "pop_at", "pop", "pop", "stacks", "total"]`, `[[1], [2], [3], [4], [5], [], [], [0], [], [], [], []]` → `[1, 1, 1, 2, 2, 2, 5, 3, 5, 4, 1, 2]`.
