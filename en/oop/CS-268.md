# Spreadsheet cells with sum formulas

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Trees and graphs](../trees-graphs/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-268?utm_source=github&utm_medium=tasks-repo)**

Implement a mini spreadsheet. Cells are identified by integers. A cell with no content equals `0`. A cell holds either a number or a sum formula: the sum of the values of other cells. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"set_value"` with arguments `cell`, `x`: store the number `x` in the cell, replacing its earlier formula if any; the result is always `1`.
- `"set_sum"` with arguments `cell`, `d1`, …, `dk` (`k` ≥ 0): make the content of the cell the sum of cells `d1…dk` (a number may repeat, then that cell is added several times; for `k = 0` the sum is `0`). If the formulas would then depend on each other in a circle (including a cell inside its own sum, directly or through other cells), the operation is rejected: the sheet does not change and the result is `0`. Otherwise the result is `1`.
- `"get"` with argument `cell`: result: the current value of the cell, formulas are recomputed from the current values.

Example: `["set_value", "set_value", "set_sum", "get", "set_value", "get"]`, `[[1, 5], [2, 7], [3, 1, 2], [3], [1, 10], [3]]` → `[1, 1, 1, 12, 1, 17]`.
