# A queue that can be turned around

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-519?utm_source=github&utm_medium=tasks-repo)**

A queue for a ride can be turned around: the person who stood last becomes the first. The queue starts empty. Operations:
- `enqueue` (x): person number x joins the end of the queue; the result is the queue length;
- `dequeue`: the first person leaves the queue; the result is their number, or `-1` if the queue is empty;
- `reverse`: the order of everyone standing is reversed (the last becomes the first); the result is the queue length. New people join the end of the already reversed queue;
- `front`: the result is the number of the first person, or `-1` if the queue is empty;
- `back`: the result is the number of the last person, or `-1` if the queue is empty.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["enqueue", "enqueue", "enqueue", "front", "back", "reverse", "front", "back", "enqueue", "dequeue", "dequeue", "reverse", "dequeue", "dequeue", "dequeue"]`, `[[1], [2], [3], [], [], [], [], [], [4], [], [], [], [], [], []]` → `[1, 2, 3, 1, 3, 3, 3, 1, 4, 3, 2, 2, 4, 1, -1]`.
