# Clock

**Difficulty:** medium · **Language:** Java · **Topics:** [Classes and OOP](../oop/), [Math](../math/), [Dates and time](../dates/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-20?utm_source=github&utm_medium=tasks-repo)**

Create a clock that stores the time of day without a date and displays it in HH:mm format. Normalize arbitrary hour and minute values, and support adding and subtracting minutes with rollover past midnight. Two instances showing the same normalized time must be considered equal.
