# Document with undo and redo

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-241?utm_source=github&utm_medium=tasks-repo)**

A document is a list of integers, empty at first. Commands change its end, and they can be undone and redone. Implement the operations:
- `insert` (x): append x to the end; the command is remembered for undo, and anything that could be redone is forgotten;
- `erase`: remove the last number. In an empty document nothing happens and the command is not remembered; otherwise it is remembered for undo and anything redoable is forgotten;
- `undo`: undo the latest command that has not been undone (an insert removes its number, an erase brings its number back); if there is nothing to undo, nothing happens;
- `redo`: redo the most recently undone command, provided no new `insert` or `erase` has happened since; otherwise nothing happens;
- `last`: the result is the last number of the document, or `-1` if it is empty.

For every operation except `last` the result is the document length after the operation. Return the list of results. `values[i]` holds the arguments of operation `i`.

Example: `["insert", "insert", "erase", "undo", "undo", "redo", "last"]`, `[[4], [7], [], [], [], [], []]` → `[1, 2, 1, 2, 1, 2, 7]`.
