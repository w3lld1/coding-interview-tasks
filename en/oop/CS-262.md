# Step tracker by days

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-262?utm_source=github&utm_medium=tasks-repo)**

Implement a step counter with a daily history. At first there is one day with `0` steps, and it is the current day. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"add"` with argument `steps`: add steps to the current day; result: the step total of the current day.
- `"new_day"` with no arguments: close the current day and start a new one with `0` steps; result: the number of closed days.
- `"best"` with no arguments: result: the largest step total of a single day among all days, the current one included.
- `"goal_days"` with argument `goal`: result: how many days, the current one included, reached at least `goal` steps.

Example: `["add", "new_day", "add", "goal_days"]`, `[[5], [], [9], [6]]` → `[5, 1, 9, 1]`.
