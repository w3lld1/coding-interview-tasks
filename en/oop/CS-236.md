# Printer queue

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-236?utm_source=github&utm_medium=tasks-repo)**

A printer takes jobs in the order they arrive and prints one page per operation. At first the queue is empty. Implement the operations:
- `submit` (job, pages): add a job with the given number and page count to the end of the queue (both positive; job numbers in the queue are distinct); the result is the queue length after adding;
- `print_page`: print one page of the first job. If that was its last page, the job leaves the queue and the result is its number; if pages remain, the result is `0`; if the queue is empty, the result is `-1`;
- `pending_pages`: the result is the total of pages still left across all jobs in the queue.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["submit", "submit", "print_page", "print_page", "print_page", "print_page"]`, `[[1, 2], [2, 1], [], [], [], []]` → `[1, 2, 0, 1, 2, -1]`.
