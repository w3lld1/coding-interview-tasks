# Cinema row seats

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-258?utm_source=github&utm_medium=tasks-repo)**

Implement seat booking for one row of a cinema. Seats are numbered from `1` to `seats`, all free at first. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"book"` with argument `seat`: take the seat; result: the number of free seats. If there is no such seat or it is taken, report an error: throw an exception, or return an error in Go.
- `"cancel"` with argument `seat`: release the seat; result: the number of free seats. If there is no such seat or it is not taken, report an error: throw an exception, or return an error in Go.
- `"is_free"` with argument `seat`: result `1` if the seat is free, otherwise `0`. If there is no such seat, report an error: throw an exception, or return an error in Go.
- `"free"` with no arguments: result: the number of free seats.
- `"first_free"` with no arguments: result: the smallest number of a free seat, or `-1` if none is free.

The error applies to the whole call: the first bad operation aborts it.

Example: `3`, `["book", "first_free", "cancel"]`, `[[1], [], [1]]` → `[2, 2, 3]`.
