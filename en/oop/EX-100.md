# Stopwatch with laps

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-100?utm_source=github&utm_medium=tasks-repo)**

A stopwatch has a state (`ready` initially, `running`, `stopped`), the time of the current lap and a list of finished laps. The function gets a list of operations `operations` and a list of arguments `values` (`values[i]` holds the arguments of `operations[i]`, an empty list if there are none) and returns a list of results, one per operation. At the start the stopwatch is `ready` and the time is 0.

Operations:
- `"start"` (from `ready` or `stopped` to `running`) time starts to run; from `running` it is an error;
- `"stop"` (from `running` to `stopped`); from any other state it is an error;
- `"lap"` (only in `running`) adds the current lap to the finished ones and zeroes it, the state stays `running`; otherwise an error;
- `"reset"` (from `stopped` to `ready`) zeroes the current lap and clears the finished ones; otherwise an error;
- `"advance_time"` with the argument `"HH:MM:SS"`: that much time passed; it counts only in `running` and is ignored in other states;
- `"state"` returns the state name; `"current_lap"` returns the time of the current lap; `"total"` returns the total time (finished laps plus the current one); `"previous_laps"` returns the times of the finished laps joined by commas (no spaces), an empty string if there are none.

Time is written as `HH:MM:SS` with at least two digits per part (`%02d`). The result of an operation that returns nothing (`start`, `stop`, `lap`, `reset`, `advance_time`) is `""`, and of an invalid operation `"error"` (the state does not change then).

Example: `["start", "advance_time", "lap", "previous_laps"]`, `[[], ["00:01:38"], [], []]` → `["", "", "", "00:01:38"]`.
