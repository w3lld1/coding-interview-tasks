# User hit counter over windows

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Searching and sorting](../search-sort/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-622?utm_source=github&utm_medium=tasks-repo)**

Implement a counter of hits on a service, empty at first. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation. A user is an integer ≥ 0 and a time is an integer ≥ 0. Hits may arrive out of time order (late events). A window `(t, w)` (`w` ≥ 1) is the set of moments `x` with `t − w < x ≤ t`; the query moment `t` may be anything, including earlier or later than every hit.

Operations:
- `"hit"` with arguments `user`, `time`: a hit by the user at moment `time` (hits at the same moment count separately). Result: how many hits of this user are stored now.
- `"count"` with arguments `user`, `t`, `w`: the number of the user's hits in the window.
- `"total"` with arguments `t`, `w`: the number of hits of all users in the window.
- `"top"` with arguments `t`, `w`: the user with the most hits in the window; on a tie the smaller number; `-1` if the window has no hits.
- `"active"` with arguments `t`, `w`, `k` (`k` ≥ 1): how many users have at least `k` hits in the window.
- `"forget"` with argument `user`: delete all the user's hits. Result: how many were deleted.

Up to 2000 operations and at most 50 different users.

Example: `["hit", "hit", "hit", "count", "top"]`, `[[7, 10], [7, 11], [3, 11], [7, 11, 1], [11, 5]]` → `[1, 2, 1, 1, 7]`.
