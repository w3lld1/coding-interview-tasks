# In-memory file system with moves

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Trees and graphs](../trees-graphs/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-621?utm_source=github&utm_medium=tasks-repo)**

Implement an in-memory file system. At first there is only the empty root directory `/`. You get a list of commands `commands`; each command is a list of strings: the name and its arguments. A path is absolute: `/` or names separated by `/`, such as `/docs/plan.txt`; a name is a non-empty string of lowercase Latin letters, digits and dots, and a path never ends with `/`. Return a list of results, one per command.

Commands:
- `["mkdir", path]`: create the directory and every missing directory on the way to it; existing directories stay as they are. Result `""`.
- `["write", path, size]`: create a file of size `size` (a decimal string, 0 to 10⁶) or overwrite the size of an existing file. Result `""`.
- `["size", path]`: the size of a file, or the total size of all files inside a directory at any depth, as a decimal string.
- `["ls", path]`: for a directory, the names of its direct children in lexicographic order joined by commas (`""` when it is empty); for a file, its own name.
- `["mv", src, dst]`: move a file or a directory with everything inside so that its full path becomes `dst`. Result `""`.
- `["rm", path]`: delete a file or a directory with everything inside. Result: the size of what was deleted, as for `size`.

Report an error (throw an exception, or return an error in Go) if: `mkdir` meets a file on the way or at `path` itself; `write` has no parent directory (or the parent is a file) or `path` is a directory; `size`, `ls`, `rm` or `mv` name a path that does not exist; `rm` or `mv` name the root; for `mv`, `dst` already exists, its parent is missing or is a file, or `dst` lies inside `src`. The error applies to the whole call: the first bad command aborts it. Up to 300 commands.

Example: `[["mkdir", "/a"], ["write", "/a/f", "5"], ["size", "/"]]` → `["", "", "5"]`.
