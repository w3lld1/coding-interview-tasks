# Browser history

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-235?utm_source=github&utm_medium=tasks-repo)**

A browser keeps a page history. Pages are integers; at the start page `0` is open and both the back and the forward histories are empty. Implement the operations; each returns the current page after it:
- `visit` (page): open the page; the old current page goes to the back history and the forward history is cleared;
- `back` (k): go back up to k steps (fewer if the history runs out); the pages passed go to the forward history;
- `forward` (k): go forward up to k steps in the same way;
- `current`: change nothing.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list for `current`).

Example: `["visit", "visit", "back", "forward", "back"]`, `[[5], [7], [1], [3], [4]]` → `[5, 7, 5, 7, 0]`.
