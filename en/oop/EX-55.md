# School roster

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-55?utm_source=github&utm_medium=tasks-repo)**

Implement a school roster that starts empty and replay a list of operations on it. Operation `operations[i]` gets the arguments `values[i]` (all strings), every operation produces one string, and the answer is the list of these strings in order.

- `"add"`, arguments `[name, grade]` (the grade is a decimal number as a string): adds a student. A student cannot be added twice, not to another grade and not to the same one. Result: `"true"` if the student was added and `"false"` if the name is already present (the roster does not change).
- `"grade"`, argument `[grade]`: the result is the names of the students of this grade in alphabetical order, joined by commas without spaces; with no students it is an empty string `""`.
- `"roster"`, no arguments: the result is the names of all students joined by commas: by ascending grade first, alphabetically inside a grade. An empty roster gives an empty string.

Names are single words without commas and compare as ordinary strings.

Example: operations `["add", "add", "roster"]`, values `[["Jim", "2"], ["Anna", "1"], []]` → `["true", "true", "Anna,Jim"]`.
