# Hero with health and mana

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-261?utm_source=github&utm_medium=tasks-repo)**

Implement a game hero. At the start it has `max_hp` health and `10` mana. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"hit"` with argument `damage`: take health away, but not below `0`; result: the health. A hero with `0` health has fallen.
- `"heal"` with argument `amount`: add health, but not above `max_hp`; result: the health. If the hero has fallen, report an error: throw an exception, or return an error in Go.
- `"cast"` with argument `cost`: spend `cost` mana; result: the mana after that. If the hero has fallen or `cost` is greater than the current mana, report an error: throw an exception, or return an error in Go.
- `"rest"` with no arguments: restore the mana to `10`; result: `10`. Rest works for a fallen hero too.
- `"hp"` and `"mana"` with no arguments: result: the current health or mana.

The error applies to the whole call: the first bad operation aborts it.

Example: `30`, `["hit", "cast", "hp"]`, `[[12], [4], []]` → `[18, 6, 18]`.
