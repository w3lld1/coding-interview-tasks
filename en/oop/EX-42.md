# Clock without a date

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-42?utm_source=github&utm_medium=tasks-repo)**

Implement a clock that shows the time of day without a date. The function gets a list of operations `operations` and a list of arguments `values` (`values[i]` holds the arguments of `operations[i]`) and returns a list of results, one per operation. At the start the clock shows `00:00`.

- `"set"`, arguments `[hours, minutes]`: set the time. The numbers may be any integers, including negative ones and ones above 23 or 59: the time is `hours·60 + minutes` minutes modulo a day (1440). Result: the new time as `"HH:MM"`.
- `"add"`, argument `[minutes]`: add minutes (possibly more than a day). Result: the new time `"HH:MM"`.
- `"subtract"`, argument `[minutes]`: subtract minutes. Result: the new time `"HH:MM"`. Counting goes back across midnight: `00:03` minus 4 minutes is `23:59`.
- `"equals"`, arguments `[hours, minutes]`: compare the current time with the time given by the same rules, without changing the clock. Result: `"true"` or `"false"`.

Example: operations `["set", "add"]`, arguments `[[23, 59], [2]]` → `["23:59", "00:01"]`.
