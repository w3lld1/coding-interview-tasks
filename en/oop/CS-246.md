# Open tag tracker

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-246?utm_source=github&utm_medium=tasks-repo)**

A markup editor tracks nested open tags; tags are positive numbers (their kinds), and several nested tags may share a kind. At first no tag is open. Implement the operations:
- `open` (tag): open a tag inside all open ones; the result is the number of open tags;
- `close` (tag): strict close. If the innermost open tag is exactly this one, it is closed and the result is `1`; otherwise nothing changes and the result is `0`;
- `close_through` (tag): close the nearest-to-the-end open tag of this kind together with every tag opened after it. The result is how many tags were closed, or `0` if there is no such tag (nothing changes then);
- `top`: the result is the innermost open tag, or `0` if none is open;
- `depth`: the result is the number of open tags.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["open", "open", "open", "close", "close_through", "top", "depth"]`, `[[1], [2], [3], [2], [2], [], []]` → `[1, 2, 3, 0, 2, 1, 1]`.
