# Least frequently used (LFU) cache

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-208?utm_source=github&utm_medium=tasks-repo)**

Implement a fixed-capacity cache that evicts the least frequently used key (LFU) and run a list of operations in order. `operations[i]` is the operation name and `values[i]` holds its arguments. The first operation is always `"init"`, it appears once, `values[i] = [capacity]` (the capacity is at least 1), and the cache starts empty.

Every key in the cache has a use counter. `"get"` with `[key]` returns the key's value and adds 1 to its counter, or returns `-1` if the key is absent. `"put"` with `[key, value]` on a present key changes the value and adds 1 to the counter; for a new key, if the cache is full, it first removes the key with the smallest counter (on a tie, the one used longest ago: its last `get` or `put` came earliest), then adds the new key with counter 1. A removed key loses its counter. For every operation return a number: `0` for `"init"` and `"put"`, and the value or `-1` for `"get"`. Ideally `get` and `put` run in O(1).

Example: `["init", "put", "put", "get", "put", "get", "get"]`, `[[2], [1, 1], [2, 2], [1], [3, 3], [2], [3]]` → `[0, 0, 0, 1, 0, -1, 3]` (key 1 has counter 2 and key 2 has 1, so `put(3, 3)` evicts key 2).
