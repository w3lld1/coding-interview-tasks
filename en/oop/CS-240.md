# Sensor ring buffer

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-240?utm_source=github&utm_medium=tasks-repo)**

A sensor keeps only its last k readings (non-negative integers): a new reading pushes out the oldest one when the space is full. The first operation is always `start`. Implement the operations:
- `start` (k): create an empty buffer of capacity k (k ≥ 1), forgetting the old one; the result is `0`;
- `add` (x): add a reading. If the buffer was full, the oldest reading is pushed out and the result is its value; otherwise the result is `-1`;
- `sum`: the result is the sum of the readings in the buffer (`0` if empty);
- `max`: the result is the largest reading in the buffer, or `-1` if the buffer is empty.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["start", "add", "add", "add", "add", "sum", "max"]`, `[[3], [5], [8], [2], [9], [], []]` → `[0, -1, -1, -1, 5, 19, 9]`.
