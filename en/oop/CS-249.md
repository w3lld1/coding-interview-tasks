# Bead row symmetry

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-249?utm_source=github&utm_medium=tasks-repo)**

A bead row is a sequence of non-negative numbers (colours). Beads are added and removed at both ends; the row is empty at first. Implement the operations:
- `add_left` (colour) and `add_right` (colour): add a bead on the left or on the right; the result is the row length;
- `remove_left` and `remove_right`: remove and return the leftmost or the rightmost bead, or `-1` for an empty row;
- `symmetric`: the result is `1` if the row reads the same from left to right and right to left (an empty row and a one-bead row are symmetric), otherwise `0`; the row does not change.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["add_right", "add_right", "add_left", "symmetric", "remove_left", "symmetric"]`, `[[1], [2], [1], [], [], []]` → `[1, 2, 3, 0, 1, 0]`.
