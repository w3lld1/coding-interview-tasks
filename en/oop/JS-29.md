# Lens Person

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Classes and OOP](../oop/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-29?utm_source=github&utm_medium=tasks-repo)**

For a Person model with nested Name, Born and Address, implement nameLens, bornAtLens and streetLens. Each lens provides get(person) and set(person, value) for person.name, person.born.bornAt and person.address.street respectively. The set method must return the updated person without changing the original object or the affected nested records; an equivalent approach without a separate lens library is also acceptable.
