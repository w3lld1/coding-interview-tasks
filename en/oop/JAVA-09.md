# Custom Set

**Difficulty:** medium · **Language:** Java · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-09?utm_source=github&utm_medium=tasks-repo)**

Create a generic set type in which adding an equal element again does not change its contents. Implement checking for emptiness and membership, adding, comparing sets, checking for inclusion, and checking for no common elements. Provide the union, intersection and difference, and make sure the order of elements does not affect the result.
