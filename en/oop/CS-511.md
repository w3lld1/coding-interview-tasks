# Thermometer log with undo

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-511?utm_source=github&utm_medium=tasks-repo)**

A weather station records thermometer readings (integer degrees from -50 to 50) and can drop the latest reading when the sensor glitches. The log starts empty. Operations:
- `record` (t): append reading t; the result is the number of readings in the log;
- `undo`: remove the latest reading if there is one; the result is the number of readings afterwards;
- `coldest`: the result is the smallest reading in the log, or `-1000` if it is empty;
- `warmest`: the result is the largest reading in the log, or `-1000` if it is empty;
- `spread`: the result is the largest reading minus the smallest, or `0` if the log is empty.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["record", "record", "record", "coldest", "warmest", "spread", "undo", "coldest", "warmest", "spread"]`, `[[5], [-2], [9], [], [], [], [], [], [], []]` → `[1, 2, 3, -2, 9, 11, 2, -2, 5, 7]`.
