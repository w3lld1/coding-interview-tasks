# Hotel booking by nights

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-271?utm_source=github&utm_medium=tasks-repo)**

Implement booking for a hotel with rooms `1..rooms`, all free at first. A booking takes the nights `[start, end)`: nights numbered from `start` to `end - 1` (always `start < end`). Two bookings of one room must not share a night; a booking that starts on the night another one ends is fine. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"book"` with arguments `start`, `end`: choose the room with the smallest number that is free for all these nights; result: the booking id. Ids are issued in order `1, 2, 3, …`. If no room fits, the result is `-1` and no id is used up.
- `"cancel"` with argument `id`: cancel the booking; result `1` if the booking was active, otherwise `0`.
- `"room_of"` with argument `id`: result: the room assigned to an active booking, or `-1` if there is none or it was cancelled.
- `"occupied"` with argument `night`: result: how many rooms are occupied on that night.

Example: `2`, `["book", "book", "book", "room_of"]`, `[[1, 4], [2, 5], [3, 6], [3]]` → `[1, 2, -1, -1]`.
