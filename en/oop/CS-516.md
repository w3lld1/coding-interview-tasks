# Recent files menu

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-516?utm_source=github&utm_medium=tasks-repo)**

A "Recent files" menu remembers at most the 3 last opened files (a file number is an integer), newest first. It starts empty. Operations:
- `open` (id): open file id. It becomes the first file in the menu; if it was already there, its old place is freed (no repeats). If the menu then holds more than 3 files, the last one drops out. The result is the number of files in the menu;
- `front`: the result is the number of the first file in the menu, or `-1` if the menu is empty;
- `position` (id): the result is the place of file id in the menu counting from 1 (the first file is place 1), or `0` if it is not there;
- `forget` (id): remove file id from the menu; the result is `1` if it was there, otherwise `0`.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["open", "open", "open", "front", "open", "position", "position", "open", "front", "position", "position"]`, `[[1], [2], [3], [], [4], [1], [4], [2], [], [3], [4]]` → `[1, 2, 3, 3, 3, 0, 1, 3, 2, 3, 2]`.
