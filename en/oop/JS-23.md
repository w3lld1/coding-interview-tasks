# Recycling Robot

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Classes and OOP](../oop/), [Parsing and validation](../parsing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-23?utm_source=github&utm_medium=tasks-repo)**

Implement checks for a boolean value, a finite number or bigint, an object other than null, a string of integer digits with an optional leading minus, an instance of ElectronicDevice or its subclass, and an empty and a non-empty array. Add a check for the presence of a type property or method, a check that type has a defined value, and an assertion assertHasId that throws an Error when id is missing. A separate function hasIdProperty must recognize an own id field, including one created by the parent class's constructor, but not a getter or a property that exists only on the prototype.
