# Ballot box

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-260?utm_source=github&utm_medium=tasks-repo)**

Implement a vote. At first there are no registered voters and no votes. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Voters and candidates are integer numbers. Return a list of results, one per operation.

Operations:
- `"register"` with argument `voter`: register a voter; result: the number of registered voters. If the voter is already registered, report an error: throw an exception, or return an error in Go.
- `"vote"` with arguments `voter`, `candidate`: cast a vote; result: the number of votes for this candidate. If the voter is not registered or has already voted, report an error: throw an exception, or return an error in Go.
- `"count"` with argument `candidate`: result: the number of their votes (`0` if none).
- `"winner"` with no arguments: result: the candidate with the most votes; on a tie the smaller number; `-1` if there were no votes yet.

The error applies to the whole call: the first bad operation aborts it.

Example: `["register", "vote", "winner"]`, `[[1], [1, 7], []]` → `[1, 1, 7]`.
