# Waiting list by urgency number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-517?utm_source=github&utm_medium=tasks-repo)**

A clinic keeps a waiting list sorted by ascending urgency number (an integer from 0 to 1000); a smaller number means a more urgent patient. The list starts empty; equal numbers are allowed. Operations:
- `add` (x): insert number x so that the list stays sorted; equal numbers stay in insertion order (the new one goes after the equal ones already there); the result is the length of the list;
- `pop_min`: remove and return the first (smallest) number, `-1` if the list is empty;
- `pop_max`: remove and return the last (largest) number, `-1` if the list is empty;
- `nth` (i): return the i-th number of the list counting from 1, without removing it; `-1` if there is no such place;
- `remove` (x): remove one number x (the first of the equal ones); the result is `1` if it was there, otherwise `0`;
- `count_below` (x): the result is how many numbers in the list are strictly less than x;
- `count`: the result is the length of the list.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["add", "add", "add", "add", "nth", "nth", "count_below", "remove", "nth", "pop_min", "pop_max", "count"]`, `[[40], [10], [30], [20], [1], [3], [30], [30], [3], [], [], []]` → `[1, 2, 3, 4, 10, 30, 2, 1, 40, 10, 40, 1]`.
