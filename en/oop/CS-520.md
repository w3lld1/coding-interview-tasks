# Three checkout lines

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-520?utm_source=github&utm_medium=tasks-repo)**

A shop has three tills numbered 0, 1, 2, each with its own line; all lines start empty. Customers get numbers 1, 2, 3, ... in order of arrival. Operations:
- `join`: the next customer joins the shortest line, and when lengths are equal, the line of the till with the smallest number; the result is that till's number;
- `serve` (k): till k serves the first customer of its line; the result is the customer's number, or `-1` if the line is empty;
- `length` (k): the result is the length of the line at till k;
- `longest`: the result is the number of the till with the longest line, and with equal lengths the smallest number.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["join", "join", "join", "join", "join", "longest", "length", "length", "length", "serve", "join", "serve", "serve", "serve", "longest"]`, `[[], [], [], [], [], [], [0], [1], [2], [0], [], [1], [1], [1], []]` → `[0, 1, 2, 0, 1, 0, 2, 2, 1, 1, 0, 2, 5, -1, 0]`.
