# Time-travel key-value store

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-123?utm_source=github&utm_medium=tasks-repo)**

Implement a store that remembers every value of a key at different moments. The function receives a list of `operations` and a list of arguments `values`: `values[i]` belongs to `operations[i]`. The store starts empty. Operations:

- `"set"` with arguments `[key, value, timestamp]` records `value` for `key` at `timestamp` and returns `0`. For a single key, the timestamps in `set` operations strictly increase.
- `"get"` with arguments `[key, timestamp]` returns the value recorded for `key` at the latest moment that is not greater than `timestamp`. If there is no such moment (or the key never appeared), return `-1`.

Values are non-negative. Return the list of results, one per operation. There are up to 1000 operations.

Example: `["set", "get", "get", "set", "get"]`, `[[1, 10, 5], [1, 5], [1, 4], [1, 20, 8], [1, 9]]` → `[0, 10, -1, 0, 20]`.
