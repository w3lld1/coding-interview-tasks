# Countdown timer

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-608?utm_source=github&utm_medium=tasks-repo)**

Implement a countdown timer in seconds. At first the timer shows `0` seconds, is stopped and has never been started. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation. Unless stated otherwise, the result is the remaining number of seconds.

Operations:
- `"start"` with argument `seconds`: set the timer to `seconds` seconds and run it (with `0` seconds it stays stopped). Starting a running or stopped timer simply begins the countdown again.
- `"pause"` with no arguments: stop the timer; the remaining time stays.
- `"resume"` with no arguments: run the timer if the remaining time is above `0`; otherwise it stays stopped.
- `"tick"` with argument `seconds`: if the timer is running, reduce the remaining time by `seconds`, but not below `0`; when it reaches `0` the timer stops. A stopped timer does not change.
- `"remaining"` with no arguments: only return the remaining time.
- `"done"` with no arguments: result `1` if the timer was started with `"start"` at least once and the remaining time is `0`, otherwise `0`.

Example: `["start", "tick", "pause", "tick", "done"]`, `[[5], [2], [], [9], []]` → `[5, 3, 3, 3, 0]`.
