# Request rate limiter

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-322?utm_source=github&utm_medium=tasks-repo)**

Implement a request rate limiter as an operations list: `apply_operations(operations, values)` returns a result string for every operation (a list of the same length). Time `t` is an integer number of seconds. At first at most 3 requests are allowed in any 10-second window, and no requests are accepted.

The window at moment `t` consists of the moments `x` with `t - window < x ≤ t`. Operations:
- `"allow"` `[t]` — if fewer than `limit` accepted requests are in the window of moment `t`, store `t` as accepted and return `"true"`; otherwise store nothing and return `"false"`;
- `"configure"` `[limit, window]` — set a new `limit` and `window` (both ≥ 1); earlier accepted requests are kept. The result is `""`;
- `"allowed_count"` `[]` — how many requests were accepted in total, as a string;
- `"wait_time"` `[t]` — how many seconds to wait from moment `t` for a request to be accepted (`"0"` if it would be accepted at once). The operation stores nothing.

Report an error (throw an exception, or return an error in Go) for the whole call if: `t` is negative; `t` in `allow` or `wait_time` is less than the moment of the last `allow` (equal is fine); `limit` or `window` in `configure` is less than 1. The first such operation aborts the call.

Example: `["allow", "allow", "allow", "allow", "allow"]`, `[[1], [2], [3], [4], [11]]` → `["true", "true", "true", "false", "true"]` (at moment 4 the window already holds three requests; at moment 11 the window `(1, 11]` holds only 2 and 3).
