# Time clock punches

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-316?utm_source=github&utm_medium=tasks-repo)**

Implement one employee's time sheet as an operations list: `apply_operations(operations, values)` returns a result string for every operation (a list of the same length). Time is minutes since the start of the week, an integer from 0 to 10080. At first the employee is off the clock and no minutes are worked.

Operations:
- `"clock_in"` `[minute]` — start of a shift. The result is `""`;
- `"clock_out"` `[minute]` — end of a shift; the finished shift adds `minute - start` to the total. The result is `""`;
- `"worked"` `[]` — the sum of minutes of finished shifts, as a string (an open shift does not count);
- `"on_clock"` `[]` — `"true"` if a shift is open, otherwise `"false"`;
- `"last_shift"` `[]` — the length of the last finished shift as a string, `"0"` if there was none;
- `"overtime"` `[limit]` — `max(0, worked - limit)` as a string; `limit` must be non-negative.

Report an error (throw an exception, or return an error in Go) for the whole call if: a punch is outside 0…10080; a punch is earlier than the previous punch (equal time is fine); `clock_in` while a shift is open; `clock_out` without an open shift; a negative `limit`. The first such operation aborts the call.

Example: `["clock_in", "clock_out", "worked", "on_clock"]`, `[[540], [1020], [], []]` → `["", "", "480", "false"]`.
