# Remote Control Competition

**Difficulty:** medium · **Language:** Java · **Topics:** [Classes and OOP](../oop/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JAVA-26?utm_source=github&utm_medium=tasks-repo)**

Define a RemoteControlCar interface with the methods drive and getDistanceTravelled, and implement it for production and experimental cars. Each call to drive increases the distance by 10 and 20 units respectively, and a shared race method must drive any car through the interface. For production cars, store the number of victories and implement Comparable so that the ranking list sorts by victories in descending order.
