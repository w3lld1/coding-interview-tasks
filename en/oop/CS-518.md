# Stack calculator

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-518?utm_source=github&utm_medium=tasks-repo)**

A calculator keeps its numbers in a stack, empty at first. Operations:
- `push` (x): put number x on top;
- `add`, `sub`, `mul`: take the two top numbers, first b (the top), then a below it, and push `a + b`, `a - b` or `a * b`. If the stack has fewer than two numbers, nothing happens;
- `dup`: push a copy of the top (nothing happens if the stack is empty);
- `swap`: swap the two top numbers (nothing happens if there are fewer than two);
- `drop`: remove the top (nothing happens if the stack is empty);
- `top`: the result is the number on top, or `0` if the stack is empty.

For every operation except `top` the result is the number of elements in the stack after the operation. Values fit in a 32-bit integer.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["push", "push", "sub", "top", "dup", "mul", "top", "push", "swap", "sub", "top"]`, `[[6], [4], [], [], [], [], [], [3], [], [], []]` → `[1, 2, 1, 2, 2, 1, 4, 2, 2, 1, -1]`.
