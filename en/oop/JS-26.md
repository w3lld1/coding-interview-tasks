# REST API

**Difficulty:** hard · **Language:** JavaScript · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-26?utm_source=github&utm_medium=tasks-repo)**

Implement an in-memory class `RestAPI` with the constructor `new RestAPI({users: [...]})` and the methods `get(url)`, `post(url, payload)`; no HTTP server is needed. A user contains `name`, `owes`, `owed_by`, `balance` (the total owed to them minus the total they owe). `get('/users')` returns `{users: [...]}` with all users; `get('/users?users=Bob')` returns the same wrapper for Bob only: the filter is passed in the query string, not as a second object. The filter is a single name (the value is URL-encoded). `post('/add', {user: 'Adam'})` returns the new user object `{name: 'Adam', owes: {}, owed_by: {}, balance: 0}` without a wrapper. `post('/iou', {lender: 'Adam', borrower: 'Bob', amount: 3})` updates both parties, offsetting mutual debts, and returns `{users: [...]}` with only the changed users. All user lists in responses are sorted by name.
