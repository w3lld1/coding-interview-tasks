# Painting a fence in segments

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-267?utm_source=github&utm_medium=tasks-repo)**

Implement the record of painting a long fence. Fence cells are numbered by integers (negative ones are possible), all unpainted at first. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation. A segment `[l, r)` holds the cells from `l` to `r - 1`; it is empty when `l ≥ r`.

Operations:
- `"paint"` with arguments `l`, `r`: paint the segment `[l, r)`; result: how many cells became painted for the first time (`0` for an empty segment).
- `"is_painted"` with argument `x`: result `1` if cell `x` is painted, otherwise `0`.
- `"painted"` with no arguments: result: how many cells are painted in all.
- `"segments"` with no arguments: result: the number of maximal solid painted stretches. Stretches that touch (one ends where the other begins) count as one.

Coordinates are up to 10⁹ in absolute value and there are up to 1000 operations, so you cannot store cells one by one.

Example: `["paint", "paint", "painted", "segments"]`, `[[2, 6], [4, 9], [], []]` → `[4, 3, 7, 1]`.
