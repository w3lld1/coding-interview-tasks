# Playlist as a linked list

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-242?utm_source=github&utm_medium=tasks-repo)**

A playlist is a sequence of songs identified by distinct positive numbers; at first it is empty. A song already in the playlist is never added again (the tests do not do it). Implement the operations:
- `add` (song): append to the end; the result is the playlist length;
- `insert_after` (song, new): insert the new song right after the given one. If the given song is absent, the playlist does not change and the result is `0`, otherwise `1`;
- `remove` (song): remove the song. The result is `1` if it was there, otherwise `0`;
- `next` (song): the result is the song that comes right after the given one, or `-1` if the given song is last or absent;
- `first`: the result is the first song, or `-1` for an empty playlist.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["add", "add", "insert_after", "next", "next", "remove", "next", "first"]`, `[[10], [20], [10, 15], [10], [20], [15], [10], []]` → `[1, 2, 1, 15, -1, 1, 20, 10]`.
