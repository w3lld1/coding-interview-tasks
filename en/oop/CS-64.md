# Prefix tree

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-64?utm_source=github&utm_medium=tasks-repo)**

Implement a word store (a prefix tree) and run a list of operations on it. The store starts empty. Words consist of lowercase Latin letters and are non-empty.

Operation `operations[i]` is applied to the word `values[i]`:
- `insert` adds the word to the store (adding it again changes nothing); the result is `false`;
- `search` gives `true` if exactly this whole word is in the store;
- `starts_with` gives `true` if the store holds at least one word that begins with `values[i]` (a word counts as its own prefix).

Return the list of results, one per operation. There are at most 10 000 operations.

Example: operations `["insert", "search", "search", "starts_with"]`, words `["apple", "apple", "app", "app"]` → `[false, true, false, true]`.
