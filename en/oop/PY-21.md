# Custom Set

**Difficulty:** medium · **Language:** Python · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-21?utm_source=github&utm_medium=tasks-repo)**

Create a set type in which adding an element again does not change its contents, and the storage order does not affect equality. Implement adding, checking for emptiness and membership, equality, checking for a subset, and checking for no common elements. Support the union, intersection and difference of two sets, including cases with empty inputs and repeated values in the source collections.
