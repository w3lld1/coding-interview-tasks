# Circle of children

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-245?utm_source=github&utm_medium=tasks-repo)**

Children stand in a circle, and one of them is the «current» child. At first the circle is empty. The direction is clockwise. Implement the operations:
- `join` (id): a child joins the circle right before the current child (so they are last when counting from the current one); the current child does not change. If the circle was empty, the newcomer becomes the current child. The result is the number of children in the circle;
- `pass` (k): the child k places clockwise becomes the current one (k ≥ 0; the circle is closed, so k may exceed the number of children); the result is the id of the new current child, or `-1` if the circle is empty;
- `out`: the current child leaves, and the next one clockwise becomes the current child. The result is the id of the child who left, or `-1` if the circle is empty.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["join", "join", "join", "pass", "out", "pass", "out"]`, `[[1], [2], [3], [1], [], [2], []]` → `[1, 2, 3, 2, 2, 3, 3]`.
