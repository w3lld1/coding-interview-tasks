# Amusement Park

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-09?utm_source=github&utm_medium=tasks-repo)**

Create a visitor object with the fields name, age and ticketId, and a function that revokes a ticket by changing only ticketId to null and returning the same object. In the tracking object, a missing key means 'unknown ticket id', the value null means 'not sold', and a visitor's name means 'sold to {name}'; implement the corresponding check. A simplified check returns the name or 'invalid ticket !!!' for an unsold or unknown ticket. Add safe retrieval of visitor.gtc.version: if the corresponding data is missing, the result must be undefined.
