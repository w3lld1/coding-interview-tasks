# Room reservations by date

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-320?utm_source=github&utm_medium=tasks-repo)**

Implement a reservation book of meeting rooms, by nights, as an operations list: `apply_operations(operations, values)` returns a result string for every operation (a list of the same length). Dates are `"YYYY-MM-DD"`, the calendar is Gregorian. At first there are no reservations; there can be any number of rooms, a room is given by a name.

A reservation `[from, to)` takes the days from `from` inclusive to `to` exclusive. Operations:
- `"reserve"` `[room, from, to]` — if the reservation overlaps no accepted reservation of the same room, store it and return `"true"`, otherwise change nothing and return `"false"`. Back-to-back reservations (`to` of one equals `from` of another) do not overlap;
- `"cancel"` `[room, from]` — remove the reservation of the room that starts exactly at `from`: `"true"` if there was one, otherwise `"false"`;
- `"is_free"` `[room, day]` — `"true"` if on `day` the room is not covered by any reservation (`from ≤ day < to`);
- `"nights"` `[room]` — the total number of reserved nights of the room as a string (`"0"` for an unknown room).

Report an error for the whole call (throw an exception, or return an error in Go) if an operation has a non-existent date (such as 2023-02-29) or `reserve` has `to` not later than `from`. The first such operation aborts the call.

Example: `["reserve", "reserve", "reserve", "nights"]`, `[["A", "2024-03-01", "2024-03-04"], ["A", "2024-03-03", "2024-03-05"], ["A", "2024-03-04", "2024-03-06"], ["A"]]` → `["true", "false", "true", "5"]`.
