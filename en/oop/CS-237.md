# Stack of nested cups

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-237?utm_source=github&utm_medium=tasks-repo)**

Cups of different sizes (positive integers) are nested into one stack: a cup may only be placed on top of a strictly larger one. At first the stack is empty. Implement the operations:
- `put` (size): if the stack is empty or the size is strictly smaller than the top cup, place the cup and return `1`; otherwise do not place it and return `0`;
- `take`: remove the top cup and return its size, or return `0` for an empty stack;
- `top`: return the size of the top cup (`0` if the stack is empty) without removing it;
- `count`: return the number of cups in the stack.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["put", "put", "put", "take", "put", "top", "count"]`, `[[5], [3], [4], [], [4], [], []]` → `[1, 1, 0, 3, 1, 4, 2]`.
