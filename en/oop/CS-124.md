# Array with snapshots

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-124?utm_source=github&utm_medium=tasks-repo)**

Given an array of `length` cells, initially all zeros. The function receives `length`, a list of `operations` and a list of arguments `values` (`values[i]` belongs to `operations[i]`; it is empty for `"snap"`). Operations:

- `"set"` with `[index, value]` writes `value` into cell `index` and returns `0`.
- `"snap"` takes a snapshot of the whole array and returns its id; ids count up from `0`.
- `"get"` with `[index, snap_id]` returns the value of cell `index` at the moment of snapshot `snap_id` (writes made after that snapshot do not count). `snap_id` always exists already.

Return the list of results, one per operation. `length` and the number of operations are at most 1000; copying the whole array on every snapshot is not needed.

Example: `2`, `["set", "snap", "set", "get", "get"]`, `[[0, 5], [], [0, 6], [0, 0], [1, 0]]` → `[0, 0, 0, 5, 0]`.
