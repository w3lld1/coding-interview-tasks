# Dimmer that remembers its level

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-264?utm_source=github&utm_medium=tasks-repo)**

Implement a dimmer for a lamp with brightness from `1` to `10`. At first the lamp is off and its remembered brightness is `5`. You get a list of operations `operations` and a list of their arguments `values` (the operations have no arguments, but the lists have the same length). Return a list of results, one per operation: the **displayed brightness**, that is `0` for an off lamp and the remembered brightness for an on lamp.

Operations:
- `"toggle"`: turn the lamp on if it is off, otherwise turn it off; the remembered brightness does not change.
- `"up"`: for an on lamp raise the brightness by `1`, but not above `10`; for an off lamp do nothing.
- `"down"`: for an on lamp lower the brightness by `1`, but not below `1`; for an off lamp do nothing.
- `"level"`: change nothing.

Example: `["toggle", "up", "toggle", "up", "toggle"]`, `[[], [], [], [], []]` → `[5, 6, 0, 0, 6]`.
