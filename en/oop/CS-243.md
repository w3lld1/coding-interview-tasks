# Round-robin scheduler

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-243?utm_source=github&utm_medium=tasks-repo)**

A processor serves tasks in turns, giving each one a slice of 3 time units. At first the queue is empty. Implement the operations:
- `add` (id, time): put a task with a positive id and a positive required time at the end of the queue; the result is the number of tasks in the queue;
- `run`: take the first task and run it for at most 3 units. If it needs 3 or fewer, it finishes and leaves the queue, and the result is its id. Otherwise 3 units are subtracted, it goes to the end of the queue, and the result is `0`. For an empty queue the result is `-1`;
- `count`: the result is the number of tasks in the queue.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["add", "add", "run", "run", "run", "run", "count"]`, `[[1, 5], [2, 2], [], [], [], [], []]` → `[1, 2, 0, 2, 1, -1, 0]`.
