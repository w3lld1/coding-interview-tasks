# Alarm clock on minutes of the day

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-607?utm_source=github&utm_medium=tasks-repo)**

Implement an alarm clock. A time is a minute of the day from `0` to `1439` (`0` is midnight, `420` is 07:00). At first there are no alarms. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"set"` with argument `minute`: add an alarm; result `1` if it was not set yet, otherwise `0`.
- `"cancel"` with argument `minute`: remove an alarm; result `1` if it was set, otherwise `0`.
- `"next"` with argument `now`: how many minutes after minute `now` the nearest alarm rings. An alarm exactly at `now` gives `0`; an alarm earlier than `now` rings tomorrow (a day has `1440` minutes). With no alarms the result is `-1`.
- `"count"` with no arguments: how many alarms are set.

Example: `["set", "next", "next"]`, `[[30], [1439], [31]]` → `[1, 31, 1439]`.
