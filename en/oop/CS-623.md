# Best-fit group seating in a row

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Searching and sorting](../search-sort/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-623?utm_source=github&utm_medium=tasks-repo)**

Implement a box office for one long row of `n` seats numbered `0` to `n − 1` (1 ≤ `n` ≤ 10⁹), all free at first. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation. A free block is a maximal run of consecutive free seats.

Operations:
- `"book"` with argument `k`: seat a group of `k` people side by side. The shortest free block of length at least `k` is chosen, and among equal lengths the leftmost; the group takes its `k` leftmost seats. Result: the group's first seat, or `-1` if no block fits (then nothing changes).
- `"cancel"` with argument `s`: cancel the booking of the group whose first seat is `s`; its seats become free and merge with the neighbouring free blocks. Result: the group size.
- `"largest"`: the length of the longest free block, `0` if no seat is free.
- `"blocks"`: the number of free blocks.
- `"owner"` with argument `seat`: the first seat of the group that holds this seat, or `-1` if it is free.

If `k` < 1, if no current booking starts at seat `s`, or if `seat` is outside `[0, n − 1]`, report an error: throw an exception, or return an error in Go. The error applies to the whole call: the first bad operation aborts it. Up to 1000 operations.

Example: `10`, `["book", "book", "book", "cancel", "book"]`, `[[3], [4], [2], [3], [2]]` → `[0, 3, 7, 4, 3]`.
