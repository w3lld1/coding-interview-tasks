# Pancake stack with a flip

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-510?utm_source=github&utm_medium=tasks-repo)**

A stack of pancakes grows upwards and starts empty. A pancake is given by its size (an integer). Operations:
- `add` (s): put a pancake of size s on top; the result is the number of pancakes in the stack;
- `eat`: eat the top pancake; the result is its size, or `-1` if the stack is empty;
- `flip` (k): slide a spatula under the top k pancakes and turn them over together, so their order is reversed. If k is larger than the number of pancakes, the whole stack is turned; the result is the size of the top pancake after the flip, or `-1` if the stack is empty;
- `top`: the result is the size of the top pancake, or `-1` if the stack is empty.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["add", "add", "add", "flip", "top", "eat", "eat", "eat"]`, `[[5], [3], [8], [2], [], [], [], []]` → `[1, 2, 3, 3, 3, 3, 8, 5]`.
