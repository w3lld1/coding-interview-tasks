# Least recently used cache

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-19?utm_source=github&utm_medium=tasks-repo)**

Implement a fixed-capacity cache that evicts the least recently used key (LRU) and run a list of operations in order. `operations[i]` is the operation name and `values[i]` holds its arguments. The first operation is always `"init"`, it appears once, `values[i] = [capacity]` (the capacity is at least 1), and the cache starts empty. The other operations: `"put"` with `[key, value]` stores the value (if the key exists its value is updated); `"get"` with `[key]` returns the value, or `-1` if the key is absent. Both `put` and a successful `get` make the key the most recently used. If after a `put` the cache holds more keys than the capacity, the least recently used key is removed. For every operation return a number: `0` for `"init"` and `"put"`, and the value or `-1` for `"get"`. Ideally `get` and `put` run in O(1).

Example: `["init", "put", "put", "get", "put", "get"]`, `[[2], [1, 1], [2, 2], [1], [3, 3], [2]]` → `[0, 0, 0, 1, 0, -1]` (after `get(1)` key 2 is the oldest and is evicted by `put(3, 3)`).
