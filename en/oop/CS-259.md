# Lift in a building

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-259?utm_source=github&utm_medium=tasks-repo)**

Implement a lift in a building with floors `0` to `top_floor`. The lift starts on floor `0`. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"go_to"` with argument `f`: go to floor `f`; result: how many floors the lift travelled. If there is no such floor, report an error: throw an exception, or return an error in Go.
- `"up"` with argument `k`: go up `k` floors; result: how many floors the lift travelled (that is `k`). If `k` < 0 or the lift would pass the top floor, report an error: throw an exception, or return an error in Go.
- `"down"` with argument `k`: go down `k` floors, same rules; the lift cannot go below floor `0`.
- `"floor"` with no arguments: result: the current floor.
- `"total"` with no arguments: result: how many floors the lift has travelled in all.

The error applies to the whole call: the first bad operation aborts it.

Example: `10`, `["go_to", "down", "total"]`, `[[7], [2], []]` → `[7, 2, 9]`.
