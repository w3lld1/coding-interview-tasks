# Parking lot with limited spots

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-256?utm_source=github&utm_medium=tasks-repo)**

Implement a parking lot with `capacity` spots (`capacity` ≥ 0), empty at first. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation. A car is identified by an integer number.

Operations:
- `"enter"` with argument `car`: the car drives in; result: the number of free spots after that. If the lot is full or a car with this number is already inside, report an error: throw an exception, or return an error in Go.
- `"leave"` with argument `car`: the car drives out; result: the number of free spots after that. If no such car is inside, report an error: throw an exception, or return an error in Go.
- `"is_parked"` with argument `car`: result `1` if the car is inside, otherwise `0`.
- `"free"` with no arguments: result: the number of free spots.

The error applies to the whole call: the first bad operation aborts it.

Example: `2`, `["enter", "enter", "leave"]`, `[[101], [102], [101]]` → `[1, 0, 1]`.
