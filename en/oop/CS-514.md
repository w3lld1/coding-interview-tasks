# Text editor with a cursor

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-514?utm_source=github&utm_medium=tasks-repo)**

An editor holds text, a sequence of letters where each letter is a number from 1 to 26, and a cursor between letters. The text starts empty with the cursor at its start. The cursor position is the number of letters to its left. Operations:
- `type` (c): insert letter c at the cursor; the cursor ends right after it; the result is the new cursor position;
- `left` (k): move the cursor left by k letters, but not past the start of the text; the result is the cursor position;
- `right` (k): move the cursor right by k letters, but not past the end of the text; the result is the cursor position;
- `backspace`: delete the letter left of the cursor; the result is its number, or `-1` if there is nothing on the left;
- `delete`: delete the letter right of the cursor; the result is its number, or `-1` if there is nothing on the right;
- `char_after`: the result is the number of the letter right of the cursor (without deleting it), or `-1`;
- `length`: the result is the length of the text.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i` (an empty list if there are none).

Example: `["type", "type", "type", "left", "char_after", "type", "length", "right", "backspace", "delete"]`, `[[8], [5], [12], [2], [], [20], [], [5], [], []]` → `[1, 2, 3, 1, 5, 2, 4, 4, 12, -1]`.
