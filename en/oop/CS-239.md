# Card dealer's deck

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-239?utm_source=github&utm_medium=tasks-repo)**

A dealer works with a deck of cards (positive integers) that is empty at first. Implement the operations:
- `add_top` (card) and `add_bottom` (card): put the card on the top or at the bottom of the deck; the result is the number of cards in the deck;
- `deal_top` and `deal_bottom`: remove and return the top or the bottom card, or `0` for an empty deck;
- `cut` (k): take k cards from the top and, keeping their order, move them to the bottom. If k exceeds the number of cards, use k modulo the number of cards; an empty deck stays unchanged. The result is the top card after the cut, or `0` if the deck is empty;
- `top`: the result is the top card (`0` if the deck is empty); the deck does not change.

Return the list of results, one per operation. `values[i]` holds the arguments of operation `i`.

Example: `["add_top", "add_bottom", "add_top", "cut", "deal_top", "deal_bottom", "top"]`, `[[3], [4], [5], [1], [], [], []]` → `[1, 2, 3, 3, 3, 5, 4]`.
