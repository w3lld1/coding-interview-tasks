# Shop stock levels

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-257?utm_source=github&utm_medium=tasks-repo)**

Implement stock keeping for a shop. The warehouse is empty at first. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation. An item is identified by an integer `item`.

Operations:
- `"add"` with arguments `item`, `qty`: receive `qty` units; result: the stock of this item. If `qty` ≤ 0, report an error: throw an exception, or return an error in Go. After its first delivery an item counts as known.
- `"remove"` with arguments `item`, `qty`: write off `qty` units; result: the stock of the item. If the item is unknown, `qty` ≤ 0 or `qty` is greater than the stock, report an error: throw an exception, or return an error in Go.
- `"stock"` with argument `item`: result: the stock (`0` for an unknown item).
- `"total"` with no arguments: result: the sum of the stocks of all items.

The error applies to the whole call: the first bad operation aborts it.

Example: `["add", "remove", "total"]`, `[[1, 10], [1, 3], []]` → `[10, 7, 7]`.
