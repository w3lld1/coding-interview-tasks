# Single-room booking calendar

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/), [Errors and exceptions](../errors/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-307?utm_source=github&utm_medium=tasks-repo)**

Implement a one-day calendar of a single meeting room as an operations list: `apply_operations(operations, values)` — for each operation `operations[i]` with arguments `values[i]` return a result string (a list of results of the same length). At the start there are no bookings.

Operations (the result is a string):
- `"book"` `[start, end]` — take the span `[start, end)` in minutes after midnight. If it overlaps no accepted booking, store it and return `"true"`; otherwise change nothing and return `"false"`. Bookings where one ends exactly when another starts do not overlap. If `0 ≤ start < end ≤ 1440` does not hold, report an error;
- `"cancel"` `[start]` — remove the booking that starts exactly at `start`: `"true"` if there was one, otherwise `"false"`;
- `"busy_at"` `[minute]` — `"true"` if `minute` lies inside some booking (`start ≤ minute < end`), otherwise `"false"`. If `minute` is outside 0 to 1439, report an error;
- `"free_minutes"` `[]` — the number of free minutes of the day (out of 1440), as a string.

The first invalid operation makes the whole call an error: report an error: throw an exception, or return an error in Go. An empty list of operations gives an empty list.

Example: `["book", "book", "book", "free_minutes"]`, `[[540, 600], [570, 630], [600, 660], []]` → `["true", "false", "true", "1320"]`.
