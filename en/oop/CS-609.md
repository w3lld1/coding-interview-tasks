# Daily planner on a minute line

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Classes and OOP](../oop/), [Dates and time](../dates/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-609?utm_source=github&utm_medium=tasks-repo)**

Implement a planner for a single day. Time is minutes from the start of the day, a day has `1440` minutes. An event `[start, end)` takes the minutes from `start` inclusive to `end` exclusive. At first there are no events. You get a list of operations `operations` and a list of their arguments `values` (`values[i]` belongs to `operations[i]`). Return a list of results, one per operation.

Operations:
- `"add"` with arguments `start`, `end`: add an event. It is valid if `0 <= start < end <= 1440` and it overlaps no existing event (events where one ends exactly when the other starts do not overlap). Result `1` if the event was added, otherwise `0` (and the planner does not change).
- `"remove"` with argument `start`: remove the event that starts at minute `start`; result `1` if there was one, otherwise `0`.
- `"busy"` with no arguments: how many minutes all events take together.
- `"longest_free"` with no arguments: the length of the longest free stretch in the day (`0` if there is no free time).
- `"at"` with argument `minute`: the start of the event that contains minute `minute`, or `-1` if that minute is free.

Example: `["add", "add", "busy", "longest_free", "at"]`, `[[60, 120], [100, 130], [], [], [60]]` → `[1, 0, 60, 1320, 60]`.
