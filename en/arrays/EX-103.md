# Keep or discard by condition

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-103?utm_source=github&utm_medium=tasks-repo)**

Implement `keep` and `discard` for a list of integers by hand, without built-in `filter`, `reject` and similar functions. You get a `mode` (`"keep"` or `"discard"`), a condition name `predicate` and a list.

Conditions: `"all"` is true for any number; `"none"` is true for no number; `"odd"` means the number is odd (not divisible by 2, negatives included); `"even"` means even; `"positive"` means strictly greater than zero. In mode `"keep"` return the numbers for which the condition is true, in mode `"discard"` the ones for which it is false. The order of elements is preserved and the input list is not changed.

Example: `"keep"`, `"even"`, `[1, 2, 3, 4, 5]` → `[2, 4]`.
