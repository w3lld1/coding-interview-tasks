# Fewest changes to a palindrome

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-73?utm_source=github&utm_medium=tasks-repo)**

You get a list of integers. In one change you replace any single element with any other number. Return the smallest number of changes after which the list reads the same forwards and backwards. An empty list and a one-element list are already symmetric, so the answer for them is `0`.

Example: `[1, 2, 3, 4, 3, 2, 2]` → `1`; `[1, 2, 3, 5, 4, 7, 9, 6]` → `4`.
