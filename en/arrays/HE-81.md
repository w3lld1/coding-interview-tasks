# Letter grades from GPA

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-81?utm_source=github&utm_medium=tasks-repo)**

A teacher keeps students' GPAs in a list. Convert each GPA to a letter grade and return the grades in the same order.

Scale: exactly `4.0` → `A+`; above `3.7` → `A`; above `3.3` → `A-`; above `3.0` → `B+`; above `2.7` → `B`; above `2.3` → `B-`; above `2.0` → `C+`; above `1.7` → `C`; above `1.3` → `C-`; above `1.0` → `D+`; above `0.7` → `D`; above `0.0` → `D-`; exactly `0.0` → `E`. The limits are strict: a GPA of `3.7` is not `A` but `A-`. For an empty list return an empty list.

Example: `[4.0, 3.0, 1.7, 2.0, 3.5]` → `["A+", "B", "C-", "C", "A-"]`.
