# Subarrays with sum divisible by k

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-161?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers `nums` (possibly negative) and an integer `k >= 1`, return the number of non-empty contiguous subarrays whose sum is divisible by `k` (0 is divisible too). Subarrays with equal values at different positions count separately. For an empty list the answer is `0`.

Example: `[4, 5, 0, -2, -3, 1]`, `5` → `7`.
