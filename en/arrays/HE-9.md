# Rolling maximum

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-9?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return a list of the same length where the element at position `i` is the largest of the original elements from position 0 to `i` inclusive. For an empty list return an empty list.

Example: `[1, 2, 3, 2, 3, 4, 2]` → `[1, 2, 3, 3, 3, 4, 4]`.
