# Positive numbers

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-30?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return a new list containing only the positive numbers, in the original order. Zero is not positive. If there are no positive numbers, return an empty list.

Example: `[-1, 2, -4, 5, 6]` → `[2, 5, 6]`.
