# k largest, ascending

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-120?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers and a number `k` (0 ≤ `k` ≤ the list length), return a list of the `k` largest elements ordered ascending. Duplicate values count as many times as they occur. For `k` = 0 the result is empty. The input list must not be modified.

Example: `[4, -4, 4]`, `2` → `[4, 4]`.
