# Task scheduler with cooldown

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-53?utm_source=github&utm_medium=tasks-repo)**

A processor runs one task per time unit. The tasks are given as a string of capital Latin letters: one letter is one task type, and the order in the string does not matter. Two tasks of the same type must not start closer than `n` units apart: at least `n` other units must pass between them (those units can run other tasks or stay idle). Return the least number of time units needed to run all the tasks. For an empty string the answer is `0`. The string has up to 1000 letters, and `0 ≤ n ≤ 100`.

Example: `"AAABBB"`, `2` → `8` (A B _ A B _ A B).
