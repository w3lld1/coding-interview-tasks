# Match prediction error

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-152?utm_source=github&utm_medium=tasks-repo)**

You get two lists of integers of the same length: the actual scores of matches and the guesses made for them. Return a list of the same length where each position holds how far off the guess was: `0` if it equals the score, otherwise the absolute difference between the guess and the score. For empty lists return an empty list.

Example: `[1, 2, 3, 4, 5, 1]`, `[1, 2, 3, 4, 2, -2]` → `[0, 0, 0, 0, 3, 3]`.
