# Sliding window maximums

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-75?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers `nums` and an integer `k` (`1 ≤ k ≤` the list length), a window of width `k` moves over the list from left to right one position at a time; there are `n − k + 1` windows. Return the list of the maximums of all windows in the order of their position. The solution must run in O(n): scanning each window in O(k) is not good enough.

The list holds 1 to 100,000 numbers, each from −10⁹ to 10⁹.

Example: `[4, -2, 5, 1, 1, 3]`, `3` → `[5, 5, 5, 3]`.
