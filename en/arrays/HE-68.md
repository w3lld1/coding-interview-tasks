# Smallest even and its index

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-68?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-negative integers, find the smallest even value and return a list of two numbers `[value, index]`. If that value occurs several times, use the leftmost one. If there are no even numbers or the list is empty, return an empty list. Zero counts as even.

Example: `[5, 0, 3, 0, 4, 2]` → `[0, 1]`.
