# Elyse's Looping Enchantments

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-07?utm_source=github&utm_medium=tasks-repo)**

The cardTypeCheck function takes an array of card numbers and a value to look for; it must count its occurrences using forEach. The determineOddEvenCards function takes the same array and a boolean flag: true means counting even cards, false means odd cards. For the second function, use a for...of loop and return the number of matching elements.
