# Sorted with no value more than twice

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-126?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-negative integers, return `true` if both conditions hold: the numbers are in non-decreasing order (each is at least the previous one) and no value occurs more than twice in the list. Otherwise return `false`. An empty list and a one-element list give `true`.

Example: `[1, 2, 2, 3, 3, 4]` → `true`, `[1, 2, 2, 2, 3, 4]` → `false`.
