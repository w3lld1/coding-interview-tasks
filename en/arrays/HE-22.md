# Filter integers

**Difficulty:** easy · **Language:** Python · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-22?utm_source=github&utm_medium=tasks-repo)**

Given a list of values of mixed types (numbers, strings, lists, objects, `null`), return a list of only the elements that are integers, in the original order. Fractional numbers, strings (even like `"7"`), nested lists, objects and `null` are skipped. If there are no integers, return an empty list.

Example: `["a", 3.14, 5]` → `[5]`.
