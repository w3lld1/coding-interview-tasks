# Elyse's Enchantments

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-02?utm_source=github&utm_medium=tasks-repo)**

A deck is represented by an array of numbers from 1 to 10, and card positions are numbered from zero; the top of the deck corresponds to the end of the array. Implement getting, replacing and removing a card by index, and adding and removing a card at both ends of the array. Mutating operations change the original array and return it; getting returns the card. `checkSizeOfStack(stack, stackSize)` returns `true` if and only if the length of the array `stack` equals `stackSize`, otherwise `false`.
