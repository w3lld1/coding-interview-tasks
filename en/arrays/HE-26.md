# Keep only unique elements

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-26?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, remove every number that occurs more than once, together with all of its occurrences. Return the remaining numbers in their original order. If none remain, return an empty list.

Example: `[1, 2, 3, 2, 4]` → `[1, 3, 4]`.
