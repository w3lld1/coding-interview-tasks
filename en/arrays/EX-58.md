# High score board

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-58?utm_source=github&utm_medium=tasks-repo)**

You get a player's scores in the order they were added (not empty) and a `query`. Return a list:
- `"scores"`: all scores in the original order;
- `"latest"`: a list of one element, the last added score;
- `"personal_best"`: a list of one element, the highest score;
- `"top_three"`: the three highest scores in descending order (equal values count separately); if there are fewer than three scores, return all of them, also in descending order.

You do not need to change the original list.

Example: `[40, 20, 40, 30]`, `"top_three"` → `[40, 40, 30]`.
