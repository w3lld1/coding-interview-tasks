# Subarrays with sum k

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-45?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers (up to 2000 elements, absolute values up to 1000, negatives and zeros possible) and an integer `k`, return the number of contiguous non-empty subarrays whose elements sum to `k`. Subarrays at different positions count separately even if they hold the same numbers. For an empty list the answer is `0`.

Example: `[1, 1, 1]`, `2` → `2` (positions 0..1 and 1..2).
