# Fewest arrows for balloons

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-158?utm_source=github&utm_medium=tasks-repo)**

Each balloon is a segment `[start, end]` on the number line, both ends included. An arrow shot at point `x` bursts every balloon with `start <= x <= end`. Return the fewest arrows that burst all balloons. For an empty list the answer is `0`. The bounds fit in a signed 32-bit integer.

Example: `[[10, 16], [2, 8], [1, 6], [7, 12]]` → `2` (an arrow at 6 bursts two balloons, an arrow at 12 bursts the other two).
