# Planets between orbits

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Strings](../strings/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-148?utm_source=github&utm_medium=tasks-repo)**

The planets of the Solar System in order from the Sun are `Mercury`, `Venus`, `Earth`, `Mars`, `Jupiter`, `Saturn`, `Uranus`, `Neptune`. Given two planet names, return the list of planets whose orbits lie strictly between the two given ones, ordered from the Sun; the order of the arguments does not matter. If either name is not in this list (case matters), or the planets are the same or adjacent, return an empty list.

Example: `"Jupiter"`, `"Neptune"` → `["Saturn", "Uranus"]`.
