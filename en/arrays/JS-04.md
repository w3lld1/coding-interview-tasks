# Elyse's Analytic Enchantments

**Difficulty:** easy · **Language:** JavaScript · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-04?utm_source=github&utm_medium=tasks-repo)**

For an array of card numbers, implement functions that find the index of a given card and check whether it is present. Other functions must determine whether all cards are even and whether there is an odd card, return the first odd card, and return the index of the first even card. Use the built-in array methods; when there is no result, keep their standard semantics: index −1, found value undefined, some gives false, and every on an empty array gives true.
