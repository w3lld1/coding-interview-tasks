# Fair sword fight

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/), [Stacks, queues, linked lists](../stacks-lists/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-77?utm_source=github&utm_medium=tasks-repo)**

You are given two lists `c` and `d` of non-negative integers of the same length `n` (`1 ≤ n ≤ 1500`) and a number `k ≥ 0`: `c[i]` and `d[i]` are the skills of two fencers with sword type `i`. A judge picks a range of indices `[l, r]` (`l ≤ r`), and each fencer takes the available sword they are best with; their strength is `max(c[l..r])` for the first and `max(d[l..r])` for the second. The fight is fair if `|max(c[l..r]) − max(d[l..r])| ≤ k`.

Return the number of ranges `[l, r]` that give a fair fight.

Example: `[1, 2, 3, 4, 5]`, `[5, 5, 5, 5, 10]`, `k = 2` → `7`.
