# Index-based power sum

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-142?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, square every element whose index is a multiple of 3. Cube every element whose index is a multiple of 4 but not of 3. Leave the other elements unchanged. Indexes start at 0, so index 0 is a multiple of 3. Return the sum of the resulting values; for an empty list it is `0`.

Example: `[-1, -5, 2, -1, -5]` → `-126` (1 − 5 + 2 + 1 − 125).
