# Sort by number of ones

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-116?utm_source=github&utm_medium=tasks-repo)**

Sort a list of integers by the number of ones in the binary form of each number, ascending. Numbers with the same count of ones go by ascending value. For negative numbers count the ones in the binary form of the absolute value. Return a new list; an empty list gives an empty list.

Example: `[1, 5, 2, 3, 4]` → `[1, 2, 4, 3, 5]` (in binary: 1, 101, 10, 11, 100).
