# Sorted distinct values

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-34?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return its distinct values sorted in ascending order: each value appears in the result once. An empty list gives an empty list.

Example: `[5, 3, 5, 2, 3, 3, 9, 0, 123]` → `[0, 2, 3, 5, 9, 123]`.
