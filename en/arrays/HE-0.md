# Close numbers

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-0?utm_source=github&utm_medium=tasks-repo)**

Given a list of numbers and a threshold, return `true` if two elements at different positions are closer to each other than the threshold (strictly less), otherwise `false`. An empty list or a list of one number gives `false`.

Example: `[1.0, 2.8, 3.0, 4.0, 5.0, 2.0]`, threshold `0.3` → `true` (2.8 and 3.0).
