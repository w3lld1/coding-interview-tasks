# Sort order by the list ends

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-88?utm_source=github&utm_medium=tasks-repo)**

Given a list of non-negative integers, return a sorted copy without changing the original list. If the sum of the first and the last element is odd, sort ascending; if it is even, sort descending. For a one-element list the sum is twice the value (even). An empty list gives an empty list.

Example: `[2, 4, 3, 0, 1, 5]` → `[0, 1, 2, 3, 4, 5]` (2 + 5 = 7, odd).
