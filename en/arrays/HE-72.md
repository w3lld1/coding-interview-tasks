# Will the balanced object fly

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-72?utm_source=github&utm_medium=tasks-repo)**

An object is described by a list of integers. It flies when two conditions hold at once: the list reads the same forwards and backwards, and the sum of its elements does not exceed the maximum weight. Return `true` if the object flies, otherwise `false`. An empty list counts as symmetric and its sum is 0.

Example: `[3, 2, 3]`, `9` → `true`; `[3, 2, 3]`, `1` → `false`; `[1, 2]`, `5` → `false`.
