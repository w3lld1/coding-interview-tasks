# Insert a separator

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-5?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers and a delimiter number, return a new list where the delimiter is inserted between every two neighbouring elements of the original list. The delimiter is not added at the start or the end. An empty list and a one-element list stay unchanged.

Example: `[1, 2, 3]`, `4` → `[1, 4, 2, 4, 3]`.
