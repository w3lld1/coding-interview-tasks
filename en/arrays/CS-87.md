# Count smaller numbers to the right

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-87?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers `nums` (up to 10^5 elements, each from −10^9 to 10^9), return a list of the same length whose element at position `i` is the number of elements to the right of position `i` that are strictly less than `nums[i]`. Equal numbers are not counted. For an empty list return an empty list.

Example: `[4, 1, 3, 1, 2]` → `[4, 0, 2, 0, 0]`.
