# Elyse's Transformative Enchantments

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-17?utm_source=github&utm_medium=tasks-repo)**

For an array of cards, implement doubling all values, replacing each three with three threes, and keeping only twos. From a deck of exactly ten cards, return the two middle elements, and for an even-sized deck perform a separate trick: remove the outer cards and insert them in the middle in the order "last, first". Add numeric sorting in ascending order and reversing the order of elements, using JavaScript's built-in tools for transforming arrays.
