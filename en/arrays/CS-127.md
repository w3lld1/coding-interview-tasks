# Shortest subarray reaching a sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-127?utm_source=github&utm_medium=tasks-repo)**

Given a list of positive integers `nums` and a positive integer `target`, find the smallest length of a contiguous segment whose sum is at least `target`. If even the whole list sums to less (or the list is empty), return `0`. The list has up to 5000 elements and sums fit in a 32-bit integer.

Example: `[2, 3, 1, 2, 4, 3]`, `7` → `2` (the segment `[4, 3]`).
