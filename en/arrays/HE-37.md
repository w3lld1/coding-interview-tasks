# Sort the even positions

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-37?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return a new list of the same length: the elements at indices 0, 2, 4, … (counting from zero) are rearranged among those positions in ascending order, and the elements at odd indices stay as they are. An empty list gives an empty list.

Example: `[5, 6, 3, 4]` → `[3, 6, 5, 4]`.
