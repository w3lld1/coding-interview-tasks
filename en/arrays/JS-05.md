# Elyse's Destructured Enchantments

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-05?utm_source=github&utm_medium=tasks-repo)**

Using destructuring, write functions that return the first and second cards, swap two elements, and turn a triple [a, b, c] into [b, c, a]. For an object with the fields chosen and disregarded, add extracting the chosen pile and creating an object with the piles swapped. You must not call array methods or access elements or properties with square brackets or dot notation.
