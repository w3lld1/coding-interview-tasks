# Pascal's triangle

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-76?utm_source=github&utm_medium=tasks-repo)**

You get a number `count` (0 to 20). Return the first `count` rows of Pascal's triangle as a list of lists. The first row is `[1]`. Every next row is one element longer than the previous one: its first and last elements are 1 and every other element is the sum of the two neighbouring elements of the previous row (the ones above it to the left and to the right). For `0` return an empty list.

Example: `4` → `[[1], [1, 1], [1, 2, 1], [1, 3, 3, 1]]`.
