# Common elements of two lists

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-58?utm_source=github&utm_medium=tasks-repo)**

Given two lists of integers, return the numbers that appear in both, without duplicates and in ascending order. If there are no common numbers or one list is empty, return an empty list.

Example: `[5, 3, 2, 8]`, `[3, 2]` → `[2, 3]`.
