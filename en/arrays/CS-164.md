# Shortest range to sort

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-164?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, find the shortest contiguous range such that sorting it in ascending order (non-strictly) makes the whole list sorted. Return the length of that range. If the list is already sorted (including an empty one or one element), return `0`.

Example: `[2, 6, 4, 8, 10, 9, 15]` → `5` (the range `[6, 4, 8, 10, 9]`).
