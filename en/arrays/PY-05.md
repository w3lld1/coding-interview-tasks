# Sublist

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/PY-05?utm_source=github&utm_medium=tasks-repo)**

For two lists A and B, return a string with one of four categories: "equal" if the lists are equal, "sublist" if A is a sublist of B, "superlist" if A contains B, "unequal" if the lists are not related in these ways. A sublist must occupy a contiguous run and preserve the order of elements, not merely contain the same values. An empty list is contained in any list; if both are empty, the answer is "equal".
