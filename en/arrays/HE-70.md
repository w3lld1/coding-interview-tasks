# Strange sort

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-70?utm_source=github&utm_medium=tasks-repo)**

The "strange" order goes like this: first the smallest number of the list, then the largest of the remaining ones, then the smallest of the remaining ones again, and so on in turn. Return a new list with all elements of the input (duplicates kept) in this order. For an empty list return an empty list.

Example: `[1, 2, 3, 4]` → `[1, 4, 2, 3]`.
