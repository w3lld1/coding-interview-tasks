# Next permutation

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-160?utm_source=github&utm_medium=tasks-repo)**

Consider all arrangements of the elements of a list, written as lists and ordered lexicographically (by the first element, on a tie by the second, and so on; equal elements are not told apart). Given `nums`, return the arrangement that comes right after it. If `nums` is the largest arrangement, return the smallest one, that is the list in ascending order. An empty list and a list of one element are returned unchanged. Do not modify the input list.

Example: `[1, 2, 3]` → `[1, 3, 2]`; `[3, 2, 1]` → `[1, 2, 3]`.
