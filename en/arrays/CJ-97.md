# Sums of sorted subarray sums

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-97?utm_source=github&utm_medium=tasks-repo)**

You are given a list of `n` positive integers. Take all `n·(n+1)/2` of its non-empty subarrays (runs of consecutive elements), compute each sum, and sort the sums in non-decreasing order: this gives a new list with positions `1` to `n·(n+1)/2`. For example, for `[2, 3, 2]` the subarray sums are `2, 3, 2, 5, 5, 7` and the sorted list is `[2, 2, 3, 5, 5, 7]`.

For every query `[l, r]` (`1 ≤ l ≤ r ≤ n·(n+1)/2`) return the sum of the new list's elements from position `l` to position `r` inclusive. Return the answers in query order.

Limits: `1 ≤ n ≤ 1500`, every element is from `1` to `100`, at most five queries. The new list holds over a million elements, and an answer may not fit in 32 bits.

Example: `[5, 4, 3, 2, 1]`, `[[3, 8]]` → `[26]` (the new list starts `1, 2, 3, 3, 4, 5, 5, 6`).
