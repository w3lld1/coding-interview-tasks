# Last element smaller than its predecessor

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-135?utm_source=github&utm_medium=tasks-repo)**

Given a list of distinct integers, return the largest index (zero-based) of an element that is smaller than the element right before it. If there is no such element (the list is increasing, empty or has one number), return `-1`.

Example: `[1, 2, 4, 3, 5]` → `3` (the number `3` is smaller than the previous `4`).
