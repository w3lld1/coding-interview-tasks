# Sort by digit sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-145?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return a sorted copy in ascending order of digit sum. For a negative number the first (leading) digit counts as negative: for `-12` the sum is `-1 + 2 = 1`. Numbers with equal sums keep the order they had in the original list.

Example: `[1, 11, -1, -11, -12]` → `[-1, -11, 1, -12, 11]`.
