# Merge intervals

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-21?utm_source=github&utm_medium=tasks-repo)**

You get a list of intervals `[start, end]` with integer ends (`start <= end`), in any order. Intervals are closed: a shared point counts as an overlap, so `[1, 4]` and `[4, 5]` merge into `[1, 5]`. Merge every group of overlapping intervals and return the result sorted by start. For an empty list return an empty list.

Example: `[[1, 3], [2, 6], [8, 10], [15, 18]]` → `[[1, 6], [8, 10], [15, 18]]`.
