# All numbers below threshold

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-52?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers and an integer threshold, return `true` if every number in the list is strictly less than the threshold, otherwise `false`. A number equal to the threshold does not count. An empty list gives `true`.

Example: `[1, 2, 4, 10]`, `100` → `true`.
