# Value of two resistor bands

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-85?utm_source=github&utm_medium=tasks-repo)**

Band colors encode digits: `black` is 0, `brown` is 1, `red` is 2, `orange` is 3, `yellow` is 4, `green` is 5, `blue` is 6, `violet` is 7, `grey` is 8, `white` is 9. Given a list of two or three color names, the first two colors make a two-digit number: the first digit is the tens, the second is the ones. A third color, if present, is ignored. Return that number (it can be below 10, e.g. `black`, `brown` → `1`).

Example: `["brown", "green", "violet"]` → `15`.
