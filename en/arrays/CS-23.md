# Meeting rooms

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-23?utm_source=github&utm_medium=tasks-repo)**

You get a list of meetings `[start, end]` with integer times, `start < end`. A meeting occupies the half-open span from start to end: if one meeting ends exactly when another starts, the room is free and both can use it. Find the smallest number of rooms that fits all the meetings. For an empty list the answer is `0`.

Example: `[[0, 30], [5, 10], [15, 20]]` → `2`.
