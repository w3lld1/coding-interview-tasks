# Find value coordinates in a ragged table

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Matrices and grids](../matrices/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-87?utm_source=github&utm_medium=tasks-repo)**

Given a table as a list of rows, where rows may have different lengths (including empty ones), and an integer `target`, find every occurrence of `target` and return a list of `[row, column]` pairs (0-based). Pairs are ordered by row ascending, and within one row by column descending. If the value is not in the table or the table is empty, return an empty list.

Example: `[[1, 2, 3], [1, 2, 1]]`, `1` → `[[0, 0], [1, 2], [1, 0]]`.
