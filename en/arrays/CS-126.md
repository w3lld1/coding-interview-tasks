# Equal zeros and ones

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-126?utm_source=github&utm_medium=tasks-repo)**

Given a list of zeros and ones, find the length of the longest contiguous segment that contains the same number of zeros and ones. If there is no such segment (including an empty list), return `0`. The list has at most 1000 elements.

Example: `[0, 1, 1, 0, 1, 1, 1, 0]` → `4` (the segment `[0, 1, 1, 0]`).
