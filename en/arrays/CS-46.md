# Product of the others

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-46?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers (up to 1000 elements), return a list of the same length where the element at position `i` equals the product of all elements of the input except the one at position `i`. Division is not allowed. All products are guaranteed to fit in a 32-bit integer. For a list of one element the answer is `[1]` (the product of nothing is 1), for an empty list it is an empty list.

Example: `[1, 2, 3, 4]` → `[24, 12, 8, 6]`.
