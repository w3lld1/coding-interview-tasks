# Sorted by rotation

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-109?utm_source=github&utm_medium=tasks-repo)**

You get a list of distinct integers. One operation moves the last element to the front (a right rotation); you may do any number of operations, including none. Return `true` if this can produce a list sorted in increasing order, otherwise `false`. An empty list and a list of one number give `true`.

Example: `[3, 4, 5, 1, 2]` → `true` (two rotations give `[1, 2, 3, 4, 5]`).
