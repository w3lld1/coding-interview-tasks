# Window with at most two values

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-128?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, find the length of the longest contiguous segment that contains at most two distinct values. For an empty list return `0`. The list has up to 5000 elements.

Example: `[1, 2, 3, 2, 2]` → `4` (the segment `[2, 3, 2, 2]`).
