# Triplets with zero sum

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-47?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers (up to 500 elements), find all distinct-by-value triplets of numbers that sum to zero; the numbers come from three different positions. Write each triplet in ascending order and return the list of triplets in lexicographic order (compare first numbers, then second, then third). Triplets equal by value appear once. If there is no such triplet, return an empty list.

Example: `[-1, 0, 1, 2, -1, -4]` → `[[-1, -1, 2], [-1, 0, 1]]`.
