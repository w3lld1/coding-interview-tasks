# Secret handshake

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/EX-96?utm_source=github&utm_medium=tasks-repo)**

Given an integer, build a list of actions from its five lowest bits (ignore higher bits), starting from the lowest bit:

- bit 0 (`1`): `"wink"`;
- bit 1 (`2`): `"double blink"`;
- bit 2 (`4`): `"close your eyes"`;
- bit 3 (`8`): `"jump"`;
- bit 4 (`16`): not an action: reverse the order of the resulting list.

If none of bits 0-3 is set, return an empty list.

Example: `19` (`10011`) → `["double blink", "wink"]`.
