# Account below zero

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-3?utm_source=github&utm_medium=tasks-repo)**

A bank account starts at zero. You get a list of operations: a positive number is a deposit and a negative one is a withdrawal. Return `true` if after any operation the balance is strictly below zero, otherwise `false`. An empty list gives `false`; a balance of exactly zero is not below zero.

Example: `[1, 2, -4, 5]` → `true`.
