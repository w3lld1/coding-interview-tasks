# Second smallest distinct number

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-90?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return the second smallest among its distinct values: duplicates count as one value. If there are fewer than two distinct values (the list is empty, has one element, or all elements are equal), return `null`.

Example: `[5, 1, 4, 3, 2]` → `2`; `[1, 1]` → `null`; `[3, 3, 2, 2]` → `3`.
