# Mysterious road signs

**Difficulty:** hard · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Recursion and backtracking](../recursion/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CJ-74?utm_source=github&utm_medium=tasks-repo)**

Signs stand along a straight road; `signs[i] = [d, a, b]` is a sign at kilometre `d` with `a` written on its west side and `b` on its east side (positions strictly increase, all numbers are from 1 to 10⁶, there are 1 to 1000 signs). A set of signs is valid if it is a contiguous segment of the list and there exist integers M and N (any, not necessarily positive or distinct) such that every sign in the segment satisfies `d + a = M` or `d − b = N` (at least one). Return the list `[length, count]`: the greatest length of a valid segment and the number of distinct valid segments of that length (a segment counts once even if several M, N pairs fit it).

Example: `[[1, 3, 3], [2, 2, 2], [3, 1, 1], [4, 2, 2], [5, 3, 3]]` → `[5, 1]` (M = 4, N = 2).
