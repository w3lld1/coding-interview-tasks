# Monotonic list

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-57?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return `true` if it is monotonic: either non-decreasing or non-increasing (equal neighbours are allowed), otherwise `false`. An empty list, a one-element list and a list of equal numbers are monotonic.

Example: `[4, 1, 1, 0]` → `true`, while `[1, 20, 4, 10]` → `false`.
