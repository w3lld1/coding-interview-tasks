# Exchange to make a list even

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-110?utm_source=github&utm_medium=tasks-repo)**

You get two non-empty lists of integers. You may swap an element of the first list with an element of the second any number of times. Return the string `"YES"` if this can make every element of the first list even, otherwise `"NO"`.

Example: `[1, 2, 3, 4]`, `[1, 5, 3, 4]` → `"NO"` (the first list has two odd numbers, the second only one even).
