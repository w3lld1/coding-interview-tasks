# Sort every third element

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Searching and sorting](../search-sort/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-33?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return a new list of the same length: the elements at indices 0, 3, 6, … (counting from zero) are rearranged among those positions in ascending order, and all other elements stay where they are. An empty list gives an empty list.

Example: `[5, 6, 3, 4, 8, 9, 2]` → `[2, 6, 3, 4, 8, 9, 5]`.
