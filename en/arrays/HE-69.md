# Value that appears often enough

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Hash maps and sets](../hashing/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-69?utm_source=github&utm_medium=tasks-repo)**

Given a non-empty list of positive integers, find the greatest number `v` that appears in the list at least `v` times. If there is no such number, return `-1`.

Example: `[4, 1, 2, 2, 3, 1]` → `2` (two appears twice, while four appears once); `[5, 5, 4, 4, 4]` → `-1`.
