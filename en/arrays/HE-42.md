# Increment every element

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-42?utm_source=github&utm_medium=tasks-repo)**

Given a list of integers, return a new list of the same length in which every element is 1 greater than the matching element of the input. The order is kept, and an empty list gives an empty list.

Example: `[1, 2, 3]` → `[2, 3, 4]`.
