# Numbers with a positive signed digit sum

**Difficulty:** easy · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/), [Math](../math/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/HE-108?utm_source=github&utm_medium=tasks-repo)**

You get a list of integers. A number has signed digits: for a positive number all digits count as they are, for a negative one the first (most significant) digit counts as negative and the rest as positive. For example, `-123` has digits `-1`, `2`, `3`. Return how many numbers in the list have a signed digit sum strictly greater than zero. For an empty list the answer is `0`.

Example: `[-1, 11, -11]` → `1` (sums: `-1`, `2`, `-1 + 1 = 0`).
