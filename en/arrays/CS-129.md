# Ones after flipping zeros

**Difficulty:** medium · **Languages:** any of Python, JavaScript, TypeScript, Java, Go · **Topics:** [Arrays and lists](../arrays/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/CS-129?utm_source=github&utm_medium=tasks-repo)**

Given a list of zeros and ones and an integer `k >= 0`, you may change at most `k` zeros into ones. Return the greatest length of a contiguous segment of only ones that you can obtain this way. For an empty list return `0`. The list has up to 5000 elements.

Example: `[1, 0, 1, 1, 0, 0, 1, 1]`, `2` → `6` (flip two zeros in the segment `[1, 1, 0, 0, 1, 1]`).
