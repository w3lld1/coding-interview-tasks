# Train Driver

**Difficulty:** medium · **Language:** JavaScript · **Topics:** [Arrays and lists](../arrays/), [Functions and closures](../functions/)

**[▶ Solve online on CodeShare](https://code-share.online/practice/JS-06?utm_source=github&utm_medium=tasks-repo)**

Using rest and spread, collect any number of wagon ID arguments into an array, move the first two wagons to the end, and insert the array of missing wagons right after the locomotive with number 1. Also write a function that merges a route object with additional properties. From a route object, extract timeOfArrival and return the pair [time, object of the remaining properties].
