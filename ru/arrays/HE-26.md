# Только неповторяющиеся элементы

Дан список целых чисел. Удалите из него все числа, которые встречаются больше одного раза — вместе со всеми их вхождениями. Верните оставшиеся числа в исходном порядке. Если таких нет, верните пустой список.

Пример: `[1, 2, 3, 2, 4]` → `[1, 3, 4]`.
