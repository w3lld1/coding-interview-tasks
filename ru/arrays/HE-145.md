# Сортировка по сумме цифр

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-145?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните его копию, отсортированную по возрастанию суммы цифр. У отрицательного числа первая (старшая) цифра считается со знаком минус: для `-12` сумма равна `-1 + 2 = 1`. Числа с одинаковой суммой оставьте в том порядке, в котором они шли в исходном списке.

Пример: `[1, 11, -1, -11, -12]` → `[-1, -11, 1, -12, 11]`.
