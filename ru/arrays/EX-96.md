# Тайное рукопожатие

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-96?utm_source=github&utm_medium=tasks-repo)**

Дано целое число. По его пяти младшим битам (старшие игнорируйте) составьте список действий, начиная с младшего бита:

- бит 0 (`1`) — `"wink"`;
- бит 1 (`2`) — `"double blink"`;
- бит 2 (`4`) — `"close your eyes"`;
- бит 3 (`8`) — `"jump"`;
- бит 4 (`16`) — не действие: порядок получившегося списка нужно развернуть.

Если ни один из битов 0–3 не установлен, верните пустой список.

Пример: `19` (`10011`) → `["double blink", "wink"]`.
