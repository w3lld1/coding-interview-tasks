# Наименьшее число стрел для шаров

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-158?utm_source=github&utm_medium=tasks-repo)**

Каждый шар — это отрезок `[start, end]` на числовой прямой, границы входят в отрезок. Стрела, выпущенная в точку `x`, лопает все шары, у которых `start <= x <= end`. Верните наименьшее число стрел, которым можно лопнуть все шары. Для пустого списка ответ `0`. Границы помещаются в 32-битное целое со знаком.

Пример: `[[10, 16], [2, 8], [1, 6], [7, 12]]` → `2` (стрела в точку 6 лопает два шара, стрела в точку 12 — два других).
