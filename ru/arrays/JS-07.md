# Два способа обхода колоды

**Сложность:** лёгкая · **Язык:** JavaScript · **Темы:** [Массивы и списки](../arrays/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-07?utm_source=github&utm_medium=tasks-repo)**

Реализуйте две функции подсчёта карт:

- `cardTypeCheck(stack, card)` — получает массив номеров карт и номер `card` и возвращает, сколько раз `card` встречается в массиве; используйте `forEach`;
- `determineOddEvenCards(stack, type)` — получает массив и логический флаг: при `true` возвращает число чётных карт, при `false` — нечётных; используйте цикл `for...of`.
