# Подмассивы с суммой k

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-45?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел (до 2000 элементов, значения по модулю до 1000, возможны отрицательные и нули) и целое число `k`. Верните количество непрерывных непустых подмассивов, сумма элементов которых равна `k`. Подмассивы на разных позициях считаются разными, даже если состоят из одинаковых чисел. Для пустого списка ответ `0`.

Пример: `[1, 1, 1]`, `2` → `2` (позиции 0..1 и 1..2).
