# Числа с положительной суммой цифр

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-108?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. У числа есть знаковые цифры: у положительного все цифры берутся как есть, а у отрицательного первая (старшая) цифра считается отрицательной, остальные — положительными. Например, у `-123` цифры `-1`, `2`, `3`. Верните, у скольких чисел списка сумма знаковых цифр строго больше нуля. Для пустого списка ответ `0`.

Пример: `[-1, 11, -11]` → `1` (суммы: `-1`, `2`, `-1 + 1 = 0`).
