# Близкие числа

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-0?utm_source=github&utm_medium=tasks-repo)**

Дан список чисел и порог. Верните `true`, если в списке есть два элемента на разных позициях, расстояние между которыми строго меньше порога, иначе `false`. Пустой список и список из одного числа дают `false`.

Пример: `[1.0, 2.8, 3.0, 4.0, 5.0, 2.0]`, порог `0.3` → `true` (2.8 и 3.0).
