# Поровну нулей и единиц

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-126?utm_source=github&utm_medium=tasks-repo)**

Дан список из нулей и единиц. Найдите длину самого длинного непрерывного отрезка, в котором нулей и единиц поровну. Если такого отрезка нет (в том числе для пустого списка), верните `0`. Длина списка до 1000.

Пример: `[0, 1, 1, 0, 1, 1, 1, 0]` → `4` (отрезок `[0, 1, 1, 0]`).
