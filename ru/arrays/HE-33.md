# Сортировка каждого третьего

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-33?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните новый список той же длины: значения на индексах 0, 3, 6, … (счёт с нуля) отсортируйте по возрастанию и запишите обратно на эти же индексы, а все остальные элементы оставьте на своих местах. Пустой список даёт пустой список.

Пример: `[5, 6, 3, 4, 8, 9, 2]` → `[2, 6, 3, 4, 8, 9, 5]`.
