# Ёмкость с наибольшим объёмом

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-48?utm_source=github&utm_medium=tasks-repo)**

Дан список неотрицательных целых чисел (до 1000 элементов): высоты вертикальных стенок, стоящих на позициях `0, 1, 2, …`. Выберите две разные стенки так, чтобы между ними поместилось как можно больше воды: площадь равна расстоянию между позициями, умноженному на меньшую из двух высот. Верните наибольшую возможную площадь. Если стенок меньше двух, ответ `0`.

Пример: `[1, 8, 6, 2, 5, 4, 8, 3, 7]` → `49` (стенки на позициях 1 и 8: `7 * 7`).
