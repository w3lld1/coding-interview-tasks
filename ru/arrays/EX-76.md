# Треугольник Паскаля

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-76?utm_source=github&utm_medium=tasks-repo)**

Дано число `count` (от 0 до 20). Верните первые `count` строк треугольника Паскаля в виде списка списков. Первая строка — `[1]`. Каждая следующая строка на один элемент длиннее предыдущей: её первый и последний элементы равны 1, а остальные равны сумме двух соседних элементов предыдущей строки (стоящих слева и справа над ним). Для `0` верните пустой список.

Пример: `4` → `[[1], [1, 1], [1, 2, 1], [1, 3, 3, 1]]`.
