# Минимальная сумма подмассива

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-114?utm_source=github&utm_medium=tasks-repo)**

Дан непустой список целых чисел. Найдите наименьшую сумму среди всех непустых непрерывных подсписков (подряд идущих элементов). Если все числа положительные, ответом будет наименьшее из них. Значения могут не помещаться в 32 бита.

Пример: `[2, 3, 4, 1, 2, 4]` → `1`; `[-1, -2, -3]` → `-6`.
