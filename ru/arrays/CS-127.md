# Кратчайший отрезок с достаточной суммой

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-127?utm_source=github&utm_medium=tasks-repo)**

Дан список положительных целых чисел `nums` и положительное целое `target`. Найдите наименьшую длину непрерывного отрезка, сумма которого не меньше `target`. Если даже весь список даёт меньшую сумму (или список пуст), верните `0`. Длина списка до 5000, сумма помещается в 32-битное целое.

Пример: `[2, 3, 1, 2, 4, 3]`, `7` → `2` (отрезок `[4, 3]`).
