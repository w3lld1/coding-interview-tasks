# Общие элементы двух списков

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-58?utm_source=github&utm_medium=tasks-repo)**

Даны два списка целых чисел. Верните список чисел, которые есть в обоих списках, без повторов и по возрастанию. Если общих чисел нет или один из списков пуст, верните пустой список.

Пример: `[5, 3, 2, 8]`, `[3, 2]` → `[2, 3]`.
