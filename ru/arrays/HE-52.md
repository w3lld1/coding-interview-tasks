# Все числа меньше порога

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-52?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел и целый порог. Верните `true`, если каждое число списка строго меньше порога, иначе `false`. Число, равное порогу, не подходит. Для пустого списка ответ `true`.

Пример: `[1, 2, 4, 10]`, `100` → `true`.
