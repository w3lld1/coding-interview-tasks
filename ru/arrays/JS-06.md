# Состав поезда: rest и spread

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Массивы и списки](../arrays/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-06?utm_source=github&utm_medium=tasks-repo)**

Используйте rest и spread. Реализуйте функции:

- `getListOfWagons(...ids)` — принимает любое число номеров вагонов и возвращает их массивом;
- `fixListOfWagons(ids)` — переносит первые два вагона в конец: `[2, 5, 1, 7]` → `[1, 7, 2, 5]`;
- `correctListOfWagons(ids, missingWagons)` — вставляет вагоны `missingWagons` сразу после первого элемента (локомотива): `[1, 7, 9]` и `[3, 4]` → `[1, 3, 4, 7, 9]`;
- `extendRouteInformation(information, additional)` — возвращает новый объект со свойствами обоих объектов;
- `separateTimeOfArrival(information)` — возвращает пару `[timeOfArrival, остальные свойства]`, где вторым элементом идёт объект маршрута без `timeOfArrival`.

Входные «массивы» в тестах — итерируемые объекты, поэтому методы массивов на них не работают.
