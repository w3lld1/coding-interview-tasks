# Отношения между списками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-05?utm_source=github&utm_medium=tasks-repo)**

Для двух списков A и B верните строку с одной из четырёх категорий: "equal" — списки равны, "sublist" — A является подсписком B, "superlist" — A содержит B, "unequal" — списки не связаны этими отношениями. Подсписок должен занимать непрерывный участок и сохранять порядок элементов, а не просто содержать те же значения. Пустой список содержится в любом списке; если оба пусты, ответ "equal".
