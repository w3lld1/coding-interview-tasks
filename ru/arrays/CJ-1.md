# Расписание поездов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/), [Даты и время](../dates/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-1?utm_source=github&utm_medium=tasks-repo)**

Между станциями A и B ходят поезда. Расписание задано двумя списками рейсов: из A в B и из B в A. Рейс — пара строк `["ЧЧ:ММ", "ЧЧ:ММ"]`: время отправления и время прибытия в пределах одних суток (24-часовой формат, отправление раньше прибытия, рейсы идут в произвольном порядке).

Прибывшему поезду нужно `turnaround` минут, прежде чем он снова сможет отправиться с этой станции (при `turnaround = 0` он уезжает в ту же минуту, когда приехал). Поезд ездит только по рейсам из расписания, за день может проехать несколько рейсов подряд, а в момент каждого отправления на станции должен уже стоять готовый поезд.

Верните список `[x, y]`: минимальное число поездов, которые должны начать день на станции A (`x`) и на станции B (`y`), чтобы выполнить всё расписание. Для пустых списков рейсов ответ `[0, 0]`. В каждом списке не больше 100 рейсов.

Пример: `5`, `[["09:00", "12:00"], ["10:00", "13:00"], ["11:00", "12:30"]]`, `[["12:02", "15:00"], ["09:00", "10:30"]]` → `[2, 2]`.
