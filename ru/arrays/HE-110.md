# Обмен ради чётного списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-110?utm_source=github&utm_medium=tasks-repo)**

Даны два непустых списка целых чисел. Можно сколько угодно раз менять местами элемент первого списка и элемент второго. Верните строку `"YES"`, если так можно сделать все элементы первого списка чётными, иначе `"NO"`.

Пример: `[1, 2, 3, 4]`, `[1, 5, 3, 4]` → `"NO"` (в первом списке два нечётных, а во втором только одно чётное).
