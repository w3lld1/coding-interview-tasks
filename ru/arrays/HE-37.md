# Сортировка элементов на чётных индексах

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-37?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните новый список той же длины: значения на индексах 0, 2, 4, … (счёт с нуля) отсортируйте по возрастанию и запишите обратно на эти же индексы, а элементы на нечётных индексах оставьте как есть. Пустой список даёт пустой список.

Пример: `[5, 6, 3, 4]` → `[3, 6, 5, 4]`.
