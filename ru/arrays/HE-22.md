# Отбор целых чисел

**Сложность:** лёгкая · **Язык:** Python · **Темы:** [Массивы и списки](../arrays/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-22?utm_source=github&utm_medium=tasks-repo)**

Дан список значений произвольных типов: числа, строки, списки, словари, `null`. Верните список только тех элементов, которые являются целыми числами, в исходном порядке. Дробные числа, строки (даже вида `"7"`), вложенные списки, словари и `null` пропускаются. Если целых нет, верните пустой список.

Пример: `["a", 3.14, 5]` → `[5]`.
