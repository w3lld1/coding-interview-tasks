# Карточные фокусы с деструктуризацией

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Массивы и списки](../arrays/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-05?utm_source=github&utm_medium=tasks-repo)**

Напишите функции, используя только деструктуризацию: нельзя вызывать методы массивов и обращаться к элементам или свойствам через `[]` или точку. Колода — итерируемый объект с картами.

- `getFirstCard(deck)` — первая карта (для пустой колоды `undefined`);
- `getSecondCard(deck)` — вторая карта (если её нет, `undefined`);
- `swapTwoCards(deck)` — колода из двух карт `[a, b]`; верните новый массив `[b, a]`;
- `shiftThreeCardsAround(deck)` — колода из трёх карт `[a, b, c]`; верните `[b, c, a]`;
- `pickNamedPile(piles)` — `piles` — объект `{ chosen, disregarded }`; верните стопку `chosen` (тот же объект, не копию);
- `swapNamedPile(piles)` — верните новый объект `{ chosen, disregarded }`, где стопки поменялись местами.
