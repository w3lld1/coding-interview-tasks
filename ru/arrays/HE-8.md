# Сумма и произведение списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-8?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните список из двух чисел: сумма всех элементов и их произведение, именно в таком порядке. Для пустого списка сумма равна `0`, а произведение равно `1`. Результаты помещаются в 32-битное целое.

Пример: `[1, 2, 3, 4]` → `[10, 24]`.
