# Монотонный список

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-57?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните `true`, если он монотонный: либо не убывает, либо не возрастает (равные соседи допустимы), иначе `false`. Пустой список, список из одного числа и список из равных чисел монотонны.

Пример: `[4, 1, 1, 0]` → `true`, а `[1, 20, 4, 10]` → `false`.
