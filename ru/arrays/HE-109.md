# Сортировка циклическим сдвигом

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-109?utm_source=github&utm_medium=tasks-repo)**

Дан список различных целых чисел. За одну операцию последний элемент переносится в начало списка (циклический сдвиг вправо); операций можно сделать сколько угодно, в том числе ни одной. Верните `true`, если так можно получить список, отсортированный по возрастанию, иначе `false`. Пустой список и список из одного числа дают `true`.

Пример: `[3, 4, 5, 1, 2]` → `true` (два сдвига дают `[1, 2, 3, 4, 5]`).
