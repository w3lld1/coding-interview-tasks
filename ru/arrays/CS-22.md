# Вставка отрезка

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-22?utm_source=github&utm_medium=tasks-repo)**

Дан список закрытых отрезков `[начало, конец]` с целыми концами. Он отсортирован по началу, и никакие два отрезка в нём не имеют общих точек. Также дан ещё один отрезок. Вставьте его в список так, чтобы результат остался отсортированным и без общих точек: все отрезки, имеющие с новым хотя бы одну общую точку (в том числе касающиеся концом), сливаются с ним в один. Верните получившийся список.

Пример: `[[1, 3], [6, 9]]`, `[2, 5]` → `[[1, 5], [6, 9]]`.
