# Разделитель между элементами

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-5?utm_source=github&utm_medium=tasks-repo)**

Даны список целых чисел и число-разделитель. Верните новый список, в котором между каждыми двумя соседними элементами исходного списка вставлен разделитель. В начало и в конец разделитель не добавляется. Пустой список и список из одного элемента остаются без изменений.

Пример: `[1, 2, 3]`, `4` → `[1, 4, 2, 4, 3]`.
