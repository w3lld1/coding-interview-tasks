# Точность прогнозов матчей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-152?utm_source=github&utm_medium=tasks-repo)**

Даны два списка целых чисел одинаковой длины: фактические счета матчей и прогнозы на них. Верните список той же длины, где на каждой позиции стоит, насколько прогноз промахнулся: `0`, если он совпал со счётом, иначе модуль разности между прогнозом и счётом. Для пустых списков верните пустой список.

Пример: `[1, 2, 3, 4, 5, 1]`, `[1, 2, 3, 4, 2, -2]` → `[0, 0, 0, 0, 3, 3]`.
