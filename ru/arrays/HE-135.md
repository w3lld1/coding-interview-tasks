# Последний элемент, меньший предыдущего

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-135?utm_source=github&utm_medium=tasks-repo)**

Дан список различных целых чисел. Верните наибольший индекс (нумерация с нуля) элемента, который меньше элемента непосредственно перед ним. Если такого элемента нет (список возрастает, пуст или состоит из одного числа), верните `-1`.

Пример: `[1, 2, 4, 3, 5]` → `3` (число `3` меньше предыдущего `4`).
