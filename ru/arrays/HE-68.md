# Наименьшее чётное и его индекс

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-68?utm_source=github&utm_medium=tasks-repo)**

Дан список неотрицательных целых чисел. Найдите наименьшее чётное значение и верните список из двух чисел `[значение, индекс]`. Если такое значение встречается несколько раз, берите самое левое. Если чётных чисел нет или список пуст, верните пустой список. Ноль считается чётным.

Пример: `[5, 0, 3, 0, 4, 2]` → `[0, 1]`.
