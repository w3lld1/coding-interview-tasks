# Второе наименьшее различное число

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-90?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните второе наименьшее среди различных значений списка: повторы считаются за одно значение. Если различных значений меньше двух (список пуст, из одного элемента или все элементы равны), верните `null`.

Пример: `[5, 1, 4, 3, 2]` → `2`; `[1, 1]` → `null`; `[3, 3, 2, 2]` → `3`.
