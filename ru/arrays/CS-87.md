# Сколько меньших чисел стоит правее

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-87?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел `nums` (до 10^5 элементов, каждое от −10^9 до 10^9). Верните список той же длины, в котором на позиции `i` стоит количество элементов, расположенных правее позиции `i` и строго меньших `nums[i]`. Равные числа не считаются. Для пустого списка верните пустой список.

Пример: `[4, 1, 3, 1, 2]` → `[4, 0, 2, 0, 0]`.
