# Подмассивы с суммой, кратной k

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-161?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел `nums` (возможно, отрицательных) и целое `k >= 1`. Верните число непустых непрерывных подмассивов, сумма которых делится на `k` без остатка (0 тоже делится). Подмассивы с одинаковыми значениями, но на разных позициях считаются разными. Для пустого списка ответ `0`.

Пример: `[4, 5, 0, -2, -3, 1]`, `5` → `7`.
