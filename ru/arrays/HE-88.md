# Порядок сортировки по краям списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-88?utm_source=github&utm_medium=tasks-repo)**

Дан список неотрицательных целых чисел. Верните его отсортированную копию, не изменяя исходный список. Если сумма первого и последнего элементов нечётна, сортируйте по возрастанию, если чётна, по убыванию. Для списка из одного элемента сумма равна удвоенному значению (чётна). Пустой список даёт пустой список.

Пример: `[2, 4, 3, 0, 1, 5]` → `[0, 1, 2, 3, 4, 5]` (2 + 5 = 7, нечётно).
