# Слияние отрезков

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

Дан список отрезков `[начало, конец]` с целыми концами (`начало <= конец`), в произвольном порядке. Отрезки закрытые: общая точка считается пересечением, поэтому `[1, 4]` и `[4, 5]` сливаются в `[1, 5]`. Объедините все пересекающиеся отрезки и верните результат, отсортированный по началу. Для пустого списка верните пустой список.

Пример: `[[1, 3], [2, 6], [8, 10], [15, 18]]` → `[[1, 6], [8, 10], [15, 18]]`.
