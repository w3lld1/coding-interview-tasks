# Тройки с нулевой суммой

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-47?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел (до 500 элементов). Найдите все различные по значениям тройки чисел, сумма которых равна нулю; числа берутся с трёх разных позиций. Каждую тройку запишите по возрастанию, а список троек верните в лексикографическом порядке (сначала сравниваются первые числа, затем вторые, затем третьи). Одинаковые по значениям тройки не повторяются. Если подходящих троек нет, верните пустой список.

Пример: `[-1, 0, 1, 2, -1, -4]` → `[[-1, -1, 2], [-1, 0, 1]]`.
