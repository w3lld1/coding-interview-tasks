# Странная сортировка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-70?utm_source=github&utm_medium=tasks-repo)**

«Странный» порядок такой: сначала наименьшее число списка, затем наибольшее из оставшихся, затем снова наименьшее из оставшихся, и так далее по очереди. Верните новый список, упорядоченный таким образом, из всех элементов исходного (повторы сохраняются). Для пустого списка верните пустой.

Пример: `[1, 2, 3, 4]` → `[1, 4, 2, 3]`.
