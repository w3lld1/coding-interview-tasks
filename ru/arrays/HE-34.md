# Уникальные значения по возрастанию

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-34?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните список его различных значений, отсортированный по возрастанию: каждое значение встречается в результате один раз. Для пустого списка результат пуст.

Пример: `[5, 3, 5, 2, 3, 3, 9, 0, 123]` → `[0, 2, 3, 5, 9, 123]`.
