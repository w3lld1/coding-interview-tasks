# Чётные числа на нечётных позициях

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-85?utm_source=github&utm_medium=tasks-repo)**

Дан непустой список целых чисел. Верните сумму тех его элементов, которые чётны и стоят на нечётных индексах (индексация с 0, то есть на позициях 1, 3, 5, …). Если таких элементов нет, ответ `0`. Отрицательные чётные числа тоже считаются.

Пример: `[4, 2, 6, 7]` → `2` (на индексах 1 и 3 стоят `2` и `7`, чётное только `2`).
