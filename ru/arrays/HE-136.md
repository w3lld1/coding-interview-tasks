# Ближайшие к нулю отрицательное и положительное

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-136?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните список из двух элементов `[a, b]`: `a` — наибольшее из отрицательных чисел (ближайшее к нулю слева), `b` — наименьшее из положительных (ближайшее к нулю справа). Если отрицательных чисел нет, `a` равно `null`; если нет положительных, `b` равно `null`. Ноль не считается ни отрицательным, ни положительным.

Пример: `[2, 4, 1, 3, 5, 7]` → `[null, 1]`, `[-6, -4, -3, 1]` → `[-3, 1]`.
