# Кратчайший участок для сортировки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-164?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Нужно найти самый короткий непрерывный участок, после сортировки которого по возрастанию (нестрого) весь список станет отсортированным. Верните длину этого участка. Если список уже отсортирован (в том числе пустой или из одного элемента), верните `0`.

Пример: `[2, 6, 4, 8, 10, 9, 15]` → `5` (участок `[6, 4, 8, 10, 9]`).
