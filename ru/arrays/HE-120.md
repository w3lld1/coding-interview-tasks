# k наибольших по возрастанию

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-120?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел и число `k` (0 ≤ `k` ≤ длины списка). Верните список из `k` наибольших элементов, упорядоченный по возрастанию. Повторяющиеся значения учитываются столько раз, сколько они встречаются. При `k` = 0 результат пуст. Исходный список менять не нужно.

Пример: `[4, -4, 4]`, `2` → `[4, 4]`.
