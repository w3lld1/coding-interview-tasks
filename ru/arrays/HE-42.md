# Увеличить каждый элемент на единицу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-42?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните новый список той же длины, в котором каждый элемент на 1 больше соответствующего элемента исходного. Порядок сохраняется, пустой список даёт пустой список.

Пример: `[1, 2, 3]` → `[2, 3, 4]`.
