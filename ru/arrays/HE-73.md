# Минимум замен до палиндрома

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-73?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. За одну замену можно заменить любой один элемент любым другим числом. Верните наименьшее число замен, после которых список читается одинаково слева направо и справа налево. Пустой список и список из одного элемента уже симметричны, ответ для них `0`.

Пример: `[1, 2, 3, 4, 3, 2, 2]` → `1`; `[1, 2, 3, 5, 4, 7, 9, 6]` → `4`.
