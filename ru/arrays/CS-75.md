# Максимумы скользящего окна

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Стек, очередь, связные списки](../stacks-lists/)

Дан список целых чисел `nums` и целое `k` (`1 ≤ k ≤ n`, где `n` — длина списка). Окно ширины `k` проходит по списку слева направо, сдвигаясь на одну позицию; всего окон `n − k + 1`. Верните список максимумов всех окон в порядке их положения. Решение должно работать за O(n): перебор каждого окна за O(k) не подходит.

В списке от 1 до 100 000 чисел, каждое от −10⁹ до 10⁹.

Пример: `[4, -2, 5, 1, 1, 3]`, `3` → `[5, 5, 5, 3]`.
