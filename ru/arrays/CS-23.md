# Переговорные комнаты

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

Дан список встреч `[начало, конец]` с целыми моментами времени, `начало < конец`. Встреча занимает полуинтервал от начала до конца: если одна встреча заканчивается в тот момент, когда другая начинается, комната освобождается и их можно провести в одной комнате. Найдите наименьшее число комнат, достаточное для всех встреч. Для пустого списка ответ `0`.

Пример: `[[0, 30], [5, 10], [15, 20]]` → `2`.
