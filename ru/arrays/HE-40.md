# Три числа с нулевой суммой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-40?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните `true`, если в нём есть три элемента на трёх разных позициях, сумма которых равна нулю, иначе `false`. Значения могут повторяться: два равных числа на разных позициях считаются разными элементами. Если в списке меньше трёх элементов, ответ `false`.

Пример: `[2, 4, -5, 3, 9, 7]` → `true` (2 + 3 − 5 = 0).
