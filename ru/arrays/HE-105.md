# Названия цифр по убыванию

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-105?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Оставьте только числа от 1 до 9 включительно, расположите их по убыванию и замените каждое английским названием: `"One"`, `"Two"`, `"Three"`, `"Four"`, `"Five"`, `"Six"`, `"Seven"`, `"Eight"`, `"Nine"`. Остальные числа (нули, отрицательные, больше 9) игнорируются. Повторы сохраняются. Если подходящих чисел нет, верните пустой список.

Пример: `[2, 1, 1, 4, 5, 8, 2, 3]` → `["Eight", "Five", "Four", "Three", "Two", "Two", "One", "One"]`.
