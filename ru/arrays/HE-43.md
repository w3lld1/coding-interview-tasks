# Пара с нулевой суммой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-43?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните `true`, если в нём есть два элемента на разных позициях, сумма которых равна нулю, иначе `false`. Два нуля в разных позициях подходят, а один ноль сам с собой — нет. Пустой список и список из одного элемента дают `false`.

Пример: `[2, 4, -5, 3, 5, 7]` → `true` (−5 и 5).
