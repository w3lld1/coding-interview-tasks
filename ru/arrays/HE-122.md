# Сумма коротких чисел в начале

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-122?utm_source=github&utm_medium=tasks-repo)**

Дан непустой список целых чисел и число `k` (1 ≤ `k` ≤ длина списка). Рассмотрите первые `k` элементов списка и верните сумму тех из них, в записи которых не больше двух цифр. Знак минус не считается цифрой: `-50` подходит, `-100` и `100` — нет.

Пример: `[111, 21, 3, 4000, 5, 6, 7, 8, 9]`, `4` → `24` (21 + 3).
