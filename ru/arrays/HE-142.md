# Сумма с возведением по индексам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-142?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Элемент с индексом, кратным 3, возведите в квадрат. Элемент с индексом, кратным 4, но не кратным 3, возведите в куб. Остальные элементы не меняйте. Индексы считаются с нуля, так что индекс 0 кратен 3. Верните сумму получившихся значений; для пустого списка это `0`.

Пример: `[-1, -5, 2, -1, -5]` → `-126` (1 − 5 + 2 + 1 − 125).
