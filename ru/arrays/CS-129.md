# Единицы после переворота нулей

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-129?utm_source=github&utm_medium=tasks-repo)**

Дан список из нулей и единиц и целое `k >= 0`. Разрешено заменить на единицу не больше `k` нулей. Верните наибольшую длину непрерывного отрезка из одних единиц, который можно получить таким образом. Для пустого списка верните `0`. Длина списка до 5000.

Пример: `[1, 0, 1, 1, 0, 0, 1, 1]`, `2` → `6` (заменяем два нуля в отрезке `[1, 1, 0, 0, 1, 1]`).
