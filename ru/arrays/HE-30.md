# Положительные числа списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-30?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Верните новый список только из положительных чисел в исходном порядке. Ноль положительным не считается. Если положительных чисел нет, верните пустой список.

Пример: `[-1, 2, -4, 5, 6]` → `[2, 5, 6]`.
