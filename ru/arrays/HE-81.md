# Буквенные оценки по среднему баллу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-81?utm_source=github&utm_medium=tasks-repo)**

Преподаватель хранит средние баллы студентов (GPA) в списке. Переведите каждый балл в буквенную оценку и верните список оценок в том же порядке.

Шкала: ровно `4.0` → `A+`; больше `3.7` → `A`; больше `3.3` → `A-`; больше `3.0` → `B+`; больше `2.7` → `B`; больше `2.3` → `B-`; больше `2.0` → `C+`; больше `1.7` → `C`; больше `1.3` → `C-`; больше `1.0` → `D+`; больше `0.7` → `D`; больше `0.0` → `D-`; ровно `0.0` → `E`. Границы строгие: балл `3.7` уже не `A`, а `A-`. Для пустого списка верните пустой список.

Пример: `[4.0, 3.0, 1.7, 2.0, 3.5]` → `["A+", "B", "C-", "C", "A-"]`.
