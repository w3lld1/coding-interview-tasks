# Следующая перестановка

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

Рассмотрим все перестановки элементов списка, записанные как списки и упорядоченные лексикографически (по первому элементу, при равенстве по второму и т. д.; равные элементы не различаются). Дан список `nums`. Верните ту перестановку, которая идёт сразу за ним. Если `nums` — наибольшая перестановка, верните наименьшую, то есть список по возрастанию. Пустой список и список из одного элемента возвращаются без изменений. Входной список менять не нужно.

Пример: `[1, 2, 3]` → `[1, 3, 2]`; `[3, 2, 1]` → `[1, 2, 3]`.
