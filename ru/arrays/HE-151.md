# Сумма квадратов нечётных

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-151?utm_source=github&utm_medium=tasks-repo)**

Дан список чисел, среди которых могут быть дробные. Верните сумму квадратов тех элементов, которые являются положительными нечётными целыми числами (например, `3` и `3.0` подходят, `3.5` и `-3` нет). Ноль и отрицательные числа не учитываются. Для пустого списка ответ `0`.

Пример: `[1, 3, 2, 0]` → `10` (1 + 9).
