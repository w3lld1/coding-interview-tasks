Дан список целых чисел. Верните список той же длины, где элемент на позиции `i` равен наибольшему из элементов исходного списка с позиции 0 по `i` включительно. Для пустого списка верните пустой список.

Пример: `[1, 2, 3, 2, 3, 4, 2]` → `[1, 2, 3, 3, 3, 4, 4]`.
