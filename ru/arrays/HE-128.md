# Сумма модулей на произведение знаков

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-128?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Знак числа — это 1 для положительного, -1 для отрицательного и 0 для нуля. Верните сумму модулей всех чисел, умноженную на произведение знаков всех чисел. Для пустого списка верните `null`.

Пример: `[1, 2, 2, -4]` → `-9` (сумма модулей 9, произведение знаков -1); `[0, 1]` → `0`; `[]` → `null`.
