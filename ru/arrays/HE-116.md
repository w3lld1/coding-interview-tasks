# Сортировка по числу единиц

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-116?utm_source=github&utm_medium=tasks-repo)**

Отсортируйте список целых чисел по возрастанию количества единиц в двоичной записи числа. Числа с одинаковым количеством единиц упорядочьте по возрастанию значения. Для отрицательных чисел единицы считаются в двоичной записи модуля. Верните новый список; пустой список даёт пустой.

Пример: `[1, 5, 2, 3, 4]` → `[1, 2, 4, 3, 5]` (в двоичном виде: 1, 101, 10, 11, 100).
