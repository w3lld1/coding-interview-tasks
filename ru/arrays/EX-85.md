# Значение двух полос резистора

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-85?utm_source=github&utm_medium=tasks-repo)**

Цвета полос кодируют цифры: `black` — 0, `brown` — 1, `red` — 2, `orange` — 3, `yellow` — 4, `green` — 5, `blue` — 6, `violet` — 7, `grey` — 8, `white` — 9. Дан список из двух или трёх названий цветов. Первые два цвета задают двузначное число: первая цифра — десятки, вторая — единицы. Третий цвет, если он есть, игнорируется. Верните это число (оно может быть меньше 10, например `black`, `brown` → `1`).

Пример: `["brown", "green", "violet"]` → `15`.
