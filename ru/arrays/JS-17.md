# Преобразования колоды встроенными методами

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-17?utm_source=github&utm_medium=tasks-repo)**

Колода — массив чисел. Реализуйте функции с помощью встроенных методов массивов:

- `seeingDouble(deck)` — новый массив, где каждое значение удвоено;
- `threeOfEachThree(deck)` — каждую карту 3 замените тремя картами 3: `[3, 1]` → `[3, 3, 3, 1]`;
- `middleTwo(deck)` — для колоды ровно из 10 карт верните массив из двух средних карт (позиции 4 и 5);
- `sandwichTrick(deck)` — для колоды чётной длины уберите первую и последнюю карты и вставьте их в середину в порядке «последняя, первая»: `[1, 2, 3, 4]` → `[2, 4, 1, 3]`;
- `twoIsSpecial(deck)` — оставьте только карты 2;
- `perfectlyOrdered(deck)` — отсортируйте по возрастанию как числа;
- `reorder(deck)` — разверните порядок карт.
