# Отрезок не более чем с двумя значениями

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-128?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел. Найдите длину самого длинного непрерывного отрезка, в котором встречается не больше двух различных значений. Для пустого списка верните `0`. Длина списка до 5000.

Пример: `[1, 2, 3, 2, 2]` → `4` (отрезок `[2, 3, 2, 2]`).
