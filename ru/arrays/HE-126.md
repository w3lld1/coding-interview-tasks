# Отсортирован ли список без троек одинаковых

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-126?utm_source=github&utm_medium=tasks-repo)**

Дан список неотрицательных целых чисел. Верните `true`, если выполнены оба условия: числа идут по неубыванию (каждое не меньше предыдущего) и ни одно значение не встречается в списке больше двух раз. Иначе верните `false`. Пустой список и список из одного числа дают `true`.

Пример: `[1, 2, 2, 3, 3, 4]` → `true`, `[1, 2, 2, 2, 3, 4]` → `false`.
