# Числа без чётных цифр

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-104?utm_source=github&utm_medium=tasks-repo)**

Дан список положительных целых чисел. Верните новый список из тех чисел, в десятичной записи которых нет ни одной чётной цифры (0, 2, 4, 6, 8), отсортированный по возрастанию. Повторы сохраняются. Если подходящих чисел нет, верните пустой список.

Пример: `[15, 33, 1422, 1]` → `[1, 15, 33]`.
