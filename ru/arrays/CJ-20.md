# Свежий шоколад

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-20?utm_source=github&utm_medium=tasks-repo)**

Шоколад продаётся пачками по `pack` кусочков (`2 ≤ pack ≤ 4`). На экскурсию приходят группы по одной; в каждой `groups[i]` человек (`1 ≤ groups[i] ≤ 100`, групп не больше 100), и каждому нужен ровно один кусочек. Сначала раздаются остатки от прошлых групп, и только когда остатков нет, открывается новая пачка; пачки открываются, пока кусочков не хватит всем, а лишнее остаётся для следующей группы.

Группа получает «свежий» шоколад, если к её приходу остатков нет. Вы можете выбрать любой порядок групп. Верните наибольшее возможное число групп со свежим шоколадом.

Пример: `[5, 6, 4, 4]`, `3` → `3` (порядок `4, 5, 6, 4`: свежий шоколад получат все группы, кроме группы из 5 человек).
