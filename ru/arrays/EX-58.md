# Таблица рекордов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

Дан список очков игрока в порядке добавления (не пустой) и запрос `query`. Верните список:
- `"scores"` — все очки в исходном порядке;
- `"latest"` — список из одного элемента, последнего добавленного очка;
- `"personal_best"` — список из одного элемента, наибольшего очка;
- `"top_three"` — три наибольших очка по убыванию (повторяющиеся значения считаются отдельно); если очков меньше трёх, верните все, тоже по убыванию.

Исходный список менять не нужно.

Пример: `[40, 20, 40, 30]`, `"top_three"` → `[40, 40, 30]`.
