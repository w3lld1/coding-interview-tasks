# Оставить или отбросить по условию

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-103?utm_source=github&utm_medium=tasks-repo)**

Реализуйте `keep` и `discard` для списка целых чисел вручную, без встроенных `filter`, `reject` и похожих функций. Даны режим `mode` (`"keep"` или `"discard"`), название условия `predicate` и список.

Условия: `"all"` — верно для любого числа; `"none"` — не верно ни для какого; `"odd"` — число нечётное (не делится на 2, в том числе отрицательное); `"even"` — чётное; `"positive"` — строго больше нуля. В режиме `"keep"` верните числа, для которых условие верно, в режиме `"discard"` — те, для которых оно неверно. Порядок элементов сохраняется, исходный список не меняется.

Пример: `"keep"`, `"even"`, `[1, 2, 3, 4, 5]` → `[2, 4]`.
