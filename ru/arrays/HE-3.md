# Уход счёта в минус

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-3?utm_source=github&utm_medium=tasks-repo)**

Банковский счёт начинается с нуля. Дан список операций: положительное число — пополнение, отрицательное — снятие. Верните `true`, если после какой-либо операции баланс стал строго меньше нуля, иначе `false`. Для пустого списка ответ `false`; баланс ровно ноль минусом не считается.

Пример: `[1, 2, -4, 5]` → `true`.
