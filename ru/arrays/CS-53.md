**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Словари и множества](../hashing/), [Математика](../math/)

Процессор выполняет по одной задаче за единицу времени. Задачи заданы строкой из заглавных латинских букв: одна буква — один тип задачи, порядок в строке не важен. Две задачи одного типа нельзя запускать ближе, чем через `n` единиц времени: между ними должно пройти не меньше `n` других единиц (в них можно выполнять другие задачи или простаивать). Верните наименьшее число единиц времени, за которое можно выполнить все задачи. Для пустой строки ответ `0`. Длина строки до 1000, `0 ≤ n ≤ 100`.

Пример: `"AAABBB"`, `2` → `8` (A B _ A B _ A B).
