# Лучшая покерная рука

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-20?utm_source=github&utm_medium=tasks-repo)**

Дан список покерных рук. Каждая рука — строка из пяти карт через пробел, карта — достоинство (`2`–`10`, `J`, `Q`, `K`, `A`) и масть (`S`, `H`, `D`, `C`), например `"10D JH QS KD AC"`. Верните все руки с наивысшей силой в любом порядке; при равенстве сил верните все такие руки. Карты в разных руках могут повторяться (играют несколько колод).

Силы комбинаций от старшей к младшей: стрит-флеш, каре, фулл-хаус, флеш, стрит, тройка, две пары, пара, старшая карта. Стрит — пять подряд идущих достоинств; туз может быть старшим (`10 J Q K A`) или младшим (`A 2 3 4 5`, такой стрит самый слабый), но не в середине (`Q K A 2 3` не стрит). Масти важны только для флеша.

Руки одной комбинации сравнивайте по достоинствам. Сначала сравниваются группы одинаковых карт большего размера, среди групп одного размера — старшие по достоинству (например, у двух пар сначала старшая пара, потом младшая, потом оставшаяся карта; у фулл-хауса сначала тройка, потом пара).

Пример: `["4S 5H 6C 8D KH", "2S 4H 6S 4D JH"]` → `["2S 4H 6S 4D JH"]` (пара сильнее старшей карты).
