# Произведение остальных

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-46?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел (до 1000 элементов). Верните список той же длины, где элемент на позиции `i` равен произведению всех элементов исходного списка, кроме элемента на позиции `i`. Деление использовать нельзя. Гарантируется, что все произведения помещаются в 32-битное целое. Для списка из одного элемента ответ `[1]` (произведение пустого набора равно 1), для пустого списка — пустой список.

Пример: `[1, 2, 3, 4]` → `[24, 12, 8, 6]`.
