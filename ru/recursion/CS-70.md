# Разбиения на палиндромы

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

Дана непустая строка `s` из строчных латинских букв длиной не более 16. Верните все способы разрезать её на подряд идущие части так, чтобы каждая часть была палиндромом (читалась одинаково слева направо и справа налево). Способ записывается как список частей по порядку. Способы упорядочьте по позициям разрезов: сравнивайте длины частей по очереди, начиная с первой, и раньше ставьте способ с более короткой частью.

Пример: `"aab"` → `[["a", "a", "b"], ["aa", "b"]]`.
