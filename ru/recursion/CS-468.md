# Разбиения на порции по порядку

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-468?utm_source=github&utm_medium=tasks-repo)**

Нужно выложить `n` плиток в ряд из нескольких стопок подряд, в каждой стопке хотя бы одна плитка; порядок стопок важен (`[1, 2]` и `[2, 1]` — разные раскладки). Верните все раскладки: каждая — список размеров стопок слева направо, сумма равна `n`. Раскладки идут в лексикографическом порядке (списки сравниваются поэлементно слева направо). Для `n = 0` раскладка одна — пустой список. Считайте, что `n` не больше 8.

Пример: `3` → `[[1, 1, 1], [1, 2], [2, 1], [3]]`.
