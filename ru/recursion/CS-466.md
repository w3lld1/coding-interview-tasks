# Положения выключателей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-466?utm_source=github&utm_medium=tasks-repo)**

На щитке `n` выключателей в ряд. Нужно, чтобы включены были ровно `k` из них. Верните все такие положения как строки из `n` символов (`1` — включён, `0` — выключен), слева направо, в порядке возрастания (как строки). Если подходящих положений нет, верните пустой список. Для `n = 0`, `k = 0` ответ — список из пустой строки. Считайте, что `n` не больше 10.

Пример: `3`, `1` → `["001", "010", "100"]`.
