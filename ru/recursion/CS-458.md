# Варианты регистра букв

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-458?utm_source=github&utm_medium=tasks-repo)**

В пароле каждую латинскую букву можно записать строчной или заглавной, а цифры остаются на месте. Верните все различные варианты строки `text`, которые получаются выбором регистра для каждой буквы (исходный регистр букв роли не играет). Порядок: слева направо, на каждой букве сначала строчная, потом заглавная, то есть первая буква меняется медленнее всех. В строке только латинские буквы и цифры, букв не больше 8. Для строки без букв вариант один — она сама.

Пример: `"a1b"` → `["a1b", "a1B", "A1b", "A1B"]`.
