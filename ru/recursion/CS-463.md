# Суммы выбора из списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

В кошельке лежат купюры, номиналы заданы списком `numbers` (возможны повторы; отрицательные числа и ноль тоже допустимы, считайте их просто числами). Можно взять любой набор купюр, в том числе пустой. Верните все различные суммы, которые получаются, по возрастанию. Пустой набор даёт сумму `0`, так что она всегда есть. В списке не больше 12 элементов, по модулю каждый не больше 100.

Пример: `[1, 2, 3]` → `[0, 1, 2, 3, 4, 5, 6]`.
