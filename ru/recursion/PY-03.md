# Разворачивание вложенного списка

**Сложность:** средняя · **Язык:** Python · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-03?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `flatten(iterable)`. Она получает список, в котором могут быть вложенные списки любой глубины, и возвращает новый плоский список из всех его элементов. Порядок элементов сохраняйте таким, как при обходе слева направо. Значения `None` пропускайте на любом уровне. Пустые вложенные списки ничего не добавляют в результат.
