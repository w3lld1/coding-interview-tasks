# Линейка Кантора

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-459?utm_source=github&utm_medium=tasks-repo)**

Рисуем линейку по шагам. Уровень 0 — одна черта `"-"`. Уровень `n` получается из уровня `n - 1` так: записываем строку уровня `n - 1`, затем столько же точек `.`, затем ту же строку уровня `n - 1` ещё раз. Верните строку уровня `n`. Считайте, что `n` не больше 7.

Пример: `2` → `"-.-...-.-"` (уровень 1 — `"-.-"`).
