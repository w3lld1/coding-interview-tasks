# Сочетания с заданной суммой

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-68?utm_source=github&utm_medium=tasks-repo)**

Дан список различных положительных целых чисел `candidates` (не более 20) и целое `target` от 1 до 40. Верните все различные наборы чисел из `candidates`, сумма которых равна `target`; каждое число можно использовать в наборе сколько угодно раз. Наборы, отличающиеся только порядком чисел, считаются одинаковыми, поэтому записывайте числа набора по неубыванию. Сами наборы упорядочьте лексикографически. Если подходящих наборов нет, верните пустой список.

Пример: `[2, 3, 6, 7]`, `7` → `[[2, 2, 3], [7]]`.
