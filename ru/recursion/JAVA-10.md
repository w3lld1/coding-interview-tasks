# Разворачивание вложенного списка

**Сложность:** средняя · **Язык:** Java · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JAVA-10?utm_source=github&utm_medium=tasks-repo)**

Реализуйте метод `flatten(List<?> list)` класса `Flattener`. Он получает список, в котором есть числа и вложенные списки любой глубины, и возвращает новый плоский список `List<Object>` со всеми числами. Порядок сохраняйте таким, как при обходе слева направо. Значения `null` пропускайте на любом уровне. Пустые вложенные списки ничего не добавляют в результат.
