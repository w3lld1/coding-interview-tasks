# Неизвестные биты

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

Датчик передал битовую маску, где часть битов потеряна и помечена знаком `?`. В строке `pattern` только символы `0`, `1` и `?`. Верните все строки, которые получаются заменой каждого `?` на `0` или `1`, в порядке возрастания (как строк). Если `?` нет, ответ — список из самой строки; для пустой строки — список из пустой строки. Знаков `?` не больше 6.

Пример: `"1?0?"` → `["1000", "1001", "1100", "1101"]`.
