# Выпадения кубиков с суммой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-465?utm_source=github&utm_medium=tasks-repo)**

Бросают `dice` обычных шестигранных кубиков по очереди (порядок кубиков важен: `[1, 4]` и `[4, 1]` — разные исходы). Верните все исходы, в которых сумма очков равна `total`. Каждый исход — список очков кубиков по порядку; исходы идут в лексикографическом порядке (списки сравниваются поэлементно слева направо). Если подходящих исходов нет, верните пустой список. Считайте, что `1 ≤ dice ≤ 5` и `total ≥ 0`.

Пример: `2`, `5` → `[[1, 4], [2, 3], [3, 2], [4, 1]]`.
