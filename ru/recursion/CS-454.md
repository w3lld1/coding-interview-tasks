# Ходы ханойской башни

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-454?utm_source=github&utm_medium=tasks-repo)**

На стержне `source` лежат `n` дисков по убыванию размера снизу вверх. Нужно перенести их на стержень `target`, используя `spare`. За ход переносится один верхний диск, класть больший диск на меньший нельзя. Верните список ходов минимальной длины в виде строк `"откуда->куда"` (названия стержней как переданы), в том порядке, в котором их нужно делать. Минимальная последовательность ходов единственна. Для `n = 0` ходов нет. Считайте, что `n` не больше 8.

Пример: `2`, `"A"`, `"C"`, `"B"` → `["A->B", "A->C", "B->C"]`.
