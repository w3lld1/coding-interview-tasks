# Слово кроликов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

Слово начинается как `"A"`. За один шаг каждая буква заменяется сразу по правилам: `A` → `AB`, `B` → `A` (все замены происходят одновременно по буквам прошлого слова). Верните слово после `steps` шагов. Считайте, что `steps` не больше 12.

Пример: `3` → `"ABAAB"` (A → AB → ABA → ABAAB).
