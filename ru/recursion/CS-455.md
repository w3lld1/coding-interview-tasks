# Выбор k номеров из n

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-455?utm_source=github&utm_medium=tasks-repo)**

На выставке `n` стендов с номерами от 1 до `n`. Нужно выбрать ровно `k` разных стендов для обхода; порядок выбора не важен. Верните все варианты: каждый — список номеров по возрастанию, а сами варианты — в лексикографическом порядке (сравнение списков поэлементно слева направо). Для `k = 0` вариант один — пустой список; если `k > n`, вариантов нет. Считайте, что `n` не больше 10.

Пример: `4`, `2` → `[[1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]]`.
