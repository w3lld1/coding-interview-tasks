# Слово на сетке букв

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Матрицы и сетки](../matrices/)

Дана сетка букв: список одинаковых по длине непустых строк (до 6×6) и непустое слово. Верните `true`, если слово можно прочитать, двигаясь по клеткам сетки на соседние по стороне клетки (вверх, вниз, влево, вправо; по диагонали нельзя) и не используя одну и ту же клетку дважды. Первая буква слова может лежать в любой клетке. Регистр важен.

Пример: `["ab", "cd"]`, `"abdc"` → `true`; `"abab"` → `false`.
