# Замкнутая цепочка домино

**Сложность:** сложная · **Язык:** Python · **Темы:** [Рекурсия и перебор](../recursion/), [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-24?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `can_chain(dominoes)`. Она получает список костяшек домино — пар чисел — и строит из них замкнутую цепочку, в которой каждая костяшка использована ровно один раз. Соседние половины соседних костяшек должны совпадать, и последнее число цепочки должно совпадать с первым. Костяшки можно переворачивать; одинаковые пары — разные костяшки. Верните любую подходящую цепочку списком пар, пустой список для пустого входа или `None`, если цепочку составить нельзя.
