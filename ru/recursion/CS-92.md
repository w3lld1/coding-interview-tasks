# Знаки между цифрами до нужного значения

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-92?utm_source=github&utm_medium=tasks-repo)**

Дана строка из цифр (от 0 до 10 символов) и целое число `target`. Между соседними цифрами можно ничего не ставить (цифры сливаются в одно число) или поставить один из знаков `+`, `-`, `*`; порядок цифр менять нельзя, знак перед первой цифрой ставить нельзя. Число из нескольких цифр не может начинаться с `0` (сам `0` допустим). Выражение считается по обычным правилам: умножение выполняется раньше сложения и вычитания, промежуточные значения могут выходить за 32 бита. Верните все выражения, значение которых равно `target`, без пробелов, отсортированные по возрастанию как строки (посимвольно по кодам: `*` < `+` < `-` < цифры). Если подходящих выражений нет или строка пуста, верните `[]`.

Пример: `"232"`, `8` → `["2*3+2", "2+3*2"]`.
