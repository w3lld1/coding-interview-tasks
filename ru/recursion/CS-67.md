# Уникальные перестановки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Массивы и списки](../arrays/)

Дан список целых чисел, возможно с повторами, не длиннее 8 элементов. Верните все различные перестановки его элементов: две перестановки считаются одинаковыми, если совпадают как последовательности значений. Результат упорядочьте лексикографически (по первому элементу, при равенстве по второму и так далее). Для пустого списка единственная перестановка — пустая, ответ `[[]]`.

Пример: `[1, 1, 2]` → `[[1, 1, 2], [1, 2, 1], [2, 1, 1]]`.
