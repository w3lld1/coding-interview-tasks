# Лампочки без соседей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-452?utm_source=github&utm_medium=tasks-repo)**

В гирлянде `n` лампочек, каждая включена (`1`) или выключена (`0`). Две включённые лампочки рядом не допускаются. Верните все допустимые состояния гирлянды как строки из нулей и единиц длины `n` в порядке возрастания (как строки, слева направо; `0` раньше `1`). Для `n = 0` есть одно состояние — пустая строка. Считайте, что `n` не больше 10.

Пример: `3` → `["000", "001", "010", "100", "101"]`.
