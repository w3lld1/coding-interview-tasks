# Код Грея

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

Положение поворотного переключателя кодируется строкой из `n` бит. Нужен порядок всех `2^n` кодов, в котором соседние коды отличаются ровно одним битом (отражённый код Грея). Постройте его так: для `n = 0` список — `[""]`; для `n > 0` возьмите список для `n - 1`, припишите к каждому коду слева `0`, затем тот же список в обратном порядке, с припиской `1`. Верните список строк. Считайте, что `n` не больше 8.

Пример: `2` → `["00", "01", "11", "10"]`.
