# Разбор строки на IP-адрес

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/), [Разбор и проверка данных](../parsing/)

Дана строка из цифр. Расставьте в ней три точки так, чтобы получился корректный IPv4-адрес: четыре части, каждая — число от 0 до 255 в десятичной записи без ведущих нулей (часть `0` допустима, `01` и `00` — нет). Цифры нельзя переставлять, удалять или добавлять. Верните все такие адреса, отсортированные по возрастанию как строки; если подходящих нет (в том числе для пустой строки), верните пустой список. Длина строки не больше 20.

Пример: `"25525511135"` → `["255.255.11.135", "255.255.111.35"]`.
