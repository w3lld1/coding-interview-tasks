# Сумма с весом по глубине

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-457?utm_source=github&utm_medium=tasks-repo)**

Строка `text` описывает вложенный список целых чисел: элементы разделены запятыми без пробелов, вложенные списки заключены в квадратные скобки, вся строка — один список (например `[1,[4,[6]]]`). Числа могут быть многозначными и отрицательными. Каждое число умножается на глубину своего списка: у внешнего списка глубина 1, у списка внутри него — 2 и так далее. Верните сумму всех таких произведений. Если чисел нет (например `[]`), ответ `0`. Глубина не больше 20.

Пример: `"[1,[4,[6]]]"` → `27` (1·1 + 4·2 + 6·3).
