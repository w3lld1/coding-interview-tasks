# Складки бумажной ленты

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

Бумажную ленту складывают пополам `n` раз, всякий раз в одну сторону, затем разворачивают. На ленте остаются сгибы, каждый смотрит вправо (`R`) или влево (`L`). Последовательность слева направо строится так: для `n = 0` она пустая; для `n > 0` берём последовательность для `n - 1`, дописываем `R`, затем её же в обратном порядке, где каждая буква заменена на противоположную (`R` на `L`, `L` на `R`). Верните строку. Считайте, что `n` не больше 10.

Пример: `3` → `"RRLRRLL"`.
