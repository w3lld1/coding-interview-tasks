# Слова по кнопкам телефона

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

На кнопочном телефоне буквы разложены так: `2` — `abc`, `3` — `def`, `4` — `ghi`, `5` — `jkl`, `6` — `mno`, `7` — `pqrs`, `8` — `tuv`, `9` — `wxyz`. Дана строка из цифр `2`–`9`. Верните все строки из букв, которые можно набрать этими кнопками (по одной букве на каждую цифру). Порядок: сначала меняется последняя буква, затем предпоследняя и т. д., буквы на кнопке идут как в таблице. Для пустой строки верните пустой список. Считайте, что цифр не больше 5.

Пример: `"23"` → `["ad", "ae", "af", "bd", "be", "bf", "cd", "ce", "cf"]`.
