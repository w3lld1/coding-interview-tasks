# Правильные скобочные строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Рекурсия и перебор](../recursion/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-66?utm_source=github&utm_medium=tasks-repo)**

Дано число `n` от 0 до 8. Верните все правильные скобочные строки из `n` пар круглых скобок: в них каждая `(` закрывается своей `)`, а в любом префиксе закрывающих скобок не больше, чем открывающих. Строки упорядочьте по возрастанию как обычные строки, при этом `(` считается меньше `)`. Для `n = 0` единственная строка — пустая, ответ `[""]`.

Пример: `3` → `["((()))", "(()())", "(())()", "()(())", "()()()"]`.
