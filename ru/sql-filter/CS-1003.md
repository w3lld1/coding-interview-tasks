# Самый загруженный час каждого объекта

**Сложность:** сложная · **Язык:** SQL (SQLite) · **Темы:** [SQL: выборка и фильтры](../sql-filter/), [SQL: группировка](../sql-aggregate/), [SQL: JOIN](../sql-join/)

Часом бронирования назовём час его начала, `strftime('%H', starttime)`. Для каждого объекта найдите час, на который пришлось больше всего забронированных слотов (все бронирования, включая гостя); при равенстве выведите все такие часы. Выведите столбцы `facility` (название объекта), `hour`, `slots` (слоты этого часа) и `percent` — какой процент всех слотов объекта приходится на этот час, округлите до одного знака. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
