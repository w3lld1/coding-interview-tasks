# Активнее соседей по почтовому индексу

**Сложность:** средняя · **Язык:** SQL (SQLite) · **Темы:** [SQL: выборка и фильтры](../sql-filter/), [SQL: группировка](../sql-aggregate/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-979?utm_source=github&utm_medium=tasks-repo)**

Для каждого члена клуба (не гостя) посчитайте число его бронирований в августе 2012 года; у кого их не было, у того 0. Выведите столбцы `memid`, `zipcode` и `bookings` тех, у кого августовских бронирований строго больше, чем в среднем у членов клуба с тем же `zipcode`. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
