# В тройке лидеров сразу на трёх объектах

**Сложность:** сложная · **Язык:** SQL (SQLite) · **Темы:** [SQL: выборка и фильтры](../sql-filter/), [SQL: группировка](../sql-aggregate/), [SQL: JOIN](../sql-join/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-1004?utm_source=github&utm_medium=tasks-repo)**

Для каждого объекта посчитайте, сколько слотов забронировал на нём каждый член клуба (гость не учитывается). Место члена клуба на объекте — 1 плюс число членов клуба, у которых на этом объекте слотов строго больше; в тройку лидеров объекта входят места 1–3, так что при ничьих в ней может быть больше трёх человек. Выведите столбцы `memid`, `surname` и `facilities` — на скольких объектах член клуба в тройке лидеров — для тех, кто в тройке хотя бы на трёх объектах. Попробуйте решить задачу без оконных функций. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
