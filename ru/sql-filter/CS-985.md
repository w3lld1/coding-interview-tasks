# Брони после того, как рекомендатель перестал ходить

**Сложность:** средняя · **Язык:** SQL (SQLite) · **Темы:** [SQL: выборка и фильтры](../sql-filter/), [SQL: JOIN](../sql-join/), [SQL: группировка](../sql-aggregate/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-985?utm_source=github&utm_medium=tasks-repo)**

Выведите столбцы `bookid`, `memid` и `recommendedby` бронирований, которые начались строго позже самого последнего бронирования рекомендателя этого члена клуба (того, кто указан в его `recommendedby`). Члены клуба без рекомендателя и с рекомендателем без бронирований в ответ не попадают. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
