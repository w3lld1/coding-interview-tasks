# Нашли объект раньше рекомендателя

**Сложность:** сложная · **Язык:** SQL (SQLite) · **Темы:** [SQL: выборка и фильтры](../sql-filter/), [SQL: JOIN](../sql-join/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-994?utm_source=github&utm_medium=tasks-repo)**

Найдите первые бронирования членом клуба тех объектов, на которых его рекомендатель (тот, кто указан в `recommendedby`) к началу этого бронирования ещё ни разу не был, в том числе если не был там вообще. Члены клуба без рекомендателя не учитываются. Выведите столбцы `memid`, `facid` и `bookid` — первое бронирование этого объекта этим членом клуба. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
