# Тексты ошибок шагов установки

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Строки](../strings/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-571?utm_source=github&utm_medium=tasks-repo)**

Установщик выполняет несколько шагов. Шаг — асинхронная функция без аргументов (`await step()`), которая возвращает число или завершается ошибкой (исключением с текстовым сообщением). Шаги независимы: их можно выполнять по одному или все сразу, ответ от этого не зависит.

Верните сообщения об ошибках тех шагов, которые упали, в порядке списка шагов (не в порядке времени падения). Сообщение исключения: `str(e)` в Python, `e.message` в JS/TS. Если ошибок не было, верните `[]`. Шагов до 50.

Пример: шаги `1`, ошибка `"no disk"`, `2` → `["no disk"]`.
