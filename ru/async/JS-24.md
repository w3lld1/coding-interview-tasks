# Promisify и комбинаторы промисов

**Сложность:** сложная · **Язык:** JavaScript · **Темы:** [Асинхронность и потоки](../async/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-24?utm_source=github&utm_medium=tasks-repo)**

Реализуйте `promisify` для функции с последним аргументом `callback(error, data)`, возвращая новую функцию с результатом Promise. Без использования одноимённых встроенных комбинаторов реализуйте `all` с сохранением порядка и отказом при первой ошибке, `allSettled` с ожиданием всех результатов в исходном порядке, `race` по первому завершению и `any` по первому успеху. Это учебный контракт, а не точные полифилы ECMAScript: `allSettled` возвращает массив значений или объектов ошибок без обёрток status; `any` при полном отказе отклоняется массивом ошибок в порядке входного массива, а не AggregateError. Для `all`, `allSettled` и `race` пустой массив успешно даёт `[]`, отсутствие аргумента — `undefined`. `any([])` возвращает Promise, отклонённый с `[]`; `any()` возвращает Promise, успешно завершённый значением `undefined`.
