# Метки исходов заданий

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Строки](../strings/)

Дан список заданий `jobs`. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением).

Выполните все задания (по одному или все сразу: ответ от этого не зависит) и верните список строк в порядке списка `jobs`: `"ok:<значение>"` для успешного задания и `"err:<сообщение>"` для задания, которое завершилось ошибкой, где сообщение — текст ошибки (`e.message` в JS/TS, `str(e)` в Python). Пример значения: `"ok:-2"`. Ошибка одного задания не должна мешать остальным. Для пустого списка верните `[]`.

Пример: задания возвращают `7`, ошибку с текстом `boom` → `["ok:7", "err:boom"]`.
