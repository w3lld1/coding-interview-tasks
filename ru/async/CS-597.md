# Собирать ответы, пока не наступит тишина

**Сложность:** средняя · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-597?utm_source=github&utm_medium=tasks-repo)**

Даны список заданий `jobs` и число `quiet ≥ 0` (миллисекунды). Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением). Запустите все задания сразу.

Собирайте значения успешных заданий в порядке завершения (при равных моментах — по возрастанию индекса), начиная с первого успешного. Сбор прекращается, как только после очередного успешного ответа проходит больше `quiet` мс без нового успешного ответа: то есть следующий успешный ответ принимается, только если пришёл не позже чем через `quiet` мс после предыдущего принятого. Ошибки ответами не считаются и сбор не продлевают. Если успешных заданий нет, верните `[]`. Для пустого списка тоже `[]`. До 50 заданий.

Пример: задания возвращают `1` (10 мс), `2` (20 мс) и `3` (60 мс), `quiet = 15` → `[1, 2]` (от 20 до 60 мс тишина длится 40 мс > 15).
