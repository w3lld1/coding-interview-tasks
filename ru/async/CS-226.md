# Пул заданий с остановкой при первой ошибке

**Сложность:** средняя · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-226?utm_source=github&utm_medium=tasks-repo)**

Дан список заданий `jobs` и предел `limit ≥ 1`. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить его; оно может завершиться ошибкой (исключением). Задания возвращают неотрицательные целые числа.

Выполняйте задания так, чтобы одновременно шло не больше `limit`: в начале запустите первые задания, а каждый раз, когда задание завершилось успешно, его место сразу занимает следующее по порядку списка. После первой ошибки новые задания не запускаются, но уже идущие доводятся до конца, и функция ждёт их все. Точное правило для одновременных событий: место, освободившееся в момент `t` после успеха, берёт следующее задание, только если ни одно задание не завершилось ошибкой строго раньше `t` (ошибка в тот же момент `t` запуску не мешает); место задания, завершившегося ошибкой, новых заданий не берёт.

Если ошибок не было, верните `["ok:<сумма значений>", "time:<время>"]`. Иначе верните `["error:<сообщение первой ошибки>", "done:<сколько заданий завершилось успешно>", "time:<время>"]`; первая ошибка — самая ранняя по времени, при равном времени — у задания с меньшим индексом. Время — миллисекунды от вызова до окончания последнего запущенного задания. Для пустого списка верните `["ok:0", "time:0"]`. Сообщение ошибки — `error.message` в JS/TS, `str(error)` в Python. Заданий до 50. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python.

Пример: задания длятся 50, 10, 5 и 5 мс, второе завершается ошибкой `"bad"`, `limit = 2` → `["error:bad", "done:1", "time:50"]`.
