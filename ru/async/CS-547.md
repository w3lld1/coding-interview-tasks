# Значения до первой ошибки

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-547?utm_source=github&utm_medium=tasks-repo)**

Дан список заданий `jobs`. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением).

Выполняйте задания по одному, в порядке списка. Как только задание завершилось ошибкой, остановитесь: следующие задания не запускайте. Верните список значений заданий, успешно выполненных до этой ошибки, в порядке списка. Если ошибок нет, это значения всех заданий; для пустого списка верните `[0]`. Заданий до 50.

Последним элементом ответа добавьте время в миллисекундах от вызова функции до момента, когда она закончила. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python.

Пример: каждое задание длится 5 мс, первое возвращает `1`, второе завершается ошибкой, третье возвращает `3` → `[1, 10]` (третье не запускается).
