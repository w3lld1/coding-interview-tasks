# Прогресс загрузки по файлам

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-585?utm_source=github&utm_medium=tasks-repo)**

Облачный клиент загружает файлы по одному и показывает, сколько байт отправлено всего. Загрузка файла — асинхронная функция без аргументов (`await upload()`), которая возвращает число отправленных байт (целое неотрицательное) или завершается ошибкой (исключением); упавшая загрузка не отправила ни одного байта.

Выполняйте загрузки строго по одной, в порядке списка, не прерываясь на ошибках. Верните список той же длины: i-й элемент равен общему числу байт, отправленных после i-й загрузки. Для пустого списка верните `[0]`. Загрузок до 50.

Последним элементом ответа добавьте время в миллисекундах от вызова функции до момента, когда она закончила. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python.

Пример: загрузки длятся 10, 5 и 5 мс, первая возвращает `5`, вторая завершается ошибкой, третья возвращает `3` → `[5, 5, 8, 20]`.
