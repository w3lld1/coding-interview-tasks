# Серия пингов одного сервера

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-588?utm_source=github&utm_medium=tasks-repo)**

Чтобы оценить стабильность канала, один и тот же сервер пингуют несколько раз подряд. Пинг — асинхронная функция без аргументов (`await job()`), которая возвращает число или завершается ошибкой (исключением); каждый новый вызов — новый пинг, и его результат может отличаться от предыдущего.

Вызовите `job` ровно `count` раз, строго по одному. Между пингами делайте паузу `pause` миллисекунд (после последнего пинга паузы нет). Ошибка пинга не прерывает серию. Верните список из двух чисел: сколько пингов завершились успешно и сколько миллисекунд прошло от вызова до возврата. Время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python. `0 ≤ count ≤ 50`.

Пример: каждый пинг длится 10 мс и успешен, `count = 3`, `pause = 100` → `[3, 230]`.
