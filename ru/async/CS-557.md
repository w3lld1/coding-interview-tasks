# Наименьший из полученных результатов

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-557?utm_source=github&utm_medium=tasks-repo)**

Дан список заданий `jobs`. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением).

Запустите все задания сразу, дождитесь каждого и верните наименьшее значение среди заданий, которые завершились успешно. Задания с ошибкой не учитываются. Если успешных заданий нет (в том числе список пуст), результат `-1`. Значения могут быть отрицательными. Заданий до 50.

Ответ — список из двух чисел: этот результат и время в миллисекундах от вызова функции до момента, когда она закончила. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python.

Пример: задания длятся 10, 20 и 30 мс, первое возвращает `3`, второе завершается ошибкой, третье возвращает `8` → `[3, 30]`.
