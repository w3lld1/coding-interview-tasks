# Какой работник взял задание

**Сложность:** средняя · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-590?utm_source=github&utm_medium=tasks-repo)**

Дан список заданий `jobs` и число работников `workers` (не меньше 1). Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением). Работники пронумерованы с `0`; каждый выполняет за раз одно задание, от старта до завершения (успешного или с ошибкой).

Задания берутся строго по порядку индексов. Задание получает свободного работника с наименьшим номером; если все заняты, оно ждёт и стартует в момент, когда освободился первый работник. Все задания в итоге выполняются, ошибка задания только освобождает работника. Каждое задание длится не меньше 1 мс, и в тестах никакие два работника не освобождаются в один и тот же момент, пока есть ждущие задания (кроме момента 0, когда свободны все).

Верните список из `len(jobs)` чисел: номер работника для каждого задания. Для пустого списка верните `[]`. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python. До 50 заданий.

Пример: задания длятся 10, 20 и 30 мс, `workers = 2` → `[0, 1, 0]` (третье берёт работника `0`, освободившегося в 10 мс).
