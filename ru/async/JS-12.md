# Асинхронный сервис переводов

**Сложность:** сложная · **Язык:** JavaScript · **Темы:** [Асинхронность и потоки](../async/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-12?utm_source=github&utm_medium=tasks-repo)**

Дан локальный учебный `api`: `fetch(text)` возвращает Promise объекта `{translation, quality}` либо отклоняется с ошибкой, а `request(text, callback)` добавляет перевод в хранилище; вызов callback без ошибки означает успех. Реализуйте класс `TranslationService` с конструктором `new TranslationService(api)`. Метод `free(text)` возвращает Promise строки перевода без проверки качества и передаёт ошибки API; `batch(texts)` возвращает Promise всех строк в исходном порядке, отклоняется при первой ошибке, а для пустого списка — с `BatchIsEmpty`. Метод `request(text)` оборачивает callback-API в Promise: не более трёх попыток всего, `resolve(undefined)` при первом успехе; при неудаче всех попыток — `reject` с последней ошибкой (не успешное возвращение объекта Error). Метод `premium(text, minimumQuality)` возвращает Promise строки: сначала выполняет fetch; только при `NotAvailable` создаёт перевод через request и повторяет fetch; качество ниже `minimumQuality` означает `reject` с `QualityThresholdNotMet`, остальные ошибки передаются вызывающему коду. Равенство порогу допустимо.
