# Дерево заданий с комбинаторами all, any и seq

**Сложность:** сложная · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-672?utm_source=github&utm_medium=tasks-repo)**

Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить его; оно может завершиться ошибкой (исключением).

Дерево заданий состоит из узлов `0…n−1`: узел 0 — корень, `parent[v]` (меньше `v`) — родитель узла `v` (`-1` у корня), дети узла идут по возрастанию индекса. `kinds[v]` — это `"job"` (лист: k-й по порядку индексов узел-задание один раз выполняет `jobs[k]`) или группа хотя бы с одним ребёнком:
- `"all"` запускает всех детей сразу; она успешна, когда успешны все, с суммой их значений, и завершается ошибкой, как только ошибся один из детей, с его сообщением;
- `"any"` запускает всех детей сразу; она успешна, как только успешен один из детей, с его значением, и завершается ошибкой, когда ошиблись все, с сообщением последней ошибки;
- `"seq"` запускает детей по одному, каждого в момент успеха предыдущего; она успешна с суммой их значений и завершается ошибкой, как только ошибся ребёнок, с его сообщением (следующие дети не запускаются).

Когда группа `"all"` или `"any"` завершилась, её ещё работающие дети отменяются вместе со всеми поддеревьями: в них больше ничего не запускается и не завершается (в JS/TS отменённое задание продолжает работать — игнорируйте его результат).

Запустите корень в момент 0. Верните список: сначала `"ok:<значение>@<момент>"` или `"err:<сообщение>@<момент>"` для корня (момент его завершения в мс), затем метку каждого задания по порядку: `"ok:<значение>"` или `"err:<сообщение>"`, если оно завершилось, `"cancelled"`, если оно запустилось и было отменено, `"skipped"`, если не запускалось. Каждое задание длится не меньше 1 мс; в тестах никакие два запущенных задания не завершаются (и не завершились бы) в один момент. До 30 узлов. Текущее время в мс: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python.

Пример: `parent = [-1, 0, 0, 0]`, `kinds = ["all", "job", "job", "job"]`, задания (10 мс → `1`), (30 мс → `2`), (20 мс → ошибка `"disk"`) → `["err:disk@20", "ok:1", "cancelled", "err:disk"]`.
