# Моменты завершения по очереди

**Сложность:** лёгкая · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Массивы и списки](../arrays/)

Дан список заданий `jobs`. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением).

Выполняйте задания по одному, в порядке списка. Верните список в порядке `jobs`: для каждого задания — время в миллисекундах от вызова функции до момента, когда оно завершилось. Все задания в тестах завершаются успешно. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python. Для пустого списка верните `[]`.

Пример: задания длятся 10, 20 и 30 мс → `[10, 30, 60]`.
