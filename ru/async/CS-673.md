# Подстраивающийся предел параллельности с повторами

**Сложность:** сложная · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-673?utm_source=github&utm_medium=tasks-repo)**

Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить его; оно может завершиться ошибкой (исключением). Каждый вызов — это попытка.

Выполните задания `jobs` в пуле с подстраивающимся пределом, как в TCP: предел сначала равен 1. Очередь сначала содержит все индексы заданий по возрастанию. Всякий раз, когда попыток работает меньше предела и очередь не пуста, запускайте попытку задания из головы очереди (убирая его оттуда). Когда попытка заканчивается в момент `t`:
- успех: ответ задания — её значение, а предел становится `min(max_limit, limit + 1)`;
- ошибка: предел становится `max(1, limit // 2)` (целочисленное деление); если у задания было меньше `attempts` попыток, оно ждёт `delay · 2^(k−1)` мс, где `k` — число его попыток к этому моменту, и затем встаёт в конец очереди; иначе его ответ `-1`.

Уменьшение предела не останавливает работающие попытки. В пределах одного момента сначала обработайте все попытки, которые в нём закончились, по возрастанию индекса задания; затем задания, у которых закончилось ожидание, встают в очередь по возрастанию индекса; затем запускайте попытки, пока позволяет предел.

Верните список из `n + 1` чисел: ответы заданий по порядку индексов, затем момент (в мс от вызова), когда закончилась последняя попытка (`0`, если попыток не было). Каждая попытка длится не меньше 1 мс; `max_limit`, `attempts` и `delay` не меньше 1; до 30 заданий. Текущее время в мс: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python.

Пример: четыре задания по 10 мс со значениями `1, 2, 3, 4`, второе ошибается в первой попытке; `max_limit = 3`, `attempts = 2`, `delay = 5` → `[1, 2, 3, 4, 35]` (в 20 мс ошибка задания 1 делит предел пополам, до 1, а успех задания 2 поднимает его до 2; задание 1 снова встаёт в очередь в 25 мс).
