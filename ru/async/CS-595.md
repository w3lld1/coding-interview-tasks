# Чтение по кворуму

**Сложность:** средняя · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Словари и множества](../hashing/)

Даны список заданий `jobs` (реплики, у каждой свой ответ), число `need ≥ 1` и срок `timeout` в миллисекундах. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением). Запустите все задания сразу в момент вызова вашей функции. Ответом реплики служит значение задания; ошибка — голос не подан.

Учитываются только ответы, пришедшие не позже `timeout` мс. Ответы обрабатываются по моменту прихода, а при равных моментах по возрастанию индекса реплики. Победитель — значение, которое первым набрало `need` одинаковых ответов. Верните список `[значение, момент]`, где момент — время в миллисекундах от вызова функции, когда набралось нужное число. Если ни одно значение не набрало `need` ответов, верните `[-1, -1]`. Значения неотрицательны. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python. До 50 заданий.

Пример: задания возвращают `5` (10 мс), `7` (20 мс), `5` (30 мс), `7` (15 мс), `need = 2`, `timeout = 100` → `[7, 20]` (семёрка набрала два голоса в 20 мс, пятёрка — только в 30 мс).
