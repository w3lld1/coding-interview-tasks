# Очередь «дырявое ведро»

**Сложность:** средняя · **Языки:** Python, JavaScript, TypeScript · **Темы:** [Асинхронность и потоки](../async/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-601?utm_source=github&utm_medium=tasks-repo)**

Даны список заданий `jobs`, моменты `arrivals` (мс от вызова вашей функции, не убывают), вместимость очереди `capacity ≥ 1` и интервал `interval ≥ 1`. Задание — асинхронная функция без аргументов: вызовите её (`await job()`), чтобы выполнить; она может завершиться ошибкой (исключением). Запрос `i` приходит в момент `arrivals[i]` и просит запустить задание `i`.

Сервер запускает не больше одного задания за `interval` мс. Запрос запускается сразу при приходе, если очередь пуста и с последнего запуска прошло не меньше `interval` мс (или запусков ещё не было). Иначе он встаёт в очередь, если в ней сейчас меньше `capacity` ожидающих, а при полной очереди отбрасывается: его задание никогда не вызывается. Из очереди запросы запускаются по одному, в порядке прихода, как только с последнего запуска прошло `interval` мс. Если запуск из очереди и приход запроса приходятся на один момент, сначала запускается запрос из очереди. Запущенные задания работают одновременно, без ограничения числа.

Верните значения успешно завершившихся запущенных заданий в порядке завершения; при равных моментах по возрастанию индекса. Для пустого списка верните `[]`. Текущее время в миллисекундах: `Date.now()` в JS/TS, `round(asyncio.get_running_loop().time() * 1000)` в Python. До 50 заданий.

Пример: четыре задания по 5 мс возвращают `1`, `2`, `3`, `4`, все приходят в 0 мс, `capacity = 2`, `interval = 10` → `[1, 2, 3]` (запросы стартуют в 0, 10 и 20 мс, четвёртый не поместился в очередь).
