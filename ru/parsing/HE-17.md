# Длительности нот

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-17?utm_source=github&utm_medium=tasks-repo)**

Строка описывает ноты в текстовом формате, ноты разделены одним пробелом. Обозначения: `o` — целая нота (4 удара), `o|` — половинная (2 удара), `.|` — четвертная (1 удар). Верните список длительностей нот в ударах в том же порядке. Для пустой строки верните пустой список.

Пример: `"o o| .| o"` → `[4, 2, 1, 4]`.
