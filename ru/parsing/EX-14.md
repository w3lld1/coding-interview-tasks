# Мини-парсер Markdown

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-14?utm_source=github&utm_medium=tasks-repo)**

Преобразуйте текст в упрощённом Markdown в HTML. Строки разделены символом `\n`, каждая строка — отдельный блок, пустых строк во входе нет.

- Строка из 1–6 символов `#`, пробела и текста — заголовок: `# Текст` → `<h1>Текст</h1>`, … `###### Текст` → `<h6>Текст</h6>`. Семь и более `#` или отсутствие пробела после них — обычный абзац.
- Строка, начинающаяся с `* `, — элемент списка `<li>…</li>`; подряд идущие элементы объединяются в один `<ul>…</ul>`, а список заканчивается на первой строке, не являющейся элементом.
- Любая другая строка — абзац `<p>…</p>`.

Внутри текста заголовков, элементов списка и абзацев пара `__текст__` превращается в `<strong>текст</strong>`, затем оставшаяся пара `_текст_` — в `<em>текст</em>`. Остальные символы, включая одиночные `#` и `*`, остаются как есть. Блоки склеиваются без разделителей.

Пример: `"# Header!\n* __Bold Item__\n* _Italic Item_"` → `"<h1>Header!</h1><ul><li><strong>Bold Item</strong></li><li><em>Italic Item</em></li></ul>"`.
