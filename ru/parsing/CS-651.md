# Выбор столбцов из CSV с кавычками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Исключения](../errors/), [Строки](../strings/)

Дан текст `text` в формате CSV, символ-разделитель `delimiter` (один символ, не кавычка и не перевод строки) и список имён `columns`. Первая строка — заголовок с именами столбцов. Верните строки данных (без заголовка) по порядку, в каждой — значения столбцов из `columns` в порядке этого списка (имя может повторяться).

Правила разбора:
- строки разделяются символом `\n`; один `\n` в самом конце текста завершает последнюю строку и новую не начинает; пустая строка в середине — это строка из одного пустого поля;
- поля строки разделяются `delimiter`;
- поле без кавычек — любые символы, кроме разделителя, `\n` и `"`; пробелы входят в значение;
- поле в кавычках начинается с `"` первым символом поля и заканчивается одиночной `"`; внутри допустимы разделитель и `\n`, а пара `""` означает одну кавычку; сразу после закрывающей кавычки должен идти разделитель, `\n` или конец текста.

Сообщите об ошибке: бросьте исключение, в Go верните error, если текст пустой, кавычка встретилась внутри поля без кавычек, после закрывающей кавычки идёт другой символ, кавычка не закрыта, в какой-то строке не столько полей, сколько в заголовке, имя в заголовке пустое или повторяется, либо в `columns` есть имя не из заголовка.

Пример: `"id,item\n1,\"Tea, green\"\n"`, `","`, `["item"]` → `[["Tea, green"]]`.
