# Запись десятичного числа с разделителями

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-194?utm_source=github&utm_medium=tasks-repo)**

Проверьте, что строка — правильная запись десятичного числа. Правильная запись состоит из трёх частей подряд, без пробелов:

1. необязательный знак `+` или `-`;
2. мантисса в одном из видов: «цифры», «цифры`.`», «цифры`.`цифры» или «`.`цифры»;
3. необязательная экспонента: буква `e` или `E`, затем необязательный знак `+` или `-`, затем цифры (без точки).

Здесь «цифры» — непустая последовательность символов `0`–`9`, в которой для удобства чтения можно ставить одиночные подчёркивания `_`, но только между двумя цифрами (`1_000` — можно, `1__0`, `_1`, `1_` — нельзя). Ведущие нули разрешены. Любой другой символ делает запись неправильной. Верните `true` или `false`; пустая строка даёт `false`.

Строка до 50 символов.

Пример: `"1_000.25e-3"` → `true`; `"1__000"` → `false`.
