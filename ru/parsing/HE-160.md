# Вычисление выражения из двух списков

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-160?utm_source=github&utm_medium=tasks-repo)**

Даны список операторов и список неотрицательных целых операндов, причём операторов на один меньше, чем операндов, и есть хотя бы один оператор. Операторы бывают `"+"`, `"-"`, `"*"`, `"//"` (целочисленное деление) и `"**"` (возведение в степень). Составьте выражение, подставляя операторы между операндами по порядку, и верните его значение с обычным приоритетом: сначала `**` (цепочка степеней вычисляется справа налево), затем `*` и `//` слева направо, затем `+` и `-` слева направо. Делитель при `//` всегда больше нуля.

Пример: `["+", "*", "-"]`, `[2, 3, 4, 5]` → `9` (выражение `2 + 3 * 4 - 5`).
