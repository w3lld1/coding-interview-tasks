# Калькулятор без скобок

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-20?utm_source=github&utm_medium=tasks-repo)**

Дана строка с арифметическим выражением из неотрицательных целых чисел, операторов `+`, `-`, `*`, `/` и пробелов (пробелы могут стоять где угодно между токенами и по краям). Скобок и унарного минуса нет. Вычислите значение по обычным правилам: `*` и `/` выполняются раньше `+` и `-`, операции одного приоритета слева направо. Деление `/` целочисленное, с округлением к нулю. Выражение корректно, деления на ноль нет, все промежуточные значения помещаются в 32-битное целое.

Пример: `" 3+5 / 2 "` → `5`.
