# Вес скобочной строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Стек, очередь, связные списки](../stacks-lists/)

Дана правильная скобочная строка `s` из символов `(` и `)` длиной до 60. Её вес определяется так: пара `()` весит `1`; если `A` и `B` правильные строки, то вес `AB` равен весу `A` плюс весу `B`; вес `(A)` равен удвоенному весу `A`. Верните вес `s`. Для пустой строки ответ `0`.

Пример: `"(()(()))"` → `6`; `"()()"` → `2`.
