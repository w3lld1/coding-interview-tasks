# Подбор версий по диапазону semver

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Разбор и проверка данных](../parsing/), [Исключения](../errors/), [Поиск и сортировка](../search-sort/)

Дан список версий `versions` и диапазон `spec` в упрощённой записи semver. Верните версии, которые подходят под диапазон, по возрастанию.

Версия — `MAJOR.MINOR.PATCH`, три неотрицательных целых без ведущих нулей; версии сравниваются как тройки чисел; все версии списка различны. Неполная версия — 1–3 части через точку, каждая часть — число без ведущих нулей или подстановка `x`, `X`, `*`; после подстановки могут идти только подстановки (`1.x.x` можно, `1.x.3` нельзя). Пусть `p` — числа неполной версии до первой подстановки, `k` — их количество (0–3), `pad(p)` — `p`, дополненная нулями до трёх чисел, `next(p, i)` — `p` с числом `i` (с нуля), увеличенным на 1, и нулями после него.

Сравнение — оператор вплотную к неполной версии (`p`, `k` как выше). Для `k = 0`: `>` и `<` не подходят ни для чего, остальные — для всего. Иначе (`k = 3` для полной):
- без оператора или `=`: при `k = 3` равна `p`, иначе `>= pad(p)` и `< next(p, k − 1)`;
- `>`: при `k = 3` больше `p`, иначе `>= next(p, k − 1)`; `>=`: `>= pad(p)`; `<`: `< pad(p)`;
- `<=`: при `k = 3` не больше `p`, иначе `< next(p, k − 1)`;
- `~`: `>= pad(p)` и `< next(p, min(k − 1, 1))`;
- `^`: `>= pad(p)` и `< next(p, i)`, где `i` — номер первого ненулевого числа в `p`, а если его нет — `k − 1`.

Диапазон — части через `||` (пробелы вокруг допустимы), версия подходит, если подходит хотя бы под одну часть. Часть — сравнения через один или несколько пробелов (нужны все) или ровно `A - B` из двух неполных версий без операторов: нижняя граница `>= pad(A)` (нет, если у `A` `k = 0`), верхняя — `<= B` для полной `B`, `< next(B, k − 1)` для неполной и нет при `k = 0`.

Сообщите об ошибке: бросьте исключение, в Go верните error, если версия в списке или запись диапазона неверна (пустая часть, неизвестный оператор, пробел после оператора, лишние части версии, ведущие нули, число после подстановки).

Пример: `["1.2.3", "1.3.0", "2.0.0"]`, `"^1.2.3"` → `["1.2.3", "1.3.0"]`.
