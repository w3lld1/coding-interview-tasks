# Самые частые слова

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

Дан список слов из строчных латинских букв и число `k ≥ 0`. Верните `k` самых частых слов (каждое различное слово один раз). Порядок результата: сначала слова с большим числом вхождений; слова с одинаковым числом вхождений идут в алфавитном порядке. Если различных слов меньше `k`, верните все различные слова в том же порядке. Для пустого списка или `k = 0` ответ — пустой список.

Пример: `["i", "love", "code", "i", "love", "tests"]`, `2` → `["i", "love"]`.
