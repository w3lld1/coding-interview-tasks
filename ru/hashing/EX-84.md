# Код цвета резистора

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-84?utm_source=github&utm_medium=tasks-repo)**

Полосы на резисторе кодируют цифры. Цвета по порядку: `black` — 0, `brown` — 1, `red` — 2, `orange` — 3, `yellow` — 4, `green` — 5, `blue` — 6, `violet` — 7, `grey` — 8, `white` — 9. Дано название цвета строчными буквами; верните соответствующую цифру.

Пример: `"brown"` → `1`, `"white"` → `9`.
