# Общий день рождения

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Даты и время](../dates/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-39?utm_source=github&utm_medium=tasks-repo)**

Дан список дат рождения в формате `"ГГГГ-ММ-ДД"`. Верните `true`, если у каких-то двух людей день рождения совпадает, то есть совпадают месяц и день (год может быть любым), и `false` иначе. Одинаковые полные даты тоже считаются совпадением. Для пустого списка и списка из одной даты результат `false`. Високосные годы не учитываются: `02-29` просто ещё один день.

Пример: `["1966-07-29", "1977-02-12", "2001-07-29"]` → `true`.
