# Смена формата очков букв

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-51?utm_source=github&utm_medium=tasks-repo)**

В старом формате буквы хранятся группами по очкам: ключ — число очков (строкой), значение — список букв с этими очками (обычно прописных, но регистр может быть любым). Преобразуйте его в новый формат: словарь, где ключ — строчная буква, а значение — её очки (число). Каждая буква встречается в старом формате только в одной группе. Пустой вход даёт пустой словарь.

Пример: `{"1": ["A", "E"], "2": ["D"]}` → `{"a": 1, "e": 1, "d": 2}`.
