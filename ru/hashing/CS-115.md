# Карты в группы подряд

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Массивы и списки](../arrays/)

Дан список целых чисел `cards` (до 2000 элементов, числа могут повторяться и быть отрицательными) и число `k >= 1`. Верните `true`, если все числа можно разложить по группам так, чтобы в каждой группе было ровно `k` чисел и они образовывали `k` последовательных значений (`x, x + 1, …, x + k - 1`), иначе `false`. Каждое число используется ровно в одной группе. Для пустого списка ответ `true`.

Пример: `[1, 2, 3, 3, 4, 4, 5, 6]`, `4` → `true` (`1 2 3 4` и `3 4 5 6`).
