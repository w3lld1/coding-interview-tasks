# Единый регистр ключей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-95?utm_source=github&utm_medium=tasks-repo)**

Дан словарь со строковыми ключами. Верните `true`, если все ключи записаны строчными буквами или все ключи записаны заглавными. Ключ считается строчным, если в нём есть хотя бы одна латинская буква и нет заглавных; заглавным — если есть хотя бы одна буква и нет строчных. Ключ без букв (например, `"8"`) не подходит ни под одно условие. Для пустого словаря верните `false`.

Пример: `{"a": "apple", "b": "banana"}` → `true`. Пример: `{"a": "apple", "A": "banana"}` → `false`.
