# Совершенные подотрезки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-45?utm_source=github&utm_medium=tasks-repo)**

Дан массив целых чисел (по модулю не больше 100). Подотрезок — непустая непрерывная часть массива; он совершенный, если сумма его элементов — точный квадрат неотрицательного целого (0, 1, 4, 9, 16, …). Подотрезки с разными границами считаются разными, даже если значения в них совпадают.

Верните количество совершенных подотрезков. Длина массива может достигать 10^5, поэтому перебирать все подотрезки нельзя.

Пример: `[4, 0, 0, 16]` → `9`.
