# Группировка анаграмм

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-39?utm_source=github&utm_medium=tasks-repo)**

Дан список слов из строчных латинских букв (до 1000 слов, слово может быть пустым). Две строки — анаграммы, если одну можно получить перестановкой букв другой. Разбейте слова на группы анаграмм и верните список групп. Повторяющиеся слова сохраняются столько раз, сколько встретились. Порядок фиксирован: слова внутри группы идут по алфавиту, а сами группы — по алфавиту их первых слов. Для пустого списка ответ — пустой список.

Пример: `["eat", "tea", "tan", "ate", "nat", "bat"]` → `[["ate", "eat", "tea"], ["bat"], ["nat", "tan"]]`.
