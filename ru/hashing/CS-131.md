# Палиндром из двухбуквенных слов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-131?utm_source=github&utm_medium=tasks-repo)**

Дан список слов, каждое из которых состоит ровно из двух строчных латинских букв. Из слов можно составить строку, выбрав часть из них (каждое слово не более одного раза, слова из списка с одинаковым текстом считаются разными экземплярами) и записав их подряд в любом порядке. Верните наибольшую длину такой строки, которая читается одинаково слева направо и справа налево. Если составить нельзя, верните `0`. Слов до 1000.

Пример: `["lc", "cl", "gg"]` → `6` (строка `lcggcl`).
