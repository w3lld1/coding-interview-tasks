# Плейлист без повторов на Set

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Словари и множества](../hashing/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-14?utm_source=github&utm_medium=tasks-repo)**

Плейлист — массив строк вида `'песня - исполнитель'`. Реализуйте функции с помощью `Set`:

- `removeDuplicates(playlist)` — массив без повторов в порядке первых появлений;
- `hasTrack(playlist, track)` — `true`, если трек есть, иначе `false`;
- `addTrack(playlist, track)` — массив с добавленным треком, если его ещё не было;
- `deleteTrack(playlist, track)` — массив без этого трека (если трека нет, плейлист не меняется);
- `listArtists(playlist)` — массив уникальных исполнителей (часть строки после `' - '`) в порядке первых появлений.

Функции, которые возвращают плейлист, возвращают массив, а не `Set`. Тесты включают большой плейлист.
