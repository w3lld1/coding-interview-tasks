# Турнирная таблица

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-29?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `tally(rows)`. Она получает список строк вида `команда1;команда2;исход`, где исход `win`, `loss` или `draw` указан для первой команды, и возвращает турнирную таблицу — список строк (или одну строку с `\n` между ними).

За победу дайте 3 очка, за ничью 1, за поражение 0. Первая строка — заголовок с колонками `Team`, `MP` (матчи), `W` (победы), `D` (ничьи), `L` (поражения), `P` (очки). Имя команды выровняйте влево в поле шириной 30 символов, числа — вправо в поле шириной 2; поля разделяйте строкой `" | "`:

```
Team                           | MP |  W |  D |  L |  P
Allegoric Alaskans             |  1 |  1 |  0 |  0 |  3
```

Команды сортируйте по убыванию очков, при равенстве — по имени. Для пустого списка матчей верните только заголовок.
