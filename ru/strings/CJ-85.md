# Удвоение и побитовое НЕ

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-85?utm_source=github&utm_medium=tasks-repo)**

Даны два неотрицательных числа в двоичной записи: `start` и `end` (без ведущих нулей; ноль записан как `"0"`; длина до 100). За одну операцию можно:

- **удвоить** число — приписать справа `0` (ноль остаётся нулём);
- взять **побитовое НЕ** — инвертировать все цифры записи без ведущих нулей и отбросить появившиеся ведущие нули. Например, `0 → 1`, `1 → 0`, `11 → 0`, `1110 → 1`, `1010 → 101`, `101 → 10`.

Верните наименьшее число операций, переводящих `start` в `end`, или `-1`, если это невозможно. Если `start` равно `end`, ответ `0`.

Пример: `"10001"`, `"111"` → `4` (НЕ: `1110`, удвоить: `11100`, удвоить: `111000`, НЕ: `111`).
