# Циклические замены пар цифр

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-109?utm_source=github&utm_medium=tasks-repo)**

Дана строка `digits` из цифр `0`–`9`. Один проход состоит из десяти операций, выполняемых строго по порядку: заменить каждое вхождение `01` на `2`, затем каждое вхождение `12` на `3`, затем `23` на `4`, … , `89` на `0` и, наконец, `90` на `1`. Каждая операция работает со строкой, получившейся после предыдущей. Проходы повторяются, пока очередной проход ничего не меняет. Верните получившуюся строку.

Вхождения одной пары не перекрываются, а замена пары никогда не создаёт новое вхождение той же пары, поэтому каждая операция определена однозначно. Порядок операций важен: из `012` получается `22`, а не `03`.

Ограничения: `1 ≤ длина digits ≤ 20000`; простое повторение замен по всей строке может оказаться слишком медленным.

Пример: `"0145"` → `"26"` (`01` → `2` даёт `245`, затем `45` → `6`).
