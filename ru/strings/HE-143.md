# Слова простой длины

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-143?utm_source=github&utm_medium=tasks-repo)**

Дано предложение: непустая строка из слов, разделённых одним пробелом; в словах только буквы. Верните строку из тех слов, длина которых — простое число, в исходном порядке и через один пробел. Если подходящих слов нет, верните пустую строку. Помните, что 1 не простое число.

Пример: `"lets go for swimming"` → `"go for"`.
