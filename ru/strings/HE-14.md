# Все префиксы строки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-14?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните список всех её непустых префиксов от самого короткого к самому длинному. Для пустой строки верните пустой список.

Пример: `"abc"` → `["a", "ab", "abc"]`.
