# Пословица о гвозде

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-80?utm_source=github&utm_medium=tasks-repo)**

Дан список слов. Составьте по нему стихотворную пословицу и верните её строки списком. Для каждой соседней пары слов `a`, `b` (в порядке списка) добавьте строку `For want of a <a> the <b> was lost.`, где `<a>` и `<b>` — эти слова. Если в списке есть хотя бы одно слово, последней строкой добавьте `And all for the want of a <X>.`, где `<X>` — первое слово списка. Для пустого списка верните пустой список, для списка из одного слова — только последнюю строку.

Пример: `["nail", "shoe", "horse"]` → `["For want of a nail the shoe was lost.", "For want of a shoe the horse was lost.", "And all for the want of a nail."]`.
