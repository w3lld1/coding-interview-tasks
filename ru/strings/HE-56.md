# Баланс угловых скобок

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-56?utm_source=github&utm_medium=tasks-repo)**

Дана строка из символов `<` и `>`. Верните `true`, если у каждой открывающей скобки `<` есть своя закрывающая `>`, стоящая правее, и наоборот, иначе `false`. Пустая строка корректна.

Пример: `"<<><>>"` → `true`, а `"><<>"` → `false`.
