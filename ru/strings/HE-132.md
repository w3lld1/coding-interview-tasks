# Вложенные скобки в подпоследовательности

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-132?utm_source=github&utm_medium=tasks-repo)**

Дана строка, состоящая только из символов `[` и `]`. Верните `true`, если из неё можно, удалив часть символов (оставшиеся не переставляются), получить строку, в которой есть вложенная пара скобок, то есть строку `[[]]`. Иначе верните `false`. Скобки в самой строке могут быть расставлены неправильно, это не мешает. Пустая строка даёт `false`.

Пример: `"[[]][["` → `true` (подпоследовательность `[[]]`), `"[][]"` → `false`.
