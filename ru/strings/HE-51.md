# Удаление гласных

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-51?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните её копию, из которой удалены все гласные английского алфавита `a`, `e`, `i`, `o`, `u` в любом регистре. Остальные символы, включая перевод строки, пробелы и знаки препинания, остаются на своих местах. Буква `y` гласной не считается. Для пустой строки результат пустой.

Пример: `"Hello, World!"` → `"Hll, Wrld!"`.
