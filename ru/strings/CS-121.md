# Наименьшая подпоследовательность без повторов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-121?utm_source=github&utm_medium=tasks-repo)**

Дана строка `s` из строчных латинских букв (до 1000 символов). Удалите часть букв так, чтобы каждая буква, встречавшаяся в `s`, осталась ровно один раз, а порядок оставшихся букв не изменился. Верните лексикографически наименьшую из всех возможных результирующих строк. Для пустой строки ответ `""`.

Пример: `"cbacdcbc"` → `"acdb"`; `"bcabc"` → `"abc"`.
