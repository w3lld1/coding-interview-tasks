# Детский сад: чьи растения

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-63?utm_source=github&utm_medium=tasks-repo)**

В классе 12 детей, по алфавиту: Alice, Bob, Charlie, David, Eve, Fred, Ginny, Harriet, Ileana, Joseph, Kincaid, Larry. Грядка — две строки, разделённые символом `\n`; каждый символ — растение: `G` — `"grass"`, `C` — `"clover"`, `R` — `"radishes"`, `V` — `"violets"`. Каждому ребёнку принадлежат по два соседних стакана в каждой строке: Alice — первые два столбца, Bob — следующие два, и так далее по алфавиту. Верните четыре растения ребёнка: сначала два из первой строки слева направо, затем два из второй.

Пример: диаграмма `"RC\nGG"`, `"Alice"` → `["radishes", "clover", "grass", "grass"]`.
