# Чётные по длине слова по порядку

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-149?utm_source=github&utm_medium=tasks-repo)**

Дан список строк (возможны повторы). Удалите строки нечётной длины и верните оставшиеся, отсортированные по возрастанию длины. Строки одинаковой длины упорядочите по алфавиту, сравнивая коды символов (заглавные буквы идут раньше строчных). Повторы сохраняются. Если ничего не осталось, верните пустой список.

Пример: `["ab", "a", "aaa", "cd"]` → `["ab", "cd"]`.
