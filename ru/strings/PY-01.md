# Поиск анаграмм

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-01?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `find_anagrams(word, candidates)`. Она получает слово `word` и список слов `candidates` и возвращает список тех кандидатов, которые являются анаграммами слова: состоят из тех же букв с тем же числом повторений. Регистр при сравнении не учитывайте. Само исходное слово анаграммой не считается, даже если оно написано в другом регистре. Возвращайте кандидатов в их исходном написании.
