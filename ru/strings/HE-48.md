# Строка-палиндром

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-48?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните `true`, если она читается одинаково слева направо и справа налево, иначе `false`. Регистр букв различается: `"Aba"` не палиндром. Пустая строка и строка из одного символа — палиндромы.

Пример: `"xywyx"` → `true`.
