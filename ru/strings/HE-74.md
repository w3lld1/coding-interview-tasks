# Список с меньшим числом символов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-74?utm_source=github&utm_medium=tasks-repo)**

Даны два списка строк. Подсчитайте для каждого из них общее число символов во всех его строках и верните тот список, у которого это число меньше. Если числа равны, верните первый список.

Пример: `["hi", "admin"]`, `["hI", "Hi"]` → `["hI", "Hi"]`; `["hi", "admin"]`, `["hI", "hi", "hii"]` → `["hi", "admin"]` (7 и 7 символов, равенство).
