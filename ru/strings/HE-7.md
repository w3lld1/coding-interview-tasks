# Строки с подстрокой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-7?utm_source=github&utm_medium=tasks-repo)**

Даны список строк и подстрока. Верните список тех строк, которые содержат подстроку, сохранив их исходный порядок и повторы. Регистр учитывается. Пустая подстрока содержится в любой строке.

Пример: `["abc", "bacd", "cde", "array"]`, `"a"` → `["abc", "bacd", "array"]`.
