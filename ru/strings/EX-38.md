# Шифр Атбаш

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-38?utm_source=github&utm_medium=tasks-repo)**

Реализуйте шифр Атбаш для латинского алфавита: первая буква заменяется на последнюю, вторая на предпоследнюю и так далее (`a` ↔ `z`, `b` ↔ `y`, …). Даны режим `mode` (`"encode"` или `"decode"`) и текст `phrase`.

Регистр букв не важен, результат пишется строчными. Цифры сохраняются без изменений, все остальные символы (пробелы, знаки препинания) отбрасываются. При кодировании результат разбивается на группы по 5 символов через пробел (последняя группа может быть короче, лишнего пробела в конце нет). При декодировании результат идёт без пробелов.

Пример: `"encode"`, `"x123 yes"` → `"c123b vh"`; `"decode"`, `"gvhg"` → `"test"`.
