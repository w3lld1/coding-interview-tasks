# Уникальные частоты букв

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-166?utm_source=github&utm_medium=tasks-repo)**

Дана строка из строчных латинских букв. За одно действие можно удалить один символ. Верните наименьшее число удалений, после которых никакие две разные буквы, оставшиеся в строке, не встречаются одинаковое число раз. Буква, удалённая полностью, в расчёт не идёт (её частота 0 может повторяться). Для пустой строки ответ `0`.

Пример: `"aaabbbcc"` → `2` (частоты 3, 3, 2 → 3, 2, 1: удаляем одну `b` и одну `c`).
