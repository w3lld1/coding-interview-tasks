# Акроним из фразы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-35?utm_source=github&utm_medium=tasks-repo)**

Дана фраза из слов. Верните её акроним: первые буквы всех слов, записанные заглавными и подряд без разделителей. Словами считаются части фразы, разделённые пробелами и дефисами `-` (любое количество подряд). Остальные знаки препинания (запятые, апострофы, подчёркивания, восклицательные знаки) игнорируются: слово `_Not_` даёт `N`, слово `It's` даёт `I`. Слово без единой буквы ничего не добавляет. Для пустой фразы результат пустая строка.

Пример: `"Thank George It's Friday!"` → `"TGIF"`; `"Liquid-crystal display"` → `"LCD"`.
