# Перевод РНК в белок

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-79?utm_source=github&utm_medium=tasks-repo)**

Цепочка РНК делится на кодоны по три символа. Каждый кодон соответствует аминокислоте:

- `AUG` → `Methionine`
- `UUU`, `UUC` → `Phenylalanine`
- `UUA`, `UUG` → `Leucine`
- `UCU`, `UCC`, `UCA`, `UCG` → `Serine`
- `UAU`, `UAC` → `Tyrosine`
- `UGU`, `UGC` → `Cysteine`
- `UGG` → `Tryptophan`
- `UAA`, `UAG`, `UGA` — кодоны остановки.

Верните список аминокислот, читая кодоны слева направо. На кодоне остановки чтение заканчивается: он сам и всё после него не учитываются (даже неполный хвост). Если до остановки попался неизвестный кодон или неполный кодон из 1–2 символов, сообщите об ошибке: бросьте исключение, в Go верните error. Пустая цепочка даёт пустой список.

Пример: `"AUGUUUUGGUAA"` → `["Methionine", "Phenylalanine", "Tryptophan"]`.
