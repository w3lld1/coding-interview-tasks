# Очки слова в «Скрэббле»

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-95?utm_source=github&utm_medium=tasks-repo)**

Дано слово из латинских букв (регистр не важен). Верните сумму очков его букв.

Очки: `A E I O U L N R S T` — 1; `D G` — 2; `B C M P` — 3; `F H V W Y` — 4; `K` — 5; `J X` — 8; `Q Z` — 10. Пустое слово стоит 0 очков.

Пример: `"cabbage"` → `14` (3 + 1 + 3 + 3 + 1 + 2 + 1).
