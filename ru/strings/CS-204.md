# Все правильные строки после наименьшего удаления скобок

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Рекурсия и перебор](../recursion/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-204?utm_source=github&utm_medium=tasks-repo)**

Дана строка `s` длиной до 25 символов из круглых скобок `(`, `)` и строчных латинских букв. Строка правильная, если в ней каждой `)` предшествует ещё не закрытая `(` и в конце все скобки закрыты; буквы на это не влияют, пустая строка тоже правильная. Удалите из `s` наименьшее возможное число скобок (буквы удалять нельзя), чтобы она стала правильной, и верните все различные строки, которые так можно получить, без повторов, отсортированными по возрастанию (сравнение по кодам символов: `(` < `)` < буквы). Если `s` уже правильная, ответ — список из неё одной; если удалить приходится все скобки, в ответе одна строка из оставшихся букв (возможно, пустая).

Пример: `"()())()"` → `["(())()", "()()()"]`.
