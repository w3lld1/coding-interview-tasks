# Шифр Виженера

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-98?utm_source=github&utm_medium=tasks-repo)**

Реализуйте шифр Виженера для латинских строчных букв. Даны режим (`"encode"` или `"decode"`), ключ из строчных букв и текст из строчных букв.

Каждая буква ключа задаёт сдвиг: `a` — 0, `b` — 1, …, `z` — 25. Буква текста на позиции `i` сдвигается по циклу алфавита (после `z` идёт `a`) на сдвиг буквы ключа с номером `i mod длина_ключа`: вперёд при `"encode"`, назад при `"decode"`. Если текст длиннее ключа, ключ повторяется с начала. Пустой текст даёт пустую строку.

Пример: `"encode"`, `"abcd"`, `"hello"` → `"hfnoo"`.
