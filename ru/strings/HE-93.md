# Шифр: регистр и гласные

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-93?utm_source=github&utm_medium=tasks-repo)**

Закодируйте сообщение из латинских букв и пробелов в два шага. Сначала смените регистр каждой буквы: строчные станут заглавными и наоборот. Затем каждую гласную (`a`, `e`, `i`, `o`, `u`, в любом регистре) замените буквой, которая стоит в алфавите на две позиции дальше (`a` → `c`), с тем же регистром. Остальные символы, в том числе пробелы, не меняются.

Пример: `"test"` → `"TGST"`.
