# Разбор групп скобок

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-1?utm_source=github&utm_medium=tasks-repo)**

Дана строка из скобок `(` и `)` и пробелов. Скобки образуют несколько правильных последовательностей, идущих подряд и не вложенных друг в друга. Пробелы нужно игнорировать. Верните список этих групп в порядке следования, каждую без пробелов. Для пустой строки или строки из одних пробелов верните пустой список.

Пример: `"( ) (( )) (( )( ))"` → `["()", "(())", "(()())"]`.
