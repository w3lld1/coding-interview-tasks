# Фильтр строк по префиксу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-29?utm_source=github&utm_medium=tasks-repo)**

Дан список строк и строка-префикс. Верните только те строки, которые начинаются с этого префикса, в исходном порядке (повторы сохраняются). Регистр важен. Пустой префикс подходит любой строке, а строка короче префикса не подходит.

Пример: `["abc", "bcd", "cde", "array"]`, `"a"` → `["abc", "array"]`.
