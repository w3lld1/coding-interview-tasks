# Слова через запятые и пробелы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-101?utm_source=github&utm_medium=tasks-repo)**

Дана строка, в которой слова разделены запятыми, пробелами или тем и другим вместе; разделителей подряд может быть сколько угодно. Верните список слов в исходном порядке, без пустых элементов. Для пустой строки, а также для строки из одних разделителей, верните пустой список.

Пример: `"Hi, my name"` → `["Hi", "my", "name"]`.
