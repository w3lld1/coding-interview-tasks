# Песня про зелёные бутылки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-41?utm_source=github&utm_medium=tasks-repo)**

Составьте текст детской песни «Ten Green Bottles». Даны число бутылок в первом куплете `start_bottles` (от 1 до 10) и число куплетов `take_down` (от 1 до `start_bottles`). Верните список строк. Куплет для `k` бутылок состоит из четырёх строк:

```
K green bottles hanging on the wall,
K green bottles hanging on the wall,
And if one green bottle should accidentally fall,
There'll be K-1 green bottles hanging on the wall.
```

Числа записаны английскими словами: в первых двух строках с заглавной буквы (`Ten`, `One`), в последней строчными (`nine`, `no`). Слово `bottle` стоит в единственном числе только после слова `one` (`One green bottle`, `one green bottle`), во всех остальных случаях это `bottles`, включая `no green bottles`. Между соседними куплетами вставляется пустая строка `""`, после последнего куплета её нет.

Пример: `2`, `1` → `["Two green bottles hanging on the wall,", "Two green bottles hanging on the wall,", "And if one green bottle should accidentally fall,", "There'll be one green bottle hanging on the wall."]`.
