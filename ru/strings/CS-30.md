# Разбиение строки на слова

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-30?utm_source=github&utm_medium=tasks-repo)**

Даны строка `s` из строчных латинских букв (до 300 символов) и словарь `words` (список слов). Каждое слово можно использовать сколько угодно раз. Верните `true`, если `s` можно разрезать на последовательные части так, что каждая часть — слово из словаря, иначе `false`. Пустая строка разбивается всегда (на ноль частей), даже при пустом словаре.

Пример: `"leetcode"`, `["leet", "code"]` → `true`.
