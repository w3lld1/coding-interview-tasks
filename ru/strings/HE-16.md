# Разные символы без учёта регистра

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-16?utm_source=github&utm_medium=tasks-repo)**

Дана строка из символов ASCII. Верните, сколько в ней различных символов, если заглавную и строчную версии одной буквы считать одним символом. Пробел и знаки препинания тоже считаются символами. Для пустой строки ответ `0`.

Пример: `"Jerry"` → `4` (`j`, `e`, `r`, `y`).
