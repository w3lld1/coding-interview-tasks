# Аффинный шифр

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-1?utm_source=github&utm_medium=tasks-repo)**

Реализуйте аффинный шифр для латинского алфавита из 26 букв. Дан режим (`"encode"` или `"decode"`), текст и ключ из двух целых чисел `a` и `b` (`a` ≥ 1, `b` ≥ 0). Буква с номером `x` (буква «a» имеет номер 0, «z» — 25) при шифровании превращается в букву с номером `(a·x + b) mod 26`; при расшифровании буква с номером `y` превращается в букву с номером `a⁻¹·(y − b) mod 26`, где `a⁻¹` — число, для которого `a·a⁻¹ mod 26 = 1`.

Регистр букв не важен, результат пишется строчными. Цифры остаются без изменений, все остальные символы (пробелы, знаки препинания) отбрасываются. При шифровании результат разбивается на группы по 5 символов через пробел (последняя группа может быть короче); при расшифровании пробелов в результате нет. Если `a` и 26 не взаимно просты, сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"encode"`, `"yes"`, `5`, `7` → `"xbt"`.
