# Разбиение текста на слова или подсчёт букв

**Сложность:** лёгкая · **Язык:** Python · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-125?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Результат зависит от её содержимого:

1. Если в строке есть хотя бы один пробел, верните список слов, разделённых пробелами (пустые слова между подряд идущими пробелами отбрасываются).
2. Иначе, если в строке есть запятая, верните список слов, разделённых запятыми (пустые слова тоже отбрасываются).
3. Иначе верните число строчных латинских букв с нечётным номером в алфавите, если нумеровать `a` = 0, `b` = 1, …, `z` = 25 (то есть `b`, `d`, `f`, …, `z`). Остальные символы не считаются; пустая строка даёт `0`.

Пример: `"Hello world,!"` → `["Hello", "world,!"]`; `"abcdef"` → `3`.
