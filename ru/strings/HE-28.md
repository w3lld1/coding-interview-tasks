# Склейка строк

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-28?utm_source=github&utm_medium=tasks-repo)**

Дан список строк. Соедините их в одну строку в том же порядке, без разделителей. Для пустого списка верните пустую строку; пустые строки внутри списка ничего не добавляют.

Пример: `["a", "b", "c"]` → `"abc"`.
