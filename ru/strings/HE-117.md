# Слова с заданным числом согласных

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-117?utm_source=github&utm_medium=tasks-repo)**

Дана строка из латинских букв и пробелов и целое число `n`. Верните список слов (последовательностей букв между пробелами), в которых ровно `n` согласных, в порядке их появления в строке. Гласные — `a`, `e`, `i`, `o`, `u` в любом регистре, все остальные буквы считаются согласными. Для пустой строки результат пуст.

Пример: `"Mary had a little lamb"`, `4` → `["little"]`.
