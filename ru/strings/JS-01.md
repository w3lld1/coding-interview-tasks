# Пароли по строкам стихотворения

**Сложность:** лёгкая · **Язык:** JavaScript · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-01?utm_source=github&utm_medium=tasks-repo)**

Реализуйте четыре функции для паролей из строк стихотворения:

- `frontDoorResponse(line)` — возвращает первый символ строки;
- `backDoorResponse(line)` — удаляет пробелы по краям строки и возвращает её последний символ;
- `frontDoorPassword(word)` — получает уже собранное слово и возвращает его с заглавной первой буквой, остальные буквы строчные (`'sHOE'` → `'Shoe'`);
- `backDoorPassword(word)` — делает то же и дописывает в конец `', please'` (`'horse'` → `'Horse, please'`).
