# Самый длинный правильный фрагмент из скобок

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-81?utm_source=github&utm_medium=tasks-repo)**

Дана строка `s` длиной до 10 000 символов, состоящая только из скобок трёх видов: `()`, `[]` и `{}`. Строка правильная, если каждой открывающей скобке соответствует закрывающая того же вида, пары не перекрываются (`([)]` неправильна), а пустая строка тоже правильная. Найдите самый длинный правильный фрагмент `s` — непрерывную подстроку — и верните его длину. Если такого непустого фрагмента нет (или `s` пуста), верните `0`.

Пример: `"(]{}[()]"` → `6` (фрагмент `{}[()]`).
