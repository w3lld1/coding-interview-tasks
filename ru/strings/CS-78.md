# Сопоставление с маской из ? и *

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

Даны строка `text` и маска `pattern`. Верните `true`, если маска описывает **всю** строку целиком, иначе `false`.

Маска состоит из строчных латинских букв и двух особых символов:
- `?` совпадает ровно с одним любым символом;
- `*` совпадает с любой последовательностью символов, в том числе с пустой.

Буква маски совпадает только с той же буквой. Строка состоит из строчных латинских букв. Пустая маска описывает только пустую строку, маска из одних `*` — любую строку, включая пустую. Длины строки и маски — до 500 символов.

Пример: `"adceb"`, `"*a*b"` → `true`.
