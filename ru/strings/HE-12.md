# Самая длинная строка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-12?utm_source=github&utm_medium=tasks-repo)**

Дан список строк. Верните самую длинную из них. Если таких несколько, верните ту, что стоит в списке раньше всех. Для пустого списка верните `null`.

Пример: `["a", "bb", "ccc"]` → `"ccc"`.
