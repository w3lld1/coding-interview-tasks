# Транспонирование текста

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-09?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `transpose(text)`. Она получает многострочный текст одной строкой (строки разделены `\n`, их длины могут различаться) и возвращает транспонированный текст в том же формате: i-я строка результата составлена из i-х символов исходных строк, сверху вниз. Если исходная строка короче, на месте недостающего символа ставьте пробел, но только когда правее в той же строке результата ещё есть символ из более длинной строки ниже. Пробелы в конце строк результата не добавляйте. Пробелы, которые были во входе, сохраняйте. Для пустой строки верните пустую строку.
