# Перестановка внутри строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-43?utm_source=github&utm_medium=tasks-repo)**

Даны две строки из строчных латинских букв: `pattern` и `text` (каждая до 1000 символов). Верните `true`, если какая-нибудь подстрока `text` (непрерывный фрагмент) является перестановкой `pattern`, то есть состоит из тех же букв с теми же количествами. Иначе верните `false`. Пустой `pattern` встречается в любой строке: ответ `true`.

Пример: `"ab"`, `"eidbaooo"` → `true` (подстрока `ba`).
