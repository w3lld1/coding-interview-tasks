# Нечётные цифры в шаблоне

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-113?utm_source=github&utm_medium=tasks-repo)**

Дан список строк, каждая из которых состоит только из цифр. Для каждой строки посчитайте количество нечётных цифр `k` и сформируйте фразу `the number of odd elements kn the strkng k of the knput.`, где каждое `k` заменено на это число (так что и в словах `kn`, `strkng`, `knput` вместо буквы `i` стоит число). Верните список фраз в том же порядке. Для пустого списка результат пуст, для строки без нечётных цифр `k` равно 0.

Пример: `["3", "11111111"]` → `["the number of odd elements 1n the str1ng 1 of the 1nput.", "the number of odd elements 8n the str8ng 8 of the 8nput."]`.
