# Шифр сдвига на четыре буквы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-89?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните строку, в которой каждая строчная латинская буква `a`–`z` заменена на букву, стоящую в алфавите на 4 позиции дальше; после `z` счёт продолжается с `a` (то есть `w` → `a`, `z` → `d`). Все остальные символы (заглавные буквы, цифры, пробелы, знаки) остаются без изменений. Пустая строка даёт пустую.

Пример: `"hi"` → `"lm"`, `"xyz"` → `"bcd"`.
