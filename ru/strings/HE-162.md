# MD5-хеш строки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-162?utm_source=github&utm_medium=tasks-repo)**

Дана строка из символов ASCII. Верните её MD5-хеш в виде строки из 32 шестнадцатеричных цифр в нижнем регистре. Для пустой строки верните `null`. Воспользуйтесь стандартной библиотекой языка, писать MD5 самостоятельно не нужно.

Пример: `"abc"` → `"900150983cd24fb0d6963f7d28e17f72"`.
