# Расстояние между цепочками ДНК

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-57?utm_source=github&utm_medium=tasks-repo)**

Даны две цепочки ДНК — строки из букв `C`, `A`, `G`, `T`. Верните число позиций, в которых буквы цепочек различаются (расстояние Хэмминга). Если длины цепочек разные, сообщите об ошибке: бросьте исключение, в Go верните error. Две пустые цепочки дают `0`.

Пример: `"GAGCCTACTAACGGGAT"`, `"CATCGTAATGACGGCCT"` → `7`.
