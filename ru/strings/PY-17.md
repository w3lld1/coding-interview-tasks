# Максимальное произведение соседних цифр

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-17?utm_source=github&utm_medium=tasks-repo)**

Для строки десятичных цифр и неотрицательной длины окна найдите наибольшее произведение цифр среди всех непрерывных фрагментов этой длины. Учитывайте нули внутри фрагментов и не изменяйте порядок цифр. При нулевой длине верните 1, в том числе для пустой строки. При отрицательной длине, превышении длины строки или нецифровых символах при положительном окне сообщите об ошибке: бросьте исключение, в Go верните error.
