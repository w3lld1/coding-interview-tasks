# Кодирование серий символов

**Сложность:** средняя · **Язык:** Python · **Темы:** [Строки](../strings/), [Разбор и проверка данных](../parsing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-06?utm_source=github&utm_medium=tasks-repo)**

Напишите две функции кодирования серий (run-length encoding):

- `encode(string)` сжимает строку: каждая серия одинаковых символов подряд записывается как её длина и сам символ, например `"AABBBC"` → `"2A3BC"`. Для серии из одного символа число не пишется.
- `decode(string)` выполняет обратное преобразование и возвращает исходную строку. Длина серии может состоять из нескольких цифр (`"12W"`).

Исходная строка содержит латинские буквы обоих регистров и пробелы, но не цифры. Пустая строка в обоих направлениях превращается в пустую строку.
