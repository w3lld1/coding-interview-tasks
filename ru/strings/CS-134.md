# Умножение чисел в строках

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-134?utm_source=github&utm_medium=tasks-repo)**

Даны два неотрицательных целых числа в виде строк из десятичных цифр (без ведущих нулей, кроме самого числа `0`; длина каждой до 200 символов). Верните их произведение тоже строкой без ведущих нулей. Переводить строки целиком в числовой тип нельзя: числа могут не поместиться ни в `int`, ни в `long`.

Пример: `"123"`, `"45"` → `"5535"`.
