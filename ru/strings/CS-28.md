# Расстояние редактирования

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-28?utm_source=github&utm_medium=tasks-repo)**

Даны две строки из строчных латинских букв, каждая не длиннее 500 символов (строка может быть пустой). За одну операцию можно вставить символ в любое место, удалить любой символ или заменить любой символ другим. Верните наименьшее число операций, превращающих первую строку во вторую.

Пример: `"horse"`, `"ros"` → `3` (horse → rorse → rose → ros).
