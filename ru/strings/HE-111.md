# Самые частые буквы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-111?utm_source=github&utm_medium=tasks-repo)**

Дана строка из строчных букв, разделённых пробелами. Верните словарь, в котором есть только самые частые буквы, а значением каждой служит число её вхождений. Если несколько букв встречаются одинаково часто и чаще остальных, верните все. Для пустой строки результат пуст.

Пример: `"a b c a b"` → `{"a": 2, "b": 2}`.
