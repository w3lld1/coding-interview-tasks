# Сопротивление по трём полосам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-87?utm_source=github&utm_medium=tasks-repo)**

Цвета полос кодируют цифры: `black` 0, `brown` 1, `red` 2, `orange` 3, `yellow` 4, `green` 5, `blue` 6, `violet` 7, `grey` 8, `white` 9. Берутся только первые три цвета списка (остальные, если есть, игнорируются). Первые два — цифры основного числа, третий — сколько нулей дописать справа. Так получается сопротивление в омах.

Верните его строкой `"<число> <единица>"`. Единица — самая крупная, на которую сопротивление делится нацело: `gigaohms` (1 000 000 000), `megaohms` (1 000 000), `kiloohms` (1000), иначе `ohms`. Число — сопротивление, делённое на эту единицу. Сопротивление 0 записывается как `"0 ohms"`.

Пример: `["orange", "orange", "black"]` → `"33 ohms"`; `["orange", "orange", "orange"]` → `"33 kiloohms"`; `["orange", "orange", "red"]` → `"3300 ohms"`.
