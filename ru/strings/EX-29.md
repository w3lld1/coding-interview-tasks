# Число прописью по-английски

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-29?utm_source=github&utm_medium=tasks-repo)**

Запишите целое число английскими словами так, как его произносят вслух. Числа от 21 до 99, не кратные десяти, пишутся через дефис (`twenty-two`), остальные слова разделяются одним пробелом; слово `and` не используется. Группы разрядов называются `thousand`, `million`, `billion`, а нулевая группа пропускается целиком. Допустимы числа от `0` до `999999999999` включительно: для `0` верните `"zero"`, для любого числа вне диапазона сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `1234` → `"one thousand two hundred thirty-four"`.
