# Повторитель

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-17?utm_source=github&utm_medium=tasks-repo)**

Дан список непустых строк из строчных латинских букв. За один ход можно либо взять любую букву в любой строке и повторить её (дописать ещё один такой же символ сразу после неё), либо в любой строке удалить один из двух соседних одинаковых символов. Верните наименьшее число ходов, после которого все строки станут одинаковыми, или `-1`, если это невозможно. Если строка одна, ответ `0`.

Пример: `["mmaw", "maw"]` → `1` (удалить одну `m`).
