# Расшифровка циклического сдвига

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-38?utm_source=github&utm_medium=tasks-repo)**

Строку зашифровали так: её разбили на группы по три символа слева направо (последняя группа может быть короче), а в каждой полной группе первый символ переставили в конец: `abc` стало `bca`. Короткую последнюю группу оставили без изменений. Дана зашифрованная строка `s`, верните исходную. Пустая строка даёт пустую.

Пример: `"bcaef"` → `"abcef"` (группа `bca` стала `abc`, группа `ef` не менялась).
