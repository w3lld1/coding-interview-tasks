# Побитовое XOR строк

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-11?utm_source=github&utm_medium=tasks-repo)**

Даны две строки одинаковой длины, состоящие только из символов `0` и `1`. Выполните над ними побитовое исключающее ИЛИ: на каждой позиции результат равен `0`, если символы совпадают, и `1`, если различаются. Верните результат строкой той же длины. Для двух пустых строк результат — пустая строка.

Пример: `"010"`, `"110"` → `"100"`.
