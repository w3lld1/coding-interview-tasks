# Транскрипция ДНК в РНК

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-89?utm_source=github&utm_medium=tasks-repo)**

Цепочка ДНК состоит из символов `A`, `C`, `G`, `T`. Чтобы получить РНК, замените каждый нуклеотид его комплементом: `G` → `C`, `C` → `G`, `T` → `A`, `A` → `U`. Верните получившуюся строку. Для пустой цепочки результат пустой.

Пример: `"ACGTGGTCTTAA"` → `"UGCACCAGAAUU"`.
