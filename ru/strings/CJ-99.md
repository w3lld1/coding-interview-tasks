# Пересечение двух шаблонов со звёздочками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-99?utm_source=github&utm_medium=tasks-repo)**

Шаблон состоит из латинских букв (заглавные и строчные различаются) и звёздочек `*`. Строка из букв подходит к шаблону, если каждую звёздочку можно заменить строкой из **от нуля до четырёх** любых букв так, чтобы шаблон совпал со строкой. Например, к `Gone**` подходят `GoneGirl` и `GoneTomorrow`, но не `Gonetomorrow` (лишняя буква) и не `TheGoneGirl`.

Даны два шаблона длиной хотя бы `1`. Верните `true`, если существует строка (возможно, пустая), подходящая к обоим, иначе `false`.

Ограничения: длина каждого шаблона до `200`, звёздочек может быть сколько угодно.

Пример: `"Shakes*e"`, `"*peare"` → `false` (звёздочка в начале второго шаблона не покрывает шесть букв `Shakes`).
