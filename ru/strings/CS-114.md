# Строка без одинаковых соседей

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-114?utm_source=github&utm_medium=tasks-repo)**

Дана строка `s` из строчных латинских букв (до 500 символов). Переставьте её буквы так, чтобы никакие две соседние буквы не совпадали. Если вариантов несколько, верните лексикографически наименьший из них. Если так переставить нельзя, верните пустую строку `""`. Для пустой строки ответ тоже `""`.

Пример: `"aabb"` → `"abab"`; `"aaab"` → `""`.
