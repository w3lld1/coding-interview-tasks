# Кратчайший палиндром с префиксом

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-10?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Найдите кратчайший палиндром, который начинается с этой строки, и верните его. Для этого найдите самый длинный суффикс строки, являющийся палиндромом, и допишите в конец строки развёрнутую часть, стоявшую перед этим суффиксом. Для пустой строки ответ — пустая строка.

Пример: `"cat"` → `"catac"`.
