# Подсчёт нуклеотидов в ДНК

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-72?utm_source=github&utm_medium=tasks-repo)**

Цепочка ДНК — строка из символов `A`, `C`, `G` и `T` (заглавные буквы). Верните словарь с ключами `"A"`, `"C"`, `"G"`, `"T"`, где значение — сколько раз символ встречается в цепочке. Все четыре ключа есть всегда, даже если счётчик равен 0; для пустой строки все счётчики нули. Если в строке есть любой другой символ (в том числе строчная буква), сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"GATTACA"` → `{"A": 3, "C": 1, "G": 1, "T": 2}`.
