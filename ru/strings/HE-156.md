# Римские цифры строчными

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-156?utm_source=github&utm_medium=tasks-repo)**

Дано целое число от 1 до 1000. Верните его запись римскими цифрами в нижнем регистре по обычным правилам с вычитанием: `iv` для 4, `ix` для 9, `xl` для 40, `xc` для 90, `cd` для 400, `cm` для 900.

Пример: `426` → `"cdxxvi"`.
