# Оптимальное выравнивание текста по ширине

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-192?utm_source=github&utm_medium=tasks-repo)**

Дан список слов и ширина строки `width`. Разбейте слова по порядку на строки так, чтобы в каждой строке слова, разделённые одним пробелом, занимали не больше `width` символов. Штраф строки — квадрат числа оставшихся в ней свободных символов (`width` минус длина строки с одиночными пробелами); последняя строка (та, где последнее слово) штрафа не даёт. Выберите разбиение с наименьшим суммарным штрафом; если таких несколько, ставьте как можно больше слов в первую строку, затем при этом условии во вторую, и так далее.

Затем выровняйте строки до длины ровно `width`. В строке из двух и более слов, кроме последней строки, раздайте свободные символы пробелами между словами поровну, а остаток — по одному пробелу в промежутки слева направо. Строку из одного слова и последнюю строку выровняйте влево: слова через один пробел, справа пробелы. Верните список строк; для пустого списка слов верните `[]`.

Слов до 300, каждое из 1–`width` символов без пробелов, `width` от 1 до 100.

Пример: `["aaa", "bb", "cc", "ddddd"]`, `6` → `["aaa   ", "bb  cc", "ddddd "]` (штраф 9 + 1; жадное `"aaa bb"` даёт 0 + 16).
