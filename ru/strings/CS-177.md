# Пары слов, склеенные в палиндром

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-177?utm_source=github&utm_medium=tasks-repo)**

Дан список **различных** слов из строчных латинских букв; одно из слов может быть пустой строкой. Найдите все пары индексов `[i, j]`, где `i ≠ j`, а склейка `words[i] + words[j]` читается одинаково слева направо и справа налево. Порядок в паре важен: `[i, j]` и `[j, i]` — разные пары.

Верните пары, отсортированные по возрастанию `i`, а при равных `i` — по возрастанию `j`. Если подходящих пар нет, верните `[]`. Ограничения: до 2000 слов длиной до 30; перебор всех пар на больших входах слишком медленный.

Пример: `["ab", "ba", "abc", "c", ""]` → `[[0, 1], [1, 0], [2, 1], [3, 4], [4, 3]]`.
