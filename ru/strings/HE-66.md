# Сумма кодов заглавных букв

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-66?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните сумму ASCII-кодов её заглавных латинских букв `A`–`Z`; все остальные символы (строчные буквы, цифры, пробелы, знаки) не учитываются. Для пустой строки и строки без заглавных букв ответ `0`.

Пример: `"abAB"` → `131` (65 + 66).
