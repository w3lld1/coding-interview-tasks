# Сцепка вагонов без разрывов букв

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/), [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-65?utm_source=github&utm_medium=tasks-repo)**

Дан список `cars` из `n` строк из строчных латинских букв: каждая строка — сцепленная группа вагонов, переворачивать её нельзя. Сцепите все группы в один поезд, выбрав их порядок. Поезд правильный, если все вхождения каждой буквы стоят подряд. Верните число порядков групп, дающих правильный поезд, по модулю `1 000 000 007`. Группы различаются по позиции в списке: две одинаковые строки, переставленные местами, дают два разных порядка.

Ограничения: `1 ≤ n ≤ 100`, длина каждой строки от 1 до 100; перебор порядков слишком медленный.

Пример: `["aa", "aa", "bc", "c"]` → `4`.
