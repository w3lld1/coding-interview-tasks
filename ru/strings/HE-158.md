# Слово с наибольшим числом разных букв

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-158?utm_source=github&utm_medium=tasks-repo)**

Дан непустой список слов. Верните слово, в котором больше всего различных символов (повторы одного символа считаются один раз). Если таких слов несколько, верните лексикографически наименьшее из них: то, что идёт первым при сравнении строк посимвольно по кодам.

Пример: `["name", "enam", "game"]` → `"enam"` (у всех трёх по 4 разных буквы, а `"enam"` идёт первым по алфавиту).
