# Набор строки копированием и вставкой

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-100?utm_source=github&utm_medium=tasks-repo)**

Нужно набрать строку `target` из строчных латинских букв. Вы начинаете с пустой строки и пустого буфера обмена; за одну операцию можно:

- дописать в конец строки одну любую букву;
- скопировать в буфер любой подотрезок (подряд идущие символы) текущей строки, заменив прежнее содержимое буфера;
- дописать в конец строки всё содержимое буфера (буфер не меняется).

В конце должна получиться ровно строка `target`, без лишних букв. Верните наименьшее число операций.

Ограничения: `1 ≤ len(target) ≤ 150`.

Пример: `"abcabab"` → `6` (набрать `a`, `b`, `c`, скопировать `ab`, вставить его дважды).
