# Сортировка цифр-слов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-19?utm_source=github&utm_medium=tasks-repo)**

Дана строка, в которой через один пробел записаны английские названия цифр: `zero`, `one`, `two`, `three`, `four`, `five`, `six`, `seven`, `eight`, `nine`. Верните строку, где те же слова отсортированы по значению цифры от меньшей к большей, тоже через один пробел. Повторы сохраняются. Для пустой строки результат — пустая строка.

Пример: `"three one five"` → `"one three five"`.
