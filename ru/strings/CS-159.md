# Самое большое склеенное число

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-159?utm_source=github&utm_medium=tasks-repo)**

Дан список неотрицательных целых чисел. Запишите их десятичные записи подряд в любом порядке и получите одно число. Верните наибольшее из возможных чисел в виде строки (оно может не поместиться в целое). Если все числа равны нулю, верните `"0"`. Для пустого списка верните пустую строку.

Пример: `[3, 30, 34, 5, 9]` → `"9534330"`.
