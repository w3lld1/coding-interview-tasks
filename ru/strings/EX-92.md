# Шифр вращения (ROT)

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-92?utm_source=github&utm_medium=tasks-repo)**

Реализуйте шифр Цезаря. Каждая латинская буква сдвигается по алфавиту вперёд на `shift_key` позиций (от 0 до 26) по кругу: после `z` идёт `a`. Регистр сохраняется, все остальные символы (пробелы, цифры, знаки препинания) остаются без изменений. Сдвиг 0 и 26 не меняют текст.

Пример: `"OMG"`, `5` → `"TRL"`; `"The quick brown fox jumps over the lazy dog."`, `13` → `"Gur dhvpx oebja sbk whzcf bire gur ynml qbt."`.
