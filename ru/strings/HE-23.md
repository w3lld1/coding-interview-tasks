# Длина строки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-23?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните количество символов в ней. Пустая строка имеет длину `0`, пробелы считаются символами. В тестах только ASCII-символы.

Пример: `"abc"` → `3`.
