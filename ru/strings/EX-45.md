# Шифр «квадратный код»

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-45?utm_source=github&utm_medium=tasks-repo)**

Зашифруйте текст методом квадратного кода. Сначала нормализуйте текст: оставьте только латинские буквы и цифры и переведите буквы в нижний регистр. Пусть получилось `n` символов. Запишите их по строкам в прямоугольник из `r` строк и `c` столбцов, где `c` наименьшее число, для которого `r·c ≥ n`, `c ≥ r` и `c − r ≤ 1` (последняя строка может быть неполной). Затем прочитайте прямоугольник по столбцам слева направо: каждый столбец это кусок длиной `r`. Куски, в которых не хватает символов, дополняются пробелом справа до длины `r`. Верните все `c` кусков, соединённых одним пробелом. Если после нормализации ничего не осталось, верните пустую строку.

Пример: `"Chill out."` → `"clu hlt io "` (8 символов, 3 столбца, 3 строки; последний кусок дополнен пробелом).
