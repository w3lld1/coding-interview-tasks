# Баланс круглых скобок

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-61?utm_source=github&utm_medium=tasks-repo)**

Дана строка, состоящая только из символов `(` и `)`. Верните `true`, если скобки расставлены правильно: каждой открывающей скобке соответствует закрывающая после неё, и ни одна закрывающая скобка не стоит раньше своей пары. Иначе верните `false`. Пустая строка считается правильной.

Пример: `"(()())"` → `true`, `")("` → `false`.
