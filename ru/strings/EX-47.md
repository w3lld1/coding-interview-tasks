# Алмаз из букв

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-47?utm_source=github&utm_medium=tasks-repo)**

Дана заглавная латинская буква `letter` от `A` до `Z`. Постройте ромб из букв: первая строка содержит одну `A`, дальше буквы идут по алфавиту до `letter` в самой широкой строке, затем в обратном порядке до `A` в последней строке. Верните список строк.

Все строки одной длины `2·k + 1`, где `k` — номер заданной буквы (`A` — это 0), и дополнены пробелами слева и справа. Каждая строка, кроме первой и последней, содержит две одинаковые буквы, строка с `A` одну. Ромб симметричен по горизонтали и вертикали. Для `A` результат `["A"]`.

Пример: `"C"` → `["  A  ", " B B ", "C   C", " B B ", "  A  "]`.
