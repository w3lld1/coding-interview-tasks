# Самая длинная подстрока из одной буквы после замен

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-42?utm_source=github&utm_medium=tasks-repo)**

Дана строка из заглавных латинских букв (до 1000 символов) и целое `k ≥ 0`. Вы можете заменить не более `k` символов на любые заглавные буквы. Верните наибольшую длину подстроки (непрерывного фрагмента), которая после таких замен состоит из одной и той же буквы. Для пустой строки ответ `0`.

Пример: `"AABABBA"`, `1` → `4` (заменив одну `B` в `AABA`, получаем `AAAA`).
