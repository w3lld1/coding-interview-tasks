# Бейджи и отсутствующие значения

**Сложность:** лёгкая · **Язык:** JavaScript · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-08?utm_source=github&utm_medium=tasks-repo)**

Напишите printBadge(id, name, department), возвращающую строку вида '[17] Анна - MARKETING', где название отдела переводится в верхний регистр. Если id равен null, не печатайте идентификатор вместе со скобками и лишним пробелом. Если department равен null, вместо отдела используйте OWNER; это правило действует и при отсутствующем идентификаторе.
