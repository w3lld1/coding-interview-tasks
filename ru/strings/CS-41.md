# Палиндромные подстроки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-41?utm_source=github&utm_medium=tasks-repo)**

Дана строка из строчных латинских букв, длиной до 1000. Верните количество её подстрок (непрерывных фрагментов), которые читаются одинаково слева направо и справа налево. Подстроки с разными позициями считаются разными, даже если их текст совпадает. Для пустой строки ответ `0`.

Пример: `"aaa"` → `6` (`a` три раза, `aa` два раза и `aaa`).
