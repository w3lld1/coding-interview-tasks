# Расшифровка сдвига на пять букв

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-50?utm_source=github&utm_medium=tasks-repo)**

Строка из строчных латинских букв `a`–`z` была зашифрована так: каждая буква заменена буквой на 5 позиций дальше по алфавиту, а после `z` счёт продолжается с `a`. Дана зашифрованная строка. Верните исходную. Пустая строка даёт пустую строку.

Пример: `"mjqqt"` → `"hello"`.
