# Самая длинная подстрока без повторов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-38?utm_source=github&utm_medium=tasks-repo)**

Дана строка (до 10 000 символов, любые символы). Верните длину самой длинной подстроки, то есть непрерывного куска строки, в которой нет двух одинаковых символов. Регистр различается, пробел — обычный символ. Для пустой строки ответ `0`.

Пример: `"abcabcbb"` → `3` (`"abc"`).
