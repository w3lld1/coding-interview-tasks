# Самый длинный палиндром внутри строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-40?utm_source=github&utm_medium=tasks-repo)**

Дана строка (до 1000 символов). Верните её самую длинную подстроку-палиндром, то есть непрерывный кусок, который читается одинаково слева направо и справа налево. Если таких несколько одинаковой длины, верните самую левую (с наименьшим индексом начала). Для пустой строки ответ — пустая строка.

Пример: `"babad"` → `"bab"` (`"aba"` той же длины, но начинается правее).
