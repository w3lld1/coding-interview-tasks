# Счастливая строка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-80?utm_source=github&utm_medium=tasks-repo)**

Строка называется счастливой, если её длина не меньше 3 и в любых трёх подряд идущих символах все символы различны. Верните `true`, если строка счастливая, и `false` иначе. Слишком короткая строка (в том числе пустая) счастливой не считается.

Пример: `"abcd"` → `true`; `"aabb"` → `false`; `"aba"` → `false`.
