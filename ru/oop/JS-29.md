# Линзы для неизменяемых вложенных объектов

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Классы и ООП](../oop/), [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-29?utm_source=github&utm_medium=tasks-repo)**

Для модели Person с вложенными Name, Born и Address реализуйте nameLens, bornAtLens и streetLens. Каждая линза предоставляет get(person) и set(person, value) соответственно для person.name, person.born.bornAt и person.address.street. Метод set должен возвращать обновлённого человека, не изменяя исходный объект и затронутые вложенные записи; допустим и эквивалентный подход без отдельной библиотеки линз.
