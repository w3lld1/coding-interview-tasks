# Оконная система: классы и прототипы

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Классы и ООП](../oop/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-19?utm_source=github&utm_medium=tasks-repo)**

Реализуйте оконную систему:

- `Size(width = 80, height = 60)` — функция-конструктор с полями `width` и `height`; метод `resize(newWidth, newHeight)` лежит в `Size.prototype`;
- `Position(x = 0, y = 0)` — функция-конструктор с полями `x` и `y`; метод `move(newX, newY)` лежит в `Position.prototype`;
- класс `ProgramWindow` — конструктор без аргументов создаёт поля `screenSize` (`new Size(800, 600)`), `size` (`new Size()`) и `position` (`new Position()`).

Метод окна `resize(newSize)` получает `Size` и меняет размер: каждая сторона не меньше 1 и не выходит за край экрана с учётом текущего положения. Метод `move(newPosition)` получает `Position` и меняет положение: координаты не меньше 0, и окно целиком остаётся на экране с учётом текущего размера. Функция `changeWindow(programWindow)` задаёт размер 400×300, положение (100, 150) и возвращает то же окно.
