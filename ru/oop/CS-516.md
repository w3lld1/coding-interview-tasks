# Недавние файлы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Меню «Недавние файлы» помнит не больше 3 последних открытых файлов (номер файла — целое число), новые сверху. Сначала оно пусто. Операции:
- `open` (id): открыть файл id. Он оказывается первым в меню; если он там уже был, прежнее место освобождается (повторов нет). Если после этого файлов больше 3, последний выпадает из меню. Результат — число файлов в меню;
- `front`: результат — номер первого файла меню или `-1`, если меню пусто;
- `position` (id): результат — место файла id в меню, считая с 1 (первый файл — место 1), или `0`, если его там нет;
- `forget` (id): убрать файл id из меню; результат `1`, если он там был, иначе `0`.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["open", "open", "open", "front", "open", "position", "position", "open", "front", "position", "position"]`, `[[1], [2], [3], [], [4], [1], [4], [2], [], [3], [4]]` → `[1, 2, 3, 3, 3, 0, 1, 3, 2, 3, 2]`.
