# Табло баскетбольного матча

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-263?utm_source=github&utm_medium=tasks-repo)**

Реализуйте табло матча двух команд, команды имеют номера `1` и `2`. Счёт сначала `0 : 0`. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"score"` с аргументами `team`, `points`: команда набрала `points` очков; результат: новый счёт этой команды.
- `"lead"` без аргументов: результат: номер команды, которая ведёт, или `0` при равенстве.
- `"diff"` без аргументов: результат: модуль разности счетов сейчас.
- `"biggest"` без аргументов: результат: наибольшая разность счетов по модулю, которая была после любой операции `"score"` (до первой это `0`).

Пример: `["score", "score", "lead", "diff"]`, `[[1, 3], [2, 2], [], []]` → `[3, 2, 1, 1]`.
