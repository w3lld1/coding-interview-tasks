# Документ с отменой и повтором

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Документ — список целых чисел, сначала пустой. Команды изменяют его конец, и их можно отменять и повторять. Реализуйте операции:
- `insert` (x): дописать x в конец; команда запоминается для отмены, а то, что можно повторить, забывается;
- `erase`: удалить последнее число. В пустом документе ничего не происходит и команда не запоминается; иначе она запоминается для отмены, а повторяемое забывается;
- `undo`: отменить последнюю ещё не отменённую команду (вставка убирает число, стирание возвращает его); если отменять нечего, ничего не происходит;
- `redo`: вернуть последнюю отменённую команду, если после неё не было новых `insert` и `erase`; иначе ничего не происходит;
- `last`: результат — последнее число документа или `-1`, если он пуст.

Для всех операций, кроме `last`, результат — длина документа после операции. Верните список результатов. `values[i]` — аргументы операции `i`.

Пример: `["insert", "insert", "erase", "undo", "undo", "redo", "last"]`, `[[4], [7], [], [], [], [], []]` → `[1, 2, 1, 2, 1, 2, 7]`.
