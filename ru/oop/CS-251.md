# Профилировщик стека вызовов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-251?utm_source=github&utm_medium=tasks-repo)**

Профилировщик следит за стеком вызовов программы; функции — положительные числа, и одна функция может быть в стеке несколько раз (рекурсия). Сначала стек пуст. Реализуйте операции:
- `enter` (функция): вызов функции, она кладётся на вершину; результат — глубина стека;
- `exit`: возврат из самой внутренней функции; результат — её номер, а для пустого стека `-1`;
- `depth`: результат — текущая глубина;
- `deepest`: результат — наибольшая глубина стека с самого начала (она не уменьшается при `exit`);
- `inside` (функция): результат `1`, если функция сейчас есть в стеке хотя бы раз, иначе `0`.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["enter", "enter", "enter", "deepest", "inside", "exit", "exit", "depth", "deepest", "inside"]`, `[[1], [2], [2], [], [1], [], [], [], [], [2]]` → `[1, 2, 3, 3, 1, 2, 2, 1, 3, 0]`.
