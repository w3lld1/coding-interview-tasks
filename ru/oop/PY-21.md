# Собственный тип множества

**Сложность:** средняя · **Язык:** Python · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-21?utm_source=github&utm_medium=tasks-repo)**

Реализуйте класс множества `CustomSet(elements=[])`. Повторное добавление элемента не меняет множество, порядок элементов не влияет на равенство, повторы во входном списке не учитываются. Методы:

- `isempty()` — `True`, если множество пусто;
- `element in s` (`__contains__`) — принадлежность элемента;
- `issubset(other)` — все элементы входят в `other`;
- `isdisjoint(other)` — нет общих элементов;
- `s1 == s2` — равенство множеств;
- `add(element)` — добавить элемент;
- `intersection(other)` — пересечение, `s1 - s2` — разность, `s1 + s2` — объединение; эти операции возвращают новый `CustomSet`.
