# Состав из вагонов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-254?utm_source=github&utm_medium=tasks-repo)**

Состав — последовательность вагонов, обозначенных неотрицательными числами (номера могут повторяться); сначала он пуст. Реализуйте операции:
- `append` (вагон) и `prepend` (вагон): прицепить вагон в конец или в начало; результат — длина состава;
- `remove_first` (вагон): отцепить первый (ближайший к началу) вагон с таким номером. Результат `1`, если он был, иначе `0`;
- `reverse`: развернуть состав; результат — его длина;
- `at` (i): результат — номер вагона на месте `i` (нумерация с нуля от начала) или `-1`, если такого места нет;
- `length`: результат — длина состава.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["append", "append", "prepend", "remove_first", "reverse", "at", "at", "length"]`, `[[3], [5], [9], [5], [], [0], [2], []]` → `[1, 2, 3, 1, 2, 3, -1, 2]`.
