# Счётчик обращений пользователей по окнам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Поиск и сортировка](../search-sort/), [Словари и множества](../hashing/)

Реализуйте счётчик обращений к сервису, сначала пустой. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию. Пользователь задаётся целым номером ≥ 0, время — целым числом ≥ 0. Обращения могут приходить не по порядку времени (запоздавшие события). Окно `(t, w)` (`w` ≥ 1) — это моменты времени `x` с `t − w < x ≤ t`; момент `t` запроса может быть любым, в том числе раньше или позже всех обращений.

Операции:
- `"hit"` с аргументами `user`, `time`: обращение пользователя в момент `time` (одинаковые моменты считаются отдельно). Результат: сколько обращений этого пользователя сейчас хранится.
- `"count"` с аргументами `user`, `t`, `w`: число обращений пользователя в окне.
- `"total"` с аргументами `t`, `w`: число обращений всех пользователей в окне.
- `"top"` с аргументами `t`, `w`: пользователь с наибольшим числом обращений в окне; при равенстве — с меньшим номером; `-1`, если в окне нет обращений.
- `"active"` с аргументами `t`, `w`, `k` (`k` ≥ 1): сколько пользователей имеют в окне не меньше `k` обращений.
- `"forget"` с аргументом `user`: удалить все обращения пользователя. Результат: сколько их было удалено.

До 2000 операций, больше 50 разных пользователей не бывает.

Пример: `["hit", "hit", "hit", "count", "top"]`, `[[7, 10], [7, 11], [3, 11], [7, 11, 1], [11, 5]]` → `[1, 2, 1, 1, 7]`.
