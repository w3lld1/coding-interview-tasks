# Ханойские башни с проверкой ходов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

В игре три стержня, пронумерованных `0`, `1`, `2`, и четыре диска размеров 1–4. Сначала все диски на стержне `0`: снизу самый большой (`4`), сверху самый маленький (`1`), на остальных стержнях пусто. Диск можно положить только на пустой стержень или на больший диск. Реализуйте операции:
- `move` (откуда, куда): перенести верхний диск одного стержня на другой. Ход допустим, если стержни разные, на исходном есть диск, а на целевом пусто или лежит диск больше переносимого. Допустимый ход выполняется и даёт `1`, недопустимый ничего не меняет и даёт `0`;
- `top` (стержень): результат — размер верхнего диска стержня или `0`, если он пуст;
- `count` (стержень): результат — число дисков на стержне.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["move", "move", "move", "top", "count", "count"]`, `[[0, 1], [0, 1], [1, 2], [0], [1], [2]]` → `[1, 0, 1, 2, 0, 1]`.
