# Остатки товаров на складе

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Исключения](../errors/)

Реализуйте учёт остатков в магазине. Склад сначала пуст. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию. Товар задаётся целым номером `item`.

Операции:
- `"add"` с аргументами `item`, `qty`: принять `qty` штук; результат: остаток этого товара. Если `qty` ≤ 0, сообщите об ошибке: бросьте исключение, в Go верните error. Товар после первого прихода считается известным.
- `"remove"` с аргументами `item`, `qty`: списать `qty` штук; результат: остаток товара. Если товар неизвестен, `qty` ≤ 0 или `qty` больше остатка, сообщите об ошибке: бросьте исключение, в Go верните error.
- `"stock"` с аргументом `item`: результат: остаток (`0` для неизвестного товара).
- `"total"` без аргументов: результат: сумма остатков всех товаров.

Ошибка относится ко всему вызову: первая же неверная операция прерывает его.

Пример: `["add", "remove", "total"]`, `[[1, 10], [1, 3], []]` → `[10, 7, 7]`.
