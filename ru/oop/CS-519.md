# Очередь, которую можно развернуть

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Очередь на аттракцион можно развернуть: тогда тот, кто стоял последним, становится первым. Сначала очередь пуста. Операции:
- `enqueue` (x): человек с номером x встаёт в конец очереди; результат — длина очереди;
- `dequeue`: первый уходит из очереди; результат — его номер или `-1`, если очередь пуста;
- `reverse`: порядок всех стоящих меняется на обратный (последний становится первым); результат — длина очереди. Новые люди после этого встают в конец уже развёрнутой очереди;
- `front`: результат — номер первого или `-1`, если очередь пуста;
- `back`: результат — номер последнего или `-1`, если очередь пуста.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["enqueue", "enqueue", "enqueue", "front", "back", "reverse", "front", "back", "enqueue", "dequeue", "dequeue", "reverse", "dequeue", "dequeue", "dequeue"]`, `[[1], [2], [3], [], [], [], [], [], [4], [], [], [], [], [], []]` → `[1, 2, 3, 1, 3, 3, 3, 1, 4, 3, 2, 2, 4, 1, -1]`.
