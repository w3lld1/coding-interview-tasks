# Планировщик с квантом времени

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-243?utm_source=github&utm_medium=tasks-repo)**

Процессор выполняет задачи по кругу: каждой даёт квант в 3 единицы времени. Сначала очередь пуста. Реализуйте операции:
- `add` (id, время): поставить в конец очереди задачу с положительными номером и требуемым временем; результат — число задач в очереди;
- `run`: взять первую задачу и выполнить её не дольше 3 единиц. Если ей осталось не больше 3, она завершается и покидает очередь, результат — её id. Иначе у неё вычитается 3 единицы, она уходит в конец очереди, результат `0`. Для пустой очереди результат `-1`;
- `count`: результат — число задач в очереди.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["add", "add", "run", "run", "run", "run", "count"]`, `[[1, 5], [2, 2], [], [], [], [], []]` → `[1, 2, 0, 2, 1, -1, 0]`.
