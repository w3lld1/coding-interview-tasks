# Журнал оценок по ученикам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-265?utm_source=github&utm_medium=tasks-repo)**

Реализуйте журнал оценок. Сначала он пуст. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Ученики заданы целыми номерами, оценки лежат в диапазоне `0..100`. Верните список результатов, по одному на операцию.

Операции:
- `"add_grade"` с аргументами `student`, `grade`: записать оценку; результат: сколько оценок теперь у ученика.
- `"average"` с аргументом `student`: результат: среднее арифметическое его оценок, округлённое вниз до целого, или `-1`, если оценок нет.
- `"top"` без аргументов: результат: номер ученика с наибольшим средним (сравнивайте точно, не округляя); при равенстве меньший номер; `-1`, если оценок ещё нет ни у кого.

Пример: `["add_grade", "add_grade", "average", "top"]`, `[[1, 90], [1, 85], [1], []]` → `[1, 2, 87, 1]`.
