# Стек прерванных дел

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Разработчика то и дело отвлекают: новое дело откладывает текущее, и к старому он возвращается, когда новое закончено. Сначала дел нет. Реализуйте операции:
- `start` (id, минуты): взять новое дело, положительные номер и время; оно становится текущим, прежнее ждёт. Результат — число дел в работе;
- `work` (минуты): потратить указанное число минут только на текущее дело (остаток времени на другое дело не переходит). Если дело требовало не больше этого времени, оно завершается и результат — его id; иначе из его времени вычитаются минуты и результат `0`. Если дел нет, результат `-1`;
- `current`: результат — id текущего дела или `-1`, если дел нет;
- `remaining`: результат — сколько минут осталось текущему делу или `-1`, если дел нет.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["start", "start", "work", "work", "current", "work", "remaining"]`, `[[1, 10], [2, 4], [3], [3], [], [5], []]` → `[1, 2, 0, 2, 1, 0, 5]`.
