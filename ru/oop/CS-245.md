# Круг детей со счётом

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Дети стоят по кругу, один из них — «текущий». Сначала круг пуст. Порядок — по часовой стрелке. Реализуйте операции:
- `join` (id): ребёнок встаёт в круг прямо перед текущим (то есть последним, если считать от текущего), и текущий не меняется. Если круг был пуст, ребёнок становится текущим. Результат — число детей в круге;
- `pass` (k): текущим становится ребёнок через k мест по часовой стрелке (k ≥ 0, круг замкнут, поэтому k может быть больше числа детей); результат — id нового текущего или `-1`, если круг пуст;
- `out`: текущий ребёнок выходит из круга, а текущим становится следующий за ним по часовой стрелке. Результат — id вышедшего или `-1`, если круг пуст.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["join", "join", "join", "pass", "out", "pass", "out"]`, `[[1], [2], [3], [1], [], [2], []]` → `[1, 2, 3, 2, 2, 3, 3]`.
