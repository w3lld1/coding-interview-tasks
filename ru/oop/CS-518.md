# Стековый калькулятор

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-518?utm_source=github&utm_medium=tasks-repo)**

Калькулятор хранит числа в стеке, сначала пустом. Операции:
- `push` (x): положить число x на вершину;
- `add`, `sub`, `mul`: снять два верхних числа — сначала b (вершина), потом a под ним — и положить результат `a + b`, `a - b` или `a * b`. Если в стеке меньше двух чисел, ничего не происходит;
- `dup`: положить копию вершины (если стек пуст, ничего не происходит);
- `swap`: поменять местами два верхних числа (если их меньше двух, ничего не происходит);
- `drop`: снять вершину (если стек пуст, ничего не происходит);
- `top`: результат — число на вершине или `0`, если стек пуст.

Для всех операций, кроме `top`, результат — число элементов в стеке после операции. Значения помещаются в 32-битное целое.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["push", "push", "sub", "top", "dup", "mul", "top", "push", "swap", "sub", "top"]`, `[[6], [4], [], [], [], [], [], [3], [], [], []]` → `[1, 2, 1, 2, 2, 1, 4, 2, 2, 1, -1]`.
