# JSON API взаимных долгов

**Сложность:** сложная · **Язык:** JavaScript · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-26?utm_source=github&utm_medium=tasks-repo)**

Реализуйте в памяти класс `RestAPI` с конструктором `new RestAPI({users: [...]})` и методами `get(url)`, `post(url, payload)`; HTTP-сервер не нужен. Пользователь содержит `name`, `owes`, `owed_by`, `balance` (сумма требований минус сумма долгов). `get('/users')` возвращает `{users: [...]}` со всеми пользователями; `get('/users?users=Bob')` — ту же обёртку только для Bob: фильтр передаётся в query string, не вторым объектом. Фильтр — одно имя (значение URL-кодировано). `post('/add', {user: 'Adam'})` возвращает объект нового пользователя `{name: 'Adam', owes: {}, owed_by: {}, balance: 0}` без обёртки. `post('/iou', {lender: 'Adam', borrower: 'Bob', amount: 3})` обновляет обе стороны с зачётом встречных долгов и возвращает `{users: [...]}` только с изменёнными пользователями. Все списки пользователей в ответах сортируются по имени.
