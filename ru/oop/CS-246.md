# Учёт открытых тегов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Редактор разметки следит за вложенными открытыми тегами; теги — положительные числа (их виды), в одном виде может быть несколько вложенных тегов. Сначала открытых тегов нет. Реализуйте операции:
- `open` (тег): открыть тег внутри всех открытых; результат — число открытых тегов;
- `close` (тег): строгое закрытие. Если самый внутренний открытый тег — именно этот, он закрывается и результат `1`; иначе ничего не меняется и результат `0`;
- `close_through` (тег): закрыть ближайший к концу открытый тег этого вида вместе со всеми тегами, открытыми после него. Результат — сколько тегов закрылось, или `0`, если такого тега нет (тогда ничего не меняется);
- `top`: результат — самый внутренний открытый тег или `0`, если открытых нет;
- `depth`: результат — число открытых тегов.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["open", "open", "open", "close", "close_through", "top", "depth"]`, `[[1], [2], [3], [2], [2], [], []]` → `[1, 2, 3, 0, 2, 1, 1]`.
