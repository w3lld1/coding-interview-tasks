# Список ожидания в ресторане

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

В ресторане гости ждут столик компаниями; компания задаётся числом человек. Очередь идёт в порядке прихода, сначала она пуста. Операции:
- `add` (n): компания из n человек встаёт в конец очереди; результат — число компаний в очереди;
- `seat` (t): освободился столик на t мест. Сажают первую по очереди компанию, в которой не больше t человек (более ранние, но слишком большие компании остаются ждать); результат — размер посаженной компании или `0`, если подходящей нет;
- `cancel` (i): i-я по очереди компания (считая с 1) уходит; результат — её размер или `0`, если такой нет;
- `people`: результат — сколько всего человек ждёт;
- `parties`: результат — число компаний в очереди.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["add", "add", "add", "add", "people", "seat", "seat", "seat", "seat", "parties", "people"]`, `[[4], [2], [6], [3], [], [3], [5], [2], [1], [], []]` → `[1, 2, 3, 4, 15, 2, 4, 0, 0, 2, 9]`.
