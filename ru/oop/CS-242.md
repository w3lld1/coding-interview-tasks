# Плейлист как связный список

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Плейлист — последовательность песен, обозначенных различными положительными числами; сначала он пуст. Песня, которая уже есть в плейлисте, второй раз не добавляется (в тестах такого нет). Реализуйте операции:
- `add` (песня): дописать в конец; результат — длина плейлиста;
- `insert_after` (песня, новая): вставить новую песню сразу после указанной. Если указанной нет, плейлист не меняется и результат `0`, иначе `1`;
- `remove` (песня): убрать песню. Результат `1`, если она была, иначе `0`;
- `next` (песня): результат — песня, которая идёт сразу после указанной, или `-1`, если указанная последняя или её нет;
- `first`: результат — первая песня или `-1` для пустого плейлиста.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["add", "add", "insert_after", "next", "next", "remove", "next", "first"]`, `[[10], [20], [10, 15], [10], [20], [15], [10], []]` → `[1, 2, 1, 15, -1, 1, 20, 10]`.
