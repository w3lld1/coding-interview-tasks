# Календарь бронирований одной комнаты

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Даты и время](../dates/), [Исключения](../errors/)

Реализуйте календарь одной переговорной на сутки в виде списка операций: `apply_operations(operations, values)` — для каждой операции `operations[i]` с аргументами `values[i]` верните строку-результат (список результатов той же длины). Сначала бронирований нет.

Операции (результат — строка):
- `"book"` `[start, end]` — занять отрезок `[start, end)` в минутах от полуночи. Если он не пересекается ни с одной принятой бронью, запомните его и верните `"true"`, иначе ничего не меняйте и верните `"false"`. Брони, у которых конец одной совпадает с началом другой, не пересекаются. Если не выполнено `0 ≤ start < end ≤ 1440`, сообщите об ошибке;
- `"cancel"` `[start]` — снять бронь, которая начинается ровно в `start`: `"true"`, если такая была, иначе `"false"`;
- `"busy_at"` `[minute]` — `"true"`, если минута `minute` лежит внутри какой-нибудь брони (`start ≤ minute < end`), иначе `"false"`. Если `minute` не в диапазоне от 0 до 1439, сообщите об ошибке;
- `"free_minutes"` `[]` — число свободных минут суток (из 1440), строкой.

Первая же неверная операция делает ошибкой весь вызов: сообщите об ошибке: бросьте исключение, в Go верните error. Пустой список операций даёт пустой список.

Пример: `["book", "book", "book", "free_minutes"]`, `[[540, 600], [570, 630], [600, 660], []]` → `["true", "false", "true", "1320"]`.
