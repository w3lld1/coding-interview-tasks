# Ежедневник на минутной шкале

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Даты и время](../dates/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-609?utm_source=github&utm_medium=tasks-repo)**

Реализуйте ежедневник одного дня. Время — минуты от начала суток, в сутках `1440` минут. Событие `[start, end)` занимает минуты от `start` включительно до `end` не включая. Сначала событий нет. Вам дан список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"add"` с аргументами `start`, `end`: добавить событие. Оно допустимо, если `0 <= start < end <= 1440` и не пересекается ни с одним из событий (события, где одно кончается там, где начинается другое, не пересекаются). Результат `1`, если событие добавлено, иначе `0` (и ежедневник не меняется).
- `"remove"` с аргументом `start`: убрать событие, которое начинается в минуту `start`; результат `1`, если оно было, иначе `0`.
- `"busy"` без аргументов: сколько минут занято всеми событиями.
- `"longest_free"` без аргументов: длина самого длинного свободного промежутка в сутках (`0`, если свободного времени нет).
- `"at"` с аргументом `minute`: время начала события, которому принадлежит минута `minute`, либо `-1`, если эта минута свободна.

Пример: `["add", "add", "busy", "longest_free", "at"]`, `[[60, 120], [100, 130], [], [], [60]]` → `[1, 0, 60, 1320, 60]`.
