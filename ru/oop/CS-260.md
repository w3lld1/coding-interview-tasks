# Урна для голосования

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Исключения](../errors/)

Реализуйте голосование. Сначала нет ни зарегистрированных избирателей, ни голосов. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Избиратели и кандидаты заданы целыми номерами. Верните список результатов, по одному на операцию.

Операции:
- `"register"` с аргументом `voter`: зарегистрировать избирателя; результат: число зарегистрированных. Если он уже зарегистрирован, сообщите об ошибке: бросьте исключение, в Go верните error.
- `"vote"` с аргументами `voter`, `candidate`: отдать голос; результат: число голосов за этого кандидата. Если избиратель не зарегистрирован или уже голосовал, сообщите об ошибке: бросьте исключение, в Go верните error.
- `"count"` с аргументом `candidate`: результат: число его голосов (`0`, если голосов нет).
- `"winner"` без аргументов: результат: кандидат с наибольшим числом голосов; при равенстве меньший номер; `-1`, если голосов ещё не было.

Ошибка относится ко всему вызову: первая же неверная операция прерывает его.

Пример: `["register", "vote", "winner"]`, `[[1], [1, 7], []]` → `[1, 1, 7]`.
