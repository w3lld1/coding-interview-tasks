# Недавно закрытые вкладки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-513?utm_source=github&utm_medium=tasks-repo)**

Браузер хранит открытые вкладки в порядке открытия (номер вкладки — целое число) и стопку недавно закрытых. Сначала всё пусто. Операции:
- `open` (id): если вкладки id нет среди открытых, открыть её в конец списка и, если она была среди закрытых, убрать её оттуда; если уже открыта, ничего не менять. Результат — число открытых вкладок;
- `close` (id): если вкладка id открыта, закрыть её (она кладётся на верх стопки закрытых), результат `1`; иначе ничего не происходит, результат `0`;
- `reopen`: вернуть последнюю закрытую вкладку: она снимается со стопки закрытых и открывается в конец списка; результат — её номер или `-1`, если закрытых нет;
- `count`: результат — число открытых вкладок;
- `last`: результат — номер последней открытой вкладки или `-1`, если открытых нет.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["open", "open", "open", "close", "close", "reopen", "last", "reopen", "last", "reopen", "count"]`, `[[1], [2], [3], [2], [3], [], [], [], [], [], []]` → `[1, 2, 3, 1, 1, 3, 3, 2, 2, -1, 3]`.
