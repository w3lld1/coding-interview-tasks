# Таблица лидеров с общими местами

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

Реализуйте таблицу лидеров игры. Игроки заданы целыми номерами, сначала таблица пуста. У игрока считается его **лучший** результат за все отправки. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"submit"` с аргументами `player`, `score`: учесть результат (лучший результат игрока не уменьшается); результат: лучший результат игрока после этого.
- `"rank"` с аргументом `player`: результат: место игрока, то есть `1` плюс число игроков со строго большим лучшим результатом (у равных результатов одно место, следующее место пропускается); `-1`, если игрока нет в таблице.
- `"player_at"` с аргументом `pos`: результат: номер игрока на позиции `pos` (с `1`) при порядке «лучший результат по убыванию, при равенстве меньший номер игрока первым»; `-1`, если `pos` вне `1..размер`.
- `"size"` без аргументов: результат: число игроков в таблице.

Пример: `["submit", "submit", "submit", "rank", "player_at"]`, `[[7, 50], [3, 80], [5, 50], [5], [2]]` → `[50, 80, 50, 2, 5]`.
