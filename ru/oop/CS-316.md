# Учёт рабочего времени по отметкам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Даты и время](../dates/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-316?utm_source=github&utm_medium=tasks-repo)**

Реализуйте табель одного сотрудника как список операций: `apply_operations(operations, values)` возвращает строку-результат для каждой операции (список той же длины). Время — минуты от начала недели, целое от 0 до 10080. Сначала сотрудник не на смене, отработанных минут нет.

Операции:
- `"clock_in"` `[minute]` — отметка начала смены. Результат `""`;
- `"clock_out"` `[minute]` — отметка конца смены; отработанная смена прибавляет `minute - начало` к итогу. Результат `""`;
- `"worked"` `[]` — сумма минут завершённых смен, строкой (открытая смена не считается);
- `"on_clock"` `[]` — `"true"`, если смена открыта, иначе `"false"`;
- `"last_shift"` `[]` — длина последней завершённой смены строкой, `"0"` если смен не было;
- `"overtime"` `[limit]` — `max(0, worked - limit)` строкой; `limit` должен быть неотрицательным.

Сообщите об ошибке (бросьте исключение, в Go верните error) для всего вызова, если: отметка вне диапазона 0…10080; отметка раньше предыдущей отметки (равное время допустимо); `clock_in` при открытой смене; `clock_out` без открытой смены; отрицательный `limit`. Первая же такая операция прерывает вызов.

Пример: `["clock_in", "clock_out", "worked", "on_clock"]`, `[[540], [1020], [], []]` → `["", "", "480", "false"]`.
