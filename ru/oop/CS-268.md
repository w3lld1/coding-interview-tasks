# Ячейки таблицы с формулами сумм

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-268?utm_source=github&utm_medium=tasks-repo)**

Реализуйте мини-таблицу. Ячейки заданы целыми номерами. Ячейка без содержимого равна `0`. Ячейка хранит либо число, либо формулу-сумму: сумму значений других ячеек. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"set_value"` с аргументами `cell`, `x`: записать в ячейку число `x`, заменив прежнюю формулу, если она была; результат всегда `1`.
- `"set_sum"` с аргументами `cell`, `d1`, …, `dk` (`k` ≥ 0): сделать содержимым ячейки сумму ячеек `d1…dk` (номер может повторяться, тогда ячейка входит в сумму несколько раз; при `k = 0` сумма равна `0`). Если после этого формулы зависели бы друг от друга по кругу (в том числе ячейка входит в собственную сумму прямо или через другие ячейки), операция отклоняется: таблица не меняется, результат `0`. Иначе результат `1`.
- `"get"` с аргументом `cell`: результат: текущее значение ячейки, формулы пересчитываются по актуальным значениям.

Пример: `["set_value", "set_value", "set_sum", "get", "set_value", "get"]`, `[[1, 5], [2, 7], [3, 1, 2], [3], [1, 10], [3]]` → `[1, 1, 1, 12, 1, 17]`.
