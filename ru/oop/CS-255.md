# Проездной баланс метро

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Исключения](../errors/)

Реализуйте карту метро с предоплатой. Сначала баланс равен `0`. Дан список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"top_up"` с одним аргументом `amount`: добавить `amount` к балансу; результат: новый баланс. Если `amount` ≤ 0, сообщите об ошибке: бросьте исключение, в Go верните error.
- `"ride"` с одним аргументом `fare`: списать стоимость поездки; результат: новый баланс. Если `fare` больше баланса, сообщите об ошибке: бросьте исключение, в Go верните error. Поездка ровно на весь баланс допустима.
- `"balance"` без аргументов: результат: текущий баланс.

Ошибка относится ко всему вызову: первая же неверная операция прерывает его, частичный результат не возвращается.

Пример: `["top_up", "ride", "balance"]`, `[[50], [18], []]` → `[50, 32, 32]`.
