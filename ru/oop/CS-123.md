# Хранилище значений во времени

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

Нужно реализовать хранилище, которое помнит все значения ключа в разные моменты времени. Функция получает список операций `operations` и список аргументов `values`: `values[i]` относится к `operations[i]`. Хранилище вначале пусто. Операции:

- `"set"` с аргументами `[key, value, timestamp]` запоминает значение `value` ключа `key` в момент `timestamp` и возвращает `0`. Для одного ключа моменты в операциях `set` строго возрастают.
- `"get"` с аргументами `[key, timestamp]` возвращает значение, записанное для `key` в самый поздний момент, который не больше `timestamp`. Если такого момента нет (или ключ не встречался), верните `-1`.

Значения неотрицательны. Верните список результатов, по одному на каждую операцию. Операций до 1000.

Пример: `["set", "get", "get", "set", "get"]`, `[[1, 10, 5], [1, 5], [1, 4], [1, 20, 8], [1, 9]]` → `[0, 10, -1, 0, 20]`.
