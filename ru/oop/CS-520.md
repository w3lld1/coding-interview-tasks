# Три очереди к кассам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

В магазине три кассы с номерами 0, 1, 2, и у каждой своя очередь, сначала все пусты. Покупатели получают номера 1, 2, 3, ... в порядке прихода. Операции:
- `join`: следующий покупатель встаёт в самую короткую очередь, а при равной длине — в очередь с наименьшим номером кассы; результат — номер этой кассы;
- `serve` (k): касса k обслуживает первого в своей очереди; результат — номер покупателя или `-1`, если очередь пуста;
- `length` (k): результат — длина очереди кассы k;
- `longest`: результат — номер кассы с самой длинной очередью, а при равной длине — наименьший номер.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["join", "join", "join", "join", "join", "longest", "length", "length", "length", "serve", "join", "serve", "serve", "serve", "longest"]`, `[[], [], [], [], [], [], [0], [1], [2], [0], [], [1], [1], [1], []]` → `[0, 1, 2, 0, 1, 0, 2, 2, 1, 1, 0, 2, 5, -1, 0]`.
