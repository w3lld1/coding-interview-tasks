# Секундомер с кругами

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Даты и время](../dates/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-100?utm_source=github&utm_medium=tasks-repo)**

Секундомер хранит состояние (`ready` — начальное, `running`, `stopped`), время текущего круга и список завершённых кругов. Функция получает список операций `operations` и список аргументов `values` (в `values[i]` аргументы операции `operations[i]`, пустой список, если их нет) и возвращает список результатов — по одному на операцию. Исходно секундомер в состоянии `ready`, время 0.

Операции:
- `"start"` (из `ready` или `stopped` → `running`) — время идёт; из `running` — ошибка;
- `"stop"` (из `running` → `stopped`); из других состояний — ошибка;
- `"lap"` (только в `running`) — добавляет текущий круг в завершённые и обнуляет его, состояние `running`; иначе ошибка;
- `"reset"` (из `stopped` → `ready`) — обнуляет текущий круг и очищает завершённые; иначе ошибка;
- `"advance_time"` с аргументом `"ЧЧ:ММ:СС"` — прошло это время; учитывается только в `running`, в других состояниях игнорируется;
- `"state"` → название состояния; `"current_lap"` → время текущего круга; `"total"` → общее время (завершённые круги плюс текущий); `"previous_laps"` → времена завершённых кругов через запятую (без пробелов), пустая строка, если их нет.

Время пишется как `ЧЧ:ММ:СС`, каждая часть минимум из двух цифр (формат `%02d`). Результат операции, которая ничего не возвращает (`start`, `stop`, `lap`, `reset`, `advance_time`), — `""`, а при недопустимой операции — `"error"` (состояние при этом не меняется).

Пример: `["start", "advance_time", "lap", "previous_laps"]`, `[[], ["00:01:38"], [], []]` → `["", "", "", "00:01:38"]`.
