# Стопка с доступом к середине

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Стопка коробок хранит целые неотрицательные числа, сначала пуста. «Серединой» стопки из n коробок называется коробка с номером `n / 2` (деление нацело), если считать номера от дна с нуля. Так, у стопки из 1 коробки середина — она сама, у стопки из 4 коробок — третья снизу. Операции:
- `push` (x): положить коробку x наверх; результат — размер стопки;
- `pop`: снять верхнюю коробку; результат — её число или `-1`, если стопка пуста;
- `middle`: результат — число средней коробки (она остаётся на месте) или `-1`, если стопка пуста;
- `pop_middle`: вытащить среднюю коробку, остальные сохраняют порядок; результат — её число или `-1`, если стопка пуста.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["push", "push", "push", "middle", "push", "middle", "pop_middle", "middle", "pop", "pop_middle", "pop_middle", "middle"]`, `[[10], [20], [30], [], [40], [], [], [], [], [], [], []]` → `[1, 2, 3, 20, 4, 30, 30, 20, 40, 20, 10, -1]`.
