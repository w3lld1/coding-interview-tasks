# Кольцевой буфер показаний

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Датчик хранит только последние k показаний (неотрицательные целые): новое показание вытесняет самое старое, когда место кончилось. Первая операция всегда `start`. Реализуйте операции:
- `start` (k): создать пустой буфер ёмкости k (k ≥ 1), забыв прежний; результат `0`;
- `add` (x): добавить показание. Если буфер был полон, самое старое показание вытесняется и результат — его значение; иначе результат `-1`;
- `sum`: результат — сумма показаний в буфере (`0` для пустого);
- `max`: результат — наибольшее показание в буфере или `-1`, если буфер пуст.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["start", "add", "add", "add", "add", "sum", "max"]`, `[[3], [5], [8], [2], [9], [], []]` → `[0, -1, -1, -1, 5, 19, 9]`.
