# Школьный журнал

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-55?utm_source=github&utm_medium=tasks-repo)**

Реализуйте школьный журнал, который начинает работу пустым, и выполните над ним список операций. Операция `operations[i]` получает аргументы `values[i]` (все — строки), результат каждой операции — одна строка; ответ — список этих строк по порядку.

- `"add"`, аргументы `[имя, класс]` (класс — десятичное число строкой): добавляет ученика. Ученик не может быть добавлен дважды, даже в другой класс или в тот же. Результат: `"true"`, если ученик добавлен, и `"false"`, если такое имя уже есть (журнал не меняется).
- `"grade"`, аргумент `[класс]`: результат — имена учеников этого класса по алфавиту через запятую, без пробелов; если учеников нет — пустая строка `""`.
- `"roster"`, без аргументов: результат — имена всех учеников через запятую: сначала по возрастанию класса, внутри класса по алфавиту. Журнал пуст — пустая строка.

Имена состоят из одного слова без запятых и сравниваются как обычные строки.

Пример: операции `["add", "add", "roster"]`, значения `[["Jim", "2"], ["Anna", "1"], []]` → `["true", "true", "Anna,Jim"]`.
