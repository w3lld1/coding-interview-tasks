# Талоны в пекарне

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

В пекарне выдают талоны с номерами 1, 2, 3, … по порядку, и людей обслуживают в порядке талонов. Сначала очередь пуста. Реализуйте операции (у них нет аргументов, `values[i]` — пустой список):
- `take`: новый покупатель берёт следующий талон и встаёт в конец очереди; результат — номер талона;
- `serve`: обслужить первого в очереди; результат — его номер, а для пустой очереди `0`;
- `step_aside`: первый в очереди пропускает двоих следующих и встаёт сразу за ними (если людей после него меньше двух, встаёт в конец; если он один, ничего не меняется). Результат — номер нового первого в очереди или `0`, если очередь пуста;
- `waiting`: результат — число людей в очереди.

Верните список результатов, по одному на операцию.

Пример: `["take", "take", "take", "take", "step_aside", "serve", "serve", "waiting"]`, `[[], [], [], [], [], [], [], []]` → `[1, 2, 3, 4, 2, 2, 3, 2]`.
