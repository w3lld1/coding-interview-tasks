# Кэш со сроком жизни и ограниченной ёмкостью

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

Реализуйте кэш на `capacity` записей (`capacity` ≥ 1), сначала пустой. Ключи — целые числа, значения — целые числа ≥ 0. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Первый аргумент каждой операции — текущее время `now`; оно не убывает от операции к операции. Верните список результатов, по одному на операцию.

Запись, положенная в момент `t` со сроком жизни `ttl`, живёт, пока `now` < `t + ttl`; в начале каждой операции все записи с `t + ttl` ≤ `now` исчезают. Использованием записи считаются `put` и успешный `get`; из двух использований более поздним считается то, что идёт в списке дальше.

Операции:
- `"put"` с аргументами `now`, `key`, `value`, `ttl` (`ttl` ≥ 1): положить запись. Если ключ уже есть, его значение и срок заменяются. Если ключа нет, а живых записей уже `capacity`, сначала вытесняется запись, которая истекает раньше всех; при равном сроке — та, которой дольше всех не пользовались. Результат: вытесненный ключ или `-1`, если никого не вытеснили (исчезновение по сроку вытеснением не считается).
- `"get"` с аргументами `now`, `key`: значение живой записи или `-1`. Срок записи не меняется.
- `"size"` с аргументом `now`: число живых записей.
- `"ttl"` с аргументами `now`, `key`: сколько записи осталось жить (`t + ttl − now`) или `-1`, если её нет.

До 2000 операций.

Пример: `2`, `["put", "put", "get", "put", "get"]`, `[[0, 1, 10, 5], [0, 2, 20, 5], [1, 1], [2, 3, 30, 9], [2, 1]]` → `[-1, -1, 10, 2, 10]`.
