# Стопки тарелок по три

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

В столовой тарелки ставят в стопки не выше 3 штук. Стопки стоят в ряд и пронумерованы с 0 слева направо; сначала их нет. Тарелка — целое число. Операции:
- `push` (x): поставить тарелку x на последнюю стопку, а если стопок нет или в последней уже 3 тарелки, начать новую стопку справа; результат — число стопок;
- `pop`: взять верхнюю тарелку последней стопки; результат — её число или `-1`, если стопок нет;
- `pop_at` (i): взять верхнюю тарелку стопки с номером i; результат — её число или `-1`, если такой стопки нет. Остальные стопки не перестраиваются;
- `stacks`: результат — число стопок;
- `total`: результат — число всех тарелок.

Опустевшая стопка пропадает, номера стопок правее неё уменьшаются на 1.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["push", "push", "push", "push", "push", "stacks", "total", "pop_at", "pop", "pop", "stacks", "total"]`, `[[1], [2], [3], [4], [5], [], [], [0], [], [], [], []]` → `[1, 1, 1, 2, 2, 2, 5, 3, 5, 4, 1, 2]`.
