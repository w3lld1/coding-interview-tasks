# Лист ожидания по номеру срочности

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-517?utm_source=github&utm_medium=tasks-repo)**

Клиника ведёт лист ожидания, отсортированный по возрастанию номера срочности (целое число от 0 до 1000); меньший номер значит, что пациент срочнее. Сначала лист пуст; одинаковые номера допускаются. Операции:
- `add` (x): вставить номер x так, чтобы лист остался отсортированным, равные номера идут в порядке вставки (новый — после уже имеющихся равных); результат — длина листа;
- `pop_min`: убрать и вернуть первый (наименьший) номер, `-1`, если лист пуст;
- `pop_max`: убрать и вернуть последний (наибольший) номер, `-1`, если лист пуст;
- `nth` (i): вернуть i-й номер листа, считая с 1, не убирая его; `-1`, если такого места нет;
- `remove` (x): убрать один номер x (первый из равных); результат `1`, если он был, иначе `0`;
- `count_below` (x): результат — сколько номеров в листе строго меньше x;
- `count`: результат — длина листа.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["add", "add", "add", "add", "nth", "nth", "count_below", "remove", "nth", "pop_min", "pop_max", "count"]`, `[[40], [10], [30], [20], [1], [3], [30], [30], [3], [], [], []]` → `[1, 2, 3, 4, 10, 30, 2, 1, 40, 10, 40, 1]`.
