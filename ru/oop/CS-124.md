# Массив со снимками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

Дан массив из `length` ячеек, вначале заполненный нулями. Функция получает `length`, список операций `operations` и список аргументов `values` (`values[i]` относится к `operations[i]`, у `"snap"` он пуст). Операции:

- `"set"` с `[index, value]` записывает `value` в ячейку `index` и возвращает `0`.
- `"snap"` сохраняет снимок всего массива и возвращает его номер; номера идут с `0` по порядку.
- `"get"` с `[index, snap_id]` возвращает значение ячейки `index` на момент снимка `snap_id` (записи, сделанные после этого снимка, не учитываются). Номер `snap_id` всегда уже существует.

Верните список результатов, по одному на операцию. `length` до 1000, операций до 1000; копировать весь массив при каждом снимке не нужно.

Пример: `2`, `["set", "snap", "set", "get", "get"]`, `[[0, 5], [], [0, 6], [0, 0], [1, 0]]` → `[0, 0, 0, 5, 0]`.
