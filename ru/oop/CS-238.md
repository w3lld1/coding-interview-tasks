# Очередь ожидания в колл-центре

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Звонящие ждут ответа оператора в порядке звонков; сначала очередь пуста. Звонящий — положительное число (идентификатор), в очереди идентификаторы не повторяются. Реализуйте операции:
- `call` (id): звонящий встаёт в конец очереди; результат — длина очереди после этого;
- `answer`: оператор отвечает тому, кто ждёт дольше всех, и он покидает очередь; результат — его id, а для пустой очереди `-1`;
- `hangup` (id): звонящий сам кладёт трубку. Если он был в очереди, он убирается из неё и результат `1`; иначе `0`;
- `position` (id): результат — место звонящего в очереди (первый стоит на месте `1`) или `0`, если его там нет.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["call", "call", "call", "hangup", "position", "answer", "answer", "answer"]`, `[[11], [12], [13], [12], [13], [], [], []]` → `[1, 2, 3, 1, 2, 11, 13, -1]`.
