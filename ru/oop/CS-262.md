# Шагомер по дням

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-262?utm_source=github&utm_medium=tasks-repo)**

Реализуйте шагомер с историей по дням. Сначала идёт один день с `0` шагов; он считается текущим. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"add"` с аргументом `steps`: добавить шаги к текущему дню; результат: сумма шагов текущего дня.
- `"new_day"` без аргументов: закрыть текущий день и начать новый с `0` шагов; результат: число закрытых дней.
- `"best"` без аргументов: результат: наибольшая сумма шагов за один день среди всех дней, включая текущий.
- `"goal_days"` с аргументом `goal`: результат: сколько дней, включая текущий, набрали не меньше `goal` шагов.

Пример: `["add", "new_day", "add", "goal_days"]`, `[[5], [], [9], [6]]` → `[5, 1, 9, 1]`.
