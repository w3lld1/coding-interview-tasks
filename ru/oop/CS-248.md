# Очередь воспроизведения

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

Плеер хранит очередь песен (положительные числа), историю прослушанного и текущую песню (`0`, если ничего не играет). Сначала всё пусто. Реализуйте операции:
- `add` (песня): поставить в конец очереди; результат — длина очереди;
- `play_next` (песня): поставить в начало очереди, чтобы она играла следующей; результат — длина очереди;
- `skip`: если очередь не пуста, текущая песня (если есть) уходит в историю, а текущей становится первая песня очереди; при пустой очереди ничего не меняется. Результат — текущая песня;
- `previous`: если история не пуста, текущая песня (если есть) возвращается в начало очереди, а текущей становится последняя песня из истории; при пустой истории ничего не меняется. Результат — текущая песня;
- `now`: результат — текущая песня.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i`.

Пример: `["add", "add", "add", "skip", "skip", "previous", "play_next", "skip", "now"]`, `[[1], [2], [3], [], [], [], [9], [], []]` → `[1, 2, 3, 1, 2, 1, 3, 9, 9]`.
