# Стеллаж с делением ячеек пополам

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Математика](../math/)

На складе стеллаж из `2^levels` ячеек с адресами `0 … 2^levels − 1` (`levels` от 0 до 30) раздаётся блоками по системе «близнецов». Блок размера `2^k` начинается с адреса, кратного `2^k`; его близнец — соседний блок того же размера, вместе они образуют блок размера `2^(k+1)` (адрес близнеца — адрес блока, у которого переключён бит `2^k`). Сначала весь стеллаж — один свободный блок. Свободные близнецы всегда сразу сливаются.

Дан список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию. Для запроса `n ≥ 1` нужен размер `2^k` — наименьшая степень двойки, не меньшая `n`.

- `"alloc"` `[n]`: среди свободных блоков размера не меньше `2^k` возьмите самый маленький, из таких — с наименьшим адресом; делите его пополам, оставляя левую половину и освобождая правую, пока размер не станет `2^k`. Результат — адрес блока или `-1`, если подходящего нет.
- `"free"` `[addr]`: если по адресу `addr` начинается выданный блок, освободите его и сливайте с близнецами, пока это возможно; результат — размер получившегося свободного блока. Иначе `-1`.
- `"resize"` `[addr, n]`: если по `addr` нет выданного блока — `-1`. Если `2^k` не больше текущего размера, блок уменьшается на месте (правые половины освобождаются), результат `addr`. Если больше: блок растёт на месте, когда `addr` кратен `2^k` и все правые близнецы на пути до размера `2^k` свободны целиком — результат `addr`; иначе блок освобождается (со слиянием) и выдаётся заново, как в `alloc`, результат — новый адрес. Если и так места нет, всё остаётся как было, результат `-1`.
- `"largest"` `[]`: размер наибольшего свободного блока, `0`, если свободных нет.

Пример: `4`, `["alloc", "alloc", "alloc", "largest", "free", "free"]`, `[[3], [5], [1], [], [0], [4]]` → `[0, 8, 4, 2, 4, 8]`.
