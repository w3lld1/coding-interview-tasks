# Касса с экспресс-линией

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Классы и ООП](../oop/), [Стек, очередь, связные списки](../stacks-lists/)

В магазине две очереди к одной кассе: экспресс (для покупателей не более чем с 5 товарами) и обычная. Сначала обе пусты. Операции:
- `join` (n): покупатель с n товарами встаёт в конец экспресс-очереди, если n не больше 5, иначе в конец обычной; результат — общее число ожидающих;
- `serve`: кассир обслуживает следующего покупателя. Обычно это первый из экспресс-очереди, но если подряд уже обслужено не менее двух экспресс-покупателей и в обычной очереди кто-то есть, то обслуживается первый из обычной очереди. Если экспресс-очередь пуста, обслуживается первый из обычной. Обслуживание покупателя из обычной очереди обнуляет счётчик подряд обслуженных экспресс-покупателей. Результат — число товаров обслуженного покупателя или `0`, если никого нет;
- `waiting`: результат — общее число ожидающих;
- `express_waiting`: результат — число ожидающих в экспресс-очереди.

Верните список результатов, по одному на операцию. `values[i]` — аргументы операции `i` (пустой список, если их нет).

Пример: `["join", "join", "join", "join", "join", "waiting", "express_waiting", "serve", "serve", "serve", "serve", "serve", "serve"]`, `[[3], [12], [4], [2], [20], [], [], [], [], [], [], [], []]` → `[1, 2, 3, 4, 5, 5, 3, 3, 4, 12, 2, 20, 0]`.
