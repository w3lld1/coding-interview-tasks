# K-я скобочная последовательность

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-31?utm_source=github&utm_medium=tasks-repo)**

Правильная скобочная последовательность из `n` пар — строка из `n` символов `(` и `n` символов `)`, которую можно полностью стереть, убирая соседние пары `()`. Все такие строки упорядочены лексикографически, при этом `(` меньше `)`. Верните `k`-ю по порядку (нумерация с 1). Если последовательностей меньше `k`, верните пустую строку.

Ограничения: `1 ≤ n ≤ 100`, `1 ≤ k ≤ 9·10^15`. Количество последовательностей может не поместиться в 64-битное число.

Пример: `3`, `4` → `"()(())"`; все пять строк для `n = 3`: `((()))`, `(()())`, `(())()`, `()(())`, `()()()`.
