# Лягушка на камнях через реку

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Словари и множества](../hashing/)

Через реку лежат камни; список `stones` строго по возрастанию содержит их координаты, первый камень всегда в точке `0` (там сидит лягушка), последний — на другом берегу. Лягушка прыгает только вперёд и только с камня на камень. Первый прыжок — ровно на `1`. Если предыдущий прыжок был длиной `k`, следующий может быть длиной `k - 1`, `k` или `k + 1` (длина всегда положительна). Верните `true`, если лягушка может добраться до последнего камня, иначе `false`. Если камень один, лягушка уже на месте: ответ `true`. Камней — до 2000, координаты — до 10⁹.

Пример: `[0, 1, 3, 5, 6, 8, 12, 17]` → `true` (прыжки 1, 2, 2, 3, 4, 5).
