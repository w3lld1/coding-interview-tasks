# Печать на линейной клавиатуре

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-44?utm_source=github&utm_medium=tasks-repo)**

Клавиатура — это один ряд из M клавиш; на клавише `j` (с нуля) записан символ `keyboard[j]`, символы — целые числа, и одинаковые символы могут встречаться на нескольких клавишах. Нужно набрать слово `word` (N символов), символ за символом по порядку; каждый символ слова встречается на клавиатуре.

Палец можно поставить на любую клавишу в начале. Перемещение пальца с клавиши `i` на клавишу `j` занимает `|j − i|` секунд, нажатий нет: когда палец стоит на клавише `x`, любое число раз подряд можно мгновенно «набрать» её символ `keyboard[x]`. Верните наименьшее время, за которое можно набрать слово (N, M ≤ 2500).

Пример: `[1, 2, 3, 2, 1]`, `[3, 1, 2, 3]` → `4`.
