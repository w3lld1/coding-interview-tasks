# Сколькими способами вычеркнуть до нужной строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-88?utm_source=github&utm_medium=tasks-repo)**

Даны строки `s` и `t` из строчных латинских букв (длина `s` от 0 до 50, длина `t` от 0 до 50). Из `s` можно вычеркнуть любые символы так, чтобы оставшиеся по порядку образовали `t`. Верните число различных способов это сделать: два способа различны, если различаются множества позиций `s`, которые остались. Если `t` пустая, способ ровно один (вычеркнуть всё), ответ `1`; если `t` длиннее `s` или не получается ни одним способом, ответ `0`. Ответ помещается в 64-битное целое.

Пример: `"abbcbc"`, `"abc"` → `5`.
