# Произведение цифр делится на сумму

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-110?utm_source=github&utm_medium=tasks-repo)**

Назовём положительное целое число интересным, если произведение его цифр делится на сумму его цифр. Например, `451` интересно (`4·5·1 = 20` делится на `4 + 5 + 1 = 10`), а любое число с цифрой `0` интересно, потому что произведение равно `0`. Даны числа `a` и `b`; верните количество интересных чисел на отрезке от `a` до `b` включительно.

Ограничения: `1 ≤ a ≤ b ≤ 10^8`; перебор всех чисел отрезка слишком медленный.

Пример: `451`, `460` → `5` (числа 451, 453, 456, 459 и 460).
