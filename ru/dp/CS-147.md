# Сколько путей с наименьшей суммой в треугольнике

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

Дан треугольник чисел: в строке с номером `i` (с нуля) ровно `i + 1` чисел, числа могут быть отрицательными. Путь начинается в единственном числе первой строки и на каждом шаге спускается на строку ниже: из позиции `j` либо в позицию `j`, либо в позицию `j + 1` следующей строки. Сумма пути — сумма всех чисел, которые он посетил. Верните, сколько различных путей (от верха до последней строки) имеют наименьшую возможную сумму. Пути различаются набором выбранных позиций. Для пустого треугольника верните `0`. Строк не больше 20.

Пример: `[[1], [2, 2], [3, 1, 3]]` → `2` (минимальная сумма 4: путь 1 → 2 → 1 можно пройти через любую из двух двоек; а `[[1], [2, 2], [3, 3, 3]]` → `4`).
