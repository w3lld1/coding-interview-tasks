# Минимальное число монет

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-16?utm_source=github&utm_medium=tasks-repo)**

Для набора положительных номиналов и требуемой суммы найдите набор монет с минимальным общим количеством. Монет каждого номинала доступно неограниченно, а результат нужно вернуть списком номиналов по возрастанию. Для нулевой суммы верните пустой список, для отрицательной или недостижимой суммы сообщите об ошибке: бросьте исключение, в Go верните error. Номиналы произвольны, поэтому выбор самой крупной подходящей монеты не гарантирует правильного ответа.
