# Самая дешёвая стирка партиями

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

В прачечной в ряд лежат `n` партий белья. Партию `i` можно постирать отдельно за `single[i]`, а две соседние партии `j` и `j + 1` — вместе за `pair[j]`. Каждая партия стирается ровно один раз, партии не переставляют. Верните наименьшую суммарную цену. В списке `single` `n` чисел, в `pair` — `n - 1` чисел (для `n` = 0 и `n` = 1 список `pair` пуст); все числа целые и не меньше 0, `n` не больше 1000.

Пример: `single = [5, 4, 6]`, `pair = [7, 8]` → `13` (первые две партии вместе за 7 и третья отдельно за 6).
