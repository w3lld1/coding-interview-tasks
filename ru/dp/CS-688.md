# Стоянка, где машины стоят колоннами

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-688?utm_source=github&utm_medium=tasks-repo)**

Вдоль улицы в один ряд идут `n` парковочных мест. Каждое место либо свободно, либо занято. Правило стоянки: занятые места образуют колонны, то есть группы подряд идущих занятых мест, и в каждой колонне не меньше `k` мест. Две колонны всегда разделены хотя бы одним свободным местом (иначе это одна колонна). Верните число разных схем стоянки — способов отметить места занятыми и свободными по этому правилу. Полностью пустая улица — тоже схема. `n` от 0 до 50, `k` от 1 до 50; для `n = 0` ответ `1`; ответ может не поместиться в 32 бита.

Пример: `4`, `3` → `4` (`....`, `###.`, `.###`, `####`, где `#` — занятое место).
