# Расписание работ с наименьшей сложностью

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Стек, очередь, связные списки](../stacks-lists/), [Массивы и списки](../arrays/)

Дан список `jobs`: сложности работ в том порядке, в котором их нужно выполнить, и число дней `days`. Работы распределяются по дням подряд: каждый день берёт следующий непрерывный кусок списка, и в каждый день выполняется хотя бы одна работа. Сложность дня равна наибольшей сложности работы этого дня, сложность расписания равна сумме сложностей всех дней. Верните наименьшую возможную сложность расписания. Если работ меньше, чем дней (в том числе при пустом списке), верните `-1`.

Ограничения: до 2000 работ, сложность каждой от 0 до 1000, `1 ≤ days ≤ 10`. Решение за O(n²·days) на самом большом тесте может не уложиться во время, нужно O(n·days).

Пример: `[6, 5, 4, 3, 2, 1]`, `2` → `7` (первый день `[6, 5, 4, 3, 2]` со сложностью 6, второй `[1]` со сложностью 1).
