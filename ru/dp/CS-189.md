# Самые выгодные непересекающиеся заказы

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-189?utm_source=github&utm_medium=tasks-repo)**

Даны три списка одной длины: заказ `i` начинается в момент `start[i]`, заканчивается в момент `end[i]` (`start[i] < end[i]`) и приносит `profit[i]`. Одновременно можно выполнять только один заказ; следующий может начаться ровно в тот момент, когда закончился предыдущий. Выберите набор заказов, никакие два из которых не пересекаются по времени, с наибольшей суммарной прибылью, и верните эту сумму. Если заказов нет, верните `0`. Заказов — до 20 000, моменты — от 0 до 10⁹, прибыль — от 1 до 10 000.

Пример: `[1, 2, 3, 3]`, `[3, 4, 5, 6]`, `[50, 10, 40, 70]` → `120` (заказы 0 и 3).
