# Обратный отсчёт до единицы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-438?utm_source=github&utm_medium=tasks-repo)**

Дано натуральное число `n`. За один ход можно сделать одно из трёх: вычесть 1; разделить на 2, если число чётное; разделить на 3, если оно делится на 3. Верните наименьшее число ходов, за которое `n` превращается в 1. Для `n` = 1 ответ 0. Ограничения: `n` от 1 до 10 000.

Жадный выбор («всегда делить, если можно») здесь ошибается; нужна таблица ответов для всех меньших чисел. Это же можно записать рекурсией с запоминанием: ответ для `m` на единицу больше лучшего из ответов для чисел, куда ведёт один ход.

Пример: `10` → `3` (10 → 9 → 3 → 1).
