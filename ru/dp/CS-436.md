# Самая длинная зигзагообразная подпоследовательность

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

Дан список чисел `values`. Подпоследовательность получается вычёркиванием любых элементов без перестановки остальных. Назовём её зигзагом, если разности соседних её элементов строго чередуют знак: плюс, минус, плюс… или минус, плюс, минус… Подпоследовательность из одного элемента — зигзаг, из двух — зигзаг, если элементы различны. Верните длину самого длинного зигзага. Для пустого списка ответ 0. Ограничения: до 1000 элементов.

У каждого элемента есть два состояния: зигзаг заканчивается подъёмом или спуском.

Пример: `[1, 7, 4, 9, 2, 5]` → `6` (разности +6, −3, +5, −7, +3).
