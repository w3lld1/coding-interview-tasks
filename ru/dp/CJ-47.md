# Перестановка блоков перед RLE

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-47?utm_source=github&utm_medium=tasks-repo)**

Дано число `k` и строка `text` из строчных латинских букв, длина которой кратна `k`. Строка делится на блоки по `k` подряд идущих букв. Выберите перестановку `p` позиций `1..k` и примените её к каждому блоку (одну и ту же ко всем): `j`-й буквой нового блока становится `p[j]`-я буква старого. Например, перестановка `[3, 1, 4, 2]` превращает `"abcdefgh"` в `"cadbgehf"`.

Сжатый размер строки — число максимальных групп подряд идущих одинаковых букв: у `"aabcaaaa"` он равен 4. Верните наименьший сжатый размер, который можно получить, выбрав перестановку.

Ограничения: `1 ≤ k ≤ 10`, длина строки от `k` до 2000.

Пример: `4`, `"abcabcabcabc"` → `7`.
