# Наименьшее число разрезов на палиндромы

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-89?utm_source=github&utm_medium=tasks-repo)**

Дана строка `s` из строчных латинских букв (длина от 0 до 1000). Её нужно разрезать на непустые куски так, чтобы каждый кусок был палиндромом (читался одинаково слева направо и справа налево). Верните наименьшее число разрезов. Строка, которая сама палиндром, и пустая строка дают `0`; строка из одного символа — тоже `0`.

Пример: `"abacc"` → `1` (`"aba" | "cc"`).
