# Броски кубиков на нужную сумму

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-431?utm_source=github&utm_medium=tasks-repo)**

Бросают `dice` обычных шестигранных кубиков с гранями от 1 до 6. Кубики различимы по порядку: исход `(1, 2)` отличается от `(2, 1)`. Верните, сколькими исходами выпадает сумма ровно `target`. Для `dice` = 0 сумма равна 0: при `target` = 0 исход один, при остальных `target` ноль. Если `target` отрицателен или слишком велик, ответ 0. Ограничения: `dice` от 0 до 8, `target` не больше 60.

Посмотрите на последний кубик: если он показал `f`, то остальные `dice - 1` кубиков дали `target - f`.

Пример: `2`, `7` → `6` (1+6, 2+5, 3+4, 4+3, 5+2, 6+1).
