# Минимум переводов для погашения долгов

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

Компания друзей записала долги: каждая запись `[a, b, x]` означает, что человек `a` должен человеку `b` сумму `x`. Люди обозначены числами от `0` до `11`, в записи `a ≠ b`, `1 ≤ x ≤ 1000`, записей не больше 50. Один перевод — это передача любой целой суммы от одного человека другому. Верните наименьшее число переводов, после которых все долги погашены: у каждого человека итоговый баланс (сколько ему должны минус сколько должен он) равен нулю. Если долгов нет или все они взаимно гасятся, ответ `0`.

Пример: `[[0, 1, 10], [1, 2, 10]]` → `1` (человек `0` переводит `10` человеку `2`).
