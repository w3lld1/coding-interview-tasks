# Жонглёры бензопилами

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-76?utm_source=github&utm_medium=tasks-repo)**

У вас `red` красных и `blue` синих бензопил (`0 ≤ red, blue ≤ 100`, `red + blue > 0`) и сколько угодно жонглёров. Нужно раздать все пилы: каждый выступающий жонглёр получает пару чисел (сколько у него красных и сколько синих пил), хотя бы одна пила у каждого, и никакие два жонглёра не получают одинаковую пару. Иначе говоря, выберите набор различных пар `(r, b)` из неотрицательных целых, кроме `(0, 0)`, у которого сумма первых чисел ровно `red`, а вторых ровно `blue`.

Верните наибольшее возможное число жонглёров (размер такого набора).

Пример: `4`, `5` → `5` (пары `(1,0)`, `(2,0)`, `(0,1)`, `(0,3)`, `(1,1)`).
