# Акции с днём отдыха после продажи

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-144?utm_source=github&utm_medium=tasks-repo)**

Дан список цен акции по дням (до 5000 дней, цены от 0 до 10000). За день можно сделать одно действие: купить одну акцию, продать её или ничего не делать. Держать больше одной акции нельзя, то есть новую можно купить только после продажи прежней. После продажи следующий день обязательно «отдых»: покупать в него нельзя. Сделок можно совершать сколько угодно. Верните максимальную прибыль; для пустого списка и если прибыль невозможна — `0`.

Пример: `[1, 2, 3, 0, 2]` → `3` (купить за 1, продать за 2, отдых, купить за 0, продать за 2).
