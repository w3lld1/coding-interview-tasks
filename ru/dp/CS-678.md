# Гирлянда: сначала выключенные, потом горящие

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-678?utm_source=github&utm_medium=tasks-repo)**

Ряд лампочек задан строкой `lamps` из символов `'0'` (лампочка выключена) и `'1'` (горит). Одним переключением можно изменить состояние одной любой лампочки. Нужно, чтобы все выключенные лампочки шли раньше всех горящих: строка должна иметь вид «сначала только `0`, потом только `1`» (любая из частей может быть пустой). Верните наименьшее число переключений. Длина строки от 0 до 10 000; для пустой строки ответ `0`.

Пример: `"00110"` → `1` (включить последнюю лампочку: `"00111"`).
