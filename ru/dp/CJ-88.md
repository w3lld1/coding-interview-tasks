# Робот-уборщик мячей

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Словари и множества](../hashing/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-88?utm_source=github&utm_medium=tasks-repo)**

На бесконечной прямой стоят станции с номерами …, −2, −1, 0, 1, 2, …; на станции 0 — склад. Дан список `balls`: каждый элемент `[x, s]` — мяч на станции `x` (`x ≠ 0`, все `x` различны) формы `s` (`0` или `1`). Робот стоит на станции 0, у него два отсека: один вмещает один мяч формы 0, другой — один мяч формы 1.

Перейти на соседнюю станцию стоит 1 единицу энергии. Взять мяч со своей станции в свободный отсек его формы — бесплатно. Сжать мяч на своей станции, сменив его форму на другую, стоит `compress_cost` (мяч уже в отсеке менять нельзя). На станции 0 можно бесплатно выгрузить все мячи из отсеков на склад.

Верните наименьшую энергию, за которую робот перенесёт все мячи на склад. Мячей до нескольких тысяч, координаты по модулю до `10^9`, `0 ≤ compress_cost ≤ 10^9`. Пустой список даёт `0`.

Пример: `[[3, 0], [6, 0], [8, 0], [10, 1], [15, 1]]`, `10` → `56`.
