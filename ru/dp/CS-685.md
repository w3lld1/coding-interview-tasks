# Упаковка партии в коробки по уровням

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Рекурсия и перебор](../recursion/), [Математика](../math/)

На складе партию из `n` одинаковых деталей упаковывают по уровням. На первом уровне детали делят на равные группы по `d1 > 1` штук, на втором группы складывают в коробки по `d2 > 1` групп, и так далее, пока не останется одна большая коробка: `d1 · d2 · … · dk = n`. Схема упаковки — это упорядоченный список множителей `[d1, d2, …, dk]`, каждый больше 1; схемы с теми же множителями в другом порядке различны. Верните число разных схем. Для `n = 1` схема одна — пустая (упаковывать нечего). `n` от 1 до 10^6.

Пример: `12` → `8` (`[12]`, `[2, 6]`, `[6, 2]`, `[3, 4]`, `[4, 3]`, `[2, 2, 3]`, `[2, 3, 2]`, `[3, 2, 2]`).
