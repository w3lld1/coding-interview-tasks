# Самая длинная арифметическая подпоследовательность

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-148?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел от 0 до 500 (до 1000 элементов). Подпоследовательность получается удалением части элементов без смены порядка оставшихся. Она арифметическая, если разность между каждыми двумя соседними её элементами одна и та же (подпоследовательность из одного или двух элементов тоже арифметическая; разность может быть нулевой или отрицательной). Верните длину самой длинной арифметической подпоследовательности. Для пустого списка верните `0`.

Пример: `[9, 4, 7, 2, 10]` → `3` (подпоследовательность `4, 7, 10` с разностью 3).
