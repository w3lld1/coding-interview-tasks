# Сколько наборов дают нужную сумму

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-442?utm_source=github&utm_medium=tasks-repo)**

Дан список натуральных чисел `values` и число `target`. Верните, сколькими способами можно выбрать из списка набор элементов, сумма которых ровно `target`. Каждый элемент либо берётся, либо нет, использовать один и тот же элемент дважды нельзя; наборы различаются выбранными позициями, поэтому равные числа в разных позициях дают разные наборы. Пустой набор имеет сумму 0. Ограничения: до 20 элементов, значения от 1 до 100, `target` от 0 до 1000.

Каждый элемент разделяет подсчёт на два случая: он в наборе (остаётся набрать `target - v`) или нет (остаётся набрать `target` из остальных).

Пример: `[1, 1, 1]`, `2` → `3` (любые две позиции из трёх).
