# Подъём без двух прыжков подряд

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-443?utm_source=github&utm_medium=tasks-repo)**

Лестница состоит из `n` ступеней. За один ход можно подняться на 1 ступень (шаг) или на 2 ступени (прыжок), но два прыжка подряд делать нельзя: между прыжками должен быть хотя бы один шаг. Нужно оказаться ровно на ступени `n`. Верните число различных последовательностей ходов. Для `n` = 0 последовательность одна, пустая. Ограничения: `n` от 0 до 40.

При подсчёте важно знать, чем закончилась последовательность: шагом (тогда дальше можно и шаг, и прыжок) или прыжком (тогда только шаг).

Пример: `4` → `4` (1+1+1+1, 1+1+2, 1+2+1, 2+1+1; последовательность 2+2 запрещена).
