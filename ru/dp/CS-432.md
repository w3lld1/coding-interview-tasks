# Продажа ленты по кускам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-432?utm_source=github&utm_medium=tasks-repo)**

В магазине есть лента длиной `n` метров, где `n` — длина списка `prices`. Кусок целой длины `k` метров продаётся за `prices[k - 1]`, цены неотрицательны и не обязаны расти с длиной. Ленту можно разрезать на любое число кусков целой длины или продать целиком, остатков нет. Верните наибольшую выручку. Для пустого списка ответ 0. Ограничения: до 40 метров.

Подумайте, какой кусок отрезать первым: после него остаётся лента меньшей длины, для которой тот же вопрос уже решён.

Пример: `[1, 5, 8, 9]` → `10` (два куска по 2 метра: 5 + 5).
