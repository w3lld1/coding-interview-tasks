# P-я битовая строка с ограничениями

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-102?utm_source=github&utm_medium=tasks-repo)**

Рассмотрим битовые строки длины `n` (из символов `0` и `1`), позиции нумеруются с 1. Дан список ограничений: каждое — тройка `[a, b, c]`, означающая, что на отрезке позиций от `a` до `b` включительно ровно `c` единиц. Строка подходит, если выполняет все ограничения. Гарантируется, что подходящих строк не меньше `p`.

Верните подходящую строку, которая стоит на `p`-м месте (счёт с 1) в лексикографическом порядке всех подходящих строк (`0` меньше `1`).

Ограничения: `1 ≤ n ≤ 60`, ограничений до 60, `1 ≤ a ≤ b ≤ n`, `b - a ≤ 9`, `0 ≤ c ≤ n`, `1 ≤ p ≤ 10^15`. Без ограничений подходит любая строка.

Пример: `n = 3`, `[[2, 2, 1]]`, `p = 2` → `"011"` (подходят `010`, `011`, `110`, `111`).
