# Самая длинная цепочка слов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Словари и множества](../hashing/), [Строки](../strings/)

Дан список непустых слов из строчных латинских букв (до 1000 слов, длина слова до 16; слова могут повторяться). Цепочка — это последовательность различных слов из списка, где каждое следующее получается из предыдущего вставкой ровно одной буквы в любое место (порядок остальных букв сохраняется). Одно слово — тоже цепочка длины 1. Верните наибольшую длину цепочки; для пустого списка верните `0`.

Пример: `["a", "b", "ba", "bca", "bda", "bdca"]` → `4` (`b` → `ba` → `bca` → `bdca`).
