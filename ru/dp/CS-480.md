# Подъёмы на профиле маршрута

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-480?utm_source=github&utm_medium=tasks-repo)**

Дан список `heights` — высоты точек туристического маршрута подряд. Подъёмом назовём непрерывный участок маршрута (по порядку точек), в котором каждая следующая высота строго больше предыдущей. Участок из одной точки тоже подъём. Участки с разными началом или концом считаются разными. Верните число подъёмов. Для пустого списка верните `0`. Точек не больше 1000.

Пример: `[1, 2, 3, 1, 2]` → `9` (пять одиночных, три из двух точек: `1,2`, `2,3`, `1,2`, и один `1,2,3`).
