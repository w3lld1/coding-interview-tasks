# Сколько вызовов сделает наивный Фибоначчи

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Рекурсия и перебор](../recursion/)

Функция `fib(k)` определена так: `fib(0)` возвращает `0`, `fib(1)` возвращает `1`, а для `k >= 2` она вызывает `fib(k - 1)` и `fib(k - 2)` и возвращает сумму. Ничего не запоминается. Верните общее число вызовов функции `fib` (включая самый первый), которое произойдёт при запуске `fib(n)`. `n` от 0 до 40. Саму рекурсию запускать не нужно: при `n = 40` вызовов сотни миллионов.

Пример: `4` → `9` (`fib(4)`, `fib(3)`, `fib(2)`, `fib(1)`, `fib(0)`, `fib(1)`, `fib(2)`, `fib(1)`, `fib(0)`).
