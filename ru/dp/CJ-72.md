# Комитет с наибольшим шансом ничьей

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-72?utm_source=github&utm_medium=tasks-repo)**

В отделе n сотрудников, `probs[i]` — вероятность того, что i-й проголосует «за» (иначе он голосует «против», воздержаться нельзя; голоса независимы). Нужно выбрать ровно `k` человек в комитет, `k` чётно и 2 ≤ `k` ≤ n ≤ 60. Ничья — это ровно `k/2` голосов «за». Выберите состав, при котором вероятность ничьей максимальна, и верните эту вероятность (сравнивается с точностью 1e-6).

Пример: `[0.75, 1.0, 0.5]`, `2` → `0.5`.
