# Сколько двоичных строк поместится в бюджет

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-150?utm_source=github&utm_medium=tasks-repo)**

Дан список непустых строк из символов `0` и `1`, а также два неотрицательных целых числа `m` и `n` — запас нулей и запас единиц. Выбрав строку, вы тратите столько нулей и единиц, сколько их в этой строке; запас каждого вида не может уйти в минус. Каждую строку списка можно выбрать не более одного раза (одинаковые строки в списке — разные элементы). Верните наибольшее число строк, которые можно выбрать. Размеры: до 600 строк, `m`, `n` до 100. Если ни одна строка не помещается, верните `0`.

Пример: `["10", "0001", "111001", "1", "0"]`, `m = 5`, `n = 3` → `4` (подойдут `"10"`, `"0001"`, `"1"`, `"0"`: нулей 1 + 3 + 0 + 1 = 5, единиц 1 + 1 + 1 + 0 = 3).
