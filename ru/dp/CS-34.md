# Ограбление домов по кругу

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-34?utm_source=github&utm_medium=tasks-repo)**

Дома стоят по кругу, в `i`-м лежит `nums[i]` монет (неотрицательное целое; домов не больше 1000). Соседние дома, включая первый и последний, нельзя брать вместе: сработает сигнализация. Верните наибольшую сумму, которую можно собрать. Для пустого списка ответ `0`, для одного дома — его значение.

Пример: `[2, 3, 2]` → `3` (первый и последний дома соседи, поэтому берём только средний).
