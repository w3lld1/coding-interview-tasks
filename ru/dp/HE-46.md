# Последовательность Fib4

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

Последовательность Fib4 задана так: `fib4(0) = 0`, `fib4(1) = 0`, `fib4(2) = 2`, `fib4(3) = 0`, а при `n ≥ 4` значение равно сумме четырёх предыдущих: `fib4(n) = fib4(n-1) + fib4(n-2) + fib4(n-3) + fib4(n-4)`. Вычислите `fib4(n)` для `n ≥ 0` без рекурсии и без пересчёта одних и тех же значений.

Пример: `6` → `8`.
