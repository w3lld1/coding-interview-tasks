# Пароли по отпечаткам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-30?utm_source=github&utm_medium=tasks-repo)**

Пароль состоит из `length` нажатий клавиш. По отпечаткам известно, что использовались ровно `keys` определённых клавиш, и каждая из них нажата хотя бы раз; других клавиш в пароле нет. Каждое нажатие даёт один символ. Сколько различных паролей возможно? Верните ответ по модулю 1000000007. Если `keys` больше `length`, ответ `0`.

Ограничения: `1 ≤ keys, length ≤ 100`.

Пример: `3`, `4` → `36` (клавиши 3, 7, 5 и пароль из четырёх символов: одна из клавиш повторяется дважды, остальные по разу).
