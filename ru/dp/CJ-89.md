# Открыть кодовый замок

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-89?utm_source=github&utm_medium=tasks-repo)**

Кодовый замок состоит из `n` дисков, стоящих в ряд; каждый диск показывает число от `0` до `size − 1`, начальные значения даны в списке `dials`. Замок открывается, когда все диски показывают `0`.

Одна операция — выбрать отрезок подряд идущих дисков `[l, r]` и повернуть все его диски вместе на одно деление вверх (`+1`) или вниз (`−1`), по кругу: после `size − 1` идёт `0`, перед `0` — `size − 1`. Условие: отрезок каждой следующей операции должен целиком содержать отрезок предыдущей (`l` не правее и `r` не левее прежних); первый отрезок любой.

Верните наименьшее число операций, открывающих замок. Дисков от 1 до 200, `2 ≤ size ≤ 10^9`, поэтому число поворотов в состоянии перебора хранить нельзя.

Пример: `[1, 1, 9, 9, 1, 1]`, `10` → `3` (дважды поднять отрезок дисков 3–4, затем опустить весь ряд).
