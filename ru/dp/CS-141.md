# Чередование двух строк

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-141?utm_source=github&utm_medium=tasks-repo)**

Даны три строки `s1`, `s2`, `s3` (каждая до 100 символов). Верните `true`, если `s3` получается чередованием `s1` и `s2`: символы обеих строк берутся по одному, каждая строка читается слева направо без пропусков и перестановок, а все символы обеих используются ровно один раз. Иначе верните `false`. Пустые строки допустимы: три пустые строки дают `true`.

Пример: `"ab"`, `"cd"`, `"acbd"` → `true`; `"ab"`, `"cd"`, `"abdc"` → `false`.
