# Два сборщика ягод на поле

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-188?utm_source=github&utm_medium=tasks-repo)**

Поле — прямоугольная таблица `grid` (не меньше 1 × 1): `1` — клетка с ягодой, `0` — пустая клетка, `-1` — колючий куст, через который ходить нельзя. Два сборщика выходят из левой верхней клетки и идут в правую нижнюю, каждый только вправо или вниз и только по клеткам без куста. Каждый собирает ягоды в клетках своего пути, но ягода в клетке, где побывали оба, считается один раз. Верните наибольшее число ягод, которое они соберут вместе. Если пути от угла до угла нет (в том числе когда куст стоит в начальной или конечной клетке), верните `0`. Таблица — до 50 × 50.

Пример: `[[0, 1, -1], [1, 0, -1], [1, 1, 1]]` → `5` (один идёт вправо, вниз, вниз, вправо, второй — вниз, вниз, вправо, вправо).
