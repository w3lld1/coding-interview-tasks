# Плейлисты с правилами перехода

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

В библиотеке `tracks` треков с номерами от 0 до `tracks - 1`. Из правил составления плейлиста известно, какой трек может идти сразу после какого: каждая пара `[a, b]` в списке `allowed` означает, что после трека `a` разрешено ставить трек `b` (обратное `b` → `a` разрешено, только если есть пара `[b, a]`; пара `[a, a]` разрешает повтор подряд). Пары в списке не повторяются. Верните, сколько существует плейлистов из ровно `length` треков, где каждая соседняя пара разрешена. Первый трек выбирается любой. Плейлисты с разным порядком считаются разными. Ограничения: `tracks` от 1 до 5, `length` от 1 до 12.

Смотрите на последний трек: число плейлистов, оканчивающихся на `b`, — это сумма чисел плейлистов на единицу короче, оканчивающихся на каждый `a`, из которого разрешён переход в `b`.

Пример: `3`, `[[0, 1], [0, 2], [1, 2]]`, `3` → `1` (единственный плейлист 0, 1, 2).
