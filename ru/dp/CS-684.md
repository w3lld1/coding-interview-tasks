# Самая длинная цепочка плиток по порядку

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-684?utm_source=github&utm_medium=tasks-repo)**

На столе в ряд лежат плитки, у каждой два числа: левое и правое, `tiles[i] = [left, right]`. Выберите несколько плиток, сохранив их порядок в ряду (плитки не обязаны лежать подряд), так, чтобы у каждой выбранной плитки, кроме первой, левое число совпадало с правым числом предыдущей выбранной. Плитки нельзя переворачивать. Верните наибольшее число плиток в такой цепочке; одна плитка — тоже цепочка, для пустого ряда ответ `0`. Плиток от 0 до 10 000, числа от 0 до 10^6.

Пример: `[[1, 2], [5, 6], [2, 3], [7, 7], [3, 1]]` → `3` (плитки `[1, 2]`, `[2, 3]`, `[3, 1]`).
