# Самая длинная серия без падений продаж

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-473?utm_source=github&utm_medium=tasks-repo)**

Дан список `sales` — продажи магазина по дням. Найдите длину самой длинной серии подряд идущих дней, в которой продажи не убывали: каждый день не меньше предыдущего. Серия из одного дня тоже считается. Для пустого списка верните `0`. В списке не больше 1000 чисел.

Пример: `[5, 3, 4, 4, 7, 2]` → `4` (серия `3, 4, 4, 7`).
