# Кратчайший замкнутый маршрут по городам

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Деревья и графы](../trees-graphs/), [Математика](../math/)

Дана квадратная матрица `dist` размером n × n (1 ≤ n ≤ 12): `dist[i][j]` — стоимость переезда из города `i` в город `j` (целое от 0 до 10^6, `dist[i][i] = 0`; матрица может быть несимметричной). Курьер выезжает из города 0, посещает каждый из остальных городов ровно один раз и возвращается в город 0. Верните наименьшую возможную суммарную стоимость такого маршрута. Если город один, маршрут пустой и ответ `0`.

Пример: `[[0, 1, 15, 6], [2, 0, 7, 3], [9, 6, 0, 12], [10, 4, 8, 0]]` → `21` (маршрут 0 → 1 → 3 → 2 → 0 стоит 1 + 3 + 8 + 9 = 21).
