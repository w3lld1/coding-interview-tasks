# Принтер, печатающий отрезками

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-203?utm_source=github&utm_medium=tasks-repo)**

Принтер печатает на ленте длиной с целевую строку. За один ход он выбирает любой непрерывный отрезок позиций и одну букву и закрашивает этой буквой весь отрезок, затирая то, что там было. Сначала лента пуста. Дана строка `s` из строчных латинских букв длиной до 100. Верните наименьшее число ходов, после которых на ленте написана ровно `s`. Для пустой строки ответ `0`.

Пример: `"abcba"` → `3` (сначала `aaaaa`, затем `abbba`, затем `abcba`).
