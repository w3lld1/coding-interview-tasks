# Прыжки по камням с очками

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-433?utm_source=github&utm_medium=tasks-repo)**

Через ручей лежит ряд камней, на каждом написано число очков (оно может быть отрицательным): список `scores`. Вы стоите на первом камне и должны добраться до последнего. За один прыжок можно переместиться вперёд на любое число камней от 1 до `k`. Очки каждого камня, на котором вы побывали, прибавляются к сумме, включая первый и последний. Верните наибольшую возможную сумму. Список содержит хотя бы один камень, `k` не меньше 1, камней не больше 1000.

Лучший итог на камне `i` складывается из его очков и лучшего итога среди камней, откуда можно прыгнуть на него.

Пример: `[1, -5, 4]`, `2` → `5` (прыжок сразу с первого камня на третий: 1 + 4).
