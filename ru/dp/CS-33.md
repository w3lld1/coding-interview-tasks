# Самый дешёвый путь вправо-вниз

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-33?utm_source=github&utm_medium=tasks-repo)**

Дана прямоугольная сетка неотрицательных целых чисел (от 1×1 до 100×100). Нужно пройти из левой верхней клетки в правую нижнюю, делая шаги только вправо или вниз. Стоимость пути — сумма чисел во всех посещённых клетках, включая первую и последнюю. Верните наименьшую возможную стоимость.

Пример: `[[1, 3, 1], [1, 5, 1], [4, 2, 1]]` → `7` (путь `1 → 3 → 1 → 1 → 1`).
