# Камни, теряющие энергию

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-105?utm_source=github&utm_medium=tasks-repo)**

Дан список камней, каждый — тройка `[s, e, l]`: камень съедается за `s` секунд, в момент 0 содержит `e` единиц энергии и теряет `l` единиц в секунду, пока энергия не дойдёт до нуля (ниже нуля она не опускается). Камни едят по одному, начиная с момента 0 и без пауз между ними; любые камни можно не есть. Когда камень начинают есть в момент `t`, сразу получают всю его оставшуюся энергию `max(0, e - l·t)`.

Верните наибольшую суммарную энергию, которую можно получить. Камней от 1 до 50, `1 ≤ s ≤ 50`, `1 ≤ e ≤ 100 000`, `0 ≤ l ≤ 100 000`.

Пример: `[[20, 10, 1], [5, 30, 5], [100, 30, 1], [5, 80, 60]]` → `105` (порядок: четвёртый, второй, третий камень).
