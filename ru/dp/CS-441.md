# Серия с положительным произведением

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-441?utm_source=github&utm_medium=tasks-repo)**

Дан список целых чисел `values`. Верните длину самого длинного непрерывного отрезка, произведение чисел которого строго больше нуля. Отрезок из одного положительного числа подходит. Если такого отрезка нет (например, список пуст или состоит из нулей), ответ 0. Перемножать числа не нужно: важен только знак. Ограничения: до 1000 элементов, значения по модулю не больше 1000.

Ноль разрывает отрезок. Для каждой позиции храните длину самого длинного отрезка, который заканчивается здесь и имеет положительное произведение, и такого же с отрицательным.

Пример: `[1, -2, -3, 4]` → `4` (два минуса дают плюс).
