# Подпоследовательности ДНК альбоцедов

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-95?utm_source=github&utm_medium=tasks-repo)**

Блоком назовём строку вида `a…a b…b c…c d…d`: сначала `i ≥ 1` букв `a`, затем `j ≥ 1` букв `b`, затем ровно `i` букв `c` и ровно `j` букв `d` (например, `abcd` и `aabbbccddd`). Правильная строка — это один или несколько блоков, записанных подряд (например, `aaabcccdaabbbccdddabcd`).

Дана строка `dna` из букв `a`, `b`, `c`, `d` (длина от 1 до 500). Посчитайте, сколько её подпоследовательностей — правильные строки. Подпоследовательности, выбранные из разных позиций, считаются разными, даже если совпадают как строки. Верните ответ по модулю `1 000 000 007`.

Пример: `"aaaabcd"` → `4` (одна из четырёх букв `a`, затем `b`, `c`, `d`).
