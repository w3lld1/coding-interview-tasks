# Последовательность FibFib

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-63?utm_source=github&utm_medium=tasks-repo)**

Последовательность FibFib похожа на числа Фибоначчи, но каждый член равен сумме трёх предыдущих: `f(0) = 0`, `f(1) = 0`, `f(2) = 1`, `f(n) = f(n-1) + f(n-2) + f(n-3)` при `n ≥ 3`. Вычислите `f(n)` для заданного `n ≥ 0` эффективно: решение должно работать быстро и для `n` порядка 30.

Пример: `5` → `4` (последовательность 0, 0, 1, 1, 2, 4).
