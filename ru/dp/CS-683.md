# Ровно k попаданий со штрафной линии

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-683?utm_source=github&utm_medium=tasks-repo)**

Баскетболист выполняет серию штрафных бросков. Бросок `i` попадает с вероятностью `chances[i]` (число от 0 до 1), броски независимы друг от друга. Верните вероятность того, что попаданий будет ровно `k`. Если `k` больше числа бросков, ответ `0`; при пустой серии ровно 0 попаданий случается с вероятностью `1`. Бросков от 0 до 100, `k` от 0 до 200. Ответ сравнивается с точностью 1e-6.

Пример: `[0.2, 0.7]`, `1` → `0.62` (0.2 · 0.3 + 0.8 · 0.7).
