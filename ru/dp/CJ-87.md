# Блины на тренажёре

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Стек, очередь, связные списки](../stacks-lists/)

Тренировка — это последовательность упражнений, которые выполняются строго по порядку. Есть `w` видов блинов для штанги; упражнение `i` задано списком `exercises[i]` длины `w`: `exercises[i][j]` — сколько блинов вида `j` должно стоять на тренажёре (в каждом упражнении есть хотя бы один блин).

Блины на тренажёре образуют стопку. За одну операцию можно положить любой блин на верх стопки или снять верхний блин. Перед упражнением в стопке должен быть ровно нужный набор блинов (порядок в стопке любой). Сначала стопка пуста, и после последнего упражнения она тоже должна стать пустой.

Верните наименьшее число операций, за которое можно выполнить все упражнения. Упражнений до 60, видов блинов до 20.

Пример: `[[1, 2, 1], [2, 1, 2]]` → `12`.
