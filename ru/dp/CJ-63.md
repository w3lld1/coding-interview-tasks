# Лотерея с побитовым И

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-63?utm_source=github&utm_medium=tasks-repo)**

Лотерея выбирает выигрышный номер так: первая машина выдаёт целое `x` с `0 ≤ x < a`, вторая — целое `y` с `0 ≤ y < b`, а номер равен их побитовому И `x & y`. Вы купили все билеты с номерами от `0` до `k - 1`. Верните, сколько упорядоченных пар `(x, y)` дают вам выигрыш, то есть `x & y < k`. Пары `(0, 1)` и `(1, 0)` различны.

Ограничения: `1 ≤ a, b, k ≤ 9·10^7`. Перебор всех пар слишком медленный. Ответ может доходить до `8·10^15` и не помещается в 32 бита.

Пример: `3`, `4`, `2` → `10` (подходят все пары, кроме `(2, 2)` и `(2, 3)`).
