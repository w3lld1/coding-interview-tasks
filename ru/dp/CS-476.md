# Смены с двумя днями отдыха

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-476?utm_source=github&utm_medium=tasks-repo)**

Курьер видит заработок `pay[i]` (целое число не меньше 0) за каждый день. Если он выходит на работу в какой-то день, то два следующих дня обязан отдыхать, то есть любые два выбранных рабочих дня различаются номерами не меньше чем на 3. Выбирать можно любые дни. Верните наибольший суммарный заработок; для пустого списка верните `0`. Дней не больше 1000.

Пример: `[4, 2, 3, 6, 1, 5]` → `10` (дни с заработком `4` и `6`).
