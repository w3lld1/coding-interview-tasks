# Колония грибов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/)

В начале месяца 0 в лаборатории появляется одна новорождённая пара грибов. Пара созревает через `maturity` месяцев после рождения; начиная с месяца созревания каждая зрелая пара в конце каждого месяца производит одну новую пару (она появляется в том же месяце). Пары никогда не гибнут. Верните число пар по итогам месяца `months`, считая и новорождённых этого месяца. Ограничения: `months` от 0 до 40, `maturity` от 1 до 40.

Число пар в месяце `t` — это пары прошлого месяца плюс новые пары, которые дали все пары, родившиеся не позже месяца `t - maturity`.

Пример: `6`, `2` → `13` (1, 1, 2, 3, 5, 8, 13).
