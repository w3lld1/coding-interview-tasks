# Самая длинная цепочка вложенных конвертов

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Поиск и сортировка](../search-sort/), [Массивы и списки](../arrays/)

Дан список конвертов `envelopes` (до 10^5 штук), каждый — пара `[ширина, высота]` из целых чисел от 1 до 10^9. Конверт A помещается в конверт B, если ширина A строго меньше ширины B и высота A строго меньше высоты B; поворачивать конверты нельзя. Верните наибольшее число конвертов, которые можно вложить друг в друга цепочкой (каждый в следующий). Одинаковые конверты друг в друга не входят. Для пустого списка ответ `0`, для одного конверта — `1`.

Пример: `[[5, 4], [6, 4], [6, 7], [2, 3]]` → `3` (`[2, 3]` → `[5, 4]` → `[6, 7]`).
