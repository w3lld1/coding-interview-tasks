# Путь к единице: пополам или на шаг

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Рекурсия и перебор](../recursion/)

На табло горит целое число `n`. За один ход его меняют по правилу: чётное число делят пополам, а нечётное (больше 1) можно либо увеличить на 1, либо уменьшить на 1, на выбор. Верните наименьшее число ходов, за которое табло покажет `1`. Для `n = 1` ответ `0`. `n` от 1 до 2 147 483 647 (`2^31 - 1`), поэтому промежуточное `n + 1` может не поместиться в 32-битное число.

Пример: `15` → `5` (15 → 16 → 8 → 4 → 2 → 1).
