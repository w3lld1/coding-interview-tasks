# Возрастающие подпоследовательности знаков

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-46?utm_source=github&utm_medium=tasks-repo)**

Водитель проехал мимо `n` знаков ограничения скорости. Последовательность `s` их значений задана генератором: даны список `a` из `m` чисел и числа `x`, `y`, `z`. Для `i = 0, 1, …, n − 1` по очереди `s[i]` равно текущему `a[i mod m]`, после чего `a[i mod m]` заменяется на `(x · a[i mod m] + y · (i + 1)) mod z`.

Посчитайте непустые строго возрастающие подпоследовательности `s`: наборы позиций `i1 < i2 < … < it` (`t ≥ 1`), для которых `s[i1] < s[i2] < … < s[it]`. Наборы с одинаковыми значениями, но разными позициями считаются разными. Верните их число по модулю `1 000 000 007`.

Ограничения: `1 ≤ m ≤ 100`, `m ≤ n ≤ 10 000`, `0 ≤ x, y ≤ 10^9`, `1 ≤ z ≤ 10^9`, `0 ≤ a[i] < z`. Произведение `x · a[i]` доходит до `10^18`: считайте в 64-битных числах (в JavaScript разбейте умножение на части).

Пример: `5, 5, 0, 0, 5, [1, 2, 1, 2, 3]` → `15` (здесь `s = [1, 2, 1, 2, 3]`).
