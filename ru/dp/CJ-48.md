# Некрасивые выражения из цифр

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Математика](../math/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-48?utm_source=github&utm_medium=tasks-repo)**

Назовём целое число некрасивым, если оно делится хотя бы на одно из чисел 2, 3, 5 или 7. Ноль некрасив, отрицательные числа тоже бывают некрасивыми (например, −14).

Дана строка `digits` из `D` цифр. Между каждыми двумя соседними цифрами поставьте плюс, минус или ничего — получится одно из `3^(D−1)` выражений. Числа в выражении могут начинаться с нулей: для `"01023"` допустимы `01023`, `0+1-02+3` и `01-023`. Верните, сколько из всех этих выражений дают некрасивое значение.

Ограничения: `1 ≤ D ≤ 30`; сами значения бывают длиной до 30 цифр.

Пример: `"011"` → `6`.
