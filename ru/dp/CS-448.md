# Игра с кучей камней

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Рекурсия и перебор](../recursion/)

Два игрока по очереди берут камни из одной кучи, в которой сначала `stones` камней. За ход игрок берёт ровно `m` камней, где `m` — одно из чисел списка `moves` (положительные, различные), при этом брать больше камней, чем осталось, нельзя. Первым ходит первый игрок. Тот, кто не может сделать ход (камней осталось меньше, чем самый маленький из `moves`, или их нет), проигрывает. Оба играют безошибочно. Верните `true`, если выигрывает первый игрок, иначе `false`. Ограничения: `stones` от 0 до 1000, в `moves` до 5 чисел.

Позиция с `s` камнями выигрышна, если из неё есть ход в проигрышную позицию; иначе проигрышна. Это рекурсия по числу камней с запоминанием.

Пример: `3`, `[1, 2]` → `false` (любой ход оставляет сопернику 2 или 1 камень, и он берёт всё).
