# Рюкзак с однократным выбором предметов

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-20?utm_source=github&utm_medium=tasks-repo)**

Даны вместимость рюкзака по весу и список предметов; каждый предмет — словарь с ключами "weight" (вес) и "value" (ценность), оба положительные. Каждый предмет разрешено взять не более одного раза, а общий вес не должен превысить вместимость. Верните максимальную суммарную ценность допустимого набора; при отсутствии подходящих предметов ответ равен нулю.
