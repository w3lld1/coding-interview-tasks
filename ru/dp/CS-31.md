# Расшифровка цифровой строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-31?utm_source=github&utm_medium=tasks-repo)**

Буквам английского алфавита поставлены в соответствие числа: `A` = 1, `B` = 2, …, `Z` = 26. Дана непустая строка из цифр (не длиннее 40 символов). Её нужно разбить на подряд идущие части так, чтобы каждая часть была записью числа от 1 до 26 без ведущего нуля (`06` не годится, `0` тоже). Верните, сколькими способами это можно сделать; если способов нет, верните `0`.

Пример: `"226"` → `3` (`2|2|6`, `22|6`, `2|26`).
