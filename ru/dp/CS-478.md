# Лучшая серия, заканчивающаяся в каждый день

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-478?utm_source=github&utm_medium=tasks-repo)**

Дан список `profits` — прибыль киоска по дням (целые числа, могут быть отрицательными). Для каждого дня `i` найдите наибольшую сумму прибыли за непрерывную серию дней, которая заканчивается ровно в день `i` (серия содержит хотя бы этот день и может начаться в любой день до него). Верните список таких сумм той же длины. Для пустого списка верните пустой список. Дней не больше 1000.

Пример: `[3, -5, 2, 4, -1]` → `[3, -2, 2, 6, 5]`.
