# Разделить на две равные по сумме части

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-36?utm_source=github&utm_medium=tasks-repo)**

Дан список положительных целых чисел (не больше 100 элементов, каждое не больше 100). Можно ли распределить все его элементы по двум частям так, чтобы суммы частей были равны? Обе части должны быть непустыми, порядок элементов не важен. Для пустого списка и списка из одного элемента ответ `false`.

Пример: `[1, 5, 11, 5]` → `true` (`11` и `1 + 5 + 5`).
