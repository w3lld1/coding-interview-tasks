# Сброс карт тройками

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-92?utm_source=github&utm_medium=tasks-repo)**

Карты с числами лежат в ряд слева направо, дано число `k ≥ 0`. За один ход можно убрать три карты, которые сейчас стоят подряд, если их числа `a, b, c` (слева направо) удовлетворяют `b − a = c − b = k`; после этого оставшиеся карты смыкаются. Ходы можно делать в любом порядке, сколько угодно раз. Верните наименьшее число карт, которое может остаться. В ряду от 1 до 100 карт.

Пример: `[3, 1, 2, 3, 4]`, `k = 1` → `2` (убираем `1, 2, 3`, остаются `3` и `4`).
