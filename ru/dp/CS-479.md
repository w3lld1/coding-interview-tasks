# Дешёвая покраска забора в три цвета

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-479?utm_source=github&utm_medium=tasks-repo)**

Забор состоит из досок по порядку. Каждую доску красят в один из трёх цветов `0`, `1`, `2`, причём соседние доски должны быть разного цвета. `costs[i][c]` — цена покраски доски `i` в цвет `c` (целое число не меньше 0, в каждой строке ровно 3 числа). Верните наименьшую суммарную цену покраски всего забора; для пустого списка верните `0`. Досок не больше 1000.

Пример: `[[1, 5, 3], [2, 9, 4]]` → `5` (цвета `0` и `2`: `1 + 4`).
