# Ряд плиток трёх цветов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-447?utm_source=github&utm_medium=tasks-repo)**

Дорожку из `n` плиток в ряд нужно выложить плитками трёх цветов: красными, зелёными и синими. Две красные плитки рядом класть нельзя; других ограничений нет. Верните, сколько существует различных рядов. Для `n` = 0 ряд один (пустой). Ограничения: `n` от 0 до 18.

Смотрите на последнюю плитку: если она красная, предыдущая обязана быть не красной; иначе её цвет один из двух некрасных, а перед ней может стоять что угодно.

Пример: `2` → `8` (девять пар цветов без красно-красной).
