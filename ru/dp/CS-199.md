# Набор слова на вращающемся кольце

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Динамическое программирование](../dp/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-199?utm_source=github&utm_medium=tasks-repo)**

Даны строки `ring` и `key` из строчных латинских букв. Буквы `ring` по порядку нанесены по кругу на кольцо; в начале под стрелкой стоит буква с индексом 0. За один шаг можно повернуть кольцо на одну букву по часовой стрелке или против неё (после последней буквы идёт первая) либо нажать кнопку, и тогда буква под стрелкой набирается. Нужно набрать буквы `key` строго по порядку: нажатие засчитывается, только если под стрелкой стоит следующая нужная буква. Верните наименьшее число шагов (повороты и нажатия вместе), за которое можно набрать всё слово. Длина `ring` — от 1 до 100, длина `key` — от 0 до 100, каждая буква `key` встречается в `ring`; для пустого `key` ответ `0`.

Пример: `"abcde"`, `"ea"` → `4` (поворот к `e` на один шаг назад, нажатие, поворот к `a`, нажатие).
