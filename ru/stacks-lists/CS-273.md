# Сложение чисел, записанных списками цифр

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Математика](../math/)

Неотрицательное число записано связным списком цифр, **младшая цифра первая**. Список задан массивами: узел `i` хранит цифру `values[i]` (`0..9`) и ссылку `next[i]` на следующий узел (`-1` для последнего). `head` — индекс первого узла, `-1` означает пустой список, то есть число `0`. Порядок узлов в массивах произвольный, идите по ссылкам.

Даны два таких числа (`values_a`, `next_a`, `head_a` и `values_b`, `next_b`, `head_b`). Верните их сумму в том же виде: список цифр от младшей к старшей, без лишних нулей в конце. Для суммы `0` верните `[0]`.

Пример: `[2, 4, 3]` (это 342) и `[5, 6, 4]` (это 465) в порядке обхода → `[7, 0, 8]` (это 807).
