# Автоколонны перед финишем

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Поиск и сортировка](../search-sort/)

Машины едут по одной полосе к финишу в точке `target`. У машины `i` стартовая позиция `position[i]` (все позиции различны, `0 <= position[i] < target`) и постоянная скорость `speed[i] >= 1`. Обгонять нельзя: машина, догнавшая более медленную впереди, дальше едет с её скоростью, и они образуют колонну (колонна из одной машины тоже колонна). Догнавшие друг друга в самой точке `target` считаются одной колонной. Верните число колонн, которые приедут на финиш. Значения до 10⁵, машин до 1000; для пустого списка ответ `0`.

Пример: `12`, позиции `[10, 8, 0, 5, 3]`, скорости `[2, 4, 1, 1, 3]` → `3`.
