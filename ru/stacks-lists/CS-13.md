# Следующий больший в кольце

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Массивы и списки](../arrays/)

Дан список чисел, который считается замкнутым в кольцо: после последнего элемента снова идёт первый. Для каждого элемента верните ближайшее число, строго большее его, если двигаться по кольцу вперёд от его позиции (не больше одного полного круга). Если такого числа нет, верните `-1`. Результат имеет ту же длину, что и вход, для пустого списка он пустой. Элемент не сравнивается с самим собой на втором круге: на нём поиск заканчивается.

Пример: `[1, 2, 1]` → `[2, -1, 2]`.
