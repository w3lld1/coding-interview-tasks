# Стек самых частых

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Словари и множества](../hashing/), [Классы и ООП](../oop/)

Реализуйте особый стек и выполните над ним список операций. Сначала стек пуст. Операция `operations[i]` получает аргументы из `values[i]`:
- `push` — `values[i]` содержит одно число `v` (от 0 до 10^9); `v` кладётся в стек. Результат — сколько раз `v` теперь лежит в стеке (с учётом этого раза);
- `pop` — `values[i]` пуст. Из стека снимается одно вхождение самого частого значения, то есть того, которое сейчас лежит в стеке больше всего раз. Если таких значений несколько, выбирается то, чьё последнее оставшееся вхождение положено позже других. Снимается именно это последнее вхождение. Результат — снятое значение;
- `peek` — `values[i]` пуст; результат — значение, которое сняла бы `pop`, но стек не меняется.

Для `pop` и `peek` на пустом стеке результат `-1`. Верните список результатов, по одному на операцию. Операций не больше 20 000, каждая должна работать за O(1).

Пример: операции `push 5, push 7, push 5, push 7, push 4, push 5, pop, peek, pop, pop, pop`, то есть `operations = ["push", …]`, `values = [[5], [7], [5], [7], [4], [5], [], [], [], [], []]` → `[1, 1, 2, 2, 1, 3, 5, 7, 7, 5, 4]`.
