# Список с вложенными списками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Рекурсия и перебор](../recursion/)

Список задан тремя массивами: узел `i` хранит число `values[i]`, ссылку `next[i]` на следующий узел своего списка и ссылку `child[i]` на первый узел вложенного списка (`-1`, если вложенного списка нет; `-1` в `next` у последнего узла). `head` — индекс первого узла главного списка, `-1` для пустого. Вложенный список устроен так же и сам может иметь вложенные списки. Каждый узел входит ровно в один список, общих узлов нет, циклов нет; узлы лежат в массивах в произвольном порядке.

Спрямите структуру в один список по такому правилу: вслед за узлом идёт весь его вложенный список (спрямлённый по тому же правилу), и только потом то, что шло за узлом по `next`. Верните числа спрямлённого списка по порядку.

Пример: `values = [10, 20, 30, 40, 50]`, `next = [1, 2, -1, 4, -1]`, `child = [-1, 3, -1, -1, -1]`, `head = 0` → `[10, 20, 40, 50, 30]` (у узла `20` вложенный список `40 → 50`).
