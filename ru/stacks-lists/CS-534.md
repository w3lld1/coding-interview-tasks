# Список-палиндром

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

Связный список задан массивами: узел `i` хранит число `values[i]` и ссылку `next[i]` на следующий узел (`-1` у последнего). `head` — индекс первого узла (`-1` для пустого списка, тогда массивы пусты). Узлы лежат в массивах в произвольном порядке, идите по ссылкам.

Верните `true`, если числа списка, прочитанные от головы к хвосту, дают то же самое, что и от хвоста к голове. Пустой список и список из одного узла — палиндромы.

Пример: `values = [1, 2, 2, 1]`, `next = [1, 2, 3, -1]`, `head = 0` → `true`.
