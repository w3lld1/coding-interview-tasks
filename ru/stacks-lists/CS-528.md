# Слияние двух отсортированных связных списков

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-528?utm_source=github&utm_medium=tasks-repo)**

Два связных списка лежат в одних и тех же массивах: узел `i` хранит число `values[i]` и ссылку `next[i]` на следующий узел своего списка (`-1` у последнего). `head_a` и `head_b` — индексы первых узлов первого и второго списка, `-1` для пустого списка. Каждый список отсортирован по неубыванию, узлы двух списков перемешаны в массивах произвольно, общих узлов нет. В массивах могут быть и узлы, которые не входят ни в один из двух списков.

Верните числа обоих списков в одном списке по неубыванию (слияние).

Пример: `values = [1, 2, 4, 3]`, `next = [2, 3, -1, -1]`, `head_a = 0`, `head_b = 1` (списки `1 → 4` и `2 → 3`) → `[1, 2, 3, 4]`.
