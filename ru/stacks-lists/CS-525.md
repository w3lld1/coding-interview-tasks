# Текст после набора с забоем

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Строки](../strings/)

Пользователь нажимает клавиши по очереди. Строка `keys` — это последовательность нажатий: обычный символ (буква, цифра или пробел) печатается в конец текста, а символ `<` — клавиша «забой»: она стирает последний напечатанный символ, а если текст пуст, ничего не делает. Верните итоговый текст.

Пример: `"abc<<d"` → `"ad"`.
