# Вагоны через тупик

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

На станцию по одному прибывают вагоны с номерами `1, 2, ..., n` именно в таком порядке. Каждый прибывший вагон заезжает в тупик, где вагоны стоят друг за другом, и выехать из тупика может только последний заехавший. Вагон можно выпустить из тупика на выходной путь в любой момент, а следующий вагон при этом ещё не обязан прибыть. Вагоны на выходном пути выстраиваются в порядке выпуска.

`order` — желаемый порядок вагонов на выходном пути; это перестановка чисел от 1 до n (для `n = 0` — пустой список). Верните `true`, если такого порядка можно добиться, иначе `false`.

Пример: `[3, 2, 1]` → `true`; `[3, 1, 2]` → `false` (чтобы выпустить 3, а потом 1, нужно, чтобы 2 уже стоял под 3 и мешал).
