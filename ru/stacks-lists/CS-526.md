# Глубина вложенности разных скобок

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-526?utm_source=github&utm_medium=tasks-repo)**

В строке `text` есть скобки трёх видов: `()`, `[]`, `{}`; остальные символы (буквы, цифры, пробелы) игнорируются. Если скобки расставлены правильно (каждая закрывающая закрывает последнюю ещё не закрытую открывающую того же вида и в конце не остаётся незакрытых), верните наибольшую глубину вложенности — наибольшее число одновременно открытых скобок. Для строки без скобок это `0`. Если расстановка неправильная, верните `-1`.

Пример: `"a(b[c]{d})"` → `2`; `"([)]"` → `-1`.
