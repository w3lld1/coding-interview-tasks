# Число в середине списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-530?utm_source=github&utm_medium=tasks-repo)**

Связный список задан массивами: узел `i` хранит число `values[i]` и ссылку `next[i]` на следующий узел (`-1` у последнего). `head` — индекс первого узла (`-1` для пустого списка, тогда массивы пусты). Узлы лежат в массивах в произвольном порядке, идите по ссылкам. Числа в списке неотрицательные.

Верните число из среднего узла списка. Если узлов чётное количество, средних два, и нужно взять второй из них. Для пустого списка верните `-1`.

Пример: `values = [10, 20, 30, 40]`, `next = [1, 2, 3, -1]`, `head = 0` → `30`.
