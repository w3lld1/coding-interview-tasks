# Распаковка повторов в скобках

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Строки](../strings/), [Разбор и проверка данных](../parsing/)

Строка закодирована по правилу `k[текст]`: внутри квадратных скобок записан фрагмент, который нужно повторить `k` раз. Скобки могут быть вложенными, `k` может быть многозначным числом (в том числе `0`), а текст может стоять и вне скобок. Цифры встречаются только как множитель `k` перед `[`, исходный текст цифр не содержит. Кодировка корректна, внутри скобок всегда есть хотя бы один символ. Верните раскодированную строку; для пустой строки верните пустую. Длина результата не превышает нескольких тысяч символов.

Пример: `"3[a2[c]]"` → `"accaccacc"`.
