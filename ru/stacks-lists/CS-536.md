# Список без обойдённых узлов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-536?utm_source=github&utm_medium=tasks-repo)**

Связный список задан массивами: узел `i` хранит число `values[i]` и ссылку `next[i]` на следующий узел (`-1` у последнего). `head` — индекс первого узла (`-1` для пустого списка, тогда массивы пусты). Узлы лежат в массивах в произвольном порядке, идите по ссылкам.

Удалите из списка каждый узел, после которого (дальше по списку) есть узел со строго большим числом. Остальные узлы остаются в прежнем порядке. Верните числа оставшихся узлов по порядку. Последний узел остаётся всегда. Числа могут быть отрицательными.

Пример: `values = [5, 2, 13, 3, 8]`, `next = [1, 2, 3, 4, -1]`, `head = 0` → `[13, 8]` (после 5, 2 и 3 есть большее число, а у 13 и 8 справа больших нет).
