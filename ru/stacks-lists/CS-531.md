# Фокус с раскладкой карт

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-531?utm_source=github&utm_medium=tasks-repo)**

В колоде `n` карт с номерами `1..n`, сверху лежит карта 1, под ней 2 и так до `n` внизу. Фокусник повторяет два действия, пока в колоде есть карты: открывает верхнюю карту и откладывает её, затем переносит новую верхнюю карту (если она есть) вниз колоды. Верните номера карт в том порядке, в котором они были открыты. Для `n = 0` верните пустой список, `n ≤ 1000`.

Пример: `5` → `[1, 3, 5, 4, 2]` (колода 1 2 3 4 5: открыта 1, 2 уходит вниз → 3 4 5 2; открыта 3, 4 вниз → 5 2 4; открыта 5, 2 вниз → 4 2; открыта 4, 2 вниз → 2; открыта 2).
