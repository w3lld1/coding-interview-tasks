# Убрать узел с конца списка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-532?utm_source=github&utm_medium=tasks-repo)**

Связный список задан массивами: узел `i` хранит число `values[i]` и ссылку `next[i]` на следующий узел (`-1` у последнего). `head` — индекс первого узла (`-1` для пустого списка, тогда массивы пусты). Узлы лежат в массивах в произвольном порядке, идите по ссылкам.

Удалите из списка узел, который стоит `n`-м с конца (последний узел — первый с конца), и верните числа оставшихся узлов в порядке списка. Если `n` больше длины списка, список не меняется. Считайте, что `n ≥ 1`.

Пример: `values = [1, 2, 3, 4, 5]`, `next = [1, 2, 3, 4, -1]`, `head = 0`, `n = 2` → `[1, 2, 3, 5]`.
