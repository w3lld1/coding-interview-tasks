# Спрятанные блины

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Деревья и графы](../trees-graphs/), [Математика](../math/)

Пекут `n` блинов радиусов 1, 2, …, `n` (каждый радиус ровно один раз) в некотором порядке. Каждый новый блин кладут на верх стопки, центры совпадают. Блин виден сверху, пока на него не положили блин большего радиуса; блин, который хоть раз накрыли бо́льшим, больше не виден.

Дан список `visible` длины `n`: `visible[i]` — сколько блинов видно сверху сразу после того, как в стопке оказались первые `i + 1` блинов. Верните, сколько из `n!` порядков выпекания дают ровно такой список, по модулю простого `1000000007`. Если такой порядок невозможен (например, видимых стало больше, чем на один, по сравнению с предыдущим шагом), верните `0`.

Гарантируется `1 ≤ visible[i] ≤ i + 1`; `n` до нескольких тысяч, поэтому перебор порядков не подходит.

Пример: `[1, 2, 2, 1]` → `1` (подходит только порядок 3, 1, 2, 4).
