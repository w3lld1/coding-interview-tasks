# Дни до потепления

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Массивы и списки](../arrays/)

Дан список температур по дням. Для каждого дня верните, сколько дней нужно подождать до более тёплого дня, то есть до ближайшего следующего дня со строго большей температурой. Если такого дня нет, для этого дня верните `0`. Результат имеет ту же длину, что и вход; для пустого списка верните пустой список. Длина входа до нескольких тысяч, решение должно быть быстрее O(n²).

Пример: `[73, 74, 75, 71, 69, 72, 76, 73]` → `[1, 1, 4, 2, 1, 1, 0, 0]`.
