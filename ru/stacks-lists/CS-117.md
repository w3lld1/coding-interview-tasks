# Рекорды цены за подряд идущие дни

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-117?utm_source=github&utm_medium=tasks-repo)**

Реализуйте «счётчик цен», который в начале пуст. Дан список операций `operations` и список аргументов `values`: у операции `operations[i]` аргументы лежат в `values[i]`. Верните список результатов, по одному на операцию. Операции:
- `"next"` с аргументом `[price]` — приходит цена очередного дня. Результат: «размах» дня, то есть число подряд идущих дней, заканчивающихся сегодняшним, в которые цена была не больше сегодняшней (сегодня включительно, считаются только дни после последнего `reset`).
- `"reset"` с пустым аргументом — забыть все дни. Результат `0`.
- `"max_span"` с пустым аргументом — наибольший размах среди всех дней после последнего `reset`, `0` если дней нет.

Операций до 2000, цены целые.

Пример: операции `["next", "next", "next", "next"]`, аргументы `[[100], [80], [60], [70]]` → `[1, 1, 1, 2]`.
