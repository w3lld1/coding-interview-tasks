# Обратная польская запись

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Разбор и проверка данных](../parsing/)

Дан список токенов выражения в обратной польской записи (постфиксной): каждый токен либо целое число (возможно, отрицательное, например `"-3"`), либо один из операторов `"+"`, `"-"`, `"*"`, `"/"`. Вычислите значение. Оператор берёт два последних вычисленных значения, причём первым операндом считается то, что было вычислено раньше. Деление целочисленное и округляется к нулю (`-7 / 2` равно `-3`). Выражение корректно, делений на ноль нет, все промежуточные значения помещаются в 32-битное целое.

Пример: `["4", "13", "5", "/", "+"]` → `6` (13 / 5 = 2, затем 4 + 2).
