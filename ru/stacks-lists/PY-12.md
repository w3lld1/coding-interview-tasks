# Односвязный список

**Сложность:** средняя · **Язык:** Python · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-12?utm_source=github&utm_medium=tasks-repo)**

Реализуйте односвязный список. Класс `Node` хранит значение и ссылку на следующий узел: метод `value()` возвращает значение, `next()` — следующий узел или `None`. Класс `LinkedList(values=None)` поддерживает:

- `push(value)` — добавить значение в голову;
- `pop()` — снять голову и вернуть её значение;
- `head()` — вернуть головной узел (`Node`, а не значение);
- `len(list)` — число элементов;
- итерацию по значениям от головы к хвосту;
- `reversed()` — вернуть новый список с элементами в обратном порядке.

Конструктор добавляет элементы `values` в голову по очереди, поэтому у `LinkedList([1, 2, 3])` головой будет 3. Вызовы `head()` и `pop()` на пустом списке вызывают `EmptyListException`.
