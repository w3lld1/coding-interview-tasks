# Столкновения астероидов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Массивы и списки](../arrays/)

Астероиды летят вдоль одной прямой с одинаковой скоростью. Знак числа задаёт направление (положительное летит вправо, отрицательное влево), модуль задаёт размер; нулей нет. Порядок в списке совпадает с порядком расположения слева направо. Если два астероида встречаются, меньший взрывается, а больший летит дальше; при равных размерах взрываются оба. Астероиды, летящие в одну сторону, никогда не встречаются. Верните список оставшихся астероидов после всех столкновений в порядке слева направо; он может оказаться пустым.

Пример: `[5, 10, -5]` → `[5, 10]` (астероид `-5` взрывается о `10`).
