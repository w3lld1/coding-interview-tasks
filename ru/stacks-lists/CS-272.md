# Разворот нечётных групп списка

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/)

Связный список задан массивами: узел `i` хранит число `values[i]` и ссылку на следующий узел `next[i]` (`-1` для последнего узла). `head` — индекс первого узла (`-1` для пустого списка, тогда массивы пусты). Узлы в массивах могут идти в любом порядке, обходите список по ссылкам.

Разделите список на группы по `k` подряд идущих узлов, считая от головы: группа 1, группа 2 и так далее; последняя группа может быть короче. **Разверните** группы с нечётными номерами (первую, третью, …), если в них ровно `k` узлов; остальные группы, в том числе короткую последнюю, оставьте как есть. Верните числа списка после этого, в порядке обхода. Считайте `k ≥ 1`.

Пример: `values = [10, 20, 30, 40, 50, 60, 70]`, `next = [1, 2, 3, 4, 5, 6, -1]`, `head = 0`, `k = 2` → `[20, 10, 30, 40, 60, 50, 70]`.
