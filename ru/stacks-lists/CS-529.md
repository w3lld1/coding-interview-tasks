# Время ухода покупателей с касс

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-529?utm_source=github&utm_medium=tasks-repo)**

В магазине `tills` касс (`tills ≥ 1`), все свободны с момента `0`. Все покупатели стоят в одной общей очереди, их обслуживание занимает `durations[0]`, `durations[1]`, ... минут. Покупатели идут по порядку очереди; каждый подходит к той кассе, которая освободится раньше всех (при равенстве — к кассе с меньшим номером), и начинает обслуживание сразу, как только она свободна. Верните список моментов, когда закончилось обслуживание каждого покупателя, в порядке очереди.

Пример: `2`, `[5, 3, 4, 1]` → `[5, 3, 7, 6]` (первый на кассе 0 до 5, второй на кассе 1 до 3, третий на кассе 1 с 3 до 7, четвёртый на кассе 0 с 5 до 6).
