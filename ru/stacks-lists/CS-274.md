# Плейлист с текущим треком

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-274?utm_source=github&utm_medium=tasks-repo)**

Реализуйте плейлист по кругу с указателем на текущий трек. Треки заданы целыми номерами (номера могут повторяться), сначала плейлист пуст. Когда в плейлисте появляется первый трек, он становится текущим. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Верните список результатов, по одному на операцию.

Операции:
- `"add"` с аргументом `song`: добавить трек в конец; результат: длина плейлиста.
- `"insert_next"` с аргументом `song`: вставить трек сразу после текущего (в пустой плейлист просто вставить); текущий трек не меняется; результат: длина плейлиста.
- `"next"`: перейти к следующему треку, после последнего идёт первый; результат: номер нового текущего трека, `-1` для пустого плейлиста.
- `"prev"`: перейти к предыдущему, перед первым идёт последний; результат как у `"next"`.
- `"remove_current"`: удалить текущий трек; текущим становится следующий за ним трек, а если удалён последний, то первый; результат: номер удалённого трека, `-1` для пустого плейлиста.
- `"current"`: результат: номер текущего трека, `-1` для пустого плейлиста.

Пример: `["add", "add", "add", "next", "insert_next", "next", "remove_current", "current"]`, `[[11], [22], [33], [], [44], [], [], []]` → `[1, 2, 3, 22, 4, 44, 44, 33]`.
