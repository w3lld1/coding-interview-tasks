# Тройка «один, три, два»

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Стек, очередь, связные списки](../stacks-lists/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-119?utm_source=github&utm_medium=tasks-repo)**

Дан список целых `nums` (до 5000 элементов, значения по модулю до 10⁹). Верните `true`, если в нём есть три позиции `i < j < k`, для которых `nums[i] < nums[k] < nums[j]` (значения образуют форму «малое, большое, среднее», неравенства строгие). Иначе верните `false`. Для списка короче трёх элементов ответ `false`.

Пример: `[3, 1, 4, 2]` → `true` (`1, 4, 2`); `[1, 2, 3, 4]` → `false`.
