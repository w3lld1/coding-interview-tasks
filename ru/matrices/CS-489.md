# Размытие картинки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Математика](../math/)

Серая картинка — непустой прямоугольный список списков неотрицательных целых `image` (яркость пикселей). Размытие заменяет каждый пиксель средним арифметическим его самого и существующих соседей слева, справа, сверху и снизу (диагонали не берутся), округлённым вниз до целого. Все новые значения считаются по исходной картинке, а не по уже размытым. Верните новую картинку того же размера.

Пример: `[[1, 2], [3, 4]]` → `[[2, 2], [2, 3]]` (для левого верхнего пикселя `(1 + 2 + 3) / 3 = 2`).
