# Места для компании в кинозале

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-486?utm_source=github&utm_medium=tasks-repo)**

Схема кинозала — список одинаковых по длине строк `seats`: `.` — свободное место, `X` — занятое. Компании из `k` человек (`k ≥ 1`) нужно `k` свободных мест подряд в одном ряду. Найдите самый ранний подходящий блок: с наименьшим номером ряда, а в ряду — с наименьшим номером первого места. Верните список `[ряд, место]` с нумерацией с нуля для первого места блока. Если подходящего блока нет, верните `[-1, -1]`.

Пример: `["..X..", "....."]`, `3` → `[1, 0]` (в первом ряду свободных мест подряд только по два).
