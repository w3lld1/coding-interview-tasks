# Таблица с итогами

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

Таблица — прямоугольный список списков целых `table`. Верните новую таблицу, в которой в конец каждой строки дописана сумма этой строки, а в конец добавлена ещё одна строка с суммами столбцов (включая новый столбец, то есть в правом нижнем углу общая сумма). Исходную таблицу менять не нужно. Для пустого списка верните пустой список.

Пример: `[[1, 2], [3, 4]]` → `[[1, 2, 3], [3, 4, 7], [4, 6, 10]]`.
