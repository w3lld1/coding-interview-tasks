# Поиск слов в буквенной сетке

**Сложность:** средняя · **Язык:** Python · **Темы:** [Матрицы и сетки](../matrices/), [Строки](../strings/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-22?utm_source=github&utm_medium=tasks-repo)**

Реализуйте класс `WordSearch(puzzle)`, где `puzzle` — список строк одинаковой длины (сетка букв). Метод `search(word)` ищет слово по прямой в любом из восьми направлений: по горизонтали, вертикали или диагонали, в обе стороны. Если слово найдено, верните кортеж из двух точек `Point(x, y)` — первой и последней буквы слова в порядке чтения; `x` — номер столбца, `y` — номер строки, оба с нуля. Слово не может поворачивать и переходить через край сетки. Если слова нет, верните `None`.
