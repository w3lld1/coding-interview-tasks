# Рамка вокруг рисунка

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-493?utm_source=github&utm_medium=tasks-repo)**

Картинка — список одинаковых по длине строк `image`: `#` — закрашенный пиксель, `.` — пустой. Найдите наименьший прямоугольник со сторонами по линиям сетки, который содержит все закрашенные пиксели. Верните `[верх, лево, низ, право]` — номера крайних строки и столбцов (с нуля, границы включительно). Если закрашенных пикселей нет, верните пустой список.

Пример: `["....", ".##.", "..#.", "...."]` → `[1, 1, 2, 2]`.
