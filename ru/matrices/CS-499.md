# Одинокие гости

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-499?utm_source=github&utm_medium=tasks-repo)**

План зала — непустой список одинаковых по длине строк `seats`: `#` — занятое место, `.` — свободное. Гость одинок, если среди восьми клеток вокруг его места (по сторонам и по диагоналям) нет ни одного занятого места. Верните число одиноких гостей. Клеток за краем плана нет.

Пример: `["#.#", ".#."]` → `0` (средний гость соседствует по диагонали с обоими), `["#..", "..#"]` → `2`.
