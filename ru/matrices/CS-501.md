# Вид квадратной матрицы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Математика](../math/)

Дана квадратная матрица целых `matrix` размером `n × n` (`n ≥ 1`). Верните строку-название её вида, проверяя виды в таком порядке: `"identity"` — на главной диагонали единицы, везде вне её нули; `"diagonal"` — все числа вне главной диагонали равны нулю; `"upper"` — все числа ниже главной диагонали равны нулю; `"lower"` — все числа выше главной диагонали равны нулю; `"other"` — ни один вид не подошёл. Возвращайте первое подошедшее название.

Пример: `[[1, 2], [0, 3]]` → `"upper"`; `[[2, 0], [0, 3]]` → `"diagonal"`.
