# Матрица по спирали

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-15?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `spiral_matrix(size)`. Она получает неотрицательное число n и возвращает квадратную матрицу n × n (список строк), заполненную числами от 1 до n² по спирали. Начинайте с левого верхнего угла и двигайтесь по часовой стрелке: вправо, вниз, влево, вверх, с каждым витком приближаясь к центру. Например, для n = 3 ответ `[[1, 2, 3], [8, 9, 4], [7, 6, 5]]`. Для n = 0 верните пустой список.
