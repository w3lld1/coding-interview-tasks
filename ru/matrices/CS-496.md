# Сбор монет по маршруту

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Словари и множества](../hashing/)

Игровое поле — прямоугольный список списков целых `board`: в клетке лежит столько монет, каково число (оно может быть отрицательным — это штраф). Игрок стоит в левой верхней клетке `(0, 0)` и сразу забирает её содержимое. Строка `moves` состоит из символов `U`, `D`, `L`, `R` (вверх, вниз, влево, вправо). Каждая команда сдвигает игрока на соседнюю клетку, и он забирает её содержимое; команда, ведущая за край поля, пропускается. Содержимое клетки забирается только один раз: при повторном заходе клетка пуста. Верните сумму всего забранного.

Пример: `[[1, 2], [3, 4]]`, `"RLRD"` → `7` (клетки `1`, `2` и `4`).
