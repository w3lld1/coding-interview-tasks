# Победитель в «Четыре в ряд»

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-490?utm_source=github&utm_medium=tasks-repo)**

Доска «Четыре в ряд» — непустой список одинаковых по длине строк `board`: `R` — красная фишка, `Y` — жёлтая, `.` — пустая клетка (нулевая строка — верхняя). Игрок выиграл, если у него есть четыре подряд идущие фишки по горизонтали, вертикали или любой из двух диагоналей. Верните `"R"` или `"Y"` для победителя, а если никто не выиграл, верните пустую строку `""`. Одновременно четвёрки двух игроков не бывает. Доска может быть любого размера.

Пример: `["....", "R...", ".R..", "..R.", "...R"]` → `"R"` (диагональ).
