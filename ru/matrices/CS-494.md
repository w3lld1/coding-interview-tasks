# Уменьшение картинки вдвое

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-494?utm_source=github&utm_medium=tasks-repo)**

Серая картинка — прямоугольный список списков неотрицательных целых `image`; число строк и число столбцов чётные (картинка может быть пустой). Уменьшите её вдвое по каждой стороне: картинка делится на блоки 2×2, а каждый блок заменяется одним пикселем — средним арифметическим четырёх значений, округлённым вниз. Верните новую картинку; для пустой картинки верните пустой список.

Пример: `[[1, 3, 0, 0], [5, 7, 0, 1]]` → `[[4, 0]]`.
