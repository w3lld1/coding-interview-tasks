# Самый горячий квадрат карты

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Поиск и сортировка](../search-sort/)

Тепловая карта — прямоугольный список списков целых `heat`, число `k` — размер окна: `1 ≤ k ≤` меньшего из размеров карты. Среди всех квадратных окон `k × k` найдите то, у которого сумма значений наибольшая. Верните `[строка, столбец]` его левого верхнего угла (с нуля). Если таких окон несколько, верните то, что встречается раньше при обходе по строкам: с меньшей строкой, а при равных строках — с меньшим столбцом.

Пример: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]`, `2` → `[1, 1]` (сумма `5 + 6 + 8 + 9 = 28`).
