# Заражённые апельсины

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Деревья и графы](../trees-graphs/)

Склад — таблица чисел: `0` — пустая клетка, `1` — свежий апельсин, `2` — гнилой. Каждую минуту каждый свежий апельсин, у которого есть гнилой сосед сверху, снизу, слева или справа, становится гнилым (все заражения в минуту происходят одновременно). Верните число минут, через которое не останется свежих апельсинов. Если свежих апельсинов не было с самого начала, ответ `0`; если какой-то свежий апельсин заразить невозможно, ответ `-1`. В таблице не больше 50×50 клеток, пустая таблица даёт `0`.

Пример: `[[2, 1, 1], [1, 1, 0], [0, 1, 1]]` → `4`.
