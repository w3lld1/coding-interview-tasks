# Латинский квадрат

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Словари и множества](../hashing/)

Дан квадрат `square` из `n` строк и `n` столбцов целых чисел (`n ≥ 1`). Это латинский квадрат, если в каждой строке и в каждом столбце каждое число от `1` до `n` встречается ровно один раз (других чисел там нет). Верните `true`, если квадрат латинский, иначе `false`.

Пример: `[[1, 2, 3], [2, 3, 1], [3, 1, 2]]` → `true`; `[[1, 2], [1, 2]]` → `false` (в первом столбце две единицы).
