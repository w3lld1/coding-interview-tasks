# Обход матрицы по диагоналям зигзагом

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-138?utm_source=github&utm_medium=tasks-repo)**

Дана прямоугольная матрица целых чисел (все строки одной длины, до 100×100). Прочитайте её по диагоналям, на которых сумма индексов `строка + столбец` постоянна, начиная с левого верхнего угла: нулевая диагональ — один элемент; первую читайте сверху вниз (строка растёт), вторую — снизу вверх (строка убывает), и так по очереди, пока не дойдёте до правого нижнего угла. Верните все элементы в порядке чтения. Для пустой матрицы (нет строк или нет столбцов) верните пустой список.

Пример: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[1, 2, 4, 7, 5, 3, 6, 8, 9]`.
