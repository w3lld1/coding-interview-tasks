# Суммы колец таблицы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-508?utm_source=github&utm_medium=tasks-repo)**

Дана прямоугольная таблица целых `grid` (возможно, пустая). Кольцо номер 0 — это все клетки по краю таблицы (первая и последняя строки, первый и последний столбцы). Кольцо номер 1 — край того, что осталось после удаления кольца 0, и так далее, пока клетки не кончатся. Верните список сумм колец, начиная с внешнего. Для пустой таблицы верните пустой список.

Пример: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[40, 5]`.
