# Раскраска прямоугольников

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-500?utm_source=github&utm_medium=tasks-repo)**

Есть пустой холст из `rows` строк и `cols` столбцов, каждая клетка — символ `.`. Список `rects` содержит прямоугольники `[r1, c1, r2, c2, d]`: закрасьте все клетки со строками от `r1` до `r2` и столбцами от `c1` до `c2` (границы включительно, с нуля) цифрой `d` (от `1` до `9`). Прямоугольники закрашиваются в порядке списка, поздний перекрывает ранний. Все прямоугольники целиком лежат на холсте, `r1 ≤ r2`, `c1 ≤ c2`. Верните холст как список строк.

Пример: `3`, `4`, `[[0, 0, 1, 1, 1], [1, 1, 2, 3, 2]]` → `["11..", "1222", ".222"]`.
