# Кратчайший мост между островами

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-108?utm_source=github&utm_medium=tasks-repo)**

Дана сетка из символов `0` (вода) и `1` (суша): каждая строка списка — строка сетки. Остров — это группа клеток `1`, соединённых по сторонам (вверх, вниз, влево, вправо). В сетке ровно два острова. Верните наименьшее число клеток воды, которые нужно превратить в сушу, чтобы острова соединились в один. Размер сетки — до 100×100.

Пример: `["0100", "0000", "0000", "0010"]` → `3` (достаточно клеток `(1, 1)`, `(2, 1)` и `(2, 2)`).
