# Тупики в лабиринте

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-419?utm_source=github&utm_medium=tasks-repo)**

Лабиринт задан списком строк `grid` одинаковой длины: `.` — свободная клетка, `#` — стена. Ходить можно на соседнюю клетку вверх, вниз, влево или вправо, только по свободным клеткам. Размер лабиринта не больше 50×50, строк хотя бы одна.

Тупик — свободная клетка, у которой ровно один свободный сосед (по четырём направлениям). Клетка без свободных соседей — не тупик, а изолированная.

Верните число тупиков.

Пример: `["..", "##"]` → `2` (обе клетки — тупики).
