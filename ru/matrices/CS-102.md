# Вода к обоим океанам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Деревья и графы](../trees-graphs/)

Дана прямоугольная карта высот: `heights[r][c]` — высота клетки. Вода из клетки переходит в соседнюю по стороне клетку, если высота соседа не больше высоты текущей (равная высота допустима), и так далее по цепочке. Верхний левый океан омывает клетки первой строки и первого столбца, нижний правый — клетки последней строки и последнего столбца. Вода достигает океана, если из клетки есть цепочка спусков до любой клетки его берега (сама береговая клетка тоже годится). Верните все клетки `[строка, столбец]`, из которых вода достигает обоих океанов, по возрастанию строки, а при равной строке — по возрастанию столбца. Пустая карта даёт `[]`. Размер карты — до 150×150.

Пример: `[[1, 2, 3], [8, 9, 4], [7, 6, 5]]` → `[[0, 2], [1, 0], [1, 1], [1, 2], [2, 0], [2, 1], [2, 2]]`.
