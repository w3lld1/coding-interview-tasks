# Горячие точки тепловой карты

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-488?utm_source=github&utm_medium=tasks-repo)**

Тепловая карта — непустой прямоугольный список списков целых `heat`. Клетка — горячая точка, если её значение строго больше значений всех существующих соседей слева, справа, сверху и снизу (диагонали не считаются). У клетки на краю соседей меньше; клетка единственной карты 1×1 — горячая точка. Верните координаты `[строка, столбец]` всех горячих точек в порядке обхода по строкам: сначала по строке, затем по столбцу.

Пример: `[[1, 3, 1], [2, 2, 4]]` → `[[0, 1], [1, 2]]`.
