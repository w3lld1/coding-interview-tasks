# Змейкой по таблице

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-507?utm_source=github&utm_medium=tasks-repo)**

Дана прямоугольная таблица целых `grid` (возможно, пустая). Обойдите её «змейкой»: нулевую строку читайте слева направо, первую — справа налево, вторую — снова слева направо и так далее. Верните все числа в порядке обхода одним списком. Для пустой таблицы верните пустой список.

Пример: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[1, 2, 3, 6, 5, 4, 7, 8, 9]`.
