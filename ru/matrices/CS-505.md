# Шахматная раскраска

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-505?utm_source=github&utm_medium=tasks-repo)**

Дана непустая таблица символов `grid` — список одинаковых по длине строк. Она раскрашена как шахматная доска, если любые две клетки, имеющие общую сторону, содержат разные символы. Верните `true`, если это так, иначе `false`. Таблица из одной клетки подходит. Допустимы любые символы, не обязательно два разных на всю таблицу.

Пример: `["#.#", ".#."]` → `true`; `["ab", "bb"]` → `false`.
