# Суммы по прямоугольникам таблицы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/), [Массивы и списки](../arrays/)

Дана таблица целых `grid` и список запросов `queries`. Запрос `[r1, c1, r2, c2]` просит сумму всех чисел в прямоугольнике со строками от `r1` до `r2` и столбцами от `c1` до `c2` (границы включительно, с нуля, `r1 ≤ r2`, `c1 ≤ c2`, прямоугольник лежит в таблице). Верните список ответов в порядке запросов. Запросов может быть много, поэтому выгодно один раз подготовить таблицу и отвечать на каждый запрос за несколько операций, а не складывать все клетки прямоугольника заново.

Пример: `[[1, 2, 3], [4, 5, 6]]`, `[[0, 1, 1, 2], [1, 0, 1, 0]]` → `[16, 4]`.
