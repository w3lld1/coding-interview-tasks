# Следующее поколение игры «Жизнь»

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-26?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `tick(matrix)`. Она получает прямоугольную матрицу из нулей и единиц (1 — живая клетка, 0 — мёртвая) и возвращает новую матрицу — следующее поколение игры «Жизнь». Живая клетка остаётся живой, если у неё два или три живых соседа. Мёртвая клетка оживает, если у неё ровно три живых соседа. Во всех остальных случаях клетка становится мёртвой. Соседи — восемь окружающих клеток внутри матрицы; края не замыкаются. Все клетки считайте одновременно по исходной матрице. Для пустой матрицы верните пустой список.
