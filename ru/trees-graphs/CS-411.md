# Самая большая компания

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-411?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — знакомства. Группа — набор людей, где любые двое связаны цепочкой знакомств; человек без знакомых — группа из одного. Здесь `1 ≤ n ≤ 1000`.

Верните размер самой большой группы.

Пример: `5`, `[[0, 1], [1, 2], [3, 4]]` → `3`.
