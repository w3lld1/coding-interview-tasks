# Телепорты и турболифты

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-27?utm_source=github&utm_medium=tasks-repo)**

На космическом корабле `n` комнат с номерами от 1 до `n`; `colors[i]` — цвет комнаты `i + 1` (строка из одного-двух символов `a-z`, `0-9`). Из любой комнаты можно мгновенно, за 0 секунд, телепортироваться в любую другую комнату того же цвета.

Кроме того, есть односторонние турболифты: `lifts[j] = [a, b, t]` увозит из комнаты `a` в комнату `b` за `t` секунд (`0 ≤ t ≤ 1000`); лифтов может быть несколько, в том числе из комнаты в неё же. Для каждого запроса `queries[j] = [p, q]` найдите наименьшее время пути из комнаты `p` в комнату `q`, а если пути нет, ответьте `-1`. Верните список ответов в порядке запросов.

Пример: `["gl", "t3", "t3"]`, `[[1, 2, 217], [3, 2, 567], [1, 1, 21]]`, `[[2, 1], [2, 3]]` → `[-1, 0]`.
