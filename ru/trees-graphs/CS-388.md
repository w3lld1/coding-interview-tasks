# Дерево-зеркало

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Дерево симметрично, если его левое поддерево — зеркальное отражение правого: форма совпадает при отражении, а значения в соответствующих узлах равны. Верните `true` для симметричного дерева, иначе `false`. Пустое дерево и дерево из одного узла симметричны.

Пример: `values = [1, 2, 2, 3, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, -1, 4, -1, -1]` → `true` (у левой двойки есть левый потомок 3, у правой — правый потомок 3).
