# Остановки в одну линию

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-424?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — перегоны между остановками. Остановки выстраиваются в линию, если их можно записать в ряд так, что перегоны соединяют ровно соседей по ряду и больше ничего. Здесь `1 ≤ n ≤ 1000`, петель `[a, a]` нет.

Верните `true`, если остановки образуют линию, иначе `false`. Одна остановка без перегонов — линия.

Пример: `4`, `[[2, 0], [0, 3], [3, 1]]` → `true` (ряд 2, 0, 3, 1); `[[0, 1], [0, 2], [0, 3]]` при `n = 4` → `false`.
