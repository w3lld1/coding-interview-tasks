# Все маршруты до конечной

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-421?utm_source=github&utm_medium=tasks-repo)**

В городе `n` станций с номерами `0…n-1`; список `roads` содержит односторонние линии `[from, to]`, причём всегда `from < to`, поэтому по кругу ездить нельзя. Одна и та же линия в списке не повторяется. Здесь `1 ≤ n ≤ 20`. Маршрутов не больше 100.

Верните все маршруты со станции `0` на станцию `n-1`, каждый — списком станций от `0` до `n-1`. Маршруты упорядочите лексикографически (сравнивая списки по первой отличающейся станции). Если `n = 1`, маршрут один: `[0]`. Если проехать нельзя, верните пустой список.

Пример: `4`, `[[0, 1], [0, 2], [1, 3], [2, 3]]` → `[[0, 1, 3], [0, 2, 3]]`.
