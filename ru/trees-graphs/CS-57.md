# Обход бинарного дерева по уровням

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-57?utm_source=github&utm_medium=tasks-repo)**

Бинарное дерево задано тремя списками одной длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`. Верните значения узлов по уровням сверху вниз: список для каждого уровня, внутри уровня слева направо. У пустого дерева (пустые списки) ответ — пустой список. В дереве до 1000 узлов, номера узлов не обязаны идти по уровням.

Пример: `values = [3, 9, 20, 15, 7]`, `left = [1, -1, 3, -1, -1]`, `right = [2, -1, 4, -1, -1]` → `[[3], [9, 20], [15, 7]]`.
