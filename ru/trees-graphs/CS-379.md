# Уровень сотрудника в оргструктуре

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Оргструктура компании. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Глубина узла — число шагов от него вверх до корня; у корня она равна `0`. Дан список `parent` и номер сотрудника `node`: верните его глубину.

Пример: `[-1, 0, 0, 1, 1, 2]`, `4` → `2` (4 → 1 → 0).
