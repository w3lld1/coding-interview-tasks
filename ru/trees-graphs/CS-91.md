# Суммы расстояний в дереве

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Динамическое программирование](../dp/)

Дано неориентированное дерево из `n` вершин с номерами от `0` до `n - 1` (`1 ≤ n ≤ 10000`) и список его `n - 1` рёбер, каждое — пара `[u, v]`. Расстояние между двумя вершинами — число рёбер на пути между ними. Для каждой вершины `i` посчитайте сумму расстояний от неё до всех остальных вершин и верните список из `n` чисел, где на позиции `i` стоит ответ для вершины `i`. Дерево из одной вершины (рёбер нет) даёт `[0]`.

Решение, которое запускает обход из каждой вершины, работает за O(n²) и слишком медленно для больших деревьев.

Пример: `n = 5`, рёбра `[[0, 1], [0, 2], [2, 3], [2, 4]]` → `[6, 9, 5, 8, 8]`.
