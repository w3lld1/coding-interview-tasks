# Куда можно добраться

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-410?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — двусторонние авиарейсы между городами.

Верните номера всех городов, до которых можно долететь из города `start` с любым числом пересадок, по возрастанию. Сам `start` входит в ответ.

Пример: `6`, `[[0, 1], [1, 2], [3, 4]]`, `0` → `[0, 1, 2]`.
