# Кольцо из дорог

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-416?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — двусторонние дороги. Кольцо — это замкнутый маршрут по дорогам, в котором ни одна дорога не используется дважды. Две одинаковые дороги между одной парой городов (`[a, b]` и `[b, a]` тоже) уже образуют кольцо. Петель `[a, a]` нет.

Верните `true`, если в сети есть хотя бы одно кольцо, иначе `false`.

Пример: `3`, `[[0, 1], [1, 2], [2, 0]]` → `true`; `4`, `[[0, 1], [1, 2], [2, 3]]` → `false`.
