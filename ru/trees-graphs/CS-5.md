# Путь по свободным клеткам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-5?utm_source=github&utm_medium=tasks-repo)**

Дана квадратная таблица из нулей и единиц: `0` — свободная клетка, `1` — стена. Нужно дойти из левой верхней клетки в правую нижнюю, переходя со свободной клетки на любую из 8 соседних свободных клеток (включая диагональные). Верните длину кратчайшего пути, то есть число клеток в нём, включая первую и последнюю. Если одна из этих двух клеток — стена или пути нет, верните `-1`. Таблица из одной свободной клетки даёт `1`, пустая таблица — `-1`. Сторона таблицы не больше 100.

Пример: `[[0, 1], [1, 0]]` → `2`.
