# Шаги по посещённым клеткам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-42?utm_source=github&utm_medium=tasks-repo)**

Робот стоит на сетке из `rows` строк (сверху вниз, с 1) и `cols` столбцов (слева направо, с 1) в клетке `start` = `[строка, столбец]`. Ему дана строка команд из символов `N` (на север, строка −1), `S` (юг, строка +1), `E` (восток, столбец +1) и `W` (запад, столбец −1).

По команде робот делает шаг в этом направлении. Если клетка уже посещалась (включая стартовую), он продолжает идти в том же направлении, пока не попадёт в клетку, где ещё не был. Робот никогда не выходит за границы сетки. Верните `[строка, столбец]` клетки, в которой он окажется после всех команд (1 ≤ rows, cols ≤ 50000, до 50000 команд).

Пример: `3`, `6`, `[2, 3]`, `"EEWNS"` → `[3, 2]`.
