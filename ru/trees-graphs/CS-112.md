# Дешёвая сеть между точками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-112?utm_source=github&utm_medium=tasks-repo)**

Даны точки на плоскости: `points[i] = [x, y]`, координаты целые, от -10⁶ до 10⁶, точек не больше 1000, совпадающие точки допустимы. Стоимость кабеля между двумя точками равна манхэттенскому расстоянию `|x1 - x2| + |y1 - y2|`. Верните наименьшую суммарную стоимость кабелей, при которой все точки оказываются связаны друг с другом (напрямую или через другие точки). Для пустого списка и для одной точки ответ `0`.

Пример: `[[0, 0], [2, 2], [3, 10], [5, 2], [7, 0]]` → `20`.
