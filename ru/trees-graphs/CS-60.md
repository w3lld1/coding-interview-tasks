# Проверка двоичного дерева поиска

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-60?utm_source=github&utm_medium=tasks-repo)**

Бинарное дерево задано списками `values`, `left`, `right` одной длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера потомков или `-1`. Корень — узел `0`. Верните `true`, если дерево — строгое дерево поиска: у каждого узла все значения в левом поддереве строго меньше его значения, а в правом строго больше. Равные значения недопустимы. Пустое дерево (пустые списки) считается деревом поиска. Значения — 32-битные целые, узлов до 1000.

Пример: `values = [5, 1, 4, 3, 6]`, `left = [1, -1, 3, -1, -1]`, `right = [2, -1, 4, -1, -1]` → `false` (у узла 4 слева стоит 3, но 3 лежит в правом поддереве корня 5 и должно быть больше 5).
