# Прямые подчинённые

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-380?utm_source=github&utm_medium=tasks-repo)**

Оргструктура компании. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Верните список длины `n`, в котором элемент `i` — число прямых подчинённых сотрудника `i` (узлов, чей родитель равен `i`). Для пустого дерева верните пустой список.

Пример: `[-1, 0, 0, 1, 1, 2]` → `[2, 2, 1, 0, 0, 0]`.
