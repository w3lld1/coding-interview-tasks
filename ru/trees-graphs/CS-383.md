# Узлы с одним потомком

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-383?utm_source=github&utm_medium=tasks-repo)**

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Верните, сколько в дереве узлов, у которых ровно один потомок (левый или правый, но не оба). Листья и узлы с двумя потомками не считаются. Для пустого дерева ответ `0`.

Пример: `values = [5, 3, 8, 1]`, `left = [1, 3, -1, -1]`, `right = [2, -1, -1, -1]` → `1` (узел 1, у него только левый потомок).
