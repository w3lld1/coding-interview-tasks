# Размеры папок

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Файловая система. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Узлы — папки, `parent[i]` — папка, в которой лежит папка `i`. В папке `i` лежат файлы общим размером `sizes[i]` (без вложенных папок). Верните список, в котором элемент `i` — полный размер папки `i`: её собственные файлы плюс полные размеры всех вложенных папок. Для пустого дерева верните пустой список.

Пример: `[-1, 0, 0, 1]`, `[5, 10, 20, 30]` → `[65, 40, 20, 30]`.
