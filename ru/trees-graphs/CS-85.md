# Кратчайший обход всех вершин небольшого графа

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-85?utm_source=github&utm_medium=tasks-repo)**

Дан неориентированный невзвешенный граф: число вершин `n` (от 1 до 12, вершины `0..n-1`) и список рёбер `edges` (пары `[u, v]`, без петель и без повторов). Маршрут начинается в любой вершине, на каждом шаге переходит по ребру в соседнюю вершину и заканчивается в любой вершине; вершины и рёбра можно проходить повторно. Верните наименьшее число шагов маршрута, который побывает в каждой вершине хотя бы раз. Для графа из одной вершины ответ `0`. Если граф несвязный и такого маршрута нет, верните `-1`.

Пример: `n = 5`, `[[0, 1], [0, 2], [0, 3], [3, 4]]` → `5` (например, `1 → 0 → 2 → 0 → 3 → 4`).
