# Узлы-суммы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-398?utm_source=github&utm_medium=tasks-repo)**

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Назовём узел узлом-суммой, если у него есть хотя бы один потомок и его значение равно сумме значений его прямых потомков (отсутствующий потомок даёт `0`). Листья узлами-суммами не считаются, даже если их значение `0`. Верните число узлов-сумм. Для пустого дерева ответ `0`.

Пример: `values = [9, 4, 5, 2, 2]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `2` (9 = 4 + 5 и 4 = 2 + 2).
