# Сотрудники без подчинённых

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-378?utm_source=github&utm_medium=tasks-repo)**

Оргструктура компании. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Верните, сколько в компании сотрудников, у которых нет ни одного прямого подчинённого (листьев дерева). Пустое дерево даёт `0`, дерево из одного корня — `1`.

Пример: `[-1, 0, 0, 1, 1, 2]` → `3` (сотрудники 3, 4 и 5).
