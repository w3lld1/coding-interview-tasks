# Время доставки сигнала

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

В сети `n` узлов с номерами от `0` до `n - 1`. Каждая запись `[u, v, w]` в списке `times` — это направленная связь: сигнал идёт от `u` к `v` за `w` единиц времени (`w` ≥ 0, связей между одной парой может быть несколько). Сигнал отправляют из узла `k` в момент 0 и он расходится по всем связям одновременно. Верните время, когда сигнал дойдёт до всех узлов, то есть наибольшее из кратчайших времён до узлов. Если до какого-то узла сигнал не доходит, верните `-1`. Узлов не больше 100, связей не больше 6000.

Пример: `4`, `[[1, 0, 1], [1, 2, 1], [2, 3, 1]]`, `1` → `2`.
