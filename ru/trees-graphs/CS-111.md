# Путь с наибольшей вероятностью

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-111?utm_source=github&utm_medium=tasks-repo)**

Дан неориентированный граф из `n` вершин `0..n-1`. Ребро `edges[i] = [a, b]` проходится успешно с вероятностью `succ_prob[i]` (число от 0 до 1), проходы независимы. Вероятность успеха пути — произведение вероятностей его рёбер. Найдите путь из `start_node` в `end_node` с наибольшей вероятностью и верните её. Если пути нет, верните `0.0`. Если `start_node` равен `end_node`, вероятность `1.0`. Рёбер — до 1000. Числа сравниваются с точностью 1e-6.

Пример: `3`, `[[0, 1], [1, 2], [0, 2]]`, `[0.5, 0.5, 0.2]`, `0`, `2` → `0.25` (путь `0 → 1 → 2` лучше прямого ребра).
