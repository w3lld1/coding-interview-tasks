# Узлы на расстоянии k от заданного

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-155?utm_source=github&utm_medium=tasks-repo)**

Дерево задано тремя списками: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — индексы левого и правого детей или `-1`, если ребёнка нет. Корень — узел `0`; у пустого дерева все три списка пусты. Все значения в дереве различны. Даны значение `target`, которое точно есть в дереве, и целое `k >= 0`.

Расстояние между узлами — число рёбер на пути между ними; по ребру можно идти и вниз, и вверх. Верните значения всех узлов на расстоянии ровно `k` от узла со значением `target`, по возрастанию. Если таких узлов нет, верните пустой список. При `k = 0` ответ — сам `target`.

Пример: дерево `3(5(6, 2(7, 4)), 1(0, 8))`, `target = 5`, `k = 2` → `[1, 4, 7]`.
