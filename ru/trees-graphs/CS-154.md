# Ближайший общий предок двух значений

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-154?utm_source=github&utm_medium=tasks-repo)**

Дерево задано тремя списками: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — индексы левого и правого детей или `-1`, если ребёнка нет. Корень — узел `0`; у пустого дерева все три списка пусты. Все значения в дереве различны. Даны два значения `p` и `q`, оба точно есть в дереве (они могут совпадать).

Ближайший общий предок — самый глубокий узел, в поддереве которого лежат оба узла со значениями `p` и `q`; узел считается предком самого себя. Верните значение этого узла.

Пример: дерево `3(5(6, 2(7, 4)), 1(0, 8))`, `p = 5`, `q = 4` → `5`; для `p = 6`, `q = 8` → `3`.
