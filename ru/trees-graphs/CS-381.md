# Размер команды менеджера

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-381?utm_source=github&utm_medium=tasks-repo)**

Оргструктура компании. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Команда менеджера — он сам, его прямые подчинённые, их подчинённые и так далее вниз по дереву. Дан список `parent` и номер `manager`: верните размер его команды, считая самого менеджера.

Пример: `[-1, 0, 0, 1, 1, 2]`, `1` → `3` (сотрудники 1, 3 и 4).
