# Число поколений

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Семейное древо. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Корень — прародитель, его дети — второе поколение и так далее. Верните число поколений: сколько уровней в дереве, считая уровень корня. Пустое дерево даёт `0`, дерево из одного корня — `1`.

Пример: `[-1, 0, 0, 1, 1, 2]` → `3` (поколения: {0}, {1, 2}, {3, 4, 5}).
