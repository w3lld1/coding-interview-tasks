# Есть ли дорога между городами

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-405?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — двусторонние дороги между городами.

Верните `true`, если из города `start` можно добраться до города `end`, проезжая по дорогам (через любое число промежуточных городов), иначе `false`. Если `start` равен `end`, ответ `true`.

Пример: `5`, `[[0, 1], [1, 2], [3, 4]]`, `0`, `2` → `true`; для `0` и `4` ответ был бы `false`.
