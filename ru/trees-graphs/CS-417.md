# Обход всех улиц

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Математика](../math/)

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — улицы между перекрёстками; две одинаковые улицы между одной парой перекрёстков — это две разные улицы. Петель `[a, a]` нет.

Почтальон хочет пройти по каждой улице ровно один раз и вернуться на перекрёсток, с которого начал (стартовать можно с любого). Верните `true`, если это возможно, иначе `false`. Если улиц нет, ответ `true`.

Известный факт: такой обход существует, если у каждого перекрёстка чётное число улиц и все перекрёстки с улицами лежат в одной связной части.

Пример: `3`, `[[0, 1], [1, 2], [2, 0]]` → `true`; `4`, `[[0, 1], [1, 2], [2, 3]]` → `false`.
