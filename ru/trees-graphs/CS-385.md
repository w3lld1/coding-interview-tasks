# Обход с корнем в конце

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Верните значения узлов в порядке обратного обхода (post-order): сначала всё левое поддерево, затем всё правое, и только потом сам узел. Так, например, считают размер папок: сначала содержимое, потом сама папка. Для пустого дерева верните пустой список.

Пример: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `[1, 3, 2, 6, 4]`.
