# Восстановление дерева по двум обходам

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JAVA-24?utm_source=github&utm_medium=tasks-repo)**

Восстановите двоичное дерево с уникальными значениями по его прямому и симметричному обходам. В прямом обходе сначала идёт корень, затем левое и правое поддеревья, а в симметричном — левое поддерево, корень и правое. Верните обратный обход восстановленного дерева: левое поддерево, правое, затем корень. Если данные несовместимы (разные наборы значений, разная длина, дубликаты), сообщите об ошибке: бросьте исключение, в Go верните error.
