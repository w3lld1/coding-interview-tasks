# Реактивные ячейки и подписки

**Сложность:** сложная · **Язык:** JavaScript · **Темы:** [Деревья и графы](../trees-graphs/), [Классы и ООП](../oop/), [Функции и замыкания](../functions/)

Реализуйте реактивные ячейки:

- `InputCell(value)` — входная ячейка; текущее значение в поле `value`, метод `setValue(value)` меняет его;
- `ComputeCell(inputCells, fn)` — вычисляемая ячейка; поле `value` равно результату `fn`, который читает значения ячеек из `inputCells`; при изменении любой ячейки, от которой она зависит, значение пересчитывается;
- `CallbackCell(fn)` — обработчик изменения; `fn` вызывается при уведомлении;
- `addCallback(cb)` и `removeCallback(cb)` вычисляемой ячейки подключают и отключают обработчик `CallbackCell`.

Изменение входной ячейки распространяется по всем зависимостям до устойчивого состояния. Обработчик вызывается, только если итоговое значение ячейки изменилось, и не больше одного раза за одно изменение входа, даже если промежуточных пересчётов было несколько.
