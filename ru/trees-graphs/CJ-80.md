# Превращение металлов в свинец

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-80?utm_source=github&utm_medium=tasks-repo)**

Известно `m` металлов (`2 ≤ m ≤ 500`), свинец — металл номер 1. Для каждого металла `i` есть ровно одна формула `recipes[i-1] = [a, b]` (`1 ≤ a < b ≤ m`): она уничтожает один грамм металла `i` и создаёт по одному грамму металлов `a` и `b` (среди них может быть и сам `i`). Формулы работают только с целыми граммами, применять их можно сколько угодно раз, пока есть нужный металл. В казне лежит `grams[i-1]` граммов металла `i` (`0 ≤ grams[i-1] ≤ 10^9`).

Верните строку `"UNBOUNDED"`, если свинца можно получить сколько угодно. Иначе верните наибольшее достижимое количество граммов свинца по модулю `1000000007` в виде десятичной строки.

Пример: `[[1, 2], [1, 2]]`, `[1, 0]` → `"UNBOUNDED"`.
