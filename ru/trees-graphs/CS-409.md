# Друзья друзей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-409?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — дружба. Человек из «друзей друзей» `start` — тот, кто дружит с кем-то из друзей `start`, но сам не друг `start` и не сам `start`.

Верните номера таких людей по возрастанию. Если их нет, верните пустой список.

Пример: `6`, `[[0, 1], [0, 2], [1, 3], [2, 4], [3, 5]]`, `0` → `[3, 4]`.
