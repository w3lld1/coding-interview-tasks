# Острова на карте

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-1?utm_source=github&utm_medium=tasks-repo)**

Карта задана списком строк одинаковой длины из символов `'1'` (суша) и `'0'` (вода). Остров — это набор клеток суши, соединённых через общую сторону (вверх, вниз, влево, вправо); по диагонали клетки не соединяются. Верните число островов. Пустая карта (пустой список) даёт `0`. На карте не больше 50 строк по 50 символов.

Пример: `["11000", "11000", "00100", "00011"]` → `3`.
