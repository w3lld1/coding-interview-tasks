# Сеть без лишних связей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-406?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Сеть — это дерево, если все вершины связаны между собой и при этом нет ни одного цикла (никакая связь не лишняя). Повторяющееся ребро образует цикл. Здесь `1 ≤ n ≤ 1000`, петель `[a, a]` нет.

Верните `true`, если граф — дерево, иначе `false`. Одна вершина без рёбер — дерево.

Пример: `4`, `[[0, 1], [1, 2], [1, 3]]` → `true`; `[[0, 1], [1, 2], [2, 0]]` при `n = 4` → `false`.
