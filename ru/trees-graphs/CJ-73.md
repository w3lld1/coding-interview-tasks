# Почта на сменных лошадях

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-73?utm_source=github&utm_medium=tasks-repo)**

Есть n городов (2 ≤ n ≤ 30), в каждом одна лошадь: `horses[i] = [e, s]` — лошадь города i может пройти суммарно не больше `e` километров и скачет со скоростью `s` км/ч. `distances[i][j]` — длина дороги из города i в город j в километрах или `-1`, если дороги нет (дорога длины `0` — тоже дорога, её проезд занимает 0 часов; дороги односторонние, `distances[i][i] = -1`, неравенство треугольника не обязано выполняться). Курьер выезжает на лошади начального города; в любом городе он может мгновенно пересесть на лошадь этого города, а пройденный лошадью путь не восстанавливается. Для каждого запроса `queries[k] = [u, v]` (города нумеруются с 0, u ≠ v) верните минимальное время доставки из u в v в часах или `-1`, если доставка невозможна. Ответы сравниваются с точностью 1e-6.

Пример: `[[2, 3], [2, 4], [4, 4]]`, `[[-1, 1, -1], [-1, -1, 1], [-1, -1, -1]]`, `[[0, 2]]` → `[0.5833333333]`.
