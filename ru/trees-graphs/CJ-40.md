# Игра с карточками

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-40?utm_source=github&utm_medium=tasks-repo)**

В коробке N карточек (2 ≤ N ≤ 100). На i-й карточке с одной стороны записано красное число `red[i]`, с другой синее `blue[i]`, оба положительные целые не больше 10^9. Пока в коробке есть хотя бы две карточки, делается ход: вы вынимаете две карточки, берёте красное число R с одной и синее число B с другой, прибавляете `R xor B` (побитовое исключающее ИЛИ) к общей сумме, затем одну из двух карточек возвращаете в коробку, а другую убираете навсегда. Игра заканчивается, когда в коробке осталась одна карточка. Сумма вначале равна 0.

Верните наименьшую возможную итоговую сумму.

Пример: `[1, 2]`, `[3, 3]` → `1` (красное число 2 второй карточки и синее 3 первой дают `2 xor 3 = 1`).
