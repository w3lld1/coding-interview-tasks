# Сумма на нечётных уровнях

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-399?utm_source=github&utm_medium=tasks-repo)**

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Корень лежит на уровне `0`, его потомки — на уровне `1` и так далее. Верните сумму значений всех узлов, которые лежат на нечётных уровнях (1, 3, 5, …). Значения могут быть отрицательными. Для пустого дерева ответ `0`.

Пример: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `8` (уровень 1: 2 + 6).
