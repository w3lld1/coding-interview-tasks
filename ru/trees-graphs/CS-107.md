# Безопасные вершины графа

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-107?utm_source=github&utm_medium=tasks-repo)**

Дан ориентированный граф: `graph[u]` — список вершин, в которые ведут рёбра из `u` (вершины `0..n-1`). Вершина безопасна, если любой путь из неё, как бы вы ни шли, приводит в вершину без исходящих рёбер, то есть из неё нельзя попасть в цикл (петля `u → u` тоже цикл). Верните все безопасные вершины по возрастанию. Пустой граф даёт `[]`. Вершин — до 1000.

Пример: `[[1, 2], [2, 3], [5], [0], [5], [], []]` → `[2, 4, 5, 6]`.
