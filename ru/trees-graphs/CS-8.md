# Слияние групп по рёбрам

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-8?utm_source=github&utm_medium=tasks-repo)**

Есть `n` вершин с номерами от `0` до `n - 1` (`n` ≥ 1), сначала между ними нет связей. Рёбра `[u, v]` добавляются по одному в заданном порядке (петель нет, повторы возможны). Верните список той же длины, что и список рёбер: его `i`-й элемент — число компонент связности после добавления первых `i + 1` рёбер. Если рёбер нет, верните пустой список. Вершин не больше 100000, рёбер не больше 100000.

Пример: `4`, `[[0, 1], [2, 3], [1, 2]]` → `[3, 2, 1]`.
