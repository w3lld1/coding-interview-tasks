# Раскраска графа в два цвета

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-7?utm_source=github&utm_medium=tasks-repo)**

Дан неориентированный граф: `n` вершин с номерами от `0` до `n - 1` и список рёбер `[u, v]`. Петель нет, кратные рёбра возможны, граф может быть несвязным. Верните `true`, если вершины можно раскрасить в два цвета так, чтобы концы каждого ребра были разного цвета, иначе `false`. Граф без рёбер раскрашивается. Вершин не больше 1000, рёбер не больше 5000.

Пример: `3`, `[[0, 1], [1, 2], [2, 0]]` → `false`.
