# Самый большой остров после одной засыпки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/), [Словари и множества](../hashing/)

Дана прямоугольная карта `grid` из нулей (вода) и единиц (суша), от 1×1 до 500×500. Остров — наибольшая группа единиц, связанных через общие стороны (по диагонали клетки не соседи), его размер — число клеток. Можно превратить не больше одного нуля в единицу или ничего не менять. Верните наибольший размер острова, который можно так получить. Если на карте нет нулей, ответ — число всех клеток; если нет единиц, ответ `1`.

Пересчитывать остров заново для каждого нуля слишком медленно: нужен алгоритм за O(m·n).

Пример: `[[1, 1, 0], [0, 0, 1], [1, 1, 1]]` → `7`: засыпка клетки в центре соединяет остров из 2 клеток сверху и остров из 4 клеток снизу и справа.
