# Листья слева направо

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Лист — узел без потомков. Верните значения всех листьев в порядке слева направо, как их видно на рисунке дерева: сначала листья левого поддерева, затем правого. Дерево из одного узла даёт список из его значения, пустое дерево — пустой список.

Пример: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `[1, 3, 6]`.
