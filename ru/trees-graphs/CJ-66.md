# Поток реки между зданиями

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-66?utm_source=github&utm_medium=tasks-repo)**

Река — прямоугольная сетка из `width` столбцов (x от 0 до width−1) и `height` рядов (y от 0 до height−1). Каждая клетка пропускает не больше 1 единицы воды, вода переходит между клетками с общей стороной. Каждая клетка южного ряда (y = 0) получает 1 единицу притока. Верните наибольший поток, который может дойти до клеток северного ряда (y = height−1).

На реке стоят здания: `buildings[i] = [x0, y0, x1, y1]` — прямоугольник клеток от левого нижнего угла (x0, y0) до правого верхнего (x1, y1) включительно. Через клетки зданий вода не течёт. Здания не перекрываются, но могут соприкасаться. Ограничения: 3 ≤ width ≤ 1000, 3 ≤ height ≤ 10⁸, не больше 200 зданий, так что построить сетку целиком нельзя.

Пример: `3`, `3`, `[[2, 0, 2, 0], [0, 2, 0, 2]]` → `1`.
