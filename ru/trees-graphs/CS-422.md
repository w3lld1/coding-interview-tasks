# До ближайшей зарядки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-422?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — дороги между остановками электробуса. Список `has_charger` из `n` чисел: `1` — на остановке есть зарядная станция, `0` — нет.

Верните наименьшее число перегонов (рёбер), которое нужно проехать от остановки `start` до остановки с зарядкой. Если зарядка есть на самой `start`, ответ `0`. Если до зарядки не добраться, верните `-1`.

Пример: `5`, `[[0, 1], [1, 2], [2, 3], [3, 4]]`, `[0, 0, 1, 0, 1]`, `0` → `2`.
