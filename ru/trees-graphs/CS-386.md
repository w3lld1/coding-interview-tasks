# Обход зеркального дерева

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Представьте, что у каждого узла поменяли местами левого и правого потомка (зеркальное отражение дерева). Верните значения зеркального дерева в прямом порядке (pre-order): сначала узел, затем его левое, затем правое поддерево — уже в отражённом виде. Само дерево перестраивать не нужно. Для пустого дерева верните пустой список.

Пример: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]` → `[4, 6, 2, 3, 1]`.
