# Корни деревьев минимальной высоты

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-106?utm_source=github&utm_medium=tasks-repo)**

Дано дерево из `n` вершин, пронумерованных от `0` до `n - 1`, и список рёбер `[a, b]`. Если выбрать вершину корнем, высота дерева — наибольшее число рёбер от корня до какой-либо вершины. Верните все вершины, при выборе которых корнем высота минимальна, по возрастанию. При `n = 1` ответ `[0]`. Вершин — до 1000.

Пример: `4`, `[[1, 0], [1, 2], [1, 3]]` → `[1]` (с корнем 1 высота 1, с любым другим корнем — 2).
