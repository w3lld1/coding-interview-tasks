# Ограбление домов на дереве

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Динамическое программирование](../dp/), [Рекурсия и перебор](../recursion/)

Дерево задано тремя списками: `values[i]` — число денег в узле `i` (не меньше 0), `left[i]` и `right[i]` — индексы левого и правого потомков или `-1`, если потомка нет. Корень — узел 0, пустое дерево задано пустыми списками. Вы выбираете набор узлов так, чтобы никакие два узла «родитель — потомок» не были выбраны вместе. Верните наибольшую возможную сумму денег выбранных узлов. Для пустого дерева ответ `0`.

Пример: `values = [3, 2, 3, 3, 1]`, `left = [1, -1, -1, -1, -1]`, `right = [2, 3, 4, -1, -1]` → `7` (узлы со значениями 3, 3 и 1: корень и правый потомок выбрать вместе нельзя, поэтому берём корень и два внука, сумма 3 + 3 + 1).
