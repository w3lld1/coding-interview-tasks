# Самый популярный участник

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-403?utm_source=github&utm_medium=tasks-repo)**

В сообществе `n` участников (`1 ≤ n ≤ 1000`), номера `0…n-1`. Список `edges` — пары `[a, b]`, означающие взаимное знакомство; повторяющаяся пара считается дважды, пар `[a, a]` нет.

Верните номер участника с наибольшим числом знакомств (больше всего вхождений в пары). Если таких несколько, верните наименьший номер. Если знакомств нет вовсе, ответ `0`.

Пример: `4`, `[[0, 1], [1, 2], [1, 3]]` → `1`.
