# Круг лучших друзей

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-70?utm_source=github&utm_medium=tasks-repo)**

В классе n детей с номерами от 0 до n−1. У каждого ребёнка i есть лучший друг `bff[i]` (bff[i] ≠ i), дружба не обязательно взаимна. Нужно посадить по кругу как можно больше детей так, чтобы каждый сидящий оказался рядом со своим лучшим другом — слева или справа. Остальные дети не участвуют. Верните наибольший возможный размер круга. Круг из двух детей допустим, если они лучшие друзья друг друга. Ограничения: 2 ≤ n ≤ 1000.

Пример: `[1, 2, 3, 0]` → `4`.
