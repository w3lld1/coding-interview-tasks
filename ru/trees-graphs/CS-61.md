# Вид дерева справа

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-61?utm_source=github&utm_medium=tasks-repo)**

Бинарное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — индексы его левого и правого потомка (`-1`, если потомка нет). Корень — узел `0`; пустое дерево задано пустыми списками.

Представьте, что вы стоите справа от дерева и смотрите на него. Верните значения узлов, которые вы видите: для каждого уровня, начиная с корня, одно значение — самого правого узла этого уровня. Для пустого дерева верните пустой список. В дереве не больше 1000 узлов.

Пример: `values = [1, 2, 3, 4]`, `left = [1, 3, -1, -1]`, `right = [2, -1, -1, -1]` → `[1, 3, 4]`.
