# Острова после каждой засыпки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/)

Дана карта из `rows` строк и `cols` столбцов (1 ≤ `rows`, `cols` ≤ 1000), вся покрыта водой. Список `positions` (до 10 000 элементов) описывает засыпки по порядку: элемент `[r, c]` превращает клетку в строке `r` и столбце `c` в сушу (все клетки внутри карты; засыпка уже суши ничего не меняет). Остров — это наибольшая группа клеток суши, связанных через общие стороны (по диагонали клетки не соседи).

Верните список той же длины, что `positions`: в позиции `i` — число островов сразу после засыпки `i`. Пустой `positions` даёт `[]`. Пересчитывать всю карту после каждой засыпки слишком медленно.

Пример: `rows = 3`, `cols = 4`, `positions = [[0, 0], [0, 2], [1, 1], [0, 1], [2, 3], [1, 3], [1, 2]]` → `[1, 2, 3, 1, 2, 2, 1]`.
