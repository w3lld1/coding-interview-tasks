# Наименьший маршрут по почтовым индексам

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Поиск и сортировка](../search-sort/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-64?utm_source=github&utm_medium=tasks-repo)**

Есть `n` городов с номерами от `0` до `n − 1`; `zips[i]` — пятизначный индекс города `i` (без ведущих нулей, все разные). Список `flights` содержит пары `[u, v]`: между городами `u` и `v` есть двусторонний рейс. Вы выбираете стартовый город и путешествуете по правилам:
- билет состоит из прямого перелёта `X → Y` и обратного `Y → X`, обратный используется после прямого (между ними можно летать дальше);
- в каждый город можно прилететь прямым перелётом не больше одного раза, в стартовый — ни разу;
- все купленные билеты используются полностью.

По сути вы обходите города как стек: летите вперёд в новый город или возвращаетесь в предыдущий открытый. Посетить нужно все города. Выписывая индекс каждого города при первом посещении (включая стартовый), вы получаете строку из `5n` цифр. Верните наименьшую такую строку. Гарантируется, что все города связаны рейсами; `1 ≤ n ≤ 50`.

Пример: `["10001", "20000", "10000"]`, `[[0, 1], [1, 2]]` → `"100002000010001"`.
