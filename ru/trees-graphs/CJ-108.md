# Восстановление матрицы по контрольным суммам

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-108?utm_source=github&utm_medium=tasks-repo)**

Была квадратная матрица `n × n` из нулей и единиц. Для каждой строки `i` записана её контрольная сумма `row_xor[i]` (XOR всех элементов строки), для каждого столбца `j` — `col_xor[j]`. Потом часть элементов потерялась: в матрице `a` потерянный элемент равен `-1`, остальные равны исходным `0` или `1`.

Потерянный элемент `a[i][j]` можно восстановить вручную за `b[i][j]` часов (для известных элементов `b[i][j] = 0`). Кроме того, элемент можно вычислить бесплатно, если в его строке или столбце он остался единственным неизвестным: его значение даёт контрольная сумма. Верните наименьшее суммарное число часов, после которого вся матрица известна однозначно.

Гарантируется, что потерянные элементы можно заполнить так, чтобы все контрольные суммы сошлись. Ограничения: `1 ≤ n ≤ 30`, `1 ≤ b[i][j] ≤ 1000` для потерянных элементов.

Пример: `[[-1, -1], [-1, -1]]`, `[[1, 10], [100, 1000]]`, `[1, 0]`, `[0, 1]` → `1` (восстановите `a[0][0]`, остальные три элемента вычисляются по суммам).
