# Вычисление отношений

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Словари и множества](../hashing/)

Даны равенства вида `a / b = k`: `equations[i] = [a, b]` и `values[i] = k` (положительное число), где `a` и `b` — имена переменных. Равенства не противоречат друг другу. Для каждого запроса `[x, y]` найдите значение `x / y`. Если его нельзя вывести из равенств или хотя бы одно из имён нигде не встречается, ответ `-1.0`. Для известной переменной `x / x = 1.0`; для неизвестной (которой нет ни в одном равенстве) тоже `-1.0`. Верните список ответов в порядке запросов. Равенств и запросов — до 100. Числа сравниваются с точностью 1e-6.

Пример: равенства `[["a", "b"], ["b", "c"]]`, значения `[2.0, 3.0]`, запросы `[["a", "c"], ["b", "a"], ["a", "e"]]` → `[6.0, 0.5, -1.0]`.
