# Цепочка до директора

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-390?utm_source=github&utm_medium=tasks-repo)**

Оргструктура компании. Дерево задано списком `parent`: `parent[i]` — номер родителя узла `i`, у корня стоит `-1`. Узлы нумеруются с `0`, корень один. Верните список номеров от сотрудника `node` вверх по цепочке начальников до корня включительно: сначала сам сотрудник, затем его непосредственный начальник и так далее, последним корень. Для корня результат — список из одного элемента.

Пример: `[-1, 0, 0, 1, 1, 2]`, `4` → `[4, 1, 0]`.
