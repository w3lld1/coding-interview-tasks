# Все знакомы со всеми

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Словари и множества](../hashing/)

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Рёбра — знакомства. Повторяющиеся рёбра (в том числе `[a, b]` и `[b, a]`) означают одну и ту же пару; петель `[a, a]` нет. Здесь `1 ≤ n ≤ 100`.

Верните `true`, если каждые двое разных людей знакомы напрямую, иначе `false`. Один человек — `true`.

Пример: `3`, `[[0, 1], [1, 2], [0, 2]]` → `true`; `[[0, 1], [1, 2]]` при `n = 3` → `false`.
