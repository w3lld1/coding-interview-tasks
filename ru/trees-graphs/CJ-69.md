# Слова двух языков

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Словари и множества](../hashing/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-69?utm_source=github&utm_medium=tasks-repo)**

Даны предложения `sentences`, каждое — список слов из строчных латинских букв. Предложение 0 точно английское, предложение 1 точно французское, каждое из остальных может быть на любом из двух языков. Все слова английского предложения — английские слова, все слова французского — французские. Слово может повторяться и внутри предложения, и в разных предложениях.

Выберите язык каждого из остальных предложений так, чтобы слов, которые оказываются сразу английскими и французскими, было как можно меньше, и верните это наименьшее число. Ограничения: 2 ≤ число предложений ≤ 200, в первых двух до 100 слов, в остальных до 10.

Пример: `[["a", "b", "c", "d", "e"], ["f", "g", "h", "i", "j"], ["a", "b", "c", "i", "j"], ["f", "g", "h", "d", "e"]]` → `4`.
