# Путь с нужной суммой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-393?utm_source=github&utm_medium=tasks-repo)**

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Путь начинается в корне и заканчивается в листе (узле без потомков). Верните `true`, если есть хотя бы один такой путь, сумма значений на котором (оба конца включены) равна `target`, иначе `false`. Значения могут быть отрицательными. Для пустого дерева ответ `false`.

Пример: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]`, `target = 7` → `true` (4 + 2 + 1).
