# Корректная оргсхема

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-396?utm_source=github&utm_medium=tasks-repo)**

Список `parent` описывает оргсхему компании: `parent[i]` — номер начальника сотрудника `i`, а `-1` означает «начальника нет». Схема корректна, если в ней ровно один сотрудник без начальника, все номера начальников лежат в диапазоне `0…n-1`, никто не начальник самому себе и из любого сотрудника можно дойти вверх до корня (нет циклов). Верните `true` для корректной схемы, иначе `false`. Пустой список некорректен: в нём нет корня.

Пример: `[-1, 0, 1]` → `true`; `[-1, 2, 1]` → `false` (сотрудники 1 и 2 подчиняются друг другу).
