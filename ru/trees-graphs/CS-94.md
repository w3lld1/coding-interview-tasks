# Пятнашки на поле 2×3

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Матрицы и сетки](../matrices/), [Словари и множества](../hashing/)

Поле из двух строк по три клетки задано списком из двух строк, например `[[1, 2, 3], [4, 0, 5]]`; в клетках стоят числа от `0` до `5`, каждое ровно один раз, а `0` — пустая клетка. За один ход можно сдвинуть в пустую клетку соседнюю с ней по стороне фишку (то есть поменять `0` местами с соседом сверху, снизу, слева или справа). Головоломка решена, когда поле равно `[[1, 2, 3], [4, 5, 0]]`. Верните наименьшее число ходов до решения; `0`, если поле уже решено, и `-1`, если решить его нельзя.

Пример: `[[4, 1, 2], [5, 0, 3]]` → `5`.
