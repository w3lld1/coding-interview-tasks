# Самый дешёвый перелёт с ограничением пересадок

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-11?utm_source=github&utm_medium=tasks-repo)**

Есть `n` городов с номерами от `0` до `n - 1` и список рейсов. Рейс `[u, v, price]` летит из города `u` в город `v` за `price` (цена положительная, рейсы односторонние, между двумя городами может быть несколько рейсов). Найдите минимальную стоимость пути из `src` в `dst`, в котором не больше `k` промежуточных городов (то есть не больше `k + 1` рейсов). Если `src` равен `dst`, ответ `0`. Если такого пути нет, верните `-1`. Ограничения: `n` не больше 100, `k` не меньше 0.

Пример: `4`, рейсы `[[0,1,100],[1,2,100],[2,0,100],[1,3,600],[2,3,200]]`, `0`, `3`, `1` → `700` (путь 0 → 1 → 3; путь через город 2 дешевле, но требует двух пересадок).
