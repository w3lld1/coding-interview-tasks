# Расстояние до цикла

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-41?utm_source=github&utm_medium=tasks-repo)**

Планеты пронумерованы от 1 до N (3 ≤ N ≤ 1000) и соединены N двусторонними трубами; каждая труба — пара `[x, y]` (x ≠ y), одна пара не встречается дважды. Из любой планеты можно добраться до любой другой, и во всей сети ровно один цикл.

Для каждой планеты найдите наименьшее число труб на пути до ближайшей планеты, лежащей на цикле (для планет цикла это 0). Верните список из N чисел: i-е число относится к планете i.

Пример: `5`, `[[1, 2], [2, 3], [3, 4], [2, 4], [5, 3]]` → `[1, 0, 0, 0, 1]` (цикл образуют планеты 2, 3, 4).
