# Мосты в неориентированном графе

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-84?utm_source=github&utm_medium=tasks-repo)**

Дан неориентированный граф: число вершин `n` (от 1 до 1000, вершины `0..n-1`) и список рёбер `edges` (до 2000 пар `[u, v]`, без петель и без повторяющихся рёбер). Граф может быть несвязным. Мост — это ребро, после удаления которого число компонент связности увеличивается. Верните все мосты, каждый как пару `[u, v]` с `u < v`; список отсортируйте по `u`, а при равных `u` — по `v`. Если мостов нет, верните пустой список `[]`.

Пример: `n = 5`, `[[0, 1], [1, 2], [2, 0], [1, 3], [3, 4]]` → `[[1, 3], [3, 4]]`.
