# Сколько маршрутов до конечной

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/)

В городе `n` станций с номерами `0…n-1`; список `roads` содержит односторонние линии `[from, to]`, причём всегда `from < to`, поэтому по кругу ездить нельзя. Одна и та же линия в списке не повторяется. Здесь `1 ≤ n ≤ 20`.

Верните, сколькими разными маршрутами можно проехать со станции `0` на станцию `n-1` (маршрут — последовательность станций, где между соседними есть линия). Если `n = 1`, маршрут один (из одной станции). Если проехать нельзя, ответ `0`.

Пример: `4`, `[[0, 1], [0, 2], [1, 3], [2, 3]]` → `2`.
