# Глубина значения в дереве поиска

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-395?utm_source=github&utm_medium=tasks-repo)**

Двоичное дерево задано тремя списками одинаковой длины: `values[i]` — значение узла `i`, `left[i]` и `right[i]` — номера его левого и правого потомков или `-1`, если потомка нет. Корень — узел `0`; пустое дерево — три пустых списка. Это дерево поиска: значения различны, в левом поддереве любого узла все значения меньше его значения, в правом — больше. Верните глубину узла со значением `key` (у корня глубина `0`) или `-1`, если такого значения в дереве нет. Для пустого дерева ответ `-1`.

Пример: `values = [4, 2, 6, 1, 3]`, `left = [1, 3, -1, -1, -1]`, `right = [2, 4, -1, -1, -1]`, `key = 3` → `2`; `key = 5` → `-1`.
