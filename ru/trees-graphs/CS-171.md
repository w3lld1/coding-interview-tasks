# Маршрут по всем билетам

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Стек, очередь, связные списки](../stacks-lists/)

Дан список авиабилетов: каждый билет — пара `[откуда, куда]` из кодов аэропортов (три заглавные латинские буквы, аэропорты в паре разные), и код аэропорта `start`. Путешественник вылетает из `start` и хочет использовать каждый билет ровно один раз: билет `[A, B]` можно взять, только находясь в `A`, и после него он оказывается в `B`. Одинаковые билеты могут повторяться, и каждый из них нужно использовать.

Верните маршрут — список аэропортов в порядке посещения, начиная с `start` (его длина на один больше числа билетов). Если подходящих маршрутов несколько, верните лексикографически наименьший: маршруты сравниваются по первому аэропорту, где они различаются, а коды — как строки. Если использовать все билеты не получается, верните `[]`. Без билетов ответ — `[start]`.

Билетов до 5000.

Пример: `[["MOW", "LED"], ["LED", "KZN"], ["MOW", "KZN"], ["KZN", "MOW"]]`, `"MOW"` → `["MOW", "KZN", "MOW", "LED", "KZN"]`.
