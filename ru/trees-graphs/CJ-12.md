# Ромбовидное наследование

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-12?utm_source=github&utm_medium=tasks-repo)**

Дана схема классов. Классы пронумерованы с `0`; `parents[i]` — список различных классов, от которых напрямую наследуется класс `i`. Класс не наследуется сам от себя, а циклов нет. Путь наследования из `X` в `Y` — цепочка `X, C1, …, Cn, Y`, где каждый следующий класс — прямой родитель предыдущего (прямой родитель — путь из двух классов). Схема содержит ромб, если существует пара классов `X` и `Y`, между которыми есть хотя бы два разных пути наследования. Верните `true`, если в схеме есть ромб, иначе `false`.

Пример: `[[1, 2], [3], [3], []]` → `true` (из класса 0 в класс 3 ведут два пути: через 1 и через 2).
