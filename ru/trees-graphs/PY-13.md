# Построение дерева из записей

**Сложность:** средняя · **Язык:** Python · **Темы:** [Деревья и графы](../trees-graphs/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-13?utm_source=github&utm_medium=tasks-repo)**

В стартовом коде есть медленная функция `BuildTree(records)`. Перепишите её так, чтобы она работала быстрее, но сохранила поведение и проверки. Функция получает список записей `Record` с полями `record_id` и `parent_id` в произвольном порядке и возвращает корневой узел `Node` (поля `node_id` и `children`). Дети каждого узла упорядочены по `node_id`. Для пустого списка верните `None`.

Правила корректности: идентификаторы образуют диапазон от 0 до n−1 без повторов и пропусков; у корня `record_id` и `parent_id` равны 0; у любого другого узла `parent_id` меньше `record_id`. При нарушении любого правила вызовите `ValueError`.
