# Аэропорты без вылетов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-413?utm_source=github&utm_medium=tasks-repo)**

В авиасети `n` аэропортов с номерами `0…n-1`. Список `flights` содержит односторонние рейсы `[from, to]` — из аэропорта `from` в аэропорт `to`. Рейсы могут повторяться; рейса из аэропорта в него же нет.

Верните по возрастанию номера аэропортов, из которых не вылетает ни один рейс. Аэропорт без рейсов вовсе тоже входит в ответ. Если таких нет, верните пустой список.

Пример: `4`, `[[0, 1], [1, 2], [0, 3]]` → `[2, 3]`.
