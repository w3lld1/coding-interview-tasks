# Двоичное дерево поиска

**Сложность:** средняя · **Язык:** Python · **Темы:** [Деревья и графы](../trees-graphs/), [Рекурсия и перебор](../recursion/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-19?utm_source=github&utm_medium=tasks-repo)**

Реализуйте двоичное дерево поиска. Класс `BinarySearchTree(tree_data)` получает список чисел и вставляет их в дерево по очереди: значение, меньшее или равное значению узла, уходит в левое поддерево, большее — в правое. Узел — это `TreeNode` с полями `data`, `left` и `right`. Методы:

- `data()` — возвращает корневой узел (`TreeNode`, а не список);
- `sorted_data()` — возвращает список всех значений по неубыванию, с повторами.
