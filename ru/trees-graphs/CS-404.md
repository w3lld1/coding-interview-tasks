# Сколько компаний друзей

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-404?utm_source=github&utm_medium=tasks-repo)**

Граф задан числом вершин `n` (вершины `0…n-1`) и списком рёбер `edges`: ребро `[u, v]` соединяет `u` и `v` в обе стороны. Назовём группой набор вершин, между любыми двумя из которых есть цепочка рёбер. Вершина без рёбер — отдельная группа из одного человека.

Верните число групп. Вершин может не быть вовсе (`n = 0`) — тогда групп `0`. Повторяющиеся рёбра допустимы, петель `[a, a]` нет.

Пример: `5`, `[[0, 1], [1, 2], [3, 4]]` → `2`.
