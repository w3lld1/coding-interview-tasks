# Тройки с суммой, кратной трём

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-147?utm_source=github&utm_medium=tasks-repo)**

Дано положительное целое `n`. Рассмотрите массив `a` длины `n`, где `a[i] = i·i − i + 1` для `i` от 1 до `n` (нумерация с единицы). Верните количество троек `(a[i], a[j], a[k])` с индексами `i < j < k`, сумма которых делится на 3. Если элементов меньше трёх, ответ `0`.

Пример: `5` → `1` (массив `[1, 3, 7, 13, 21]`, подходит только тройка `1, 7, 13`).
