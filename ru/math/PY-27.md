# Простые числа решетом Эратосфена

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-27?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `primes(limit)`. Она возвращает список всех простых чисел, не больших `limit`, по возрастанию. Используйте решето Эратосфена: отмечайте кратные каждого очередного неотмеченного числа, а не проверяйте делимость каждого кандидата отдельно. Если `limit` меньше 2, верните пустой список.
