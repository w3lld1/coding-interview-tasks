# Сумма чисел от 1 до n

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-60?utm_source=github&utm_medium=tasks-repo)**

Дано целое число `n >= 0`. Верните сумму всех целых чисел от 1 до `n` включительно. Для `n = 0` сумма равна 0. Результат помещается в 32-битное целое.

Пример: `5` → `15` (1 + 2 + 3 + 4 + 5).
