# Кодировщик чисел

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-37?utm_source=github&utm_medium=tasks-repo)**

Дан список положительных целых чисел (до 10000 штук, каждое не больше 10000), порядок произвольный. Для каждого непустого подмножества элементов (подмножества различают по позициям, равные числа на разных позициях считаются разными) возьмите разность между наибольшим и наименьшим числом в нём; у подмножества из одного элемента она равна 0. Верните сумму всех этих разностей по модулю 1000000007.

Пример: `[3, 6, 7, 9]` → `44`.
