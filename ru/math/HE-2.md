# Дробная часть числа

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-2?utm_source=github&utm_medium=tasks-repo)**

Дано неотрицательное число с плавающей точкой. Его можно разложить на целую часть (наибольшее целое, не превосходящее число) и дробную часть, которая всегда меньше 1. Верните дробную часть. Для целого числа результат равен `0`.

Пример: `3.5` → `0.5`.
