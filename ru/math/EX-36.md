# Аллергии по баллу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-36?utm_source=github&utm_medium=tasks-repo)**

Результат теста на аллергию хранится одним числом. Каждому аллергену соответствует своя степень двойки: `eggs` (1), `peanuts` (2), `shellfish` (4), `strawberries` (8), `tomatoes` (16), `chocolate` (32), `pollen` (64), `cats` (128). Балл равен сумме значений всех аллергенов человека: балл 34 означает арахис и шоколад. Значения 256, 512 и выше в список аллергенов не входят, их нужно игнорировать.

Даны балл `score` и строка `item`. Если `item` пустая, верните список всех аллергенов человека в порядке из перечисления выше. Иначе верните список из одного элемента `item`, если человек аллергик на него, и пустой список, если нет.

Пример: `257`, `""` → `["eggs"]`; `5`, `"peanuts"` → `[]`.
