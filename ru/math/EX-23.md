# Пифагоровы тройки с заданной суммой

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-23?utm_source=github&utm_medium=tasks-repo)**

Пифагорова тройка — три натуральных числа `a < b < c`, для которых `a² + b² = c²`. Дано число `n`. Верните все тройки `[a, b, c]` с суммой `a + b + c = n`. Тройки упорядочьте по возрастанию `a`; если подходящих троек нет, верните пустой список.

Для `n` порядка 30000 перебор всех пар `a`, `b` слишком медленный, поэтому ищите решение быстрее, чем O(n²).

Пример: `12` → `[[3, 4, 5]]`.
