# Сломанный калькулятор

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-93?utm_source=github&utm_medium=tasks-repo)**

У калькулятора исправны только некоторые цифровые кнопки и кнопки «×» и «=». Список `working` из 10 элементов говорит, какие цифры работают: `working[d] = 1` — кнопка `d` исправна, `0` — сломана. Чтобы получить число `x` (`1 ≤ x ≤ 10⁶`), нужно набрать выражение вида `a₁ × a₂ × … × aₘ =` (`m ≥ 1`), где каждое `aᵢ` набрано только исправными цифрами, а произведение равно `x`. Каждая цифра, каждый «×» и завершающий «=» — одно нажатие. Верните наименьшее число нажатий или `-1`, если получить `x` нельзя.

Пример: исправны `1`, `2`, `5`, `x = 60` → `5` (`12×5=`).
