# Характеристики персонажа D&D

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-49?utm_source=github&utm_medium=tasks-repo)**

Персонаж настольной игры получает характеристики по броскам четырёх шестигранных кубиков. Функция получает операцию `operation` и список целых `values`.

- `"ability"`: `values` содержит значения четырёх кубиков. Значение характеристики равно сумме трёх наибольших кубиков (наименьший отбрасывается; при равенстве отбрасывается любой из наименьших). Верните это значение.
- `"modifier"`: `values` содержит один элемент, значение характеристики. Модификатор равен `(значение − 10) / 2`, округлённому вниз (к минус бесконечности): для 3 это `-4`, для 9 это `-1`.
- `"hitpoints"`: `values` содержит один элемент, значение телосложения. Верните `10 +` его модификатор.

Пример: `"ability"`, `[5, 3, 1, 6]` → `14`; `"hitpoints"`, `[3]` → `6`.
