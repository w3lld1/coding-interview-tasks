# Дробь в виде десятичной строки

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Строки](../strings/), [Словари и множества](../hashing/)

Даны целые `numerator` и `denominator` (знаменатель не равен 0). Верните значение дроби `numerator / denominator` в десятичной записи в виде строки. Если дробь бесконечная, повторяющуюся часть (период) возьмите в круглые скобки, начиная с первой цифры периода. Если результат целый, точку не ставьте. Минус ставится, только если результат отрицателен; ноль записывается как `"0"`. Промежуточные значения могут выйти за 32-битный диапазон.

Пример: `1`, `6` → `"0.1(6)"`; `2`, `1` → `"2"`; `-50`, `8` → `"-6.25"`.
