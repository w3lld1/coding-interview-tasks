# Арифметика рациональных чисел

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-83?utm_source=github&utm_medium=tasks-repo)**

Рациональное число задано списком из двух целых `[числитель, знаменатель]`, знаменатель не равен нулю (он может быть и отрицательным). Выполните операцию `operation` и верните результат в том же виде, **всегда сокращённый до несократимой дроби со знаменателем больше нуля** (ноль записывается как `[0, 1]`).

Операции:
- `"add"`, `"sub"`, `"mul"`, `"div"` — сумма, разность, произведение и частное `first` и `second` (при делении числитель `second` не равен нулю);
- `"abs"` — модуль `first` (`second` пуст);
- `"reduce"` — только сокращение `first` (`second` пуст);
- `"pow"` — `first` в целой степени `n`, где `second = [n]`. Для отрицательной степени `n` результат равен `(знаменатель^|n|) / (числитель^|n|)` (в этом случае числитель `first` не равен нулю), а любое число в степени 0 равно `[1, 1]`.

Пример: `"add"`, `[1, 2]`, `[2, 3]` → `[7, 6]`; `"reduce"`, `[3, -4]`, `[]` → `[-3, 4]`.
