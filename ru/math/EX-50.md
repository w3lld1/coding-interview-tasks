# Сколько яиц в инкубаторе

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-50?utm_source=github&utm_medium=tasks-repo)**

Число задаёт занятые ячейки инкубатора: каждый единичный бит двоичной записи — это одно яйцо. Дано неотрицательное целое число, верните количество единиц в его двоичной записи. Стандартные функции подсчёта битов использовать не нужно, посчитайте сами. Для `0` ответ `0`.

Пример: `89` → `4` (двоичная запись `1011001`).
