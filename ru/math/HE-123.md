# Нечётные члены последовательности Коллатца

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Поиск и сортировка](../search-sort/)

Последовательность Коллатца строится так: начните с натурального числа `n`; если текущее число чётно, следующее равно его половине, если нечётно — утроенному значению плюс 1. Последовательность заканчивается, когда достигнуто число 1 (оно входит в неё). Для `n = 1` последовательность состоит из одного числа 1.

Верните все нечётные числа этой последовательности, отсортированные по возрастанию, без повторов.

Пример: `5` → `[1, 5]` (последовательность 5, 16, 8, 4, 2, 1).
