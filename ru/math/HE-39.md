# Простые числа Фибоначчи

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

Числа Фибоначчи: 1, 1, 2, 3, 5, 8, 13, … (каждое следующее равно сумме двух предыдущих). Среди них есть простые: 2, 3, 5, 13, 89, … Дано `n` от 1 до 10. Верните `n`-е по порядку простое число Фибоначчи (счёт с единицы).

Пример: `4` → `13`.
