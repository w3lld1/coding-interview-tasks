# Преобразование чисел и проверка ввода

**Сложность:** лёгкая · **Язык:** JavaScript · **Темы:** [Математика](../math/), [Разбор и проверка данных](../parsing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-03?utm_source=github&utm_medium=tasks-repo)**

Реализуйте три функции:

- `twoSum(array1, array2)` — каждый из двух непустых массивов цифр превращает в число (`[2, 4]` → 24, `[1, 5, 7]` → 157) и возвращает сумму чисел (181);
- `luckyNumber(value)` — возвращает `true`, если положительное целое число — палиндром (читается одинаково в обе стороны), иначе `false`;
- `errorMessage(input)` — проверяет значение поля ввода: для `null`, `undefined` и пустой строки возвращает `'Required field'`; если `Number(input)` даёт 0 или `NaN`, возвращает `'Must be a number besides 0'`; иначе возвращает пустую строку.
