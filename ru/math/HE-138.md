# Сумма четырёх положительных чётных

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-138?utm_source=github&utm_medium=tasks-repo)**

Дано целое число `n`. Верните `true`, если его можно представить в виде суммы ровно четырёх положительных чётных чисел (слагаемые могут повторяться), иначе `false`. Ноль и отрицательные числа дают `false`.

Пример: `8` → `true` (2 + 2 + 2 + 2), `6` → `false`.
