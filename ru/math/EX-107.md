# Кодирование числами переменной длины (VLQ)

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-107?utm_source=github&utm_medium=tasks-repo)**

Реализуйте кодирование и декодирование VLQ (variable-length quantity). Даны режим `mode` (`"encode"` или `"decode"`) и список чисел. Числа — неотрицательные, помещаются в 32 бита без знака (до 4294967295).

При `"encode"` каждое число переводится в последовательность байтов (значений 0–255): число делится на группы по 7 бит, от старшей группы к младшей; в каждом байте, кроме последнего, старший бит (значение 128) установлен, в последнем сброшен. Число 0 — один байт `0`. Результат — склеенные байты всех чисел по порядку. При `"decode"` список байтов разбирается обратно в список чисел.

При декодировании сообщите об ошибке: бросьте исключение, в Go верните error, если список заканчивается на байте с установленным старшим битом (последовательность не завершена).

Пример: `"encode"`, `[128, 0]` → `[129, 0, 0]`; `"decode"`, `[192, 0]` → `[8192]`.
