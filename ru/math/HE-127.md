# Простая длина пересечения отрезков

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-127?utm_source=github&utm_medium=tasks-repo)**

Даны два закрытых отрезка, каждый задан списком из двух целых чисел `[начало, конец]`, где начало не больше конца. Пересечением отрезков называется общая часть; её длина равна конец минус начало (для отрезка `[2, 3]` длина 1). Если отрезки не пересекаются, ответ `"NO"`. Если длина пересечения — простое число, верните `"YES"`, иначе `"NO"`. Пересечение из одной точки имеет длину 0 и простым не считается.

Пример: `[-3, -1]`, `[-5, 5]` → `"YES"` (пересечение `[-3, -1]` имеет длину 2).
