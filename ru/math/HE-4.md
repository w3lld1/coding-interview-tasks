# Среднее абсолютное отклонение

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-4?utm_source=github&utm_medium=tasks-repo)**

Дан непустой список чисел. Найдите их среднее арифметическое, затем среднее значение абсолютных разностей каждого числа и этого среднего. Верните это значение. Для списка из одного числа или из равных чисел результат `0`.

Пример: `[1.0, 2.0, 3.0, 4.0]` → `1.0` (среднее `2.5`, отклонения `1.5, 0.5, 0.5, 1.5`).
