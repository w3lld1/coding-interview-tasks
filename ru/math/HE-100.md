# Горка из камней

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-100?utm_source=github&utm_medium=tasks-repo)**

Дано положительное целое число `n`. Нужно сложить горку из `n` уровней. На первом уровне лежит `n` камней, а на каждом следующем на два камня больше, чем на предыдущем (так чётность числа камней не меняется). Верните список количества камней по уровням, начиная с первого.

Пример: `3` → `[3, 5, 7]`. Пример: `4` → `[4, 6, 8, 10]`.
