# Разность квадратов первых N чисел

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-48?utm_source=github&utm_medium=tasks-repo)**

Даны операция `operation` и целое число `number` (от 0 до 100). Работайте с первыми `number` натуральными числами `1, 2, …, number` (при 0 их нет, и все суммы равны 0).

- `"square_of_sum"`: квадрат суммы этих чисел, например для 5 это `(1+2+3+4+5)² = 225`.
- `"sum_of_squares"`: сумма их квадратов, для 5 это `1+4+9+16+25 = 55`.
- `"difference"`: разность между первым и вторым, для 5 это `225 − 55 = 170`.

Пример: `"difference"`, `10` → `2640` (3025 − 385).
