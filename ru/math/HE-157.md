# Прямоугольный ли треугольник

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-157?utm_source=github&utm_medium=tasks-repo)**

Даны три положительных целых числа, длины сторон. Верните `true`, если из отрезков таких длин можно составить прямоугольный треугольник, иначе `false`. Стороны могут прийти в любом порядке, и гипотенузой может оказаться любая из них.

Пример: `3`, `4`, `5` → `true`; `1`, `2`, `3` → `false`.
