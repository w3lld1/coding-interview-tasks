# Разложение на простые множители

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/PY-28?utm_source=github&utm_medium=tasks-repo)**

Напишите функцию `factors(value)`. Она получает положительное целое число и возвращает список его простых множителей по возрастанию. Каждый множитель повторяйте столько раз, сколько он входит в разложение, чтобы произведение элементов списка равнялось исходному числу. Для 1 верните пустой список.
