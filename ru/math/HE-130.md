# Необычные числа трибоначчи

Последовательность `t` задана так: `t(0) = 1`, `t(1) = 3`; для чётного `i ≥ 2` значение `t(i) = 1 + i / 2` (целое); для нечётного `i ≥ 3` значение `t(i) = t(i - 1) + t(i - 2) + t(i + 1)`. Все значения целые. Для нечётного `i` слагаемое `t(i + 1)` берётся по формуле для чётного индекса, поэтому цикла в определении нет.

Дано целое `n ≥ 0`. Верните список первых `n + 1` членов, то есть `t(0)`, …, `t(n)`.

Пример: `3` → `[1, 3, 2, 8]` (t(2) = 2, t(3) = 2 + 3 + t(4) = 2 + 3 + 3 = 8).
