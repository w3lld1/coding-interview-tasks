# Счёт с разворотом цифр

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-68?utm_source=github&utm_medium=tasks-repo)**

Вы считаете вслух, начиная с числа 1. Следующее число — либо предыдущее плюс 1, либо предыдущее с цифрами в обратном порядке (ведущие нули отбрасываются: после 2300 можно сказать 32). Верните наименьшее количество сказанных чисел, чтобы дойти до `n`. Первое число 1 и само `n` учитываются, а повторно сказанное число считается каждый раз. Ограничения: 1 ≤ n ≤ 10¹⁴.

Пример: `23` → `15` (1, 2, …, 12, 21, 22, 23).
