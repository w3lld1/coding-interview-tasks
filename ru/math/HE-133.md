# Сумма квадратов округлённых вверх чисел

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-133?utm_source=github&utm_medium=tasks-repo)**

Дан список чисел, целых или дробных. Округлите каждое число вверх до ближайшего целого (то есть до наименьшего целого, не меньшего числа) и верните сумму квадратов полученных целых. Для отрицательных чисел округление вверх идёт к нулю: `-2.4` становится `-2`. Для пустого списка результат `0`.

Пример: `[1.4, 4.2, 0]` → `29` (2² + 5² + 0²).
