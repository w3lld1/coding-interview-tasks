# Площадь треугольника по сторонам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-71?utm_source=github&utm_medium=tasks-repo)**

Даны длины трёх сторон — положительные целые числа. Если из них можно составить треугольник, верните его площадь, округлённую до двух знаков после запятой. Иначе верните `-1`. Треугольник существует, когда сумма любых двух сторон строго больше третьей; вырожденный случай, когда сумма равна третьей стороне, треугольником не считается.

Пример: `3`, `4`, `5` → `6.0`; `1`, `2`, `10` → `-1`.
