# Степень двойки по модулю

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-49?utm_source=github&utm_medium=tasks-repo)**

Даны неотрицательное целое `n` и положительное целое `p`. Верните остаток от деления `2` в степени `n` на `p`. Значение `2^n` может быть огромным, поэтому не вычисляйте его целиком. При `n = 0` результат равен `1 % p`, то есть `0` при `p = 1`.

Пример: `3`, `5` → `3` (8 даёт остаток 3 при делении на 5).
