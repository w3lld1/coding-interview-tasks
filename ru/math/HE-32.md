# Корень многочлена

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-32?utm_source=github&utm_medium=tasks-repo)**

Дан список коэффициентов многочлена `c[0] + c[1]·x + c[2]·x² + … + c[n]·xⁿ`. Количество коэффициентов чётное (степень многочлена нечётная), старший коэффициент не равен нулю, а у многочлена ровно один вещественный корень. Верните этот корень; ответ принимается с точностью 1e-6.

Пример: `[1, 2]` → `-0.5` (многочлен `1 + 2x`).
