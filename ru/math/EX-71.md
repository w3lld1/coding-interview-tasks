# N-е простое число

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/EX-71?utm_source=github&utm_medium=tasks-repo)**

Дан номер `number`. Верните простое число с этим номером, если считать с 1: первое простое — 2, второе — 3, шестое — 13. Если `number` меньше 1, сообщите об ошибке: бросьте исключение, в Go верните error. Номер не больше 10001. Готовыми функциями для простых чисел пользоваться не нужно.

Пример: `6` → `13`.
