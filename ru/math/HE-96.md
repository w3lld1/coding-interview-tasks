# Простые числа меньше n

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-96?utm_source=github&utm_medium=tasks-repo)**

Дано неотрицательное целое число `n`. Верните список всех простых чисел, которые строго меньше `n`, по возрастанию. Для `n`, равного `0`, `1` или `2` список пуст.

Пример: `11` → `[2, 3, 5, 7]` (само `11` не входит). Пример: `20` → `[2, 3, 5, 7, 11, 13, 17, 19]`.
