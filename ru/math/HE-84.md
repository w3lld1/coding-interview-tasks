# Сумма цифр в двоичной записи

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-84?utm_source=github&utm_medium=tasks-repo)**

Дано целое `n` от 0 до 10000. Найдите сумму его десятичных цифр и верните эту сумму в двоичной записи в виде строки без ведущих нулей. Для суммы 0 верните `"0"`.

Пример: `150` → `"110"` (сумма цифр 1 + 5 + 0 = 6, а 6 в двоичной записи — `110`).
