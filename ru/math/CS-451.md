# Сколько раз складывать цифры

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-451?utm_source=github&utm_medium=tasks-repo)**

Дано неотрицательное целое число `n`. Заменим число суммой его цифр, затем снова и снова, пока не получится число из одной цифры (меньше 10). Верните, сколько таких замен потребовалось. Если `n` уже меньше 10, ответ `0`.

Пример: `38` → `2` (38 → 3+8 = 11 → 1+1 = 2).
