# Факториал или сумма по позиции

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-106?utm_source=github&utm_medium=tasks-repo)**

Дано целое `n` от 0 до 12. Верните список из `n` элементов: для позиции `i` (нумерация с 1) элемент равен факториалу `i` (`1 · 2 · … · i`), если `i` чётно, и сумме чисел от 1 до `i`, если `i` нечётно. При `n = 0` верните пустой список.

Пример: `5` → `[1, 2, 6, 24, 15]`.
