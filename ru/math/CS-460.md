# Последний в кругу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Рекурсия и перебор](../recursion/)

В детской игре `n` ребят стоят по кругу, они пронумерованы от 1 до `n` по часовой стрелке. Счёт начинается с первого: считаем `k` человек по кругу, начиная с первого; тот, на ком счёт закончился, выбывает, а следующий за ним становится началом нового счёта. Так продолжается, пока не останется один. Верните его номер. Считайте, что `1 ≤ n ≤ 500` и `k ≥ 1`.

Пример: `7`, `3` → `4` (выбывают 3, 6, 2, 7, 5, 1).
