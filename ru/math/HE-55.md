# Число Фибоначчи

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Динамическое программирование](../dp/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-55?utm_source=github&utm_medium=tasks-repo)**

Верните `n`-е число Фибоначчи, где `n >= 0`. Последовательность начинается так: F(0) = 0, F(1) = 1, а каждое следующее число равно сумме двух предыдущих. В тестах `n` не больше 40.

Пример: `10` → `55`.
