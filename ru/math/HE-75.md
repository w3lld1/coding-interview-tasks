# Произведение трёх простых чисел

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-75?utm_source=github&utm_medium=tasks-repo)**

Дано натуральное число. Верните `true`, если его можно представить в виде произведения ровно трёх простых чисел, и `false` иначе. Простые множители могут повторяться: `8 = 2 · 2 · 2`. Число `1` не раскладывается на простые множители, ответ для него `false`.

Пример: `30` → `true` (30 = 2 · 3 · 5); `10` → `false`; `60` → `false` (четыре множителя).
