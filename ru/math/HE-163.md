# Чётные цифры между двумя числами

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-163?utm_source=github&utm_medium=tasks-repo)**

Даны два положительных целых числа `a` и `b`, причём `a` может быть больше `b`. Верните по возрастанию все чётные цифры (однозначные числа 2, 4, 6, 8), которые лежат между ними, включая сами границы. Если таких цифр нет, верните пустой список. Многозначные числа в ответ не входят, даже если они чётные.

Пример: `10`, `2` → `[2, 4, 6, 8]`; `10`, `14` → `[]`.
