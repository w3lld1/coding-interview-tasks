# Простая длина строки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-82?utm_source=github&utm_medium=tasks-repo)**

Дана строка. Верните `true`, если её длина — простое число, иначе `false`. Простое число — натуральное число больше 1, которое делится только на 1 и на себя. Длины `0` и `1` простыми не считаются, поэтому для пустой строки и строки из одного символа ответ `false`.

Пример: `"Hello"` → `true` (длина 5), `"orange"` → `false` (длина 6).
