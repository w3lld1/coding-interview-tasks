# Наибольший общий делитель

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-13?utm_source=github&utm_medium=tasks-repo)**

Даны два неотрицательных целых числа, не равных нулю одновременно. Верните их наибольший общий делитель, то есть самое большое число, на которое делятся оба. Если одно из чисел равно `0`, ответом будет другое число.

Пример: `25`, `15` → `5`.
