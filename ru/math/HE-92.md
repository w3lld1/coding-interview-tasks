# Одно число равно сумме двух других

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-92?utm_source=github&utm_medium=tasks-repo)**

Даны три числа. Верните `true`, если все три числа целые (без дробной части; `3.0` считается целым) и одно из них равно сумме двух других. Иначе верните `false`.

Пример: `5`, `2`, `7` → `true` (5 + 2 = 7). Пример: `3.6`, `-2.2`, `2` → `false`.
