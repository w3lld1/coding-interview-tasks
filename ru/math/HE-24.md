# Наибольший делитель меньше n

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/HE-24?utm_source=github&utm_medium=tasks-repo)**

Дано целое число `n` не меньше `2`. Найдите наибольшее целое число, которое меньше `n` и делит `n` без остатка. Для простого `n` ответ равен `1`.

Пример: `15` → `5`.
