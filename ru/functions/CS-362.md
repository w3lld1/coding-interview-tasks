# Композиция частично применённых функций

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/)

Функции двух аргументов `add`, `sub`, `mul`, `div`, `mod`, `min`, `max` частично применены: один аргумент зафиксирован числом, второй пока свободен. Шаг записывается строкой `имя@сторона:k`. При `left` число `k` — левый операнд (`sub@left:10` означает `x → 10 - x`), при `right` — правый (`sub@right:10` означает `x → x - 10`).

Список шагов `steps` задаёт композицию `f1 ∘ f2 ∘ … ∘ fn`: сначала применяется последний шаг, затем предпоследний, и так до первого. Пустой список — тождественная функция.

Дан `steps` и список чисел `xs`. Верните результат композиции для каждого числа.

Правила арифметики: `div` — целочисленное деление с округлением к нулю (`-7 / 2 = -3`); `mod` — остаток со знаком делимого (`-7 mod 2 = -1`), то есть `a - b · div(a, b)`; если делитель равен `0`, и `div`, и `mod` дают `0`. Значения помещаются в 32 бита.

Пример: `["sub@left:10", "mul@right:3"]`, `[4]` → `[-2]`: сначала `4 · 3 = 12`, затем `10 - 12 = -2`.
