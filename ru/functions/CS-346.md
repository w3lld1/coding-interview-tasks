# Промежуточные итоги по правилу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-346?utm_source=github&utm_medium=tasks-repo)**

Даны имя правила `op` и список целых чисел `numbers`. Верните список той же длины: первый элемент равен `numbers[0]`, а каждый следующий получается из предыдущего элемента результата `r` и текущего числа `n` по правилу. Для пустого списка ответ — пустой список.

Правила:
- `"sum"`: `r + n`.
- `"max"`: большее из `r` и `n`.
- `"min"`: меньшее из `r` и `n`.
- `"diff"`: `r - n`.

Пример: `"diff"`, `[10, 3, 2]` → `[10, 7, 5]`.
