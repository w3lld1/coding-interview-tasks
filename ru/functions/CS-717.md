# Где расходятся два конвейера операций

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-717?utm_source=github&utm_medium=tasks-repo)**

Число проходит через конвейер операций по очереди. Операции: `"add K"` (прибавить `K`), `"mul K"` (умножить на `K`), `"neg"` (сменить знак), `"abs"` (модуль), `"max K"` (взять `max(x, K)`), `"min K"` (взять `min(x, K)`). Даны два конвейера `left` и `right` (списки операций; пустой список оставляет число как есть). Их применяют к одному и тому же целому `x`.

Если для всех целых `x` (любых, без ограничения величины) результаты совпадают, верните `[]`. Иначе найдите целое `x` с наименьшим `|x|`, при котором результаты различаются (из `x` и `−x` берите отрицательное), и верните `[x, left(x), right(x)]`.

Ограничения: в каждом конвейере до 12 операций, `|K| ≤ 10^6`, произведение `|K|` всех `mul` одного конвейера не больше `10^6` (`mul 0` разрешён). Ответ помещается в 64-битное целое.

Пример: `["abs", "min 5"]`, `["min 5", "abs"]` → `[-6, 5, 6]`.
