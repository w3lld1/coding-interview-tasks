# Шагов до единицы

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/)

Даны имя шага `name` и целое `x` от 1 до 100000. Применяйте шаг к `x`, затем к результату, и так далее, пока значение не станет равным `1`. Верните число применений шага. Если `x` уже равно `1`, ответ `0`.

Шаги (над текущим значением `v`):
- `"half"`: `v / 2` с отбрасыванием дробной части.
- `"isqrt"`: целая часть квадратного корня из `v`.
- `"collatz"`: если `v` чётно, `v / 2`, иначе `3 * v + 1`.
- `"third_ceil"`: `v / 3`, округлённое вверх до целого.

Для всех входов теста значение доходит до `1`, а промежуточные значения помещаются в 32-битное целое.

Пример: `"isqrt"`, `81` → `3` (81 → 9 → 3 → 1).
