# Сортировка слов по выбранному ключу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-343?utm_source=github&utm_medium=tasks-repo)**

Даны имя ключа `key` и список слов `words` из строчных латинских букв (слова не пустые). Верните новый список тех же слов, отсортированный по возрастанию значения ключа. Слова с равным значением ключа остаются в исходном порядке (сортировка устойчивая).

Ключи:
- `"length"`: длина слова.
- `"vowels"`: число гласных `a`, `e`, `i`, `o`, `u` в слове.
- `"last_letter"`: номер последней буквы в алфавите (`a` = 1, …, `z` = 26).
- `"alphabet_sum"`: сумма номеров всех букв слова в алфавите.

Пример: `"vowels"`, `["sky", "tree", "banana", "go"]` → `["sky", "go", "tree", "banana"]` (0, 1, 2 и 3 гласных).
