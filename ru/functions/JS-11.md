# Заказ фруктов через обратные вызовы

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Функции и замыкания](../functions/), [Асинхронность и потоки](../async/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-11?utm_source=github&utm_medium=tasks-repo)**

Внешний API предоставляет функцию `order(query, onSuccessCallback, onErrorCallback)`, где `query` — объект `{ variety, quantity }`, и функцию `notify(message)` для уведомления клиента. Реализуйте:

- `onSuccess()` — вызывает `notify({ message: 'SUCCESS' })`;
- `onError()` — вызывает `notify({ message: 'ERROR' })`;
- `orderFromGrocer(query, onSuccessCallback, onErrorCallback)` — вызывает `order` с теми же тремя аргументами без изменений;
- `postOrder(variety, quantity)` — собирает объект `{ variety, quantity }` и отправляет заказ через `orderFromGrocer` с обработчиками `onSuccess` и `onError`.

Сами функции не должны вызывать `notify` напрямую, кроме обработчиков.
