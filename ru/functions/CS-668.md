# Редукция комбинаторов SKI с пределом шагов

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Рекурсия и перебор](../recursion/), [Разбор и проверка данных](../parsing/)

Терм комбинаторной логики `term_text` записан символами: заглавные `S`, `K`, `I`, `B`, `C` — комбинаторы, строчные латинские буквы — переменные; применение — запись рядом, оно левоассоциативно (`abc` значит `(ab)c`), скобки группируют, пробелы игнорируются. Правила редукции (каждое применение правила — один шаг):
- `I x → x`;
- `K x y → x`;
- `S x y z → x z (y z)`;
- `B x y z → x (y z)`;
- `C x y z → x z y`.
Здесь `x`, `y`, `z` — любые термы. Редекс — комбинатор, к которому применено не меньше аргументов, чем нужно правилу.

Редуцируйте в нормальном порядке: всегда сокращайте самый левый внешний редекс. Иначе говоря, если терм — это голова, применённая к аргументам `a1 … an`, и голова — комбинатор с достаточным числом аргументов, сокращается именно он; иначе по очереди слева направо ищется первый аргумент, в котором есть редекс, и в нём шаг делается по тому же правилу.

Сделайте не больше `limit` шагов. Если терм дошёл до нормальной формы (редексов нет), верните её в каноническом виде: без пробелов, со скобками только вокруг аргумента, который сам — применение (`xz(yz)`). Если после `limit` шагов редексы остались, верните `"diverges"`. В тестах терм всегда короче 2000 символов, `0 ≤ limit ≤ 1000`.

Пример: `"S(Kx)(Ky)z"`, `10` → `"xy"`.
