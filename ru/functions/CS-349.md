# Функция с ограничением числа вызовов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-349?utm_source=github&utm_medium=tasks-repo)**

Есть функция `f(x) = x * x + 1`. Обёртка пропускает к `f` только первые `limit` вызовов; каждый такой вызов возвращает значение `f`. Все следующие вызовы `f` не запускают и возвращают результат последнего вызова, который дошёл до `f`. Число `limit` не меньше 1.

Вызовите обёртку по очереди для каждого числа из `inputs` и верните список результатов.

Пример: `2`, `[1, 2, 3, 4]` → `[2, 5, 5, 5]`: `f(1) = 2`, `f(2) = 5`, а на третьем и четвёртом вызовах возвращается прежнее `5`.
