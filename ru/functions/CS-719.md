# Интерпретатор Scheme с замыканиями и хвостовыми вызовами

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Разбор и проверка данных](../parsing/), [Рекурсия и перебор](../recursion/)

Дана строка `source` — программа на маленьком диалекте Scheme: несколько форм подряд. Выполните их по очереди и верните значение последней формы: целое число в десятичной записи или `"function"`, если это функция.

Лексемы — `(`, `)` и слова между пробелами и скобками; слово из необязательного `-` и цифр — целое число, остальные — имена. Формы:
- число; имя — значение ближайшей привязки (сначала самые внутренние области, в конце глобальная);
- `(define name e)` и `(define (name p1 … pk) body…)` (функция) — только на верхнем уровне, создают или заменяют глобальное имя;
- `(lambda (p1 … pk) body…)` — функция, запоминающая окружение, в котором создана (лексическая область видимости);
- `(let ((n1 e1) …) body…)` — все `ei` вычисляются во внешнем окружении, затем новая область с `ni`;
- `(if c a b)` — ложь только `0`; `(begin e…)`;
- `(set! name e)` — меняет ближайшую существующую привязку `name`; её видят все замыкания, разделяющие эту привязку; значение формы — новое значение;
- вызов `(f a1 … ak)`: вычисляются `f`, затем аргументы слева направо; у вызова новой функции новая область с параметрами. Тело (`body…`) — одно или несколько выражений, значение — последнего.

Встроенные функции двух аргументов `+`, `-`, `*`, `<`, `=` (сравнения дают `1` или `0`) — обычные значения: их можно передать в функцию или скрыть своим именем. Слова `define lambda let if begin set!` не бывают именами.

Хвостовые вызовы не должны расти стек: в тестах циклы через хвостовую рекурсию идут до `10^4` шагов, а обычная (нехвостовая) глубина рекурсии — не больше `100`. Программа корректна, длина до 3000 символов, все значения помещаются в 32-битное целое.

Пример: `"(define (make-counter) (let ((n 0)) (lambda () (set! n (+ n 1)) n))) (define c (make-counter)) (c) (c)"` → `"2"`.
