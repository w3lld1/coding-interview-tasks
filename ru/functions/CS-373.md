# Продукционная система: первое подходящее правило

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Разбор и проверка данных](../parsing/), [Словари и множества](../hashing/)

Дана таблица переменных `facts` (имя → целое число) и список правил `rules`. Правило записано как `УСЛОВИЕ -> ДЕЙСТВИЕ` (разделитель ровно ` -> `, слова внутри разделены одним пробелом):
- условие — `имя оператор число`, оператор из `>`, `>=`, `<`, `<=`, `==`, `!=`;
- действие — `имя присваивание число`, присваивание — `=` (записать число), `+=` (прибавить) или `-=` (вычесть).

Числа могут быть отрицательными. Переменная, которой нет в таблице, при чтении равна `0`; присваивание создаёт её.

Работа идёт шагами. На каждом шаге берётся первое по порядку правило, условие которого сейчас истинно, и выполняется его действие. Если ни одно правило не подходит, работа закончена. Всего выполняется не больше 100 шагов, затем работа обрывается. Верните итоговую таблицу переменных (все исходные и созданные).

Пример: `{"x": 2, "y": 0}`, правила `["x > 0 -> x -= 1", "y > 0 -> x = -5", "x == 0 -> y += 1"]` → `{"x": -5, "y": 1}`: `x` уменьшается до 0, затем `y` становится 1, затем `x` становится -5, и подходящих правил нет.
