# Вывод типов для маленького функционального языка

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Разбор и проверка данных](../parsing/), [Рекурсия и перебор](../recursion/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-715?utm_source=github&utm_medium=tasks-repo)**

Дана строка `program` — выражение маленького функционального языка. Верните его наиболее общий тип или `"error"`, если выражение не типизируется.

Синтаксис (лексемы разделены пробелами или скобками):
- целые числа (`0`, `42`) имеют тип `int`, `true` и `false` — тип `bool`;
- переменная — слово из строчных латинских букв, цифр и `_`, начинающееся с буквы;
- `fun x y -> e` — функция; `fun x y -> e` означает `fun x -> fun y -> e`; тело тянется как можно дальше вправо;
- применение `f a b` — это `(f a) b`; аргументом может быть только переменная, число, `true`, `false` или выражение в скобках;
- `let x = e1 in e2` и `let rec f = e1 in e2` (внутри `e1` имя `f` уже доступно);
- `if c then a else b`: `c` типа `bool`, у `a` и `b` один тип.

Встроенные имена: `add`, `sub`, `mul` : `int -> int -> int`; `eq`, `lt` : `int -> int -> bool`; `nil` : `[a]`; `cons` : `a -> [a] -> [a]`; `head` : `[a] -> a`; `tail` : `[a] -> [a]`; `isnil` : `[a] -> bool`. Свои привязки скрывают встроенные. Ключевые слова `let rec in fun if then else true false` не бывают именами.

Типы: `int`, `bool`, список `[t]`, функция `t1 -> t2` (стрелка правоассоциативна). Правила — как в ML (Хиндли — Милнер): параметр `fun` имеет один тип во всём теле; имя из `let` (и из `let rec` в `e2`) полиморфно: обобщаются переменные типа, не свободные в окружении; внутри своего определения `let rec`-имя мономорфно. Унификация с проверкой вхождения: бесконечный тип — ошибка. Ошибка также — несовпадение типов и неизвестная переменная.

Ответ печатайте так: переменные типа называйте `a`, `b`, `c`, … в порядке первого появления слева направо; стрелку слева берите в скобки: `(a -> b) -> a -> b`; между частями стрелки — ` -> `. Выражение синтаксически корректно, до 300 символов.

Пример: `"let rec map = fun f l -> if isnil l then nil else cons (f (head l)) (map f (tail l)) in map"` → `"(a -> b) -> [a] -> [b]"`.
