# Рассылка событий обработчикам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Классы и ООП](../oop/)

Реализуйте диспетчер событий. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Сначала обработчиков нет. Верните список результатов, по одному на операцию.

Обработчики называются `"double"` (умножает число на 2), `"inc"` (прибавляет 1), `"square"` (возводит в квадрат) и `"negate"` (меняет знак). Один и тот же обработчик можно подписать несколько раз; каждая подписка работает отдельно.

Операции:
- `"on_<имя>"` без аргументов, например `"on_double"`: добавить подписку обработчика `<имя>`; результат: число подписок.
- `"off_<имя>"` без аргументов: удалить одну подписку обработчика `<имя>` (любую из одинаковых); если подписок нет, ничего не менять; результат: число подписок после этого.
- `"emit"` с аргументом `x`: вызвать каждую подписку с числом `x`; результат: сумма всех их значений, `0` без подписок.

Пример: `["on_double", "on_inc", "emit", "off_double", "emit"]`, `[[], [], [5], [], [5]]` → `[1, 2, 16, 1, 6]`.
