# Команды с обратными функциями и выборочной отменой

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Стек, очередь, связные списки](../stacks-lists/)

Состояние — пара целых `(a, b)`, сначала `(0, 0)`. У каждой команды есть прямая функция и обратная:
- `add_a K`: `a + K` / `a − K`; `add_b K`: `b + K` / `b − K`;
- `move K`: `(a − K, b + K)` / `(a + K, b − K)`;
- `swap`: `(b, a)` / `(b, a)`; `neg_a`: `(−a, b)` / `(−a, b)`;
- `rot`: `(b, −a)` / `(−b, a)`.
Макрос — последовательность команд и ранее определённых макросов; его прямая функция выполняет части по порядку, обратная — обратные функции частей в обратном порядке.

Обработайте список `operations` (`K` — целое число):
- `define ИМЯ ЧАСТЬ1 ; ЧАСТЬ2 ; …` — определить макрос (части разделены ` ; `);
- `do КОМАНДА` — выполнить команду или макрос (прямую функцию); это запись истории с номером: первая `do` — `1`, следующая — `2` и так далее. Стек повторов очищается;
- `undo` — взять последнюю активную запись истории, применить её обратную функцию к текущему состоянию и положить запись на стек повторов; если активных записей нет — ничего;
- `redo` — снять запись со стека повторов, применить её прямую функцию и снова сделать её последней активной; если стек пуст — ничего;
- `revert N` — выборочная отмена: если запись `N` активна, применить её обратную функцию к текущему состоянию (даже если после неё были другие записи) и убрать её из активных; стек повторов очищается. Если записи `N` нет или она уже не активна — ничего.

После каждой операции запишите состояние строкой `"a,b"` и верните список этих строк. До 100 операций, все значения помещаются в 32-битное целое.

Пример: `["do add_a 5", "do rot", "undo", "redo"]` → `["5,0", "0,-5", "5,0", "0,-5"]`.
