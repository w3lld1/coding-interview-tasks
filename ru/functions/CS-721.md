# Цикл событий: таймеры, микрозадачи и промисы

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Стек, очередь, связные списки](../stacks-lists/)

Смоделируйте цикл событий в духе JavaScript на виртуальных часах (время в мс, все действия мгновенны). Дан список `callbacks` строк вида `"имя: действие; действие; …"` (тело может быть пустым) и число `until`. Сначала в момент `0` выполняется колбэк `main`. Верните журнал — строки `"TEXT@t"` в порядке записи.

Действия:
- `log TEXT` — записать `"TEXT@t"`, `t` — текущий момент;
- `timeout CB MS` — запланировать `CB` на момент `t + MS` (`MS ≥ 0`); `interval CB MS` — запускать `CB` в `t + MS`, `t + 2·MS`, … (`MS ≥ 1`). Каждый таймер получает номер `1, 2, 3, …` по порядку создания (общий счёт для обоих видов);
- `clear ID` — отменить таймер `ID`, если он уже создан (интервал больше не запускается, даже если его отменяют из его же колбэка); иначе ничего не делать;
- `micro CB` — поставить `CB` в очередь микрозадач;
- `call CB` — сразу выполнить `CB` (вложенно), затем продолжить текущий колбэк;
- `promise P MS` — создать промис `P`, который выполнится в момент `t + MS`;
- `then P CB` или `then P CB Q` — если `P` уже выполнен, сразу поставить микрозадачу `CB`, иначе запомнить её (в порядке вызовов `then`) до выполнения `P`. С `Q` создаётся новый промис `Q`, который выполняется сразу после того, как отработает эта микрозадача `CB`.

Порядок. Таймеры и выполнения промисов — макрозадачи; берётся та, у которой момент меньше, при равенстве — раньше запланированная (повторный запуск интервала планируется заново после его колбэка). Выполнение промиса ставит все его ожидающие микрозадачи в конец очереди. После `main` и после каждой макрозадачи выполняются микрозадачи по очереди, включая добавленные по ходу, пока очередь не опустеет. Цикл останавливается, когда не осталось макрозадач с моментом не больше `until`.

Имена промисов создаются только в `main`, каждое один раз; программа завершается (не больше `10^4` выполненных колбэков), до 30 колбэков.

Пример: `["main: log a; timeout t 0; micro m; log b", "t: log T", "m: log M"]`, `until = 10` → `["a@0", "b@0", "M@0", "T@0"]`.
