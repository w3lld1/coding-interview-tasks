# Калькулятор с накопителем

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-353?utm_source=github&utm_medium=tasks-repo)**

Реализуйте калькулятор с одним числом-накопителем, сначала равным `0`. Даны список команд `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Выполняйте команды по порядку и верните список значений накопителя после каждой команды.

Команды (`acc` — накопитель):
- `"set"` с аргументом `n`: `acc = n`.
- `"add"` с аргументом `n`: `acc = acc + n`.
- `"sub"` с аргументом `n`: `acc = acc - n`.
- `"mul"` с аргументом `n`: `acc = acc * n`.
- `"max"` с аргументом `n`: `acc` становится большим из `acc` и `n`.
- `"min"` с аргументом `n`: `acc` становится меньшим из `acc` и `n`.
- `"neg"` без аргументов: сменить знак `acc`.
- `"square"` без аргументов: возвести `acc` в квадрат.

Значения помещаются в 32-битное целое.

Пример: `["add", "mul", "neg", "max"]`, `[[5], [3], [], [10]]` → `[5, 15, -15, 10]`.
