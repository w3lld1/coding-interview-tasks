# Группировка чисел по правилу

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Словари и множества](../hashing/)

Даны имя правила `rule` и список целых чисел `numbers`. Правило сопоставляет каждому числу строку-ключ. Верните словарь, где каждому встретившемуся ключу соответствует список чисел с этим ключом, в исходном порядке. Ключи, которые не встретились, в словарь не попадают; для пустого списка ответ — пустой словарь.

Правила:
- `"parity"`: ключ `"even"` для чётного числа и `"odd"` для нечётного (учитывайте и отрицательные).
- `"sign"`: `"negative"`, `"zero"` или `"positive"`.
- `"last_digit"`: последняя цифра модуля числа как строка, например `"3"`.
- `"digits"`: число цифр в модуле числа как строка; у `0` одна цифра.

Пример: `"parity"`, `[1, 2, 3, 4, 5]` → `{"odd": [1, 3, 5], "even": [2, 4]}`.
