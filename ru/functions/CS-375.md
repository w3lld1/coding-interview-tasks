# Частичное применение с номерами аргументов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Разбор и проверка данных](../parsing/)

Есть функции: `sub(a, b) = a - b`, `pow(a, b) = a` в степени `b`, `mad(a, b, c) = a · b + c`, `clamp(x, lo, hi)` — `x`, прижатый к отрезку от `lo` до `hi` (то есть `min(max(x, lo), hi)`), и `between(lo, x, hi)` — `1`, если `lo ≤ x ≤ hi`, иначе `0`.

Строка `spec` задаёт частично применённую функцию: `имя(арг,арг,…)` без пробелов, где каждый аргумент — либо целое число (возможно отрицательное), либо метка `_k` (`k ≥ 1`). Метка `_k` означает «возьмите `k`-е из чисел, которые придут при вызове»; одна метка может встречаться несколько раз, а метки могут идти в любом порядке.

Дан список вызовов `calls`: каждый вызов — список чисел, в котором есть все нужные метки (лишние числа игнорируются). Верните результат функции для каждого вызова. В тестах показатель `pow` неотрицателен, а результаты помещаются в 32 бита.

Пример: `"mad(_1,_1,_2)"`, `[[3, 1], [-4, 0]]` → `[10, 16]`: `3·3+1` и `(-4)·(-4)+0`.
