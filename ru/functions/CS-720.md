# Самоссылающиеся бесконечные потоки

Бесконечный поток — последовательность целых чисел с номерами `0, 1, 2, …`. Дан список определений `definitions` вида `"имя = выражение"` и список запросов `queries` вида `"имя k"`. Верните список: для каждого запроса элемент номер `k` потока `имя`.

Выражения (лексемы — слова, целые числа, `(`, `)` и `:`):
- `N : S` — поток, начинающийся числом `N`, за которым идёт поток `S` (правоассоциативно: `0 : 1 : S`);
- `from A D` — `A, A + D, A + 2D, …`;
- `add S T`, `mul S T` — поэлементные сумма и произведение; `scale K S` — каждый элемент умножен на `K`;
- `tail S` — `S` без первого элемента; `sums S` — частичные суммы `S[0], S[0] + S[1], …`;
- `merge S T` — слияние: сравните текущие элементы `x` из `S` и `y` из `T`; выдайте меньший и перейдите к следующему в его потоке, а при `x = y` выдайте `x` один раз и сдвиньте оба потока; повторяйте.
Аргументы `S` и `T` — имя или выражение в скобках, `A`, `D`, `K`, `N` — целые числа (возможно отрицательные).

Определения могут ссылаться на любые имена, в том числе на себя и на определённые ниже: `fibs = 0 : 1 : add fibs (tail fibs)`. Гарантируется, что каждый запрошенный элемент определён (вычисление не зацикливается), до 20 определений, `k ≤ 2000`, и каждый элемент, нужный для ответов, по модулю не больше `10^15`.

Пример: `["fibs = 0 : 1 : add fibs (tail fibs)"]`, `["fibs 10"]` → `[55]`.
