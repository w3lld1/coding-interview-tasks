# Раскрытие псевдонимов операций

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Рекурсия и перебор](../recursion/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-377?utm_source=github&utm_medium=tasks-repo)**

Есть пять базовых операций над целым числом: `inc` (+1), `dec` (−1), `double` (×2), `negate` (смена знака) и `square` (квадрат). Из них собираются псевдонимы: определение `ПСЕВДОНИМ=имя имя …` (знак `=` без пробелов, справа непустой список имён через пробел) задаёт операцию, которая по очереди применяет перечисленные операции — базовые или другие псевдонимы. Имя псевдонима не совпадает с именем базовой операции и определено не больше одного раза.

Дан список определений `definitions`, список имён `names` и число `x`. Верните список результатов применения каждой операции из `names` к `x` (каждая применяется к исходному `x` отдельно). Пустой `names` даёт пустой список.

Если при раскрытии встретилось неизвестное имя или псевдоним, который прямо или через другие содержит сам себя, сообщите об ошибке: бросьте исключение, в Go верните error. Определения, которые не нужны запрошенным именам, не проверяются. Повторное использование одного псевдонима в разных местах — не цикл. Ошибка относится ко всему вызову. Результаты помещаются в 32 бита.

Пример: `["triple_inc=inc inc inc", "twice=triple_inc triple_inc"]`, `["twice", "inc"]`, `1` → `[7, 2]`.
