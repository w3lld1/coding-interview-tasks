# Значение и производная через дуальные числа

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Разбор и проверка данных](../parsing/), [Математика](../math/)

Даны определения функций `definitions` вида `ИМЯ(x) = ВЫРАЖЕНИЕ` (параметр всегда `x`), выражение `expression` от `x` и точки `points`. Для каждой точки `x₀` верните `[f(x₀), f′(x₀)]` — значение выражения и его производную по `x`.

Выражение: целые неотрицательные числа, переменная `x`, скобки, бинарные `+`, `-`, `*` (умножение сильнее сложения и вычитания, операции одного уровня — слева направо), унарный минус, степень `A^N` с целым `N ≥ 0` (сильнее унарного минуса: `-x^2` значит `-(x^2)`; `x^0 = 1`), вызовы функций `ИМЯ(выражение)`. Встроенные функции: `sq(t) = t²` и `cube(t) = t³`; функция из `definitions` может вызывать встроенные и определённые выше неё. Пробелы необязательны.

Все значения и производные по модулю меньше 10¹⁵ и вычисляются в целых числах точно.

Пример: `[]`, `"3*x^2 - 2*x + 7"`, `[2]` → `[[15, 10]]`.
