# Зафиксировать первый аргумент

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-350?utm_source=github&utm_medium=tasks-repo)**

Даны имя функции двух аргументов `name`, число `fixed` и список чисел `rest`. Зафиксируйте `fixed` как первый аргумент функции и примените получившуюся функцию одного аргумента к каждому числу `x` из `rest`: результат для `x` равен `f(fixed, x)`. Верните список результатов в порядке `rest`.

Функции `f(a, b)`:
- `"sub"`: `a - b`.
- `"div"`: целая часть от деления `a / b`.
- `"pow"`: `a` в степени `b` (`0` в степени `0` равно `1`).
- `"mod"`: остаток от деления `a` на `b`.

Гарантии: `fixed >= 0`; для `"div"` и `"mod"` все `x >= 1`; для `"pow"` `fixed <= 9` и `0 <= x <= 8`; для `"sub"` любые `x`.

Пример: `"div"`, `100`, `[1, 3, 7]` → `[100, 33, 14]`.
