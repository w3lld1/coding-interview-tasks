# Повторить шаг n раз

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-342?utm_source=github&utm_medium=tasks-repo)**

Даны имя шага `name`, неотрицательное целое `x` и число повторов `n`. Примените шаг к `x`, затем к результату, и так `n` раз подряд; верните итог. При `n = 0` ответ равен `x`.

Шаги (над текущим значением `v`):
- `"collatz"`: если `v` чётно, `v / 2`, иначе `3 * v + 1`.
- `"digit_sum"`: сумма десятичных цифр `v`.
- `"reverse_digits"`: число, записанное цифрами `v` в обратном порядке, без ведущих нулей (`120` → `21`).
- `"square_mod"`: остаток от деления `v * v` на `1000`.

`x` не больше 100000, `n` не больше 50, промежуточные значения помещаются в 32-битное целое.

Пример: `"collatz"`, `6`, `3` → `5` (6 → 3 → 10 → 5).
