# Отбор и преобразование по именам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-354?utm_source=github&utm_medium=tasks-repo)**

Даны имя условия `predicate`, имя преобразования `transform` и список целых чисел `numbers`. Оставьте только числа, подходящие под условие, примените к каждому из них преобразование и верните результаты в исходном порядке.

Условия (для числа `n`): `"even"` (чётное, 0 чётно), `"odd"` (нечётное, в том числе отрицательное), `"positive"` (`n > 0`), `"negative"` (`n < 0`), `"multiple_of_5"` (делится на 5 нацело, 0 делится).

Преобразования: `"double"` (`n * 2`), `"square"` (`n * n`), `"negate"` (`-n`), `"inc"` (`n + 1`), `"abs"` (модуль).

Пример: `"even"`, `"square"`, `[1, 2, 3, 4]` → `[4, 16]`.
