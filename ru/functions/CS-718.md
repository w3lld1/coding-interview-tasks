# Мультиметоды и линеаризация C3

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Классы и ООП](../oop/), [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-718?utm_source=github&utm_medium=tasks-repo)**

Реализуйте классы с множественным наследованием и обобщённые функции с выбором метода по классам всех аргументов. Дан список команд `operations` (слова через один пробел); верните список результатов, по одному на команду.

- `class NAME P1 P2 …` — создать класс с прямыми родителями `P1, P2, …` в этом порядке (созданными ранее, без повторов; родителей может не быть). Порядок разрешения (MRO) строится линеаризацией C3: `L(NAME) = NAME + merge(L(P1), …, L(Pk), [P1, …, Pk])`, где `merge` берёт первый из голов списков (слева направо), не встречающийся в хвосте ни одного списка, добавляет его в результат, убирает из голов и повторяет. Если подходящей головы нет, класс не создаётся, результат `"error"`; иначе результат — MRO через пробел.
- `method G LABEL FLAG T1 … Tk` — добавить обобщённой функции `G` метод для классов аргументов `T1 … Tk` с меткой `LABEL`; `FLAG` — `next` (метод вызывает следующий метод) или `stop`. Метод с тем же `G` и теми же классами заменяет прежний. Результат `""`.
- `call G A1 … Ak` — вызвать `G` с аргументами классов `A1 … Ak`. Метод применим, если у него `k` классов и каждый `Ti` есть в MRO класса `Ai`. Применимые методы упорядочите от самого специфичного: сравнивайте позиции аргументов слева направо, и в первой позиции, где классы различаются, специфичнее метод, чей класс стоит раньше в MRO `Ai`. Выполняется первый метод; если у выполненного метода `next`, выполняется следующий по порядку, и так далее. Результат — метки выполненных методов через `>`; если последний выполненный метод вызвал следующий, а его нет, допишите `>no-next`. Если применимых методов нет (или функции `G` нет), результат `"no-method"`.

Команды упоминают только созданные классы, до 100 команд.

Пример: `["class A", "class B A", "class C A", "class D B C", "method greet b next B", "method greet a stop A", "call greet D"]` → `["A", "B A", "C A", "D B C A", "", "", "b>a"]`.
