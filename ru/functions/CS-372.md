# Свёртка каждого окна именованной операцией

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/), [Математика](../math/)

Свёртка списка слева направо берёт первый элемент, затем по очереди сворачивает его со следующими выбранной операцией: для `[a, b, c]` это `op(op(a, b), c)`. Операции названы:
- `sum` — сумма, `product` — произведение, `max`, `min`;
- `gcd` — наибольший общий делитель (`gcd(0, 0) = 0`), `lcm` — наименьшее общее кратное (`lcm` с нулём равно `0`);
- `xor` — побитовое исключающее ИЛИ;
- `diff` — разность, то есть `a - b - c - …`.

Даны список имён операций `names`, список `values` (числа от 0 до 99) и размер окна `k` (от 1 до 4). Окно — это `k` подряд идущих элементов `values`; окон `len(values) - k + 1` (если `values` короче `k`, окон нет). Для каждого имени из `names` верните список результатов свёртки по всем окнам слева направо; итог — список таких списков в порядке `names`. Пустой `names` даёт пустой список.

Пример: `["sum", "max"]`, `[3, 1, 4, 1, 5]`, `3` → `[[8, 6, 10], [4, 4, 5]]`.
