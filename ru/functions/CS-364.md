# Межсетевой экран: первое подходящее правило

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Разбор и проверка данных](../parsing/)

Межсетевой экран проверяет пакеты по списку правил `rules`. Правило записано как `действие протокол порты` (три слова через пробел):
- действие — `allow` или `deny`;
- протокол — `tcp`, `udp` или `any` (подходит любой протокол);
- порты — `*` (любой порт) или список через запятую без пробелов, где каждый элемент — число `80` или отрезок `1000-2000` (границы входят).

Пакет записан как `протокол порт`, например `tcp 443`. Для каждого пакета из `packets` найдите первое по порядку правило, которому он подходит (протокол и порт), и верните его действие. Если подходящего правила нет, ответ — `deny`.

Верните список ответов по одному на пакет. Порты — числа от 0 до 65535.

Пример: `["allow tcp 80,443", "deny any *"]`, `["tcp 80", "tcp 22", "udp 443"]` → `["allow", "deny", "deny"]`.
