# Функции, значения по умолчанию и рецепты

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-15?utm_source=github&utm_medium=tasks-repo)**

Реализуйте функции для рецепта лазаньи:

- `cookingStatus(remainingTime)` — возвращает `'Lasagna is done.'`, если осталось 0 минут; `'Not done, please wait.'` для любого другого числа; `'You forgot to set the timer.'`, если аргумент не передан;
- `preparationTime(layers, averageTimePerLayer = 2)` — время приготовления: число слоёв в массиве `layers` умножить на время на слой;
- `quantities(layers)` — возвращает объект `{ noodles, sauce }`: 50 граммов на каждый слой `'noodles'` и 0.2 литра на каждый слой `'sauce'`;
- `addSecretIngredient(friendsList, myList)` — добавляет последний элемент `friendsList` в конец `myList`; список друга не меняет и возвращает `undefined`;
- `scaleRecipe(recipe, portions)` — рецепт `recipe` рассчитан на 2 порции; верните новый объект с количествами для `portions` порций, исходный не меняйте.
