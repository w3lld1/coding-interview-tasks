# Фабрика счётчиков

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-341?utm_source=github&utm_medium=tasks-repo)**

Реализуйте набор независимых счётчиков. Даны список операций `operations` и список их аргументов `values` (`values[i]` относится к `operations[i]`). Сначала счётчиков нет. Верните список результатов, по одному на операцию. Номера счётчиков в тестах всегда существуют.

Операции:
- `"create"` с аргументами `start` и `step`: создать счётчик с текущим значением `start` и шагом `step`; номера выдаются по порядку создания с 0; результат: номер нового счётчика.
- `"tick"` с аргументом `id`: результат: текущее значение счётчика, после чего к нему прибавляется его шаг.
- `"peek"` с аргументом `id`: результат: текущее значение счётчика, без изменений.
- `"reset"` с аргументом `id`: вернуть счётчику его начальное значение `start`; результат: это значение.

Пример: `["create", "tick", "tick", "peek", "reset", "tick"]`, `[[10, 5], [0], [0], [0], [0], [0]]` → `[0, 10, 15, 20, 10, 10]`.
