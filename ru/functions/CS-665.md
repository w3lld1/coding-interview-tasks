# Программа диска: позиция через триллионы тактов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/), [Словари и множества](../hashing/)

У кодового диска `m` позиций: `0 … m-1`; сначала он стоит в позиции `start`. Каждый такт к позиции по очереди применяются шаги программы `program`, каждый — строка `имя` или `имя:K`:
- `add:K` → `(x + K) mod m`; `mul:K` → `(x · K) mod m`; `xor:K` → `(x XOR K) mod m` (побитовое исключающее ИЛИ);
- `square` → `x² mod m`; `rev` → `m − 1 − x`; `half` → `x / 2` с округлением вниз;
- `digitsum` → сумма десятичных цифр `x`, по модулю `m`.
Пустая программа оставляет позицию прежней.

Для каждого `k` из `queries` верните позицию диска после `k` тактов (после `0` тактов — `start`). Ограничения: `1 ≤ m ≤ 20000`, `0 ≤ start < m`, `0 ≤ K ≤ 10000`, до 10 шагов, до 20 запросов, `0 ≤ k ≤ 10¹⁵`.

Пример: `12`, `1`, `["mul:5", "add:1"]`, `[0, 1, 2, 3]` → `[1, 6, 7, 0]`.
