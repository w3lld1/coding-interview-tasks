# Типизированный конвейер шагов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Исключения](../errors/), [Разбор и проверка данных](../parsing/)

Значение имеет тип: сначала это строка `value` (тип `string`). Шаги из списка `steps` применяются по очереди; каждый принимает значение определённого типа и возвращает значение определённого типа:
- `to_int`: string → int (десятичная запись с необязательным минусом, например `"-15"`; не более 6 цифр);
- `len`: string → int (длина); `upper`, `reverse`, `trim` (убрать пробелы по краям): string → string;
- `double`, `inc`, `square`, `neg`: int → int (×2, +1, квадрат, смена знака);
- `to_str`: int → string; `is_even`: int → bool;
- `not`: bool → bool; `show`: bool → string (`"yes"` или `"no"`).

Верните итоговое значение в виде строки: строка как есть, число в десятичной записи, булево значение как `"true"` или `"false"`. Пустой список шагов возвращает `value`.

Если шаг неизвестен, получает значение не того типа или `to_int` применяется к строке, которая не является числом (пустая, только `-`, с другими символами), сообщите об ошибке: бросьте исключение, в Go верните error. Ошибка относится ко всему вызову: даже если ошибочный шаг стоит после нескольких удачных.

Пример: `"42"`, `["to_int", "double", "to_str"]` → `"84"`.
