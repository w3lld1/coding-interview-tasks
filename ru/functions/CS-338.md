# Свёртка списка по имени операции

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-338?utm_source=github&utm_medium=tasks-repo)**

Даны имя операции `op`, список целых чисел `numbers` и начальное значение `start`. Положите в накопитель `start`, затем по порядку для каждого числа замените накопитель на результат операции над накопителем и этим числом. Верните накопитель. Для пустого списка ответ равен `start`.

Операции (над накопителем `a` и числом `b`):
- `"sum"`: `a + b`.
- `"product"`: `a * b`.
- `"max"`: большее из двух.
- `"min"`: меньшее из двух.
- `"gcd"`: наибольший общий делитель; при этом все числа и `start` неотрицательны, а `gcd(0, 0)` равен `0`.

Результат помещается в 32-битное целое.

Пример: `"product"`, `[2, 3, 4]`, `1` → `24`.
