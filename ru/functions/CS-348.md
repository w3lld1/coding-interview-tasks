# Первый аргумент, достигающий цели

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-348?utm_source=github&utm_medium=tasks-repo)**

Дано имя возрастающей функции `name` и целое `target` (от 0 до 1000000). Найдите наименьшее целое `n >= 0`, при котором значение функции в `n` не меньше `target`.

Функции:
- `"square"`: `n * n`.
- `"cube"`: `n * n * n`.
- `"triangle"`: `n * (n + 1) / 2` (результат целый).
- `"double_inc"`: `2 * n + 1`.
- `"power_of_two"`: `2` в степени `n`.

Пример: `"square"`, `50` → `8` (`7 * 7 = 49 < 50`, `8 * 8 = 64`).
