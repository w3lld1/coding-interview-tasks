# Мемоизация с временем жизни записей

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Словари и множества](../hashing/)

Функция мемоизирована кэшем с временем жизни (TTL). В кэше для ключа хранится момент `s`: когда значение было вычислено (режим `"fixed"`) или когда к нему в последний раз обращались (режим `"sliding"`). Кэш в начале пуст.

Даны `ttl` (целое > 0), режим `mode` и список вызовов `calls`: каждый вызов — пара `[время, ключ]`, времена не убывают. Вызов в момент `t` с ключом `k`:
- если `k` нет в кэше — `"miss"`: значение вычисляется и запоминается с моментом `t`;
- если `k` есть и `t - s < ttl` — `"hit"`: значение берётся из кэша; в режиме `"sliding"` момент `s` становится `t`, в режиме `"fixed"` не меняется;
- если `k` есть, но `t - s ≥ ttl` — `"expired"`: запись устарела, значение вычисляется заново и запоминается с моментом `t`.

Верните список ответов по одному на вызов.

Пример: `10`, `"fixed"`, `[[0, 1], [5, 1], [10, 1], [11, 1]]` → `["miss", "hit", "expired", "hit"]`: на 10 запись, созданная в 0, уже устарела, а новая, созданная в 10, живёт и в 11.
