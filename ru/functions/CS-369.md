# Обработчики событий с приоритетами и остановкой

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Поиск и сортировка](../search-sort/)

Шина событий хранит для каждого события обработчики с приоритетами. Обработчики названы и меняют число (полезную нагрузку): `inc` — прибавить 1, `double` — умножить на 2, `square` — возвести в квадрат, `negate` — сменить знак, `stop` — не менять число, но прервать цепочку.

Дан список команд `commands`; верните по числу на каждую команду. Слова в команде разделены одним пробелом:
- `on событие обработчик приоритет` — зарегистрировать обработчик (приоритет — целое, может быть отрицательным); результат — число обработчиков этого события после регистрации. Один и тот же обработчик можно зарегистрировать несколько раз;
- `off событие обработчик` — убрать все регистрации этого обработчика у этого события; результат — число оставшихся обработчиков события;
- `emit событие число` — запустить обработчики события по убыванию приоритета (при равных приоритетах — в порядке регистрации): каждый получает результат предыдущего, первый получает `число`. Если запущен `stop`, остальные обработчики не запускаются. Результат — итоговое число (для события без обработчиков — исходное).

Пример: `["on save inc 1", "on save double 5", "emit save 3"]` → `[1, 2, 7]`: сначала `double` (приоритет 5): 6, затем `inc`: 7.
