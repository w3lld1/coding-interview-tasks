# Мини-движок запросов к таблице

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/), [Словари и множества](../hashing/)

Дана таблица: имена столбцов `columns` и строки `rows` (списки целых чисел той же длины). Запрос `query` — список шагов, которые по очереди преобразуют таблицу (и её набор столбцов); верните строки итоговой таблицы. Шаги (слова через пробел):
- `where C OP V` — оставить строки, где значение столбца `C` в сравнении `OP` (`<`, `<=`, `>`, `>=`, `==`, `!=`) с целым `V` истинно;
- `select C1 C2 …` — оставить только эти столбцы в этом порядке;
- `derive N F A B` — добавить в конец столбец `N` со значением `F(A, B)`, где `F` — `add`, `sub` (A − B), `mul`, `max` или `min`, а `A` и `B` — имена столбцов или целые числа;
- `group K1,K2,… AGG:C …` — сгруппировать строки по значениям ключевых столбцов (через запятую) и для каждой группы выдать строку: значения ключей, затем значения агрегатов в указанном порядке. Агрегаты: `sum`, `count` (число строк группы), `min`, `max`, `avg` (сумма, делённая на количество с округлением вниз). Новые столбцы: ключи, затем `AGG_C` (например `sum_qty`). Группы идут в порядке появления их первой строки;
- `order C1 DIR1 C2 DIR2 …` — устойчиво отсортировать по столбцам, `DIR` — `asc` (по возрастанию) или `desc` (по убыванию); равные по всем ключам строки сохраняют порядок;
- `limit N` — оставить первые `N` строк;
- `distinct` — убрать повторяющиеся строки, оставив первое вхождение.

Запрос корректен: все имена существуют, имена столбцов различны. До 100 строк, до 10 шагов, все значения помещаются в 32-битное целое.

Пример: `["a", "b"]`, `[[1, 5], [2, 7], [1, 4]]`, `["group a sum:b", "order sum_b asc"]` → `[[2, 7], [1, 9]]`.
