# Маленький движок правил с выводом тегов

Дан набор фактов `facts` (имя → целое число) и список правил `rules`. Правило записано как `УСЛОВИЕ => тег` (разделитель ровно ` => `). Условие — одно или несколько простых условий, соединённых ` and `. Простое условие — это либо три слова `имя оператор число` (оператор из `>`, `>=`, `<`, `<=`, `==`, `!=`; число может быть отрицательным), либо одно слово — имя тега, которое истинно, если такой тег уже выведен. Условие про факт, которого нет в `facts`, ложно.

Вывод идёт так. Проходите правила по порядку; правило, которое ещё не срабатывало и у которого все условия истинны сейчас (с учётом уже выведенных тегов), срабатывает: его тег добавляется в конец результата, если такого тега там ещё нет. Правило срабатывает не больше одного раза. Новый проход начинается, если на предыдущем что-то сработало; когда проход ничего не меняет, вывод закончен.

Верните выведенные теги в порядке добавления.

Пример: факты `{"age": 20, "score": 70}`, правила `["adult and score > 60 => admit", "age >= 18 => adult"]` → `["adult", "admit"]`: на первом проходе первое правило ещё не выполняется, сработало второе, на втором — первое.
