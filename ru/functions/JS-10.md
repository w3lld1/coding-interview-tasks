# Замыкания для преобразования координат

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Функции и замыкания](../functions/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-10?utm_source=github&utm_medium=tasks-repo)**

Создайте translate2d(dx, dy) и scale2d(sx, sy), возвращающие функции от координат (x, y) с результатом в виде пары [x, y]; первая прибавляет смещения, вторая умножает координаты на положительные коэффициенты. Реализуйте composeTransform(f, g), последовательно применяющую сначала f, затем g. Добавьте memoizeTransform: обёртка хранит только последнюю пару входных координат и последний результат, поэтому повторный вызов с той же парой не должен вычислять преобразование заново.
