# Цепочка промежуточных обработчиков с повторами

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Рекурсия и перебор](../recursion/), [Стек, очередь, связные списки](../stacks-lists/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-666?utm_source=github&utm_medium=tasks-repo)**

Запрос (целое число) проходит через цепочку промежуточных обработчиков `middlewares` (первый — самый внешний) к конечному обработчику. Каждый промежуточный обработчик получает запрос и функцию `next` — остаток цепочки — и сам решает, вызывать ли её, сколько раз и с каким запросом. Результат вызова — число или неудача.

Конечный обработчик `h` нумерует свои вызовы за всё время работы, начиная с `1`. Вызов с номером из `fail_calls` или с отрицательным запросом `x` — неудача, в журнал пишется `h(x)!`; иначе результат `2x`, в журнал пишется `h(x)=2x`.

Промежуточные обработчики (параметры через `:`):
- `log:N` — пишет `N>`, вызывает `next(x)`, затем пишет `<N` при успехе или `<N!` при неудаче;
- `retry:K` — вызывает `next(x)`, а при неудаче повторяет ещё до `K` раз; результат — первый успех или последняя неудача;
- `fallback:V` — вызывает `next(x)`; неудачу заменяет успехом `V`;
- `cache` — если для запроса `x` уже есть сохранённый успешный результат этого обработчика, возвращает его без вызова `next`; иначе вызывает `next(x)` и сохраняет успех (неудачи не сохраняются). Память у каждого `cache` своя и живёт весь вызов функции;
- `guard:T` — при `x < T` сразу неудача без вызова `next`, иначе `next(x)`;
- `add:K` — вызывает `next(x + K)`;
- `breaker:F:C` — предохранитель: если открыт, уменьшает счётчик блокировки и сразу возвращает неудачу; иначе вызывает `next(x)`; после `F` неудачных вызовов `next` подряд (успех обнуляет их счёт) открывается на следующие `C` вызовов, а счёт неудач обнуляется.

Запросы `requests` обрабатываются по очереди, состояние (номера вызовов `h`, кэши, предохранители) сохраняется между ними. Для каждого запроса верните строку: записи журнала этого запроса через пробел, затем `=>` и результат (число или `fail`). Если журнал пуст, строка начинается с `=>`. До 10 обработчиков, до 20 запросов, числа по модулю до 10⁶.

Пример: `["log:A", "retry:2", "log:B"]`, `[1, 2]`, `[3]` → `["A> B> h(3)! <B! B> h(3)! <B! B> h(3)=6 <B <A => 6"]`.
