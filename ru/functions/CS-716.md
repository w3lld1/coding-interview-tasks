# Реактивные сигналы без промежуточных значений

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Классы и ООП](../oop/), [Деревья и графы](../trees-graphs/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-716?utm_source=github&utm_medium=tasks-repo)**

Реализуйте граф реактивных значений. Дан список команд `operations` (слова разделены одним пробелом); верните список результатов, по одному на команду.

- `signal NAME V` — создать исходный сигнал со значением `V`; результат `""`.
- `computed NAME F A [B]` — создать вычисляемое значение: функция `F` от значений `A` и `B` (уже созданных сигналов или вычисляемых значений); оно сразу вычисляется. Функции двух аргументов: `add` (сумма), `sub` (`A − B`), `mul`, `max`, `min`; одного: `neg` (минус), `abs`, `sign` (−1, 0 или 1). Результат `""`.
- `effect NAME DEP` — создать эффект, следящий за `DEP`; он сразу срабатывает один раз; результат `"NAME=значение"`.
- `set NAME V` — новое значение исходного сигнала. Вне пакета результат — отчёт об обновлении (ниже), внутри пакета значение только запоминается, результат `""`.
- `batch` — начать пакет (пакеты не вложены; внутри бывают только `set` и `get`); результат `""`. `commit` — закончить пакет и провести одно обновление; результат — отчёт.
- `get NAME` — текущее значение как строка. Внутри пакета для исходного сигнала это запомненное новое значение, для вычисляемого — значение до пакета.

Обновление. Изменились исходные сигналы, чьё значение стало другим (в пакете сравнивается значение до пакета и последнее заданное). Вычисляемое значение пересчитывается, только если изменился хотя бы один его прямой аргумент, и не больше одного раза за обновление: сначала должны устояться все его аргументы. Если после пересчёта значение то же, оно не считается изменившимся (дальше изменение не идёт). Когда всё устоялось, срабатывают эффекты, чей `DEP` изменился, в порядке создания эффектов. Отчёт: `"k|e1=v1,e2=v2"`, где `k` — сколько раз вызывались функции, далее эффекты с новыми значениями (`"0|"`, если ничего).

Команды корректны, до 100 команд, все значения помещаются в 32-битное целое.

Пример: `["signal a 1", "computed b add a a", "computed c mul a a", "computed d sub b c", "effect e d", "set a 2"]` → `["", "", "", "", "e=1", "3|e=0"]` (`d` пересчитан один раз, после `b` и `c`).
