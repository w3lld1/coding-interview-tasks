# Попарное объединение двух списков

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/)

Даны имя операции `op` и два списка целых чисел `a` и `b`. Верните список, в котором элемент с номером `i` равен результату операции над `a[i]` и `b[i]`. Если списки разной длины, лишний хвост более длинного игнорируется: длина результата равна длине более короткого списка.

Операции (над `x = a[i]` и `y = b[i]`):
- `"add"`: `x + y`.
- `"sub"`: `x - y`.
- `"mul"`: `x * y`.
- `"max"`: большее из двух.
- `"min"`: меньшее из двух.
- `"diff"`: модуль разности, `|x - y|`.

Пример: `"sub"`, `[5, 5]`, `[1, 7]` → `[4, -2]`.
