# Пометить числа подходящими условиями

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Массивы и списки](../arrays/), [Строки](../strings/)

Даны список имён условий `predicates` (имена различны) и список целых чисел `numbers`. Для каждого числа верните строку: имена всех условий, которым число удовлетворяет, в том порядке, в каком они стоят в `predicates`, через запятую без пробелов. Если число не подходит ни под одно условие, строка пустая. Результат содержит по строке на число, в исходном порядке.

Условия (для числа `n`): `"even"` (чётное, 0 чётно), `"odd"` (нечётное, в том числе отрицательное), `"positive"` (`n > 0`), `"negative"` (`n < 0`), `"multiple_of_5"` (делится на 5 нацело, 0 делится), `"big"` (модуль `n` не меньше 100).

Пример: `["even", "positive"]`, `[4, -2, 3, 0]` → `["even,positive", "even", "positive", "even"]`.
