# Текстовый конвейер с условными шагами

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Функции и замыкания](../functions/), [Строки](../strings/), [Разбор и проверка данных](../parsing/)

Дан конвейер строк: список шагов `steps`, которые применяются по очереди к каждой строке из `texts` (все строки состоят из символов ASCII). Верните список результатов в том же порядке. Пустой конвейер возвращает строки без изменений.

Простые шаги:
- `trim` — убрать пробелы по краям; `squeeze` — заменить каждую серию пробелов одним пробелом;
- `upper`, `lower` — перевести буквы в верхний / нижний регистр; `reverse` — развернуть строку;
- `drop_vowels` — удалить гласные `aeiouAEIOU`;
- `truncate:n` — оставить первые `n` символов (или всю строку, если она короче);
- `pad:n` — дописать справа точки `.` до длины `n` (если строка короче);
- `repeat:n` — повторить строку `n` раз (`n ≥ 0`).

Условные шаги оборачивают любой другой шаг, в том числе условный: `when_longer:n:ШАГ` применяет `ШАГ`, только если текущая длина строки больше `n`; `when_shorter:n:ШАГ` — если меньше `n`; `when_has:c:ШАГ` — если строка содержит символ `c` (один символ, не двоеточие, может быть пробелом). Иначе строка проходит без изменений. Условие проверяется на строке, пришедшей на этот шаг.

Пример: `["when_longer:5:reverse"]`, `["abcdef", "abcde"]` → `["fedcba", "abcde"]`.
