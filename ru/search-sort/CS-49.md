# Поиск в сдвинутом списке

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-49?utm_source=github&utm_medium=tasks-repo)**

Отсортированный по возрастанию список различных целых чисел циклически сдвинули на неизвестное число позиций (например, `[0, 1, 2, 4, 5, 6, 7]` могло стать `[4, 5, 6, 7, 0, 1, 2]`; сдвиг на 0 допустим). Дан такой список (до 100000 элементов) и число `target`. Верните индекс `target` в списке или `-1`, если его нет. Для пустого списка ответ `-1`. Ожидается решение за O(log n).

Пример: `[4, 5, 6, 7, 0, 1, 2]`, `0` → `4`.
