# Наибольший капитал после k проектов

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Поиск и сортировка](../search-sort/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-179?utm_source=github&utm_medium=tasks-repo)**

У вас есть капитал `w`. Проект `i` можно начать, только если текущий капитал не меньше `capital[i]`; вложенное не тратится, а после завершения проект добавляет к капиталу чистую прибыль `profits[i]`. Проекты выполняются по одному, каждый не больше одного раза. Выберите не больше `k` проектов и их порядок так, чтобы итоговый капитал был наибольшим, и верните его.

Если ни один проект недоступен, ответ равен `w`; `k` может быть больше числа проектов. Ограничения: до 10 000 проектов, `0 ≤ k ≤ 10^5`, `0 ≤ w, profits[i], capital[i] ≤ 10^9`; ответ может не поместиться в 32 бита.

Пример: `2`, `0`, `[1, 2, 3]`, `[0, 1, 1]` → `4` (сначала проект 0, затем проект 2).
