# Колода из улучшенных карт

**Сложность:** сложная · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Поиск и сортировка](../search-sort/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CJ-98?utm_source=github&utm_medium=tasks-repo)**

У игрока `N` карт и `coins` монет. Карта `i` может иметь уровень от `1` до `K_i = len(powers[i])`; на уровне `j` её сила равна `powers[i][j-1]` (сила строго растёт с уровнем). Сейчас карта на уровне `levels[i]`. Повысить карту `i` с уровня `j` до `j + 1` стоит `costs[i][j-1]` монет; повышать можно только на один уровень за раз, но сколько угодно раз, пока хватает монет. Понижать уровни нельзя.

Игрок тратит часть монет (или ни одной) на повышения, а затем собирает колоду ровно из `deck` разных карт. Верните наибольшую возможную суммарную силу колоды. Монеты на карты вне колоды тратить бессмысленно, но разрешено.

Ограничения: `1 ≤ deck ≤ N ≤ 12`, `1 ≤ K_i ≤ 5`, `0 ≤ coins ≤ 3·10^9`, силы и цены от `1` до `10^9`; суммы не помещаются в 32 бита. В оригинальной игре `deck = 8`.

Пример: `10`, `1`, `[1, 1]`, `[[1, 50, 60], [30, 40]]`, `[[6, 5], [3]]` → `50` (первая карта до уровня 2 за 6 монет).
