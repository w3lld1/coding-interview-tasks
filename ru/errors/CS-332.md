# Элементы списка по номерам

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-332?utm_source=github&utm_medium=tasks-repo)**

Даны список строк `items` и список номеров `indexes`. Верните список строк: для каждого номера по порядку — элемент `items` с этим номером. Номера считаются с нуля; отрицательный номер отсчитывается с конца: `-1` — последний элемент, `-2` — предпоследний и так далее. Номера могут повторяться.

Допустимы номера от `-n` до `n - 1`, где `n` — длина `items`. Если хотя бы один номер вне этого диапазона, сообщите об ошибке: бросьте исключение, в Go верните error. При пустом `indexes` результат пуст, даже если пуст и `items`.

Пример: `["a", "b", "c", "d"]`, `[-1, 0]` → `["d", "a"]`; `["a", "b", "c"]`, `[1, 3]` → ошибка.
