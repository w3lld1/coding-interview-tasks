# Строка настройки «ключ = значение»

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Разбор и проверка данных](../parsing/), [Строки](../strings/)

Загрузчик настроек читает файл по строкам. Строка должна иметь вид `ключ = значение`. Разделите её по ПЕРВОМУ знаку `=`: всё до него — ключ, всё после — значение (значение может быть пустым и может содержать другие `=`). Пробелы (только символ пробела) в начале и в конце ключа и значения отбросьте.

Ключ допустим, если он не пуст, начинается с латинской буквы или `_`, а остальные его символы — латинские буквы, цифры или `_`. Если в строке нет `=` или ключ недопустим, сообщите об ошибке: бросьте исключение, в Go верните error.

Верните список из двух строк: ключ и значение.

Пример: `"  port =  8080 "` → `["port", "8080"]`; `"path=/a=b"` → `["path", "/a=b"]`; `"1abc=2"` → ошибка.
