# Цвет «#RRGGBB» в числа

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Разбор и проверка данных](../parsing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-329?utm_source=github&utm_medium=tasks-repo)**

Дизайнер присылает цвет в виде `#RRGGBB`: символ `#` и ровно шесть шестнадцатеричных цифр (`0`–`9`, `a`–`f`, `A`–`F`, регистр любой). Первые две цифры — красный канал, следующие две — зелёный, последние две — синий.

Верните список из трёх целых чисел `[красный, зелёный, синий]`, каждое от 0 до 255. Если строка не соответствует формату (нет `#`, не шесть цифр, есть другие символы, в том числе пробелы), сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"#FF8000"` → `[255, 128, 0]`; `"#1a2B3c"` → `[26, 43, 60]`; `"FF8000"` → ошибка.
