# Средний балл экзамена с проверкой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-328?utm_source=github&utm_medium=tasks-repo)**

Преподаватель собрал баллы за экзамен. Каждый балл — целое число от 0 до 100 включительно. Верните средний балл: сумму, делённую на количество (обычное деление, не целочисленное).

Если список пуст (среднего нет) или хотя бы один балл вне диапазона от 0 до 100, сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `[80, 90, 100]` → `90`; `[70, 71]` → `70.5`; `[]` → ошибка; `[50, 101]` → ошибка.
