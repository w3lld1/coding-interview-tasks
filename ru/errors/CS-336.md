# Номер столбца таблицы по имени

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Строки](../strings/), [Математика](../math/)

В электронных таблицах столбцы называются буквами: `A` — первый, `B` — второй, …, `Z` — 26-й, затем `AA` — 27-й, `AB` — 28-й, …, `AZ` — 52-й, `BA` — 53-й и так далее (как система счисления по основанию 26 без нуля).

По имени столбца верните его номер, считая с 1. Имя допустимо, если оно состоит из 1–4 заглавных латинских букв `A`–`Z`. Если имя пустое, длиннее четырёх букв или содержит что-то кроме заглавных букв (строчные буквы, цифры, пробелы, другие символы), сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"A"` → `1`; `"AB"` → `28`; `"ZZ"` → `702`; `"a"` → ошибка.
