# Остаток товара после заказов

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-333?utm_source=github&utm_medium=tasks-repo)**

На складе магазина лежит `stock` штук товара. Заказы обрабатываются строго по порядку; заказ — это количество штук, которое нужно отгрузить. Обработанный заказ уменьшает остаток.

Верните список: остаток на складе после каждого заказа.

Если начальный остаток отрицателен, какой-то заказ меньше 1 или какой-то заказ больше текущего остатка (товара не хватает), сообщите об ошибке: бросьте исключение, в Go верните error. Заказ ровно на весь остаток допустим. Без заказов результат пуст (при допустимом остатке, в том числе нулевом).

Пример: `10`, `[3, 2, 5]` → `[7, 5, 0]`; `10`, `[6, 5]` → ошибка.
