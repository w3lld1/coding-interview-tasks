# Типизированные ошибки датчиков

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Исключения](../errors/), [Классы и ООП](../oop/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-16?utm_source=github&utm_medium=tasks-repo)**

Реализуйте функции проверки датчиков:

- `checkHumidityLevel(humidityPercentage)` — если влажность больше 70, бросает `Error`, иначе возвращает `undefined`;
- `reportOverheating(temperature)` — если `temperature` равна `null`, бросает `ArgumentError`; если температура больше 500, бросает `OverheatingError` (в её поле `temperature` хранится температура); иначе возвращает `undefined`;
- `monitorTheMachine(actions)` — вызывает `actions.check()`. Если проверка бросила `ArgumentError`, вызовите `actions.alertDeadSensor()`. Если `OverheatingError` с температурой не больше 600 — `actions.alertOverheating()`, а выше 600 — `actions.shutdown()`. Любую другую ошибку бросьте дальше. Если проверка прошла без ошибки, ничего не делайте.

Классы `ArgumentError` и `OverheatingError` есть в заготовке.
