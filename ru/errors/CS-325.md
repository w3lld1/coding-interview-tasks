# Поэлементное деление с проверкой

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Массивы и списки](../arrays/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-325?utm_source=github&utm_medium=tasks-repo)**

Даны два списка чисел одинаковой длины: делимые и делители. Верните список, в котором на каждой позиции стоит результат обычного (не целочисленного) деления делимого на делитель с той же позиции.

Если списки разной длины или среди делителей есть ноль (на любой позиции, даже в конце), сообщите об ошибке: бросьте исключение, в Go верните error. Два пустых списка дают пустой список.

Пример: `[10, 9, 7]`, `[2, 3, 2]` → `[5, 3, 3.5]`; `[4, 5]`, `[2, 0]` → ошибка.
