# Номер версии «major.minor.patch»

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Разбор и проверка данных](../parsing/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-335?utm_source=github&utm_medium=tasks-repo)**

Номер версии программы записывается как `major.minor.patch`: ровно три числа, разделённые точками. Каждое число — десятичная запись неотрицательного целого без знака и пробелов, без ведущих нулей (число 0 записывается одной цифрой `0`) и не длиннее шести цифр.

Верните список из трёх целых `[major, minor, patch]`. Если строка не соответствует формату (частей не три, пустая часть, ведущий нуль, посторонний символ вроде `v`, слишком длинное число), сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"1.2.3"` → `[1, 2, 3]`; `"10.0.30"` → `[10, 0, 30]`; `"1.02.3"` → ошибка; `"1.2"` → ошибка.
