# Список чисел из строки

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Исключения](../errors/), [Разбор и проверка данных](../parsing/), [Массивы и списки](../arrays/)

Пользователь вводит числа через запятую, например `"1, 2, -3"`. Преобразуйте строку в список целых чисел в том же порядке.

Правила. Строка делится запятыми на элементы. Пробелы (только символ пробела) вокруг элемента отбрасываются. Элемент — это необязательный минус и от 1 до 9 цифр; плюс, пробелы внутри числа, дробная часть и любые другие символы недопустимы. Ведущие нули разрешены. Пустой элемент (например, `"1,,2"` или запятая в конце) — ошибка. Строка, пустая или состоящая только из пробелов, даёт пустой список.

При нарушении правил сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"1, 2, -3"` → `[1, 2, -3]`; `""` → `[]`; `"1,,2"` → ошибка; `"1.5, 2"` → ошибка.
