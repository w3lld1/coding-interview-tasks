# Дни выплаты зарплаты

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-618?utm_source=github&utm_medium=tasks-repo)**

Компания платит зарплату в последний рабочий день месяца. Рабочие дни — с понедельника по пятницу, праздники не учитываются. Дан год `year` (от `1600` до `9999`, григорианский календарь). Верните список из `12` чисел: для каждого месяца от января до декабря — число месяца, в которое выплата.

Пример: `2023` → `[31, 28, 31, 28, 31, 30, 31, 31, 29, 31, 30, 29]`.
