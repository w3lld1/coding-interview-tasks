# Назначение встреч и Date

**Сложность:** средняя · **Язык:** JavaScript · **Темы:** [Даты и время](../dates/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/JS-21?utm_source=github&utm_medium=tasks-repo)**

Реализуйте функции для встреч:

- `createAppointment(days, now)` — возвращает `Date` через `days` календарных дней от момента `now` (число миллисекунд); если `now` не передан, считайте от текущего времени. Местное время суток сохраняется, даже при переходе на летнее время;
- `getAppointmentTimestamp(appointmentDate)` — возвращает ISO-строку даты (`toISOString`);
- `getAppointmentDetails(timestamp)` — по строке времени возвращает объект `{ year, month, date, hour, minute }` в местном времени; месяц нумеруется с нуля;
- `updateAppointment(timestamp, options)` — меняет в дате поля из `options` (они называются так же; значение 0 тоже применяется, переполнение нормализует `Date`) и возвращает такой же объект деталей;
- `timeBetween(timestampA, timestampB)` — разница «B минус A» в секундах, округлённая до целого;
- `isValid(appointmentTimestamp, currentTimestamp)` — `true`, если встреча строго позже текущего момента.
