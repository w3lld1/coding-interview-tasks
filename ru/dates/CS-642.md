# Длительности ISO 8601 по очереди

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Разбор и проверка данных](../parsing/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-642?utm_source=github&utm_medium=tasks-repo)**

Дан момент `start` вида `"YYYY-MM-DD HH:MM"` и список длительностей `durations` в упрощённом формате ISO 8601. Длительность — необязательный знак `-`, буква `P`, затем по порядку необязательные части `nY` (годы), `nM` (месяцы), `nW` (недели), `nD` (дни), затем необязательная часть времени: буква `T` и по порядку `nH` (часы) и `nM` (минуты). Здесь `n` — от одной до трёх цифр; должна быть хотя бы одна часть, а после `T` — хотя бы одна часть времени. Например: `"P1Y2M"`, `"P1W2D"`, `"PT36H"`, `"-P1M1DT1H"`.

Применяйте длительности по очереди. Каждая применяется так: сначала годы и месяцы сдвигают месяц (если в новом месяце нет такого числа, берётся его последний день), затем прибавляются недели и дни, затем часы и минуты. Для знака `-` все части вычитаются в том же порядке. Верните итоговый момент в формате `"YYYY-MM-DD HH:MM"`; пустой список возвращает `start`. Календарь григорианский, часовых поясов нет, `start` корректен, все промежуточные годы лежат в пределах 1000–9000.

Если какая-то длительность записана не по этим правилам, сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `"2024-01-31 10:00"`, `["P1M", "P1M"]` → `"2024-03-29 10:00"`.
