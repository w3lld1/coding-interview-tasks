# Чистое время вложенных кухонных задач

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Стек, очередь, связные списки](../stacks-lists/)

Повар ведёт журнал `log` за один день — строки `"HH:MM:SS start ИМЯ"` и `"HH:MM:SS end ИМЯ"` в хронологическом порядке (время не убывает). Задачи вкладываются: если новая задача начинается, пока идёт другая, внешняя приостанавливается, а когда вложенная заканчивается, внешняя продолжается. Каждый `end` закрывает самую последнюю начатую и ещё не закрытую задачу и содержит её имя; журнал корректен, к концу все задачи закрыты. Задача с одним именем может выполняться несколько раз, в том числе вложенно в себя.

Чистое время задачи — сколько секунд она была самой внутренней из выполняющихся (`end` в момент `t` означает, что задача шла до `t`, не включая). Верните словарь «имя → суммарное чистое время в секундах» по всем запускам; в нём есть каждое встретившееся имя, даже с временем `0`. Пустой журнал даёт пустой словарь.

Пример: `["18:00:00 start soup", "18:05:00 start onions", "18:12:30 end onions", "18:20:00 end soup"]` → `{"soup": 750, "onions": 450}`.
