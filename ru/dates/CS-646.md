# Табло хакатона по времени отправок

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Поиск и сортировка](../search-sort/), [Словари и множества](../hashing/)

Хакатон начался в `start` (`"HH:MM:SS"`) и идёт в пределах одного дня. Отправки `submissions` — строки `"HH:MM:SS КОМАНДА ЗАДАЧА ВЕРДИКТ"` (вердикт `OK` или `FAIL`, все моменты не раньше `start`) в любом порядке; рассматривайте их по времени, при равном времени — в порядке списка. Задача решена командой при первой отправке `OK`; все её отправки этой задачи после этого не учитываются. За решённую задачу штраф — целое число минут от `start` до принятой отправки (с округлением вниз) плюс `20` за каждую `FAIL` по этой задаче до принятия. Нерешённые задачи штрафа не дают.

Верните табло — строки `"КОМАНДА РЕШЕНО ШТРАФ"` для каждой команды, у которой есть хотя бы одна отправка: сначала больше решённых, затем меньше штраф, затем имя команды по возрастанию (по кодам символов). Пустой список даёт `[]`.

Пример: `"10:00:00"`, `["10:12:30 owls A FAIL", "10:15:00 owls A OK", "10:40:59 foxes A OK"]` → `["owls 1 35", "foxes 1 40"]`.
