# Сумма длительностей из строк

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Разбор и проверка данных](../parsing/), [Исключения](../errors/)

Дан список длительностей в записи вроде `"1h30m15s"`: необязательные части «часы `h`», «минуты `m`», «секунды `s`», именно в таком порядке, каждая не более одного раза, каждая — число из 1–6 десятичных цифр и буква. Минуты и секунды не обязаны быть меньше 60 (`"90m"` допустимо). Верните сумму всех длительностей в секундах (число может не поместиться в 32 бита). Для пустого списка верните `0`.

Сообщите об ошибке: бросьте исключение, в Go верните error — если какая-то строка пуста, не следует этой записи (другой порядок частей, повтор части, неизвестная буква, число без буквы, пробелы, знак минус, число длиннее 6 цифр).

Пример: `["1h30m15s", "45s"]` → `5460`.
