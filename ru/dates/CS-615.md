# Подпись «через N дней»

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Строки](../strings/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-615?utm_source=github&utm_medium=tasks-repo)**

Даны сегодняшняя дата `today` и дата события `event` в формате `"ГГГГ-ММ-ДД"` (существующие даты, григорианский календарь). Пусть `n` — число календарных дней от `today` до `event` (отрицательное, если событие в прошлом). Верните подпись:
- `n = 0` → `"today"`;
- `n = 1` → `"tomorrow"`;
- `n = -1` → `"yesterday"`;
- `n >= 2` → `"in n days"`;
- `n <= -2` → `"k days ago"`, где `k = -n`.

Слова подписи всегда английские, как показано.

Пример: `"2024-03-10"`, `"2024-03-15"` → `"in 5 days"`.
