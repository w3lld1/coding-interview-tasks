# Номер недели по ISO 8601

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Разбор и проверка данных](../parsing/)

Дана дата `date` в формате `"ГГГГ-ММ-ДД"` (существующая дата, григорианский календарь). Верните её неделю по стандарту ISO 8601 в виде `"ГГГГ-Wнн"`, где `нн` — номер недели из двух цифр.

Правила ISO: неделя начинается в понедельник; первая неделя года — та, в которой первый четверг этого года (то есть в ней есть `4` января). Поэтому начало января может относиться к последней неделе прошлого года, а конец декабря — к первой неделе следующего; в строке указан год недели, а не календарный год даты.

Пример: `"2021-01-03"` → `"2020-W53"`.
