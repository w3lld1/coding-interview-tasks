# Сортировка дат по возрастанию

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Разбор и проверка данных](../parsing/), [Поиск и сортировка](../search-sort/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-299?utm_source=github&utm_medium=tasks-repo)**

Дан список дат в формате `ДД.ММ.ГГГГ` (все верные, год из четырёх цифр, григорианский календарь). Верните новый список тех же строк, упорядоченный от самой ранней даты к самой поздней; одинаковые даты идут подряд. Исходный список менять не нужно. Обычное сравнение строк тут не подходит: `"10.02.2023"` лексикографически больше `"09.03.2024"`, хотя дата раньше.

Пример: `["15.03.2024", "01.01.2025", "31.12.2023"]` → `["31.12.2023", "15.03.2024", "01.01.2025"]`.
