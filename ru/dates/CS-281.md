# Длительность часами

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Строки](../strings/), [Исключения](../errors/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-281?utm_source=github&utm_medium=tasks-repo)**

Дано число секунд. Верните длительность в виде `Ч:ММ:СС`: часы без ведущих нулей (их может быть больше 24, суток не выделяют), минуты и секунды всегда из двух цифр.

Если число отрицательное, сообщите об ошибке: бросьте исключение, в Go верните error.

Пример: `3661` → `"1:01:01"`.
