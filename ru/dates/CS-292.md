# Сдвиг времени на часах

**Сложность:** лёгкая · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Математика](../math/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-292?utm_source=github&utm_medium=tasks-repo)**

Дано время `ЧЧ:ММ` (верное, 24-часовой формат) и целое число минут, которое может быть отрицательным и больше суток. Верните время, которое будет на часах через это число минут (раньше — при отрицательном). Часы идут по кругу: после `23:59` идёт `00:00`; даты нет. Результат — `ЧЧ:ММ` с нулями слева.

Пример: `"23:50"`, `20` → `"00:10"`.
