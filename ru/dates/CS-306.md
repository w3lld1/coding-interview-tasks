# Совместные минуты двух смен

**Сложность:** средняя · **Языки:** любой из Python, JavaScript, TypeScript, Java, Go · **Темы:** [Даты и время](../dates/), [Массивы и списки](../arrays/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-306?utm_source=github&utm_medium=tasks-repo)**

У двух сотрудников есть расписания смен на один день. Каждое расписание — список строк `"ЧЧ:ММ-ЧЧ:ММ"` (начало строго раньше конца), смены внутри одного расписания идут по возрастанию времени и не пересекаются (могут касаться). Верните, сколько минут оба сотрудника на смене одновременно. Если одно из расписаний пустое, ответ `0`. Если смена одного кончается ровно в момент начала смены другого, общих минут нет.

Пример: `["09:00-13:00", "14:00-18:00"]`, `["12:00-15:00"]` → `120` (12:00–13:00 и 14:00–15:00).
