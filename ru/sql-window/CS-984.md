# Доля месяца в летней выручке объекта

**Сложность:** средняя · **Язык:** SQL (SQLite) · **Темы:** [SQL: оконные функции](../sql-window/), [SQL: группировка](../sql-aggregate/), [SQL: JOIN](../sql-join/)

Выручка бронирования — `slots`, умноженное на `guestcost` для гостя (`memid = 0`) и на `membercost` для члена клуба. Для каждого объекта и каждого месяца с июля по сентябрь 2012 года, в котором у объекта были бронирования, выведите столбцы `facility` (название объекта), `month` (вида `2012-07`), `revenue` (выручка за месяц) и `percent` — какой процент летней выручки объекта (июль–сентябрь) пришёлся на этот месяц, округлите до одного знака. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
