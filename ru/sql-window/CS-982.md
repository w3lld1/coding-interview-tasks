# Ядро постоянных посетителей объекта

**Сложность:** сложная · **Язык:** SQL (SQLite) · **Темы:** [SQL: оконные функции](../sql-window/), [SQL: группировка](../sql-aggregate/), [SQL: выборка и фильтры](../sql-filter/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-982?utm_source=github&utm_medium=tasks-repo)**

Для каждого объекта посчитайте, сколько слотов забронировал на нём каждый член клуба (гость не учитывается). Упорядочим членов клуба объекта по убыванию слотов, при равенстве — по убыванию `memid`, и будем брать их по очереди, пока набранные слоты не составят хотя бы половину всех слотов членов клуба на этом объекте. Выведите взятых: столбцы `facid`, `memid`, `slots` (его слоты на объекте) и `running` (слоты его и всех взятых до него). Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
