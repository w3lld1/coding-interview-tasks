# Слоты за два последних дня посещений

**Сложность:** средняя · **Язык:** SQL (SQLite) · **Темы:** [SQL: оконные функции](../sql-window/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-963?utm_source=github&utm_medium=tasks-repo)**

Днём посещения назовём дату (`date(starttime)`), в которую у члена клуба есть бронирования. Для каждого бронирования членов клуба с `memid` 1 и 2 выведите столбцы `bookid`, `memid` и `two_days` — сумму слотов всех бронирований того же члена клуба в день этого бронирования и в его предыдущий день посещения (у первого дня — только за сам день). Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
