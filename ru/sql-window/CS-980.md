# Серии визитов несколько дней подряд

**Сложность:** сложная · **Язык:** SQL (SQLite) · **Темы:** [SQL: оконные функции](../sql-window/), [SQL: группировка](../sql-aggregate/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-980?utm_source=github&utm_medium=tasks-repo)**

Серией назовём наибольшую цепочку идущих подряд календарных дней, в каждый из которых у члена клуба есть хотя бы одно бронирование. Для каждой серии длиной не меньше трёх дней выведите столбцы `memid`, `first_day` и `last_day` (даты вида `2012-07-04`) и `days` (длина серии в днях). Гость не учитывается. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
