# Сколько дней прошло с первой игры на корте

**Сложность:** лёгкая · **Язык:** SQL (SQLite) · **Темы:** [SQL: оконные функции](../sql-window/), [SQL: JOIN](../sql-join/)

**[▶ Решить онлайн на CodeShare](https://code-share.ru/practice/CS-888?utm_source=github&utm_medium=tasks-repo)**

Для каждого бронирования объекта с названием `'Tennis Court 1'` выведите столбцы `bookid` и `days_in` — сколько полных суток (24-часовых промежутков, дробную часть отбросьте) прошло от самого первого бронирования этого объекта до начала текущего. У первого бронирования `days_in = 0`. Порядок строк не важен.

Таблицы и данные уже есть в стартовом коде и создаются заново при каждом запуске (SQLite):

- `facilities(facid, name, membercost, guestcost, initialoutlay, monthlymaintenance)` — объекты клуба; `membercost` и `guestcost` — цена одного слота для участника и для гостя.
- `members(memid, surname, firstname, address, zipcode, telephone, recommendedby, joindate)` — участники; `recommendedby` — `memid` пригласившего или `NULL`; `memid = 0` — гость.
- `bookings(bookid, facid, memid, starttime, slots)` — бронирования; один слот — 30 минут; `starttime` — текст вида `2012-09-14 09:00:00`.
